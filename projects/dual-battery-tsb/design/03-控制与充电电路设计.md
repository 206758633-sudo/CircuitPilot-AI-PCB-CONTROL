# DBTS-A01 控制与充电电路设计 v1.0（2026-10-28）

> 本文回答两个问题：**① 谁来判断外部电源存在、如何互锁四个 MOS；② 48V→29.4V 充电电路怎么做成完整电路。**

## 一、控制架构

```
        ┌─────────── 辅助电源（宽压） ───────────┐
EXT_48V ─┤ D2 ├── VAUX ── LM5017 ── 12V ── AMS1117 ── 3V3 ── MCU
INT_24V ─┤ D3 ├──┘        (100V buck)              (LDO)      STM32G030F6P6
        └─────────────────────────────────────────────────────┘

        ┌──────── 检测 ────────┐      ┌──── MCU 判断 ────┐      ┌── 硬件互锁 ──┐
EXT_48V ─┤ 330k/22k 分压 ├─ ADC ─→ │ 模式状态机       │ ─→ EN_EXT ─┤ 74HC00 ×4 ├─→ U2/U3.INP
INT_24V ─┤ 100k/12k 分压 ├─ ADC ─→ │ （见真值表）     │ ─→ EN_INT ─┤ (NAND 网络)├─→ U4/U5.INP
VDC     ─┤ 330k/22k 分压 ├─ ADC ─→ │                  │ ─→ CHG_EN ─→ 充电使能
        └──────────────────────┘      └──────────────────┘      └──────────────┘
```

## 二、模式真值表（核心控制逻辑）

| EXT_OK | INT_OK | 判定 | EN_EXT(G1/G2) | EN_INT(G3/G4) | CHG_EN | 说明 |
|---|---|---|---|---|---|---|
| 1 | 1 | 外置优先 + 同时充电 | **1** | **0** | 1 | 负载由 48V 供电，24V 电池充电 |
| 1 | 0 | 仅外置 | 1 | 0 | 0 | 无电池可充 |
| 0 | 1 | 内置供电 | 0 | 1 | 0 | 电池经 Q3/Q4 供负载 |
| 0 | 0 | 全断 | 0 | 0 | 0 | 深睡/保护 |

补充规则：
1. **EN_EXT 与 EN_INT 永不同时为 1**（否则 48V 直灌 24V 电池），由软件 + 硬件双重保证。
2. 切换时先断后通（dead time ≥ 5 ms），避免两路同时导通。
3. 欠压保护：VDC < 20 V 时 EN_INT=1、EN_EXT=0（电池自动接管）；VDC > 52 V 时两路全断。

### 硬件互锁（74HC00 四 NAND）

| 门 | 输入 | 输出 | 作用 |
|---|---|---|---|
| N1 | EN_INT, EN_INT | nINT = ¬EN_INT | 取反 |
| N2 | EN_EXT, nINT | **EN_EXT_A = EN_EXT ∧ ¬EN_INT** | 互锁后的外置使能 |
| N3 | EN_EXT, EN_EXT | nEXT = ¬EN_EXT | 取反 |
| N4 | EN_INT, nEXT | **EN_INT_A = EN_INT ∧ ¬EN_EXT** | 互锁后的内置使能 |

即使 MCU 跑飞同时拉高两路，硬件也会把两路都关死。

## 四、充电电路（48V → 29.4V / 3–5 A，CC-CV）

### 拓扑：同步 Buck + 数字 CC/CV 环

```
EXT_48V ──┬── C_IN 10µF×2 / 100V ──┬── Q_HS ──┬── L 22µH ──┬── INT_24V (29.4V CV)
          │                        │          │             │
          │                     LM5146      Q_LS         C_OUT 100µF×2/35V
          │                   (100V 同步    (同步整流)         │
          │                    buck 控制器)                   │
          │                        │                          │
          └── R_SHUNT 10mΩ ────────┴── INA240A1 ── ADC(电流) ──┘
                                   └── 分压 ── ADC(电压)
                                   └── MCU PWM+RC ── FB(CC/CV 调节)
```

### 关键参数

| 项 | 值 | 依据 |
|---|---|---|
| 输入 | 48 V（36–58 V） | 外置电池 |
| 输出 CV | **29.4 V** | 7S Li-ion 4.2 V×7 |
| 输出 CC | **3–5 A**（默认 4 A） | 用户给定 |
| 开关频率 | 250 kHz | 体积/效率折中 |
| 电感 | 22 µH / 8 A 饱和 | ΔI≈2 A |
| 采样电阻 | 10 mΩ / 3 W（2512） | 5 A → 50 mV |
| 效率估算 | ≈ 95 %（48→29.4 V） | 损耗 ≈ 6 W @ 120 W |

### CC/CV 控制方式

- **CV**：MCU 读输出电压，与 29.4 V 目标比较，PWM 经 RC 滤波送入 LM5146 的 FB 分压中点，微调反馈
- **CC**：MCU 读 INA240 输出（10 mΩ×5 A×50 V/V = 2.5 V），超 4 A 时下调 FB
- **保护**：过压 31 V 关断、过流 6 A 关断、超温 85 ℃ 降额
- 充电终止：电流降至 0.1C（≈ 400 mA）后转浮充 27.6 V

## 七、待确认

1. MCU 选 **STM32G030F6P6**（64 KB，TSSOP-20，国内好买）；若你想用现成开发板上的型号（如 STM32F103C8T6）我改成那个。
2. 充电电流默认 **4 A**（3–5 A 可调），CV 29.4 V；如果你电池是 8S LiFePO4（29.2 V）我再调。
3. 负载 2 kW 的 40 A 限流，我打算用 **INA240 + 母线检流 + MCU 关断**实现，不再加独立比较器，除非你要求硬件快速保护。
