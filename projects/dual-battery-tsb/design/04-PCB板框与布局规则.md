## 1. M-01 结论：板框尺寸

| 项目 | 定义 |
|---|---|
| 长 × 宽 | **120 mm × 80 mm** |
| 板厚 | 1.6 mm |
| 层数 | **4 层**（L1 信号/功率 · L2 完整 GND · L3 电源平面 · L4 信号/功率） |
| 铜厚 | 外层 2 oz（70 µm），内层 1 oz（35 µm） |
| 板材 | FR-4，TG170，无卤 |
| 表面处理 | 沉金 ENIG（大电流焊盘平整度优先） |
| 圆角 | R2 mm |

### 尺寸依据（不是拍脑袋）
1. **大电流通路**：24V 侧 40 A 连续（≈960 W）+ 2 kW 峰值。4 层 2 oz 下，40 A 需要 ≥ 8 mm 等效铜宽（或整片铜皮）。仅 VDC 母线 + Q1–Q4 + 母线电容 + TVS 就需要 ≥ 45 × 55 mm 的净区。
2. **母线储能电容**：2 × 1000 µF / 63 V 电解（单只 ≈ ⌀16 × 25 mm），加 SMBJ58A TVS，占 ≥ 35 × 30 mm。
3. **充电 Buck**：LM5146（QFN-20+EP，5×5 mm）+ 2 × DPAK MOS + 22 µH 功率电感（≈ 12×12 mm）+ 输入 10 mΩ 分流 + INA240 + 补偿网络，占 ≥ 45 × 35 mm。
4. **MCU 与辅助电源**：STM32G030F6（TSSOP-20）+ LM5017 + 100 µH + AMS1117 + 去耦，占 ≥ 35 × 30 mm。
5. **接插件**：XT60PW-M 三只（每只本体 ≈ 16 × 8 mm，需 ±3 mm 插拔空间），2×5 控制排针、1×4 SWD 排针。
6. **安装与加强**：4 × M3 安装孔 + 功率级散热铜皮。

→ 60 × 80（功率 = 半板）+ 60 × 80（充电 + 控制）= 120 × 80 mm，且留 8–10 mm 边缘布线/爬电余量。

## 4. 布线规则（按需求）

| 项 | 规则 |
|---|---|
| 48V 输入 → Q1/Q2 | 线宽 ≥ 6 mm（2 oz）或铺铜，加 6 × ⌀0.3 热/流 via |
| VDC 母线（40 A） | 铺铜连接，L1+L4 并联，等效 ≥ 16 mm² |
| INT_24V 充电输出 | ≥ 4 mm 或铺铜，3 A 连续 |
| 19.4V→栅极驱动 | 独立走线，远离 SW 节点 ≥ 2 mm |
| 栅极驱动回路 | 米勒钳位，栅极电阻贴 MOS 焊盘，回路面积 ≤ 60 mm² |
| 48V/63V 爬电 | ≥ 1.5 mm；48V 对地 ≥ 1.0 mm |
| SW 节点（充电） | 铜面积最小化，禁止平行长走线 |
| 检流 R24 | 开尔文走线，差分等长 ±0.5 mm |
| 时钟/I²C/ADC | 远离开关节点 ≥ 3 mm；ADC 分压地单点汇到 L2 |
| 过孔 | 普通 ⌀0.3/0.6；散热 ⌀0.3 × 12/器件 |

## 9. 本机 PCB 自动化流程的可用命令与坑（供后续复用）

**可用**：`pcb outline-set / outline-round / mount-holes / import-changes / power-planes / pour / pour-list / layout-lint / check / dump / place-constrained / auto-place / route-critical / autoroute / drc / save`。

**坑（每条都实测过）**：
1. 任何 PCB 写操作后引擎状态 stale → 下一次读写前必须 `easyeda doc reload --project "<项目名>"`，否则报 `STALE_READ` 或 "no document named"。
2. `pcb arrange --mode cluster/grid` **完全不认板框**，会把器件排到板外（实测 x 到 17919 mil）；不能用它做板内布局。
3. `pcb auto-place` 以主芯片当前位置为锚，主芯片在板外时它只会在板外堆；且会加重重叠（实测 16 → 34 处）。
4. `pcb place-constrained` 只负责边缘接口件朝向 + 主芯片，不做整体打包。
5. `pcb floorplan` 需要 S0 spec（`flow` 结构），本机没有示例/文档，试错未通过 schema 校验 → 弃用。
6. `pcb mount-holes` 偶发单角 `failed`，重跑一次或 `--corners` 单角补即可。
7. 网格落位必须按**实测 bbox** 留格：XT60 ≈ 640×744 mil、1000µF 电容 ≈ 640×640、DPAK ≈ 330×420；统一 300 mil 网格一定重叠。

## 10. M-01 修订 v2：板框放大到 130 × 88 mm（2026-10-29）

### 为什么改
第一版 120×80 mm 落位后虽 0 重叠/0 出板，但**布线跑完后 DRC 仍有 173 处间隙违规 + 23 处连通违规**。原因是密度过高：器件间实测最小间隙只有 1.4 mil 量级，而规则要求 6 mil（功率类 11.8 mil），布线器无论怎么绕都满足不了。用户选 **A 方案：放大板框**。

### 新板框
| 项 | v1（120×80） | **v2（130×88）** |
|---|---|---|
| 尺寸 | 4724 × 3150 mil | **5118 × 3465 mil**（含 R2 圆角后 5128×3475） |
| 面积 | 96 cm² | **114.4 cm²（+19%）** |
| 安装孔 | 4 × M3（内缩 157 mil） | 4 × M3（内缩 197 mil ≈ 5 mm） |
| 层叠 | 4 层 2oz/1oz | 不变 |
| 分区 | A 功率 / B 充电 / C 控制 | 不变（坐标随板放大重算） |

### 重排后的几何指标（`layout-lint`）
- 短路 **0** / 重叠 **0** / 出板 **0**
- 信号 ratsnest **32 009 mil**（v1 优化后 50 984 → 再降 37%；初版 110 831）
- 因为板更大，布线通道变宽，目标是让 Freerouting 能把 DRC 收敛到 0。
