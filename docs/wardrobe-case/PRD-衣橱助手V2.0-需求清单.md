## 1. 产品定位与场景（推断）

**一句话定位**：面向家用衣橱的「AI 衣物助手」——通过摄像头看衣物、麦克风+扬声器做语音交互、RGB 灯效做照明与状态反馈，并预留电机与触摸接口，由 Type-C 充电、内置 1S 锂电池供电，可软开关待机。

| 场景 | 用户价值（推断） | 对应硬件能力【实测】 |
|---|---|---|
| 衣物识别/搭配建议 | 拍照即得搭配建议、衣物数字化管理 | 24P FPC DVP 摄像头（U8）+ ESP32-S3（WiFi/BLE，16MB Flash/8MB PSRAM） |
| 语音问答/语音记账 | 免手操作，问“今天穿什么” | MEMS 麦（MIC1→ES7210）+ ES8311+NS4150B+扬声器 + AEC 回声参考 |
| 夜间取衣照明/氛围 | 开柜即亮、状态颜色提示 | 卫星板 5×WS2812B（5V）+ 主板 4×充电指示/1×电源指示 |
| 触控/按键交互 | 轻触或按键开关/配网 | 触摸电极接口 CN1 + POWER/NET 双按键 |
| 电动衣杆/柜门（待确认） | 自动升降/开门 | 5V 电机接口 U13 + LOCK 软锁存电源 |
| 便携/免布线 | 内置电池、Type-C 充电 | ETA9880 充电+5V boost + 1S 电池接口 |

**能力与场景的边界（PM 需要明确的）**：本板**没有**温湿度传感器、没有板载电机驱动、没有本地屏幕——因此“环境监测”“自动升降”只能作为外设/后续版本能力，V2.0 的固件范围应聚焦“视觉+语音+灯效+电源管理”。

## 2. 硬件系统拆解（全部【实测】，用作需求证据）

### 2.1 双板结构

| 板 | 尺寸（板框实测） | 器件数 | 贴装面 | 说明 |
|---|---|---|---|---|
| 主板 | 56.1 × 61.8 mm 异形（含圆弧/缺口） | 164 | 顶面 10 件（MIC1、USB1、R11/R12、R18、LED1、D11/D12/D13、U8）、底面 154 件 | 集成主控/电源/音频/接口 |
| 按键指示板 | 21.4 × 44.9 mm | 15 | 顶面 15 件 | 5×WS2812B + 2 按键（SW1/SW3）+ 2×3P 连接器（U16/U17）+ 去耦 |
| 板间连接 | — | — | — | 2 根 3P SH1.0 线缆（U14↔U16、U18↔U17），线序为 **1↔3 交叉**（见 IF-03/IF-04） |

### 2.2 电源树

```
USB-C VBUS(5V) ──ESD(D11/D12/D13)──> ETA9880(U2, 1S锂电充电 + 5V boost)
                                        ├─ BAT ──> 电池接口 CN5(ZH1.5-2P)
                                        └─ VOUT(5V) ──Q16(SI2305 PMOS, 软开关锁存)──> +5V
+5V ──SY8301(U6 buck)──> 3V3 ──ME6211C28(U7)──> 2V8（摄像头 AVDD）
                       │        └─ME6211C15(U20)──> 1V5（摄像头 DVDD）
                       ├─RC──> CODEC_3V3（ES8311）
                       └─RC──> ADC_3V3（ES7210）
BAT ──R10/R7 分压──> BAT_SAMPLE（ADC 电量采样）
LOCK(GPIO) ──R16/Q2(NPN)──> Q16 栅极（+5V 保持）；POWER 键 ──D1/R19──> Q16 栅极（关机态可开机）
```

【实测】网络/器件：`VBUS、BAT、VOUT、+5V、3V3、2V8、1V5、CODEC_3V3、ADC_3V3、AU_GND/AGND、BAT_SAMPLE、LOCK、STATE、BUTTON`。

### 2.3 计算与存储

- **ESP32-S3-WROOM-1-N16R8**（U1，16MB Flash / 8MB PSRAM，WiFi 2.4G + BLE）【实测：C2913202】
- 3.3V 供电、RESET（EN）、IO0_BOOT 启动模式；USB 原生 D+/D-（IO19/IO20）与 UART0（U0TXD/U0RXD）均引出到调试链路。
- 12MHz 晶振 X1 供 USB Hub CH334F 使用（ESP32 模组内置 40MHz）。

### 2.4 视觉链路

- **24P 0.5mm FPC**（U8，HX 0.5-24PIN）接外部 DVP 摄像头模块：8-bit D0–D7 + PCLK + XCLK + VSYNC + HREF + PWDN + RESET + I2C(SCL/SDA) + 2V8/1V5/AVDD_2V8/AGND【实测 pinout 见附录 C】。
- 主板丝印有 `Camera` 标识；摄像头型号/分辨率不在 BOM（模块外购，见 Q2）。

### 2.5 音频链路（含 AEC）

- **MIC1（ZTS6216，MEMS 麦克风）** → 偏置 R51/C43（ADC_MICBIAS12）→ RC 滤波（R49/R50/C65/C66）→ **ES7210（U10，4 通道 ADC）** 通道 1；
- 扬声器差分输出 **OUTP/OUTN 经 R34/R35 回到 ES7210 通道 3**，作为回声消除（AEC）参考；
- **ES8311（U9，codec）** I2S（BCK/WS/MCK/DO：IO14/IO13/IO38/IO45）接入 ESP32，输出 → **NS4150B（U11，功放）** → **J7 扬声器 2P 差分**；`PA_EN` 控制功放使能；**ES7210 的 ADC 数据经 IO12_I2S_DI 回传 ESP32**；
- 数字侧：ES7210/ES8311 共用 I2C（IO1/IO2），两芯片 I2S 主从时序由 ESP32 提供。

### 2.6 交互与灯效

- 卫星板 **SW1 → BUTTON0 →（线缆）→ BUTTON**：软开关 POWER 键（关机态经 D1 拉低 Q16 栅极开机；开机后 MCU 用 LOCK 保持；STATE 供 MCU 读键态）；
- 卫星板 **SW3 → IO0_BOOT0 →（线缆）→ IO0_BOOT**：NET 键（运行时 GPIO0，用于配网/恢复出厂）；
- **触摸**：CN1（GH1.25-2P）→ `TOUCH10` → ESP32 触摸通道；
- **灯效**：卫星板 5×WS2812B-2020（5V 供电，数据由主板 `LED` 网络经 U14/U16 送入 LED7，再串联）；主板 4×绿色 LED（LED2/3/4/6）由 ETA9880 三个状态引脚以矩阵方式驱动（充电指示），LED1 红色为电源指示；
- 主板丝印：`Motor / Touch / Speaker / Camera / LED / MIC1 / RST / NET / POWER / NET&POWER / Wardrobe Assistant V2.0.0919`。

### 2.7 USB 与调试

- Type-C 16P（USB1）：VBUS/GND/D+/D-/CC1/CC2，CC 各 5.1kΩ（R11/R12）下拉，USB 数据加 RCLAMP0521T ESD；
- **CH334F（U5）USB2.0 Hub**：上行接 Type-C，下行两路 → ESP32 原生 USB（IO19/IO20）与 **CH340K（U4）USB-UART**；CH340K 的 DTR/RTS 经 Q1 自动下载电路控制 RESET/IO0_BOOT；
- 单 Type-C 同时承担充电、固件下载、串口调试与 ESP32 USB 功能。
