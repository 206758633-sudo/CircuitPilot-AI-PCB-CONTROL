# 衣橱助手 V2.0 —— PCB 板需求清单（PM 版 v1.0）

> **定位**：把"产品需求"里**只跟 PCB/PCBA 本身有关**的部分单独抽出来，形成研发能接、采购能核、产品能验收的"板级需求"。
> **边界**：本文只写"板子必须满足什么特点和能力"，不写怎么设计（叠层、走线、DRC、选型细节由研发负责）；产品经理验收样机、报告、证书和试产结果，不参与电路设计。
> 产品需求基线见 [产品需求分析-衣橱助手V2.0-PM版.md](产品需求分析-衣橱助手V2.0-PM版.md)；工程验证细节见 [工程附录](PRD-衣橱助手V2.0-需求清单.md)。
> **面向普通产品经理的版本**（大白话、含具体接口型号）见 [PCB 板需求-产品经理版](PCB板需求-产品经理版.md)；本文偏工程验收口径。
> 各外设/接口的具体型号（摄像头 OV5640、电池 582830、喇叭 1811、舵机 2g、板间 SH1.0 3P 线等）见 [需求清单（普通产品经理版）](需求清单-普通产品经理版.md) 第四节"外设接口一览"。

## 0. 一页纸：PCB 需求管什么、不管什么

| PCB 需求要管（本文范围） | 不属于 PCB 需求（别混进来） |
|---|---|
| 板级功能：供电/充电、开关机、按键、灯、音频、摄像头、无线、调试 | 产品卖点、App/云端、AI 算法、搭配推荐策略 |
| 板级形态：双板结构、尺寸、安装孔、开孔对位、连接器可及性 | 外观 ID、材质颜色、包装设计 |
| 板级可靠与安全：电池安全、ESD/EMC、温升、寿命、环境、跌落 | 认证证书本身（板子需支持通过认证） |
| 板级可制造：工艺、BOM、DFM、产测、丝印版本、交付文件 | 整机说明书文案、售后话术 |
| 板级交付：样机、测试报告、维修备件、变更通知（PCN） | 整机定价/渠道/营销 |

## 8. 验收方式（PM 怎么验 PCB）

1. **样机验收**：PCB-V-01 样机按"用户场景脚本"走查（开关机、拍照、语音、灯效、充电、配网），不测电路细节；
2. **报告验收**：PCB-V-02/PCB-R-* 看研发/第三方报告（DFM、DRC、EMC、ESD、安规、寿命、环境），报告结论合格即可；
3. **认证验收**：PCB-R-01/02/08 看证书（3C/SRRC/电池认证等）；
4. **试产验收**：PCB-MF-01~07 看试产报告（良率、产测直通率、BOM 齐套、交期）；
5. **文档验收**：PCB-MF-05/06、PCB-V-04 看文件与版本记录。

> 产品经理不参与电路设计与调试；若报告/样机不达标，退回研发整改，需求 ID 用于问题单追溯。
