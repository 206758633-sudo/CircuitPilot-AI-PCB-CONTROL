## 1. 产品定义

### 1.1 一句话定位

**一款装在衣橱里的 AI 衣物助手：能"看"衣物（拍照识别）、能"说话"（语音问答/播报）、能"亮"（夜间照明与氛围灯），可按键/触控操作，内置电池、Type-C 充电。**

### 1.2 产品形态与组成

案例板文件显示这是一块**智能衣橱助手的控制核心**，不是完整整机。整机大致由以下部分组成：

| 组成 | 说明 | 谁来负责 |
|---|---|---|
| 主控板（约 5.6×6.2cm） | 计算、无线、电源、音频、灯效、接口 | 硬件研发 |
| 按键/指示灯板（约 2.1×4.5cm） | POWER/NET 两键 + 5 颗 RGB 灯 | 硬件研发 |
| 外接摄像头模组 | 通过排线连接到主控板（型号未定） | 结构+采购+硬件 |
| 扬声器 | 外接（音腔由结构设计） | 结构+声学 |
| 内置锂电池 | 1S 锂电，Type-C 充电 | 硬件+结构+认证 |
| 触摸电极（预留） | 可做触摸开关/手势（V2.0 是否启用待定） | 结构+硬件 |
| 电机/电动部件（预留） | 可驱动电动衣杆/柜门（V2.0 是否启用待定） | 结构+外设 |
| 外壳/安装件 | 挂钩/磁吸/螺丝固定于衣橱 | 结构+ID |

### 1.3 目标用户与场景

| 场景 | 用户痛点 | 产品动作 | 用户价值 |
|---|---|---|---|
| 早上选衣 | 不知道穿什么、搭配耗时 | 拍照/语音问"今天穿什么"，给出搭配建议 | 省时间、少纠结 |
| 找衣物 | 衣物多、找不到某件 | 拍照记录 + 语音查询衣物位置 | 衣物数字化管理 |
| 夜间取衣 | 开灯刺眼/摸黑 | 开柜感应/语音开灯，柔和 RGB 照明 | 不打扰家人、方便 |
| 双手忙时 | 手上拿东西不方便按键 | 语音唤醒、免手操作 | 更自然的交互 |
| 配网/升级 | 不会设置、固件不更新 | POWER/NET 按键一键配网，App 引导，OTA | 用得久、越用越好 |
| 充电 | 忘记充电/找不到线 | Type-C 通用充电、充电/低电指示 | 无续航焦虑 |

### 1.4 核心卖点假设（需产品确认）

1. **能看会说**：摄像头+语音组合，从"智能灯"升级为"衣物助手"；
2. **衣柜即装即用**：内置电池+Type-C，无需改柜体布线（挂钩/磁吸安装）；
3. **有温度的交互**：RGB 灯效+语音反馈，夜间体验友好。

| 尺寸 | 主控板约 5.6×6.2cm，按键板约 2.1×4.5cm | 整机可做小巧壁挂/挂钩式 |
| 制造复杂度 | 4 层板、双面贴装、50 行物料/179 个器件 | 属中等偏复杂 PCBA，需评估代工厂能力与成本 |
| 物料风险 | 50 行物料中约 31 行为"扩展库"、部分物料信息不全 | 成本/交期/齐套存在不确定性，需工程补全 |
| 版本信息 | 硬件丝印为 V2.0.0919，工程文件日期 2026-10-16，原理图标题栏仍是旧工程名 | 版本管理不规范，量产追溯有风险 |
| 能力边界 | 无屏幕、无温湿度传感器、无板载电机驱动 | **不要承诺**屏幕交互、环境监测、大功率电动功能 |

## 3. 需求清单（产品语言）

> 优先级：**P0**=V2.0 上市必须；**P1**=核心体验/交付必须；**P2**=可延后到 V2.1。
> "验收标准"尽量写成用户可感知/可测量的结果；带"待定"的指标需产品确认。
