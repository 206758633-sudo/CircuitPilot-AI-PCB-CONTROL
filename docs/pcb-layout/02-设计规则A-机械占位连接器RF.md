# 设计规则 A：机械 · 占位 · 连接器 · 射频（MECH / SPACE / CONN / RF）

> 适用对象：ESP32 测试板（板框估算 ≈70×48 mm）。板面事实见 `_baseline-板面基线.md`，问题清单见 `01-布局诊断.md`，
> 电气/丝印/制造/装配规则见 `03-设计规则B-电气丝印制造装配.md`。
>
> 本文件把「元件不许叠、位置要合理、接线方式与方向要对」拆成 **63 条可判定规则**：
> MECH 15 条（板框/边缘/拼板/Mark/定位孔）· SPACE 18 条（占位与禁止叠放/间距矩阵）·
> CONN 17 条（朝向/插拔空间/线缆禁布区）· RF 13 条（天线禁布区/缝合/GND）。
>
> 编号规则：`前缀-两位序号`（如 `CONN-04`），下游 `04-规则落地校验清单.md` 与
> `rules/board-layout-rules.json` 原文引用，**不得改写编号、不得重排**。
>
> 依据代号：`IPC-2221B`（通用设计）、`IPC-7351B`（焊盘/courtyard）、`JLC`（厂规默认，以板厂确认单为准）、
> `EXP`（工程经验值）、`DS`（器件 datasheet）。凡无标准条款对应的数值一律标 EXP 或 JLC，不臆造条款号。
>
> 等级：「硬门禁」= 违反即阻断投产；「推荐」= 不阻断，但需书面签核接受理由。
> 距离一律指**边缘到边缘**；单位 mm，未注公差 ±0.05 mm；图像测量误差 ±10%，只用于判「明显违反」。

### 1.3 边缘/拼板出图与判读要求（判定方法补充）

- 机械层按用途拆开且不得混画：`MECH-OUTLINE`（唯一闭合外形）、`VCUT`（V-CUT 线，直线）、`PANEL-EDGE`（工艺边）、`TOOL-HOLE`（定位孔）、`MARK`（光学点）、`CABLE-KO`（线缆禁布区）；出图前逐层做「非空 + 闭合」检查。
- 拼板图必须同时交付四件：拼板布置图、V-CUT 深度/邮票孔孔距与孔径标注、Mark 与定位孔坐标表、拼板坐标文件（单板坐标 + 阵列偏移）。缺任一件，MECH-07~12 视为未判定。
- 与板厂确认单逐项签：板厚、翘曲、V-CUT 残厚、邮票孔孔径、最小成品孔径——五项对齐后 MECH-02/03/08/09 才可签「通过」。
- 3D 装配：导出 STEP，元件模型按 courtyard + 实际高度建模，用于 MECH-15 与 CONN-02/CONN-12 的干涉与净空走查。
- 可自动化项（写进 DRC/脚本）：焊盘到板边、本体到板边、Mark 数量与共线、NPTH 孔径、keepout 与元件层求交。
- 不可自动化项（必须 3D 人工走查 + 截图存档）：翻盖开启高度、手指/治具伸入空间、插头插入长度、线缆弯曲包络。

## 2. SPACE —— 元件占位（courtyard）与「禁止叠放」

### 2.1 判定基准（先读这一段再看表）

- **间距的定义**：本文所有「间距」= **两个器件 courtyard 之间的最小距离**，不是焊盘边到焊盘边，也不是本体边到本体边。焊盘间距是 DFM 的事，courtyard 间距才是占位的事。
- **courtyard（占位框）**：器件本体最大包络（长宽高 + 制造公差 ±0.05 mm，含焊点外溢 0.05 mm）向外均匀外扩后的矩形。本板取 IPC-7351B **Nominal（Level B）**，即外扩 0.25 mm。连接器、模组等有 datasheet 推荐 footprint 的器件，直接用其自带 courtyard，**禁止自造缩小**。
- **高度包络**：器件本体最高点 + 焊接后抬升（0.05 mm）+ 生产公差（0.10 mm）。3D 干涉检查用的是这个包络，不是丝印框。
- **双跑判定**：每个器件对必须同时跑 ① courtyard-to-courtyard 2D DRC ② 3D 实体/高度干涉检查。**任一报错即判不通过**，不允许用「2D 看着还行」放行。
- 单位统一 mm，未注公差 ±0.10 mm。板坐标系取板左下角为原点，X 向右、Y 向上（下文裁定值均按此记法）。

### 2.3 判定口径的三个易错点（写给人看，不是给 DRC 看）

1. **「看着没碰」不算通过**。courtyard 相交但本体没碰，仍然判硬违规——因为回流焊时焊点外溢、返修时烙铁头 / 热风嘴都要占空间。A-06 就是典型：模组三面焊盘与邻件净距 ≤0.5 mm，本体可能没碰，但 courtyard 已经相交。
2. **高度也要交**。两个器件 XY 不交但高度包络在 Z 向射影重叠，例如 USB-C 本体悬在模组本体正上方——这在 3D 上是碰撞，SPACE-02 同样判死。
3. **吸嘴空间是本体的事**。SPACE-14 用的是本体间距而非 courtyard 间距，因为吸嘴从正上方下压，只认本体最大外轮廓 + 半径。两种判定要分开跑，别混用一个数。

## 4. RF —— 2.4 GHz 天线禁布区与模组摆放

### 4.1 先自己算一遍（2.4 GHz，不许只抄结论）

1. **自由空间波长 λ0** = c / f = 2.998×10⁸ m/s ÷ 2.400×10⁹ Hz = 0.1249 m ≈ **125 mm**。
   （按中心 2.44 GHz 算是 122.9 mm；工程上仍取 **λ0 = 125 mm** 作为保守基准。）
2. **有效介电常数 εeff**：FR4 表层微带，εr ≈ 4.2–4.6，考虑空气-介质混合后 εeff ≈ **3.3–4.0**。
3. **介质内波长 λg** = λ0 / √εeff：
   - εeff = 3.3 → √3.3 = 1.817 → λg = 125 ÷ 1.817 = **68.8 mm**
   - εeff = 4.0 → √4.0 = 2.000 → λg = 125 ÷ 2.000 = **62.5 mm**
   - 结论：λg ≈ **62.5–68.8 mm**，取整 **λg = 63–69 mm**。
4. **缝合孔间距上限 λg/20**：
   - 62.5 ÷ 20 = **3.13 mm**
   - 68.8 ÷ 20 = **3.44 mm**
   - 结论：**λg/20 ≈ 3.1–3.4 mm**，工程写成 **≤3.0–3.5 mm**；本板硬门禁取保守值 **≤3.0 mm**，3.5 mm 仅作放宽推荐。
5. **交叉验证（重要，证明 15 mm 不是拍脑袋）**：λg/4 = 62.5÷4 … 68.8÷4 = **15.6–17.2 mm**。天线正前方「15 mm 净空」正好 ≈ λg/4，即近场强耦合区边界。所以 RF-02/RF-03 的 15 mm 是有物理依据的量化值，而不是经验口号。

### 4.5 改图后的 RF 实测验证（规则达标 ≠ 性能达标）

courtyard 与禁布区只能保证「不该有的东西不在」，不能保证辐射效率。改完图必须补三项实测：

**ZCLR-05 为什么是「推荐」而不是硬门禁**：模块投影下有 >5.00 mm 的高件不必然违规（本例插合 8.5 mm、C40 7.7 mm 仍余 0.8 mm），但它意味着**必须签核确认模块底面没有向下凸出的元件**（否则 0.8 mm 余量会被模块自己的电容/焊点吃掉）。真正的硬上限是 ZCLR-03（区内件高度 ≤ 插合高度−0.50 mm）。

**ZCLR 组的判定口径（写给人看）：**

1. **2D 不重叠 ≠ 3D 不干涉**：`C39` 与 `Q5` 在 2D 上只差 4.5×5.3 mm，但电解本体 Φ16 / 25 mm 高出 TO-252（2.3 mm）近 23 mm，属于"看着没压、装着压死"。凡高度差 >2.00 mm 的相邻件必须做 3D 复核。
2. **"排针连接高度"必须落到数值**：2.54 mm 单排针（PZ254 类）裸焊时模块底面 ≈8.5 mm；配 2.54 mm 双排母/加高排母时 ≈11.0 mm。这个数必须写进 assemblyZones[].matingHeightMm，不许用"差不多"。
3. **搬走 ≠ 解决**：把高件挪出装配区后，必须重跑 ZCLR-03/05 + ZCLR-02（新位置不得压别的件），并核对新位置的走线代价（见 `03` §8 MOVE 组）。

## 6. 依据分级说明（为什么不给一堆标准条款号）

本文刻意区分三类依据，避免把工程经验包装成标准条文：

- **可直接引用的标准**：只有两类——IPC-7351B（courtyard 概念、三档密度等级、极性标识）与 IPC-2221B（结构/间距的通用原则）。凡引用均指概念与档位，不虚指具体小节号。
- **器件 datasheet**：ESP32-WROOM 类模组的天线端净空、接地建议、馈点位置。这类数值以官方 datasheet 的推荐布局为准，本文的 15 mm / 5 mm 与其量级一致。
- **EXP（工程经验值）**：间距矩阵中的具体毫米数（0.15 / 0.20 / 0.30 / 0.50 / 1.00 / 1.50 / 2.00 / 3.00）、缝合孔取值 3.00 mm、吸嘴避让 0.30 mm。这些是行业通用实践的量级，**不是**某条标准的强制条款；若客户规范更严，以客户规范为准。
- **JLC（厂规默认）**：贴装顺序、吸嘴空间、点胶加固、拼板铣边公差 ±0.50 mm、阻焊/丝印工艺限制。取值以嘉立创公开工艺能力表为准，换厂需重新核对。

**冲突处理顺序**：客户规范 > 器件 datasheet > 本文 EXP/JLC > 通用经验。任何一处按更严值执行都不算违规；按更松值执行必须在评审记录里写明依据。
