# 板面基线（工作底稿，供规则编写与校验共用）

> 本文是 2026-10-18 这块 ESP32 测试板的图像取证结果，作为「布局设计规则」与「落地校验清单」的共同事实底座。

## 0. 标定与误差声明

| 项 | 值 | 方法 |
| --- | --- | --- |
| 比例尺 | ≈ 24 px/mm（0.042 mm/px） | 双标定：顶部 FFC 接触排按 0.5 mm 间距点数；ESP32-WROOM 类模组按 18×25.5 mm |
| 估算板框 | ≈ 70 × 48 mm | 板面平行四边形包围盒 |
| 丝印字高 | ≈ 22 px ≈ 0.9 mm | 位号 "C25" 字高像素 |
| 测量误差 | ±10%（透视 + 抗锯齿） | 只用于「量级判断」 |

绝对值判定（如 0.3 mm 还是 0.5 mm）一律以标准条款为准；图像测量只用于证明「明显违反」或「明显紧贴」。

## 2. 缺陷清单（带严重度）

严重度：**P0** = 阻断投产（3D 干涉 / 无法装配 / RF 失效）；**P1** = 影响良率或装配效率；**P2** = 可读性与工艺优化。

### A. 实体/占位重叠（P0）
- **A-01** 顶部 USB-C 母座与模组天线端实体相接（间隙 ≈0），属 3D 碰撞 + 天线禁布区被金属侵占。
- **A-02** 左中 J7 与下方白色连接器互相穿插；两者自制外框丝印交叉并越出板边。
- **A-03** 下右两个 FFC 开口相对、净距 1.5–2.0 mm，柔性排线无法插入，治具无法夹持。
- **A-04** J52 FFC 本体越出上板边，执行器压板边；翻盖需要 1.5 mm 以上开启空间，无空间。
- **A-05** USB1 壳体与背后 0402 电容阵列净距 <0.3 mm；USB 插拔侧向力直接传到电容焊点。
- **A-06** 模组三面焊盘与周边元件（上 SOT-23-6、下 SOT-23-3、右 QFN）净距 ≤0.5 mm，低于模组 courtyard。

### B. 朝向与接线方向（P0/P1）
- **B-01** 插拔口朝向分散在 4 个方向（上、下、左、右上），线缆走向互相冲突。
- **B-02** USB1 开口斜向左下，与板边不垂直；线缆自然垂向与板边成角，应力集中。
- **B-03** 模组天线端朝板内且正对板边仅 ≈6 mm，天线主瓣被板边、USB-C 金属座和铺铜包围。
- **B-04** 两个 FFC 应朝同一板边、同一方向出线（或改为侧插），现方案必须拆板才能插线。
- **B-05** 调试接口（USB1、J52、下右 FFC）分居三侧，产线治具与夹具无法一次定位。
- **B-06** 按键位于右上角与右下角，操作方向无标识，手指操作空间被连接器和 LED 挤占。

### C. 丝印（P1）
- **C-01** 位号互相叠压（≥12 处）：`UR52/C25/UR26/C15`、`C65/C70`、`C38/C5/C7`、`3R3/K51`、`R4/R6`、`R36/R41`、`U10/C86`、`LED5/LE U1`、`U5/U902`、`DR59/R59`、`C39/C5/C32`、`C48/C4?`。
- **C-02** 位号压在焊盘/器件本体上：顶部 SOT-23-6 的 `R59`、底部 `LED5`、右侧 `U10`、`D4`。
- **C-03** 丝印被板边截断（顶部 `UR52…` 一排）。
- **C-04** 字高与字距不统一，笔画粘连（`U38d?`、`0.567`）。
- **C-05** 缺 1 脚/极性标识：FFC 第 1 脚、USB 方向、二极管阴极、电解/钽电容正极均不可辨。
- **C-06** 存在与器件无关的长丝印线（底部斜长线、左侧大矩形框），既非外框也非装配标识。

### D. 边缘/机械（P0）
- **D-01** 连接器相对板边位置不一致：有的越边（J52、USB1），有的距边 2–3 mm（下右 FFC）。
- **D-02** 元件与焊盘离板边过近，V-CUT/铣槽路径会切到焊盘与本体。
- **D-03** 板面未见定位孔、Mark 光学点、拼板工艺边。
- **D-04** 无安装孔/螺钉柱，按键与连接器无机械支撑与应力释放。
- **D-05** 未见测试点（TP）与探针可及区域。

### E. 电气/RF 布局（P0/P1）
- **E-01** 天线禁布区被 USB-C 金属座、SOT-23-6、板边铜箔侵占。
- **E-02** 去耦电容散落板面（左侧 C43/C89/C28、左下 C62/C63、右下 C56/C57/C68/C69），距 IC 电源脚远超 2 mm。
- **E-03** 复位/BOOT 按键距模组远（右上、右下），走线穿越密集区。
- **E-04** 无 RF GND 过孔围栏/缝合阵列可见。
- **E-05** USB 差分对（D+/D−）与 USB1 的斜置朝向矛盾，等长与 90 Ω 参考面难保证。

## 3. 规则命名空间（三位一体编号，供规则文档/JSON/清单共用）

| 前缀 | 主题 |
| --- | --- |
| `MECH` | 板框、边缘、拼板、工艺边、Mark、定位孔、翘曲 |
| `SPACE` | 元件占位、courtyard、禁叠、间距矩阵 |
| `CONN` | 连接器选型与朝向、插拔/接线空间、线缆禁布区 |
| `RF` | 天线禁布区、模组摆放、GND 缝合 |
| `PWR` | 电源、去耦、回路、热 |
| `SILK` | 丝印字高线宽、位号、极性标识、禁上焊盘 |
| `DFM` | 焊盘、阻焊、过孔、拼板、贴片/回流工艺 |
| `DFA` | 装配、治具、测试点、ESD |
| `GATE` | 验收门禁与放行流程 |

每条规则必须给出：编号、名称、**硬门禁/推荐**、可判定数值、判定方法、依据（IPC/JLC/厂规）、本板适用对象。
