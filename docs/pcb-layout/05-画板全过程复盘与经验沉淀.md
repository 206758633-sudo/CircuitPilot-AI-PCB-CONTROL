# DBTS-A01 画板全过程复盘与经验沉淀

> 板：**DBTS-A01 双电池无缝切换测试板**（48 V 输入 → 27 V 预稳压 → 外置 6S 3 A 充电模块 → 6S 电池；27 V → 5 V → 3.3 V 系统供电）
> 时间：2026-10-28 20:50 → 2026-10-29 16:10（约 19 小时，含一次需求变更、两次电气更正、一次 3D 装配返工）
> 工具链：EasyEDA Pro 3.2.186（`easyeda` CLI，`--skip-version-check`）+ CircuitPilot Runtime + 自研 Python/Node 脚本（布局退火、板图渲染、审计）
> 本文不是流水账，分三层：**发生了什么（可核对的事实）→ 为什么会踩坑（根因）→ 沉淀成了什么（规则/脚本/流程/SOP）**。

## 2. 关键设计决策与依据

| # | 决策 | 依据（数字来自本板实测/计算） |
| --- | --- | --- |
| 1 | 充电改**外置 6S 3 A 模块**，本板只做**27 V 预稳压** | 普通开关电源无恒流，锂电充电不受控；模块自带 CC/CV/NTC/OVP/OCP；模块 VIN ≤28 V → 27.0 V 留 1 V 余量 |
| 2 | 48 V → 27 V 用 LM5146，R25 360 k/R26 11 k | FB 0.8 V ×(1+360/11) = **26.98 V**；6S 满电 25.2 V 需 VIN ≳26 V |
| 3 | 降压输出定 **5 V** 而非 12 V | 12 V→3.3 V 线性压差过大、耗散高；5 V→AMS1117 耗散降约 **80%** |
| 4 | 6S 一律升额：C26–C30 → **50 V**，L2 → **22 µH/5.6 A** | 25.2 V 电池/27 V 母线对 25 V 电容 = 超压；L2 峰值 **4.1 A**（3.05 A DC + 2.1 A p-p），2.7 A 件会饱和 |
| 5 | 模块**直接对插**在板下，J7/J8 改 1×6、中心距 **47.0 mm** | 模块实物照片标定 15.30 px/mm：两列焊盘中心距 47.0 mm（旧 68.1 mm 差 21 mm 插不上） |
| 6 | 加 **J12 默认开路跳线** | 模块引脚分配是"成对出现"的推断；即使猜错，6S 电池也不会经模块地平面短路 |
| 7 | 3 A 充电铜加宽到 **40 mil** | 3 A 走线载流 + 温升预算；J7/J8 单针 2.54 排针额定 3 A 已到顶 → 建议模块设 2.5 A 或双针并联 |
| 8 | `C39`(Φ16/25 mm) 与 `L2`(8.1 mm) 放**右下角空区**而不是"挤一挤" | 装配区（模块 50×30 投影，插合 8.5 mm）根本容不下；迁出后 DRC 0、装配净空硬门禁 PASS |
| 9 | `SW_NODE` 拉长到 1911 mil **接受** | 物理约束优先于 EMI 理想值；代价进 `nets[].approvedBy` 具名留痕（MOVE-02/03 → REVIEW） |
| 10 | 布局用**模拟退火**而不是手工拖 | ratsnest −54%、交叉 −72%，且可复跑；手工摆放的"齐整度"另用 `silk-set`/对齐脚本补 |

### 3.1 工具/平台类（最耗时，也最容易沉淀）
| 现象 | 根因 | 解法 | 固化 |
| --- | --- | --- | --- |
| "已落件"回读发现没保存 | CLI 写入后未确认 | 每次写后回读校验（`saved:true` + 重新 `ls`） | 工作记录 §环境接管 |
| `doc reload` 之后连接器卡死 | 平台 connector 状态机缺陷 | 不再用 `doc reload`；用 `pcb save` | eda-workspace.md「两个硬约束」 |
| `pcb track-delete` 删不干净 | **它不删过孔** | 布线前保证 0 走线 0 过孔 0 铺铜；批量 `via-delete` | DRC 收敛章 |
| 过孔从 198 涨到 **1009** | 历次布线叠加 | 同上，干净板起步 | 同上 |
| DRC 一直有 4 处"假违规" | `mount-holes` 重复执行累积 **7 个旧禁布区** | `pcb fill delete` 清掉 | 同上 |
| Freerouting 跑不起来 | v1.9 纯 GUI；v2.5 native 序列化崩溃；本机无 JDK | 装 OpenJDK 27，用 **v2.5 JVM jar** | 工作记录 §00:40 |
| SES 导入后过孔翻倍（191→389） | 导入会**叠加**在已有布线上 | `pcb rip-up` → `import-autoroute` → `pour-rebuild` | v2 变更章 |
| `import-changes` 把替换件丢到板边 | 平台不保留"被替换件"坐标 | `pcb modify --patch` 逐个搬回（84 次写） | 6S 章 |
| `sch replace` 全部报错 | 连接器 handler 缺失 | 「删 → 同坐标重放 → 导线自动重连」 | 6S 章 |
| `sch connect --direction left` 接错网 | 该方向在这批引脚上不稳定 | 改 `--direction up/down`，或先挪开元件 | 排针章 |
| `sch list --include-pins` 返回 null | 新放置件旧缓存 | 用 `schematic.export.netlist` 导出 ENET 逐脚比对 | 排针章 |
| `pcb snapshot` 被拒 | EasyEDA 标签页隐藏时画布不重绘 | 改数据自渲染（Python/Pillow） | 交付物 |
| Gerber 导不出 | CLI 无通道 | 只能 GUI「制造 → 输出 Gerber」 | 遗留 |
| DRC 里 1 条 `Netlist Error` 清不掉 | 工程内**重复旧图纸 + PCB1_1** 一起比网表 | ENET 证明本板 0 差异；删除需用户点头（不可撤销） | 遗留 |

| 1 | **先算后画**：所有选型先用一张核算表定死 | 48V→27V→25.2V/3A 的电流、纹波、峰值 4.1 A、功耗 75.6 W；C26–C30 升 50 V；L2 换 5.6 A | README §3 核算表 |
| 2 | **先定约束，再摆器件**：板框/接口/装配区/维护空间是硬约束 | J7/J8 中心距 47.0 mm、模块投影 50×30、插合高度 8.5 mm | `assemblyZones[]` 输入契约 |
| 3 | **2D 间隙 ≠ 3D 净空**：Z 轴必须显式建模 | Φ16/25 mm 电解塞进 8.5 mm 插合区 | ZCLR 9 条 |
| 4 | **门禁化**：能脚本判的绝不靠"我记得" | 10 道门禁；`layout-lint --gate`、`confirm-tier`、DRC/DFM | `evaluateGates` |
| 5 | **证据链**：每一步都留可回读的数据，而不是截图结论 | board/tracks/vias/pours/drc/dfm/net-report + `auditHash` | `artifacts/final-5v-chg/` |
| 6 | **变更必须登记并量化影响** | C39/L2 搬迁后 `SW_NODE` 140→1911 mil、环路 ×38，具名接受 | MOVE 5 条 |
| 7 | **缺数据 = REVIEW，不猜；阈值可覆盖但必须进哈希** | 高度缺失→REVIEW；`limits` 覆盖进 `auditHash` | 引擎 + 测试 |
| 8 | **真机返工案例 = 回归样板** | `DBTS-A01-MODULE-BEFORE/AFTER` 进了 fixtures | 21 条引擎测试 |

### 4.2 六条工具纪律

1. **写后必回读**：CLI 说成功不等于真的落盘（`saved:true` + 重读）。
2. **改前先确认目标 UUID**：工程里有重复旧图纸/旧 PCB，操作错对象=白干（`doc ls` → `pcb save` 前后核对）。
3. **干净板起步**：布线前 0 走线/0 过孔/0 铺铜/0 禁布区，否则历史垃圾会伪装成"新问题"。
4. **单文档单一事实源**：规则数值只在 md 表里写一次，JSON 由脚本生成、文档由脚本回写。
5. **单位与坐标系先归一**：mil/mm、10 mil 缩放、镜像坐标（模块挂板下）都曾导致误判。
6. **截图不可用作量测证据**：要么反算（单应变换），要么用数据渲染。

### 4.3 三个反模式（这次差点踩/踩过的）

| 反模式 | 后果 | 正解 |
| --- | --- | --- |
| 用"看起来空"的地方放高件 | 红框返工、重布 | 先算装配区 + 维护环带（ZCLR-03/04/05） |
| 用"改小间距"换取布线通过 | DRC 473 处违规来回修 | 改 DSN 规则源头，留余量（6.03 → 7.5） |
| 后处理修补（删过孔、扶正丝印） | 越修越乱 | 从**布线器/导出源头**改（盘中孔、丝印摆放） |

## 5. 可复用 SOP（下次画同类板照抄）

> 目标：从"能跑通"变成"一次做对"。每步都有**通过标准**，不达标不进下一步。

### Step 0 开工前（30 分钟）
- [ ] 确认板子目标：电压/电流/功率、接口、装配方式（直插/侧插/对插）、外壳与维护空间
- [ ] 确认工具链可用：CLI 版本、Java/Freerouting、截图/回读通道
- [ ] 建 `artifacts/<board>/` 与 `projects/<board>/records/`，从第一天就开始记录

### Step 1 电气核算表（半天）
- [ ] 一张表：输入范围 → 各级输出 → 峰值电流/纹波 → 器件额定选型（含电容耐压、电感饱和）
- [ ] 所有"决定选型"的数字写进 README，后续任何变更都先改这张表

### Step 2 原理图（1–2 天，门禁循环）
- [ ] 分页：电源 / 保护 / 功率监测 / MCU / IO / 充电
- [ ] 逐页 `sch gate`（check / bridge-check / drc）；`--all-pages` 不可靠就逐页
- [ ] 网表导出 ENET，逐脚比对；**不信 `sch list --include-pins` 的缓存**

### Step 3 板框 + 装配约束先行（关键改进）
- [ ] 板框、安装孔、Mark、工艺边、禁布区一次定死
- [ ] **在布局之前声明 `assemblyZones[]`**：模块矩形、插合高度、维护环带、允许的高件
- [ ] 生成 STEP/3D 或至少一张高度表（型号 → 本体高度 → 来源）

### Step 4 布局
- [ ] 接口件贴边、功率区/信号区/充电区划分
- [ ] 退火或脚本化摆放（可复跑），`layout-lint --gate` + `layout-score`
- [ ] 分档确认 `confirm-tier 1..4`（改布局后必须逐级重确认）

### Step 5 布线
- [ ] 干净板起步；外置布线器前先补 DSN 网络类间隙
- [ ] 导入后 `rip-up` 去重叠、`pour-rebuild` 收敛铺铜
- [ ] `pcb drc` 归零；功率网按载流加宽（本板 3 A → 40 mil）

### Step 6 丝印/盘中孔/工艺
- [ ] 位号自算摆放，`silkFlipped=0 / silkOverPad=0`
- [ ] 盘中孔从导出源头解决
- [ ] DFM `ERROR=0`，WARN 逐类解释

### Step 7 证据与一致性
- [ ] ENET ↔ PCB 逐脚比对
- [ ] BOM 与位号交叉核对
- [ ] 保存 board/tracks/vias/pours/drc/dfm/net-report 快照

### Step 8 3D 装配复核（本板新增，不可省）
- [ ] 按 `assemblyZones` 逐区核对高度：**区内件 ≤ 插合高度 − 0.5 mm**
- [ ] 高件是否在模块投影/维护环带内（推荐级 → 签核）
- [ ] 电解/晶振是否在遮盖区（寿命/温漂）

### Step 9 规则审计 + 返工闭环
- [ ] 跑 `node scripts/audit-dbts-3d-layout.mjs`（或同类）：ZCLR/MOVE 全 PASS 或具名 REVIEW
- [ ] 任何搬迁写进 `changes[]` + ECO 号 + 前后网络长度/环路面积
- [ ] 返工后重跑 DRC/DFM/网表，三份证据一起归档

### Step 10 交付
- [ ] 四层视图 + 界面/装配图 + BOM + 证据包 + 返工报告
- [ ] 遗留清单（谁、什么条件、什么动作）写清楚，不留"口头 TODO"

## 7. 仍然欠缺的（诚实清单）

| # | 缺口 | 影响 | 建议动作 |
| --- | --- | --- | --- |
| 1 | 高度表靠封装名/型号推断，`CD11Z`/`RVT` 仍标"待卡尺实测" | ZCLR-01 只能给 REVIEW | 卡尺实测 + 拍照留档，补进高度表 |

| 4 | 平台 `Netlist Error`（重复旧图纸） | DRC 永远是"0 + 1 平台错"；**PRJ-01 现判 FAIL** | 用户确认后删除旧图纸 + `PCB1_1` |
| 5 | 未做上电/功能验证（FAI、测试点） | 电气正确性只到"网表 + 规则"层 | 打样后 FAI + 上电测试清单（已在 REWORK-REPORT §10） |
