# 案例 04：ST STM32 Nucleo-64 官方参考设计 —— 把“供电选择、电流测量、调试隔离”做成可见连接

> **一句话结论**：Nucleo-64 值得学的不是器件选型，而是它把**5V 从哪来、MCU 电流怎么测、调试器与目标怎么隔离、8MHz 晶振怎么摆、每个电源脚怎么去耦、USB 怎么防 ESD** 都落成了可见的跳线/焊桥与短连接；自研最小系统时按这套“连接关系”落地，比照抄 BOM 更有价值。

## 案例档案

| 项 | 内容 |
|---|---|
| 板型 | 官方评估板：STM32 Nucleo-64（MB1136 主/底板，板载 ST-LINK/V2-1 调试器） |
| 层数 | 公开资料常见为 2～4 层（本机未核对官方 Gerber/叠层，以官方文件为准） |
| 尺寸 | 以官方机械图为准（Arduino 兼容排针决定外形下限，此处不给数值断言） |
| 主控 | STM32F103RB / STM32F401RE 等 64 引脚 LQFP 系列（不同型号不同） |
| 电源 | USB 5V（ST-LINK 侧）→ 3.3V LDO；另有 E5V/VIN 外部供电入口，由跳线选择 5V 来源 |
| 关键接口 | SWD、虚拟 COM（UART）、USB、Arduino/Morpho 排针、8MHz HSE 晶振、复位/用户按键、LED |
| 来源类型 | 公开参考设计（B 级）：ST 官方评估板原理图 + 用户手册（如 “STM32 Nucleo-64 user manual UM1724” 系列）+ 公开工程常识；**本机无外网，未逐页核对官方文件** |

## 设计原理拆解

以下按“电源树 → 时钟与复位 → 接口与保护 → 去耦与地 → EMC/ESD → 热与 DFM”拆解；每个知识点回答判据/为什么/怎么做/怎么查。涉及具体阻容、层数、尺寸的数值均标注“按官方原理图/UM1724/datasheet 复核”。

**电源树**

### KP-CASE-NUCLEO-01 评估板的真正价值：每个可配置项都有跳线/焊桥/测试点

- **判据**：一份合格的参考设计，关键量必须“不拆焊就能测、不改板就能配”：各电源域可串 0Ω/跳线测电流，SWD 有 3.3V/GND/NRST，关键电源与复位有测试点，调试器与目标之间可断开。缺一项，该参考设计的“可验证性”就不足。
- **为什么**：评估板要覆盖 USB 供电、外部供电、低功耗测电流、外接调试器等多种场景，所以必须把电源域、调试器与目标、时钟源做成可断开/可选择的节点；这同时也是量产板“可测试性设计（DFT）”的范本。
- **怎么做**：自研板至少保留：①各电源域串联 0Ω/跳线位（测电流）；②SWD 的 3.3V/GND/NRST；③关键电源与复位测试点（裸铜/焊盘，不盖阻焊）；④调试器与目标之间可断开（0Ω 或焊桥）；⑤BOOT/时钟源选择点。
- **怎么查**：对照原理图逐项数“可断开点/测试点”；上电后把电流表串入 0Ω 位测电流，用示波器测 SWD/UART/复位波形；不通过 → 补测试点或改 0Ω/焊桥。

### KP-CASE-NUCLEO-02 多路 5V 来源必须互锁：跳线选择或 ORing，禁止简单并联

- **判据**：板上有 ≥2 个 5V 来源（USB、E5V、VIN 经稳压）时，任一时刻只允许一个来源供电；选择靠跳线/焊桥或 ORing 电路（理想二极管/肖特基/电源路径管理 IC）实现，不允许两个 5V 直接并联。
- **为什么**：两个 5V 源直接并联，电压高的会向电压低的灌电流；LDO/稳压器输出被反灌可能损坏，USB 主机侧也可能触发过流保护。评估板用“跳线选择”正是用最便宜的方式消除这条反灌路径。
- **怎么做**：评估板用跳线选择 5V 来源；产品板若需“插上外部电源自动切换”，用理想二极管 ORing 或电源路径管理 IC；USB 入口加限流/保险丝；可能反灌的路径上加肖特基或背靠背 MOS。
- **怎么查**：同时接 USB 与外部 5V，测两路电流方向与 LDO 输入电压；做断电/上电顺序测试（先外部后 USB、先 USB 后外部）；不通过 → 加 ORing/改跳线。

### KP-CASE-NUCLEO-03 3.3V LDO 的压差与功耗决定它能不能“从 VIN 供电”

- **判据**：LDO 功耗 `P = (Vin − 3.3 V) × I_load`；在 VIN 取外部 5～12V、I_load 为板载电流时，必须核算 P 与 θja 下的结温。VIN 越高、负载越大，评估板越只适合短时/轻载使用。
- **为什么**：LDO 是线性调压，多余电压全变成热；结温过高会触发热保护或长期可靠性下降。Nucleo 类评估板用 LDO 是为了简单与低噪声，并不是因为 LDO 适合宽压差大电流。
- **怎么做**：明确目标板最大负载电流；VIN 与 3.3V 压差大时改用 Buck；LDO 输入/输出电容按 datasheet；LDO 下方铺铜散热；必要时加散热焊盘/过孔。
- **怎么查**：满载老化测 LDO 壳温/结温（热像仪或热电偶）；按 `Tj = Ta + θja × P` 估算；不通过 → 改开关电源/降负载/加散热。

**时钟与复位**

### KP-CASE-NUCLEO-04 8MHz HSE 晶振要“贴、短、对称、净空”

- **判据**：晶振紧贴 MCU（走线尽量 ≤10 mm），XIN/XOUT 短且等长，负载电容对称、地端就近接地，晶振下方与其他层不穿信号/电源，外围加地保护环或地铜（`PCB-RULE-CRYSTAL-001`）。
- **为什么**：皮尔斯振荡器的负载电容 `CL` 由外部电容加寄生电容共同决定；走线越长寄生越大，频率偏移与起振裕量下降。晶振是高阻节点，容易被 SW/时钟/数字线耦合导致停振或频偏。
- **怎么做**：晶振放 MCU 同侧最近处；负载电容按 `C1 = C2 ≈ 2(CL − Cstray)` 估算（具体按晶振 datasheet）；地端各自就近打过孔；下方禁布线；加地保护环；远离 DC-DC/电感/天线。
- **怎么查**：频率计/示波器测 HSE 输出（MCO）与频偏；不同温度/电压下做起振测试；检查晶振下方净空与负载电容对称性；不通过 → 改 CL/改布局/换晶振。

### KP-CASE-NUCLEO-05 NRST 与 BOOT0 必须有确定电平，不能悬空

- **判据**：NRST 接 100 nF 到地 + 按键到地（内部上拉），走线短、远离晶振/SW；BOOT0 通过下拉电阻固定为低（需要 ISP 时留跳线），不得悬空（`SCH-MOD-RESET` 模块口径）。
- **为什么**：NRST 悬空/长线会耦合噪声导致随机复位；BOOT0 悬空会因漏电/耦合进入错误启动模式（如从系统存储器启动），表现为“程序不跑/偶发不启动”。
- **怎么做**：NRST 电容靠近 MCU 引脚，按键地就近；BOOT0 下拉阻值按 datasheet（常见 10 kΩ 量级，需复核）；需要 ISP 时用跳线/排针接到高电平；复位线包地、远离高速线。
- **怎么查**：上电/复位波形（NRST 上升沿）；BOOT0 电平实测；反复上电 100 次看是否偶发不启动；不通过 → 加电容/改下拉/改布局。

**接口与保护**

### KP-CASE-NUCLEO-06 板载 ST-LINK：SWD + VCP + 可断开焊桥，是调试通路最小集

- **判据**：调试通路至少包含 SWDIO/SWCLK/NRST/3.3V/GND；虚拟 COM 固定接到一个 USART（公开资料常见为 USART2，按官方原理图核对）；调试器与目标之间用焊桥/0Ω 可断开，便于测电流与接外部调试器。
- **为什么**：SWD 是同步两线接口，NRST 参与连接失败恢复；VCP 让“打印调试”不额外占用 USB-UART；可断开点避免调试器给目标“偷偷供电”导致电流测量失真，也避免外部调试器与板载调试器对打。
- **怎么做**：目标板保留 SWD 排针（含 NRST）；SWD 走线短、包地、远离晶振/DC-DC；VCP 的 TX/RX 串 0Ω 或直连；调试器供电与目标供电分域，用焊桥/0Ω 选择；外接调试器时断开板载调试器输出，或只接 SWDIO/SWCLK/GND。
- **怎么查**：用 ST-LINK 连接目标并读 ID；拔掉/接上外部调试器复测；断开目标电源看 3.3V 是否有电压（判断是否反灌）；不通过 → 改焊桥/加隔离。

### KP-CASE-NUCLEO-07 USB 受电口：90Ω 差分 + 连接器侧 ESD + VBUS 保护

- **判据**：D+/D− 按 90Ω 差分、对内等长 ≤5 mil、不跨分割、不打 stub；ESD 阵列在连接器与 MCU 之间且靠近连接器（≤10 mm 量级）；VBUS 有 TVS/限流（`PCB-RULE-USB-001`、`PCB-RULE-ESD-001`）。
- **为什么**：差分阻抗失配 → 反射/眼图闭合 → 枚举失败；ESD 是共模事件，保护器件放得越靠后残压越高、越容易打坏 MCU；VBUS 热插拔浪涌会损坏后级。
- **怎么做**：连接器 → ESD 阵列 →（按需串阻/共模）→ MCU；差分对同层同参考、少过孔；ESD 地短宽多孔；VBUS 加 TVS 与保险丝/限流；外壳地按整机接地策略接。
- **怎么查**：差分 DRC/等长报告；USB 枚举与传输测试；IEC 61000-4-2 接触/空气放电（按产品等级）；不通过 → 改 ESD/改差分/改保护。

**去耦与地**

### KP-CASE-NUCLEO-08 每个 VDD 脚就近 100 nF，VDDA 单独滤波

- **判据**：每个 VDD 引脚一颗 0.1 µF（≤2 mm、过孔直连平面）；板级体电容 10 µF 级放在 LDO 输出；VDDA 经磁珠/RC 与 VDD 隔离并就近去耦；VCAP 引脚（若有）按 datasheet 配电容（`PCB-RULE-DECOUPLE-001`、`PCB-RULE-DECOUPLE-002`）。
- **为什么**：数字开关电流的 di/dt 由近端电容提供，距离越远安装电感越大、高频阻抗越高；VDDA 是 ADC/时钟的模拟电源，数字噪声会直接进模拟域；VCAP 是内核稳压输出，容值错会导致内核不稳。
- **怎么做**：去耦放 MCU 同侧或背面正对引脚；电容 GND 端各自打过孔；VDDA 用磁珠 + 1 µF/100 nF（按 datasheet）；VCAP 用低 ESR 电容并靠近引脚；去耦不要菊花链到远处。
- **怎么查**：逐引脚核对去耦距离/过孔；测电源纹波（20 MHz 带宽、地弹簧）；ADC 采样噪声测试；不通过 → 移电容/加过孔/改 VDDA 滤波。

### KP-CASE-NUCLEO-09 整片地 + 局部保护，比“分模拟地/数字地”更有效

- **判据**：优先整片地，四层板的 L2 保持完整 GND；晶振下方净空、USB 差分参考连续；只有高精度模拟/隔离才做局部隔离，且单点连接（`PCB-RULE-STACKUP-001`、`PCB-RULE-RETURN-001`）。
- **为什么**：高频回流走最低电感路径（信号正下方），地平面被切开会迫使回流绕行、环路面积增大 → 辐射与串扰；评估板用整片地正是低成本且正确的做法。
- **怎么做**：四层板用 SIG-GND-PWR-SIG；关键信号走与 GND 相邻的层；换层加回流地孔；晶振周围地过孔围栏；连接器地针全部接平面。
- **怎么查**：地平面连通性/开槽检查；关键信号换层处的地孔；EMC 预测试；不通过 → 补地孔/改层/改分割。

**EMC/ESD**

### KP-CASE-NUCLEO-10 评估板的 EMC 余量来自“接口保护 + 短回流 + 完整地”，不来自堆料

- **判据**：每个对外接口（USB、排针、电源入口）在连接器侧有 ESD/浪涌保护；保护器件地回流短宽多孔；晶振/DC-DC 与接口分区布置（`PCB-RULE-ESD-001`）。
- **为什么**：电缆是共模辐射与抗扰的主要“天线”；ESD/浪涌电流必须在接口处泄放到地，不能穿过板内走线；保护器件的地回流电感直接决定残压。
- **怎么做**：接口保护按“连接器 → 保护 → 滤波 → 芯片”顺序；ESD 地就近打过孔到地平面；必要时加共模电感/磁珠；排针信号按需串阻；外壳地/屏蔽按产品接地策略处理。
- **怎么查**：ESD 枪打接口（接触/空气）；近场探头找热点；共模辐射测试；不通过 → 改保护/改回流/加滤波。

**热与 DFM**

### KP-CASE-NUCLEO-11 可测试性/可制造性：焊桥、丝印、定位点、排针间距都要在 DFM 评审里过

- **判据**：板上有 ≥3 个非对称光学定位点；丝印不压焊盘、字高 ≥0.8 mm；Arduino/Morpho 排针间距与孔径按连接器 datasheet；焊桥/0Ω 的默认状态在丝印/BOM 上写清（`PCB-RULE-FIDUCIAL-001`、`PCB-RULE-SILK-001`）。
- **为什么**：评估板是“给人用的”，装配、调试、维修都依赖可读丝印与定位点；焊桥默认状态不清会导致“出厂配置错”，排查成本极高。
- **怎么做**：定位点放板边非对称；丝印标跳线默认位置（如 5V 来源、IDD 短接）；排针 2.54 mm 布局按机械图；焊桥开窗足够（按板厂能力）；BOM 注明 0Ω/不贴。
- **怎么查**：DFM 检查表；首件装配核对跳线/焊桥状态；丝印可读性目检；不通过 → 改丝印/改焊盘/改 BOM。

## 规则依据

| 规则 ID | 本案例对应做法 | 物理/标准依据 |
|---|---|---|
| `PCB-RULE-CRYSTAL-001` | 8 MHz 晶振紧贴 MCU、负载电容对称、下方净空 | 皮尔斯振荡器 CL 受寄生电容影响；晶振高阻节点易被耦合，环路面积越大越易停振/频偏 |
| `PCB-RULE-DECOUPLE-001` | 每个 VDD 脚就近 0.1 µF、过孔直连平面 | 高频去耦靠“安装电感”生效，距离与回路面积决定有效频段 |
| `PCB-RULE-DECOUPLE-002` | 10 µF 体电容 + 100 nF 近端 + VDDA 滤波 | 容值按约 10× 间隔组合覆盖频段，避免同容值并联的反谐振峰 |
| `PCB-RULE-USB-001` | USB D+/D− 90Ω 差分、ESD 靠连接器 | 差分阻抗失配引起反射/眼图闭合；ESD 是共模事件，越靠前残压越低 |
| `PCB-RULE-ESD-001` | TVS 在连接器与 MCU 之间、地短宽多孔 | IEC 61000-4-2 的放电电流上升沿极快，长地线 = 大电感 = 高残压 |
| `PCB-RULE-STACKUP-001` | 四层 SIG-GND-PWR-SIG，L2 完整地 | 每个信号层都需要相邻完整参考面，否则回流被迫绕行 |
| `PCB-RULE-RETURN-001` | USB/晶振等换层处补回流地孔 | 高频回流走最低电感路径，必须与信号过孔就近配对 |
| `PCB-RULE-CLEARANCE-001` | 3.3V/5V 低压区域间距 ≥0.2 mm | IPC-2221 低压间距经验值，按板厂能力与工作电压加严 |
| `PCB-RULE-THERMAL-001` | LDO/调试器 MCU 局部铺铜散热 | 结温 `Tj = Ta + θja·P`，铜面积与过孔是低成本散热路径 |
| `PCB-RULE-MEASURE-001` | IDD 跳线、电源纹波测试点 | 纹波测量须 20 MHz 带宽限制 + 短地回路，测点在负载端 |

**依据说明**

- **回路面积**：去耦、晶振、USB 三条路径的共同物理量都是“信号—回流”围成的面积；面积越小，寄生电感越小，高频阻抗与辐射越低。
- **ESD 残压**：保护器件的钳位电压不是常数，而是“钳位电压 + 地回流电感 × di/dt”；所以 ESD 规则强调“靠连接器 + 短宽地”，而不只是“加一颗 TVS”。
- **时钟起振**：晶振能否起振由“负阻裕量”决定，负载电容、走线寄生、地噪声都会吃掉裕量；评估板的短走线+地保护环是通用解。
- **上电确定性**：BOOT/EN/NRST 这类“状态引脚”一旦悬空，行为由漏电与耦合决定，属于典型的设计缺陷而非“偶发故障”。

## 可迁移的设计经验

**做对的**

1. 用跳线/焊桥把“配置”变成可测点：5V 来源、IDD 电流、调试器隔离都能不拆焊切换。
2. 晶振、复位、BOOT0 三件套全部贴在 MCU 旁，几乎零走线，把时钟与启动风险压到最低。
3. USB/调试接口的保护与差分处理在连接器侧一次做完，后续板内走线“干净”。
4. 电源入口有明确的“单一来源选择”，从结构上消除多源反灌。

**妥协的**

1. 评估板为兼容多种供电与排针，电源路径比产品板长、跳线多；产品化时应删掉跳线并换成 ORing/电源路径管理。
2. 评估板面积宽松，去耦可以四面摆开；小产品板必须把去耦放到背面正对引脚，依赖过孔与平面。
3. 为兼容多个 MCU 型号，部分网络用 0Ω/焊桥做选择，BOM 与调试复杂度上升，量产前要收敛成固定配置。

**反面教训**

1. “评估板能跑”不等于“产品能过 EMC”：评估板没有外壳、线缆与成本约束，接口保护与地策略必须按产品重做。
2. 照抄排针定义却忽略“5V 容忍是引脚属性（FT 引脚）而非排针属性”，非 FT 引脚接 5V 会损坏。
3. 产品板省掉电源选择结构、USB 与外部 5V 同时接入，形成反灌路径，轻则 LDO 发热，重则烧板。

## 评审清单

- [ ] 电源来源是否唯一，或有 ORing/跳线互锁？是否存在双源反灌路径？
- [ ] 每个 VDD/VDDA 脚是否都有 ≤2 mm 的 0.1 µF？VDDA 是否有独立滤波？
- [ ] VCAP 引脚（如适用）的电容值是否按 datasheet 选取并靠近引脚？
- [ ] 8 MHz 晶振是否贴近 MCU、负载电容按 CL 计算并对地就近？
- [ ] NRST 是否有 100 nF + 按键，走线短且远离 SW/晶振？
- [ ] BOOT0 是否有确定电平（下拉/跳线），不会悬空？
- [ ] SWD 是否预留（含 NRST、3.3V、GND），调试器与目标是否可隔离？
- [ ] USB D+/D− 是否 90Ω 差分、不跨分割，ESD 是否在连接器侧？
- [ ] 5V 兼容排针信号是否只落在 FT（5V 容忍）引脚？
- [ ] LDO 在最坏输入/最大负载下的功耗与结温是否核算？
- [ ] 是否有 IDD/电源纹波测试点，且测量方法（带宽/地回路）已写明？
- [ ] 调试器/目标电源域是否独立去耦、地回流是否各自干净？
