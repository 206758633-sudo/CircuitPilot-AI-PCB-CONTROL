# 案例 07：隔离 CAN / RS485 工业节点参考设计 —— 隔离带是“结构”，不是一条分割线

> **一句话结论**：隔离节点必须同时具备**隔离电源 + 数字隔离 + 收发器 + 总线保护**四件套；隔离带两侧的铜、过孔、地必须真正断开，爬电/间隙按安规标准算够；总线的 120Ω 终端、TVS/共模电感位置与屏蔽/共模回流决定它能不能在工业现场长期活下来。

## 案例档案

| 项 | 内容 |
|---|---|
| 板型 | 工业隔离 CAN / RS485 节点参考设计（收发器/隔离器厂商公开参考设计与应用笔记的通用做法） |
| 层数 | 公开参考设计常见为 4 层（两侧各有地平面）；2 层也可实现但 EMC 余量更小（以具体设计为准，本机未核对） |
| 尺寸 | 无统一值；隔离带宽度/开槽由工作电压、认证等级与板厂能力决定（以具体设计为准） |
| 主控 | 任意 MCU + 数字隔离器；或集成隔离的收发器（型号以 datasheet 为准，本案例不指定料号） |
| 电源 | 逻辑侧 3.3 V/5 V；总线侧 5 V 由隔离 DC-DC（变压器驱动或隔离模块）产生 |
| 关键接口 | CAN_H/CAN_L 或 RS485 A/B、隔离侧地（CAN_GND/ISO_GND）、屏蔽/外壳、终端与失效保护偏置 |
| 来源类型 | 公开参考设计（B 级）：ISO 11898-2、TIA-485-A、IEC 61000-4-2/4-4/4-5、IEC 62368-1/UL 1577 等标准常识 + 公开工程资料；**本机无外网，未逐页核对官方文件** |

## 设计原理拆解

以下按“电源树（隔离电源）→ 上电时序与方向控制 → 接口与保护 → 去耦与地 → EMC/ESD → 热与 DFM”拆解。隔离距离、耐压、终端阻值、偏置阻值均标注“按 IEC/UL 标准与 datasheet 复核”。

**电源树：隔离电源是隔离节点的“心脏”**

### KP-CASE-CANISO-01 隔离节点四件套：隔离电源 + 数字隔离 + 收发器 + 总线保护

- **判据**：隔离节点至少包含：隔离电源（隔离 DC-DC/模块）、数字隔离器（或集成隔离的收发器）、总线收发器、总线保护（TVS/共模电感/保险丝）。四者缺一，隔离与抗扰都不完整（`SCH-MOD-CAN-RS485`、`SCH-MOD-ESD`）。
- **为什么**：隔离电源给总线侧供电；数字隔离切断逻辑侧与总线侧的信号地环路；收发器把逻辑电平转成差分总线；保护器件吸收浪涌/ESD。只有“隔离器”没有“隔离电源”，等于隔离了个寂寞。
- **怎么做**：按通道数/速率/隔离等级选器件；隔离器与收发器同一隔离域供电；总线侧地独立；保护放连接器侧；隔离器两侧电源各自去耦。
- **怎么查**：原理图逐项核对四件套；隔离耐压测试（按 UL 1577/认证要求）；总线通信与误码测试；不通过 → 补器件/改供电。

### KP-CASE-CANISO-02 隔离电源的开关噪声会直接调制到总线上

- **判据**：隔离 DC-DC（尤其变压器驱动方案）的开关噪声必须滤：输入/输出各加去耦与 LC（按 datasheet）；变压器/模块下方禁布线；隔离侧电源给收发器/隔离器就近去耦（`PCB-RULE-DECOUPLE-001`、`PCB-RULE-DECOUPLE-002`）。
- **为什么**：隔离电源是开关电源，纹波与共模噪声会通过总线侧电源耦合到差分总线上，表现为通信误码、EMC 超标；布局不当还会把噪声耦合到隔离带。
- **怎么做**：隔离模块/变压器按 datasheet 布局；输入输出电容就近；必要时加共模电感/LC；隔离带两侧地各自干净；开关节点远离隔离带与总线。
- **怎么查**：隔离侧电源纹波；总线共模噪声；通信误码率；不通过 → 加滤波/改布局/改方案。

**上电时序与方向控制（时钟与复位：本案例无独立时钟域，以隔离器/收发器上电时序与方向控制替代）**

### KP-CASE-CANISO-03 使能/方向/上电时序：不得让总线出现“错误驱动”

- **判据**：收发器使能、隔离器使能/方向控制引脚必须有确定电平（上拉/下拉），不得悬空；上电/复位期间保证总线不出现错误驱动（`SCH-MOD-CAN-RS485`）。
- **为什么**：悬空使能会导致随机进入发送态，多节点总线冲突；上电瞬间方向错误会把总线拉死，表现为“整条总线不通信”。
- **怎么做**：EN/DE/RE 加上拉/下拉；RS485 方向由 MCU GPIO 控制并默认接收；CAN 收发器 standby 引脚按需；上电顺序先地后电源。
- **怎么查**：上电瞬间总线波形；反复上电测试；不通过 → 改上下拉/改时序。

**接口与保护**

### KP-CASE-CANISO-04 CAN 终端：120Ω 分裂终端 + 中心电容

- **判据**：CAN 总线物理两端各一个 120Ω 终端；分裂终端常见 2×60.4Ω + 中心电容到地（具体阻容按 ISO 11898-2/app note 复核）；中间节点不装终端；终端靠近连接器。
- **为什么**：120Ω 匹配总线特性阻抗，抑制反射；分裂终端的中心电容给共模提供低阻抗路径，改善共模/EMC。
- **怎么做**：终端电阻放连接器附近；分裂终端中心节点经电容到总线侧地；终端可跳线/焊盘选择便于调试；stub 尽量短。
- **怎么查**：断电测 CAN_H–CAN_L 电阻（两端并联约 60Ω）；眼图/波形反射；不通过 → 改终端/改拓扑。

### KP-CASE-CANISO-05 RS485 终端与失效保护偏置

- **判据**：RS485 总线两端各 120Ω 终端；空闲失效保护偏置保证总线空闲差分电压 > 200 mV（偏置阻值按 TIA-485-A/收发器 datasheet 复核，常见数百Ω 量级）；偏置只在一处（通常主机）。
- **为什么**：无偏置时总线空闲差分近 0，接收器输出不确定 → 误帧；终端匹配抑制反射。
- **怎么做**：终端与偏置靠近两端/主机；偏置电阻接总线侧电源（隔离侧）并加去耦；多节点时核算总线负载与驱动能力。
- **怎么查**：空闲差分电压实测；多节点通信误码率；不通过 → 调偏置/改终端。

### KP-CASE-CANISO-06 TVS / 共模电感：位置比型号更重要

- **判据**：TVS 在连接器与收发器之间、尽量靠连接器；共模电感在 TVS 与收发器之间或连接器侧（按方案）；TVS 地接总线侧地、短宽多孔（`PCB-RULE-ESD-001`）。
- **为什么**：浪涌/ESD 必须先泄放再进收发器；TVS 地回路长会抬高残压；共模电感抑制共模噪声但差模信号必须无损通过。
- **怎么做**：连接器 → TVS → 共模电感 → 收发器；TVS 选双向、反向工作电压高于总线共模范围（按 datasheet）；地回路短；必要时加 PTC/保险丝。
- **怎么查**：ESD/浪涌测试（IEC 61000-4-2/4-4/4-5）；总线波形；不通过 → 改保护/改位置。

### KP-CASE-CANISO-07 总线布线：成对、无 stub、终端在两端

- **判据**：CAN_H/CAN_L 或 A/B 成对紧耦合走线，stub 尽量短（按速率/标准复核），分支节点用菊花链；终端在物理两端；总线不与高 dv/dt 信号并行。
- **为什么**：差分对紧耦合抗共模干扰；stub 产生反射；终端位置错导致阻抗不匹配；与开关电源并行会耦合噪声。
- **怎么做**：总线走线成对、等长；节点分支短；终端靠连接器；远离 DC-DC/开关节点；必要时包地。
- **怎么查**：布线检查 stub 长度；波形反射；通信误码率；不通过 → 改拓扑/改终端。

**去耦与地**

### KP-CASE-CANISO-08 两侧地必须真正分开：万用表测应开路

- **判据**：逻辑侧 GND 与总线侧 GND 在 PCB 上不连通（除非通过 Y 电容/安规元件单点）；隔离器/隔离电源两侧地各自完整；跨隔离带的信号只经过隔离器件（`PCB-RULE-RETURN-001`）。
- **为什么**：一旦两侧地连通，隔离失效，共模电流绕过隔离器形成环路；地环路会引入噪声甚至损坏器件。
- **怎么做**：隔离器件下方禁止铺铜跨带；两侧地各自铺铜 + 过孔；Y 电容跨接（按安规，单点）；连接器屏蔽/外壳地按策略接总线侧或机壳。
- **怎么查**：万用表测两侧地电阻（应开路）；共模干扰测试；EMC 预测试；不通过 → 查跨带铜/过孔/器件。

### KP-CASE-CANISO-09 隔离带：爬电/间隙按标准算，必要时开槽

- **判据**：隔离带两侧铜/焊盘/过孔之间的爬电距离与电气间隙按目标安规（IEC 62368-1、IEC 61010、UL 1577 等）与工作电压/污染等级/材料组计算，并留 ≥20% 裕量；隔离带下可开槽（`PCB-RULE-CREEPAGE-001`、`PCB-RULE-CLEARANCE-001`）。
- **为什么**：隔离失效多发生在 PCB 表面爬电（污染 + 潮湿）而非器件内部；开槽切断表面漏电路径，距离不够时靠结构补。
- **怎么做**：隔离带画成直线、宽度按认证等级（常见数 mm 量级，**必须按标准复核**）；禁止任何铜/过孔跨越；开槽宽度按板厂能力；两侧地平面不跨越隔离带。
- **怎么查**：逐段量爬电/间隙；耐压/绝缘电阻测试；安规评审；不通过 → 加宽/开槽/换隔离器件。

**EMC/ESD**

### KP-CASE-CANISO-10 屏蔽、Y 电容与共模回流：给共模电流一条受控路径

- **判据**：屏蔽电缆的屏蔽层接机壳/总线侧地（按系统接地策略，一端或两端）；跨隔离带可加 Y 电容（按安规耐压与漏电流要求）；共模回流路径明确、不穿越隔离带。
- **为什么**：屏蔽层不接地 = 天线；两端接地可能形成地环路；Y 电容给共模电流提供受控路径，但取值不当会超过漏电流限值。
- **怎么做**：连接器屏蔽外壳大面积接机壳；Y 电容跨隔离带（单点、安规认证型）；地平面与机壳连接点明确；总线共模电感与 Y 电容配合。
- **怎么查**：共模辐射/抗扰测试；漏电流测试；不通过 → 改屏蔽接地/Y 电容。

### KP-CASE-CANISO-11 整机抗扰：ESD/EFT/浪涌按工业等级做，保护地回路要短

- **判据**：工业接口常见目标：ESD（IEC 61000-4-2）、EFT（IEC 61000-4-4）、浪涌（IEC 61000-4-5），等级按产品标准/认证要求复核；保护器件地回路短宽多孔。
- **为什么**：工业现场干扰能量大，TVS/共模电感的残压与地回路电感决定后级是否被击穿；保护不是“装了就行”，回流路径是关键。
- **怎么做**：连接器侧保护链完整；TVS 地就近接总线侧地；必要时加气体放电管/压敏电阻做多级保护（按方案）；隔离带与保护布局协同。
- **怎么查**：按等级做 ESD/EFT/浪涌测试；故障后功能检查；不通过 → 改保护链/改布局。

**热与 DFM**

### KP-CASE-CANISO-12 热与 DFM：隔离电源占位、开槽可制造、丝印标隔离区

- **判据**：隔离模块/变压器按 datasheet 留占位与禁布区；隔离开槽宽度按板厂能力并避开走线；隔离带两侧器件爬电满足认证；丝印标出隔离区/高压区（`PCB-RULE-THERMAL-001` 适用于隔离电源）。
- **为什么**：隔离电源有损耗与发热，占位/散热不够会降额；开槽过窄板厂做不出/易断板；隔离区标识缺失会导致装配/维修误操作。
- **怎么做**：隔离电源按 datasheet 布局；开槽 ≥ 板厂最小槽宽；隔离带禁布器件/丝印；DFM 评审开槽与拼板；热敏电阻靠近隔离电源做保护。
- **怎么查**：DFM 检查；温升测试；安规评审；不通过 → 改开槽/改布局/改占位。

## 规则依据

| 规则 ID | 本案例对应做法 | 物理/标准依据 |
|---|---|---|
| `PCB-RULE-CREEPAGE-001` | 隔离带宽度、开槽、爬电按标准计算 | 污染 + 潮湿下表面漏电；IEC 62368-1/UL 1577 等按工作电压/污染等级/材料组查表 |
| `PCB-RULE-CLEARANCE-001` | 隔离带电气间隙、总线与高压区间距 | IPC-2221 与安规间隙要求；空气击穿与电压/海拔相关 |
| `PCB-RULE-ESD-001` | TVS 靠连接器、地短宽多孔 | ESD 共模事件，残压 = 钳位电压 + 地回路电感 × di/dt |
| `PCB-RULE-RETURN-001` | 两侧地独立、跨带只走隔离器件 | 共模电流必须被隔离带阻断，回流路径不能跨越隔离 |
| `PCB-RULE-DECOUPLE-001` | 两侧电源/收发器/隔离器就近去耦 | 高频去耦靠安装电感，隔离电源噪声需就地滤除 |
| `PCB-RULE-DECOUPLE-002` | 隔离电源输入/输出大小电容组合 | 开关噪声宽频，需多容值覆盖并抑制反谐振 |
| `PCB-RULE-THERMAL-001` | 隔离模块/收发器散热铜与过孔 | `Tj = Ta + θja·P`，隔离电源损耗需导出 |
| `PCB-RULE-STACKUP-001` | 四层板两侧地平面完整 | 完整参考面是回流与屏蔽前提，隔离带处禁止跨层铜 |
| `PCB-RULE-CURRENT-001` | 总线/电源走线按电流选宽 | 工业节点总线电流与隔离电源电流需按 IPC-2152 校核 |

**依据说明**

- **隔离的本质**：隔离 = 断开“地环路 + 共模电流路径”，同时保持信号/电源跨带传输；所以仅靠数字隔离器不够，隔离电源与 PCB 隔离带必须同步成立。
- **爬电 vs 间隙**：爬电沿绝缘表面，受污染/潮湿影响；间隙是空气距离，受海拔/电压影响；两者都要按标准分别核算，不能用“线宽间距”代替。
- **终端与反射**：CAN 总线特性阻抗约 120Ω（按 ISO 11898-2 复核），终端失配会产生反射，表现为波形过冲/振铃与高速下误码。
- **TVS 残压**：TVS 的钳位不是理想稳压，浪涌电流越大钳位越高；地回路电感与走线长度会显著抬高实际加在收发器上的电压。

## 可迁移的设计经验

**做对的**

1. 四件套一次画全：隔离电源、数字隔离、收发器、总线保护，缺一不投板。
2. 隔离带画成直线、禁止铜/过孔跨越，并在需要时开槽，爬电/间隙按标准核算留裕量。
3. 两侧地各自完整、只在安规元件处单点联系；跨带信号只经过隔离器件。
4. 终端与保护都在连接器侧，TVS 地回流短、共模电感与 Y 电容配合。

**妥协的**

1. 2 层板成本低，但两侧地平面不完整、隔离带处回流差，EMC 余量小；工业环境建议 4 层。
2. 集成隔离的收发器省面积/省器件，但隔离耐压/爬电由器件封装决定，PCB 隔离带仍需按认证留够。
3. 为兼容多协议共用一套接口，终端/偏置用跳线或焊盘选择，增加 BOM 与误配置风险。

**反面教训**

1. 只加数字隔离器、不做隔离电源 → 总线侧无供电或共地，隔离名存实亡。
2. 隔离带上有过孔/铺铜跨接，或两侧地通过测试点/安装孔连通 → 共模电流绕过隔离，EMC/耐压都过不了。
3. TVS 放得离连接器远、地回路细长 → 浪涌残压高，收发器仍被击穿（`PCB-FAIL-ESD-DAMAGE`）。
4. 终端缺失/位置错误/偏置不当 → 总线空闲误帧、长线反射；选错 TVS 反向工作电压/忽略总线共模范围 → 正常电平下漏电或保护失效（`PCB-FAIL-TVS-WRONG`）。

## 评审清单

- [ ] 四件套（隔离电源/数字隔离/收发器/总线保护）是否齐全？
- [ ] 隔离带两侧铜、焊盘、过孔是否真正断开？万用表测两侧地是否开路？
- [ ] 隔离带爬电/间隙是否按 IEC/UL 标准计算并留 ≥20% 裕量？
- [ ] 隔离带是否需要开槽？开槽宽度是否在板厂能力内？
