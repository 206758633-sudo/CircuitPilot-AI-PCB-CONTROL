# 案例 15：RF 模组 / 天线 —— 50 Ω、净空、共存三件事决定“能不能连得远”

> **一句话结论**：RF 模组底板的设计自由度比想象中小：**射频链路只有“50 Ω + 净空 + 接地”三件事可做，天线性能在结构定型时就已决定**；底板真正能优化的是电源噪声、共存干扰与量产一致性。所有“换个匹配电容就能救回来”的想法，在净空被铜皮侵占或天线被电池挡住时都不成立。

## 设计原理拆解

以下按“模组边界 → 50 Ω 链路 → 天线净空 → 匹配网络 → 共存 → 电源与地 → ESD → 认证与量产”拆解。所有具体尺寸/容值/电流均标注“按模组 datasheet 与天线指南复核”。

**一、模组边界**

### KP-CASE-RFMOD-01 底板不设计射频：模组与底板的责任边界必须先划清

- **判据**：模组已包含射频前端、匹配网络与天线（或提供 IPEX 输出）；底板只负责 50 Ω 传输线、天线净空、电源与数字接口。若模组只提供 RF 输出脚，则匹配网络与天线由底板设计，必须按模组指南执行（`PCB-RULE-RF-001`、`SCH-MOD-RF`）。
- **为什么**：射频设计需要阻抗控制、匹配调试与认证能力；模组厂已完成并认证。底板越界设计射频，等于把认证风险与调试成本全部揽回自己身上，且很难达到模组原厂指标。
- **怎么做**：选型时确认模组是否含天线/匹配/认证；含天线模组按“净空 + 结构”设计；IPEX 方案按模组指南选连接器与线缆；底板只保留 50 Ω 走线与测试口。
- **怎么查**：模组 datasheet 的“参考设计/天线”章节逐项对照；确认模组认证覆盖目标市场；底板不出现自制的匹配网络（除非官方要求）。

**二、50 Ω 链路**

### KP-CASE-RFMOD-02 射频走线必须按 50 Ω 单端设计，且参考面连续

- **判据**：天线脚/IPEX 座到模组的射频走线按 50 Ω 单端设计：微带线初估 `W ≈ 2H`（FR-4，εr≈4.2），最终线宽按叠层用场求解器/板厂阻抗计算确认（`PCB-RULE-IMPEDANCE-001`）；走线尽量短、不跨分割、两侧包地并打缝合孔（`PCB-RULE-RETURN-001`）。
- **为什么**：50 Ω 失配会把功率反射回 PA，降低辐射效率、增加发热，严重时触发模组降功率；参考面不连续会让回流绕行，形成辐射与额外损耗，表现为“距离变短、吞吐下降”。
- **怎么做**：射频走线单独规划，避免与数字/电源并行；必须换层时成对补回流地孔；两侧地铜 + 缝合孔（间距按最高频率 λ/20，2.4 GHz 约 6 mm 量级）；走线避免直角，用圆弧/45°。
- **怎么查**：板厂阻抗计算单；TDR 测试条（有条件）；目检参考面连续性与缝合孔；整机吞吐/RSSI 对比。

### KP-CASE-RFMOD-03 射频走线要远离噪声源与金属件，长度按“最短可行”而非“布线方便”

- **判据**：射频走线远离 DC-DC 电感/SW 节点、晶振、高速数字线、大电流路径与金属结构件；射频走线长度按模块指南控制（常见“越短越好”，长走线会引入损耗与失配）；不得在射频线下方走其他信号（`PCB-RULE-PLACE-RF-001`、`PCB-MOD-EMC`）。
- **为什么**：射频线是敏感的高频小信号路径，邻近的开关噪声会耦合进接收链路，抬升底噪；金属件会改变阻抗与辐射方向图；长走线损耗直接吃掉发射功率与接收灵敏度。
- **怎么做**：布局时把模组与天线放板边，射频走线直达；DC-DC 与晶振远离射频区；必要时在射频区加屏蔽罩（接地过孔按 λ/20）；避免射频线穿过连接器/电池下方。
- **怎么查**：布局评审（间距/邻线/下方走线）；近场探头扫描噪声耦合；接收灵敏度与吞吐测试；屏蔽罩接地检查。

**三、天线净空与匹配**

### KP-CASE-RFMOD-04 天线净空是硬约束：所有层禁铜、禁器件、禁走线，宁大勿小

- **判据**：按 `PCB-RULE-RF-001` 与模组/天线指南留足净空：净空区内所有层（含 GND 覆铜）不得有铜、走线、过孔、器件、丝印；天线尽量伸出板边、朝外；天线与电池/金属/外壳的距离按指南与整机实测确认（常见前方 15 mm 级，具体按模组 datasheet 复核）。
- **为什么**：天线附近的任何导体都会改变谐振频率、降低效率、畸变方向图；自动覆铜最容易误入净空区，是无线产品最常见的低级错误；净空不足无法靠匹配网络补救（匹配只能调谐振，救不回被吸收的能量）。
- **怎么做**：把净空画成所有层生效的 keepout；模组放板边、天线伸出或整块挖空；电池、屏、摄像头、喇叭远离天线；外壳避免金属涂层，金属件留净空；排针/连接器不要在天线正下方。
- **怎么查**：逐层检查 keepout 内无铜；Gerber 叠层核对；整机 RSSI/吞吐/距离实测；有条件做暗室 OTA 效率与方向图测试。

### KP-CASE-RFMOD-05 匹配网络按 π 型留焊盘，元件靠近天线端且地端多过孔

- **判据**：天线匹配网络按 π 型（串联 + 并联到地）预留焊盘，便于调试；匹配元件尽量靠近天线端，地端就近打过孔（`PCB-RULE-IMPEDANCE-001`、`PCB-RULE-DECOUPLE-001` 的回路原则）；匹配网络下方保持地平面完整（`SCH-MOD-RF`）。
- **为什么**：匹配元件的地端走线会引入额外电感，让调试结果与仿真对不上；元件离天线越远，中间走线越像“额外传输线”，调好的匹配换个外壳又变了；π 型留焊盘允许后续用不同元件值微调。
- **怎么做**：π 型留 3 个焊盘（串联 + 两个并联位）；元件用 0402/0201 高频器件；地端就近打 2 个以上过孔；匹配网络区域地平面完整、不切割；调试后用固定值替代可调件。
- **怎么查**：网络分析仪测 S11（有条件）；无仪器时按指南核对布局与元件值；整机与裸板对比测试；换外壳/电池后复测。

**四、电源、共存与 ESD**

### KP-CASE-RFMOD-06 电源噪声会直接调制到射频：按发射峰值电流做去耦与 LDO/Buck 选型

- **判据**：模组电源引脚就近 0.1 µF + µF 级体电容（`PCB-RULE-DECOUPLE-001`/`002`）；LDO/Buck 按发射峰值电流（常见数百 mA 量级，按 datasheet 复核）选型并留 ≥30% 余量；开关电源的 SW 节点远离射频区（`PCB-RULE-PLACE-DCDC-001`）。
- **为什么**：射频功放在发射瞬间拉大电流，电源跌落会直接调制到射频包络，表现为 EVM 恶化、距离变短、丢包；DC-DC 的开关纹波落在射频带内会抬升底噪。
- **怎么做**：模组电源独立 LDO（若效率允许）或低噪声 Buck；体电容紧贴模组电源脚；SW 节点铜皮小、远离天线与射频线；必要时在电源上串磁珠/LC（注意瞬态压降）。
- **怎么查**：发射瞬间测模组电源纹波（短地弹簧、20 MHz 带宽）；吞吐/距离测试；频谱看是否有开关频率谐波；LDO/Buck 温升。

### KP-CASE-RFMOD-07 共存：多射频同时工作时，滤波、隔离与时分策略要一起设计

- **判据**：Wi-Fi/BT/LTE/Sub-GHz 共存时，各射频前端之间要有滤波与隔离（间距、屏蔽、滤波器件）；天线之间保持足够隔离度；必要时用时分/信道协调策略；共存导致的灵敏度下降要按整机实测评估（`SCH-MOD-RF`、`PCB-MOD-EMC`）。
- **为什么**：多个发射机同时工作会产生阻塞与互调，接收机灵敏度下降；天线距离过近时隔离度不足，一个频段的发射会淹没另一个频段的接收；这些在单射频测试中完全看不出来。
- **怎么做**：多天线尽量拉开距离、方向错开；必要时加 SAW/LC 滤波器；射频区之间加屏蔽或地过孔墙；软件上做时分/信道规避；整机做多射频同时工作的吞吐测试。
- **怎么查**：单射频与多射频同时工作的吞吐/灵敏度对比；频谱仪看互调与阻塞；整机老化测试；认证预测试（同时发射模式）。

### KP-CASE-RFMOD-08 天线口/射频前端的 ESD 与浪涌：保护器件要低电容、靠接口

- **判据**：外置天线座（IPEX/SMA）与射频前端需要 ESD 保护时，必须选低电容（不影响 50 Ω 与插损）的器件，且放在连接器与射频链路之间（`PCB-RULE-ESD-001`、`PCB-RULE-PLACE-ESD-001`）；保护器件地端短宽多孔；不能用普通大电容 TVS。
- **为什么**：射频链路的 ESD 器件结电容会直接改变阻抗、增加插损；天线座是用户可触摸/可插拔的金属件，是 ESD 入口；保护器件位置靠后会放过残压进入 PA/LNA（`PCB-FAIL-ESD-DAMAGE`）。
- **怎么做**：选低电容（如 pF 级以下，按频段与插损预算复核）ESD 器件；放在天线座与匹配网络之间；地端多过孔；必要时用射频专用 ESD 器件；评估保护器件对 S11/插损的影响。
- **怎么查**：S11/插损测试（有条件）；ESD 枪打天线座（按产品等级）；整机吞吐对比有无保护器件；保护器件温升/漏电。

**五、认证与量产一致性**

### KP-CASE-RFMOD-09 认证是“整机行为”：预测试、测试口与结构一起规划

- **判据**：无线认证（CE/FCC/SRRC 等）按整机测试，模组认证只覆盖模组本身；整机需要预留射频测试口/天线座、支持测试模式（定频发射/接收），并保证外壳、电池、线缆状态与量产一致（`PCB-RULE-RF-001`、`PCB-MOD-EMC`）。
- **为什么**：认证测的是“整机辐射/传导/占用带宽/杂散”，外壳与线缆会显著改变结果；没有测试模式与测试口，认证与产线测试都无法进行；样机与量产结构不一致会导致认证失效。
- **怎么做**：预留 50 Ω 测试口或 IPEX 座；固件提供定频/信道/功率测试模式；结构样机与量产一致（含外壳涂层、电池、线缆）；提前做预测试（辐射/传导/杂散/EIRP）。
- **怎么查**：预测试报告；测试模式验证；样机与量产 BOM/结构对比；认证机构沟通记录。

### KP-CASE-RFMOD-10 量产一致性：天线一致性靠工艺与抽检，不靠“设计一次成功”

- **判据**：天线性能受 PCB 公差、外壳、装配、电池位置影响，必须定义量产抽检项（RSSI/吞吐/发射功率/频偏）与判据；天线区工艺（覆盖膜、外壳间隙、点胶）要固化到作业指导书（`PCB-RULE-TESTPOINT-001`、`PCB-MOD-ASSEMBLY`）。
- **为什么**：同一天线设计在不同批次/不同装配下性能可以差几个 dB；没有抽检就发现不了“某批外壳涂层变了/电池位置偏了”；等客户投诉再查，成本极高。
- **怎么做**：定义产线射频测试工位与判据（如 RSSI 分布、吞吐下限）；天线区工艺参数固化；来料/外壳/电池位置做首件确认；定期做整机 OTA 抽检。
- **怎么查**：产线测试数据分布（CPK）；与黄金样机对比；定期暗室抽检；客诉回溯到批次与工艺参数。

## 规则依据

| 规则 ID | 本案例对应做法 | 物理/标准依据 |
|---|---|---|
| `PCB-RULE-RF-001` | 天线净空区所有层禁铜/禁线/禁器件，天线伸出板边 | 天线附近导体改变谐振、降低效率、畸变方向图 |
| `PCB-RULE-PLACE-RF-001` | 模组靠板边、天线朝外、净空区无铜 | 布局阶段决定天线环境，后期无法补救 |
| `PCB-RULE-PLACE-ANTENNA-15MM-001` | 整机天线净空按指南留足（常见 15 mm 级） | 净空不足直接损失辐射效率 |
| `PCB-RULE-IMPEDANCE-001` | 射频走线 50 Ω，线宽按叠层计算 | 阻抗失配引起反射，降低效率、增加 PA 发热 |
| `PCB-RULE-RETURN-001` | 射频换层/过孔旁补回流地孔 | 参考面不连续时回流绕行，形成辐射与损耗 |
| `PCB-RULE-STACKUP-001` | 优先 4 层，保证射频参考面完整 | 参考平面是回流路径，2 层板天然不完整 |
| `PCB-RULE-DECOUPLE-001` | 模组电源脚 0.1 µF、≤2 mm | 发射峰值 di/dt 下 `ΔV = L·di/dt` |
| `PCB-RULE-DECOUPLE-002` | 体电容 + 近端小电容组合 | 覆盖宽频段，抑制反谐振峰 |
| `PCB-RULE-PLACE-DCDC-001` | DC-DC 远离射频区、SW 节点最小 | 开关纹波落在射频带内会抬升底噪 |
| `PCB-RULE-ESD-001` | 天线座 ESD 低电容、靠接口、地短宽 | ESD 残压 = 钳位 + 地回路电感 × di/dt |
| `PCB-RULE-EDGE-001` | 模组/天线区到板边留工艺余量 | 铣切公差与板边应力影响天线与模组 |

**依据说明**

- **为什么 50 Ω 是“唯一正确的数”**：射频前端、线缆、天线都按 50 Ω 定义；任何一段失配都会产生反射，反射功率不会辐射出去，而是回到 PA 变成热。50 Ω 不是“最优”，而是“全链路约定的标准”。
- **净空与匹配的关系**：匹配网络只能把天线端口的阻抗调到 50 Ω，**不能改变天线的辐射效率**；净空被侵占损失的是效率（能量变成介质/涡流损耗），匹配救不回来。
- **共存干扰的物理**：接收机在强发射信号附近会阻塞（blocking）或产生互调；天线隔离度不足时，共存的发射功率直接进入另一路接收前端，靠软件时分只能缓解、不能根除。

## 可迁移的设计经验

**做对的**

1. 选型就选“含天线 + 含认证”的模组，底板只做 50 Ω 走线与净空，把射频风险外包。
2. 天线净空在布局前画成所有层 keepout，电池/屏/金属件按净空要求摆位。
3. 射频走线短、包地、参考面连续，匹配网络留 π 型焊盘与测试口。
4. 电源按发射峰值电流去耦与选型，DC-DC 远离射频区。

**妥协的**

1. 2 层低成本方案做射频，参考面不完整、阻抗难控，只能靠短走线与净空降级满足。
2. 小体积产品天线净空与电池/结构冲突，只能牺牲天线效率或电池容量。
3. 多射频共存靠软件时分缓解，硬件隔离度不足时吞吐仍会下降。
4. 低电容 ESD 器件成本高于普通 TVS，且仍需评估对插损的影响。

**反面教训**

1. 自动覆铜进入天线净空：整机距离直接掉一半，且很难通过改固件补救（`PCB-FAIL-EMI-FAIL`）。
2. 射频走线跨分割/换层不补回流孔：损耗与辐射同时变差，误判为“模组性能不行”。
3. 模组电源只放 1 µF、不按峰值电流选 LDO：发射瞬间掉压，表现为“连上就断、丢包”（`PCB-FAIL-CAP-DISTANCE`）。
4. 天线座用普通大电容 TVS：插损增大、S11 变差，接收灵敏度下降（`PCB-FAIL-TVS-WRONG`）。
