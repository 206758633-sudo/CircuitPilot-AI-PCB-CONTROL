# 案例 09：衣橱助手 V2.0（主板 + 按键灯板）—— 4 层异形板的电源树、天线净空与细间距 DFM

> **一句话结论**：这块板是“功能密度 + 结构约束 + 成本”三重挤压下的典型消费类主板：**4 层板要在 56×62mm 异形空间里塞下 ESP32-S3、Type-C 充电、双路 DC-DC、音频、摄像头 FPC、舵机与灯板连接**；决定它成败的不是布线技巧，而是**叠层/净空/细间距工艺/板间防反**四件事在前面是否定清楚。

## 设计原理拆解：一、叠层与电源树

### KP-CASE-WARDROBE20-01 4 层板优先“信号-地-电源-信号”，但异形板要先定板框再谈叠层

- **判据**：4 层推荐 Top(SIG) / Inner1(GND) / Inner2(PWR) / Bottom(SIG)；板框异形或缺口多时，先按 DXF 定板框与结构避让，再确认每层参考平面是否连续，最后才布线。
- **为什么**：ESP32-S3 的射频、USB、DVP 并行总线都依赖连续参考平面；异形板框会导致局部参考平面被切掉，若先布线再改板框，会出现大量跨分割和返工。
- **怎么做**：按 DXF 生成闭合板框（记录中主板轮廓 104 点、bbox 56.06×61.84mm）；Inner1 完整 GND；Inner2 3V3/电源分区；Top/Bottom 走信号并铺 GND；板框缺口处用地铜/缝合孔保持参考连续。
- **怎么查**：逐层检查参考平面完整性；关键信号（USB/DVP/晶振）是否跨分割；板框尺寸与结构件 3D 复核。

### KP-CASE-WARDROBE20-02 电源树按“充电-储能-升压-降压-负载”分层，并核算每一级的电流

- **判据**：Type-C VBUS → 保护 → 充电 IC → 电池 → 升压/降压 → 各负载；每一级要给出输入/输出电压、最大电流、效率、发热，电池充电截止电压必须与电池化学体系一致（本案例 4.35V 电池配 IP2312-4V35）。
- **为什么**：舵机堵转、功放峰值、WS2812 全白、WiFi 发射同时发生时，峰值电流可能数倍于平均电流；任何一级限流/电感饱和电流不足都会掉压复位。
- **怎么做**：按峰值电流选电感饱和电流与 MOS；VBUS 入口加 TVS + P-MOS 防反接；电池入口加 PTC/保险丝；3V3 与 5V 分别去耦；舵机/灯板电源单独走线并在入口加电容。
- **怎么查**：满载/峰值场景测 VBUS、电池端、3V3 压降与温升；核对充电电流与电池规格；做 WiFi 发射 + 舵机 + 灯效同时工作的压力测试。

### KP-CASE-WARDROBE20-03 电池充电 IC 的“后缀电压”是硬约束，不是可调参数

- **判据**：`IP2312-4V35` 的 `4V35` 表示 4.35V 截止；电池 582830 标称 3.85V 对应 4.35V 充电上限。若换成普通 4.2V 电池，必须换充电 IC 或改配置，不能混用。
- **为什么**：过充会鼓包/起火，欠充会容量不足；消费类产品认证（GB31241/UN38.3）也要求充电参数与电池规格一致。
- **怎么做**：把电池规格书中的截止电压、充电电流、NTC 要求写进设计输入；BOM 中固定充电 IC 型号；打样后做满电/过充保护/温度保护测试。
- **怎么查**：实测充满电压；核对电池保护板参数；确认充电 IC 的 NTC/温度脚是否按规格连接。

### KP-CASE-WARDROBE20-04 升压/降压外围按 datasheet 计算，不用“参考模块”的默认值

- **判据**：MT3608 升压的电感、输入/输出电容、反馈电阻；SY8089 降压的电感、输出电容、反馈电阻，都必须按输入/输出/负载计算，并按实际电容的直流偏压降容修正。
- **为什么**：模块化参考板的参数针对特定输入输出；换电池电压/负载后，纹波、限流、环路稳定性都会变，轻则纹波大，重则启动失败/振荡。
- **怎么做**：用 datasheet 公式算电感纹波电流、输出电容 RMS 电流、反馈分压；电感饱和电流 ≥ 峰值输入电流的 1.3 倍；输出电容按偏压后的有效容值选；反馈走线远离 SW 节点。
- **怎么查**：测启动/满载/负载跳变波形；测 SW 节点振铃与效率；热像仪确认电感/IC 温升。

## 二、天线净空与射频

### KP-CASE-WARDROBE20-05 ESP32 模组天线净空区必须“四层无铜、无走线、无器件、无丝印”

- **判据**：模组天线端伸出板边或位于板边净空区；净空区内所有层（含 GND 覆铜）不得有铜、走线、过孔、器件、丝印；净空尺寸按模组 datasheet（常见为天线前方 15mm 级、侧向数 mm，具体以官方文件为准）。
- **为什么**：天线附近的铜会改变谐振频率、降低效率、增加方向图畸变；自动覆铜最容易“误入”净空区。
- **怎么做**：在 EDA 中用 keepout/禁布区约束所有层；天线下方所有层挖空；外壳/电池/金属件远离天线；整机装配后再做射频测试。
- **怎么查**：逐层检查净空区；用矢量网络分析仪/整机吞吐测试验证；对比“净空区有铜/无铜”的 RSSI 差异。

### KP-CASE-WARDROBE20-06 射频模组的电源去耦与地回流要“短、宽、多孔”

- **判据**：模组 3V3 引脚旁 100nF 就近放置，模组地焊盘下方地平面完整，地过孔阵列间距 ≤3mm；射频走线（如有）按 50Ω 并包地。
- **为什么**：WiFi 发射是脉冲电流，电源/地阻抗会在发射瞬间产生压降与地弹，导致掉线/复位。
- **怎么做**：模组正下方保持完整 GND；去耦电容地端独立过孔；电源走线短而宽；避免数字高速线穿过模组下方。
- **怎么查**：测发射瞬间 3V3 纹波与地弹；做长时间 ping/吞吐测试；检查地过孔阵列。

## 三、细间距、连接器与 DFM

### KP-CASE-WARDROBE20-07 0.5mm 细间距器件禁止盘中孔，阻焊桥与钢网要同步设计

- **判据**：USB-C 16P、24P FPC、SH1.0 等 0.5mm 级焊盘内不得放盘中孔（via-in-pad）；阻焊桥宽度按板厂能力（常见 ≥0.08mm，需确认）；钢网厚度 0.10mm 级、面积比 <0.66 的开口缩窗。
- **为什么**：盘中孔会吸走锡膏造成虚焊/锡珠；阻焊桥不足会连锡；钢网开窗不当会锡量过多桥接。
- **怎么做**：细间距焊盘外引过孔；与板厂确认阻焊桥与塞孔能力；Type-C 固定脚大焊盘钢网缩窗约 70%；首件 AOI/X-Ray 检查。
- **怎么查**：Gerber 逐层检查盘中孔；首件 AOI/显微镜；连锡率统计；必要时切片。

### KP-CASE-WARDROBE20-08 板间连接器用“交叉线序 + 防呆 + 低电容 TVS”防装反

- **判据**：两块板用 SH1.0 3P 连接时，线序按 1↔3 交叉并在丝印/结构上防呆；每根信号线加低电容 TVS（<0.5pF 级）到地；连接器额定电流覆盖灯板峰值。
- **为什么**：装配时插反是高频人为错误；交叉线序让“反插”变成信号错位而不是电源短路；TVS 吸收热插拔/ESD。
- **怎么做**：连接器 Pin1 用方形焊盘/丝印标识；线序表写进装配图；TVS 靠近连接器；灯板入口加去耦电容。
- **怎么查**：故意反插测试不烧板；插拔/热插拔测试；检查 TVS 结电容是否影响 WS2812 数据。

### KP-CASE-WARDROBE20-09 异形板框不能 V-CUT，拼板用邮票孔/铣槽

- **判据**：异形边、圆弧、缺口处禁止 V-CUT；拼板采用邮票孔（孔 0.5mm、间距 0.8–1.0mm）或铣槽 + 连接筋；工艺边 ≥5mm，Mark 点 3 个且周围 1mm 无铜无阻焊。
- **为什么**：V-CUT 只能走直线，异形边会被切坏；邮票孔/铣槽能适应曲线并控制分板应力。
- **怎么做**：拼板图与板厂确认；工艺边加 Mark 点与定位孔；分板方向避开细间距器件与 FPC。
- **怎么查**：检查拼板图、Mark 点、工艺边；首件分板后检查边缘裂纹与器件损伤。

### KP-CASE-WARDROBE20-10 结构件与 3D 复核是“能不能装”的最后一道门

- **判据**：摄像头/FPC 弯折半径、Type-C 插拔空间、按键行程、导光柱与 WS2812 对位、电池仓、磁吸件、螺丝柱，必须在 3D 中逐项确认；连接器与外壳壁留 ≥0.3mm 间隙（按结构公差）。
- **为什么**：2D 板框正确不代表 3D 不干涉；FPC 弯折半径不足会断线，导光柱偏位会漏光。
- **怎么做**：导出 STEP 与外壳 3D 装配；重点检查连接器、按键、灯、FPC 出线；打样前做结构手板验证。
- **怎么查**：3D 干涉检查、装配手板、插拔/按压手感测试。

## 四、可迁移的设计经验

**做对的**
1. 先用 DXF 定异形板框，再做 4 层叠层与布局，避免后期大改。
2. 天线净空、细间距、板间防反这些“硬约束”在设计输入阶段就写进评审清单。
3. 电源树按峰值电流设计，而不是按平均电流。

**妥协的**
1. 4 层板在音频/摄像头/射频三套地参考之间只能折中，靠分区与单点连接控制噪声。
2. 单 Type-C + 充电 + 烧录共用，需要额外保护与 HUB/串口桥，BOM 成本上升。

**反面教训**
1. **“DRC 0 违规”不等于可制造**：本案例 DRC 在 EDA 规则集内通过，但评审仍列出天线净空、盘中孔、阻焊桥、钢网等必须人工确认项。
2. 自动布局/自动布线不能替代人工确认：去耦就近性、参考平面连续性、细间距扇出都需要逐项复核。
3. 发布门禁被阻断的真实原因包括 BOM 阻容值缺失、CPL 坐标与实机偏差 0.15–3.44mm、网表/网络不完整（274 焊盘 171 个初始无网络）——**设计数据不完整时，“文件导出成功”没有意义**。
