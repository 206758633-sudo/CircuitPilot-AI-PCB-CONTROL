# 案例 10：CircuitPilot 6 层监测板 —— 90Ω 差分反解、屏蔽过孔墙与“编译器抓出的 CC 缺失”

> **一句话结论**：这块 60×40mm 的 6 层监测板是“**先算阻抗、再落线宽**”的正面样本：USB 差分对不是填一个“差不多”的线宽，而是用叠层反解出 0.2102mm、实际布 0.213mm，回算 89.99Ω；同时，语义编译器在投板前抓出了 CC1/CC2 各只有一个端点（缺 5.1k 下拉）这种“看起来像画完了”的致命缺件。

## 设计原理拆解：一、叠层与阻抗——先反解，再布线

### KP-CASE-CP6L-01 阻抗控制必须“叠层→线宽→回算”闭环，不能拍脑袋填线宽

- **判据**：给定叠层（介质厚度/εr/铜厚）与目标阻抗（USB 90Ω、单端 50Ω），先反解线宽/间隙，再正向回算验证；回算偏差应控制在 ±5% 内（更严按项目要求）。
- **为什么**：线宽每变化 0.01mm，差分阻抗可能变化数Ω；按“常见 0.2mm”布线会得到 93.44Ω（+3.44Ω，+3.8%），在 USB HS 上已不可忽略。
- **怎么做**：建立叠层参数表（材料、厚度、铜厚、εr、阻焊厚度）；用场求解器/公式反解；把结果写入 EDA 规则与叠层计算单；打样加阻抗测试条，用 TDR 复核。
- **怎么查**：查看叠层计算单与 EDA 线宽是否一致；TDR 测差分阻抗；对比计算值与实测值并记录偏差。

### KP-CASE-CP6L-02 差分对“等长 + 等距 + 同参考 + 少过孔”四件事缺一不可

- **判据**：USB HS 差分对长度失配 ≤5mil（本案例 0.0000mm）；全程同层、同参考平面、间距恒定；换层时成对换并就近补地孔；避免跨分割。
- **为什么**：失配会产生共模转换与眼图闭合；参考不连续会造成阻抗突变；单端换层会破坏回流。
- **怎么做**：DP/DM 并行走线，中心距固定；蛇形补偿放在失配段且幅度小；换层处成对打孔并加回流地孔；差分对包地/屏蔽过孔墙。
- **怎么查**：EDA 等长报告；TDR/眼图；检查过孔数量与地孔位置；确认差分对未跨分割。

### KP-CASE-CP6L-03 差分对两侧的 GND 屏蔽过孔墙要“连续、够密、不切断参考”

- **判据**：高速差分对两侧布置地过孔墙（间距通常 ≤λ/10 或按项目规则，常见 1–3mm），过孔连接到同一地平面；过孔墙不得切断差分对的参考平面。
- **为什么**：过孔墙把差分对与相邻信号隔离，降低串扰；同时为换层/边缘场提供回流路径。
- **怎么做**：沿差分对两侧等距打地孔；过孔到走线边缘留够间距（本案例 ≥0.6mm）；与板边/连接器地铜连成整体。
- **怎么查**：检查过孔墙连续性、间距、是否落到 GND 平面；近场扫描/串扰测试。

### KP-CASE-CP6L-04 6 层板要明确每一层的“职责”，避免“有层但没参考”

- **判据**：6 层叠层必须定义 Top(SIG)/Inner1(GND)/Inner2(PWR)/Inner3(SIG)/Inner4(SIG)/Bottom(GND) 之类的职责；每个信号层都要有相邻完整参考平面；电源平面与地平面紧耦合。
- **为什么**：层数多不等于性能好；如果 Inner3/Inner4 都没有完整参考，走线仍然会跨分割、回流绕行。
- **怎么做**：先定平面（GND/PWR），再分配信号层；关键高速线优先走与 GND 相邻的层；电源平面分割处加缝合电容；叠层对称控制翘曲。
- **怎么查**：逐层检查参考平面完整性；关键网络跨层/跨分割统计；叠层对称性与板厚复核。

## 二、电源与监测：小信号测量最怕地/热噪声

### KP-CASE-CP6L-05 电流监测（INA226 类）要用开尔文接法，采样电阻功率与温漂要核算

- **判据**：分流电阻采用四线开尔文连接（电压采样点在内侧、电流路径在外侧）；采样走线成对、等长、远离开关节点；分流电阻功率 ≥ I²R 的 2 倍，温漂按精度要求选。
- **为什么**：分流电阻上的压降是 mV 级，走线/过孔的寄生电阻会直接变成测量误差；功率不足会温漂甚至烧毁。
- **怎么做**：分流电阻放在电流路径中，采样线从焊盘内侧引出；差分对走线短、包地；INA226 的 IN+/IN− 加 RC 滤波（按 datasheet）；校准用两点法。
- **怎么查**：对比万用表/电子负载读数；测不同电流下的线性度；热像仪检查分流电阻温升。

### KP-CASE-CP6L-06 温湿度/温度传感器要远离热源与板边，并留热隔离槽/开窗

- **判据**：TMP117/SHT40 类传感器远离 MCU、DC-DC、LDO、USB 连接器；传感器下方/周围避免大铜散热；需要时开热隔离槽或局部开窗；I2C 上拉与走线按总线电容计算。
- **为什么**：传感器测的是“自身温度”，板级热源与铜箔导热会让读数偏离环境温度；SHT40 还受 PCB 热质量与外壳影响。
- **怎么做**：传感器放在板边/通风处；下方挖空或只留窄走线；远离发热器件 ≥5mm（按精度要求）；外壳开透气孔；出厂做温度校准。
- **怎么查**：与标准温湿度计对比；热像仪看板面温度分布；整机老化测试看漂移。

### KP-CASE-CP6L-07 I2C 多器件共享要核对地址、上拉、总线电容与 ALERT 极性

- **判据**：SDA/SCL 上拉按速率与总线电容计算；所有从机地址不冲突；ALERT_N 为开漏、需上拉，极性/复位状态明确；总线走线远离 SW 节点与射频。
- **为什么**：地址冲突/上拉不当会导致通信失败；ALERT 极性接反会让 MCU 误判。
- **怎么做**：列地址表；上拉 2.2–4.7kΩ 级；ALERT_N 加上拉与 RC 滤波（按需）；长线加缓冲器。
- **怎么查**：I2C 扫描；示波器看上升沿；读取每个器件 ID 与告警状态。

## 三、USB-C 与 ESD

### KP-CASE-CP6L-08 CC1/CC2 各一只 5.1kΩ 下拉是受电“通电”的前提，编译器应在投板前拦住缺件

- **判据**：Sink 设备 CC1/CC2 各接一只 5.1kΩ±1% 到 GND；任何一端悬空/只有一个端点都视为缺件；PD 控制器方案按控制器参考设计接 CC 与 VBUS。
- **为什么**：C-to-C 线下 Source 通过 CC 检测 Rd 才输出 VBUS；本案例语义编译器正是发现 CC1/CC2 各只有 1 个端点，补 R1/R2 后才 ready。
- **怎么做**：原理图阶段就画两只 5.1kΩ；PCB 上靠近 Type-C 的 CC 引脚；BOM 固定 1% 精度；投板前跑端点/编译检查。
- **怎么查**：万用表测 CC 对地电阻；C-to-C 线实测 VBUS；检查 BOM 是否有两只 5.1kΩ。

### KP-CASE-CP6L-09 USB ESD 器件要靠近连接器，且结电容/钳位满足 HS 要求

- **判据**：USBLC6-2SC6 类 ESD 阵列放在 Type-C 与 MCU 之间，越靠近连接器越好；结电容满足 USB HS（通常 <1–2pF 级，按器件规格）；地端多过孔到地平面。
- **为什么**：ESD 是共模事件，器件越靠前残压越低；结电容过大会使眼图闭合。
- **怎么做**：D+/D− 先过 ESD 再进 MCU；ESD 地引脚短宽多孔；VBUS 加 TVS；连接器外壳地按接地策略处理。
- **怎么查**：检查 ESD 位置/结电容/地回流；做 IEC 61000-4-2 接触/空气放电测试（有条件）。

## 四、真实 DRC 与可制造性

### KP-CASE-CP6L-10 “DRC 有项数”比“DRC 0 项”更可信：要区分真违规、陈旧填充与未布线

- **判据**：DRC 报告必须带类别与位置；铺铜需“删除后重建”才会按净空挖空；Connection Error 往往意味着未布线/网络不完整，不是“DRC 误报”。
- **为什么**：本案例真实 DRC 为 156 项（Clearance 73 / 同封装净空 20 / Connection 63），其中大面积“铜到过孔”违规来自陈旧填充；如果只看“0 项”会误判可制造。
- **怎么做**：铺铜删除后重建；逐类处理 Clearance/Connection；对豁免项写理由与批准人；投板前复查 Gerber。
- **怎么查**：导出 DRC 报告逐条核对；对比不同板态的项数；重跑 DRC 确认收敛。

## 五、可迁移的设计经验

**做对的**
1. 先用叠层反解线宽，再正向回算验证（89.99Ω vs 目标 90Ω）。
2. 差分对等长做到 0.0000mm，并用 GND 过孔墙隔离。
3. 用语义编译器在投板前抓出 CC 缺件，而不是等打样后“充不了电”。

**妥协的**
1. 6 层板成本高于 4 层，只适合对阻抗/信号完整性有明确要求的板。
2. 差分对走 Inner4 需要换层过孔，增加了阻抗不连续点，需要靠地孔/线宽补偿。

**反面教训**
1. 只布线不算完：CC 下拉、ESD、去耦这些“小器件”缺失会让整板功能失效。
2. 把“DRC 超时/0 项”当成“没问题”是危险的；必须区分超时、空结果与真实 0 违规。
3. 阻抗只写在文档里、不落到 EDA 规则与叠层计算单，换个人布线就会走偏。
