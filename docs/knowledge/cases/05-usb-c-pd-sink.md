# 案例 05：USB-C PD 受电/充电参考设计 —— CC 是“通行证”，VBUS 开关与泄放是“安全闸”

> **一句话结论**：USB-C PD 受电板的最小正确集是**两路独立 5.1 kΩ Rd（CC1/CC2）+ 会解析 PD 报文的控制器 + 受控的 VBUS 开关与泄放 + 连接器侧 ESD/浪涌保护 + 独立于系统电源的死电池路径**；少任何一项，表现都是“某些线/某些适配器充不上电”，而且很难靠软件补救。

## 案例档案

| 项 | 内容 |
|---|---|
| 板型 | USB-C 受电（Sink）/充电输入参考设计（公开参考设计与公开设计指南的通用做法） |
| 层数 | 公开参考设计常见为 4 层（以具体参考设计文件为准，本机未核对） |
| 尺寸 | 无统一值，取决于产品与连接器/电感/电容占位（以具体参考设计为准） |
| 主控 | 可无 MCU（纯硬件 PD 控制器）；带数据/智能充电时用 MCU + PD 控制器（型号以 datasheet 为准） |
| 电源 | PD 适配器 VBUS 5～20 V（PD 3.1 EPR 更高，按规范版本复核）→ 保护 → VBUS 开关 → 后级 Buck/充电 IC |
| 关键接口 | Type-C 座（16 pin 或 24 pin）、CC1/CC2、VBUS/GND、D+/D−（USB2）、可选 SBU |
| 来源类型 | 公开参考设计（B 级）：USB Type-C 规范 + USB PD 规范 + 芯片厂商公开参考设计/应用笔记 + 公开工程常识；**本机无外网，未逐页核对官方文件** |

## 设计原理拆解

以下按“电源树 → 上电时序与复位 → 接口与保护 → 去耦与地 → EMC/ESD → 热与 DFM”拆解。所有具体电压/电流/电容/钳位数值均标注“按 Type-C/PD 规范版本与控制器 datasheet 复核”。

**电源树：从插座到后级**

### KP-CASE-USBCPD-01 两个独立 5.1 kΩ Rd 是“能被供电”的最小必要条件

- **判据**：Sink 的 CC1/CC2 各接一只 5.1 kΩ ±1% 到 GND，两路独立；不得只接一路、不得两路并联成一只、不得用 10 kΩ 代替（`PCB-RULE-USBC-CC-001`）。
- **为什么**：Source 通过 CC 上的 Rd 识别“对面是一台受电设备”并据此输出 VBUS；C-to-C 线只有检测到合法的 Rd 才建立供电。缺一路或阻值错误，表现为“A-to-C 能充、C-to-C 不充”或“只能小电流”。
- **怎么做**：两颗独立电阻分别靠近连接器 CC1/CC2 引脚；1% 精度；CC 走线短；电阻地端就近接 GND；注意 CC 可能被 Source 加 VCONN，不要用普通 3.3V 器件直连。
- **怎么查**：万用表测 CC1–GND、CC2–GND；分别用 C-to-C 线与 A-to-C 线实测 VBUS 是否建立；不通过 → 补电阻/改阻值/改接法。

### KP-CASE-USBCPD-02 PD 协商是 CC 上的 BMC 数字通信，不是模拟分压

- **判据**：PD 报文通过 CC 单线以 BMC 编码传输；Sink 必须用 PD 控制器（或支持 PD 的 MCU + PHY）解析 Source_Capabilities 并回 Request，才能拿到 9 V/15 V/20 V（及 PPS）；电阻分压/固定电平只能拿到默认 5 V。
- **为什么**：PD 报文有 CRC 与状态机，电压/电流档位由 Source_Capabilities 定义；靠“骗电平”无法参与协商，也无法处理软复位、角色切换与异常恢复。
- **怎么做**：按 datasheet 选 PD 控制器（关注 CC 耐压、VCONN 支持、是否内置 VBUS 开关/泄放）；CC 上器件按参考设计；固件实现 PDO 选择、PPS、软复位与错误恢复；VBUS 电压反馈给控制器做 OVP。
- **怎么查**：PD 分析仪/协议分析仪抓 CC 报文；用不同品牌适配器交叉测试；不通过 → 改控制器配置/固件/CC 外围。

### KP-CASE-USBCPD-03 VBUS 开关与泄放：换档前必须先落到 vSafe0V

- **判据**：Source 改变 VBUS 电压前会先降到 vSafe0V；Sink 侧若需主动切换/断开，应在 VBUS 落到安全电压后再闭合开关，并在断开时提供受控泄放路径（泄放阻值/时间按规范与控制器 datasheet 复核）。
- **为什么**：VBUS 电容上残压未泄放时重新升压，会产生大涌流与过冲，可能触发适配器 OVP 或打坏后级；泄放太快又会造成额外功耗与热。
- **怎么做**：用带放电功能的负载开关/背靠背 MOS；泄放电阻与开关配合（避免常接耗电）；VBUS 电容按规范上限与后级需求折中；软启动/限流。
- **怎么查**：示波器测电压切换波形（过冲/下冲/泄放时间）；不同适配器重复切换；不通过 → 改泄放/改软启动/改开关。

### KP-CASE-USBCPD-04 死电池（dead battery）路径：系统没电也要能拿到 5 V

- **判据**：电池完全没电/系统未上电时，Sink 仍必须通过**无源 Rd** 让 Source 输出 5 V；PD 控制器若由 VBUS 供电，要保证上电前 CC 已呈现 Rd（`SCH-MOD-USBC-SINK`，具体按控制器 datasheet 复核）。
- **为什么**：死电池场景系统电源为 0，若 Rd 由 MCU GPIO 控制则会呈高阻，Source 认为“无设备”→ 不供电 → 永远充不上，形成“死锁”。
- **怎么做**：Rd 用无源电阻常接；需要省电时保持“常接 Rd + 上电后按需维持”；PD 控制器 bus-powered（从 VBUS 取电）；死电池时先 5 V 慢充，再协商高压。
- **怎么查**：放电到欠压/拔电池，插 C-to-C 适配器测 VBUS 是否为 5 V；系统断电时测 CC 对地电阻；不通过 → 改无源 Rd/改供电路径。

**上电时序与复位**

### KP-CASE-USBCPD-05 上电/复位时序：VBUS 建立、控制器复位、PG 与后级使能要有先后

- **判据**：PD 控制器上电自复位完成前不得依赖 CC 状态；VBUS 建立且电压稳定后才允许后级 Buck/充电 IC 使能；PG（Power Good）/FAULT 要有确定状态与上拉；插入/拔出/软复位都要能回到确定态。
- **为什么**：上电时序错乱会让控制器在 VBUS 未稳时误判 PDO，或让后级在过压瞬间启动；这是“偶发不充电/偶发重启”的常见根因。
- **怎么做**：控制器 RST 加 RC/上拉；后级 EN 由 PG 或控制器 GPIO 控制并加默认下拉；FAULT 上拉并接 MCU 中断；插入检测用 CC 状态而非仅 VBUS。
- **怎么查**：示波器四通道同时看 VBUS、CC、PG、后级 EN；反复插拔/软复位；不通过 → 改时序/改上下拉。

**接口与保护**

### KP-CASE-USBCPD-06 VBUS 入口保护顺序：连接器 → ESD/TVS → 保险丝/eFuse → 开关 → 后级

- **判据**：保护器件按“先泄放、后限流、再开关”的顺序布置；TVS 钳位电压低于后级耐压且高于最大 VBUS；保险丝/eFuse 额定电流覆盖最大 PD 电流并留裕量（`PCB-RULE-ESD-001`、`PCB-RULE-CURRENT-001`）。
- **为什么**：浪涌先到 TVS 泄放，残余能量再由保险丝/开关承受；顺序反了会让浪涌穿过保护进入后级；保险丝选小会误断，选大则失去保护。
- **怎么做**：TVS 放连接器与开关之间，地回路短；保险丝按功率档位选（2 A/3 A/5 A 档位按产品复核）；eFuse 集成 OVP/OCP/SCP/OTP；VBUS 走线按最大电流加宽并用多层并联。
- **怎么查**：浪涌/EFT 测试（IEC 61000-4-5/4-4，按产品等级）；过流/短路保护测试；满载压降与温升；不通过 → 改 TVS/保险丝/走线。

### KP-CASE-USBCPD-07 CC 走线与 ESD：短、独立、低电容，不并大电容

- **判据**：CC 走线短（连接器到控制器尽量 ≤10 mm 量级，按布局）、不与 VBUS/开关节点并行；ESD 器件低电容且耐 VCONN 电压；CC 上不加大电容（容值按 Type-C 规范上限复核）。
- **为什么**：CC 上跑 BMC 高频信号，长走线/大电容会破坏边沿导致协商失败；ESD 结电容过大同样失真；VCONN 电压可能超过普通 3.3V ESD 耐压而击穿。
- **怎么做**：CC 单独走线、短、少过孔；ESD 阵列放连接器侧；按规范控制 CC 对地电容；CC 与 VBUS 保持间距（20 V/48 V 按 `PCB-RULE-CLEARANCE-001` 加严）。
- **怎么查**：示波器看 CC 波形（BMC 边沿/幅度）；PD 协商成功率；耐压测试；不通过 → 改 ESD/改走线。

### KP-CASE-USBCPD-08 USB2 D+/D−：90Ω 差分 + ESD + 不跨分割

- **判据**：若 Sink 带 USB2 数据，D+/D− 按 90Ω 差分、对内等长 ≤5 mil、不跨分割、ESD 靠连接器（`PCB-RULE-USB-001`、`PCB-RULE-DIFF-001`、`PCB-RULE-IMPEDANCE-001`）。
- **为什么**：与通用 USB2 要求一致：阻抗失配 → 反射/枚举失败；ESD 靠后 → 残压高；跨分割 → 回流绕行、共模辐射增大。
- **怎么做**：连接器 → ESD → MCU；差分对同层同参考；避免 stub；外壳地按整机策略接；如需共模电感按 datasheet 并保持差分对称。
- **怎么查**：差分 DRC/等长报告；USB 枚举与传输测试；眼图（有条件）；不通过 → 改布线/改 ESD。

**去耦与地**

### KP-CASE-USBCPD-09 涌流与 VBUS 电容：受电端电容有上限，必须软启动/限流

- **判据**：VBUS 对地电容与插入涌流必须满足 Type-C/PD 限值（具体数值按规范版本与控制器 datasheet 复核）；用软启动/限流避免插入瞬间拉低 VBUS。
- **为什么**：插入瞬间电容充电电流很大，会触发适配器过流/电压跌落，导致协商失败或反复重试；电容超过规范上限还可能导致 Source 拒绝供电。
- **怎么做**：选带软启动的负载开关/eFuse；VBUS 电容按规范上限与后级需求折中；必要时加有源限流；大容量电容放开关之后而非之前。
- **怎么查**：插入瞬间 VBUS 波形（跌落/涌流峰值）；不同适配器重复插拔；不通过 → 改软启动/改电容。

### KP-CASE-USBCPD-10 PD 控制器供电与接口：去耦、I2C 地址、GPIO 中断

- **判据**：控制器 VDD 就近 0.1 µF；若由 VBUS 经 LDO 供电，LDO 输入/输出电容按 datasheet；I2C 上拉/地址按总线规划；中断/复位/使能引脚有确定电平（`PCB-RULE-DECOUPLE-001`、`PCB-RULE-I2C-001`）。
- **为什么**：PD 控制器是数字+模拟混合，电源噪声会影响 CC 采样与 BMC 解码；I2C 地址冲突/上拉不当会导致 MCU 读不到状态，表现为“协商正常但系统不知道”。
- **怎么做**：去耦就近；I2C 走线短、上拉按总线电容算；中断引脚上拉；复位引脚 RC；GPIO 控制 VBUS 开关时注意上电默认态（避免误开）。
- **怎么查**：读控制器 ID/状态寄存器；I2C 扫描；插拔/复位测试；不通过 → 改去耦/上拉/默认电平。

**EMC/ESD**

### KP-CASE-USBCPD-11 整机 EMC/ESD：接口保护 + 外壳地 + 线缆共模，按产品等级做

- **判据**：ESD 目标按产品等级（常见 IEC 61000-4-2 接触 ±8 kV / 空气 ±15 kV，**按产品标准与认证要求复核**）；VBUS/CC/D+/D− 均在连接器侧受保护；外壳地与信号地关系明确；屏蔽/共模按线缆与结构定。
- **为什么**：Type-C 线缆是共模注入的主要路径；ESD/浪涌电流必须在接口处泄放，不能进入板内；外壳地处理决定了共模电流往哪走。
- **怎么做**：连接器外壳地多过孔/大面积接机壳或地平面（按策略）；TVS 地短宽；必要时 VBUS 加共模电感/磁珠；整机做 ESD/EFT/浪涌预测试。
- **怎么查**：ESD 枪打外壳、CC、VBUS、D+/D− 引脚；近场探头定位热点；共模辐射测试；不通过 → 改保护/改接地/改结构。

**热与 DFM**

### KP-CASE-USBCPD-12 热与 DFM：VBUS 开关/充电 IC 的损耗按最大档位算

- **判据**：开关管损耗含导通 `I²R` 与开关损耗；5 A/20 V 档位下 Rdson 与 PCB 铜箔温升要核算；EPAD 打过孔阵列 + 大面积铜；连接器焊盘/外壳满足机械与回流焊要求（`PCB-RULE-THERMAL-001`）。
- **为什么**：PD 高功率档位电流大，导通损耗与连接器/走线电阻发热明显；温升过高会触发 OTP 降档，表现为“充一会儿就掉功率”。
- **怎么做**：选低 Rdson 开关；VBUS 走线宽/多层并联；开关/充电 IC 的 EPAD 按 datasheet 打孔；热敏电阻靠近发热点做温度保护；连接器选 16 pin 或 24 pin 按功能与机械强度定。
- **怎么查**：满载老化热像仪；`Tj` 估算；插拔寿命测试；不通过 → 改器件/加铜/加散热。

## 规则依据

| 规则 ID | 本案例对应做法 | 物理/标准依据 |
|---|---|---|
| `PCB-RULE-USBC-CC-001` | CC1/CC2 各 5.1 kΩ ±1% 下拉到 GND | USB Type-C 规范用 Rd 标识 Sink；Source 检测到 Rd 才输出 VBUS |
| `PCB-RULE-ESD-001` | ESD/TVS 在连接器与后级之间、地短宽多孔 | ESD 是共模事件，残压 = 钳位电压 + 地回路电感 × di/dt |
| `PCB-RULE-USB-001` | 带数据时 D+/D− 90Ω、ESD 靠连接器 | 差分阻抗失配引起反射/枚举失败 |
| `PCB-RULE-DIFF-001` | 差分对内等长 ≤5 mil、同参考、不跨分割 | 失配产生共模转换，跨分割破坏回流 |
| `PCB-RULE-IMPEDANCE-001` | 90Ω 差分线宽由叠层反解 | 阻抗由线宽/介质/参考面共同决定，必须按叠层计算 |
| `PCB-RULE-CURRENT-001` | VBUS/地按最大 PD 电流选线宽与铜厚 | IPC-2152 载流与温升；大电流路径压降与发热 |
| `PCB-RULE-DECOUPLE-001` | 控制器 VDD 就近 0.1 µF | 高频去耦靠安装电感，距离越远越失效 |
| `PCB-RULE-DECOUPLE-002` | VBUS 体电容 + 近端小电容组合 | 容值间隔覆盖频段，抑制并联反谐振峰 |
| `PCB-RULE-THERMAL-001` | 开关/充电 IC EPAD 过孔阵列 + 铜皮 | 结温 `Tj = Ta + θja·P`，EPAD 是主要散热路径 |
| `PCB-RULE-CLEARANCE-001` | VBUS（20 V/EPR 更高）与 CC 间距加严 | 工作电压越高，IPC-2221 间距要求越高 |
| `PCB-RULE-CREEPAGE-001` | 高压/认证场景按爬电距离核算 | 污染+潮湿下表面漏电，按安规标准计算 |

**依据说明**

- **Rd 的物理意义**：CC 线上的 Rd 是一个“我是受电方”的直流标识；Source 通过它判断是否上电、能提供多大电流，属于协议层而非“充电协议芯片”的私有约定。
- **BMC 编码**：PD 把数字报文调制到 CC 上（双相标记编码），所以 CC 的完整性 = 协商成功率；任何额外电容/长线/大结电容 ESD 都会直接降低成功率。
- **VBUS 泄放**：受电端在电压切换时是“被供电方”，必须尊重 Source 的 vSafe0V 过渡；不泄放会形成涌流，触发 OVP/OCP，表现为“插上闪一下就没电”。
- **死电池**：本质是“系统电源与 CC 标识解耦”——Rd 必须由无源器件在系统未上电时也呈现，这是 PD 受电板最容易被忽略的一条。

## 可迁移的设计经验

**做对的**

1. CC 用两颗独立 5.1 kΩ ±1%，不省、不并联、不用 10 kΩ，这是所有 PD 功能的“入场券”。
2. 保护顺序固定为“连接器 → ESD/TVS → 保险丝/eFuse → 开关 → 后级”，并让保护地回流尽量短。
3. PD 控制器与 VBUS 开关靠近连接器，CC 走线短，减少 BMC 波形劣化。
4. 死电池路径用无源 Rd，保证系统零电时也能先拿到 5 V。

**妥协的**

1. 成本优先时用 16 pin Type-C 座（仅充电/USB2），牺牲 SuperSpeed 与部分机械强度/寿命。
2. 纯硬件 PD 控制器（电阻配置档位）省 MCU，但读不到 PDO、不能动态调压；要自适应就得上 I2C 控制器。
3. 参考设计常把 ESD 与开关做成 combo 器件省面积，产品拆分后布局空间变紧，需要重新核算环路与散热。

**反面教训**

1. CC 只接一路或两路并联一只 5.1 kΩ → C-to-C 线不供电，且很难通过软件发现（`PCB-FAIL-USBC-CC`）。
2. 电压切换不泄放/不按 vSafe0V 过渡 → 后级过压、适配器重协商失败，表现为“反复插拔才偶尔成功”。
3. CC 上加大电容或用高结电容 ESD、忽略 VCONN 5 V 容限 → BMC 波形被破坏或 ESD 击穿；但普通 5 V 充电仍正常，极易误判为“协议芯片问题”。
4. VBUS 走线/开关按 5 V/500 mA 设计，实际 20 V/3 A 档位发热严重，触发 OTP 降档。

## 评审清单
