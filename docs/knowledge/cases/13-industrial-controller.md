# 案例 13：工业控制器 —— 宽压输入、隔离总线、宽温与抗扰是四条硬边界

> **一句话结论**：工业控制器与消费板的差别不在“用了更贵的器件”，而在**四条硬边界必须同时成立**：24 V 级宽压输入要能扛浪涌与反接、现场总线要电气隔离且隔离带真正断开、−40～85 °C 要按降额而非按常温设计、EMC 抗扰要按 IEC 61000-4 系列而不是“过一遍 ESD 就行”。任何一条打折，现场表现都是“偶发死机/通信丢包/烧接口”，而这些故障在实验室常温台面上几乎复现不出来。

## 设计原理拆解

以下按“输入保护与电源树 → 隔离与总线 → 抗扰与 ESD → 宽温与器件降额 → 采样与精度 → 机械与防护 → 可测试性”拆解。数值均标注“按器件 datasheet、标准版本与认证要求复核”。

**一、输入保护与电源树**

### KP-CASE-INDUSTRIAL-01 24 V 输入的保护顺序是“先泄放、再阻断、后稳压”

- **判据**：输入路径按“端子 → 保险丝/熔断 → TVS/压敏 → 反接阻断（MOS/二极管）→ 浪涌抑制 → 共模/差模滤波 → DC-DC”布置；每个器件的额定值覆盖最大持续电压与浪涌电流（`PCB-RULE-ESD-001`、`PCB-RULE-POWERMUX-001`、`PCB-RULE-CURRENT-001`）。
- **为什么**：工业现场的浪涌能量大（雷击感应、感性负载切换），必须先在入口泄放，再让后级承受残余；反接保护放在前端才能保护整条路径；顺序反了会让浪涌穿过 TVS 进入 DC-DC，直接炸机。
- **怎么做**：端子后先保险丝（分断能力覆盖短路电流），再 TVS/压敏（钳位低于后级耐压），再反接 MOS（低 Rdson、栅极有稳压管保护），再 π 型滤波；DC-DC 选宽压输入并留 1.5 倍以上耐压余量。
- **怎么查**：按 IEC 61000-4-5（浪涌）、4-4（EFT）等级做预测试；反接测试（正负反接 1 min）后功能正常；满载温升与压降；保险丝分断能力核对。

### KP-CASE-INDUSTRIAL-02 隔离侧要有独立隔离电源，不能从非隔离侧“借电”

- **判据**：凡是需要电气隔离的接口（RS485/CAN/数字输入），其收发器与隔离器二次侧必须由**隔离 DC-DC**供电；隔离电源的隔离等级、爬电距离与数字隔离器匹配（`PCB-RULE-ISO-001`、`SCH-MOD-CAN-RS485`）。
- **为什么**：隔离的目的是切断地环路与共模电压，如果二次侧从一次侧取电，隔离 barrier 被电源线短接，隔离形同虚设；现场两侧地电位差可达数十伏，共模电流会直接烧收发器。
- **怎么做**：选集成隔离电源的隔离收发器（省空间）或“隔离 DC-DC + 数字隔离器 + 收发器”分立方案；隔离电源输出加去耦；两侧地严格分开；隔离器使能/方向脚默认态要确定。
- **怎么查**：万用表测隔离带两侧 GND 应开路（高阻）；耐压测试（按隔离等级，如 2.5 kVrms/1 min，按器件与认证要求复核）；共模干扰下通信误码率测试。

**二、隔离与总线**

### KP-CASE-INDUSTRIAL-03 隔离带是物理结构：无铜、无过孔、爬电/间隙按标准算

- **判据**：隔离带（barrier）下方所有层不得有铜、不得有过孔、不得有丝印跨越；爬电距离与电气间隙按工作电压、污染等级、海拔与绝缘等级查表计算并留裕量（`PCB-RULE-CREEPAGE-001`、`PCB-RULE-CLEARANCE-001`）；必要时开槽（`PCB-RULE-ISO-001`）。
- **为什么**：污染与潮湿会在 PCB 表面形成漏电通路，隔离带被铜或过孔跨越时，爬电距离实际被短路；开槽能显著增加表面爬电路径，是工业/电源板的常规手段。
- **怎么做**：隔离带在布局阶段画成禁布区（所有层）；跨隔离带的信号只走隔离器/变压器/光耦本体；隔离带两侧铜皮各自收边；需要更高爬电时开槽并做三防漆；丝印标“隔离区”。
- **怎么查**：逐层检查隔离带内无铜无过孔；量爬电/间隙与计算值；耐压/绝缘电阻测试；湿热后复测绝缘电阻。

### KP-CASE-INDUSTRIAL-04 RS485/CAN 终端、偏置与 TVS 的位置决定“能不能长期活”

- **判据**：RS485 终端 120 Ω 装在总线两端（不是每个节点）；失效保护偏置按总线空闲状态设计；CAN 用 120 Ω 分裂终端 + 中心电容（按收发器指南复核）；TVS/共模电感放在连接器与收发器之间，地端短宽（`PCB-RULE-ISO-001`、`PCB-RULE-ESD-001`）；总线走线成对、无 stub、分支尽量短。
- **为什么**：终端不匹配会产生反射，长线高速率时误码率上升；偏置缺失会让总线空闲态不确定；TVS 位置靠后会让浪涌先进收发器；stub 会形成阻抗不连续与天线效应。
- **怎么做**：终端电阻放在连接器附近并用跳线/焊桥可选；偏置电阻按总线电容与速率计算；TVS 用地线短接、多过孔；共模电感保持差分对称；A/B、H/L 成对走线并包地。
- **怎么查**：示波器看总线波形（上升沿、反射、共模）；长线（如 100 m 级，按现场）通信误码测试；终端电阻实测；浪涌/EFT 后通信恢复测试。

### KP-CASE-INDUSTRIAL-05 隔离器两侧的去耦与地：每侧各自就近，禁止跨带

- **判据**：数字隔离器/隔离收发器的一次侧、二次侧电源各有 0.1 µF 就近去耦（到引脚 ≤2 mm），两侧地去耦电容不得共用过孔或跨隔离带连接（`PCB-RULE-DECOUPLE-001`、`PCB-RULE-ISO-001`）；隔离器输出侧的负载回流路径要短。
- **为什么**：隔离器靠电容/变压器耦合传递信号，两侧电源噪声会通过耦合路径互串；若两侧去耦共用过孔，等于在隔离带上开了交流通路，共模抑制变差。
- **怎么做**：两侧各放 0.1 µF + µF 级电容；二次侧地平面独立（在隔离带内侧收边）；隔离器下方不跨带铺铜；输出侧信号回流地就近。
- **怎么查**：目检两侧去耦与地是否独立；共模干扰下误码测试；隔离耐压测试；两侧地之间用万用表确认无直流通路。

**三、抗扰与 ESD**

### KP-CASE-INDUSTRIAL-06 EMC 抗扰要按 IEC 61000-4 系列逐项设计，不是“加个 TVS”**

- **判据**：按目标等级逐项落实：ESD（4-2）、EFT（4-4）、浪涌（4-5）、辐射抗扰（4-3）、传导抗扰（4-6）；每一项都要有对应的保护/滤波/接地措施与验证方法（`PCB-RULE-ESD-001`、`PCB-MOD-EMC`）。
- **为什么**：不同干扰的耦合路径不同——ESD 是共模瞬态、EFT 是快速脉冲群、浪涌是大能量、辐射抗扰是场耦合；只做 ESD 防护无法通过 EFT/浪涌，反之亦然。
- **怎么做**：接口保护 + 共模滤波 + 完整地平面 + 屏蔽/结构接地；电源入口做差模/共模滤波；线缆屏蔽层按“一端接地/两端接地”策略选；敏感信号远离接口与开关节点。
- **怎么查**：按等级做预测试（第三方或自建）；失败项定位到“端口/频段/耦合路径”再改；整改后回归全部项目，避免“修好一项坏另一项”。

### KP-CASE-INDUSTRIAL-07 数字输入的隔离与滤波：现场 24 V 不能直接进 MCU

- **判据**：24 V 数字输入（DI）必须经“限流 + 分压/光耦/数字隔离器 + 滤波”后进 MCU；输入阈值按工业标准（如 ON ≥ 15 V、OFF ≤ 5 V 量级，按目标标准复核）；输入要有反接与浪涌保护（`SCH-MOD-PWR-PROTECT`、`PCB-RULE-CREEPAGE-001`）。
- **为什么**：现场 24 V 会叠加浪涌与感应尖峰，直接进 MCU 会击穿 IO；长线输入会引入共模与振铃，需要 RC 滤波与迟滞；不做反接保护时，接线错误直接烧输入。
- **怎么做**：每通道独立限流电阻 + TVS + 光耦/隔离器；RC 滤波时间常数按输入频率与去抖需求定；输入状态 LED 与 MCU 采样解耦；通道间保持爬电距离。
- **怎么查**：按标准阈值与浪涌等级测试；反接测试；长线（现场长度）输入抖动测试；通道间绝缘测试。

**四、宽温与器件降额**

### KP-CASE-INDUSTRIAL-08 宽温设计是“降额 + 选型 + 布局”三件事，不是筛选

- **判据**：所有器件按目标温度范围（常见 −40～85 °C，按产品规格复核）核对降额曲线：电解电容按温度/纹波电流降额、晶振按温漂与起振裕度、DC-DC 按高温效率与 θJA、连接器/线缆按材料耐温（`PCB-RULE-THERMAL-001`、`PCB-MOD-THERMAL`）。
- **为什么**：电解电容寿命约每升 10 °C 减半；晶振在低温起振裕度下降；DC-DC 高温下 Rdson 上升、损耗增加；常温测不出这些问题，现场高温机柜内集中爆发。
- **怎么做**：优先固态电容/陶瓷电容；晶振选宽温型号并核对负阻裕度；DC-DC 按最高环境温度算 `Tj`；发热件分散并远离温度敏感件；必要时加导热/散热结构。
- **怎么查**：高低温箱做功能与起振测试（−40 °C 冷启动、85 °C 连续运行）；高温老化测电容纹波与温升；温度循环后复测关键参数。

### KP-CASE-INDUSTRIAL-09 掉电保持与看门狗：工业现场断电是常态，不是异常

- **判据**：控制器要有掉电检测（PVD/比较器）与足够时间的保持电容（或超级电容），保证断电瞬间能保存关键数据并安全关断输出；独立看门狗（外部或内部）必须使能且喂狗逻辑可靠（`SCH-MOD-RESET`）。
- **为什么**：工业现场断电/电压跌落频繁，若掉电时正在写 Flash 或驱动继电器，会造成数据损坏或输出抖动；看门狗是抗干扰的最后一道防线，但喂狗逻辑写错会变成“周期性复位”。
- **怎么做**：电源入口加掉电检测分压；保持电容按“检测到掉电后完成关键操作”的能量计算；写 Flash 前先确认电压；看门狗用独立时钟源并留调试禁用跳线（量产使能）。
- **怎么查**：可调电源快速跌落到 0 V，观察数据完整性与输出状态；反复上下电 1000 次；注入干扰验证看门狗动作；测量保持时间。

**五、采样、机械与可测试性**

### KP-CASE-INDUSTRIAL-10 4～20 mA / 电流采样：开尔文接法 + 成对走线 + 功率降额

- **判据**：分流电阻（shunt）采样必须开尔文接法，采样走线从电阻焊盘内侧成对引出并远离功率路径（`PCB-RULE-SHUNT-001`）；分流电阻功率按最大电流的 1.5～2 倍降额；ADC 前端加 RC 滤波与保护（`SCH-MOD-ADC`）。
- **为什么**：分流电阻上的压降是 mV 级，功率走线上的 IR 压降会直接叠加成误差；开尔文接法把“采样点”与“功率点”分开，才能测准；功率不足会让电阻温漂，进一步破坏精度。
- **怎么做**：四线焊盘布局；采样走线成对、短、等长、包地；ADC 输入加 RC 低通与钳位；分流电阻选低温度系数（如 50 ppm/°C 级，按精度需求复核）；必要时做温度补偿。
- **怎么查**：用标准源校准零点与满量程；多点线性度测试；满载温升与温漂测试；长线/共模干扰下的读数稳定性。

### KP-CASE-INDUSTRIAL-11 机械防护与可测试性：端子、安装孔、三防与调试口都要在布局阶段定

- **判据**：接线端子/连接器靠板边、开口朝外并做机械固定（`PCB-RULE-PLACE-CONN-001`）；安装孔与导轨结构匹配、孔周围留禁布区；高湿/污染环境要预留三防漆或灌封（开窗、排气、连接器避让）；关键网络留测试点与隔离调试口（`PCB-RULE-TESTPOINT-001`、`PCB-RULE-PLACE-TEST-001`）。
- **为什么**：工业现场振动会让连接器焊点疲劳开裂（`PCB-FAIL-CONNECTOR-STRESS`）；三防漆若涂到连接器/测试点上会导致接触不良；没有隔离调试口时，现场调试会引入地环路与浪涌风险。
- **怎么做**：端子加固定脚/卡扣；大质量器件（电感、继电器）远离板边并点胶；三防漆区域在丝印/加工图上标清；调试 UART 经隔离器引出或留排针；测试点按探针网格布置。
- **怎么查**：振动/跌落测试（按产品等级）；三防漆后连接器与测试点功能验证；安装孔与结构件装配检查；治具试测。

## 规则依据

| 规则 ID | 本案例对应做法 | 物理/标准依据 |
|---|---|---|
| `PCB-RULE-ISO-001` | 隔离带无铜无过孔、隔离电源独立、TVS/终端按指南 | 隔离靠物理断开与爬电距离；跨带铜/过孔等于短路隔离 |
| `PCB-RULE-CREEPAGE-001` | 爬电距离按电压/污染等级/海拔查表并留裕量 | 潮湿+污染下表面漏电，按 IEC 60664/安规标准计算 |
| `PCB-RULE-CLEARANCE-001` | 24 V 与隔离前后按电压分级取间距 | 电气间隙与工作电压相关 |
| `PCB-RULE-ESD-001` | 接口 TVS 在连接器与收发器之间、地短宽 | ESD 共模事件，残压 = 钳位电压 + 地回路电感 × di/dt |
| `PCB-RULE-POWERMUX-001` | 24 V 输入与调试供电的优先级/防倒灌 | 多电源路径无优先级会倒灌、切换掉电复位 |
| `PCB-RULE-DECOUPLE-001` | 隔离器两侧各自就近 0.1 µF | 高频去耦靠安装电感，跨带去耦破坏隔离 |
| `PCB-RULE-SHUNT-001` | 分流电阻开尔文接法、成对走线、功率降额 | mV 级信号，功率路径 IR 压降是主要误差源 |
| `PCB-RULE-THERMAL-001` | DC-DC/线性稳压 EPAD 过孔 + 铜皮 | `Tj = Ta + P×θJA`，高温环境 θJA 更差 |
| `PCB-RULE-CURRENT-001` | 24 V/5 V/3.3 V 与继电器路径按峰值选线宽 | `P = I²R`，连接器与过孔是瓶颈 |
| `PCB-RULE-TESTPOINT-001` | 电源/地/总线/调试口留测试点 | 可测试性决定现场排障与量产良率 |
| `PCB-RULE-PLACE-CONN-001` | 端子靠板边、开口朝外、机械固定 | 振动与插拔应力集中在连接器焊点 |
| `PCB-RULE-RETURN-001` | 高速/敏感信号换层旁补回流地孔 | 参考面不连续时回流绕行，形成共模辐射 |

**依据说明**

- **隔离的物理本质**：隔离不是“画一条线”，而是**切断所有导电通路（含电源、地、信号、铜皮、过孔）**；任何跨带导体都会把隔离阻抗从 GΩ 级降到 kΩ 级，共模电压直接加在收发器上。
- **爬电与间隙的区别**：电气间隙是空气中最短距离（耐压击穿），爬电是沿绝缘表面的最短路径（污染+潮湿漏电）；两者按不同表格计算，不能互相替代。
- **宽温的物理**：电解电容寿命随温度指数下降、晶振负阻裕度随温度下降、半导体 Rdson 随温度上升；这三条决定了工业板必须在“最高环境温度 + 最大负载”下验证，而不是常温通过就算完。

## 可迁移的设计经验

**做对的**

1. 输入保护按“泄放 → 阻断 → 滤波 → 稳压”固定顺序设计，每一级都有明确职责与额定值。
2. 隔离接口用独立隔离电源 + 数字隔离器 + 收发器三件套，两侧地与去耦完全独立。
3. 隔离带在布局阶段就画成禁布区，所有层无铜无过孔，爬电距离按标准表格算而不是凭感觉。
4. 掉电检测 + 保持电容 + 独立看门狗，把“现场断电”当常态设计。

**妥协的**

1. 集成隔离电源的隔离收发器省空间，但隔离等级与输出功率受限，高隔离/大功率场景仍需分立方案。
2. 4 层板在隔离带处必须收边，牺牲了部分地平面连续性；6 层能更好兼顾，但成本更高。
3. 三防漆提升防护，但会污染测试点与连接器，产线需要遮蔽工序，返修也更困难。
4. 宽温器件与固态电容成本显著高于常温方案，低端产品常在温度范围上打折。

**反面教训**

1. 隔离带下方走了地铜或过孔“为了连通”：耐压测试直接击穿，或现场共模干扰下收发器批量损坏（`PCB-FAIL-GND-LOOP`）。
2. 24 V 输入只加 TVS 不加保险丝/反接保护：一次接线错误烧整板，返修成本远超保护器件成本。
3. 隔离器两侧共用一个去耦过孔：共模抑制比骤降，EFT 测试必挂。
4. 常温验证通过就量产：低温 −40 °C 晶振不起振、高温 85 °C 电容鼓包，现场批量返修（`PCB-FAIL-CRYSTAL`、`PCB-FAIL-THERMAL-RUNAWAY`）。

## 评审清单

- [ ] 24 V 输入保护顺序是否为“保险丝 → TVS/压敏 → 反接阻断 → 滤波 → DC-DC”？额定值是否覆盖浪涌？
- [ ] 隔离接口是否有独立隔离电源？隔离等级与数字隔离器/收发器是否匹配？
- [ ] 隔离带是否所有层无铜、无过孔、无丝印跨越？爬电/间隙是否按标准表格计算？
- [ ] 隔离器两侧去耦与地是否完全独立？两侧 GND 是否开路（万用表验证）？
- [ ] RS485/CAN 终端、偏置、TVS、共模电感位置是否正确？总线是否成对无 stub？
- [ ] 24 V DI 是否经限流 + 隔离 + 滤波？阈值与反接保护是否满足标准？
- [ ] 所有器件是否按 −40～85 °C 核对降额曲线（电容/晶振/DC-DC/连接器）？
- [ ] 是否有掉电检测与保持电容？保持时间是否覆盖关键数据保存？
- [ ] 看门狗是否独立、量产使能、喂狗逻辑是否可靠？
- [ ] 分流电阻是否开尔文接法、成对走线、功率降额 1.5～2 倍？
- [ ] 端子/连接器是否靠板边并机械固定？大质量器件是否远离板边/点胶？
- [ ] 三防漆/灌封区域是否标注清楚？测试点与隔离调试口是否预留？
