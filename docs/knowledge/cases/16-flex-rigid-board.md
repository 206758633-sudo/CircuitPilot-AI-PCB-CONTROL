# 案例 16：柔性 / 刚挠结合板 —— 弯折区是“结构件”，不是普通布线区

> **一句话结论**：柔性/刚挠结合板的设计核心只有一句：**把“刚性区、柔性区、过渡区、连接器区”当成四种不同的结构来设计**——弯折区不许有跨弯折线的走线、不许有过孔，覆盖膜与补强要按弯折半径设计；刚性区的贴片与分板应力要隔离；刚挠过渡区的层间结合与开窗是良率杀手。任何“按普通 PCB 画完再折一下”的做法，都会在弯折寿命或装配环节失效。

## 设计原理拆解

以下按“结构分区 → 弯折区设计 → 补强与连接器 → 刚挠过渡 → 覆盖膜/开窗 → 阻抗与信号 → 装配 → 可靠性验证”拆解。所有数值均标注“按材料规格、板厂工艺能力与结构仿真复核”。

**一、结构分区**

### KP-CASE-FLEX-01 先把板分成刚性区、柔性区、过渡区、连接器区，再谈布线

- **判据**：布局前必须画出四类区域并作为布局约束：刚性区（贴片、多层、完整地平面）、柔性区（只走线/覆盖膜，可弯折）、刚挠过渡区（层间结合、禁布/禁过孔）、连接器区（补强、受力）（`PCB-RULE-FPC-001`、`PCB-RULE-PLACE-CONN-001`）。
- **为什么**：四种区域的机械与工艺约束完全不同：刚性区怕弯折、柔性区怕元件与过孔、过渡区怕分层、连接器区怕插拔应力；混在一起设计，等于把四种失效模式同时引入。
- **怎么做**：在结构图上标出分区与弯折线；柔性区只放走线与覆盖膜开窗；过渡区两侧留禁布带；连接器区加补强并远离弯折线；所有分区在丝印/装配图上标注。
- **怎么查**：布局评审逐区检查；3D 装配（含弯折状态）干涉检查；板厂工艺确认（刚挠结合能力、过渡区最小宽度）。

**二、弯折区设计**

### KP-CASE-FLEX-02 弯折区走线必须垂直于弯折线，且禁止跨弯折线换层/打孔

- **判据**：弯折区内走线方向应**垂直于弯折线**（即沿弯折轴的法线方向），不得平行于弯折线长距离走线；弯折区内禁止过孔、禁止跨弯折线换层、禁止元件与补强（`PCB-RULE-FPC-001`）。
- **为什么**：弯折时外层受拉、内层受压，平行于弯折线的长走线会被反复拉伸/压缩，铜箔疲劳断裂；过孔是刚性结构，在弯折区会形成应力集中点，直接从孔壁开裂。
- **怎么做**：弯折区走线垂直穿过，宽度均匀、避免突变；多条线间距均匀，减少应力不均；弯折线两侧留过渡圆弧；必须换层时在弯折区外完成；弯折区铜箔可做网格/多段处理（按板厂建议）。
- **怎么查**：目检/EDA 检查弯折区走线方向与过孔；弯折仿真（有条件）；弯折寿命测试（按角度与次数）；切片看铜箔是否有微裂纹。

### KP-CASE-FLEX-03 弯折半径与板厚/铜厚共同决定寿命，半径不足是断线首因

- **判据**：最小弯折半径按“板厚（含覆盖膜/补强）× 经验系数”设计（常见静态弯折为板厚的数倍、动态弯折更大，**具体系数按材料规格与板厂指南复核**）；弯折次数越多、半径越要放大；动态弯折区铜厚通常选 1/2 oz 或更薄（按板厂能力复核）。
- **为什么**：弯折时外层应变 `ε ≈ t/(2R)`，板厚 t 越大、半径 R 越小，应变越大；铜箔延展有限，超过疲劳极限就断裂。覆盖膜与补强会显著增加局部厚度，让实际半径小于设计值。
- **怎么做**：结构上尽量放大弯折半径；弯折区减薄（薄铜、薄覆盖膜、去掉不必要的补强）；避免在弯折区做“台阶”厚度突变；动态弯折区按板厂推荐的最小半径并留 30% 以上裕量。
- **怎么查**：结构 3D 模拟弯折状态测实际半径；弯折寿命测试（如 1 万～10 万次，按产品要求）；失效分析切片；与板厂确认最小半径能力。

**三、补强与连接器**

### KP-CASE-FLEX-04 补强（stiffener）要覆盖连接器/焊接区，但必须避开弯折区

- **判据**：FPC 连接器、金手指、焊接盘区域必须加补强（PI/FR-4/不锈钢，按受力与焊接工艺选）；补强边缘要留过渡，不得直接落在弯折区；补强与覆盖膜的开窗要匹配（`PCB-RULE-FPC-001`、`PCB-RULE-BOARD2BOARD-001`）。
- **为什么**：FPC 本身柔软，连接器插拔力会让焊盘剥离、金手指磨损；补强提供刚性支撑；但补强边缘是刚度突变点，若落在弯折区，应力集中会直接撕裂。
- **怎么做**：补强覆盖连接器全长并超出 0.5～1 mm（按连接器规格）；补强边缘做斜边/圆角过渡；补强远离弯折线至少一个弯折半径；补强区在装配图上标注厚度与材料。
- **怎么查**：装配图核对补强位置/厚度；插拔力测试；弯折测试后检查补强边缘是否分层；切片看补强与覆盖膜结合。

### KP-CASE-FLEX-05 FPC 连接器：翻盖方向、Pin1 标识、插拔空间三件事缺一不可

- **判据**：连接器选型与布局必须明确翻盖/抽拉方向（装配时能否操作）、Pin1 标识（丝印/开窗）、插拔工具空间；连接器下方/背面不得有弯折或受力结构（`PCB-RULE-FPC-001`、`PCB-RULE-PLACE-CONN-001`）。
- **为什么**：翻盖方向与结构空间冲突时，产线装不进去或强行装配导致翻盖断裂；Pin1 标错会整批反插烧板；插拔空间不足会让返修无法进行。
- **怎么做**：连接器靠板边、开口朝外；Pin1 用丝印三角 + 焊盘 1 方形双重标识；连接器周围留手指/工具空间；加强片（背板）按插拔力设计；必要时用带锁扣的连接器。
- **怎么查**：3D 装配模拟（插拔路径）；首件实插；Pin1 与线序对照检查；插拔寿命测试。

**四、刚挠过渡与覆盖膜**

### KP-CASE-FLEX-06 刚挠过渡区是分层与开路的高发区：禁布、禁孔、留结合宽度

- **判据**：刚性层与柔性层结合的过渡区，两侧要留足够的结合宽度（按板厂能力复核），过渡区内不得有过孔、不得有元件、不得有锐角外形；柔性层在过渡区要平滑过渡，不得有台阶（`PCB-RULE-FPC-001`、`PCB-RULE-ML-WARP-001`）。
- **为什么**：刚挠结合靠胶层/无流动半固化片压合，过渡区是材料与刚度突变处，热应力与机械应力集中；开孔/锐角会成为分层起点，分层后水汽进入导致 CAF 或开路。
- **怎么做**：过渡区画禁布带并在所有层生效；外形用圆弧过渡；压合参数由板厂控制；过渡区避免大面积铜不对称（减少翘曲）；必要时增加结合宽度的“锚定”铜。
- **怎么查**：板厂 DFM 确认过渡区宽度；热循环/湿热测试后切片看分层；外观检查（白斑/气泡）；弯折测试后重点检查过渡区。

### KP-CASE-FLEX-07 覆盖膜（coverlay）开窗要包住焊盘并留工艺余量，不能按阻焊思维设计

- **判据**：覆盖膜开窗应比焊盘单边大（常见 0.1 mm 量级，按板厂能力复核），且开窗边缘不得压在弯折区；覆盖膜与焊盘之间的“搭接”宽度要足够防止起翘；金手指区域按插拔寿命决定是否加硬金/镍厚（`PCB-RULE-MASK-001`、`PCB-RULE-FPC-001`）。
- **为什么**：覆盖膜是贴合上去的 PI 膜，不是印刷阻焊，开窗过小会压不住焊盘边缘、回流时起翘；开窗过大又会让胶层外露、吸潮；覆盖膜在弯折区边缘会起皱剥离。
- **怎么做**：按板厂开窗能力设计（通常比阻焊开窗大）；开窗边缘远离弯折线；金手指做倒角与硬金；需要焊接的焊盘保证覆盖膜“压边”宽度；开窗图形在装配图上标注。
- **怎么查**：板厂 DFM 报告；首件显微镜看覆盖膜压边与起翘；回流焊后检查开窗边缘；插拔/弯折后复查。

**五、阻抗、装配与可靠性**

### KP-CASE-FLEX-08 柔性区的阻抗要按“柔性材料 + 覆盖膜”重新算，不能沿用刚性板参数

- **判据**：需要阻抗控制的柔性走线（如 USB、射频、差分）必须按柔性基材的 Dk/损耗与覆盖膜厚度重新计算线宽/间距（`PCB-RULE-IMPEDANCE-001`、`PCB-RULE-DIFF-001`）；弯折区阻抗会随弯折状态变化，需在“平展态”定义并留公差。
- **为什么**：FPC 常用 PI 基材与胶层，Dk 与刚性 FR-4 不同，覆盖膜也参与介质；直接套用 FR-4 的线宽会让阻抗偏差；弯折时介质厚度变化会进一步改变阻抗。
- **怎么做**：把叠层（含覆盖膜、胶层）交给板厂做阻抗计算；阻抗测试条与产品同叠层同工艺；差分对在柔性区保持等长与对称；弯折区避免阻抗突变（线宽渐变）。
- **怎么查**：板厂阻抗计算单；TDR 测试条；整机信号完整性测试（USB 枚举/眼图，有条件）；弯折前后对比测试。

### KP-CASE-FLEX-09 装配：柔性板要“托着装”，不能悬空受力

- **判据**：贴片/焊接/测试工装必须为柔性区提供支撑（托板/真空吸附/仿形夹具）；回流焊时柔性区不得悬空；分板/裁切不得让柔性区承受拉力；装配后弯折区不得被结构件持续压迫（`PCB-MOD-ASSEMBLY`、`PCB-RULE-PANEL-001`）。
- **为什么**：FPC 刚性差，悬空过回流会因热变形导致贴片偏移/虚焊；工装拉扯会让走线微裂；装配后长期压迫会让弯折区蠕变、寿命骤降。
- **怎么做**：设计专用托盘/载具；在 FPC 上留工艺定位孔（拼板内）；分板用激光/冲切并避开走线；结构上给弯折区留自然弯曲空间（不绷紧、不压死）。
- **怎么查**：首件过炉后偏移/虚焊检查；装配后弯折区应力检查（目检/显微）；整机跌落/振动后功能测试；产线工装评审。

### KP-CASE-FLEX-10 可靠性验证：弯折寿命、湿热、冷热冲击、插拔四类测试缺一不可

- **判据**：柔性/刚挠板必须做四类验证：弯折寿命（按产品实际角度/次数）、湿热（分层/绝缘）、冷热冲击（过渡区/焊点）、连接器插拔寿命；测试后要测导通电阻与绝缘电阻，而不只是“看起来没断”（`PCB-RULE-FPC-001`、`PCB-FAIL-CONNECTOR-STRESS`）。
- **为什么**：柔性板的失效多是渐进式的——铜箔微裂、分层吸潮、焊点疲劳，功能测试可能仍通过，但寿命已大幅缩短；只有按标准做加速试验并测参数漂移，才能暴露问题。
- **怎么做**：按产品使用场景定义弯折角度/次数（静态安装 vs 动态频繁弯折）；湿热按温湿度等级；冷热冲击按温度范围与循环数；插拔按连接器额定次数；测试前后测导通电阻、绝缘电阻、外观。
- **怎么查**：第三方或自建可靠性报告；失效分析（切片/显微）；与竞品/标准对比；把测试结果回写到设计规则。

## 规则依据

| 规则 ID | 本案例对应做法 | 物理/标准依据 |
|---|---|---|
| `PCB-RULE-FPC-001` | 弯折区走线垂直弯折线、禁过孔、补强避开弯折、覆盖膜开窗压边 | 弯折应变 `ε ≈ t/(2R)`；过孔与补强是刚度突变点 |
| `PCB-RULE-PLACE-CONN-001` | 连接器靠板边、开口朝外、补强固定 | 插拔力集中在焊点，需刚性支撑与操作空间 |
| `PCB-RULE-BOARD2BOARD-001` | 板间/FPC 连接器交叉线序 + 防呆 | 反插会烧板；防呆降低装配错误 |
| `PCB-RULE-MASK-001` | 覆盖膜开窗按板厂能力放大 | 覆盖膜是贴合膜，开窗过小会起翘 |
| `PCB-RULE-IMPEDANCE-001` | 柔性区阻抗按柔性材料 + 覆盖膜重算 | Dk/介质厚度与 FR-4 不同，套用会失配 |
| `PCB-RULE-DIFF-001` | 差分对在柔性区保持等长、对称、线宽渐变 | 失配产生共模转换，弯折区突变加剧反射 |
| `PCB-RULE-ML-WARP-001` | 过渡区铜对称、压合参数受控 | 材料/刚度不对称导致翘曲与分层 |
| `PCB-RULE-EDGE-001` | 柔性区外形圆弧过渡、远离板边禁布 | 锐角外形是撕裂与分层起点 |
| `PCB-RULE-PANEL-001` | 拼板留工艺边、分板避开走线 | 分板应力导致柔性区微裂 |
| `PCB-RULE-THERMAL-001` | 刚性区功率器件散热按常规；柔性区不承载热源 | 柔性材料耐温与导热低于 FR-4 |
| `PCB-RULE-TESTPOINT-001` | 关键网络留测试点（避开弯折区） | 可测试性决定量产良率与返修 |

**依据说明**

- **弯折应变的物理**：板厚 t、弯折半径 R 决定外层应变 `ε ≈ t/(2R)`；铜箔疲劳寿命随应变指数下降，所以“减薄 + 放大半径”是最有效的两个手段。
- **为什么弯折区禁过孔**：过孔是镀铜的刚性筒，弯折时孔壁与铜箔交界处应力集中，微裂纹从孔壁开始扩展，最终开路。
- **刚挠过渡的分层机理**：不同材料的热膨胀系数与吸湿膨胀不同，过渡区是界面，温湿循环下界面应力最大；结合宽度不足或存在锐角/开孔时，分层从界面缺陷处开始。

## 可迁移的设计经验

**做对的**

1. 布局前先分四区（刚性/柔性/过渡/连接器），每区按各自的机械约束设计，而不是一张图统一处理。
2. 弯折区只走垂直弯折线的均匀走线，禁过孔、禁元件、禁补强，把疲劳源降到最低。
3. 连接器区加补强并留操作空间，Pin1 双重标识，装配与返修都省事。
4. 可靠性验证同时测“功能”和“参数漂移”（导通电阻/绝缘电阻），能提前发现渐进失效。

**妥协的**

1. 柔性区用薄铜（如 1/2 oz）提升弯折寿命，但载流与阻抗设计余量变小，大电流要另走刚性区。
2. 刚挠结合减少连接器与装配工序，但工艺复杂、良率与成本高于“FPC + 连接器”方案。
3. 补强提升连接器可靠性，但增加厚度与刚度突变，弯折半径必须相应放大。
4. 覆盖膜开窗按板厂能力放大，牺牲部分密度换可制造性。

**反面教训**

1. 弯折区走线与弯折线平行：样机通过、量产弯折几千次后批量断线（`PCB-FAIL-COLD-JOINT` 类渐进失效）。
2. 弯折区打过孔“为了换层”：孔壁开裂，表现为“弯到某个角度就断”，极难定位。
3. 补强边缘正好落在弯折线上：应力集中，弯折几次就分层撕裂。
4. 柔性区沿用 FR-4 阻抗参数：USB 枚举不稳、射频指标不达标，误判为芯片问题。

## 评审清单

- [ ] 刚性区/柔性区/过渡区/连接器区是否已分区并在所有层生效？
- [ ] 弯折区走线是否垂直弯折线？是否无过孔、无元件、无补强？
- [ ] 最小弯折半径是否按板厚/覆盖膜/补强核算并留 ≥30% 裕量？
- [ ] 补强是否覆盖连接器/焊接区且避开弯折区？边缘是否做过渡？
- [ ] FPC 连接器翻盖方向、Pin1 标识、插拔空间是否与结构匹配？
- [ ] 刚挠过渡区是否禁布禁孔、外形圆弧、结合宽度足够？
- [ ] 覆盖膜开窗是否包住焊盘并留压边？是否远离弯折区？
- [ ] 柔性区阻抗是否按柔性材料 + 覆盖膜重新计算并做测试条？
- [ ] 装配工装是否支撑柔性区？回流/分板/装配是否避免拉扯弯折区？
- [ ] 是否做了弯折寿命、湿热、冷热冲击、插拔四类验证并测参数漂移？
- [ ] 拼板与分板是否避开走线？工艺边是否够宽？
- [ ] 关键网络测试点是否避开弯折区并可按探针测试？
