# 案例 06：同步 Buck 电源参考布局 —— 先管“热环路”，再谈纹波与效率

> **一句话结论**：同步 Buck 的布局有且只有一条主线——**把“输入电容—高侧开关—低侧开关—PGND”这个脉冲电流环路压到最小**；环路定了，再按“SW 节点最小、电感紧靠、反馈 Kelvin、地平面完整、散热过孔到位”的顺序收尾。功率级参数（频率/电感/输出电容）是布局的前置约束，布局只能优化寄生，不能弥补选型错误。

## 设计原理拆解

以下按“电源树/功率级 → 上电时序与使能 → 接口与保护 → 去耦与地 → EMC/ESD → 热与 DFM”拆解。所有具体面积、距离、频率、纹波比例为工程门禁参考值，**按具体 app note 与 datasheet 复核**。

**功率级与电源树**

### KP-CASE-BUCK-01 热环路（hot loop）面积是布局第一优先级

- **判据**：输入电容—高侧开关—低侧开关—PGND 围成的脉冲电流环路面积最小（常见工程门禁 ≤25 mm²，推荐 ≤15 mm²，按 app note 复核）；输入电容到 VIN/PGND 引脚 ≤2～3 mm。
- **为什么**：Buck 的脉冲电流只在输入电容与开关之间流动，环路面积决定寄生电感与辐射；寄生电感与 di/dt 产生振铃/电压尖峰，抬高开关损耗与 EMI。
- **怎么做**：输入电容与 VIN/PGND 同侧紧贴；电容两端各自打过孔到平面；高/低侧开关与电容围成紧凑“口”字形；环路内不放无关过孔/测试点。
- **怎么查**：量环路面积与电容到引脚距离；SW 波形振铃频率/幅度；近场探头扫辐射；不通过 → 重排输入电容/改布局。

### KP-CASE-BUCK-02 输入电容：VIN 与 PGND 成对、就近、并联多颗

- **判据**：每个高侧开关的 VIN–PGND 对都要有就近陶瓷电容；大容量体电容可稍远但必须低 ESL 连接；输入电容按纹波电流有效值与电压降额选（`PCB-RULE-DECOUPLE-001`、`PCB-RULE-DECOUPLE-002` 的电源版）。
- **为什么**：输入电容承担开关脉冲电流，纹波电流有效值大；单颗容值/ESL 不足会过热或滤波不够；距离远则高频去耦失效。
- **怎么做**：小电容（高频）最近、大电容稍远；同侧摆放；焊盘直接连平面；按 datasheet 算输入纹波电流 RMS；X5R/X7R 注意直流偏压降容（`PCB-FAIL-DC-BIAS`）。
- **怎么查**：输入纹波电压（20 MHz 带宽、短地）；电容温升；容值降额核算；不通过 → 加电容/改封装/改布局。

### KP-CASE-BUCK-03 SW 节点：面积最小、载流够、不引长线

- **判据**：SW 铜皮在满足载流/散热前提下尽量小；SW 节点不作为信号参考、不走长引线；测试点用短针或小焊盘（`PCB-RULE-CURRENT-001`、`PCB-RULE-CLEARANCE-001`）。
- **为什么**：SW 是高 dv/dt 节点，铜皮越大对周围耦合越强（容性耦合），是主要辐射源；同时 SW 也是高 di/dt 路径的一部分。
- **怎么做**：电感紧邻开关；SW 铜皮短而宽；不在 SW 下方/旁边走 FB/COMP/EN；SW 测试点小而短；必要时加 RC snubber（按 app note）。
- **怎么查**：SW 波形上升沿/振铃；近场扫描热点；FB 波形是否有 SW 耦合；不通过 → 缩铜/改层/加 snubber。

### KP-CASE-BUCK-04 电感：紧靠 SW、下方净空、按饱和/温升选

- **判据**：电感一端紧邻 SW 节点、另一端紧邻输出电容；电感焊盘短；电感下方与周边不走敏感线；电感额定电流 ≥ 最大负载 + 纹波峰值，饱和电流留裕量（按 datasheet 复核）。
- **为什么**：电感与 SW 之间走线是 di/dt 路径，长走线增加寄生电感与辐射；电感漏磁会耦合进 FB/COMP。
- **怎么做**：电感放开关与输出电容之间；屏蔽电感优先；FB/COMP 远离电感（≥2 mm）且不穿电感下方；功率电感下方铺铜需评估涡流损耗（按 app note）。
- **怎么查**：电感电流波形（饱和/温升）；FB 噪声；热像仪；不通过 → 换电感/改布局。

### KP-CASE-BUCK-05 布局前置约束：开关频率、电感、输出电容必须先定

- **判据**：开关频率、电感值（纹波电流比常见 20%～40%，按 app note）、输出电容（纹波/瞬态）必须在布局前定；最小导通/关断时间限制决定占空比范围（按 datasheet 复核）。
- **为什么**：布局只能优化寄生，不能改变功率级设计；频率越高电感越小但开关损耗/EMI 越大；占空比极限会导致跳周期/失稳。
- **怎么做**：先做功率级计算（纹波、RMS、损耗、`Tj`），再选封装与布局；高频率时注意最小 on-time；输入/输出电容按 RMS 与瞬态选。
- **怎么查**：计算书与实测对比（纹波/效率/温升）；极限占空比测试；不通过 → 改频率/改电感。

**上电时序与使能（时钟与复位：本案例为电源板，无独立时钟域，以开关频率、使能与软启动替代）**

### KP-CASE-BUCK-06 使能/软启动/频率设置：小信号要有确定电平且靠近芯片

- **判据**：EN 分压/RC 有确定默认态（不得悬空）、SS 电容靠近引脚、RT/FS 电阻靠近芯片；上电时序保证 VIN 稳定后再使能（`SCH-MOD-BUCK`）。
- **为什么**：EN 悬空会随机启停；软启动电容离得远会引入噪声导致启动波形异常；频率设置电阻被耦合会让开关频率抖动。
- **怎么做**：EN 分压靠近芯片并加小电容；SS 电容紧贴引脚；RT/FS 电阻靠近并包地；PGOOD 上拉；上电顺序由 VIN/EN 的 RC 或 PG 控制。
- **怎么查**：上电启动波形（软启动时间、过冲）；EN 电平；开关频率实测；不通过 → 改 RC/改布局。

**接口与保护**

### KP-CASE-BUCK-07 保护与接口：OCP/OVP/UVLO 与 PGOOD 的布局同样影响可靠性

- **判据**：电流采样（ sense 电阻/DCR/内部）走线 Kelvin、短；OVP/UVLO 分压靠近芯片；PGOOD 上拉且不被 SW 耦合；保护阈值按 datasheet 与最坏工况核算。
- **为什么**：电流采样走线有寄生电阻/电感会改变限流点；分压被 SW 耦合会让保护误动作；PGOOD 误触发会让系统反复重启。
- **怎么做**：sense 走线从采样点内侧引出、成对等长；OVP/UVLO 分压靠近芯片并加小电容；PGOOD 上拉并远离 SW；必要时加 RC 滤波。
- **怎么查**：限流点实测（电子负载短路/过流）；OVP/UVLO 阈值实测；PGOOD 波形；不通过 → 改采样/改滤波/改布局。

### KP-CASE-BUCK-08 输出电容与反馈取样：Kelvin 从输出电容之后取

- **判据**：输出电容紧贴电感输出与 PGND；FB 分压取样点在输出电容之后（Kelvin），不在电感/走线中间；FB 走线细、短、包地、远离 SW/电感。
- **为什么**：取样点若在电感后但输出电容前，会把电感/走线压降算进去；FB 被 SW 耦合会改变占空比 → 输出纹波/抖动。
- **怎么做**：输出电容先放，再从电容焊盘/铜皮取 FB；分压电阻靠近 FB 脚；FB 线不跨 SW；补偿网络靠近芯片。
- **怎么查**：空载/满载输出电压精度；负载瞬态；FB 波形噪声；不通过 → 改取样点/改布线。

**去耦与地**

### KP-CASE-BUCK-09 地：PGND 与 AGND 单点连接，内层地完整

- **判据**：功率地（输入电容/低侧开关/输出电容）与信号地（FB/COMP/控制）在芯片 AGND/PGND 处单点连接；内层地平面完整、不被分割缝切断；功率地过孔阵列（`PCB-RULE-STACKUP-001`、`PCB-RULE-RETURN-001`）。
- **为什么**：功率地有大脉冲电流，若与小信号地共享长路径，地弹会叠加到 FB 参考上；单点连接给噪声电流指定路径。
- **怎么做**：四层板 L2 完整 GND；PGND 用大面积铜 + 过孔；AGND 单独铺铜后单点接 PGND；不要在两地域之间开长缝。
- **怎么查**：地连通性/单点位置；FB 参考地噪声；负载瞬态；不通过 → 改地/改层。

### KP-CASE-BUCK-10 自举与 VCC：短回路、就近去耦

- **判据**：BOOT 电容回路（SW → Cboot → BOOT 引脚）面积最小；VCC/VDD 去耦电容靠近引脚；自举二极管（若有）靠近（`PCB-RULE-DECOUPLE-001`）。
- **为什么**：自举电容给高侧驱动提供瞬态电流，回路长会抬高高侧驱动电压跌落与开关损耗；VCC 噪声会导致驱动异常。
- **怎么做**：Cboot 紧贴 BOOT–SW 引脚；VCC 电容就近；自举走线短；避免与 SW 大铜皮重叠。
- **怎么查**：高侧驱动波形（Vgs）；BOOT 电压；不通过 → 改布局/加电容。

**EMC/ESD**

### KP-CASE-BUCK-11 开关电源的 EMC：源头（dv/dt、di/dt、环路）+ 传播路径一起管

- **判据**：先压热环路面积与 SW 铜皮，再按需加输入滤波/RC snubber/屏蔽；输入线缆侧加共模/差模滤波；频率与边沿速率按效率-EMI 折中（按 app note 与标准复核）。
- **为什么**：Buck 的辐射主要来自热环路与 SW 节点（近场），传导主要沿输入线；只加滤波不治源头会“成本高、效果差”。
- **怎么做**：输入电容就近、SW 最小；必要时 RC snubber（损耗换 EMI）；输入 π 型滤波；电感屏蔽；布局上让 SW/电感远离接口与敏感线。
- **怎么查**：近场探头定位热点；传导/辐射预测试（按 CISPR/FCC 等标准）；不通过 → 改源头/改滤波。

**热与 DFM**

### KP-CASE-BUCK-12 散热：EPAD 过孔阵列 + 铜面积 + 热焊盘

- **判据**：QFN/DFN 散热焊盘下 0.3 mm 过孔阵列（间距 1.0～1.2 mm、盖油塞孔），连到内层/底层大面积地铜；铜面积与过孔数按功耗/温升预算（`PCB-RULE-THERMAL-001`）。
- **为什么**：同步 Buck 的损耗集中在开关管/驱动，EPAD 是主要散热路径；过孔少/铜小 → θja 高 → 结温超限。
- **怎么做**：按 datasheet θja/θjc 估算；EPAD 打孔阵列；多面铺铜；热焊盘连接（热 relief 按需）；过孔塞孔防漏锡。
- **怎么查**：满载热像仪；`Tj` 估算；不通过 → 加铜/加过孔/改器件。

## 规则依据

| 规则 ID | 本案例对应做法 | 物理/标准依据 |
|---|---|---|
| `PCB-RULE-DECOUPLE-001` | 输入电容/VCC/BOOT 电容就近、过孔直连 | 高频去耦靠安装电感，环路越小阻抗越低 |
| `PCB-RULE-DECOUPLE-002` | 大电容 + 小电容按约 10× 间隔组合 | 覆盖频段并抑制并联反谐振峰 |
| `PCB-RULE-RETURN-001` | 功率地/信号地单点、换层补回流地孔 | 回流走最低电感路径，环路面积决定辐射 |
| `PCB-RULE-STACKUP-001` | 四层 SIG-GND-PWR-SIG，内层地完整 | 完整参考面是低阻抗回流与屏蔽的前提 |
| `PCB-RULE-THERMAL-001` | EPAD 过孔阵列 + 大面积铜 | `Tj = Ta + θja·P`，过孔/铜面积降低 θja |
| `PCB-RULE-CURRENT-001` | VIN/SW/电感/输出按最大电流选线宽与铜厚 | IPC-2152 载流与温升；压降影响效率与反馈精度 |
| `PCB-RULE-CLEARANCE-001` | SW 与低压信号间距、爬电按工作电压 | 高 dv/dt 节点需要足够间距降低耦合/击穿风险 |
| `PCB-RULE-MEASURE-001` | 输入/输出纹波与 SW 波形测量 | 20 MHz 带宽限制 + 短地回路，测点在负载端 |
| `PCB-RULE-COPPER-001` | 大面积铜/热焊盘平衡，避免孤岛 | 铜分布不均导致板翘/蚀刻与焊接问题 |

**依据说明**

- **热环路与寄生电感**：`V_spike ≈ L_loop × di/dt`，同步 Buck 的 di/dt 可达数 A/ns 量级；环路电感每增加 1 nH，尖峰与振铃就明显上升，因此“面积最小”优先于“摆得整齐”。
- **SW 铜皮的两难**：铜皮大→载流/散热好，但对周围容性耦合强；正确做法是“够用即止”，把大面积铜留给地/电源平面。
- **反馈取样**：FB 是高阻小信号，取样点位置决定“测的是输出电压还是电感后电压”；Kelvin 取样把走线压降排除在环路外。
- **地弹**：功率地与信号地共享阻抗时，开关电流在地阻抗上产生的压降会叠加到 FB 参考，表现为输出纹波/抖动，严重时失稳。

## 可迁移的设计经验

**做对的**

1. 先定功率级参数，再画布局：频率、电感、输出电容、电流路径都先算清楚。
2. 输入电容与开关围成最小“口”字，功率地与信号地单点，FB 从输出电容后 Kelvin 取。
3. SW 铜皮“够流即止”，FB/COMP 全部远离 SW/电感，并包地。
4. 散热焊盘按过孔阵列 + 多面铺铜做，热像仪验收。

**妥协的**

1. 2 层板成本低，但缺少完整地平面，热环路与回流只能靠铺铜优化，EMC 余量小；高功率/高频率建议 4 层。
2. 为省面积把多个容值合并成一颗大电容，会牺牲高频去耦与纹波电流分担。
3. 高开关频率缩小电感/电容体积，但开关损耗与 EMI 上升，需要 snubber/屏蔽等额外成本。

**反面教训**

1. 输入电容只放在连接器/板边，热环路被拉长 → SW 振铃大、辐射超标、效率下降。
2. FB 从电感后/走线中间取样，或 FB 线贴着电感走 → 输出精度差、负载瞬态抖动。
3. 只追求“能出电压”，不测 SW 振铃/纹波/效率 → 量产出现随机复位、EMI 认证失败。
4. 散热焊盘过孔不足、铜皮被分割 → 满载结温超限、触发 OTP 降档。

## 评审清单

- [ ] 输入电容是否紧邻 VIN/PGND，热环路面积是否量测并达标？
- [ ] 输入电容是否按纹波电流 RMS 与直流偏压降容选型？
- [ ] SW 铜皮是否“载流够、面积小”，且未走长引线/未与 FB 并行？
- [ ] 电感是否紧靠 SW 与输出电容，下方/周边是否净空？
- [ ] 输出电容是否紧贴电感输出与 PGND？
- [ ] FB 是否从输出电容之后 Kelvin 取样，走线短、包地、远离 SW/电感？
- [ ] PGND 与 AGND 是否单点连接，内层地是否完整？
- [ ] 自举电容/VCC 去耦回路是否最小？
- [ ] 电流采样/OVP/UVLO 分压是否靠近芯片并远离 SW？
- [ ] EPAD 过孔阵列、铜面积是否按功耗预算并塞孔？
- [ ] 是否实测 SW 波形、输入/输出纹波、效率曲线与近场 EMI？
- [ ] 频率/电感/输出电容的计算书是否与实测一致并留档？
