# 案例 14：AC-DC / 适配器 —— 安规是设计输入，隔离带与热环路是两条命门

> **一句话结论**：AC-DC 板的第一原则是**安规在画第一根线之前就已经决定**——绝缘等级、污染等级、海拔、过压类别决定爬电/电气间隙与隔离带宽度；第二原则是**初级热环路（输入电容—开关管—变压器）面积决定 EMI 与效率**。这两件事做错，后面用再好的芯片、再多的滤波也补不回来；而且它们是**认证与人身安全**问题，不是“性能优化”问题。本案例只讨论设计原理与规则依据，具体安规数值必须由具备资质的工程师按标准版本与认证机构要求确定。

## 设计原理拆解

以下按“安规输入 → 隔离带 → 输入保护与 EMI 滤波 → 初级热环路 → 变压器与反馈 → 次级与输出 → 热 → 验证与 DFM”拆解。所有安规数值均标注“按标准版本、污染等级与认证机构要求查表复核”，本文不给“保证通过”的具体毫米数。

**一、安规是设计输入**

### KP-CASE-ACDC-01 先定绝缘等级/污染等级/海拔/过压类别，再谈间距与器件

- **判据**：设计开始前必须明确：输入电压范围、过压类别（OVC）、污染等级（常见 2 级）、海拔、绝缘类型（基本/附加/加强/双重）、工作环境；这些参数直接决定爬电距离、电气间隙、Y 电容容值上限与隔离耐压等级（`PCB-RULE-CREEPAGE-001`、`PCB-RULE-CLEARANCE-001`）。
- **为什么**：安规距离不是“经验值”，而是标准按上述参数查表得出的**下限**；同一块板在 2000 m 与 5000 m 海拔、污染等级 1 与 2 下的要求不同；先画板再补距离，往往要改板框、重做变压器。
- **怎么做**：列出“安规输入表”（电压/OVC/污染等级/海拔/绝缘类型）；按目标标准（如 IEC 62368-1，按产品类别选择）查爬电/间隙表；把结果写成布局约束（隔离带宽度、开槽位置、Y 电容容值上限）；与认证机构/安规工程师预沟通。
- **怎么查**：安规输入表评审；按表逐项量爬电/间隙；耐压与绝缘电阻测试；预测试（第三方实验室）后再定型。

### KP-CASE-ACDC-02 隔离带是物理结构：所有层无铜、无过孔、必要时开槽，且宽度按查表值

- **判据**：初级-次级隔离带下方所有层不得有铜、不得有过孔、不得有丝印跨越；隔离带宽度按查表爬电距离 + 裕量；需要更高爬电时开槽；变压器/光耦/隔离电容等跨带器件本体是唯一的合法跨越点（`PCB-RULE-ISO-001`、`PCB-RULE-CREEPAGE-001`）。
- **为什么**：隔离带被铜或过孔跨越时，实际爬电距离被短路，耐压测试会击穿；潮湿与污染会在表面形成漏电通路，开槽能显著增加表面路径；这是“人身安全”级别的约束，不是 EMC 优化项。
- **怎么做**：布局阶段把隔离带画成所有层禁布区；跨带只允许变压器/光耦/隔离器件；隔离带两侧铜皮各自收边并留裕量；需要时开槽（槽宽与位置按板厂能力与标准）；丝印标“高压危险/隔离区”。
- **怎么查**：逐层检查隔离带无铜无过孔；量爬电/间隙；耐压测试（按绝缘等级）；湿热后绝缘电阻复测。

### KP-CASE-ACDC-03 Y 电容是“共模回流通道”，容值受安规漏电流限制

- **判据**：Y 电容跨接初级-次级（或初级-地），为共模电流提供低阻抗回流路径；容值必须在安规漏电流限值内（按标准与产品类别查表复核），且耐压等级满足隔离要求（`PCB-RULE-CREEPAGE-001`、`PCB-MOD-EMC`）。
- **为什么**：没有 Y 电容时共模电流只能走空间/线缆，辐射与传导超标；Y 电容太大则漏电流超标（触及电流安全），太小则 EMC 压不住；Y 电容失效短路会破坏隔离，所以必须用符合安规认证的 Y 类器件。
- **怎么做**：按漏电流预算选容值；Y 电容靠近变压器/隔离带放置，引脚短；地端连接到初级地或次级地按拓扑定；使用有认证的 Y 电容（X1/Y1/Y2 按位置）；必要时用两颗串联提高可靠性（按标准允许）。
- **怎么查**：漏电流测试（按标准限值）；传导/辐射 EMI 测试对比有无 Y 电容；Y 电容认证证书核对；耐压测试。

**二、输入保护与 EMI 滤波**

### KP-CASE-ACDC-04 输入保护顺序：保险丝 → 压敏/NTC → X 电容/共模 → 整流

- **判据**：AC 输入端按“保险丝（分断能力覆盖短路电流）→ 压敏电阻（浪涌钳位）→ NTC/继电器（涌流限制，若需要）→ X 电容 + 共模电感 → 整流桥”布置；放电电阻并在 X 电容两端，保证拔插头后插头不带电（`PCB-RULE-ESD-001`、`PCB-RULE-POWERMUX-001`）。
- **为什么**：保险丝必须能承受正常涌流但能在短路时分断；压敏吸收浪涌；X 电容抑制差模；放电电阻保证安全（拔插头后 X 电容残压会在插头引脚上电人）；顺序反了会让浪涌先到整流桥。
- **怎么做**：保险丝按额定电流与分断能力选；压敏电压按输入上限选；X 电容 + 放电电阻配套（时间常数按安规要求复核）；NTC 热态电阻要小（减少正常工作损耗），冷态要大（限制涌流）；必要时用继电器/可控硅旁路 NTC。
- **怎么查**：涌流测试（冷启动峰值）；短路分断测试（按保险丝规格）；拔插头后插头电压衰减时间测试；浪涌测试。

### KP-CASE-ACDC-05 初级热环路（输入电容—开关管—变压器）面积决定 EMI 与效率

- **判据**：初级脉冲电流环路（输入电解电容 → 变压器初级 → 开关管 → 采样电阻/地 → 回到电容）必须面积最小；输入电容紧贴变压器与开关管，开关管与变压器引脚距离最短；采样电阻用地就近（`PCB-RULE-ESD-001` 不适用，按 `PCB-MOD-EMC` 与热环路原则执行）。
- **为什么**：该环路承载高 di/dt 脉冲电流，环路面积越大，寄生电感越大，开关瞬间的电压尖峰与辐射越强；同时环路电感会降低效率、增加开关管应力。
- **怎么做**：输入电容与变压器/开关管同侧紧贴；功率走线短而宽；采样电阻与开关管源极之间的地回路最短；避免在热环路内放过孔与细线；散热片与开关管漏极的寄生电容也要评估。
- **怎么查**：目检热环路面积；开关管漏极电压波形（尖峰/振铃）；传导/辐射 EMI 预扫；效率与温升测试。

**三、变压器、反馈与次级**

### KP-CASE-ACDC-06 变压器/光耦/隔离反馈是隔离带的“合法跨越点”，但周边布线仍要守距离

- **判据**：跨隔离带的器件（变压器、光耦、隔离放大器）本体可跨越，但其焊盘、引脚、周边铜皮仍必须满足爬电/间隙；光耦下方的隔离带不得被铜填充；反馈走线不得绕行跨越隔离带（`PCB-RULE-ISO-001`、`PCB-RULE-CREEPAGE-001`）。
- **为什么**：器件本体有认证的绝缘距离，但 PCB 上的焊盘间距、助焊剂残留、污染物会降低实际绝缘；反馈线若绕到隔离带另一侧，等于制造了第二条耦合路径。
- **怎么做**：光耦/变压器下方开隔离槽或保持无铜；跨带器件焊盘之间留足距离；反馈网络全部放在次级侧；Y 电容靠近跨带点；必要时在跨带器件下方开槽。
- **怎么查**：逐层检查跨带器件周边铜皮与间距；耐压测试；湿热后绝缘电阻；EMI 测试确认无额外耦合路径。

### KP-CASE-ACDC-07 次级整流与输出电容：环路要小，纹波与寿命要一起算

- **判据**：次级整流管/同步整流 → 输出电容 → 负载的环路面积最小；输出电容按纹波电流与寿命选型（电解电容按温度/纹波降额，固态/陶瓷按直流偏压降容）；反馈取样点在输出电容之后（`PCB-RULE-FEEDBACK-001`、`PCB-RULE-DECOUPLE-002`）。
- **为什么**：次级同样有高 di/dt 环路；输出电容纹波电流过大会发热、寿命骤降；取样点在电容之前会把纹波与压降算进反馈，导致输出偏差。
- **怎么做**：同步整流管与输出电容紧贴；输出电容多颗并联降低 ESR/纹波电流；反馈分压从最后一级输出电容之后取；避免在输出路径上放长细线。
- **怎么查**：输出纹波测试（带宽按规格）；满载纹波电流与电容温升；负载瞬态响应；反馈点电压与输出端电压对比。

**四、热、验证与 DFM**

### KP-CASE-ACDC-08 热：效率与损耗分布决定散热结构，电解电容是寿命短板

- **判据**：按 `Tj = Ta + P×θJA` 估算开关管、整流管、变压器、输出电容的温度（`PCB-RULE-THERMAL-001`）；电解电容按“温度每升 10 °C 寿命减半”量级降额；满载 + 最高环境温度是最恶劣工况。
- **为什么**：适配器常封闭无风扇，热只能靠外壳与铜皮传导；开关管与变压器是主要热源，电解电容紧邻热源时寿命骤降；温度还会改变变压器饱和点与开关损耗。
- **怎么做**：发热件分散、远离电解电容；开关管/整流管用铜皮 + 过孔/散热片；变压器按温升选磁芯与线径；电解电容选高耐温/长寿命系列并留纹波余量；必要时灌封导热。
- **怎么查**：满载 + 最高环境温度连续跑 1 h，测关键器件温度；高温老化；电解电容纹波电流与温升核对；`Tj` 余量建议 ≥20 °C。

### KP-CASE-ACDC-09 高压测量与安规验证：耐压、绝缘电阻、爬电、漏电流四件套

- **判据**：必须做耐压（Hi-pot，按绝缘等级与标准）、绝缘电阻、爬电/间隙实测、漏电流测试；测量时注意高压探头/隔离、放电与安全距离；所有验证记录归档（`PCB-RULE-MEASURE-001`、`PCB-RULE-DRC-001`）。
- **为什么**：安规是“通过/不通过”的硬门槛，不能靠设计推断；耐压测试能暴露隔离带缺陷，绝缘电阻能暴露污染/吸潮，漏电流关系到人身安全。
- **怎么做**：按标准设定测试电压/时间/判据；测试前放电；用合适的耐压仪与限流；记录环境湿度与温度；失败项定位到隔离带/器件/污染；整改后复测。
- **怎么查**：第三方实验室报告；自建预测试对比；湿热/老化后复测；把失败案例回写到布局规则。

### KP-CASE-ACDC-10 DFM 与认证标识：高压区丝印、开槽、三防与安全标识

- **判据**：高压区在丝印上明确标识（高压危险、隔离区）；开槽/铣空按板厂能力设计；三防漆覆盖高压区但避开连接器/测试点；认证标识（输入范围、极性、认证号）与丝印内容按认证要求（`PCB-RULE-SILK-001`、`PCB-RULE-EDGE-001`、`PCB-RULE-GERBER-001`）。
- **为什么**：产线与维修人员需要明确的危险标识；开槽位置错误会削弱板强或违反安规；三防漆涂到连接器会造成接触不良；认证标识缺失会导致认证不通过。
- **怎么做**：高压区丝印加边框与警示；开槽位置在装配图标注；三防漆区域出遮蔽图；丝印内容（型号、输入、认证号）按认证文件；拼板与分板避开隔离带。
- **怎么查**：丝印与装配图核对；板厂 DFM 报告；认证样机检查；产线三防漆遮蔽验证。

## 规则依据

| 规则 ID | 本案例对应做法 | 物理/标准依据 |
|---|---|---|
| `PCB-RULE-CREEPAGE-001` | 隔离带宽度、Y 电容容值、爬电距离按标准查表 | 污染+潮湿下表面漏电；安规按电压/污染等级/海拔计算 |
| `PCB-RULE-CLEARANCE-001` | 初级高压区电气间隙按电压分级 | 空气击穿与电压/距离相关 |
| `PCB-RULE-ISO-001` | 隔离带无铜无过孔、跨带仅限变压器/光耦 | 隔离靠物理断开；任何跨带导体短路隔离 |
| `PCB-RULE-ESD-001` | 输入端压敏/TVS 位置与地回路 | 浪涌/ESD 能量必须在入口泄放 |
| `PCB-RULE-POWERMUX-001` | 输入保护与放电路径的先后与互锁 | 无放电路径时 X 电容残压危及人身 |
| `PCB-RULE-FEEDBACK-001` | 反馈取样在输出电容之后 | 取样点位置决定环路稳压精度 |
| `PCB-RULE-DECOUPLE-002` | 输出电容组合与纹波电流分配 | 容值/ESR 组合决定纹波与寿命 |
| `PCB-RULE-THERMAL-001` | 开关管/整流管散热铜皮与过孔 | `Tj = Ta + P×θJA`；封闭外壳 θJA 更差 |
| `PCB-RULE-CURRENT-001` | 初级/次级大电流路径线宽与铜厚 | `P = I²R`；热环路载流决定温升 |
| `PCB-RULE-MEASURE-001` | 纹波/高压测量方法与安全 | 测量方法错误会低估纹波或危及安全 |
| `PCB-RULE-SILK-001` | 高压区警示丝印、极性/认证标识 | 安全标识与可维修性要求 |
| `PCB-RULE-GERBER-001` | 开槽/三防/拼板信息随制造文件交付 | 制造信息缺失导致工艺错误 |

**依据说明**

- **安规距离的两个概念**：电气间隙（air clearance）防空气击穿，爬电距离（creepage）防沿面漏电；两者按不同表格计算，开槽只增加爬电、不改变电气间隙，不能互相替代。
- **热环路的物理**：`V = L·di/dt`，环路面积越大寄生电感越大，开关瞬间尖峰越高、辐射越强；这也是为什么“输入电容必须紧贴开关管与变压器”。
- **Y 电容的双面性**：它是共模回流通道（利好 EMC），也是漏电流来源（利空安全）；容值必须在“EMC 够用”与“漏电流合规”之间取交集，并由认证确认。

## 可迁移的设计经验

**做对的**

1. 先做“安规输入表”再画板：绝缘等级/污染等级/海拔/OVC 决定隔离带与间距，避免后期改板。
2. 隔离带在所有层禁铜禁孔，跨带只允许变压器/光耦，Y 电容靠近跨带点。
3. 初级热环路面积最小化：输入电容紧贴变压器与开关管，采样电阻地回路最短。
4. 输出电容按纹波电流与寿命选型，反馈取样在输出电容之后。

**妥协的**

1. 宽压输入（85～264 V）覆盖全球电网，但低压满载时输入电流大、效率与热设计更苛刻。
2. 封闭无风扇适配器靠外壳散热，功率密度受限于散热能力。
3. 成本优先时用非同步整流，效率低几个点、热更集中。
4. Y 电容容值受漏电流限制，EMC 与安全只能取交集，不能各自最优。

**反面教训**

1. 隔离带下走了地铜“为了连通”：耐压测试击穿，或认证直接不通过（人身安全级问题）。
2. 输入电容离开关管太远：开关尖峰高、EMI 超标、开关管应力大（`PCB-FAIL-EMI-FAIL`）。
3. X 电容没有放电电阻：拔插头后插头引脚带电，是典型的安全隐患。
4. 电解电容紧贴变压器：纹波电流 + 高温，寿命骤降，质保期内批量失效（`PCB-FAIL-THERMAL-RUNAWAY`）。

## 评审清单

- [ ] 是否已建立安规输入表（电压/OVC/污染等级/海拔/绝缘类型）并按标准查表？
- [ ] 隔离带是否所有层无铜无过孔？宽度是否含裕量？需要时是否开槽？

- [ ] Y 电容容值是否满足漏电流限值？是否使用安规认证的 Y 类器件？
- [ ] 输入保护顺序是否为“保险丝 → 压敏 → NTC → X 电容/共模 → 整流”？
- [ ] X 电容是否有放电电阻？拔插头后插头电压能否在要求时间内衰减？

- [ ] 次级整流→输出电容→负载环路是否最小？输出电容是否按纹波电流降额？
- [ ] 反馈取样是否在输出电容之后？反馈走线是否全程在次级侧？
- [ ] 满载 + 最高环境温度下，开关管/整流管/变压器/电解电容温度是否在限值内？
