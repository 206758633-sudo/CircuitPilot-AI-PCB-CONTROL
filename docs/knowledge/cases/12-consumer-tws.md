# 案例 12：消费电子 TWS / 可穿戴 —— 结构先定、电源其次，天线与音频是硬约束

> **一句话结论**：TWS/可穿戴板的设计顺序与常规板相反——**先定结构与堆叠（外形、FPC、触点、天线区），再定电源树与充电，最后才排音频与 ESD**；因为在这类 1～2 cm² 的板上，天线净空、电池占位、触点位置一旦确定就无法用布线补救，而电源与音频还有优化空间。超小板的“性能”本质是**结构、热、射频、装配四件事的联合约束**，不是单纯的电气设计。

## 设计原理拆解

以下按“结构与堆叠 → 电源与充电 → 电池保护 → 射频与天线 → 音频 → 触点与 ESD → 去耦与地 → 热 → DFM 与可测试性”拆解。所有具体电流/电压/容值/尺寸均标注“按电池规格、芯片 datasheet 与射频指南复核”。

**一、结构与堆叠先行**

### KP-CASE-TWS-01 超小板的第一个约束是结构与装配，不是电气

- **判据**：外形尺寸、板厚、FPC 出线方向、充电触点位置、天线区域、电池占位必须在原理图冻结前锁定；任何电气方案都不得要求这些项让步（`PCB-RULE-PLACE-CONN-001`、`PCB-RULE-FPC-001`）。
- **为什么**：耳机腔体只有固定体积，天线净空、电池、喇叭三者互相挤占；板子画完再改外形，等于天线、连接器、固定孔全部重来，且模具/结构件已经开好，改板成本远高于改电路。
- **怎么做**：先出“结构-堆叠图”：外形、板厚、器件高度分区、天线区、触点、FPC 出线；再按堆叠图排布关键器件；把天线 keep-out 与 FPC 弯折区作为布局禁布区（room/keepout）先画出来。
- **怎么查**：结构与 PCB 叠合检查（3D 干涉）；天线区逐层确认无铜；FPC 弯折区无器件；样机装配验证（扣壳、按压、扭转）。

### KP-CASE-TWS-02 充电盒与耳机是两套电源树，不要按“一块板”设计

- **判据**：充电盒（VBUS → 盒电池 → 耳机充电）与耳机（触点/VBUS → 耳机电池 → 系统）必须分别画电源树，标清每一段的电压/电流/效率与保护；触点两侧的“谁给谁供电、谁检测谁”必须写死（`PCB-RULE-POWERMUX-001`、`PCB-RULE-CHARGER-001`）。
- **为什么**：充电盒给耳机充电时是“电源”，被 USB 充电时是“负载”，两种角色下电流方向与保护需求不同；如果按单板思路画，很容易出现“盒给耳机充电时倒灌到 USB 口”或“耳机插上 USB 时向盒内电池反充”。
- **怎么做**：分别画两张电源树；触点串联“充电开关 + 电流检测 + 反灌阻断”；耳机侧充电 IC 支持“输入来自触点”与“输入来自 USB”两种场景；检测线（插入检测）单独走，不要复用充电电流路径。
- **怎么查**：按“盒充耳机 / USB 充盒 / USB 直充耳机 / 都断开”四种组合测各路电流方向；触摸充电 IC 与开关温升；确认无反向漏电（待机电流预算）。

**二、电池与充电**

### KP-CASE-TWS-03 充电电流、截止电压、温度保护必须与电池规格逐项匹配

- **判据**：充电 IC 的恒流值、浮充/截止电压、充电温度窗口必须落在电池规格书范围内（常见锂离子 4.2 V 档，**按实际电池规格复核**）；电池 NTC 必须接入充电 IC 的温度检测脚，且 NTC 位置贴电池本体（`PCB-RULE-CHARGER-001`）。
- **为什么**：截止电压偏高会加速电池衰减甚至鼓包；充电电流超过电池允许值会在小体积、无对流条件下持续发热；NTC 贴错位置（贴 PCB 而非电池）会让温度保护形同虚设，热失控时保护来不及动作。
- **怎么做**：按电池规格书反推充电电流与截止电压；NTC 用导热胶/胶带贴电芯表面并引线到检测脚；充电 IC 的 ISET/PROG 电阻按公式计算并留裕量；充电状态指示与满电检测独立于 MCU（防 MCU 死机后一直充）。
- **怎么查**：用电子负载/电池模拟器测恒流值与截止电压；高低温箱测充电窗口；故意遮挡/加热 NTC 验证保护动作；充满后静置测电池电压回落。

### KP-CASE-TWS-04 电池保护必须独立于充电 IC，且过放恢复要有明确策略

- **判据**：电池必须有独立的保护板或保护 IC（过充/过放/过流/短路），充电 IC 的保护不能替代电池保护；过放后（电池电压低于欠压阈值）系统要有“禁止大电流启动、先小电流预充”的策略（按电池与充电 IC datasheet 复核）。
- **为什么**：充电 IC 失效（如 MOSFET 击穿）时只有电池保护能切断；过放电池直接大电流充电会析锂、发热，是消费电子安全事故的常见根因；过放后系统若立刻满载启动，会反复触发保护形成“打嗝”。
- **怎么做**：电池保护板串在电芯与系统之间；系统侧加欠压检测，低电时先关功放/射频再进低功耗；充电 IC 支持预充（trickle）与再充（recharge）阈值；长期仓储模式要有超低待机电流路径。
- **怎么查**：模拟电池过放（可调电源限流）后上电，观察是否先预充；短路保护测试；仓储静置 30 天测电池电压跌落与待机电流。

**三、射频与天线**

### KP-CASE-TWS-05 天线净空是第一位约束：耳机里比板上更难，因为电池和人体都在旁边

- **判据**：天线净空区（所有层禁铜、禁器件、禁走线）按模组/天线 datasheet 留足（`PCB-RULE-RF-001`）；天线尽量朝外、远离电池与金属壳体；人体佩戴时天线效率会下降，必须按“佩戴状态”而不是“自由空间”评估（具体尺寸按天线/模组指南复核）。
- **为什么**：2.4 GHz 天线靠周围空间辐射，电池（含金属箔）、喇叭磁铁、金属装饰件都会改变谐振与方向图；人体是损耗介质，佩戴后效率显著下降，自由空间测出的“能连”不代表佩戴能连。
- **怎么做**：天线区在布局前画 keep-out；电池/喇叭/磁铁远离天线；天线与外壳留净空，外壳避免金属涂层；必要时用陶瓷天线或 FPC 天线并按其指南留净空；匹配网络留 π 型焊盘便于调试。
- **怎么查**：逐层检查 keep-out；裸板与整机分别测 RSSI/吞吐；佩戴（人头模型或真人）复测；有条件做暗室 OTA 效率测试。

### KP-CASE-TWS-06 射频走线按 50 Ω 处理，匹配网络靠近天线且地参考连续

- **判据**：天线到射频引脚之间的走线按 50 Ω 单端设计（微带线宽按叠层用场求解器确认，粗估 `W ≈ 2H`，FR-4 εr≈4.2），走线尽量短、不跨分割、两侧包地并打缝合孔（`PCB-RULE-IMPEDANCE-001`、`PCB-RULE-RETURN-001`）；匹配网络的地端就近打过孔。
- **为什么**：50 Ω 失配会把功率反射回 PA，降低辐射效率并增加发热；参考面不连续会让回流绕行，形成辐射与损耗；匹配元件地端的长走线会引入额外电感，让调试结果与仿真对不上。
- **怎么做**：射频走线单独规划，避免与数字/电源并行；匹配网络按 π 型（串联+并联）留焊盘，元件靠近天线端；射频走线两侧地铜 + 缝合孔；过孔尽量少，必须换层时旁边补回流地孔。
- **怎么查**：用网络分析仪/矢量阻抗仪测天线端口 S11（有条件）；无仪器时至少核对接地、包地、走线长度；整机吞吐与距离测试；量产做天线一致性抽检。

**四、音频**

### KP-CASE-TWS-07 音频链路：功放电源去耦 + 单点 AU_GND + 默认静音，三件事决定“有没有爆音”

- **判据**：音频功放电源就近去耦（大电容 + 0.1 µF，`PCB-RULE-DECOUPLE-001`/`002`）；功放/喇叭地与被测模拟地按 datasheet 做单点/星点连接（`PCB-RULE-AUDIO-001`）；上电/复位/切换过程中功放必须有确定静音（mute）状态，避免“上电爆音”。
- **为什么**：功放是脉冲大电流负载，电源纹波会直接调制到音频输出；音频地与数字地混接会把数字噪声耦合进喇叭；上电瞬间电容充电/偏置建立会在喇叭上产生“砰”声，用户感知极强。
- **怎么做**：功放电源独立 LC/磁珠滤波；AU_GND 单点连到主地；mute 引脚默认上拉/下拉到静音态，由 MCU 在稳定后释放；喇叭走线成对、短；麦克风走线远离射频与电源。
- **怎么查**：示波器测上电/复位/切歌时的喇叭波形（有无瞬态）；听感测试（爆音/底噪）；电源纹波与音频输出 SNR 测试（有条件）；射频发射时听是否有“哒哒”干扰。

**五、触点、ESD 与去耦**

### KP-CASE-TWS-08 充电触点是“用户可触摸的裸金属”，ESD/浪涌路径必须在触点侧处理

- **判据**：充电触点/金手指在连接器侧就要有 ESD 器件（低电容、耐触点电压），地端短宽多孔（`PCB-RULE-ESD-001`、`PCB-RULE-BOARD2BOARD-001`）；触点与内部电路之间先过保护再进充电 IC；触点金属外露时按“人体可触摸”对待。
- **为什么**：TWS 触点是用户手指、桌面、衣物静电的直接入口；耳机放入盒中的瞬间还有接触抖动与浪涌；ESD 电流若先进充电 IC，轻则通信异常，重则击穿（`PCB-FAIL-ESD-DAMAGE`）。
- **怎么做**：触点 → ESD → 充电 IC 的顺序不可颠倒；ESD 地就近接充电地并多过孔；触点串小阻/磁珠（按充电电流与压降权衡）；触点镀层与弹片压力按插拔寿命选；耳机/盒两侧都做保护（谁先接触不确定）。
- **怎么查**：ESD 枪打触点（IEC 61000-4-2，等级按产品要求）；插拔 1 万次后测接触电阻；充电电流与压降测试；保护器件温升与漏电。

### KP-CASE-TWS-09 超小板的去耦与地：引脚到电容的 2 mm 比“总容量”重要

- **判据**：蓝牙 SoC/功放的每个电源引脚就近 0.1 µF（到引脚 ≤2 mm、两端各 ≥1 过孔），电源入口放 µF 级体电容（`PCB-RULE-DECOUPLE-001`/`002`、`PCB-RULE-PLACE-DECOUPLE-001`）；地平面在超小板上也要尽量完整，避免被过孔与走线切成碎片。
- **为什么**：SoC 在射频发射瞬间的 di/dt 很高，去耦靠的是短回路；超小板空间紧张，最容易犯的错就是“电容放在了板子另一头”或“地过孔只有一个”，导致瞬态压降触发复位（`PCB-FAIL-CAP-DISTANCE`、`PCB-FAIL-MISSING-DECOUP`）。
- **怎么做**：先放去耦再排线；电容与引脚同层，过孔贴焊盘；体电容靠近电池/充电入口；4 层板用完整地平面，2 层板用底层地铜 + 缝合孔；避免在电源入口串磁珠（除非有实测依据）。
- **怎么查**：逐引脚核对电容位置与过孔；射频发射时测 3V3 纹波（短地弹簧、20 MHz 带宽）；负载瞬变（开功放/发射）时看有无复位；热像仪看电容与 SoC 温升。

**六、热、DFM 与可测试性**

### KP-CASE-TWS-10 热：充电 + 射频 + 音频同时工作，小体积里没有对流

- **判据**：按 `Tj = Ta + P×θJA` 估算 SoC、功放、充电 IC 结温（`PCB-RULE-THERMAL-001`）；充电（盒内、无风）与射频发射是最恶劣组合；所有器件按最高环境温度（如 40～45 °C 贴身环境）降额。
- **为什么**：耳机腔体几乎密闭、无对流，热量只能靠外壳与铜皮传导；充电时盒内多颗 IC 同时发热，温度叠加后可能触发充电 IC 的 OTP 降流，表现为“充得越来越慢”。
- **怎么做**：发热件分散布置、远离电池 NTC；充电 IC/功放下方铺铜 + 热过孔；利用外壳/金属件做导热（注意天线净空）；必要时限制充电电流或加充电温度降额曲线；避免把发热件贴在天线上。
- **怎么查**：整机充电 + 播放 + 连接状态连续跑 1 h，测外壳与器件温度；高环境温度（如 45 °C）复测充电电流；确认 OTP 触发点与降额策略；`Tj` 余量建议 ≥20 °C。

### KP-CASE-TWS-11 DFM 与可测试性：0.4 mm 间距、拼板分板、测试点都要在布局阶段定

- **判据**：细间距器件（0.4 mm pitch 级）的焊盘/阻焊桥按板厂能力设计（`PCB-RULE-MASK-001`、`PCB-RULE-ANNULAR-001`）；拼板与分板方式避开易损件（`PCB-RULE-PANEL-001`、`PCB-RULE-EDGE-001`）；关键网络（VBUS、电池、3V3、GND、触点、UART/烧录）留测试点（`PCB-RULE-TESTPOINT-001`、`PCB-RULE-PLACE-TEST-001`）；天线口留射频测试点/座。
- **为什么**：超小板上器件密、板边近，分板应力与贴片偏移会直接造成虚焊/立碑（`PCB-FAIL-TOMBSTONE`、`PCB-FAIL-COLD-JOINT`）；没有测试点，量产只能靠整机功能判断，返修成本高。
- **怎么做**：拼板优先邮票孔 + 工艺边，V-CUT 远离易损件；细间距器件四周留返修空间；测试点按探针网格布置、不被高件遮挡；天线匹配网络留调试焊盘；丝印标 Pin1 与极性。
- **怎么查**：板厂 DFM 报告；首件 AOI/X-Ray（BGA/QFN）；分板后抽检焊点；治具试测；天线一致性抽检（RSSI 分布）。

## 规则依据

| 规则 ID | 本案例对应做法 | 物理/标准依据 |
|---|---|---|
| `PCB-RULE-CHARGER-001` | 充电电流/截止电压/温度保护与电池规格逐项匹配 | 锂离子充电必须遵守 CC/CV 与温度窗口；超限会析锂/鼓包 |
| `PCB-RULE-BOARD2BOARD-001` | 充电触点/板间连接器交叉线序 + 防呆 + TVS | 触点对接瞬间存在抖动与浪涌；线序错误会反接烧板 |

| `PCB-RULE-RF-001` | 天线净空区所有层禁铜/禁线/禁器件 | 天线附近导体改变谐振频率、降低效率、畸变方向图 |
| `PCB-RULE-IMPEDANCE-001` | 射频走线 50 Ω，线宽按叠层计算 | 阻抗失配引起反射，降低辐射效率并增加 PA 发热 |
| `PCB-RULE-RETURN-001` | 射频换层/过孔旁补回流地孔 | 参考面不连续时回流绕行，形成辐射与损耗 |
| `PCB-RULE-AUDIO-001` | 功放去耦、AU_GND 单点、默认静音 | 功放脉冲电流调制电源；地噪声耦合进喇叭 |
| `PCB-RULE-DECOUPLE-001` | 每个电源引脚 0.1 µF、≤2 mm、两端过孔 | 高频去耦靠安装电感，距离越远越失效 |
| `PCB-RULE-DECOUPLE-002` | 体电容 + 近端小电容组合 | 容值间隔覆盖频段，抑制并联反谐振峰 |
| `PCB-RULE-THERMAL-001` | 功放/充电 IC 铺铜 + 热过孔 | `Tj = Ta + P×θJA`，小体积无对流时 θJA 更差 |
| `PCB-RULE-FPC-001` | FPC 出线方向、补强、弯折半径按连接器规格 | 弯折应力集中在补强边缘，半径不足会断线 |
| `PCB-RULE-PANEL-001` | 拼板/分板远离易损件，工艺边 ≥5 mm | 分板应力导致焊点开裂与器件损伤 |
| `PCB-RULE-TESTPOINT-001` | VBUS/电池/3V3/GND/触点/烧录留测试点 | 可测试性决定量产良率与返修成本 |

**依据说明**

- **为什么“结构先行”**：天线净空与电池占位是**不可布线的约束**，它们直接决定板框；而电源、音频、ESD 都能在既定板框内通过布局与选型优化。设计顺序必须服从“约束刚性排序”。
- **触点 ESD 的物理**：用户触摸触点时，静电荷经触点进入板内；保护器件越靠触点，路径电感越小，钳位残压越低。耳机与盒两侧都要保护，因为接触顺序不确定。
- **音频爆音的本质**：功放上电时内部偏置建立与耦合电容充电产生阶跃，若 mute 未拉住，阶跃直接加到喇叭；这是“电路正确但体验很差”的典型，必须在时序上解决。

## 可迁移的设计经验

**做对的**

1. 先出结构与堆叠图，把天线区、电池占位、触点、FPC 出线作为布局硬约束，再画电路。
2. 充电盒与耳机分别画电源树，触点两侧都做 ESD 与反灌阻断，按四种供电组合验证。
3. 电池 NTC 贴电芯本体而不是贴 PCBA，让温度保护真正反映电芯温度。
4. 天线匹配网络留 π 型焊盘 + 射频测试点，给调试与量产一致性留后路。

**妥协的**

1. 超小板上天线净空与电池占位互相挤占，只能牺牲天线效率或电池容量，没有两全方案。
2. 2 层板做蓝牙射频，阻抗与地平面都不理想；4 层能显著改善，但成本与板厚受限。
3. 充电触点既要低接触电阻又要耐 ESD，串联保护器件会带来压降与发热，需在充电电流上折中。
4. 密闭腔体散热只能靠外壳传导，充电电流与射频占空比必须做温度降额。

**反面教训**

1. 先画板再考虑结构：天线被电池/金属件挡住，整机距离不达标，只能改板改模（`PCB-FAIL-EMI-FAIL`）。
2. 充电 IC 的 NTC 贴在 PCB 上：电芯过热时保护不动作，是消费电子召回级风险。
3. 触点无 ESD 保护：用户摸一下触点就击穿充电 IC，表现为“放回盒子不充电”，返修率极高（`PCB-FAIL-ESD-DAMAGE`）。
4. 功放 mute 默认释放：每次上电“砰”一声，用户直接判定为质量差。
