# RF 与天线设计：50Ω 传输、匹配、巴伦、净空、调试与认证

> **一句话结论**：RF 前端不是“把天线接到芯片上”，而是**一条从芯片引脚到自由空间都保持受控阻抗、受控损耗、受控净空的链路**；先保证 50Ω 参考与地回流连续，再谈匹配网络与天线选型，最后才用 VNA 与暗室证明它。

## 适用范围与边界

| 项 | 内容 |
| --- | --- |
| 适用阶段 | 无线需求/频段确定 → RF 前端原理图 → 匹配与天线布局 → 调试 → 认证 |

| 输出 | RF 链路预算、50Ω 走线与匹配网络、巴伦/滤波器、天线净空与馈线规则、调试与认证记录 |

## 一、RF 基础与传输线

### KP-SCH-211 RF 前端设计总则：先定链路指标，再谈电路

- **判据**：RF 前端开画前必须明确：频段与带宽、发射功率/EIRP 上限、接收灵敏度、天线形式与增益、可用结构空间、认证地区与标准；原理图上的每个匹配/滤波/巴伦元件都要能对应到链路预算中的一项（插损、抑制、隔离）。
- **为什么**：RF 是“系统指标逐级累加”的设计：滤波器插损直接降低发射功率与接收灵敏度，匹配损耗直接变成回波损耗与辐射效率，任何一级没有指标就无法判断取舍。
- **怎么做**：画链路预算表：芯片输出功率 → 匹配/滤波插损 → 巴伦插损 → 馈线损耗 → 天线增益 → EIRP；接收方向按噪声系数级联计算（KP-SCH-224）；每级标注目标值与来源（datasheet/参考设计/实测）。
- **怎么查**：用 VNA/功率计/暗室实测各级插损与 EIRP，回填预算表；与认证限值比对。不通过 → 调整链路或换器件。

### KP-SCH-212 50Ω 参考阻抗与微带线宽度

- **判据**：单端 RF 链路默认 50Ω（芯片 datasheet 另有规定除外）；微带线宽度由叠层决定，必须用叠层参数（h、εr、铜厚）通过场求解器或 EDA 阻抗工具计算，不得凭经验拍宽度；50Ω 线两侧必须有连续参考地。
- **为什么**：阻抗偏离会造成反射（S11 变差）、功率损耗与辐射；宽度算错在 2.4GHz 就可能从 -20dB 回波恶化到 -6dB。
- **怎么做**：示例量级：FR-4 类材料 εr≈4.2、介质厚 h=0.2mm 时，50Ω 微带线宽约 0.37mm（w/h≈1.9；**必须用实际叠层与场求解器复核**）；射频走线优先布在表层并紧邻完整地平面，避免跨分割；线宽变化处做渐变，不做过孔换层（除非必要且有地过孔伴随）。
- **怎么查**：EDA 阻抗计算 + 板厂阻抗报告；VNA 测 S11/S21；TDR 测阻抗连续性。不通过 → 调线宽/叠层/参考地。

### KP-SCH-213 共面波导与地回流：RF 走线的“地”比线更重要

- **判据**：RF 走线两侧与下方的地必须连续；共面波导（CPW）的缝隙 g 与线宽 w 共同决定阻抗，两侧地必须用密集地过孔连接到主地平面；地过孔间距建议小于最高频率对应波长的 1/20（2.4GHz 时 λ≈125mm，λ/20≈6mm，**按实际频率与仿真复核**）。
- **为什么**：RF 电流走“最小电感路径”，地不连续会让回流绕行，形成辐射环路与阻抗突变；CPW 没有地过孔时两侧地会浮动，等效阻抗与损耗都不可控。
- **怎么做**：RF 线两侧包地并沿線打地过孔；CPW 参数（w/g）由场求解器算；连接器地脚就近多过孔下地；避免 RF 线下方有电源/数字平面切割；天线馈电点附近地过孔按参考设计布置。
- **怎么查**：目检地过孔密度与连续性；VNA 测 S11/S21；近场扫描看辐射热点。不通过 → 补地过孔/改走线/改叠层。

### KP-SCH-214 匹配网络拓扑：L 型、π 型、T 型与 Q 值

- **判据**：匹配网络必须把芯片引脚阻抗变换到 50Ω（或天线阻抗），并满足目标带宽；L 型匹配的 Q 值 `Q = √(Rhigh/Rlow − 1)`，Q 越高带宽越窄；需要更宽带宽或更低 Q 时用 π/T 型或多级；匹配元件必须按工作频率选型（见 KP-SCH-215）。
- **为什么**：匹配不是“凑到 50Ω”就完事，Q 值决定带宽与对元件容差的敏感度；高 Q 网络在量产容差/温度漂移下容易失配。
- **怎么做**：示例：50Ω ↔ 25Ω 用 L 型，`Q=√(50/25−1)=1`；在 2.4GHz 下串联电抗 25Ω 对应 L≈1.66nH 或 C≈2.65pF（按拓扑方向），并联支路同理；需要更宽带宽时用两级 L 型或 π 型降低单级 Q；匹配网络靠近芯片引脚放置，先做 π 型预留调试位（KP-SCH-222）。
- **怎么查**：VNA 在目标频段扫 S11，看带宽内是否满足回波损耗目标；用 Smith 圆图核对匹配轨迹；高低温/换批次复测。不通过 → 改拓扑/换元件/加调试位。

### KP-SCH-215 匹配元件选型：Q 值、SRF 与容差

- **判据**：匹配用电感/电容必须满足：自谐振频率（SRF）高于工作频率足够多（一般要求 SRF ≥ 2~3×工作频率，按器件 datasheet 与仿真复核）、Q 值在频段内足够高、容差满足带宽/良率预算（常见 0.1pF/0.1nH 级或更高精度）、额定功率/电流覆盖 RF 功率。
- **为什么**：元件在 SRF 以上呈容性/感性反转，匹配会完全失效；Q 低会引入插损；容差大则量产一致性差（S11 漂移）。
- **怎么做**：2.4GHz 下 1nH 的感抗约 15Ω、1pF 的容抗约 66Ω（量级参考），因此 0.1pF/0.1nH 的误差就会明显移动匹配点；选高频薄膜/陶瓷 RF 专用元件，避免大封装（寄生大）；电感按饱和电流与 Q 选；电容用 C0G/NP0，不用 X7R/Y5V；在 BOM 中标注精度与 SRF。
- **怎么查**：查 datasheet 的 SRF/Q vs 频率曲线；VNA 实测匹配与带宽；换批次抽测 S11。不通过 → 换更高 SRF/更高精度元件/改拓扑。

### KP-SCH-216 巴伦（Balun）：差分 RF 与单端的转换

- **判据**：差分 RF 端口（芯片侧）到单端天线必须用巴伦（集成或分立）；巴伦需满足：频率范围、插入损耗、幅度/相位平衡（幅度差、相位差按 datasheet 指标）、共模抑制、阻抗比（常见 1:1 或按芯片要求）；巴伦到芯片与到天线的走线都必须 50Ω（或规定阻抗）。
- **为什么**：差分 RF 直接接单端天线会破坏平衡，产生共模电流、辐射方向图畸变与损耗；巴伦不平衡会降低共模抑制与接收灵敏度。
- **怎么做**：优先用芯片参考设计推荐的集成巴伦；分立巴伦按 datasheet 的拓扑与元件值；巴伦靠近芯片放置，差分对等长对称；巴伦下方地完整，地脚多过孔；在链路预算中计入巴伦插损（典型 0.5~1.5dB，按 datasheet）。
- **怎么查**：VNA 测单端 S11/插损；用差分探头/巴伦测试夹具测幅度/相位平衡；暗室测辐射方向图。不通过 → 换巴伦/调匹配/改布局。

### KP-SCH-217 滤波器：SAW/LC/低通/带通与抑制指标

- **判据**：滤波器选型必须给出：通带插损、带外抑制（对谐波/邻频/镜像）、群时延、功率容量、阻抗；SAW/BAW 插损低但功率容量有限，LC 可承受更大功率但插损/Q 受限；滤波器前后都要匹配 50Ω；LC 滤波器截止 `fc = 1/(2π√(LC))` 需按目标频段核算。
- **为什么**：滤波器是“用插损换抑制”：插损直接降低发射功率与接收灵敏度，抑制不足则谐波/邻频干扰导致认证失败或共存变差。
- **怎么做**：按链路预算分配插损（发射链路总插损影响 EIRP，接收链路插损直接加噪声系数）；谐波抑制按 2 次/3 次谐波频率设计；LC 低通示例：目标 fc=3GHz，取 L=2.2nH、C=1.3pF 量级（实际用滤波器设计工具/仿真复核）；SAW 注意输入功率不得超过其额定值。
- **怎么查**：VNA 测通带插损与带外抑制；频谱仪测谐波；高低温/功率扫测。不通过 → 加级/换滤波器/改拓扑。

## 二、天线、净空与馈线

### KP-SCH-218 天线类型选型：PCB/陶瓷/外置

- **判据**：按频段、带宽、尺寸、增益、成本、结构空间选择：PCB 走线天线（成本低、需净空）、陶瓷贴片天线（尺寸小、带宽窄、对净空敏感）、外置天线（性能好、需连接器与线缆）；必须核对天线 datasheet 的推荐净空、匹配与效率；天线增益与方向图要匹配整机形态。
- **为什么**：天线是“结构相关的器件”，同一颗天线在不同净空/外壳下效率可能差数 dB；选型不看净空条件，实测必然偏离 datasheet。
- **怎么做**：优先选模块/芯片厂商推荐天线；PCB 天线按参考设计的尺寸与净空 1:1 复制；陶瓷天线按 datasheet 的 keepout 与地脚要求布局；外置天线选与频段/阻抗匹配的型号并核算线缆损耗；在原理图上标注天线型号/阻抗/净空要求。
- **怎么查**：VNA 测天线端 S11；暗室测效率/方向图；整机（含外壳/电池）复测。不通过 → 换天线/改结构/调匹配。

### KP-SCH-219 天线净空：禁布区、参考地与周围金属

- **判据**：天线净空区（keepout）内不得有铜箔、走线、过孔、电池、金属螺丝/屏蔽罩/外壳；净空尺寸严格按天线或模块 datasheet（常见为数十 mm 量级，**必须以所选器件 datasheet 为准**）；天线下方与正前方不得有地平面（除非参考设计明确要求）；周围金属会改变谐振频率与效率。
- **为什么**：天线靠空间电磁场工作，净空内任何导体都会吸收/反射能量、改变输入阻抗，表现为频偏、效率下降、距离变短。
- **怎么做**：在原理图与布局说明中画出 keepout 区域并标注“禁止铺铜/走线/放器件”；电池、喇叭、屏蔽罩、金属结构件远离天线；必要时把天线放在板边并伸出；外壳材料（金属/含金属涂层）必须评估。
- **怎么查**：目检/DRC 检查 keepout 内是否有铜与器件；VNA 测天线 S11 与效率；整机暗室测总辐射功率（TRP）。不通过 → 清净空/改结构/换天线位置。

### KP-SCH-220 天线馈线与地回流

- **判据**：天线馈线必须 50Ω、尽量短、少弯曲；馈线参考地连续，连接器地脚与天线地脚就近多过孔下地；馈线不得跨越分割地或电源平面缺口；外置天线线缆需按损耗（dB/m）核算，必要时选低损线缆或缩短长度。
- **为什么**：馈线损耗直接降低发射功率与接收灵敏度（发射/接收各一次），地不连续会造成共模电流与方向图畸变。
- **怎么做**：芯片/模块 → 匹配 → 馈线 → 天线连接器，全程 50Ω；馈线长度在链路预算中计入损耗（示例：2.4GHz 低损线缆约 0.3~0.6dB/m，**按线缆 datasheet 复核**）；连接器（U.FL/SMA）按频率与插损选型；天线地脚与连接器地脚用多过孔连接。
- **怎么查**：VNA 测馈线插损（两端校准）；目检参考地连续性；整机灵敏度/TRP 测试。不通过 → 缩短馈线/换低损线缆/改地。

### KP-SCH-221 RF 走线布局：短、直、包地、远离干扰

- **判据**：RF 走线尽量短、直、少过孔；两侧包地并密集地过孔；RF 线远离开关电源（DC-DC 电感/开关节点）、晶振/时钟、数字高速线、电机/继电器；RF 与数字/电源分区；匹配元件紧贴芯片引脚，元件下方地完整。
- **为什么**：RF 走线既是传输线也是天线：长线/过孔引入寄生参数，邻近的开关节点与时钟会通过容性/感性耦合恶化噪声系数与 EVM。
- **怎么做**：先放 RF 器件并锁定位置，再布数字/电源；RF 走线不跨分割、不换层（必须换层时伴随地过孔）；DC-DC 与晶振远离天线与 RF 输入；匹配元件地脚就近下地；屏蔽罩（如有）接地良好。
- **怎么查**：目检走线长度/过孔/包地；近场探头扫描干扰；整机灵敏度与 EVM 测试。不通过 → 改布局/加屏蔽/改地。

### KP-SCH-222 RF 连接器、测试点与 π 型调试网络

- **判据**：RF 链路应预留调试手段：π 型匹配位（串联+两个并联焊盘）或 0Ω 跳线位，便于调试时替换匹配；测试点/连接器（U.FL/SMA）按频率与插损选型；调试位在量产后可贴 0Ω 或按最终匹配值贴片；测试点不得破坏 50Ω 连续性。
- **为什么**：RF 匹配几乎不可能一次算准，没有调试位就要割线/飞线；π 型网络可在不改变拓扑的情况下调整串联/并联元件。
- **怎么做**：在芯片与天线之间预留 π 型（串联元件位 + 两个对地元件位）；调试连接器尽量用 U.FL（小、插损低）或测试焊盘；调试后用 0Ω/最终值替换；在原理图上标注“调试位，默认 DNP”。
- **怎么查**：VNA 从调试连接器测 S11；确认调试位在最终 BOM 中的贴装状态；不通过 → 调整匹配/更换调试方案。

## 三、链路预算、共存与法规

### KP-SCH-223 发射功率、EIRP 与法规限值

- **判据**：`EIRP(dBm) = Ptx(dBm) + Gant(dBi) − Lfeed(dB) − Lfilter(dB)`；EIRP 必须低于目标地区法规限值（FCC/CE RED/SRRC 等，具体限值与测试方法**必须查对应标准原文**）；传导功率与 EIRP 是两件事，认证通常两者都测。
- **为什么**：超 EIRP 会导致认证失败、干扰其他设备；只看芯片输出功率而不算天线增益与损耗，很容易超标或功率不足。
- **怎么做**：示例：Ptx=20dBm、Gant=2dBi、馈线+滤波损耗 1dB → EIRP=21dBm；按地区标准核对限值并留 1~2dB 余量；软件功率档位与硬件匹配；认证前用功率计/频谱仪预测传导功率，暗室测 EIRP。
- **怎么查**：传导功率测试 + 暗室 EIRP/TRP；对照标准限值（查原文）；不通过 → 降功率/换天线/加滤波。

### KP-SCH-224 接收灵敏度、噪声系数与 Friis 级联

- **判据**：接收灵敏度 `Pmin(dBm) = −174 + 10log10(B) + NF + SNRmin`；级联噪声系数按 Friis：`F_total = F1 + (F2−1)/G1 + (F3−1)/(G1G2) + …`；LNA 必须尽量靠前且增益足够，滤波器插损直接加在 NF 上。
- **为什么**：接收灵敏度由噪声系数与带宽决定；前级损耗/噪声会被后续级放大，LNA 位置与增益是接收链路的关键。
- **怎么做**：示例：B=1MHz（10logB=60dB）、NF=2dB、SNRmin=10dB → `Pmin ≈ −174+60+2+10 = −102dBm`；Friis 示例：LNA NF=1.5dB、G=15dB，后级混频器 NF=8dB → `F_total ≈ 1.413+(6.31−1)/31.6 ≈ 1.58`，即约 2.0dB；滤波器插损放在 LNA 前会直接恶化 NF，需权衡抑制与灵敏度。
- **怎么查**：用信号源+频谱仪测灵敏度（误包率/BER 判据）；噪声系数分析仪测 NF；链路预算与实际对比。不通过 → 换 LNA/调增益/改滤波位置。

### KP-SCH-225 共存与干扰：WiFi/BT/LTE 同板共存

- **判据**：多无线制式共存时必须做：频段/谐波分析（2 次/3 次谐波是否落入对方频段）、天线隔离度（间距/方向/极化）、滤波与屏蔽、时分/仲裁机制（芯片支持时）；共存指标（灵敏度回退、吞吐下降）必须有测试判据。
- **为什么**：同一块板上 WiFi 发射的谐波可能落入 BT/LTE 接收频段，造成灵敏度回退；天线距离太近则隔离度不足。
- **怎么做**：天线间距尽量大（按波长与隔离度目标，2.4GHz λ≈125mm，**具体间距按仿真/实测**），不同天线极化正交；发射链路加谐波低通；接收链路加带通；必要时加屏蔽罩/吸波材料；软件侧使用时隙/仲裁。
- **怎么查**：分别测单制式与共存场景的灵敏度/吞吐；频谱仪看谐波与杂散；暗室测隔离度。不通过 → 加滤波/改天线布局/改屏蔽。

### KP-SCH-226 天线与 RF 测量：VNA、S11、效率与暗室

- **判据**：RF 调试必须用校准过的 VNA 测 S11/S21，并换算：回波损耗 `RL(dB) = −20log10|S11|`、驻波比 `VSWR = (1+|S11|)/(1−|S11|)`；天线效率/方向图/TRP 必须在暗室或标准场地测；测量前必须做 SOLT 校准并记录校准件与日期。
- **为什么**：没有校准的测量没有意义；S11 与效率/TRP 是不同层面的指标，前者只看匹配，后者才反映辐射性能。
- **怎么做**：参考换算表：S11=−10dB → RL=10dB、VSWR≈1.93；−15dB → 15dB、≈1.43；−20dB → 20dB、≈1.22（**目标值按产品/芯片要求定**）；VNA 校准到测试端面（含线缆/夹具）；暗室测 TRP/TIS 或方向图；记录测试条件（频点、功率、温度）。
- **怎么查**：复核校准记录与测试端面；重复测量一致性；与仿真/参考设计对比。不通过 → 重新校准/改匹配/改天线。

### KP-SCH-227 RF 接口的 ESD 与保护

- **判据**：外露天线接口/连接器必须评估 ESD；RF 路径上的保护器件结电容必须极低（高频下几 pF 就会显著改变匹配，**按频段与器件 datasheet 复核**）；保护器件放在连接器侧，地回路短；不得用普通 TVS 直接并在 50Ω RF 线上而不评估其电容/寄生。
- **为什么**：RF 接口常外露，ESD 会打坏 LNA/开关；但保护器件的寄生电容会破坏 50Ω 匹配与插损，二者必须权衡。
- **怎么做**：优先选 RF 专用低电容 ESD 器件；把保护器件放在匹配网络之前或之后按仿真/实测决定；地脚就近下地；必要时用 π 型网络吸收寄生；对天线馈电点做 ESD 测试。
- **怎么查**：IEC 61000-4-2 测试后复测 S11/灵敏度；VNA 对比加保护前后的插损/匹配。不通过 → 换低电容器件/改位置/加匹配补偿。

### KP-SCH-228 参考时钟与相位噪声对 RF 的影响

- **判据**：RF 芯片的参考时钟（晶振/TCXO/时钟芯片）必须满足 datasheet 的频率精度、相位噪声与抖动要求；参考时钟走线要短、包地、远离数字/开关噪声；时钟源的电源必须低噪声去耦。
- **为什么**：参考时钟的相噪会直接恶化 RF 的 EVM/邻道功率与接收灵敏度；时钟抖动在高速 ADC/DAC 与 LO 中会被放大。
- **怎么做**：按芯片要求选晶振/TCXO（频率、ppm、相噪）；时钟走线做 50Ω/包地；电源用 LDO 单独供电并加磁珠/去耦；晶振下方完整地、远离 DC-DC 与天线；在原理图上标注时钟指标。
- **怎么查**：相位噪声分析仪/频谱仪测相噪；EVM/邻道功率测试；对比不同时钟源的灵敏度。不通过 → 换时钟源/改供电/改布局。

### KP-SCH-229 屏蔽、隔离与腔体谐振

- **判据**：对辐射/敏感模块（RF、DC-DC、晶振）评估屏蔽罩：屏蔽罩必须多点接地（四周地过孔/弹片），不得只焊一角；腔体尺寸要避开谐振（腔体谐振频率与尺寸相关，**需用仿真/公式复核**）；屏蔽罩内的走线/器件不得顶到罩体。
- **为什么**：屏蔽罩接地不良会变成“天线”或形成腔体谐振，反而放大特定频率的辐射/耦合；腔体谐振会恶化隔离度。
- **怎么做**：屏蔽罩四周连续接地，地过孔间距小于最高频率波长的 1/20（按实际复核）；罩内留足净空；进出屏蔽区的信号加滤波/馈通；DC-DC 与 RF 分区屏蔽；屏蔽罩材料/镀层按 EMC 方案选。
- **怎么查**：近场扫描对比加罩前后；暗室测辐射/隔离度；目检接地连续性。不通过 → 改接地/改腔体/加吸波。

### KP-SCH-230 认证测试：按地区标准核对，不凭记忆引用条款

- **判据**：认证项目按目标市场确定（如 FCC Part 15、CE RED、SRRC、MIC/Telec 等）；测试项目通常含传导/辐射骚扰、EIRP、频率误差、占用带宽、杂散、灵敏度等；**具体限值、测试方法与条款号必须查对应标准原文或认证实验室要求**，不得凭记忆写数字。
- **为什么**：不同地区/频段的限值差异大，凭记忆引用会写错；认证失败通常要改硬件（滤波/屏蔽/功率），越早评估成本越低。
- **怎么做**：列出目标市场 → 对应标准与测试项目 → 在原理图阶段预留滤波/屏蔽/功率调整手段 → 认证前做预测试（pre-scan）；把标准原文/实验室要求作为证据归档；软件功率档位可调以留余量。
- **怎么查**：预测试报告与正式认证报告；对照标准原文逐项核对；不通过 → 整改后重测。

## 四、一致性、验证与评审

### KP-SCH-231 天线与匹配的批次一致性

- **判据**：天线与匹配元件必须有批次一致性控制：天线供应商/型号/批次固定；匹配元件精度与 SRF 满足要求；量产抽测 S11/EIRP/灵敏度；换料必须走变更评估（见 `13-documentation-eco.md`）。
- **为什么**：天线是结构敏感件，不同批次/不同供应商的天线效率与谐振点可能偏移；匹配元件容差会移动匹配点，导致部分产品距离变短。
- **怎么做**：BOM 固定天线 MPN 与供应商；匹配元件标精度与 SRF；产线抽测 S11（或 RSSI 距离测试）；换料前做小批验证；把测试数据归档。
- **怎么查**：抽测 S11/TRP/灵敏度分布；对比不同批次；不通过 → 锁定供应商/加严容差/重新匹配。

### KP-SCH-232 谐波、杂散与板级 EMC

- **判据**：发射链路的 2 次/3 次谐波与杂散必须满足认证限值；板级 EMC 要控制：RF 走线辐射、DC-DC 开关噪声、时钟谐波、接地不良形成的共模电流；必要时加低通/带通、磁珠、屏蔽、展频。
- **为什么**：谐波/杂散超标是认证失败的高频原因；DC-DC 与时钟的宽带噪声会抬高底噪、恶化接收灵敏度。
- **怎么做**：按频段计算谐波频率并选滤波器；DC-DC 开关频率避开 RF 接收频段（或加屏蔽/滤波）；时钟走线包地；RF 与数字分区；整机线缆/结构共模电流用共模扼流/接地处理。
- **怎么查**：频谱仪测传导/辐射杂散；近场扫描定位热点；暗室预扫。不通过 → 加滤波/屏蔽/改布局/改频率规划。

### KP-SCH-233 RF 调试记录与证据要求

- **判据**：RF 调试必须留证据：VNA 校准记录、S11/S21 曲线、匹配元件最终值、天线型号与净空照片、EIRP/灵敏度/TRP 测试条件与结果、问题与整改记录；没有证据的“调通了”不算通过。
- **为什么**：RF 结果对测试端面、线缆、夹具、环境极敏感；没有记录无法复现，也无法在换料/改版时判断是否回归。
- **怎么做**：建立 RF 调试记录模板（日期/板号/频点/校准件/测试端面/结果/结论）；保存 VNA 截图与原始数据；匹配最终值写入 BOM 与原理图；整机测试记录含外壳/电池状态。
- **怎么查**：抽查记录完整性；按记录复现关键测试；不通过 → 补记录/重测。

### KP-SCH-234 RF 常见失败模式

- **判据**：以下任一项存在即判 RF 设计高风险：天线净空内有铜/电池/金属；50Ω 走线跨分割或参考地不连续；匹配元件 SRF 不足或精度不够；巴伦/滤波器插损未计入链路预算；RF 与 DC-DC/时钟过近；未预留调试位；无 VNA/暗室测试记录；认证限值凭记忆引用。
- **为什么**：这些失败模式在原理图上“看起来正常”，但会在距离、灵敏度、认证上集中暴露，且整改往往需要改板/改结构。
- **怎么做**：把本清单做成评审勾选项，逐条对照原理图/布局/测试记录；对“需实测/需 datasheet”的项单独列表；不通过 → 整改后复评。
- **怎么查**：评审会逐条打勾并留证；样机做 VNA/暗室/认证预测试；不通过 → 整改并复评。

### KP-SCH-235 天线与结构/外壳的配合

- **判据**：天线性能必须结合整机结构评估：外壳材料（金属/含金属涂层/高介电常数塑料）、电池位置、手部/人体影响、装配公差、天线与外壳的距离；结构变更（换壳/加金属件/改电池）必须重新评估天线。
- **为什么**：天线是整机系统的一部分，裸板测试通过不代表整机通过；外壳与人体会改变谐振与效率。
- **怎么做**：结构评审时把天线净空/位置作为硬约束；打样阶段做裸板 + 整机对比测试；外壳材料与涂层要求写入结构规格；结构变更走 ECO 并触发 RF 复测。
- **怎么查**：整机暗室 TRP/TIS；不同握持/姿态测试；结构变更后的回归测试。不通过 → 改结构/改天线位置/重新匹配。

### KP-SCH-236 RF 设计评审清单

- **判据**：评审必须逐项确认：频段与链路预算、50Ω 走线与参考地、匹配网络与调试位、巴伦/滤波器、天线净空与馈线、连接器与 ESD、时钟相噪、共存与谐波、屏蔽与结构、认证要求、测试记录。每项有计算/仿真/实测/datasheet 证据才算通过。
- **为什么**：RF 问题是跨专业耦合（电路/布局/结构/认证），清单化评审能确保没有遗漏项。
- **怎么做**：用下表逐项打勾；对“需实测/需仿真”的项列出测试计划；问题单记录编号/位置/严重度/整改/证据；评审后重跑相关测试。
- **怎么查**：按表逐项要证据；抽查关键项做实测复现；不通过 → 整改后复评。

| 类别 | 检查项 | 关键判据 | 证据 |
| --- | --- | --- | --- |
| 链路 | 频段/功率/灵敏度/EIRP 预算 | 满足产品与法规目标 | 预算表、实测 |
| 传输线 | 50Ω 线宽、参考地、地过孔 | 阻抗连续、S11 达标 | 阻抗报告、VNA |
| 匹配 | L/π 拓扑、Q、元件 SRF/精度、调试位 | 带宽内 S11 达标、有调试位 | Smith 图、BOM |
| 巴伦/滤波 | 插损、平衡、抑制、功率容量 | 链路预算内 | datasheet、VNA |
| 天线 | 类型、净空、馈线、结构配合 | 净空符合 datasheet、整机效率达标 | 布局图、暗室 |
| 共存 | 谐波/隔离/滤波/屏蔽 | 灵敏度回退在限值内 | 频谱、暗室 |
| 认证 | 地区标准、预测试、余量 | 限值留余量 | 标准原文、预测试报告 |
| 记录 | VNA 校准、最终匹配值、测试条件 | 可复现 | 调试记录 |
