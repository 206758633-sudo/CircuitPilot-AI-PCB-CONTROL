# 电源架构设计：拓扑选择、LDO/Buck 边界、时序与电源域

> **一句话结论**：电源架构的产出不是“几颗稳压芯片”，而是一张**电源树**（输入 → 保护 → 变换 → 负载）加上每个节点的电压、电流、效率、热耗、上电顺序与去耦预算；任何一项没算过，就会在样机阶段以发热、复位、掉压或时序竞争的形式出现。

## 适用范围与边界

| 项 | 内容 |
| --- | --- |
| 适用阶段 | 需求分析 → 电源树设计 → 器件选型 → 原理图绘制 → 电源评审 |
| 输入 | 输入源（USB/适配器/电池/POE）、负载清单（电压/电流/峰值/噪声）、环境温度、成本与尺寸约束 |
| 输出 | 电源树表、选型表、时序表、去耦分配表、热校核记录 |
| 不覆盖 | 保护器件细节（见 `05-protection.md`）、PCB 布局/平面（见 `docs/pcb-layout/`）、具体料号核验（见 `docs/knowledge/components/`） |
| 编号说明 | 本篇知识点编号为 **KP-SCH-019～036** |

## 一、拓扑与选型

### KP-SCH-019 先画电源树，再选器件

- **判据**：原理图开画前必须有一张电源树表，列出每个电源域的：来源、标称/最小/最大电压、稳态电流、峰值电流与持续时间、负载类型（数字/模拟/射频/电机）、允许纹波、上电顺序、去耦预算。缺项不得进入选型。
- **为什么**：电源问题 80% 来自“负载没算清”——峰值电流被当成稳态电流、模拟域和数字域共用一个 LDO、上电顺序没定义。电源树表是后续所有计算（热、压差、线宽、去耦、时序）的唯一输入。
- **怎么做**：
  - 从输入源出发逐级展开，例：`USB 5V → 保护 → 5V 轨 → Buck 3.3V → LDO 1.8V(模拟)`。
  - 每个变换级标注效率、静态电流、最大输出电流、所需外围。
  - 峰值电流按“负载 datasheet 最大值 + 电容充电电流”估算，不用典型值。
- **怎么查**：拿电源树表逐行与原理图核对，确认没有“图上有、表里没有”的电源域；用电子负载/电流探头实测每轨稳态与峰值并回填表格。不通过 → 补齐表格再评审。

### KP-SCH-020 输入级顺序：连接器 → 保护 → 滤波 → 变换

- **判据**：所有外部输入（USB、DC 座、电池、排针）进入板内后，信号必须按“连接器 → ESD/浪涌 → 保险丝/PTC/反接 → π 型滤波 → 变换器”的顺序排列；保护器件必须在连接器与被保护电路之间，不得放在变换器之后。
- **为什么**：保护器件的能量吸收能力有限，放在后级会让浪涌电流先打穿变换器；滤波放在保护前则浪涌直接冲击电容和电感。
- **怎么做**：典型网络链 `VBUS_IN → TVS → F1(保险丝/PTC) → L1+C1/C2(π 滤波) → 反接 P-MOS → 变换器 VIN`；在原理图上按信号流从左到右画，并在连接器旁标注额定电压/电流。
- **怎么查**：按信号流逐级目检顺序；用万用表/示波器确认保护器件两端网络名正确；浪涌测试后检查保护器件是否失效。不通过 → 调整顺序并重新评审（细节见 `05-protection.md`）。

### KP-SCH-021 LDO 与 Buck 的选择边界

- **判据**：用下表判定，**不凭习惯**。核心是功耗与压差：当 `(Vin−Vout)×Iout` 的热耗在目标封装/环境温度下可接受、且 Vin 与 Vout 压差大于 dropout+余量时选 LDO；否则选 Buck。

  | 条件 | LDO | Buck |
  | --- | --- | --- |
  | 压差 `Vin−Vout` | 小（一般 <1~1.5V 且满足 dropout） | 大（>2V 时优势明显） |
  | 输出电流 | 小（几十~几百 mA，受热限制） | 大（数百 mA~数 A） |
  | 效率 | `η ≈ Vout/Vin`（线性） | 85%~95%（开关） |
  | 输出噪声 | 低（µV 级，适合模拟/射频） | 较高（开关纹波，需后级滤波或 LDO） |
  | 外围/成本/EMI | 最少、无 EMI | 需电感+电容+布局，有 EMI |
  | 静态电流 | 可做到 µA 级（电池待机友好） | 轻载效率依赖模式（PFM 等） |

- **为什么**：LDO 是“用压差换噪声”，Buck 是“用开关换效率”。把 12V 降到 3.3V/500mA 用 LDO，热耗 4.35W，任何小封装都撑不住；把 3.3V 降到 1.8V/20mA 用 Buck，则是用复杂度和 EMI 换几乎为零的收益。
- **怎么做**：先按热耗估算（KP-SCH-022）判 LDO 是否可行；噪声敏感负载用“Buck 预降 + LDO 后稳”两级；电池设备优先低 Iq LDO 或支持 PFM 的 Buck。
- **怎么查**：选型表里每个变换级必须有“选型理由”一栏；热校核记录随选型表归档；实测效率与温升回填。不通过 → 换拓扑或改封装/加散热。

### KP-SCH-022 LDO 热耗与结温校核

- **判据**：`Pd = (Vin − Vout) × Iout + Vin × Iq`，`Tj = Ta + Pd × θJA`，要求 `Tj ≤ 0.8 × Tj(max)`（留 20% 余量）；θJA 与 Tj(max) 必须以 datasheet 和实际封装/铜皮为准，不能套用别的封装。
- **为什么**：LDO 的“最大输出电流”是在特定散热条件下给出的，不是无条件指标；忽略热耗是“LDO 一上电就热保护/输出掉压”的根因。
- **怎么做**：
  - 示例：12V→3.3V、Iout=300mA、Iq=5mA：`Pd = (12−3.3)×0.3 + 12×0.005 = 2.61 + 0.06 = 2.67W`。
  - SOT-223 的 θJA 常约 50~80°C/W（需查 datasheet）：ΔT ≈ 2.67×60 = 160°C，Ta=40°C 时 Tj≈200°C，**不可行**。
  - 同负载改 5V→3.3V：`Pd = (5−3.3)×0.3+0.025 = 0.535W`，θJA=60°C/W 时 ΔT≈32°C，可行。
  - 结论：大压差大电流必须先 Buck 预降，或改开关电源，或降低 Iout/加散热铜皮（θJA 随铜面积变化，需按 datasheet 曲线复核）。
- **怎么查**：把 Pd/Tj 计算写入选型表；样机用热电偶/热像仪测壳温与 Tj 估算（`Tj ≈ Tcase + Pd×θJC`）；满载老化 30 分钟看是否热保护。不通过 → 换封装/加铜/改拓扑。

### KP-SCH-023 LDO 压差（dropout）与最低输入电压

- **判据**：`Vin(min) ≥ Vout + Vdropout(max @ Iout) + 余量`，余量按纹波与负载瞬变取 100~300mV（需按 datasheet 的 dropout 曲线复核）；电池供电还必须覆盖电池放电末端电压。
- **为什么**：dropout 随负载电流和温度变化，datasheet 的“典型 200mV”往往是轻载值；轻信典型值会在电池电压下降时输出跌落、MCU 复位。
- **怎么做**：查 datasheet 的 `Vdropout vs Iout` 曲线（取最大负载、最高温度）；电池设备按截止电压反推：如 3.3V 输出、dropout 0.3V，则电池最低需 3.6V 以上，若电池放到 3.4V 就欠压，需改用 Buck-Boost 或降低输出电压。
- **怎么查**：用可调电源从高到低扫 Vin，示波器看 Vout 开始跌落的点，与计算值对比；电池设备做放电曲线测试。不通过 → 换低压差 LDO、改拓扑或调整欠压保护点。

### KP-SCH-024 LDO 稳定性与输出电容选择

- **判据**：输出电容的容值、ESR、介质必须满足 datasheet 的稳定区要求（有的 LDO 要求 ESR 在指定窗口内，有的要求陶瓷电容最小 1µF/10µF）；输入输出电容必须就近放置；不得用“随便一颗 100nF”替代 datasheet 指定的输出电容。
- **为什么**：LDO 是闭环系统，输出电容的 ESR 参与环路零点；ESR 过小或过大都会振荡（表现为输出叠加几十~几百 kHz 纹波、负载瞬变过冲）。
- **怎么做**：按 datasheet 的“典型应用电路”取值，不擅自改容值/介质；需要低 ESR 时选陶瓷电容并确认 LDO 支持；输出电容耐压按 `≥1.5×Vout` 且考虑降额；输入电容 ≥1µF 就近。
- **怎么查**：对照 datasheet 典型电路逐项核对容值与介质；示波器看空载/满载/负载跳变的输出纹波与过冲；必要时做环路（负载阶跃）测试。不通过 → 按 datasheet 改电容或换型号。

### KP-SCH-025 Buck 关键外围：电感、输出电容、反馈分压

- **判据**：电感按纹波电流设计，`ΔIL = (Vin−Vout)×D/(L×fsw)`，`D = Vout/Vin`，取 `ΔIL = 20%~40% × Iout`；电感饱和电流 `Isat ≥ Iout + ΔIL/2`（并留 ≥20% 余量）；反馈分压 `Vout = Vref × (1 + R1/R2)`，分压电阻按 datasheet 推荐范围（通常 10k~100k 量级）选取以兼顾精度与静态功耗。
- **为什么**：电感太小 → 纹波大、损耗高、可能进入断续模式；电感饱和 → 电流失控、烧开关管。反馈电阻取值不当 → 轻载精度差或静态电流大。
- **怎么做**：
  - 示例：12V→5V、fsw=500kHz、L=22µH：`D=0.417`，`ΔIL = (12−5)×0.417/(22µ×500k) = 0.265A`；Iout=1A 时纹波约 26%，合理。若 L=10µH，ΔIL≈0.58A（58%，偏大）。
  - 输出电容按 `ΔVout ≈ ΔIL/(8×fsw×Cout)` 估算纹波，再叠加 ESR 项；陶瓷电容注意直流偏压下降额（实际容值可能只有标称的 50%~70%，需查 datasheet 曲线）。
  - 反馈：Vref=0.8V、目标 5V、R2=10kΩ → R1 = 10k×(5/0.8−1) = 52.5kΩ（取 52.3kΩ 标准值，按 1% 精度）。
- **怎么查**：按 datasheet 的选型公式复核电感/电容；示波器测开关节点与输出纹波；满载测电感温升与是否饱和（电流波形是否出现尖峰）。不通过 → 调整 L/C 或换器件。

### KP-SCH-026 Buck 输入电容与输入纹波电流

- **判据**：输入电容的 RMS 纹波电流 `Icin(rms) ≈ Iout × √(D(1−D))`，所选电容的额定纹波电流（含温度/频率修正）必须大于该值并留余量；输入电容必须紧靠开关管/输入端，回路面积最小。
- **为什么**：Buck 的脉冲电流全部由输入电容提供，纹波电流不足会导致电容发热、寿命下降甚至鼓包；回路面积大则输入环路辐射 EMI。
- **怎么做**：示例 12V→5V、Iout=1A、D=0.417：`Icin(rms) ≈ 1×√(0.417×0.583) ≈ 0.49A`；选 2 颗 10µF/25V X7R 并联（纹波电流按 datasheet 降额），并在原理图上标注“靠近 VIN 引脚”。
- **怎么查**：核对电容 datasheet 的 ripple current 额定值与温度降额；样机测输入电容温升与 VIN 纹波；EMI 预扫看开关频段。不通过 → 加电容/换低 ESR 型号/改布局。

### KP-SCH-027 EN/UVLO 分压与滞回

- **判据**：使能/欠压锁定阈值由分压决定：`V_th = Vin × R2/(R1+R2)`；必须设置滞回（防止输入缓慢上升时反复开关），滞回可通过 EN 引脚内部电流源、外部正反馈电阻或开漏 PG 实现；EN 引脚不得悬空。
- **为什么**：没有滞回的 UVLO 会在输入电压爬升/跌落时反复启停，表现为“上电打嗝”、输出抖动、MCU 反复复位。
- **怎么做**：
  - 示例：EN 阈值 1.2V、希望 Vin=10V 启动：`R2/(R1+R2)=0.12`，取 R1+R2=100kΩ → R2=12kΩ、R1=88kΩ（取 12.1k/88.7k 标准值，1%）。
  - 滞回：若 EN 内部有 5µA 迟滞电流，则 `ΔVin ≈ 5µA × R1`（按 datasheet 公式复核）；或加开漏 PG 反馈。
  - 电池设备 UVLO 必须高于电池过放保护点，避免反复重启。
- **怎么查**：可调电源缓慢升/降输入，测启动点与关断点是否分开（滞回>纹波）；确认 EN 在全程有确定电平。不通过 → 调整分压/加滞回。

### KP-SCH-028 软启动与输入浪涌电流

- **判据**：负载电容充电电流 `Iinrush ≈ C × dV/dt`；若该电流超过输入源/连接器/保险丝能力，必须加软启动（SS 脚电容、缓启动电路、热插拔控制器）或限制负载电容。上电时间 `t ≈ C × Vout / Ilimit`。
- **为什么**：大容量负载电容上电瞬间近似短路，USB 口会限流/掉电、电池会瞬间大电流、连接器会打火；软启动把 dV/dt 压下来是最直接的解法。
- **怎么做**：
  - 示例：Cout=100µF、目标 5V/10ms：`I ≈ 100µ×5/10m = 50mA`；若要求 1ms 上电，则 `I ≈ 500mA`，需确认源能力。
  - 用变换器的 SS 脚外接电容设定斜率（按 datasheet 公式）；无 SS 脚的 LDO 可在 EN 上加 RC 缓启动；热插拔场景用专用控制器（见 `05-protection.md`）。
- **怎么查**：示波器用电流探头/分流电阻测上电输入电流峰值与 Vout 斜率；确认不触发源端限流；保险丝 I²t 能承受启动冲击。不通过 → 增大软启动时间/减小负载电容/换更大保险丝。

### KP-SCH-029 多电源域上电时序与 Power Good

- **判据**：存在多个电源域时必须有明确的上电/掉电顺序，且满足器件 datasheet 的时序要求（常见：IO 电源不早于 core 过多、模拟域与数字域同时或模拟后上、ADC 基准最后上）；需要用 PG（Power Good）或使能链保证顺序，不能只靠“同时上电碰运气”。
- **为什么**：顺序错误会导致 IO 对 core 灌电流（latch-up 风险）、ADC 输入超过电源、总线器件抢先驱动、MCU 启动时外设未就绪。
- **怎么做**：用前级 PG 驱动后级 EN，形成链式启动；或用带 sequencing 的 PMIC/电源监控 IC；RC 延时只用于“保证最小间隔”，不能用于精确顺序；掉电顺序也要考虑（大电容放电慢）。
- **怎么查**：用 4 通道示波器同时抓各轨上升沿，核对顺序与间隔；反复上下电 100 次看是否偶发不启动；核对 datasheet 的 sequencing 表。不通过 → 加 PG 链/改 EN 分压/换 PMIC。

### KP-SCH-030 电源树与去耦分配

- **判据**：去耦按“域”分配：每个 IC 电源脚一颗 100nF；每个域至少一颗 1~10µF 储能；大电流/高速器件按 datasheet 增加容值与数量；去耦电容必须在原理图上归属到具体器件引脚，并在 PCB 上满足 `≤2.0mm`（模组 ≤1.5mm、QFN ≤1.0mm，见 `PWR-01`）。
- **为什么**：去耦是“就近提供瞬态电流、压低电源阻抗”；容值/数量/位置任何一项缺失都会在负载瞬变时表现为掉压、复位、通信误码。
- **怎么做**：建立“电源域 → 器件引脚 → 去耦容值/数量”三列表；100nF 用 0402/0603 小封装（ESL 小），10µF 可用 0805/1206；铁氧体磁珠用于域间隔离时，磁珠两侧各放去耦。
- **怎么查**：统计电源脚数与 100nF 数量是否匹配；PCB 检查每颗去耦到引脚距离；示波器测负载瞬变时电源跌落。不通过 → 补电容/改布局。

### KP-SCH-031 电源域划分与地/回流

- **判据**：电源域按“噪声源/敏感负载/电压/开关”划分；地策略默认单地，只有在回流隔离有明确收益时才分割，且分割地必须有唯一桥接点；高速信号的回流路径不得被分割地切断。
- **为什么**：电源域和地是同一个问题的两面——电流从哪里来回哪里去。分割地不做桥接会让回流绕远路，形成大环路（EMI/串扰）；该分不分则噪声耦合到模拟/射频。
- **怎么做**：噪声源（Buck、电机、继电器）与敏感负载（ADC、射频、晶振）分域；域间用磁珠/0Ω/电源开关隔离并在图上标注；地分割只在明确回流边界处（如隔离侧、ADC 下方）使用，桥接点靠近 ADC 或电源入口。
- **怎么查**：画出每路大电流的回流路径，确认不跨越分割缝隙；用近场探头/示波器测地噪声；核对 PCB 地平面完整性。不通过 → 合并地或补桥接/改布局。

### KP-SCH-032 电池充电拓扑：线性 vs 开关、CC/CV 与热

- **判据**：充电器拓扑按“输入-电池压差 × 充电电流”的热耗选择：线性充电器 `Pd ≈ (Vin−Vbat)×Ichg`（另加 Iq），小电流/小压差可用；大电流或高压差用开关充电器。充电曲线必须为 CC/CV（恒流→恒压），终止电流、再充阈值、充电电流、定时器按电池规格与 datasheet 设置，必须有 NTC 温度保护（JEITA 按需）。
- **为什么**：锂电池过充/过流/高温充电有安全风险；线性充电器在 5V→3.7V、1A 时热耗 1.3W，小封装会热保护降流，表现为“充不满/充电慢”。
- **怎么做**：
  - 充电电流按电池容量与规格设定（常见 0.5C 以内，具体以电池 datasheet 为准）；`Ichg` 由 PROG 电阻设定，公式查充电 IC datasheet。
  - 线性充电示例：5V→3.7V、0.5A：`Pd=(5−3.7)×0.5=0.65W`，θJA=60°C/W 时 ΔT≈39°C，需评估环境温度。
  - NTC 分压接 TS 引脚，按 datasheet 的电阻窗口设置高低温门限；充电指示 LED 串联电阻按 `(Vrail−Vf)/I` 计算。
- **怎么查**：实测充电电流/终止电压/温升；高低温箱做 NTC 保护动作测试；核对电池规格书。不通过 → 调整电流/换开关充电/加散热。

### KP-SCH-033 电池电压与电量检测

- **判据**：电压检测用分压 + ADC，分压比按 ADC 量程与最大电池电压设计，分压电阻总阻值要兼顾精度与漏电（电池长期待机时漏电应远小于电池自放电）；需要更高精度时用库仑计/电量计 IC。ADC 参考电压精度、分压电阻精度、校准方式必须记录。
- **为什么**：分压电阻太小 → 持续漏电，电池放着放着就没电；太大 → 高阻节点易受噪声/漏电流影响，读数漂移。
- **怎么做**：示例：4.2V 最大、ADC 3.3V、取分压比 1/2：R1=100kΩ、R2=100kΩ，最大节点 2.1V；漏电 `4.2/200k = 21µA`，1000mAh 电池理论上可忽略（需按待机预算复核）。ADC 前加 100nF 滤波与 1kΩ 限流；分批采样+中值滤波。
- **怎么查**：用可调电源扫电池电压，对比 ADC 读数与万用表；测待机漏电；核对分压电阻精度与温漂。不通过 → 调整分压/加缓冲/换电量计。

### KP-SCH-034 USB 供电与受电

- **判据**：USB 2.0 受电设备默认从 VBUS 取 ≤500mA（枚举前 ≤100mA）；Type-C 受电端每个 CC 脚接 `Rd = 5.1kΩ ±10%` 到 GND，从 Source 的 Rp 判断可用电流（默认 USB/1.5A/3A 档）；VBUS 必须有过流保护（保险丝/限流开关）与 ESD；需要更高电压/功率时用 PD 控制器协商，不得直接“骗”取。
- **为什么**：CC 脚是 Type-C 的“电流能力协商线”，Rd 缺失或阻值错误会导致 Source 不供电或只给 500mA；过流保护缺失会让故障时 USB 口/线缆过热。
- **怎么做**：
  - Type-C 受电：CC1/CC2 各一颗 5.1kΩ 到 GND（Sink）；VBUS 加 TVS（低电容/大功率）与 ≥1µF 电容；DP/DM 如需 FS 设备上拉 1.5kΩ（或芯片内置）。
  - 过流：自恢复保险丝或限流开关，按最大取电电流 1.5~2 倍选型；VBUS 走线/连接器额定电流要匹配。
  - 仅作供电（不通信）的设备也必须接 CC 的 Rd，否则部分 Source 不输出。
- **怎么查**：接不同 Source（充电器/电脑/PD 电源）实测 VBUS 与可取电流；短路测试过流保护动作；CC 阻值万用表核对。不通过 → 修正 CC/保护/PD 配置（PD 协议细节需按控制器 datasheet 复核）。

### KP-SCH-035 电源指示、测试点与上电验证

- **判据**：每个电源域至少一个测试点（TP）与（可选）电源指示 LED；LED 限流电阻按 `R=(Vrail−Vf)/I` 计算，电流一般 1~5mA（低功耗设备更低）；关键 PG/FAULT 信号要有 TP；上电顺序验证点必须可同时探测。
- **为什么**：没有 TP 的电源域在调试时只能飞线，飞线会引入额外电感/接触电阻，掩盖真实问题；LED 电流过大则待机功耗和亮度都不合适。
- **怎么做**：示例：3.3V 轨、红色 LED Vf≈1.8V、目标 2mA：`R=(3.3−1.8)/2mA=750Ω`（取 750Ω/1kΩ）。TP 命名 `TP_3V3/TP_5V0/TP_PG`；把 TP 集中布置在板边便于探头。
- **怎么查**：对照调试计划检查 TP 是否齐全；测 LED 电流与亮度；上电用示波器按顺序抓各 TP。不通过 → 补 TP/调电阻。

### KP-SCH-036 降额与余量规则

- **判据**：电源相关器件必须按降额使用：电容耐压 ≥1.5×工作电压（电解 ≥1.5~2×）、电感 Isat ≥1.3×峰值电流、二极管/ MOS 耐压 ≥1.3~1.5×最高反向电压、电阻功率 ≥2×实际功耗、连接器电流 ≥1.5×最大电流；具体数值以器件 datasheet 与公司降额规范为准。
- **为什么**：额定值不是工作值；温度、纹波、瞬态都会让实际应力超过计算值，降额是可靠性的最后一道保险。
- **怎么做**：在选型表增加“降额校核”列，逐项填写实际值/额定值/比值；高温环境（>60°C）进一步降额；电解电容注意寿命与纹波电流。
- **怎么查**：选型表逐项核对；样机高温老化后复测关键点电压/电流/温升；不通过 → 换更高规格器件或改拓扑。
