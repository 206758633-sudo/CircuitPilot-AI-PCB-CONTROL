# 模拟 / 音频 / 采样前端设计：分区、麦克风、功放、ADC 与检测

> **一句话结论**：模拟与音频前端的成败由三件事决定——**参考与地是否干净、源阻抗与采样/滤波是否匹配、大信号（功放/DC-DC）是否被隔离在敏感小信号之外**；器件选型只在这三件事之后才有意义。

## 适用范围与边界

| 项 | 内容 |
| --- | --- |
| 适用阶段 | 音频/模拟需求 → 信号链预算 → 前端原理图 → 采样与音频联调 → 评审 |
| 输入 | 传感器/麦克风输出特性、功放与喇叭参数、ADC 采样率/位数/输入结构、电源与地架构、EMC/音频指标要求 |
| 输出 | 信号链与噪声预算表、前端电路（偏置/滤波/缓冲/保护）、功放与喇叭接口、采样校准记录、评审证据 |
| 不覆盖 | 数字音频协议（I2S/PDM/TDM）的时序细节、结构声学与外壳设计、具体料号核验（见 `docs/knowledge/components/`） |

## 一、模拟分区、地与参考

### KP-SCH-110 模拟小信号、音频功率与数字必须分区

- **判据**：原理图与 PCB 必须把四类电路分区：模拟小信号（麦克风、ADC 前端、基准）、音频功率（功放输出、喇叭）、数字（MCU、SPI、时钟）、电源（DC-DC、LDO）。模拟小信号区不得与功放输出、DC-DC 开关节点、高速时钟共享回流路径；跨区信号只在定义好的参考点汇合。
- **为什么**：功放输出电流可达安培级、DC-DC 开关节点 dv/dt 达数十 V/ns，它们在地/电源阻抗上的压降和容性耦合会直接叠加到 µV~mV 级的小信号上；分区是噪声控制的第一性手段。
- **怎么做**：按“电源 → 数字 → 模拟 → 功放”顺序布置；模拟区下方保持完整地平面；功放输出与喇叭线远离麦克风与 ADC 输入；跨区信号用串阻/滤波/差分；在原理图上用模块框与地符号明确分区边界。
- **怎么查**：目检分区与回流路径；用近场探头/示波器测模拟输入上的开关噪声；做“功放满功率 + ADC 采样”的联合测试。不通过 → 调整布局/地/滤波。

### KP-SCH-111 模拟地与单点连接

- **判据**：默认单地；需要分 `AGND/PGND` 时，只在 ADC 或功放的参考点单点汇合，桥接点必须在图上可见（0Ω/磁珠/星点）；高速数字回流不得跨越地分割缝隙；模拟地不得承载功放/电机的返回电流。
- **为什么**：地是参考，不是“零电位”。功放/DC-DC 的大电流在地阻抗上产生 mV 级压降，若与小信号共用一段地，就会被 ADC/麦克风当成信号放大。
- **怎么做**：模拟小信号地汇集到 ADC 的 AGND 引脚；功放/喇叭地单独走线回到电源入口的 PGND；单点桥接放在 ADC 或电源入口；地分割处不跨高速信号；用宽铜/多过孔降低地阻抗。
- **怎么查**：测 AGND 与 PGND 之间的直流/交流压差；ADC 采样时观察地噪声；检查桥接点唯一。不通过 → 改地策略/加桥接/改布局。

### KP-SCH-112 参考电压与 VDDA 处理

- **判据**：ADC 参考（内部 VREF 或外部基准）的初始精度、温漂、噪声必须与目标精度匹配；VDDA/VREF 必须有独立去耦（典型 100nF + 1~10µF）与隔离（磁珠/LC）；外部基准的输出电容、负载电流、开尔文连接按 datasheet；参考电压的误差直接按比例进入所有采样结果。
- **为什么**：ADC 输出码 = `Vin/Vref × 2^N`，Vref 的 1% 误差就是 1% 的增益误差；Vref 上的噪声会直接出现在每个采样码上，且无法靠软件平均完全消除（相关噪声）。
- **怎么做**：内部 VREF 时 VDDA 用磁珠从 3V3 隔离，两侧各 100nF+10µF；外部基准选低噪声、低温漂型号，输出加 datasheet 要求电容，走线远离开关节点；基准地回到 ADC 的 AGND；需要更高精度时用基准 IC + 缓冲。
- **怎么查**：用 6.5 位表测 Vref 实际值与温漂；示波器测 Vref 纹波（AC 耦合、限制带宽）；做零点/满量程校准看偏差是否可被校准吸收。不通过 → 换基准/加滤波/改布局。

### KP-SCH-113 信号链噪声预算：输入参考噪声 RSS 合成

- **判据**：整条链的等效输入噪声按功率（RMS）合成：`e_total = √(e_sensor² + e_amp² + e_adc² + e_ref² + …)`；要求 `e_total ≤ 目标分辨率 / 6`（经验判据，按项目精度要求调整）；每一级的增益要保证后级噪声不被过度放大。
- **为什么**：噪声是功率叠加，不是简单相加；只盯着 ADC 位数而忽略前端/基准噪声，会得到“16 位 ADC 实际只有 11 位有效”的结果。
- **怎么做**：
  - 示例：传感器 10µVrms、运放 5µVrms、ADC 20µVrms → `e_total = √(100+25+400) ≈ 22.9µVrms`；若目标分辨率 100µV，则噪声约为目标的 23%，可接受（按项目要求判定）。
  - 把每级噪声折算到输入端（除以该级之前的增益）；对高阻源注意电阻热噪声 `e_n = √(4kTRB)`（k=1.38e-23、T 为绝对温度、B 为带宽）。
  - 在信号链表里逐级列增益、带宽、噪声、失调，最后合成。
- **怎么查**：用短路输入测输出噪声 RMS（限制带宽到信号带宽）；与预算表对比；不通过 → 降低带宽/换低噪声器件/提高前端增益。

## 二、音频输入：麦克风、偏置与滤波

### KP-SCH-114 麦克风接口：驻极体与 MEMS 模拟输出

- **判据**：驻极体麦克风需要偏置电阻（典型 2.2kΩ 级，按麦克风规格与供电选择）与交流耦合电容；MEMS 模拟麦克风需要干净的 VDD（典型 1.8~3.3V，按 datasheet）与 100nF+1µF 去耦，输出经交流耦合进 ADC/功放；PDM/I2S 数字麦克风不属于模拟前端，其时钟/数据按数字接口规则处理。
- **为什么**：驻极体内部是 JFET/电容结构，偏置电阻同时是负载，阻值影响灵敏度与低频响应；MEMS 内部有电荷泵/放大器，电源噪声会直接调制输出。
- **怎么做**：驻极体：VDD → 偏置电阻 → MIC+，MIC− 接地，输出经 1µF 耦合到放大/ADC；MEMS：VDD 加 100nF+1µF，输出串联耦合电容，必要时加 RC 低通；麦克风地回到模拟地；偏置电阻的电源必须去耦。
- **怎么查**：测麦克风输出偏置点与交流幅度；用声源（1kHz）测灵敏度与频响；换不同电源纹波看输出噪声。不通过 → 调偏置/去耦/换麦克风。

### KP-SCH-115 音频输入交流耦合与高通截止

- **判据**：交流耦合的高通截止 `fc = 1/(2πRC)`；音频输入通常要求 fc ≤ 20Hz（语音可放宽到 100~300Hz），且输入阻抗与耦合电容要匹配；耦合电容的耐压、介质（推荐 C0G/薄膜，避免高容值陶瓷的压电效应）与极性（电解）必须正确。
- **为什么**：耦合电容与输入阻抗构成高通，fc 过高会削掉低频（低音薄）；电容介质不当会引入失真/压电噪声；电解电容反接会漏电/损坏。
- **怎么做**：示例：C=1µF、Rin=10kΩ → `fc = 1/(2π×1µ×10k) ≈ 15.9Hz`；若 Rin=100kΩ，同样 1µF 时 fc≈1.6Hz（但高阻更易拾噪，需权衡）。音频耦合尽量用薄膜/C0G；电解电容正极接直流电位高的一侧。
- **怎么查**：扫频测低频响应（20Hz~20kHz）；测耦合电容两端直流偏压与极性；不通过 → 调整 C/R 或换介质。

### KP-SCH-116 差分模拟输入、共模与单端转差分

- **判据**：差分输入必须确认输入共模范围（含偏置点）、共模抑制比（CMRR）与差分阻抗；单端源转差分可用运放（差分放大器/全差分运放）或变压器；差分对的偏置共模点通常设在 VREF/2 或器件规定的 VCM；差分走线等长、对称、靠近。
- **为什么**：共模超限会让运放/ADC 输入饱和或损坏；CMRR 不足会把电源/地噪声转成差分信号；偏置点错误会让输出削顶。
- **怎么做**：按 datasheet 的 VCM 范围设置偏置（电阻分压 + 缓冲，分压电容去耦）；差分放大器四电阻匹配（0.1% 级）以保证 CMRR；差分对在原理图上成对命名（`AUDIO_IN_P/N`），PCB 上等长对称；单端转差分优先用集成差分放大器。
- **怎么查**：测共模点电压与差分信号；注入共模噪声看输出变化（评估 CMRR）；扫频看幅度/相位平衡。不通过 → 调偏置/换电阻精度/改拓扑。

### KP-SCH-117 音频/模拟输入保护与 ESD

- **判据**：外露的音频/模拟输入（耳机、麦克风、线路输入）必须有 ESD 保护与过压限流：串阻（典型 100Ω~1kΩ）+ 低电容 TVS/ESD 阵列 + 必要时钳位到电源轨；保护器件结电容不能明显影响音频带宽（音频对几 pF 不敏感，但射频/高速 ADC 前要核算）。
- **为什么**：耳机/麦克风接口是人体接触点，ESD 会打坏运放/ADC；无串阻时限流不足，钳位器件也会承受过大电流。
- **怎么做**：连接器 → 串阻 → TVS（低电容）→ 耦合电容 → 放大器；TVS 地就近下模拟地；输入过压用肖特基钳位到 AVDD/AGND（注意漏电与容性）；在图上标注保护器件与地回路。
- **怎么查**：IEC 61000-4-2 接触/空气放电后复测音频指标；测串阻对频响的影响；不通过 → 换低电容 TVS/调串阻/改布局。

## 三、音频功放

### KP-SCH-118 音频功放选型：A/B 类与 D 类边界

- **判据**：按下表选择，不凭“音质传说”。核心是效率、发热、EMI、供电与成本；电池/大功率优先 D 类，小功率/低 EMI 优先 AB 类；D 类必须评估输出滤波器与 EMC。

  | 维度 | A/B 类 | D 类 |
  | --- | --- | --- |
  | 效率 | 低（10%~50%，随功率） | 高（80%~95%） |
  | 发热 | 大，需散热 | 小，封装可更小 |
  | EMI | 低（线性） | 高（开关，需 LC/展频/布局） |
  | 音质/THD+N | 易做好（无开关失真） | 依赖调制与滤波，现代器件已很好 |
  | 供电 | 单/双电源，模拟 | 单电源为主，BTL 常见 |
  | 典型场景 | 小功率耳机/便携 | 蓝牙音箱、电池供电、大功率 |

- **为什么**：A/B 类的效率上限由偏置与输出摆幅决定，大功率时热耗不可接受；D 类效率高但开关边沿产生宽带 EMI，必须用 LC 滤波与布局控制。
- **怎么做**：先算输出功率 `Pout = Vpeak²/(2R)`（正弦、单端）或 BTL 的 `Vpeak²/(2R)`（Vpeak 为输出峰值）；按电源电压、喇叭阻抗、目标功率选型；D 类确认调制频率、是否需要 LC、是否支持无滤波（filterless）并评估 EMC。
- **怎么查**：实测效率、THD+N、输出功率、温升与 EMI 预扫；不通过 → 换类别/换器件/改滤波。

### KP-SCH-119 功放电源去耦与 PVDD/AVDD 分离

- **判据**：功放电源必须“大储能 + 小高频”并联：体电容（数十~数百 µF）吸收音频低频电流，100nF~1µF 靠近 PVDD 引脚抑制开关/高频；PVDD（功率）与 AVDD（模拟前级）之间用磁珠/LC 隔离，避免功放电流调制前级电源；电源走线宽度按峰值电流设计。
- **为什么**：音频是低频大电流信号（20Hz~20kHz），体电容不足会导致低频失真/掉压；功放电流流过共用电源阻抗会串到前级，形成“随音量变化的噪声”。
- **怎么做**：PVDD 引脚旁 100nF+10µF（或按 datasheet），板级 100~470µF 体电容靠近功放；AVDD 用磁珠从 PVDD/系统电源引出并加 100nF+10µF；功放地与喇叭地单独回流到电源入口；大电流走线短而宽。
- **怎么查**：满载低频（如 100Hz）时测 PVDD 纹波与掉压；测前级电源上的音频串扰；温升测试；不通过 → 加体电容/改隔离/改布局。

### KP-SCH-120 D 类功放输出 LC 滤波与 EMI

- **判据**：D 类输出 LC 低通截止 `fc = 1/(2π√(LC))`，应位于音频上限（20kHz）之上、开关频率之下（常见开关频率 300kHz~1.2MHz，需按器件 datasheet）；LC 的 Q 值、电感饱和电流、电容耐压/介质必须匹配；喇叭线双绞、环路面积最小；必要时加磁珠/共模扼流与展频。
- **为什么**：LC 滤除开关载波与边沿，避免 EMI 与喇叭发热；fc 过低会削高频/影响稳定性，过高则滤波不足；电感饱和会导致失真与过流。
- **怎么做**：示例：L=10µH、C=0.47µF → `fc = 1/(2π√(10µ×0.47µ)) ≈ 73.4kHz`，高于 20kHz、低于常见 300kHz 开关频率，合理。电感选饱和电流 > 峰值输出电流并留余量；电容用低 ESR、耐压 ≥ 电源电压；输出走线短、双绞、远离麦克风/ADC；按 EMC 测试结果决定是否加共模扼流。
- **怎么查**：示波器测输出残余开关纹波；EMI 预扫（30MHz~1GHz）；音频频响与 THD 测试；不通过 → 调 LC/加滤波/改布局/降开关频率。

### KP-SCH-121 静音、增益与关断引脚

- **判据**：MUTE/SD（shutdown）/GAIN 等控制脚必须有确定电平（上拉或下拉，按 datasheet 有效电平），不得悬空；上电/掉电时用 MUTE 或 SD 抑制 pop 声，且静音时序要覆盖电源建立与稳定；增益由外部电阻/引脚设置时，阻值与容差按 datasheet 计算。
- **为什么**：控制脚悬空会随机进入静音/关断或最大增益；上电瞬间功放未稳定就输出会产生“砰”声，甚至损坏喇叭。
- **怎么做**：MUTE/SD 默认状态用 10kΩ 上拉/下拉确定；上电时由 RC 或 MCU GPIO 先保持静音，等电源稳定（如 100~500ms）后再释放；掉电时先静音；GAIN 脚按 datasheet 接固定电阻/分压，不要悬空；控制信号远离开关节点。
- **怎么查**：反复上下电听/测输出 pop 幅度；测控制脚电平与静音时序；不通过 → 调 RC/加静音控制/改默认电平。

### KP-SCH-122 功放输出保护：短路、过流、过热与直流

- **判据**：功放必须评估：输出对地/对电源短路、过流、过热、直流偏移（DC offset）保护；喇叭保护可用功放内置保护 + 外部直流检测/继电器/保险；单端输出必须用隔直电容（除非确认无直流），BTL 输出不得对地短路。保护动作后应可恢复或有明确故障指示。
- **为什么**：输出短路/直流偏移会让喇叭音圈过热烧毁；BTL 输出对地短路会瞬间大电流损坏功放；没有保护时一次故障就报废整机。
- **怎么做**：选带 OCP/OTP/短路保护的功放；单端输出串联隔直电容（`fc = 1/(2πRC)`，如 8Ω+470µF→42Hz）；BTL 不加隔直电容但严禁输出对地短路；需要高可靠时加喇叭保护 IC（直流检测 + 继电器/MOS 切断）；故障指示 LED/FAULT 引脚接 MCU。
- **怎么查**：做输出短路/过流/过热测试，确认保护动作且可恢复；测输出直流偏移；不通过 → 加保护/换器件/改拓扑。

## 四、喇叭与耳机接口

### KP-SCH-123 喇叭接口与走线

- **判据**：喇叭连接器与走线按峰值电流选型（`Ipeak = Vpeak/R`）；单端输出必须有隔直电容，BTL 不需要；喇叭线双绞、环路面积最小、远离麦克风与天线；走线宽度与连接器额定电流要覆盖峰值并留余量；喇叭地单独回流。
- **为什么**：喇叭是低阻大电流负载，走线电阻会造成功率损失与失真；大环路会辐射/接收 EMI；与麦克风并行会形成啸叫/串音。
- **怎么做**：BTL：`SPK+ / SPK−` 双绞直接到连接器；单端：功放输出 → 隔直电容 → 喇叭 → 地；连接器 pin 定义标注正负；走线宽度按 1A 约需 0.5mm（外层，需按温升/铜厚复核）；喇叭线远离模拟输入与射频。
- **怎么查**：满载测喇叭端电压/电流与温升；测串音与啸叫；EMI 预扫；不通过 → 加宽走线/改双绞/改布局。

### KP-SCH-124 耳机接口与插入检测

- **判据**：耳机输出需隔直电容与串联限流电阻（典型 10~33Ω，按器件与耳机阻抗选）；插入检测（jack detect）引脚要有上拉/下拉与去抖；耳机地与麦克风地按连接器定义处理；ESD 保护必须加；耳机输出功率小，注意与喇叭输出的切换（如有）。
- **为什么**：耳机阻抗低（16~32Ω），隔直电容防直流损坏耳机；无串联电阻时短路/插拔瞬态电流大；插入检测错误会导致“插耳机喇叭还响/不响”。
- **怎么做**：输出 → 隔直电容（如 100µF/16Ω→100Hz 左右，按目标低频算）→ 串阻 → 连接器；jack detect 用 GPIO + 上拉，加 RC 去抖与 ESD；耳机地与模拟地单点连接；切换用模拟开关/继电器并注意 pop。
- **怎么查**：插拔测试检测电平与音频切换；测低频响应与直流偏移；ESD 测试；不通过 → 调电容/检测电路/保护。

## 五、ADC 前端

### KP-SCH-125 ADC 分压与源阻抗

- **判据**：分压后的源阻抗（戴维南 `R = R1||R2`）必须满足 ADC datasheet 对最大源阻抗/采样时间的要求；分压电阻兼顾漏电与噪声：电池检测等低功耗场景可用高阻（100k~1MΩ）+ 必要时用 MOSFET 切换分压网络；分压比按最大输入与 VREF 设计并留余量。
- **为什么**：SAR ADC 采样时对采样电容充电，源阻抗过大导致采样不足（读数偏低/非线性）；分压电阻太小则持续漏电、增加功耗。
- **怎么做**：示例：4.2V 电池、VREF=3.3V、R1=R2=100kΩ → 最大 2.1V，源阻抗 50kΩ（偏高，需核算采样时间或加缓冲）；漏电 `4.2V/200kΩ = 21µA`；需要低功耗时加分压使能 MOS，仅在采样时打开。
- **怎么查**：用高阻源+不同采样时间扫输入，看读数是否随采样时间变化；测待机漏电；不通过 → 降阻/加缓冲/改采样时间/加分压开关。

### KP-SCH-126 采样时间与保持电容计算

- **判据**：采样时间必须满足 `ts ≥ (Rsource + Rmux) × Csh × ln(2^(N+1))`（SAR ADC 常用模型，N 为位数；系数按 datasheet 公式，可能含额外项）；计算后至少留 2 倍余量；Rsource 包含分压、串阻、传感器输出阻抗。
- **为什么**：采样电容没充满就转换，会得到偏低的码值；源阻抗越大所需采样时间越长，二者必须匹配。
- **怎么做**：示例：12 位、Csh=8pF、Rsource=10kΩ → `ts ≥ 10k×8p×ln(2^13) = 10k×8p×9.01 ≈ 721ns`；若 Rsource=50kΩ → 约 3.6µs，需显著降低采样率或加缓冲。优先用运放缓冲把源阻抗降到 <1kΩ。
- **怎么查**：改变采样时间/采样率看读数稳定性；用已知电压源对比万用表；不通过 → 加缓冲/降源阻抗/加长采样时间。

### KP-SCH-127 RC 抗混叠滤波

- **判据**：ADC 前必须有抗混叠低通，截止 `fc = 1/(2πRC)` 低于 `fs/2`（实际按所需衰减与信号带宽取，音频常取 20kHz 附近）；单阶 RC 衰减不够时用二阶（Sallen-Key/多反馈）；滤波电阻会与 ADC 采样电容相互作用，需同时满足 KP-SCH-126 的采样时间。
- **为什么**：高于 fs/2 的成分会混叠到带内且无法用软件去除；单阶 RC 在 fs/2 处衰减有限，需要按目标衰减量选阶数。
- **怎么做**：示例：fs=48kHz、目标 fc≈20kHz：取 R=1kΩ、C=8.2nF → `fc ≈ 19.4kHz`；若需要 40dB 衰减，需二阶以上（按滤波器设计工具/公式）。R 不宜过大（影响采样），C 用 C0G/薄膜保证线性；滤波前后加缓冲按需。
- **怎么查**：扫频测幅频响应；注入带外信号看混叠；不通过 → 加阶数/调 fc/加缓冲。

### KP-SCH-128 运放缓冲与驱动

- **判据**：ADC 前缓冲运放需满足：输入共模/输出摆幅覆盖信号范围（轨到轨按需）、带宽 ≥ 信号带宽 × 增益 × 余量、输出阻抗足够低以驱动采样电容、噪声与失调在预算内、容性负载稳定（必要时串隔离电阻）。
- **为什么**：运放输出阻抗与 ADC 采样电容形成 RC，直接影响建立时间；带宽不足会导致高频失真；容性负载会让运放振荡。
- **怎么做**：选低噪声、轨到轨、GBW 足够的运放；输出串 10~100Ω 隔离 ADC 容性负载；反馈电阻按噪声/带宽权衡；单电源时用 VREF/2 偏置并加去耦；缓冲器电源与 ADC 电源同域并去耦。
- **怎么查**：测缓冲输出阶跃建立时间与过冲；扫频测 THD/带宽；示波器看是否振荡；不通过 → 换运放/加隔离电阻/调偏置。

## 六、电池电压/电流检测与校准

### KP-SCH-129 电池电压检测

- **判据**：电池电压检测用分压 + ADC（或专用电量计）；分压比覆盖满电到截止电压并留余量；分压电阻的漏电必须纳入待机预算；ADC 参考精度、分压电阻精度（建议 0.1%~1%）、温漂决定电压测量精度；高精度场景用库仑计/电量计。
- **为什么**：电池电压是电量估算与保护判据的输入；分压误差直接变成电量误差；高阻分压受 ADC 输入漏电影响。
- **怎么做**：示例：4.2V 满电、VREF 3.3V，取分压比 1/2（R1=R2=100kΩ），最大 2.1V；加 100nF 滤波与 1kΩ 限流；低功耗设备用 MOS 开关分压，采样时导通；校准用实际电压两点法（见 KP-SCH-131）。
- **怎么查**：可调电源扫 3.0~4.2V，对比 ADC 读数与万用表；测待机漏电；高低温复测；不通过 → 调分压/加校准/换电量计。

### KP-SCH-130 电流检测：低边与高边采样

- **判据**：低边采样（分流电阻在地侧）成本低、共模低，但会破坏负载地参考；高边采样（分流在电源侧）保持地完整，但需要高共模抑制的电流检测放大器/电平转换。分流电阻按 `P = I²×Rshunt` 与压降预算选型（压降通常 10~100mV，需按精度与功耗权衡）；走线必须开尔文连接。
- **为什么**：低边采样会把负载地抬高，影响与其他电路的共地；高边采样的共模电压接近电源，普通运放无法直接处理；分流电阻功耗/温漂直接影响精度。
- **怎么做**：示例：I=2A、Rshunt=10mΩ → 压降 20mV、功耗 40mW；若 ADC 量程 1V，需要增益 50 的电流检测放大器。低边：分流电阻在地与负载地之间，注意负载地不再等于系统地；高边：用高共模电流检测放大器，输出经 RC 进 ADC；开尔文走线从分流电阻焊盘内侧引出。
- **怎么查**：用电子负载/已知电流源校准；测不同电流下的线性度与温漂；检查共模/地偏移；不通过 → 改采样方式/换放大器/调分流电阻。

### KP-SCH-131 采样校准：偏移、增益与两点法

- **判据**：每个关键模拟通道应有校准方案：零点（偏移）与满量程（增益）至少两点校准；校准基准必须可溯源（高精度表/基准源）；校准系数存储（EEPROM/Flash）并带版本；温漂大的通道需多点/温度补偿（按需）。
- **为什么**：分压电阻容差、基准误差、运放失调都会造成系统误差；两点校准能同时修正偏移与增益，把误差压到校准源精度水平。
- **怎么做**：在产线/实验室用两个已知输入（如 0V 与 90% 满量程）记录 ADC 码，计算 `y = a×x + b`；把 a/b 写入非易失存储；校准记录含日期、设备、环境温度、操作者；对电池电压/电流通道分别校准。
- **怎么查**：校准后回测 3~5 个点，误差应在目标内；换板抽检一致性；不通过 → 重新校准/检查硬件。

## 七、精度、噪声与布局评审

### KP-SCH-132 采样精度与噪声预算：ENOB、地反弹、数字串扰

- **判据**：用 `SNR_ideal = 6.02N + 1.76 dB` 与 `ENOB = (SINAD − 1.76)/6.02` 评估实际有效位数；地反弹（数字回流在地阻抗上的压降）、数字串扰（SPI/时钟对模拟输入的容性/感性耦合）、参考噪声都会降低 ENOB；平均 N 次可改善随机噪声 √N，但对相关噪声/地反弹无效。
- **为什么**：标称位数不等于有效位数；12 位 ADC 在噪声/地反弹下可能只有 10~11 位 ENOB，直接决定测量精度。
- **怎么做**：示例：12 位理想 SNR≈74dB；若实测 SINAD=68dB，则 `ENOB=(68−1.76)/6.02≈11.0 位`。预算表列出各噪声源，优先治理地反弹与串扰（布局/去耦/隔离），再考虑平均；数字信号远离开关节点与模拟输入，必要时加屏蔽/包地。
- **怎么查**：用 FFT 测 SINAD/THD/SNR；短路输入测噪声底；对比“数字静默/数字繁忙”两种状态的采样结果；不通过 → 改布局/加屏蔽/降采样率/换基准。

### KP-SCH-133 模拟走线布局要点

- **判据**：模拟走线短、直、少过孔；模拟输入远离 DC-DC 电感/开关节点、时钟、功放输出；敏感节点包地（guard）并单点接地；模拟地与数字地按分区策略汇合；去耦电容靠近引脚；差分对等长对称；高阻节点加保护环/缩短走线。
- **为什么**：模拟走线是“天线”，长度与环路面积决定耦合量；包地与短走线能显著降低串扰；去耦位置决定高频回流路径。
- **怎么做**：先放模拟器件再放数字/功率；模拟区下方完整地平面；麦克风/ADC 输入走线尽量短并包地；DC-DC 与功放远离模拟区；晶振/时钟远离模拟输入；过孔远离高阻节点；按“信号流从左到右”布置。
- **怎么查**：目检走线长度/环路/包地；近场探头扫描；联合测试（功放+ADC+数字）看噪声；不通过 → 改布局/加屏蔽/改地。

### KP-SCH-134 模拟/音频评审清单

- **判据**：评审必须逐项确认：分区与地策略、参考/VDDA 去耦、麦克风偏置与耦合、输入保护、功放选型与电源去耦、D 类 LC/EMI、静音/增益/保护、喇叭/耳机接口、ADC 分压/源阻抗/采样时间、抗混叠、缓冲、检测校准、噪声预算、布局要点。每项有证据（计算/波形/datasheet 页码）才算通过。
- **为什么**：模拟问题的特点是“单看每项都对，合起来出问题”；清单化评审能把跨项耦合（如功放电流调制前级、数字串扰 ADC）纳入检查。
- **怎么做**：用下表逐项打勾；对“需实测”的项单独列测试计划；问题单记录编号/位置/严重度/整改/证据；评审后重跑相关测试。
- **怎么查**：按表逐项要证据；抽查 3 项做实测复现；不通过 → 整改后复评。

| 类别 | 检查项 | 关键判据 | 证据 |
| --- | --- | --- | --- |
| 分区/地 | 模拟/数字/功放分区、单点桥接 | 回流不共路径、桥接唯一 | 布局截图、地压差 |
| 参考 | VREF/VDDA 去耦与隔离 | 噪声/精度满足预算 | 纹波波形、Vref 实测 |
| 输入 | 麦克风偏置、耦合 fc、保护 | fc≤20Hz（音频）、ESD 通过 | 频响、ESD 记录 |
| 功放 | 选型、PVDD 去耦、LC、静音、保护 | 效率/THD/EMI/温升达标 | 实测曲线、EMI 预扫 |
| 喇叭/耳机 | 隔直、串阻、走线、检测 | 无直流、无啸叫、检测正确 | 波形、插拔测试 |
| ADC | 分压、源阻抗、采样时间、抗混叠、缓冲 | ts≥计算值×2、fc<fs/2 | 计算表、扫频 |
| 检测 | 电压/电流采样、校准 | 两点校准后误差达标 | 校准记录、回测 |
| 精度 | 噪声预算、ENOB、地反弹、串扰 | ENOB 满足目标 | FFT、静默/繁忙对比 |
