# 电池与 BMS 设计：充电、保护、电量计、均衡、热安全与认证证据

> **一句话结论**：电池系统的设计目标是**“在电芯允许的电压/电流/温度窗口内工作，并且在任何单点失效下都不越过安全边界”**；充电 IC、保护板、电量计、BMS 各管一段，必须先把职责边界与保护层级画清楚，再谈器件选型。

## 一、系统架构与充电

### KP-SCH-187 电池系统架构：充电、保护、电量计、BMS 的职责边界

- **判据**：画图前必须把四层职责写清楚，缺一层就存在“单点失效即越界”的风险：①**充电控制**（CC/CV、终止、温度窗口、输入限流）；②**一次保护**（OVP/OCP/SCP/OTP，独立于充电 IC，通常为保护板/AFE + 双 MOS）；③**二次保护**（一次性保险丝/PTC/化学 CID，不可复位，兜底）；④**计量与均衡**（SOC/SOH、均衡）。多串系统还必须有 AFE 采样与断线检测。
- **为什么**：充电 IC 失效（过充）时只有一次保护能切断；一次保护 MOS 短路时只有二次保护（保险丝）能兜底；把“保护”和“充电”混在一个芯片里而不做冗余，是电池安全事故最常见的架构缺陷。
- **怎么做**：
  - 画架构图：`输入 → 输入保护 → 充电 IC → 电池（含保护板）→ 系统负载`；标出每一层的保护对象与阈值。
  - 1S 便携产品可用“充电 IC + 保护板（含双 MOS + 控制 IC）”+ 电池自带 PTC/保险丝；多串用 AFE/保护 IC + 外部均衡 + 独立二次保护。
  - 明确“谁能在异常时切断电流”“谁能复位”“谁只报警不切断”，并写进设计说明。
  - 保护层级与阈值必须协调（见 KP-SCH-200），避免“一次保护动作前二次保护已断”或反之。
- **怎么查**：按失效模式表逐项推演（充电 IC 短路、MOS 短路、采样断线、过温），确认每层保护动作与结果；对照 `02-power-architecture.md` KP-SCH-032/033。不通过 → 补层级/改阈值/加冗余。
- **依据**：`PCB-RULE-CHARGER-001`；电芯 datasheet 的充放电窗口；`02-power-architecture.md` 的电源树与充电拓扑。

### KP-SCH-188 充电拓扑：线性与开关的边界与热耗

- **判据**：充电拓扑按“热耗 + 效率 + 输入电压差”选择，不凭习惯：线性充电 `P_loss = (Vin − Vbat) × I_charge`，必须校核结温 `Tj = Ta + P × θJA`（θJA 按封装/铜皮/散热焊盘，datasheet 给值）；开关充电效率高但需电感/输入输出电容与 EMI 处理；压差大/电流大/密封外壳优先开关方案，小电流/低成本/低噪声优先线性方案。
- **为什么**：线性充电把压差全部变成热——5V 输入、1A、4.2V 电池就有 0.8W；SOT-23/SOIC 封装的 θJA 动辄 50~100°C/W，结温很容易超过 125°C 触发热调节，充电变慢甚至过热。**失败模式**：热耗超过封装/铜皮散热能力时，充电 IC 反复触发热调节甚至热关断，表现为“高温环境永远充不满、外壳发烫”，长期还加速器件老化。
- **怎么做**：
  - 示例：`Vin=5V、Vbat=4.2V、I=1A` → `P=(5−4.2)×1=0.8W`；若 `θJA=50°C/W`、`Ta=40°C` → `Tj≈40+40=80°C`，可接受；若封装 θJA=100°C/W 则 `Tj≈120°C`，接近上限，必须降流/改开关方案/加散热铜皮。
  - 开关充电：按 `η` 估算输入电流 `Iin = (Vbat × I)/ (Vin × η)`，选电感饱和电流 > 峰值，输入/输出电容按纹波电流选；布局按 Buck 的功率回路最小原则（见 `02-power-architecture.md` KP-SCH-026 与 `PCB-RULE-PLACE-DCDC-001`）。
  - 充电 IC 的散热焊盘按 `PCB-RULE-THERMAL-001` 打过孔阵列；热调节（thermal regulation）阈值按 datasheet，不能长期依赖它工作。
  - 多串/大电流（>2A）：优先开关充电 + 独立保护；线性方案只在小电流/低压差场景。
- **怎么查**：满载充电测 IC 表面/结温（`Tj` 用热像仪或 datasheet 的热阻换算）；高温环境（如 45°C）复测充电电流是否被热调节；效率测试。不通过 → 降流/加铜/改拓扑。
- **依据**：充电 IC datasheet 的 θJA、热调节、最大充电电流与效率曲线；`PCB-RULE-THERMAL-001`。

### KP-SCH-189 CC/CV、预充、终止与温度窗口（JEITA）

- **判据**：锂电池充电必须按“预充（涓流）→ 恒流（CC）→ 恒压（CV）→ 终止”流程，并叠加温度窗口：终止电压必须与电芯化学体系一致（4.2V/4.35V/4.4V 不可混用，`PCB-RULE-CHARGER-001`）；预充电流/阈值（深度放电时）、CC 电流（常见 0.5C 级，按电芯规格）、CV 终止电流（常见 C/10 级，按规格）、定时器/安全定时、JEITA 温度分区（低温/高温降流或禁止，区间按电池规格）。
- **为什么**：过充会析锂/产气/热失控；低温充电会析锂（尤其 <0°C）；高温充电加速老化；预充缺失会让深度放电电芯大电流充电发热；终止电流过大会充不满、过小会延长充电且可能无法终止。
- **怎么做**：
  - 充电时间估算：`t_CC ≈ C × (V_CV − V_start)/I_CC`；示例 `2000mAh、1A、3.0V→4.2V` → `t_CC ≈ 2Ah × 1.2V/1A = 2.4h`，CV 阶段再叠加（终止电流 C/10 时通常再加 0.3~0.6h，按实测）。
  - 温度窗口：按电池规格设 JEITA 分区（如 0~10°C 降流、<0°C 禁止、>45°C 降流/停止，**具体区间与电流系数必须按电芯规格复核**）；NTC 采样与充电 IC 的 TS 引脚分压匹配（见 KP-SCH-196）。
  - 安全定时：`t_safety ≈ 1.5~2 × 预计充满时间`，超时强制终止并报故障。
  - 终止电压精度：按 `PCB-RULE-CHARGER-001` 与电芯规格，±1% 级（4.2V 对应 ±42mV，需按 IC 精度与校准复核）。
- **怎么查**：用电子负载/电池模拟器扫充电曲线，核对预充/CC/CV/终止点；高低温箱验证 JEITA 分区；过放电池测试预充。不通过 → 改参数/换充电 IC/改 NTC 网络。
- **依据**：电芯 datasheet 的充电规格（电压/电流/温度）；`PCB-RULE-CHARGER-001`；JEITA 类温度分区（按电池厂推荐/标准复核）。

### KP-SCH-190 充电输入：限流、动态电源管理与输入保护

- **判据**：充电输入必须校核：输入限流（适配器/USB 端口能力，USB 2.0 500mA、USB-C/PD 按协商，需按规范复核）、动态电源管理（DPM：输入电压跌落时自动降充电电流，避免适配器过载/掉电）、输入保护（反接/过压/浪涌/ESD，见 `05-protection.md`）、输入电容与软启动（避免插入瞬间浪涌）、输入电压范围覆盖适配器容差与线损。
- **为什么**：适配器能力不足时，充电电流会把输入电压拉塌，导致系统复位/适配器保护；没有 DPM 的系统在弱适配器上表现为“插上就重启”；输入浪涌会损伤充电 IC 或触发适配器保护。
- **怎么做**：
  - 输入限流按适配器额定 80% 设置（如 5V/1A 适配器设 800mA），并留 USB-C 协商后的余量；USB-C 受电按 `04-interfaces.md` KP-SCH-066/068 处理 CC/PD。
  - DPM 阈值按系统最低工作电压设置（如 `VIN_DPM = 4.5V`），跌落时优先保系统、降充电电流。
  - 输入保护：TVS/ESD + 过压保护（OVP）+ 反接保护（P-MOS/理想二极管，见 `05-protection.md` KP-SCH-080/081）；输入电容按纹波/浪涌选，软启动限制 `di/dt`。
  - 输入走线/连接器按最大输入电流选型，压降计入 DPM 阈值。
- **怎么查**：用可调电源模拟弱适配器（限流/掉压）看系统是否复位、充电电流是否自动下降；插拔浪涌测试；反接/过压测试。不通过 → 改限流/DPM/加保护。
- **依据**：充电 IC datasheet 的输入限流/DPM/OVP 阈值；`05-protection.md` 的输入保护顺序；USB 规范（按版本复核）。

## 二、保护、计量与均衡

### KP-SCH-191 1S 保护板：OVP/OCP/SCP/OTP 与双 MOS 选型

- **判据**：1S 保护板必须覆盖：过充（OVP，典型 4.25~4.35V 级，按电芯规格）、过放（UVP，典型 2.4~3.0V 级）、充电/放电过流（OCP）、短路（SCP，延时 µs~ms 级）、过温（OTP，配合 NTC）；双 MOS 背靠背串联（见 KP-SCH-198），`Rds(on)` 与封装按最大持续电流选型并校核发热 `P = I² × (Rds_chg + Rds_dis)`；保护 IC 的延时/阈值按 datasheet，不能只看典型值。
- **为什么**：保护板是电芯的最后一道电气防线；MOS `Rds(on)` 选大 → 正常工作时就发热/压降大；阈值/延时不当 → 正常负载误保护或短路时来不及切断。
- **怎么做**：
  - 示例：`I=5A、双 MOS 各 20mΩ` → `P = 25 × 0.04 = 1W`，需要足够铜皮/散热；若用 10mΩ 各，则 0.5W。
  - 阈值：OVP/UVP 按电芯规格并留测量误差余量（保护 IC 精度常见 ±25~50mV 级，按 datasheet 复核）；OCP 按最大持续电流的 1.5~2 倍、延时避开启动浪涌；SCP 延时尽量短（µs~ms）。
  - NTC 贴近电芯/ MOS，按 KP-SCH-196 设计分压与断线检测。
  - 保护 IC 的供电/采样走线开尔文，避免大电流路径的压降影响阈值。
- **怎么查**：用电池模拟器/电子负载逐项触发 OVP/UVP/OCP/SCP/OTP，测动作阈值与延时；满载测 MOS 温升与压降；不通过 → 调阈值/换 MOS/改散热。
- **依据**：保护 IC datasheet 的阈值/延时/精度；MOSFET datasheet 的 Rds(on) 与热阻；电芯规格的电压/电流窗口。

### KP-SCH-192 多串电池 AFE 采样与断线检测

- **判据**：多串（≥2S）系统必须用 AFE/保护 IC 逐节采样：每节采样走线开尔文、RC 滤波（`fc` 按采样率与噪声选）、采样精度（AFE 的电压测量误差 + 分压/滤波误差）要满足保护阈值精度；必须支持**断线检测**（采样线断开时不能误判为正常电压）；节间均衡与采样共用走线时注意共阻抗串扰（见 KP-SCH-206）。
- **为什么**：多串系统的过充/过放保护依赖逐节电压；采样线断一根，AFE 可能读到 0V 或虚高，导致保护误动/拒动；滤波过强会让保护响应变慢。
- **怎么做**：
  - 每节采样：`R_filter`（典型 100Ω~1kΩ）+ `C`（典型 10~100nF）低通，`fc = 1/(2πRC)`；示例 `1kΩ、100nF → fc≈1.59kHz`，远高于保护响应需求、又能滤开关噪声。
  - 采样线从电芯连接器/镍片开尔文引出，电流路径与采样路径分开；采样线成对/相邻走线，远离功率回路。
  - 断线检测：按 AFE datasheet 的断线检测机制（注入电流/比较器），并在软件侧做“相邻节电压突变/不合理”交叉校验。
  - 采样精度：AFE 的 VOS/增益误差 + 外部 RC/分压误差，按最坏情况折算到 mV 级，与 OVP/UVP 余量比较。
- **怎么查**：逐节注入已知电压（电池模拟器）核对读数；断开任一采样线看是否报断线；高低温复测；不通过 → 改滤波/改走线/换 AFE。
- **依据**：AFE datasheet 的采样精度、断线检测、滤波建议；`08-analog-signal-chain.md` KP-SCH-142/144（采样建立与过压保护）。

### KP-SCH-193 电量计选型：库仑计、电压法与阻抗跟踪

- **判据**：按精度需求与成本选电量计：**电压法**（OCV/SOC 查表）便宜，但锂电池 3.6~3.8V 平台区 `dOCV/dSOC` 极小，负载/温度变化会造成大误差；**库仑计**（Rsense 积分）在中高精度场景主流，需校核 Rsense 精度/温漂、ADC 失调与积分漂移；**阻抗跟踪/模型法**（如带电池模型的电量计）精度高但需配置电池参数与学习周期。任何方案都要有初始 SOC 与满充/满放校准点。
- **为什么**：SOC 误差直接决定“会不会突然关机/过充过放”；平台区电压法误差可达 ±10%~20%，库仑计的失调会随时间累积（`误差 = I_offset × t`），模型法依赖参数准确性。
- **怎么做**：
  - 库仑计误差示例：`ADC 失调 50µV、Rsense=5mΩ` → 等效电流误差 10mA；若系统平均待机电流 10mA，误差 100%，必须选低失调器件/更大 Rsense/周期性校准；`Rsense=1mΩ` 时同样 50µV → 50mA 误差，更差。
  - Rsense：按 `P = I²R` 与压降选（典型 1~10mΩ），开尔文走线（`PCB-RULE-SHUNT-001`），温漂按 ppm/°C 折算到 SOC 误差。
  - 校准：满充（CV 终止）与满放（UVP）作为 100%/0% 锚点；阻抗跟踪方案按电池 datasheet 配置模型参数。
  - 低功耗设备：待机电流可能小于电量计分辨力，需评估“小电流丢失”并做补偿/休眠策略。
- **怎么查**：用电池模拟器/实际电池做充放电循环，对比电量计 SOC 与库仑积分真值；测待机小电流累积误差；高低温复测；不通过 → 换方案/改 Rsense/加校准。
- **依据**：电量计 datasheet 的电流/电压测量精度、失调、Rsense 要求；电芯 datasheet 的 OCV-SOC 曲线（平台区斜率）。

### KP-SCH-194 SOC 估算误差预算与学习

- **判据**：SOC 误差必须做预算：容量误差（电芯标称/老化/温度）、电流测量误差（失调+增益+温漂）、积分时间、初始 SOC 误差、自放电/小电流丢失；各项 RSS 或最坏情况合成后与产品要求（常见 ±5%~±10%，按产品定义）比较；必须有“学习/修正”机制（满充/满放/静置 OCV 修正），否则误差只增不减。
- **为什么**：库仑计是开环积分，任何小偏差都会累积；没有修正机制的电量计在几次部分充放后就会明显跑偏。
- **怎么做**：
  - 误差示例：容量 ±3%、电流增益 ±2%、失调等效 1% 满量程、初始 SOC ±5% → RSS 约 `√(9+4+1+25) ≈ 6.2%`，已接近 ±5% 目标，必须加修正。
  - 修正点：满充（CV 终止 + 温度补偿）、静置 OCV（平台区外）、满放（UVP）；记录学习值并按老化更新容量。
  - 温度：低温容量下降、内阻上升，SOC 显示需按温度修正（按电芯 datasheet）。
  - 显示策略：低电量提前告警/分级降功耗，避免“显示 5% 突然关机”。
- **怎么查**：多循环（至少 5~10 次部分充放）对比 SOC 漂移；低温/高温循环；与库仑真值对比。不通过 → 加修正点/换电量计/调参数。
- **依据**：电芯 datasheet 的容量-温度/老化曲线；电量计 datasheet 的学习算法说明；产品 SOC 精度要求。

### KP-SCH-195 均衡：被动与主动、均衡电流与热

- **判据**：多串电池必须评估均衡：被动均衡（电阻放电，成本低、效率低、发热）适合小容量/小失衡；主动均衡（电感/电容/变压器搬能量）效率高但复杂、成本高；均衡电流按失衡速率与均衡时间选：`t_balance ≈ ΔQ / I_balance`；被动均衡电阻功率 `P = Vcell²/R` 与 PCB 温升必须校核；均衡阈值/启停条件（电压差/静置/温度）要明确。
- **为什么**：不均衡会让 weakest cell 先到截止，整包容量下降；被动均衡电流过小则永远均衡不完，过大则发热/耗电；均衡在充电/静置时进行更安全（避免放电时加剧失衡）。
- **怎么做**：
  - 示例：`Vcell=3.7V、R=37Ω → I≈100mA、P=0.37W`；若失衡 100mAh → `t ≈ 0.1Ah/0.1A = 1h`（不含效率与占空比）。
  - 被动均衡：电阻/ MOS 按电流与功耗选，布局远离温度敏感器件；均衡时监控温度，超温暂停。
  - 主动均衡：按拓扑选器件（电感饱和电流、电容耐压、开关损耗）；注意 EMI 与采样串扰。
  - 策略：仅在充电/静置且电压差 > 阈值时均衡；低温/高温窗口内禁止或降流（按电芯规格）。
- **怎么查**：人为制造失衡（单节多充/少充）看均衡效果与时间；测均衡电阻/MOS 温升；测均衡对采样精度的影响。不通过 → 改电流/改策略/换拓扑。
- **依据**：AFE/BMS datasheet 的均衡驱动能力；电芯规格的均衡建议；`PCB-RULE-THERMAL-001`。

### KP-SCH-196 电池温度检测：NTC 分压、断线与温窗

- **判据**：电池温度检测必须：NTC 贴近电芯（不是贴在 PCB 边缘）、分压上拉/下拉按 NTC 的 B 值与温区选（使目标温区落在 ADC 分辨率较好的区间）、ADC 采样加 RC 滤波、必须能检测 NTC **开路/短路**（电压贴轨即判故障）、温度窗口与充电/放电策略联动（JEITA，见 KP-SCH-189）；多串/多包要有多点测温（至少电芯表面 + 功率 MOS/连接器）。
- **为什么**：温度是锂电池安全的第一约束；NTC 开路时若按“低温”处理会禁止充电（可用但体验差），若按“正常”处理会失去保护；NTC 贴错位置测到的是 PCB 温度而不是电芯温度。
- **怎么做**：
  - NTC 公式：`R(T) = R25 × exp(B × (1/T − 1/298.15))`；示例 `R25=10kΩ、B=3950`：0°C ≈ 33.6kΩ、25°C=10kΩ、60°C ≈ 2.49kΩ（与上拉 10kΩ 分压，3.3V 下分别约 2.54V、1.65V、0.66V）。
  - 分压：上拉电阻按目标温区中点选（常与 R25 同值），并确认 ADC 量程覆盖全温区；加 100nF 滤波（`fc` 远低于温度变化率，几十 Hz 足够）。
  - 断线检测：开路时 NTC 端电压被上拉拉到接近 VDD，短路时接近 0V；软件设合理窗口 + 故障标志；必要时用 AFE 的 TS 引脚内置检测。
  - 布局：NTC 引线远离功率器件/发热源，按 `PCB-RULE-PLACE-SENSOR-001` 布置；多点测温取最高/加权。
- **怎么查**：恒温箱扫 -20~60°C 对比 NTC 读数与标准温度计；拔掉/短接 NTC 看故障检测；充电时测 NTC 与电芯实际温差。不通过 → 改分压/改位置/加检测。
- **依据**：NTC datasheet 的 B 值/R-T 表/精度；电芯规格的温度窗口；`PCB-RULE-PLACE-SENSOR-001`。

### KP-SCH-197 热失控防护与二次保护

- **判据**：电池包必须有超出电气保护的热安全设计：电芯间热隔离/隔热、泄压方向（不得朝向用户/易燃物）、一次性保险丝/PTC/化学 CID 等二次保护、温度/电压/电流异常的多重判据（不依赖单一传感器）、外壳阻燃等级与结构强度（按整机安规要求）；热失控是“不可逆”事件，设计目标是把单节失效限制在包内、不蔓延、不伤人。
- **为什么**：电气保护只能防“电”滥用，无法阻止内短路/机械损伤引发的热失控；热失控一旦发生，泄压与隔热决定是否蔓延；二次保护（保险丝/CID）是最后的物理切断。
- **怎么做**：
  - 电芯布局：发热/泄压方向与相邻电芯、线束、外壳留出间距；电芯间加隔热垫/云母片（材料与厚度按热蔓延测试定）。
  - 二次保护：每串/包加一次性保险丝或 PTC，阈值与 `I²t` 协调（KP-SCH-200）；电芯自带 CID/vent 时确认泄压路径。
  - 监测：至少两路温度（电芯 + 功率路径）+ 电压/电流；异常时先降流/断开，不依赖单一 NTC。
  - 结构与认证：外壳阻燃（UL94 V-0 级材料，按整机要求）、机械固定、防短路（绝缘片/灌封）；按 KP-SCH-201 做认证测试。
- **怎么查**：按标准做热滥用/过充/短路/挤压等滥用测试（需专业实验室）；热蔓延测试（单节加热触发）；不通过 → 改热隔离/加二次保护/改结构。
- **依据**：GB 31241-2022、IEC 62133-2、UN 38.3 的相关试验项（**需按标准原文与认证机构要求复核**）；电芯 datasheet 的滥用测试数据。

## 三、功率路径、连接与认证

### KP-SCH-198 充放电 MOS 背靠背与体二极管路径

- **判据**：保护板的充/放电 MOS 必须背靠背串联（共源或共漏，按保护 IC datasheet 推荐），利用体二极管方向实现“充电/放电独立切断”；必须校核反向导通路径（体二极管在关断时是否仍能导通）、MOS 的 `Vgs` 驱动电压（低电池电压时驱动能力）、`Rds(on)` 随 `Vgs` 变化、以及“充电禁止但放电允许”等状态下的电流路径是否符合预期。
- **为什么**：单 MOS 只能单向切断，反向仍通过体二极管导通，等于没保护；低电量时 `Vgs` 不足会让 MOS 进入线性区、发热甚至失效。
- **怎么做**：
  - 按保护 IC datasheet 的推荐接法（共源/共漏）连接双 NMOS；确认体二极管方向：充电 MOS 的体二极管方向要能阻断过充电流。
  - 驱动：`Vgs` 由保护 IC 的内部电荷泵/电池电压提供，低电量时确认 `Vgs ≥ 4.5V` 级（按 MOS datasheet 的 `Rds(on)@Vgs` 曲线）；不足时选逻辑电平 MOS 或带电荷泵的保护 IC。
  - 状态机：正常/过充禁止/过放禁止/过流禁止，逐一确认哪个 MOS 关断、剩余电流路径是什么。
  - 热：`P = I² × (Rds_chg + Rds_dis)`，按最大持续电流与温升选封装/铜皮。
- **怎么查**：逐状态测两个 MOS 的 `Vgs`/`Vds` 与电流路径；低电量（如 2.8V）满载测 MOS 温升与压降；反向充电测试。不通过 → 换 MOS/换保护 IC/改驱动。
- **依据**：保护 IC datasheet 的 MOS 接法与驱动；MOSFET datasheet 的 `Rds(on) vs Vgs`、体二极管与 SOA。

### KP-SCH-199 电池连接器与线束：接触电阻、压降与温升

- **判据**：电池连接器/线束按最大持续电流与峰值电流选型并降额（常见按额定 70%~80%），校核接触电阻压降 `ΔV = I × R_contact` 与发热 `P = I² × R_contact`、线束压降 `ΔV = I × ρL/A`（铜电阻率约 1.72e-8 Ω·m，按温度修正）、插拔寿命与防呆（极性/防反插）、线束固定与应力释放；大电流路径不得经过 PCB 细走线/过孔瓶颈。
- **为什么**：连接器是电池包最容易发热/失效的环节——接触电阻随氧化/插拔磨损上升，5A 下 20mΩ 就是 0.1V/0.5W；线束过细会发热/压降大；反插会直接烧板。
- **怎么做**：
  - 示例：`5A、R_contact=20mΩ` → `ΔV=0.1V、P=0.5W`（连接器需按此选型并做温升测试）；线束 `0.5mm²` 铜线约 34mΩ/m，1m 线束在 5A 下压降 0.17V、发热 0.85W。
  - 极性防呆：连接器选带防反插结构，PCB 上加反接保护（`05-protection.md` KP-SCH-080）；关键产品用不同端子或键位区分电压。
  - 大电流路径：连接器焊盘/铜皮/过孔按载流加宽（`PCB-RULE-CURRENT-001`）；电池正负极走线尽量短粗，采样线与功率线分开。
  - 线束：按电流选线径并留余量、固定防振、应力释放；高温环境按线材温度等级降额。
- **怎么查**：满载测连接器/线束温升与压降；插拔寿命测试后复测接触电阻；反插测试；不通过 → 换连接器/加粗线束/改布局。
- **依据**：连接器 datasheet 的额定电流/接触电阻/插拔寿命；线材载流表（按标准/厂家数据复核）；`PCB-RULE-CURRENT-001`。

### KP-SCH-200 保险丝、PTC 与双保护协调（I²t）

- **判据**：电池包的保险丝/PTC 必须与电芯、MOS、线束的耐受能力协调：保险丝的 `I²t`（熔断能量）应小于被保护对象（电芯/线束/MOS）的耐受 `I²t`，且大于正常工作/启动浪涌的 `I²t`；PTC 的动作电流/时间随温度变化，不能作为精密过流保护；一次保护（可复位）与二次保护（一次性）的先后顺序必须可推演。
- **为什么**：保险丝选大了短路时不断（烧线束/电芯），选小了正常启动就熔断；PTC 在高温下动作电流下降，可能正常工作时误动作；没有 `I²t` 协调，保护器件之间会“抢动作”或“都不动”。
- **怎么做**：
  - 计算：`I²t_fuse < I²t_withstand × 0.8`（经验余量），且 `I²t_fuse > I²t_inrush × 1.5~2`（按启动浪涌实测）。
  - 示例：若线束/电芯可耐受短路能量对应 `I²t ≈ 100 A²s`，保险丝选 `I²t ≤ 80 A²s` 且额定电流覆盖最大持续电流；具体数值必须按器件 datasheet 与实测短路波形复核。
  - PTC：按“保持电流/动作电流/环境温度降额曲线”选，避免在最高工作温度下误动作；PTC 不能替代一次性保险丝做短路兜底。
  - 双保护顺序：一次保护（AFE+MOS）先动作；若失效，保险丝/PTC 兜底；文档化动作阈值与顺序。
- **怎么查**：做外部短路测试（按标准条件）看保护动作与器件状态；测启动浪涌 `I²t`；高温下 PTC 保持电流测试。不通过 → 换器件/调阈值/改拓扑。
- **依据**：保险丝/PTC datasheet 的 `I²t`、时间-电流曲线、温度降额；电芯 datasheet 的短路耐受；GB 31241/IEC 62133 的短路试验要求（按标准原文复核）。

### KP-SCH-201 认证证据：UN38.3、GB31241、IEC 62133 与整机安规

- **判据**：电池系统出货前必须有可追溯的认证/测试证据，且**原理图设计要为测试项留出接口与裕量**：UN 38.3（运输，T.1~T.8 试验）、GB 31241-2022（便携式电子产品用锂离子电池和电池组安全）、IEC 62133-2（便携式锂二次电池安全）、整机 IEC 62368-1（如适用）；证据包括测试报告、证书、电芯规格书、BMS 保护参数、生产一致性（批次/追溯）。认证不是“设计通过就自动有”，需要送样测试与工厂审查。
- **为什么**：没有 UN 38.3 报告无法合规运输锂电池；没有 GB 31241/IEC 62133 报告无法进入对应市场；认证测试会暴露设计边界（过充、短路、热滥用、跌落、振动），原理图阶段就要考虑可测试性与保护裕量。
- **怎么做**：
  - 列出目标市场的认证清单与责任方（电芯厂/电池包厂/整机厂）；确认已有报告覆盖的型号/批次（**证书与报告必须按实际型号核对，不能复用**）。
  - 设计侧准备：保护参数可测（测试点/通信读出）、可恢复保护与一次性保护状态可判、关键器件有规格书与批次追溯。
  - UN 38.3：确认试验摘要（Test Summary）与报告；运输 SoC 按承运商/法规要求（常见 30% 左右，**按最新运输法规复核**）。
  - 变更管理：电芯/保护 IC/关键器件变更需评估是否触发重新认证。
- **怎么查**：核对报告/证书的型号、批次、日期、测试机构资质；对照 BOM 与原理图保护参数；不通过 → 补测试/改设计/换电芯。
- **依据**：UN《试验和标准手册》第 III 部分 38.3 节（T.1~T.8）；GB 31241-2022；IEC 62133-2；IEC 62368-1。**具体条款、试验条件与判定以标准原文和认证机构要求为准，本文件不替代标准。**

### KP-SCH-202 电池测试与可量测判据：容量、内阻、循环与自放电

- **判据**：电池/电池包必须有可量测的验收判据：容量（按标准倍率放电，如 0.2C/1C，按电芯规格）、内阻（ACIR 1kHz 或 DCIR，按方法定义）、循环寿命（容量保持率 vs 循环数）、自放电（静置电压降/容量损失）、充电/放电温升、保护动作阈值。判据要写测试条件（温度/倍率/截止电压）与判定窗口。
- **为什么**：电池是“会老化的器件”，没有基线测试就无法判断来料/设计是否合格，也无法在售后区分“电芯问题”与“BMS 问题”。
- **怎么做**：
  - 容量：标准充放电循环，记录放电容量；判据如“≥ 标称容量的 95%（新包，按规格）”。
  - 内阻：ACIR 用 1kHz 交流注入；DCIR 用脉冲电流测 `ΔV/ΔI`；记录初始值与批次分布。
  - 循环：按规格循环（如 500 次后容量 ≥80%，按电芯 datasheet）；记录温升与保护动作。
  - 自放电：满充静置（如 7/28 天，按标准）测电压/容量损失；异常自放电是内短路的前兆。
  - 保护：逐项触发 OVP/UVP/OCP/SCP/OTP 并记录动作值/延时。
- **怎么查**：按测试表执行并留原始数据（充放电曲线/内阻/温度）；抽检批次一致性；不通过 → 换电芯/改 BMS/改设计。
- **依据**：电芯 datasheet 的容量/内阻/循环/自放电规格；GB 31241/IEC 62133 的相关试验方法（按标准原文复核）。

### KP-SCH-203 BMS 通信：SMBus/I2C、CAN 与隔离

- **判据**：BMS 与主控通信必须校核：总线类型与速率（SMBus/I2C 常见 100kHz、CAN 按速率）、上拉/终端、报文超时与 CRC/校验、地址冲突、隔离需求（高压多串 BMS 与低压主控之间必须隔离，见 `PCB-RULE-ISO-001`）、失效安全（通信丢失时系统进入安全状态）。SMBus 还需注意时钟延展、超时与 `ALERT` 中断处理。
- **为什么**：BMS 通信承载电压/电流/温度/保护状态，通信失效会让主控“看不见电池”；多串高压系统的地电位差会损坏未隔离的通信口。
- **怎么做**：
  - I2C/SMBus：上拉按 `04-interfaces.md` KP-SCH-055 计算；`ALERT` 开漏上拉 + 中断；超时/重试策略；SMBus 的 `SMBALERT` 与超时按规范复核。
  - CAN：终端 120Ω、共模/隔离按 `04-interfaces.md` KP-SCH-069/071；报文周期与超时监控。
  - 隔离：数字隔离器/隔离 CAN 收发器，隔离电源；跨隔离带下方禁止铺铜（`PCB-RULE-ISO-001`）。
  - 失效安全：通信丢失 N 秒后进入安全状态（降流/断开/报警），不得保持最后危险指令。
- **怎么查**：总线波形/CRC 错误率；拔线/干扰测试看失效安全；隔离耐压测试；不通过 → 加上拉/隔离/改协议。
- **依据**：`04-interfaces.md` 的 I2C/CAN 规则；`PCB-RULE-ISO-001`；BMS/电量计 datasheet 的通信时序与超时。

### KP-SCH-204 电池反接、热插拔与浪涌

- **判据**：可插拔电池/外接电池接口必须评估：反接（P-MOS/理想二极管/防反接连接器，见 `05-protection.md` KP-SCH-080）、热插拔浪涌（插入瞬间电容充电电流 `I = C × dV/dt`，需软启动/限流/NTC）、插拔时的地弹与通信线瞬态（先地后信号/先信号后地的连接器设计）、浪涌/ESD（TVS，见 `05-protection.md`）。不可依赖“用户不会插反”。
- **为什么**：反接会瞬间烧毁充电 IC/保护电路；热插拔的浪涌电流会拉塌系统电压、打火/氧化连接器；插拔瞬态会通过通信线损伤 BMS。
- **怎么做**：
  - 反接：P-MOS 高边/理想二极管方案；连接器防呆；反接时确保电流不经过体二极管形成通路（按拓扑复核）。
  - 热插拔：输入加 NTC/软启动/限流 IC；`I_inrush` 与连接器额定电流、`I²t` 比较；大电容分批上电（预充电阻+继电器/MOS）。
  - 连接器 pin 顺序：长 pin 先接地/先接电池负极，短 pin 后接信号；通信线加 TVS/串阻。
  - 浪涌/ESD：接口 TVS + 共模电感，按 `05-protection.md` 的顺序与摆放。
- **怎么查**：反接测试（限流电源）、反复热插拔测浪涌与打火、ESD/浪涌测试；不通过 → 加保护/改连接器/加软启动。
- **依据**：`05-protection.md` KP-SCH-080/083/084/088；连接器 datasheet 的插拔顺序与额定电流；`PCB-RULE-ESD-001`。

### KP-SCH-205 电池 PCB 分区与开尔文采样

- **判据**：电池板必须分区：大电流充放电回路（连接器→MOS→电芯）面积最小、走线短粗；采样/保护 IC 走线开尔文、远离大电流路径；NTC 走线远离发热源与功率线；高压多串注意爬电/间隙（`PCB-RULE-CREEPAGE-001`）。电流采样电阻/保护 MOS 的电压检测点必须从焊盘内侧引出（`PCB-RULE-SHUNT-001`）。
- **为什么**：大电流路径的压降（mΩ 级走线在数安培下就是 mV 级）会叠加到采样电压上，造成保护阈值/电量计误差；功率回路的 `di/dt` 会耦合到采样线。
- **怎么做**：
  - 功率回路：连接器 → 保护 MOS → 电芯，走线宽度按载流（`PCB-RULE-CURRENT-001`），回路面积最小；MOS 散热焊盘打过孔阵列（`PCB-RULE-THERMAL-001`）。
  - 采样：Rsense/电芯电压采样从焊盘内侧开尔文引出，成对走线、包地、远离开关节点；采样 RC 靠近 IC。
  - 分区：保护 IC/电量计放在采样点附近，数字通信线远离功率回路；高压区与低压区按爬电/间隙分隔并开槽（按标准计算）。
  - 连接器：大电流端子与采样端子分开，避免共用接触电阻。
- **怎么查**：满载测采样点电压与真实值偏差；近场探头/示波器看采样线噪声；爬电/间隙目检+测量；不通过 → 改布局/改开尔文/加滤波。
- **依据**：`PCB-RULE-SHUNT-001`、`PCB-RULE-CURRENT-001`、`PCB-RULE-THERMAL-001`、`PCB-RULE-CREEPAGE-001`；`08-analog-signal-chain.md` KP-SCH-139。

### KP-SCH-206 多串采样线序与均衡走线：共阻抗串扰

- **判据**：多串电池的采样线必须按“从低到高/从高到低”固定线序接入连接器，并在原理图上标注 pin 定义与线序；均衡电流不得流过采样线（或采样线与均衡线分开/加滤波隔离），否则均衡时采样电压被共阻抗抬升/拉低，造成误保护；采样线每根加 RC 滤波与（按需）限流电阻，连接器处加 TVS/ESD。
- **为什么**：多串采样线常与均衡电阻共用走线，均衡 100mA 在 0.1Ω 共阻抗上就是 10mV，足以让 4.2V 的 OVP 误判；线序接错会直接短路电芯/烧 AFE。
- **怎么做**：
  - 线序：连接器 pin1=CELL0−（或最高串，按 AFE 规定），逐级定义并在图上画清楚；装配用防错连接器/颜色标识。
  - 采样与均衡：均衡电阻从 AFE 的均衡引脚单独走线到电芯节点，采样从电芯节点单独开尔文引出；无法分开时在采样侧加 RC 滤波并评估共阻抗误差。
  - 滤波：每节 `R+C`（见 KP-SCH-192），电阻兼作限流；连接器处 TVS 保护。
  - 布线：采样线成组、远离功率回路与均衡大电流路径；跨节走线注意爬电。
- **怎么查**：开启均衡时测各节采样电压变化（应 < 几 mV）；核对线序与 AFE datasheet；插错线序的防护测试（防呆）；不通过 → 改走线/改滤波/改连接器。
- **依据**：AFE datasheet 的引脚定义与均衡接法；`PCB-RULE-SHUNT-001` 的开尔文原则；`PCB-RULE-CREEPAGE-001`（高压多串）。

### KP-SCH-207 电池存储、运输与 SoC 窗口

- **判据**：电池包/整机的存储与运输要求必须在设计与文档中体现：运输 SoC（常见 30% 左右，按最新运输法规/承运商要求复核）、存储温度/湿度范围、长期存储的电压窗口（避免满电/空电长期存放）、运输包装（UN 38.3 报告、危包证/UN 编号按法规）、MSDS/SDS 与标签。设计上要能让产线把电池充/放到指定 SoC 并记录。
- **为什么**：满电高温存储加速老化/鼓包；空电长期存储会过放损坏；运输 SoC 与包装不合规会被拒运/罚款。
- **怎么做**：
  - 产线：EOL 时把电池调到运输 SoC 并记录（见 KP-SCH-209）；测试工位能读 SOC/电压。
  - 存储：按电芯 datasheet 的温度/湿度/电压窗口；长期存储建议 3.7~3.9V 级（按电芯规格）。
  - 运输：确认 UN 38.3 报告、UN 编号/包装类别、标签；空运/海运/陆运要求可能不同（按最新法规复核）。
  - 文档：SDS/MSDS、运输声明、电池信息表随货。
- **怎么查**：产线抽检运输 SoC；核对运输文件与包装标签；不通过 → 调产线流程/补文件/改包装。
- **依据**：UN 38.3 与运输法规（IATA/IMDG 等，按最新版本复核）；电芯 datasheet 的存储条件；GB 31241 的标记/说明要求。

### KP-SCH-208 硬件保护与固件保护的冗余

- **判据**：安全相关保护不能只靠固件：过充/过放/过流/短路/过温至少有一层**硬件**保护（保护 IC/AFE/比较器/保险丝），固件保护作为第二层（更精细的阈值、告警、降流）；固件跑飞/看门狗复位时硬件保护仍有效；关键状态（保护锁存、故障记录）掉电不丢；不得用“软件关断”替代硬件切断。
- **为什么**：固件可能死机、ADC 读错、寄存器写错；电池安全事件的时间尺度是 ms~s，固件失效时硬件必须在场。反过来，只有硬件没有固件精细管理，会频繁误保护/体验差。
- **怎么做**：
  - 硬件层：保护 IC/AFE 独立供电与采样（不复用 MCU ADC 路径），阈值按电芯规格；短路用硬件比较器快速关断。
  - 固件层：独立采样通道交叉校验、看门狗、保护状态机、故障锁存与上报；固件与硬件阈值分层（固件更早告警，硬件兜底）。
  - 失效安全：MCU 复位/掉电时保护 MOS 默认状态要安全（按 KP-SCH-198 的驱动设计）；保护锁存需满足“故障排除后可控恢复”。
  - 记录：故障码/次数/时间存非易失，便于售后分析。
- **怎么查**：模拟固件死机（看门狗复位/拔调试器）看硬件保护是否仍动作；注入故障看锁存与恢复；掉电保持测试。不通过 → 加硬件层/改默认态/改记录。
- **依据**：保护 IC/AFE datasheet 的独立保护机制；`05-protection.md` 的保护层级；`02-power-architecture.md` 的上电/复位安全。

### KP-SCH-209 电池包 EOL 测试、追溯与档案

- **判据**：产线 EOL 必须有电池包测试与追溯：开路电压/内阻、容量/充电功能、保护动作（OVP/UVP/OCP/SCP/OTP）、通信（电量计/BMS 读写）、NTC 读数、运输 SoC 设定；每包记录序列号、测试数据、时间、工位、操作员/设备；不良品隔离与返修记录；关键器件（电芯批次/保护 IC/电量计）可追溯到 BOM。
- **为什么**：电池包的安全问题常在出货后才暴露；没有 EOL 数据与追溯，无法定位批次、无法证明一致性，也无法满足认证的工厂检查要求。
- **怎么做**：
  - 测试项与判据表（见 KP-SCH-202）；自动记录原始数据（电压/内阻/保护动作值/通信日志）。
  - 追溯：序列号绑定电芯批次/保护板批次/固件版本/校准数据；数据库/文件保存期限按质量体系。
  - 运输 SoC 设定并记录（KP-SCH-207）；不良品标记、隔离、返修后复测。
  - 与认证一致性：量产参数（保护阈值/固件）变更需评估是否触发重新认证（KP-SCH-201）。
- **怎么查**：抽检 EOL 记录完整性；用序列号反查 BOM/测试数据；复核不良品处理流程。不通过 → 补测试项/改追溯/改流程。
- **依据**：`PCB-RULE-TESTPOINT-001` 与产测规范；GB 31241/IEC 62133 的生产一致性要求（按认证机构要求复核）；质量体系文件。

### KP-SCH-210 电池与 BMS 评审清单

- **判据**：评审必须逐项确认并有证据：架构与保护层级、充电 CC/CV/温度窗口、热耗与散热、1S/多串保护阈值与 MOS、AFE 采样与断线检测、电量计精度/校准、均衡、NTC 与断线、二次保护与热安全、MOS 背靠背/体二极管、连接器/线束、保险丝 `I²t` 协调、认证证据、测试判据、EOL 追溯、通信与失效安全、分区/开尔文。缺证据不得放行（`SCH-RULE-REVIEW-001`、`PCB-RULE-CHARGER-001`）。
- **为什么**：电池系统是“电气+电化学+热+认证”的交叉领域，任何一层漏掉都可能在量产/认证/售后爆发；清单化评审把跨层耦合（如均衡串扰采样、充电热调导致充不满、运输 SoC 不合规）纳入检查。
- **怎么做**：用下表逐项打勾；对“需实测/需认证”项单列计划；问题单记录编号/位置/严重度/整改/证据；整改后重跑相关测试与认证评估。
- **怎么查**：按表要证据；抽查 3 项做实测复现；不通过 → 整改后复评。

| 类别 | 检查项 | 关键判据 | 证据 |
| --- | --- | --- | --- |
| 架构 | 充电/一次保护/二次保护/计量职责 | 每层可切断、可复位、可兜底 | 架构图、失效模式推演 |
| 充电 | CC/CV/预充/终止/温度窗口 | 终止电压与电芯一致、JEITA 分区正确 | 充电曲线、高低温记录 |
| 热 | 线性/开关热耗与结温 | `Tj` 在规格内、高温不热失控降流 | 温升测试、热像 |
| 1S 保护 | OVP/UVP/OCP/SCP/OTP、双 MOS | 阈值/延时达标、MOS 温升达标 | 逐项触发记录 |
| 多串 | AFE 采样/断线检测/精度 | 断线可检测、采样误差在阈值余量内 | 电池模拟器记录 |
| 计量 | 电量计方案/Rsense/校准 | SOC 误差在目标内、小电流不丢 | 循环对比数据 |
| 均衡 | 电流/时间/热/策略 | 均衡有效、温升可控、不干扰采样 | 失衡测试、温升 |
| 温度 | NTC 位置/分压/断线/温窗 | 读数偏差小、开路短路可检 | 恒温箱、拔线测试 |
| 二次保护 | 保险丝/PTC/`I²t` 协调 | `I²t` 协调、短路动作 | 短路测试、器件曲线 |
| 功率路径 | MOS 背靠背/体二极管/连接器/线束 | 状态路径正确、压降/温升达标 | 状态波形、压降温升 |
| 认证 | UN38.3/GB31241/IEC62133/62368 | 报告证书覆盖实际型号批次 | 报告、证书、BOM 核对 |
| 通信 | I2C/SMBus/CAN/隔离/失效安全 | 通信可靠、丢失进安全态 | 波形、拔线测试 |
| 分区 | 大电流回路/开尔文/爬电 | 采样误差小、爬电达标 | 布局检查、测量 |
| EOL | 测试项/追溯/运输 SoC | 数据完整、可反查 | EOL 记录、追溯查询 |
