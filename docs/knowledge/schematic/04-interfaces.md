# 总线与接口设计：I2C / SPI / UART / USB / CAN / RS485 / 电平转换

> **一句话结论**：接口设计先定四件事——**电平是否匹配、速率与距离是否匹配、总线上有没有必须的终端/上拉/ESD、地和参考是否共地**；这四件事定错，后续软件怎么调都救不回来。

## 一、通用原则与 I2C

### KP-SCH-054 接口设计四问：电平、速率、距离、参考地

- **判据**：每个接口在画图前必须回答：①驱动方/接收方的 VOH/VOL/VIH/VIL 是否兼容（含绝对最大额定值）；②速率（时钟/波特率）是否在器件与线缆能力内；③距离/拓扑（板内、板间、线缆、多节点）是否匹配总线类型；④是否共地/需要隔离。四问缺一不得定稿。
- **为什么**：接口故障大多不是协议问题，而是电平超限、速率过高导致眼图闭合、线缆过长导致反射/衰减、地电位差导致共模超限。
- **怎么做**：做一张“接口契约表”，每个接口一行：信号、方向、电平、速率、拓扑、终端/上拉、ESD、测试点；板间/线缆接口额外标连接器 pin 定义与线序。
- **怎么查**：逐接口对照双方 datasheet 直流/交流参数；联调时先测电平与波形再调协议；不通过 → 加转换/降速/改拓扑/加隔离。

### KP-SCH-055 I2C 上拉电阻范围计算

- **判据**：上拉电阻必须同时满足下限（灌电流能力）与上限（上升时间）：
  - `Rp(min) = (VDD − VOL(max)) / IOL`，其中 `IOL` 为总线规定灌电流（标准/快速模式通常 3mA，具体查规范/器件）。
  - `Rp(max) = tr / (0.8473 × Cb)`，其中 `Cb` 为总线总电容（规范上限 400pF），`tr` 为规范允许最大上升时间（100kHz 标准模式 1000ns；400kHz 快速模式 300ns，需按规范复核）。
  - 取 `Rp(min) < Rp < Rp(max)`，并留 ≥20% 余量。
- **为什么**：上拉太大 → 上升沿被 RC 拖慢，高速下位采样错误；上拉太小 → 灌电流超器件能力、VOL 抬高、功耗增大。
- **怎么做**：
  - 示例（3.3V、VOL=0.4V、IOL=3mA、Cb=200pF、400kHz）：`Rp(min)=(3.3−0.4)/3mA≈967Ω`；`Rp(max)=300ns/(0.8473×200pF)≈1.77kΩ`；可选 1.2k~1.5kΩ。若 Cb=100pF，则 `Rp(max)≈3.5kΩ`，可选用 2.2kΩ。
  - 常见取值：3.3V/100kHz 用 4.7kΩ；3.3V/400kHz 用 2.2kΩ；5V 系统按同样公式重算（注意 5V 器件 IOL 与 3.3V 器件耐压）。
  - 多主/多从共用一条总线时，上拉只在一处（或按总线分段）放置，不要每个器件都放。
- **怎么查**：示波器测 SCL/SDA 上升时间与高电平；用 `Cb` 估算与实测对比；不同从机全接入后复测。不通过 → 调上拉/降速/加总线缓冲器。

### KP-SCH-056 I2C 地址规划与多从机

- **判据**：每个从机地址唯一；7 位地址中 `0x00~0x07` 与 `0x78~0x7F` 为保留地址，不得使用；地址由硬件引脚（ADDR/A0~A2）或固定地址决定，必须在图上标注实际地址与设置方式；10 位地址设备需确认主控支持。
- **为什么**：地址冲突是“总线上挂两个器件后都不通信”的最常见原因；地址设置错误会表现为“读不到/读到别的器件”。
- **怎么做**：做地址分配表：器件位号、7 位地址、设置引脚电平、备注；地址引脚用 0Ω/上下拉明确设置，不允许悬空；同一总线挂多个同型号器件时用地址引脚区分；地址冲突时用 I2C 多路复用器（TCA9548 类）分总线。
- **怎么查**：上电后用 I2C 扫描工具扫全部地址，与分配表对照；逐器件单独通信验证；不通过 → 改地址/加分路。

### KP-SCH-057 I2C 总线电容、走线与缓冲

- **判据**：整条总线电容 `Cb ≤ 400pF`（标准/快速模式规范值）；板内走线短、少过孔；板间/线缆连接必须核算线缆电容（常见约 50~100pF/m，需按线缆 datasheet 复核）；超限时用 I2C 缓冲器/中继器分段，而不是继续加大上拉。
- **为什么**：总线电容决定上升时间与上拉取值；电容超限时无论怎么调上拉都无法同时满足上升时间与灌电流。
- **怎么做**：估算 `Cb = 器件引脚电容 + PCB 走线电容(约 1~3pF/cm) + 连接器/线缆电容`；长线/多节点用缓冲器（如 PCA9515 类）把总线分段，每段独立上拉；SDA/SCL 远离高频/大电流信号，必要时包地。
- **怎么查**：实测上升时间反推 Cb；总线挂满器件后复测；不通过 → 缩短线缆/加分段缓冲/降速。

### KP-SCH-058 I2C 隔离与电平转换

- **判据**：两侧不共地或地电位差较大时必须用数字隔离器（I2C 专用隔离器，注意双向性与时钟延展支持）；两侧电压不同用双向电平转换器（开漏架构，如 BSS138 方案或专用 I2C 转换器），两侧各保留上拉；隔离器两侧电源必须各自去耦。
- **为什么**：I2C 是双向开漏总线，普通单向隔离器/转换器无法正确传递 ACK 与时钟延展；隔离侧地浮动会导致通信失败甚至损坏。
- **怎么做**：隔离器选支持双向 I2C 的型号，按 datasheet 加两侧上拉（注意隔离器内部可能有等效串联电阻）；BSS138 双向转换：低压侧栅极接低压电源、源极接低压总线、漏极接高压总线，两侧各 4.7kΩ 上拉（速率受 RC 限制，一般 ≤400kHz，需实测）；隔离侧电源用隔离 DC-DC 或变压器。
- **怎么查**：两侧分别测波形与电平；做地电位差/共模干扰测试；高速下测上升时间。不通过 → 换专用隔离器/降速/改拓扑。

## 二、SPI 与 UART

### KP-SCH-059 SPI 信号完整性：串阻、走线与速率

- **判据**：SPI 时钟速率必须 ≤ 从机器件 datasheet 上限，并考虑走线长度与负载；SCLK/MOSI 可串 22~100Ω 阻尼电阻抑制过冲（按实测决定，不是必加）；长走线/多负载时降速优先于加电阻；CS 必须有上拉（默认不选中）。
- **为什么**：SPI 是推挽高速信号，过冲/振铃会造成误采样；CS 在上电/复位期间浮空会让从机误响应。
- **怎么做**：按“主 → 从”方向画信号；每个从机独立 CS；CS 上拉 10kΩ 到从机 IO 电压；SCLK 走线尽量短、避免跨分割；多从机时可用菊花链（需器件支持）或独立 CS + 多路复用。
- **怎么查**：示波器测 SCLK/MOSI 在从机端的过冲与建立/保持时间；上电瞬间测 CS 电平；不通过 → 串阻/降速/改拓扑。

### KP-SCH-060 SPI 多从机与片选管理

- **判据**：每个从机一个独立 CS（或使用译码器/多路复用器扩展）；同一时刻只有一个 CS 有效；CS 的有效电平与默认电平必须与从机 datasheet 一致；CS 走线与 SCLK 尽量等长（高速时）。
- **为什么**：CS 共享或译码错误会让多个从机同时驱动 MISO，造成总线冲突和读数错乱。
- **怎么做**：N 个从机 → N 个 GPIO 或 1 个译码器（74HC138 类）；未使用的 CS 输出默认无效；MISO 为多从机共享输入，注意从机在 CS 无效时必须是高阻（查 datasheet）；必要时 MISO 加串联电阻/缓冲。
- **怎么查**：逐个从机单独读写验证；示波器同时抓多路 CS 确认互斥；不通过 → 改片选逻辑/加缓冲。

### KP-SCH-061 SPI 时序模式（CPOL/CPHA）与建立保持

- **判据**：主从双方 CPOL/CPHA 必须一致（Mode 0~3）；采样沿与数据有效窗口必须满足从机的 setup/hold 时间；高速时还要核算主控输出延迟、走线延迟与从机输入延迟。
- **为什么**：模式不匹配会表现为“读回数据整体移位/偶发错位”，软件上很难定位；时序余量不足会在温度/电压变化时偶发失败。
- **怎么做**：在接口表里写明 Mode（如 Mode 0：CPOL=0、CPHA=0，上升沿采样）；按 datasheet 的时序图核算 `tsetup/thold` 与时钟周期；高速/长线时降低 SCLK 或加时钟缓冲。
- **怎么查**：示波器四通道抓 CS/SCLK/MOSI/MISO 核对采样沿与数据窗口；高低温复测；不通过 → 改模式/降速/改走线。

### KP-SCH-062 UART 电平与交叉连接

- **判据**：UART 是“TX→RX、RX←TX”交叉连接；电平必须匹配：TTL 3.3V/5V 直连需确认双方 VIH/VIL 与耐压；RS-232 用 ±3~15V 电平，必须经收发器；RS-485 用差分收发器。空闲电平为高（UART 空闲为 mark 状态），TX 必须有确定的上拉/默认高电平。
- **为什么**：TX/RX 未交叉是最常见的“能发不能收”；TTL 直连 5V 到 3.3V 可能超绝对最大额定值。
- **怎么做**：连接器/排针标注 `TXD/RXD/GND` 方向（相对本板）；跨板连接时在图上画交叉；未使用的 UART 引脚接上拉；RS-232 收发器按 datasheet 加电荷泵电容；RS-485 见 KP-SCH-070。
- **怎么查**：用 USB-UART 工具自发自收/交叉验证；示波器测空闲电平与波特率；不通过 → 改交叉/加转换/改电平。

### KP-SCH-063 UART 流控与接口保护

- **判据**：高速/大数据量或接收方处理不过来时必须用硬件流控（RTS/CTS）；对外接口必须加 ESD 保护（低电容 TVS）；长线/板间连接建议串 22~100Ω 并考虑共模；隔离场景见 KP-SCH-064。
- **为什么**：无流控时接收 FIFO 溢出会丢数据；外部接口无 ESD 会在插拔/人体接触时损坏收发器。
- **怎么做**：RTS/CTS 交叉连接（本板 RTS → 对端 CTS）；TVS 放在连接器与收发器之间；串阻靠近驱动端；必要时加共模扼流圈（差分/单端按接口类型）。
- **怎么查**：满负荷持续收发验证不丢包；ESD 测试后复测通信；不通过 → 加流控/保护/降速。

### KP-SCH-064 UART 隔离

- **判据**：两侧不共地、存在地电位差、或接口引出到长线/室外时必须隔离；隔离器选数字隔离器（注意方向与速率），隔离侧电源必须独立（隔离 DC-DC），两侧地分别为 `GND` 与 `ISO_GND`，不得跨接。
- **为什么**：地电位差会在收发器上形成共模电流，轻则误码，重则烧毁接口；隔离是切断地环路的最直接方式。
- **怎么做**：数字隔离器（如容耦/磁耦）按方向配置通道；隔离侧供电用隔离电源模块；隔离器两侧各加去耦与 ESD；原理图上明确画出隔离带（不同地符号 + 隔离器件跨越）。
- **怎么查**：测两侧地之间的电位差与隔离电阻；做共模干扰/浪涌测试；不通过 → 补隔离/改拓扑。

## 三、USB 与 Type-C

### KP-SCH-065 USB 2.0 设备端硬件要点

- **判据**：USB 2.0 全速（12Mbps）/高速（480Mbps）差分对 `DP/DM` 按 90Ω 差分阻抗设计（±15%，需按叠层与板厂能力复核）；全速设备 D+ 需 1.5kΩ 上拉到 3.3V（芯片内置则外部不重复加）；VBUS 需 1~10µF 电容与 ESD；DP/DM 上串阻按速率选择（全速常用 22Ω，内置则不加）。
- **为什么**：差分阻抗与端接决定信号质量；D+ 上拉是设备被主机识别的必要条件；VBUS 电容不足会在插拔瞬间掉压导致枚举失败。
- **怎么做**：连接器 → ESD（低电容）→ 串阻/共模 → MCU；DP/DM 走线等长、短、少过孔；VBUS 加 TVS 与电容；ID 引脚（如有）按 OTG 角色处理；屏蔽壳接地按 EMC 策略（直接接地或经 RC/磁珠，需按整机 EMC 方案）。
- **怎么查**：USB 眼图/一致性测试（可用 USB 测试夹具）；枚举成功率、插拔 100 次；不通过 → 改阻抗/端接/ESD/布局。

### KP-SCH-066 USB Type-C CC 配置（Sink 与 Source）

- **判据**：Type-C 受电端（Sink）每个 CC 脚各接 `Rd = 5.1kΩ ±10%` 到 GND，不得两个 CC 共用一个电阻；供电端（Source）用 `Rp` 表示电流能力（默认 USB 56kΩ、1.5A 22kΩ、3A 10kΩ 到 +5V，具体按 Type-C 规范复核）；CC 线必须加 ESD 保护；正反插由 CC 自动识别，DP/DM 需按连接器两侧对称布线（同一网络）。
- **为什么**：CC 是 Type-C 的配置通道；Rd 缺失/错值会让 Source 不供电或只按默认 500mA 供电；两个 CC 共用一个 Rd 会导致部分方向识别失败。
- **怎么做**：Sink：CC1、CC2 各 5.1kΩ 到 GND；Source：CC1/CC2 各一个 Rp 到 +5V（按电流档）；需要 5V/9V/15V/20V 时用 PD 控制器（见 KP-SCH-068）；VBUS/GND 按最大电流选连接器与走线宽度；外壳地与信号地处理按 EMC 方案。
- **怎么查**：用不同线缆（正反插）与不同 Source 实测供电与枚举；万用表测 CC 对地阻值；不通过 → 修正 Rd/Rp/PD 配置。

### KP-SCH-067 USB ESD 与保护器件选型

- **判据**：VBUS、DP/DM、CC 都必须有 ESD 保护；DP/DM 的 TVS 结电容必须足够低（高速建议 <1pF，全速 <3~5pF，需按器件 datasheet 复核），否则会破坏信号完整性；VBUS 的 TVS 需按 5V 工作电压与浪涌能量选型（钳位电压低于后级绝对最大值）；保护器件必须放在连接器与芯片之间，接地回路短。
- **为什么**：USB 口是最常见的 ESD 入口；结电容过大会让眼图闭合，钳位电压过高会打穿后级。
- **怎么做**：选 USB 专用 ESD 阵列（低电容、多通道）；VBUS 可加保险丝/PTC + TVS；DP/DM 串阻与 TVS 顺序按“连接器 → TVS → 串阻 → 芯片”；地过孔就近打，避免保护电流穿过敏感地。
- **怎么查**：IEC 61000-4-2 接触/空气放电测试（±4kV/±8kV 等级按产品要求）；测试后复测枚举与误码；不通过 → 换低电容 TVS/改接地/加共模。

### KP-SCH-068 USB PD 受电要点

- **判据**：需要 >5V 或 >3A 时必须用 PD 控制器/协议芯片协商，不得用电阻“欺骗”Source；PD 控制器需要 CC 通信、VBUS 检测分压、必要的 MOSFET 开关与泄放；受电电压变化后后级 DCDC 的输入范围必须覆盖 PD 档位（5V/9V/15V/20V，按协议与适配器能力）。
- **为什么**：非 PD 的“骗电压”方式不受规范支持，兼容性差且有安全风险；后级 DCDC 若只按 5V 设计，接入 20V 会直接损坏。
- **怎么做**：PD 控制器按 datasheet 接 CC1/CC2、VBUS 分压、VCONN（如需）、MOSFET 与电流检测；后级 DCDC 输入耐压按最高 PD 电压选型并留余量；VBUS 路径加 TVS/保险丝；原理图上标明协商档位与后级输入范围。
- **怎么查**：用 PD 分析仪/不同 PD 电源实测协商电压与电流；满载/热插拔测试；不通过 → 改 PD 配置/后级选型。

## 四、CAN、RS485 与电平转换

### KP-SCH-069 CAN 总线终端、共模与保护

- **判据**：CAN 总线两端各一个 120Ω 终端电阻（中间节点不接）；总线较长/EMC 要求高时用分裂终端（2×60Ω + 4.7nF 到地）；CANH/CANL 为差分对，需共模扼流圈（按速率选型，注意差分阻抗匹配）；收发器电源与 IO 电平匹配，总线侧加 TVS；总线拓扑为直线型，支线尽量短（支线长度按速率约束，需按规范复核）。
- **为什么**：终端电阻吸收反射；缺失或多余终端会导致通信距离缩短、误码率上升；分裂终端提供共模泄放路径，改善 EMC。
- **怎么做**：两个端点各 120Ω（可用跳线/焊盘选择）；分裂终端在两端或按 EMC 需要放置；共模扼流圈靠近连接器；TVS 选 CAN 专用（低结电容、双向）；CANH/CANL 与 GND 一起走线；隔离场景见 KP-SCH-071。
- **怎么查**：断电测 CANH-CANL 电阻（应约 60Ω，两个 120Ω 并联）；示波器看差分波形与反射；总线满载误码测试；不通过 → 检查终端/拓扑/保护。

### KP-SCH-070 RS485 终端、失效保护偏置与共模范围

- **判据**：RS485 总线两端各 120Ω 终端；总线空闲时必须有确定电平（失效保护偏置：A 上拉、B 下拉，阻值按终端与节点数计算，常见 390~680Ω，需按总线负载核算）；收发器共模范围通常 -7V~+12V，超出时必须隔离或加保护；总线侧加 TVS（双向、低结电容），室外/长线加 GDT。
- **为什么**：无偏置时总线空闲为不定态，接收端可能输出随机数据；共模超限会损坏收发器；终端缺失导致反射与误码。
- **怎么做**：端点 120Ω；偏置电阻只在主机/一个节点放置（避免多节点并联改变偏置）；A/B 线序与连接器定义一致；TVS 靠近连接器，GDT 用于高能量浪涌（与 TVS 配合，见 `05-protection.md`）；隔离场景见 KP-SCH-071。
- **怎么查**：断电测 A-B 电阻（约 60Ω 含终端）；空闲时测 A/B 差分电压（应有数百 mV 偏置）；长线满载误码测试；不通过 → 加偏置/终端/保护。

### KP-SCH-071 CAN/RS485 隔离

- **判据**：总线引出到不同地系统、长线、室外或强干扰环境时必须隔离；隔离收发器需要隔离电源（或从总线侧取电的隔离方案）；隔离侧地 `ISO_GND` 与逻辑地不得连接；隔离器/收发器的速率与共模抑制能力必须满足总线速率。
- **为什么**：地电位差与共模浪涌是现场总线损坏的主因；隔离切断地环路，同时保护逻辑侧。
- **怎么做**：选隔离 CAN/RS485 收发器（或“数字隔离器 + 普通收发器 + 隔离电源”组合）；隔离电源按总线侧功耗选型；隔离带两侧各加 TVS/共模；原理图上明确隔离带与两侧地符号。
- **怎么查**：测隔离耐压与绝缘电阻；做共模/浪涌测试；总线满载通信验证；不通过 → 换隔离方案/加保护。

### KP-SCH-072 电平转换：双向与单向、方向控制

- **判据**：开漏总线（I2C、部分中断/复位）用双向转换（BSS138 类或专用双向转换器），两侧各保留上拉；推挽高速信号（SPI、UART、时钟）用单向缓冲/方向控制转换器，方向由 `DIR` 或使能控制且不得浮空；转换器速率必须覆盖信号频率（含上升时间），并核算两侧负载电容。
- **为什么**：用双向转换器传推挽高速信号会因上下拉 RC 拖慢边沿；用单向转换器传双向开漏信号会丢失 ACK/时钟延展；方向控制脚浮空会导致总线争用。
- **怎么做**：
  - 双向（I2C）：BSS138 方案：低压侧源极接低压总线、栅极接低压电源、漏极接高压总线，两侧各 4.7kΩ 上拉；速率一般 ≤400kHz（需实测上升时间）。
  - 单向：SN74LVC1T45 类带 DIR 的转换器；DIR 由 MCU GPIO 或固定电平控制，加 10kΩ 下拉/上拉保证默认方向。
  - 多通道：按方向分组选多通道转换器；未用通道输入接固定电平。
- **怎么查**：示波器测两侧波形、上升时间与过冲；满速通信误码测试；测方向切换时序；不通过 → 换转换器/降速/改上拉。
