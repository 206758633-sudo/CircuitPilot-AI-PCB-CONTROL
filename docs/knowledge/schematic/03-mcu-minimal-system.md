# MCU 最小系统设计：电源、复位、时钟、调试与量产接口

> **一句话结论**：MCU 最小系统只有六件事——**电源与去耦、复位、时钟、启动模式（BOOT）、调试接口、未用引脚处理**；任何一件“先不画、后面再说”，都会变成样机上“偶发不启动、烧不进程序、跑飞、功耗异常”的长期病根。

## 适用范围与边界

| 项 | 内容 |
| --- | --- |
| 适用阶段 | MCU 选型确定 → 最小系统原理图 → 首次上电 → 调试/量产烧录 |
| 输入 | MCU datasheet（pin/电源/复位/时钟/启动/调试章节）、参考手册、封装与引脚复用表 |
| 输出 | 最小系统原理图、上电时序与复位波形记录、烧录/调试接口定义、量产测试点 |
| 不覆盖 | MCU 内部固件逻辑、RTOS、外设驱动；这些不在原理图知识范围内 |
| 编号说明 | 本篇知识点编号为 **KP-SCH-037～053** |

## 一、最小系统清单与电源

### KP-SCH-037 最小系统六要素清单

- **判据**：任何 MCU 原理图必须能指出以下六项且逐项有证据：①每对 VDD/VSS 都有去耦；②复位引脚有确定的上电复位行为；③时钟源（内部 RC 或外部晶振）明确且频率/精度可查；④BOOT/模式引脚在复位采样时刻有确定电平；⑤调试接口（SWD/JTAG）可用且不被功能复用破坏；⑥所有未用引脚有明确处理。缺一项不得进入原理图评审。
- **为什么**：这六项是 MCU 能否“被烧写、能启动、能跑稳”的最低条件；缺任何一项，问题往往在样机阶段才暴露，且排查成本极高。
- **怎么做**：在最小系统模块旁放一张“六要素核对表”，每项注明对应网络/器件位号；参考 datasheet 的“最小系统/典型应用”章节逐项对照。
- **怎么查**：评审时按表逐项要证据（网络名、位号、波形）；首板上电测复位波形、时钟波形、烧录连接。不通过 → 补电路后再评审。

### KP-SCH-038 电源引脚去耦：每对 VDD/VSS 一颗 100nF

- **判据**：每个 VDD（含 VDDIO、VDDA、VBAT 等）引脚就近配一颗 100nF；每个电源域至少一颗 1~10µF 储能；去耦电容在原理图上必须与具体电源引脚成对出现，不允许“总共几颗”含糊处理。
- **为什么**：MCU 内部数字开关瞬间电流由就近电容提供；去耦不足表现为电源纹波大、ADC 抖动、通信误码、偶发复位。
- **怎么做**：按封装引脚列出 VDD/VSS 对（如 48pin 有 3~4 对），逐一画 100nF；10µF 按域放置在电源入口；模拟电源 VDDA 单独用磁珠/电感从数字电源隔离并加去耦；VBAT 若接电池/超级电容，需单独去耦与防反充二极管（按 datasheet）。
- **怎么查**：统计“VDD 引脚数 vs 100nF 数量”，相等或有明确说明；PCB 检查每颗电容到引脚 ≤1.0~2.0mm（QFN 更严）；示波器测负载瞬变时 VDD 跌落。不通过 → 补电容或改布局。

### KP-SCH-039 模拟电源、基准与 ADC 精度

- **判据**：VDDA/VREF+ 必须有独立去耦（典型 100nF + 1~10µF）与隔离（磁珠/电感/RC）；VREF 来源（内部/外部）明确；ADC 输入电压范围不得超过 VDDA；高精度 ADC 需外部基准时，基准的初始精度、温漂、噪声必须与目标位数匹配。
- **为什么**：ADC 的精度上限由基准和电源噪声决定，12 位 ADC 在 3.3V 下 1LSB≈0.8mV，电源上 10mV 纹波就会让有效位数掉几位。
- **怎么做**：VDDA 用磁珠从 3V3 引出，两侧各 100nF+10µF；VREF 引脚加 100nF+1µF；ADC 输入加 RC 低通（R 按采样保持时间与源阻抗计算，C 取 1~10nF，具体按 datasheet 的“ADC 输入阻抗/采样时间”章节复核）；基准芯片按其 datasheet 要求加输出电容。
- **怎么查**：测 VDDA 纹波（示波器 AC 耦合、20MHz 带宽）；用基准源扫 ADC 输入做线性度测试；核对 datasheet 的 VREF 范围与输入阻抗要求。不通过 → 加滤波/换基准/降低采样率。

### KP-SCH-040 复位电路：上电复位 + 手动复位 + 复位脉宽

- **判据**：复位引脚必须有确定的上电复位行为（内部 POR 或外部复位 IC/RC）；手动复位按键要有去抖与 ESD 防护；复位低电平持续时间必须大于 datasheet 的最小复位脉宽；复位引脚不得悬空、不得被强驱动。
- **为什么**：复位脉宽不足会导致“上电偶尔不启动”；复位脚被外部强驱动会与内部复位冲突；无去抖按键会一次按下产生多次复位。
- **怎么做**：
  - 低电平复位（常见 NRST）：10kΩ 上拉到 VDD + 100nF 到 GND（τ=1ms），并联按键到 GND 与 100Ω~1kΩ 串联电阻 + 100nF 去抖；需要快速放电时并在电容两端加二极管（阳极 GND、阴极 NRST）。
  - 电源上升慢或抖动大时用专用复位 IC（阈值精度高、带延迟），按 datasheet 选阈值与延迟。
  - 复位信号走线远离高频/大电流节点，长度尽量短；必要时串 100Ω。
- **怎么查**：示波器测上电复位波形（低电平时间、上升沿）与按键波形；反复上下电 100 次验证；核对 datasheet 最小复位脉宽。不通过 → 调整 RC/换复位 IC/改布局。

### KP-SCH-041 复位与启动异常排查接口

- **判据**：复位网络必须有测试点；复位源（POR/BOR/看门狗/软件复位）应能通过寄存器或状态引脚读出；若 MCU 支持，复位状态引脚/调试口必须可访问。
- **为什么**：现场“偶发重启”若无法区分复位源，只能靠猜；可读复位源能把问题收敛到电源、看门狗或软件。
- **怎么做**：TP_RST 测试点；固件启动时读取并记录复位原因寄存器（RCC 等）；必要时把复位状态引到调试口输出；保留 SWD 连接。
- **怎么查**：上电/手动复位/看门狗复位分别记录复位源寄存器值；与预期对照。不通过 → 补测试点或固件记录。

## 二、启动模式与时钟

### KP-SCH-042 BOOT/模式引脚必须在复位采样时刻有确定电平

- **判据**：所有启动模式引脚（BOOT0、MODE、TEST 等）在复位释放瞬间必须有确定电平（上拉或下拉，阻值按 datasheet 推荐，常见 10kΩ）；不得悬空、不得仅靠内部弱上下拉；量产默认值与调试/烧录模式必须明确区分。
- **为什么**：启动模式引脚在复位时被采样，悬空或受干扰会进入错误启动模式（如进入系统存储器/DFU），表现为“程序不跑/烧录后不启动”。
- **怎么做**：BOOT0 用 10kΩ 下拉到 GND（默认从 Flash 启动），需要进入烧录模式时用跳线/测试点拉高；模式引脚旁加 100nF 滤波（注意不要影响采样）；在图上标注“复位时采样，禁止悬空”。
- **怎么查**：上电瞬间用示波器测 BOOT 引脚电平；万用表核对下拉阻值；反复上下电验证启动一致。不通过 → 补上下拉/加滤波/改跳线。

### KP-SCH-043 晶振电路与负载电容计算

- **判据**：外部晶振（或陶瓷谐振器）的负载电容按 `CL = (C1×C2)/(C1+C2) + Cstray` 设计，通常取 `C1 = C2 = 2×(CL − Cstray)`；Cstray 为 PCB 与引脚寄生电容（典型 2~5pF，需按实际布局估算）；晶振的 ESR、驱动电平、频率精度必须满足 MCU 振荡器要求（查 datasheet 的“oscillator characteristics”）。
- **为什么**：负载电容偏离 → 实际振荡频率偏离标称（ppm 级偏差），影响 UART/CAN/USB/计时；驱动电平过高会加速晶振老化甚至损坏。
- **怎么做**：
  - 示例：晶振 CL=8pF、Cstray=3pF → `C1=C2=2×(8−3)=10pF`（取 10pF/0603 或 0402，±5% NPO/C0G）。
  - 晶振尽量靠近 MCU，走线短且对称，下方不走其他信号，周围包地；负载电容地就近回到 MCU 地。
  - 高精度场景（USB、CAN、RTC）选 ±10~20ppm 晶振，并核对 MCU 内部振荡器是否支持；RTC 用 32.768kHz 时注意负载电容与起振裕量（按 datasheet）。
- **怎么查**：频率计/示波器测实际频率与 ppm 偏差；用频谱看起振时间与是否停振；核对晶振 datasheet 的 CL/ESR/驱动电平。不通过 → 调整负载电容/换晶振/改布局。

### KP-SCH-044 内部 RC 与外部晶振的选择边界

- **判据**：内部 RC 振荡器精度通常为 ±1%~±2%（全温区，需查 datasheet），适用于对时序不敏感的 UART（可容忍 ±2%~3%）、GPIO、低速控制；以下场景必须外部晶振：USB（全速需 ±0.25% 即 ±2500ppm）、CAN（通常需 ±0.5% 以内，按协议与节点数复核）、高精度计时/RTC、长距离 UART、射频。
- **为什么**：内部 RC 随温度和电压漂移，USB/CAN 的位定时容差远小于 RC 精度；用内部 RC 做 USB 会出现“枚举失败/偶发断连”。
- **怎么做**：在时钟方案表里写清：时钟源、频率、精度、起振时间、失效影响；USB/CAN 必须外部晶振或专用时钟；低功耗场景可用内部 RC + 校准，但需评估唤醒后的时钟精度。
- **怎么查**：回读 MCU 时钟配置寄存器确认实际时钟源；全温区（-20~70°C）测频率偏差；USB/CAN 做长时间通信误码测试。不通过 → 改外部晶振。

### KP-SCH-045 SWD 调试接口标准接法

- **判据**：SWD 至少包含 `SWDIO / SWCLK / GND / VDD(参考)` 四根线，可选 `NRST`；SWDIO 建议 10kΩ~100kΩ 上拉到 VDD（或依赖 MCU 内部上拉，需查 datasheet）；SWCLK 下拉 10kΩ 可选；信号线可串 22~100Ω 阻尼电阻；接口必须靠近 MCU、走线短。
- **为什么**：SWD 是开发与量产烧录的命脉；上拉缺失/走线过长会导致连接不稳定、偶发识别不到芯片；NRST 接入可以让调试器在异常时复位。
- **怎么做**：标准 10pin 1.27mm 或 2.54mm 排针：`1=VDD, 2=SWDIO, 3=GND, 4=SWCLK, 5=GND, 6=SWO(可选), 7=KEY/NC, 8=NC, 9=GND, 10=NRST`（具体按调试器引脚定义复核）；接口加 ESD 保护（低电容 TVS）；调试口不要与高速/大电流信号复用同一排针相邻脚。
- **怎么查**：用调试器实际连接、读 ID、烧录、断点调试；示波器看 SWCLK/SWDIO 波形质量；插拔 20 次验证稳定。不通过 → 加上拉/串阻/缩短走线/换接口。

### KP-SCH-046 JTAG 与多器件调试链（按需）

- **判据**：使用 JTAG 时，TCK/TMS/TDI/TDO 必须按链路顺序串联，TDO→TDI 级联；每个器件的 TRST（如有）与系统复位处理明确；长链路需考虑信号完整性与上拉/下拉。若只用 SWD 则不布 JTAG。
- **为什么**：JTAG 菊花链接错会导致整条链识别失败；TRST 处理不当会让器件处于测试模式。
- **怎么做**：按调试器与 MCU datasheet 的 pin 定义连接；TCK 串阻/下拉按需；链路上的器件 VREF 必须共参考；在原理图上标明链路顺序（1→2→…）。
- **怎么查**：调试器扫描链路应识别到全部器件；逐器件读 IDCODE；不通过 → 检查级联顺序与 TRST。

### KP-SCH-047 调试接口的保护与量产复用

- **判据**：暴露到板边/外部的调试接口必须有 ESD 保护与（必要时）串阻；调试引脚若与功能复用，必须保证功能模式下不被外部调试器/排针负载影响；量产烧录点与调试口可以复用，但要有明确的进入/退出方法。
- **为什么**：调试口是最容易被静电打到的接口；复用引脚在功能模式下被外部电路拉动会导致功能异常。
- **怎么做**：调试口加低电容 TVS（结电容 <5pF 级别，按信号速率选）；复用引脚加 0Ω/跳线或缓冲；量产用 pogo pin 焊盘而非排针时，焊盘间距与测试治具匹配。
- **怎么查**：ESD 测试后复测调试连接；功能模式下测复用引脚电平；核对治具与焊盘。不通过 → 加保护/改复用方案。

## 三、看门狗、GPIO 与量产

### KP-SCH-048 看门狗：内部与外部看门狗的选择

- **判据**：可靠性要求高的产品必须启用看门狗；内部看门狗（IWDG）够用则优先；对“时钟失效/程序跑飞/中断风暴”要求更严时用外部看门狗（带独立时钟、WDI 引脚、复位输出）。喂狗周期必须小于超时时间，且喂狗点应覆盖所有关键任务（不要只在主循环喂）。
- **为什么**：看门狗是“程序跑飞后自恢复”的最后手段；只在一个任务里喂狗，会让卡死的任务无法被复位；外部看门狗能在 MCU 时钟失效时仍然工作。
- **怎么做**：内部 IWDG 超时按最长任务周期 ×2~3 设置；外部看门狗 WDI 接 GPIO，超时 1~2s，输出接 NRST（开漏/推挽要注意电平）；调试时用调试器暂停看门狗或加“调试模式冻结”配置（按 datasheet）。
- **怎么查**：人为制造死循环/关时钟，观察是否复位并记录复位源；测喂狗波形周期；调试模式下验证不会误复位。不通过 → 调整喂狗策略/换外部看门狗。

### KP-SCH-049 GPIO 上电默认状态与外部负载

- **判据**：必须查清复位期间与复位后各 GPIO 的默认状态（高阻输入/上拉/下拉/模拟），外部电路不得因默认状态产生误动作（如继电器吸合、MOS 导通、LED 常亮、总线被拉低）；关键控制信号必须有外部上下拉确定电平。
- **为什么**：MCU 复位期间 GPIO 是高阻，外部上下拉决定实际电平；若外部没有确定电平，MOS/继电器可能在启动瞬间误动作，造成安全或设备损坏。
- **怎么做**：列出关键 GPIO（使能、电机、加热、通信 CS）的默认状态表；复位期间需要“关断”的输出加外部下拉/上拉；上电顺序敏感的执行器加硬件互锁或默认关断电路；用高阻输入时避免浮空。
- **怎么查**：上电瞬间用示波器抓关键 GPIO 与执行器电流；核对 datasheet 的 GPIO 复位状态表；不通过 → 加外部上下拉/改驱动极性。

### KP-SCH-050 未用引脚处理

- **判据**：未用引脚按 datasheet 要求处理：数字输入接 GND 或 VDD（不得悬空）；数字输出可悬空但建议标注 NC；模拟输入按 datasheet（通常接地或接固定电平）；专用引脚（如 USB、晶振、调试）未用时按 datasheet 建议处理。所有处理必须在图上显式标注。
- **为什么**：悬空输入会因漏电/耦合随机翻转，增加功耗与噪声；某些引脚悬空还可能影响内部模拟电路或低功耗模式电流。
- **怎么做**：建立“未用引脚清单”，逐脚写处理方式与依据；输入类接 GND/VDD（通过 0Ω 或直接）；输出类放 NC 符号；未用外设时钟在固件中关闭。
- **怎么查**：ERC 未连接检查逐条处理；实测待机电流是否异常（悬空输入会导致电流偏大）；核对 datasheet 的 unused pin 章节。不通过 → 补处理。

### KP-SCH-051 量产烧录接口与流程

- **判据**：量产必须有可重复的烧录接口与流程：烧录点（pogo pin 焊盘/排针/测试治具）、进入烧录模式的方法（BOOT 跳线/自动进入）、烧录后校验、读保护/加密配置、烧录记录（序列号/固件版本）。烧录点不得被外壳/器件遮挡。
- **为什么**：研发能烧不等于产线能烧；烧录接口被遮挡、进入模式不可靠、无校验，会在量产阶段造成批量返工。
- **怎么做**：预留 `VDD/GND/SWDIO/SWCLK/NRST/BOOT` 测试焊盘，间距与治具匹配；烧录模式用测试点拉 BOOT 或专用命令进入；烧录后做 CRC/回读校验；按需开启读保护，并记录配置；固件版本写入可读区域。
- **怎么查**：用产线治具实际烧录 10 片并校验；确认烧录点可接触、外壳不遮挡；抽检读保护是否生效。不通过 → 改焊盘位置/流程。

### KP-SCH-052 IO 电平与 VDDIO 匹配

- **判据**：MCU 的 IO 电压（VDDIO）必须与所连接器件的电平匹配：`VIL/VIH`、`VOL/VOH` 满足双方 datasheet 的直流参数；不同电压域之间必须用电平转换或确认器件兼容（如 3.3V 输出到 5V 输入通常可识别，但 5V 输出到 3.3V 输入可能超绝对最大额定值）。
- **为什么**：电平不匹配表现为“通信偶发错误/器件发热/IO 损坏”；超绝对最大额定值即使“能用”也在缩短寿命。
- **怎么做**：建立“接口电平表”：驱动方 VOH/VOL、接收方 VIH/VIL、是否 5V 容忍；需要转换时按速率选双向/单向转换器（见 `04-interfaces.md`）；串联电阻限流只用于低速/短距离，不能替代电平转换。
- **怎么查**：逐接口核对其 datasheet 直流参数；示波器测高/低电平余量；不通过 → 加转换/改供电/换器件。

### KP-SCH-053 最小系统的布局约束必须在原理图阶段固化

- **判据**：晶振、负载电容、复位 RC、去耦电容、BOOT 上下拉这些“必须就近”的器件，原理图上必须成组画出（同一模块框内），并在图上注明“就近放置”；不得把它们散落在图纸各处，导致 PCB 阶段漏放或放远。
- **为什么**：原理图是 PCB 布局的输入；散落的器件在布局时容易被放到板子另一侧，晶振走线变长、去耦失效、复位受干扰。
- **怎么做**：为每个“就近组”画模块框并标注摆放要求（如“晶振+2 颗负载电容，距 MCU ≤5mm，下方不走线”）；在 BOM/布局说明中同步；关键网络在图上高亮。
- **怎么查**：布局评审时按模块框核对器件是否成组就近；测晶振波形与复位波形确认无干扰；不通过 → 调整布局或改原理图分组。
