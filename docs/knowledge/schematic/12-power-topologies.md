# 先进电源拓扑：Buck-Boost、反激、LLC、多相、热插拔与环路

> **一句话结论**：拓扑选择由**输入输出范围、隔离要求、功率等级、EMI/认证约束**四个变量决定；选定拓扑后，成败点在**环路补偿、功率环路布局、保护与热设计**三处——先算清楚，再画图。

## 适用范围与边界

| --- | --- |

## 一、拓扑选择

### KP-SCH-237 拓扑选择总则：四个变量定方向

- **判据**：按四个变量选择：①输入/输出范围（是否需要升降压、宽输入）；②是否隔离；③功率等级（W~kW）；④EMI/认证/尺寸约束。典型映射：宽输入升降压 → 四开关 Buck-Boost；隔离中小功率 → 反激；隔离中大功率高效 → LLC/正激/半桥；非隔离大电流 → 多相 Buck；高压差小电流 → Buck。
- **为什么**：拓扑决定了效率上限、器件应力、EMI 特性与成本；选错拓扑后靠“堆器件”补救通常无效（例如宽输入用普通 Buck，输入低于输出时就掉压）。
- **怎么做**：先列输入/输出/隔离/功率四要素，再查拓扑对比表（KP-SCH-241）；在原理图首页写“拓扑选择依据”一段，注明放弃其他拓扑的原因；关键器件应力（Vds、Id、Irms）按最恶劣工况计算。
- **怎么查**：核对输入全范围（含瞬态/电池末端）与输出全范围；满载/轻载/瞬态测试；不通过 → 换拓扑或改规格。

### KP-SCH-238 四开关 Buck-Boost：宽输入升降压

- **判据**：输入可能高于、低于或等于输出时必须用升降压拓扑（四开关 Buck-Boost 或 Buck-Boost 控制器）；四开关结构有三个工作区：Buck（Vin>Vout）、Buck-Boost 过渡区、Boost（Vin<Vout）；过渡区效率与纹波最差，设计要尽量让工作点避开或快速穿越；开关管应力按最高输入电压与最大电流核算。
- **为什么**：普通 Buck 在 Vin<Vout 时无法维持输出，普通 Boost 在 Vin>Vout 时无法启动/直通；四开关结构用两个半桥实现无缝切换，但过渡区存在额外开关损耗与输入电流纹波。
- **怎么做**：按控制器 datasheet 的 VIN/VOUT 关系设置工作区与切换阈值（带滞回，避免反复切换）；电感按最恶劣工作区（通常是过渡区）计算 `ΔIL = Vin×D/(L×fsw)` 并留余量；输入/输出电容按 RMS 纹波选型；开关管 Vds ≥ 1.3×Vin(max)，Id ≥ 1.5×Iout(max)。
- **怎么查**：全输入范围扫描（含过渡区）测效率、纹波、稳定性；负载瞬态测试；高温满载；不通过 → 调工作区/电感/补偿。

### KP-SCH-239 反激（Flyback）：隔离中小功率主力

- **判据**：反激适合数十瓦以内的隔离电源；匝比按 `Np/Ns = Vin×D / ((Vout+Vf)×(1−D))`（CCM 近似）设计，D 取 0.4~0.5 附近（按控制器与器件能力复核）；必须设计 RCD/有源钳位吸收漏感能量，开关管 Vds 应力 = `Vin + Vclamp + 尖峰`；光耦/辅助绕组反馈的环路与补偿按 datasheet；CCM/DCM 模式影响纹波与环路。
- **为什么**：反激变压器兼做储能电感，漏感能量不吸收会击穿开关管；匝比/D 设计不当会导致占空比越界、输出不足或器件过压。
- **怎么做**：示例：Vin=24V、Vout=5V、Vf=0.5V、D=0.45 → `Np/Ns = 24×0.45/((5+0.5)×0.55) ≈ 3.57`（取整后复核 D 与应力）；RCD 钳位电容/电阻按漏感能量 `E=½×Llk×Ipk²` 与钳位电压设计；输出整流管耐压 ≥ `Vin×Ns/Np + Vout` 并留余量；光耦 CTR 随温度/寿命变化，环路要留裕度。
- **怎么查**：满载/轻载/短路/过载测试；开关管 Vds 尖峰与温升；环路阶跃响应；不通过 → 调匝比/钳位/补偿。

### KP-SCH-240 LLC 谐振：中大功率高效隔离

- **判据**：LLC 适合数百瓦级、追求高效率的隔离电源；谐振频率 `fr = 1/(2π√(Lr×Cr))`，工作频率在 fr 附近实现 ZVS；增益范围由 Lm/Lr 比与 Q 值决定，必须覆盖输入/输出全范围；死区时间要匹配 MOS 结电容与励磁电流；轻载/空载要防止频率过高与稳压失败。
- **为什么**：LLC 靠谐振腔实现软开关，效率高但增益非线性；设计不当会出现“启动不了/轻载失控/短路时频率崩溃”。
- **怎么做**：按 datasheet/设计工具算 Lr、Cr、Lm、匝比；`Lm/Lr` 常见 3~10（按设计目标复核）；死区按 `t_dead ≥ 2×Coss×Vin/Ipri` 量级估算；输出电容按纹波与保持时间选；轻载加 burst/PFM 模式；谐振腔元件靠近开关管，减小寄生。
- **怎么查**：全范围增益/效率/温升；ZVS 波形（Vds 是否在开通前到零）；短路/过载/轻载测试；不通过 → 调谐振参数/死区/控制策略。

### KP-SCH-241 隔离拓扑对比：正激/推挽/半桥/全桥

- **判据**：按功率与复杂度选择：正激（数十~数百瓦，需复位绕组/有源钳位）、推挽（低压输入、数百瓦，需中心抽头）、半桥（数百瓦~kW，需隔直电容）、全桥（kW 级，器件多、驱动复杂）；每种拓扑的变压器利用率、器件应力、复位方式不同，必须按实际工况对比后选择。
- **为什么**：拓扑的器件应力与变压器利用率直接决定成本与可靠性；例如推挽的开关管承受 2×Vin 应力，全桥适合高压大功率但驱动复杂。
- **怎么做**：做拓扑对比表：功率范围、输入电压、开关管应力、变压器利用率、复位/钳位方式、驱动复杂度、典型效率；选择后在原理图上标注关键应力计算；正激必须有复位（绕组/有源钳位/RCD），否则磁饱和炸管。
- **怎么查**：核对器件应力与降额；满载/短路/启动测试；变压器温升与饱和；不通过 → 换拓扑/改器件。

### KP-SCH-242 多相 Buck：大电流与纹波抵消

- **判据**：输出电流较大（数十安以上）或多相可显著降低输入/输出纹波时用多相 Buck；各相位错开 `360°/N`，输出纹波频率为 `N×fsw`，纹波幅值因抵消而下降；必须做均流（droop 或主动均流），每相电流不平衡会导致单相过热；相位数量按电流、纹波、成本权衡（常见 2/3/4/6 相）。
- **为什么**：多相把电流分散到多个功率级，降低单相损耗与输出纹波；但不均流时最热的一相先失效，多相的优势变成劣势。
- **怎么做**：示例：4 相、每相 25A → 总 100A；输出纹波频率 4×fsw，输出电容可按单相纹波的近似 1/N 估算（实际按占空比与相数计算）；每相电感/开关管/驱动独立且参数一致；均流误差目标按控制器 datasheet（常见 <10%）；相位间布局对称。
- **怎么查**：满载测各相电流与温升（电流探头/分流）；输出纹波与频谱；动态负载测试；不通过 → 调均流/改布局/换控制器。

## 二、热插拔、eFuse 与 ORing

### KP-SCH-243 热插拔控制器：浪涌、SOA 与 dV/dt

- **判据**：带电插拔的板卡必须有限流/软启动；启动电流 `Iinrush ≈ C×dV/dt`，必须小于连接器/母线/上游保护能力；MOSFET 的 SOA 必须覆盖启动过程的电压-电流-时间组合；热插拔控制器按 datasheet 设置限流值、dV/dt、故障响应（闭锁/自动重试）。
- **为什么**：热插拔瞬间负载电容近似短路，电流可达数十安培，会拉低母线、烧连接器、触发上游保护；MOSFET 在“高电压+大电流”同时存在时最容易超出 SOA。
- **怎么做**：示例：C=470µF、48V、要求 50ms 上电 → `I ≈ 470µ×48/50m ≈ 451mA`（实际按限流与 dV/dt 设置）；选 SOA 足够的 MOSFET 并核算启动功耗 `P≈Vin×I/2` 与时间；加 TVS 抑制插拔瞬态；连接器长针地/短针电源。
- **怎么查**：带电插拔测试（示波器看母线跌落、启动电流、MOSFET 温升）；反复插拔 100 次；短路/过流保护动作；不通过 → 调限流/dV/dt/换 MOSFET。

### KP-SCH-244 eFuse / 电子保险丝

- **判据**：eFuse 用于替代传统保险丝/分立热插拔：需确认限流值、过压保护（OVP）阈值、短路响应时间、热保护、闭锁/自动重试行为；`I²t` 与下游器件耐受协调；eFuse 的导通电阻与散热按最大电流核算。
- **为什么**：eFuse 可复位、响应快、带诊断，但限流/热保护设置不当会误触发或保护不足；导通损耗在低压大电流下不可忽略。
- **怎么做**：按最大稳态电流 ×1.5 设置限流；OVP 阈值低于下游绝对最大值；短路响应时间满足下游器件耐受；`Rds(on)` 功耗 `P=I²×Rds(on)` 与 θJA 校核；故障指示/状态引脚接 MCU；与 TVS/保险丝配合（见 `05-protection.md`）。
- **怎么查**：限流/短路/过压/过温测试；满载温升；故障恢复行为；不通过 → 调参数/换器件。

### KP-SCH-245 ORing 与理想二极管：多电源切换

- **判据**：多电源输入（适配器+电池、双路冗余）必须做 ORing 防倒灌；理想二极管（MOS+控制器）压降通常几十 mV，优于肖特基（0.3~0.5V）；选型关注反向关断速度、正向压降、耐压、浪涌能力；切换瞬态不得让输出掉到负载欠压阈值以下。
- **为什么**：ORing 让电流从电压高的电源流向负载而不倒灌；肖特基在大电流下损耗大，理想二极管降低损耗并提高效率。
- **怎么做**：每路电源串理想二极管控制器 + MOSFET；输入输出加 TVS/电容；设置优先级（如适配器优先、电池备份）；软启动避免切换冲击；反向关断时间按负载保持电容核算。
- **怎么查**：双路切换测试（输出跌落、倒灌电流）；效率/温升；反向测试；不通过 → 调优先级/加电容/换器件。

### KP-SCH-246 隔离电源与安规：隔离电压、爬电与 Y 电容

- **判据**：隔离电源的隔离电压、爬电距离/电气间隙、Y 电容（跨接一二次侧）必须满足目标安规标准（如 IEC 62368-1 等，**具体数值必须查标准原文与认证机构要求**）；隔离侧地 `ISO_GND` 与一次侧地不得直接连接；Y 电容的漏电流必须满足安规限值。
- **为什么**：隔离失效会导致触电/设备损坏；爬电/间隙不足在污染/潮湿环境下会击穿；Y 电容漏电流超标会导致认证失败或漏保误动作。
- **怎么做**：按标准确定隔离等级与爬电/间隙；选符合安规的隔离电源模块/变压器（含认证证书）；Y 电容按漏电流限值选（容值越大漏电流越大）；隔离带在原理图/布局上明确标注；一二次侧元件不得跨越隔离带。
- **怎么查**：耐压/绝缘电阻测试；漏电流测试；对照标准原文核对爬电/间隙；不通过 → 改隔离方案/换器件。

## 三、环路、反馈与功率级设计

### KP-SCH-247 环路补偿基础：穿越频率、相位裕度与 Type II/III

- **判据**：开关电源环路必须满足：穿越频率 `fc ≤ fsw/5~fsw/10`（按控制器与动态要求复核）、相位裕度 ≥45°（工程目标常取 60°）、增益裕度 ≥10dB；补偿网络按拓扑选 Type II（电流模式/反激常用）或 Type III（电压模式/高带宽）；补偿参数按功率级传递函数与输出电容 ESR 计算，不能照抄。
- **为什么**：fc 太高会受开关噪声影响、相位裕度不足会振荡；fc 太低则负载瞬态响应差（掉压/过冲）。
- **怎么做**：先算功率级极点/零点（LC 双极点、输出电容 ESR 零点、右半平面零点等），再按 datasheet 的补偿设计流程算 Rc/Cc/Cp；在原理图上标注补偿元件值与计算依据；用仿真/实测验证。
- **怎么查**：环路增益/相位实测（注入法）；负载阶跃响应（过冲/恢复时间）；不通过 → 调补偿/改输出电容/降 fc。

### KP-SCH-248 环路稳定性测量：注入法与判据

- **判据**：环路测量必须在闭环下用注入电阻（通常 10~50Ω）串入反馈分压点，注入小信号扫频，测环路增益与相位；测量要覆盖 fc 附近足够频段；判据：PM≥45°、GM≥10dB、fc 在目标范围；测量时避免大信号非线性（注入幅度足够小）。
- **为什么**：计算与仿真不能完全代表实际（寄生、ESR、布局），注入法是验证稳定性的标准手段；不测量就调板容易“过冲/振荡”反复。
- **怎么做**：在反馈分压中点串注入电阻（预留焊盘）；用频响分析仪/带注入变压器的示波器测 Bode；记录 fc/PM/GM 与测试条件（Vin、Iout、温度）；不同工况复测（满载/轻载/高低输入）。
- **怎么查**：核对测量端面与注入幅度；对比 datasheet 目标；不通过 → 调补偿/改功率级。

### KP-SCH-249 反馈分压、基准与输出精度

- **判据**：`Vout = Vref×(1+R1/R2)`；输出精度由基准精度/温漂、分压电阻精度/温漂、误差放大器失调决定；分压电阻按 datasheet 推荐范围选（兼顾静态功耗与噪声）；反馈走线远离开关节点，采用开尔文 sense 到输出电容/负载点。
- **为什么**：基准与电阻误差直接变成输出电压误差；反馈走线拾取开关噪声会导致输出抖动/环路不稳。
- **怎么做**：示例：Vref=0.8V、目标 5V、R2=10kΩ → R1=52.5kΩ（取 52.3kΩ/1%）；精度预算按 RSS 合成（如基准 0.5% + 电阻 1% + 失调）；反馈分压靠近控制器，sense 线从输出电容正端引出；补偿元件靠近 FB 引脚。
- **怎么查**：测空载/满载输出电压与温漂；对比计算；不通过 → 换高精度基准/电阻/改 sense 点。

### KP-SCH-250 变压器设计要点：匝比、磁芯、饱和与漏感

- **判据**：变压器必须满足：匝比按输入/输出/占空比计算（反激见 KP-SCH-239，正激 `Vout ≈ Vin×D×Ns/Np`）；磁芯面积积（Ap）满足功率与温升；峰值磁通密度 `Bpk = Vin×D/(Np×Ae×fsw)` 低于磁芯饱和值并留余量；漏感要小（影响钳位与效率）；绕组按趋肤效应/邻近效应选线径与绕法。
- **为什么**：变压器饱和会导致电感量骤降、电流失控、炸管；漏感大则钳位损耗高、EMI 差；绕组设计不当温升过高。
- **怎么做**：按功率/频率选磁芯与材质；算 Np 保证 Bpk ≤ 0.8×Bsat（按温度降额）；算 Ns 满足输出；漏感目标按拓扑（反激通常 <5% 初级电感，按设计复核）；夹层绕法/三明治绕法降低漏感；变压器规格书写明匝比/电感/漏感/耐压/温升。
- **怎么查**：测电感量/漏感/匝比；满载温升与波形（是否饱和）；耐压测试；不通过 → 改设计/换磁芯/改绕法。

### KP-SCH-251 同步整流：效率、死区与驱动

- **判据**：低压大电流输出优先同步整流（SR）；SR MOSFET 的导通电阻与热耗按 `P=I²×Rds(on)` 核算；死区时间要避免上下管直通，同时减少体二极管导通时间；SR 控制器的检测/驱动时序必须匹配变压器/电感波形；轻载时 SR 可能反向导通，需要防止。
- **为什么**：同步整流用 MOS 替代二极管降低压降损耗，但驱动/死区不当会直通或反向导通，轻则效率下降，重则炸管。
- **怎么做**：选低 Rds(on)、合适 Vds/Qg 的 MOS；按控制器 datasheet 设置死区；SR 驱动走线短、远离功率环路；轻载进入 DCM 时按控制器策略关闭 SR 或允许反向电流判断；核算 SR 体二极管在死区内的损耗。
- **怎么查**：满载效率与温升；死区波形（是否直通/体二极管导通时间）；轻载/空载行为；不通过 → 调死区/换 MOS/改控制策略。

### KP-SCH-252 输出电容与纹波计算

- **判据**：输出纹波由容性纹波与 ESR 纹波组成：`ΔVout ≈ ΔIL/(8×fsw×Cout) + ESR×ΔIL`（Buck 连续模式近似）；电容的纹波电流额定值与温度降额必须覆盖实际 RMS 电流；陶瓷电容注意直流偏压降容；多颗并联降低 ESR/提高纹波电流能力。
- **为什么**：输出电容不足会导致纹波超标、环路不稳、负载瞬态掉压；ESR 过大则纹波以 ESR 项为主。
- **怎么做**：按纹波目标反推 Cout 与 ESR；示例：ΔIL=0.3A、fsw=500kHz、Cout=22µF → 容性纹波 ≈ 0.3/(8×500k×22µ)=3.4mV，再加 ESR×ΔIL；电容耐压 ≥1.5×Vout；铝电解注意寿命与低温 ESR 上升。
- **怎么查**：示波器测输出纹波（20MHz 带宽、接地弹簧）；满载/低温；不通过 → 加电容/换低 ESR/改拓扑。

### KP-SCH-253 输入滤波与 EMI：差模/共模

- **判据**：开关电源输入必须评估差模（DM）与共模（CM）噪声：DM 由输入电容/电感滤除，CM 由共模扼流圈/Y 电容处理；滤波器截止 `fc = 1/(2π√(LC))` 要低于开关频率并留衰减余量；滤波器要避免与电源环路形成谐振（加阻尼）。
- **为什么**：开关电流的脉冲成分会沿输入线传导/辐射，超标会导致认证失败；滤波器设计不当会谐振放大特定频段噪声。
- **怎么做**：输入端 π 型（C-L-C）滤 DM；共模扼流圈 + Y 电容滤 CM（Y 电容受漏电流限制）；按开关频率与目标衰减选 fc（如 fsw=500kHz，fc 取 50~100kHz 量级，按衰减需求复核）；加阻尼电阻/电解电容抑制谐振；滤波器靠近输入连接器。
- **怎么查**：传导/辐射 EMI 预扫；不同负载/输入电压；不通过 → 调滤波器/加屏蔽/改开关频率。

### KP-SCH-254 保护与软启动：OVP/OCP/OTP/UVLO

- **判据**：开关电源必须具备：输入 UVLO（带滞回）、输出 OVP、逐周期/打嗝式 OCP、OTP、软启动；保护阈值与恢复方式（闭锁/自动重试）必须明确；保护动作不得导致器件应力超限；故障指示可被系统读取。
- **为什么**：开关电源故障时电流/电压上升快，没有逐周期保护会在毫秒级损坏功率级；软启动避免启动冲击。
- **怎么做**：按控制器 datasheet 设置 UVLO 分压（带滞回）、OCP 采样电阻/阈值、OTP 热敏位置；软启动电容按目标启动时间选；保护后状态引脚接 MCU；关键保护做双重（如硬件 OCP + 软件监控）。
- **怎么查**：逐项触发保护（输入跌落/输出短路/过温）并记录动作与恢复；不通过 → 调阈值/改保护方式。

## 四、效率、热、布局与评审

### KP-SCH-255 并联与均流：droop 与主动均流

- **判据**：多个电源模块/相位并联时必须做均流：droop 法简单但电压精度差，主动均流（均流总线/主从）精度高但复杂；均流误差目标按系统要求（常见 <10%）；并联时还要考虑 ORing 防倒灌与故障隔离。
- **为什么**：不均流会让某一路满载/过载，其余轻载，整体寿命与可靠性下降；故障时可能反向倒灌。
- **怎么做**：选支持均流的控制器/模块；均流总线布线抗干扰；每路输出加 ORing；按 datasheet 设置 droop 或均流增益；并联前做单机一致性测试。
- **怎么查**：满载/半载测各模块电流与温升；拔掉一路看均流与输出；不通过 → 调均流/换方案。

### KP-SCH-256 轻载效率与工作模式

- **判据**：电池/待机设备必须评估轻载效率：PFM/burst/跳周期模式可显著降低轻载损耗，但会增加纹波与 EMI；静态电流（Iq）与轻载效率要按待机时间预算核算；模式切换点要避免振荡/音频噪声。
- **为什么**：轻载时开关损耗与驱动损耗占比大，固定频率 PWM 效率低；但 burst 模式会产生低频纹波，可能干扰音频/射频。
- **怎么做**：按待机功耗预算选低 Iq 控制器；设置 PFM 进入阈值（带滞回）；评估 burst 频率是否落入音频/敏感频段；轻载纹波用足够输出电容抑制；在 datasheet 允许范围内配置模式。
- **怎么查**：空载/轻载效率与输入电流；输出纹波与音频噪声；模式切换稳定性；不通过 → 调模式/换器件。

### KP-SCH-257 损耗分解与热设计

- **判据**：功率级损耗必须分解核算：导通损耗（`I²×Rds(on)`/绕组电阻/二极管压降）、开关损耗（`½×V×I×(tr+tf)×fsw`）、驱动损耗（`Qg×Vg×fsw`）、磁芯损耗（按材质/频率/磁通曲线）、控制/静态损耗；结温 `Tj = Ta + Pd×θJA` 必须低于 0.8×Tj(max)；高温环境进一步降额。
- **为什么**：效率与温升是拓扑可行性的硬约束；只算导通损耗会低估发热（开关/磁芯损耗常占 30%~50%）。
- **怎么做**：逐项列损耗表；MOSFET 用 datasheet 的 Rds(on)@Tj 与开关损耗曲线；电感/变压器用厂商损耗曲线；散热按 θJA/θJC 与铜皮/散热器核算；热点用热像仪验证。
- **怎么查**：满载温升与效率实测；热像仪找热点；高温老化；不通过 → 换低损耗器件/加散热/降额。

### KP-SCH-258 功率级布局要点

- **判据**：功率环路（输入电容→开关管→电感→输出电容）面积最小；开关节点（SW）短而宽、不引长线；反馈/采样走开尔文连接、远离 SW；地平面按功率地/信号地分区单点汇合；栅极驱动回路短；散热焊盘/过孔足够。
- **为什么**：功率环路面积决定寄生电感与 EMI；SW 节点是 dv/dt 最大的节点，长线会辐射并耦合到反馈；地处理不当会导致采样误差与振荡。
- **怎么做**：先放功率器件并锁定环路；输入电容紧贴开关管；SW 节点铜皮小；反馈分压靠近 IC、sense 线从输出电容开尔文引出；驱动电阻靠近栅极；功率地与信号地在 IC 的 AGND/PGND 处单点连接；散热焊盘多过孔。
- **怎么查**：目检环路面积/SW 节点/地；近场扫描；效率与纹波对比；不通过 → 改布局。

### KP-SCH-259 拓扑选择案例

- **判据**：以下典型场景可作为选型起点（最终必须按实际参数核算）：9~36V 输入、12V/3A 输出 → 四开关 Buck-Boost；48V 输入、5V/2A 隔离 → 反激；400V 输入、12V/20A 隔离 → LLC/全桥；3.3V 输入、1.0V/100A → 多相 Buck；24V 热插拔板卡 → 热插拔控制器 + eFuse；双电源冗余 → ORing/理想二极管。
- **为什么**：案例能快速收敛方向，但每个场景的器件应力/效率/成本仍需单独计算，不能直接套用。
- **怎么做**：按案例确定拓扑后，回到 KP-SCH-237 的四变量与 KP-SCH-257 的损耗核算；在原理图首页记录“为什么选这个拓扑”。
- **怎么查**：与实测效率/温升/EMI 对比；不通过 → 重新评估拓扑。

### KP-SCH-260 电源模块 vs 分立方案

- **判据**：电源模块（含隔离模块）适合快速上市、认证/隔离已做、功率中小；分立方案适合成本敏感、特殊规格、大功率；选择要考虑：认证证书、散热、尺寸、外围器件数量、可靠性、供应链；模块的输入/输出电容与保护仍需按 datasheet 配置。
- **为什么**：模块省设计但成本高、灵活性差；分立灵活但环路/变压器/安规都要自己做，风险和周期更高。
- **怎么做**：做方案对比表（BOM 成本、面积、效率、认证、开发周期、风险）；模块方案核对 datasheet 的推荐外围；分立方案按本篇各 KP 逐项设计。
- **怎么查**：样机效率/温升/EMI/认证对比；不通过 → 换方案。

### KP-SCH-261 先进电源拓扑常见失败模式

- **判据**：以下任一项存在即判高风险：宽输入用普通 Buck/Boost；反激无 RCD/钳位或匝比错误；LLC 谐振参数不覆盖全范围；多相不均流；热插拔无 SOA 核算；eFuse 限流/OVP 设置错误；ORing 无反向关断；隔离爬电/间隙不足；环路 fc 过高/相位裕度不足；输出电容纹波电流不足；功率环路面积大；轻载模式与音频/射频冲突。
- **为什么**：这些失败模式在原理图上往往“看起来正常”，但会在启动/满载/短路/认证时集中暴露。
- **怎么做**：把本清单做成评审勾选项，逐条对照原理图与测试记录；对“需实测/需仿真”的项单独列表；不通过 → 整改后复评。
- **怎么查**：评审逐条打勾并留证；样机做启动/满载/短路/热插拔/EMI 测试；不通过 → 整改并复评。

### KP-SCH-262 先进电源拓扑评审清单

- **判据**：评审必须逐项确认：拓扑选择依据、器件应力与降额、变压器/电感设计、环路补偿与实测 Bode、保护与软启动、热设计、功率环路布局、EMI 滤波、均流/ORing、隔离安规、测试记录。每项有计算/仿真/实测/datasheet 证据才算通过。
- **为什么**：先进拓扑的耦合点多（控制/磁/热/安规），清单化评审能避免漏项。
- **怎么做**：用下表逐项打勾；问题单记录编号/位置/严重度/整改/证据；评审后重跑相关测试。
- **怎么查**：按表逐项要证据；抽查关键项做实测复现；不通过 → 整改后复评。

| 类别 | 检查项 | 关键判据 | 证据 |
| --- | --- | --- | --- |
| 拓扑 | 选择依据、输入输出全范围 | 全范围可稳压 | 计算表、实测 |
| 功率级 | 电感/变压器/开关管应力 | 降额满足（V/I/热） | 计算、波形 |
| 环路 | 补偿网络、fc/PM/GM | fc≤fsw/5~1/10、PM≥45° | Bode 实测 |
| 保护 | UVLO/OVP/OCP/OTP/软启动 | 逐项动作正确 | 测试记录 |
| 热 | 损耗分解、Tj | Tj≤0.8×Tj(max) | 热像、温升 |
| 布局 | 功率环路、SW、开尔文 | 环路小、采样准 | 布局图、近场 |
| EMI | DM/CM 滤波、屏蔽 | 预扫达标 | EMI 预扫 |
| 隔离/安规 | 爬电/间隙/Y 电容 | 符合标准原文 | 耐压/漏电流 |
