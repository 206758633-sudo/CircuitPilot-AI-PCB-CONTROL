# 传感器与执行器接口设计：I2C/SPI/模拟/脉冲、校准、隔离与电机驱动

> **一句话结论**：传感器和执行器的电路问题只有两类——**“进来的信号被污染/被误解”与“出去的电流没有回路/没有钳位”**；前者靠激励、参考、滤波、校准解决，后者靠续流、死区、去耦与保护解决，二者都不能靠软件兜底。

## 一、传感器接口拓扑与总线

### KP-SCH-161 传感器接口选型矩阵：模拟 / I2C / SPI / 脉冲 / 开关量

- **判据**：选接口前必须回答四问（沿用 `04-interfaces.md` KP-SCH-054）：①信号类型与量程；②精度/分辨率需求；③更新率与延迟；④距离/共地/隔离需求。按下表定拓扑，不能“手头有什么 IO 就用什么”。数字接口优先于长距离模拟；比例式测量优先于绝对测量；需要隔离时接口与电源一起隔离。

  | 接口 | 适用 | 优点 | 代价/风险 |
  | --- | --- | --- | --- |
  | 模拟电压/电流 | 电桥、RTD、霍尔、模拟传感器 | 简单、延迟低 | 受源阻抗/噪声/参考精度限制，长线易被污染 |
  | I2C | 低速多传感器（温度/湿度/气压/IMU） | 两线、可多设备 | 总线电容/上拉受限，长线差，需地址规划 |
  | SPI | 高速/大数据量（IMU、ADC、磁编码器） | 速率高、全双工 | 线多、片选多、时序模式要求 |
  | 脉冲/频率 | 编码器、流量计、转速 | 抗幅度噪声、易隔离 | 需整形/计数，高频时带宽与抖动受限 |
  | 开关量/干接点 | 限位、门磁、急停 | 简单、可靠 | 需去抖、上拉、ESD/浪涌保护 |

- **为什么**：接口选错后，滤波器、上拉、隔离都救不回来；例如长线模拟信号把地电位差直接串进 ADC，软件滤波只能掩盖不能消除。
- **怎么做**：按表逐项打分（精度/速率/距离/成本/隔离），记录选择理由；同一系统尽量统一接口族以减少驱动与测试工作量；对“需要隔离”的传感器优先选数字接口+数字隔离，而不是模拟隔离放大器（成本/精度权衡）。
- **怎么查**：用接口契约表逐项对照 datasheet；联调先测电平/波形再调协议；不通过 → 换接口/加转换/加隔离。
- **依据**：`04-interfaces.md` 的接口四问与各总线规则；`docs/knowledge/components/09-sensors-actuators.md` 的传感器参数（待核验）。

### KP-SCH-162 I2C 传感器接入：上拉、地址、中断与总线电容

- **判据**：I2C 传感器必须校核：上拉范围（`Rp(min)=(VDD−VOL)/IOL`、`Rp(max)=tr/(0.8473·Cb)`，见 `04-interfaces.md` KP-SCH-055 与 `PCB-RULE-I2C-001`）、地址唯一且标注设置方式、总线电容 ≤400pF（标准/快速模式）、中断输出为开漏需上拉并接到支持边沿/电平唤醒的 GPIO、时钟延展（clock stretching）是否被主控支持。
- **为什么**：I2C 故障绝大多数不是协议问题，而是上拉过大导致上升沿慢、地址冲突、总线电容超限；传感器中断脚若悬空或上拉缺失，会漏事件或误触发。
- **怎么做**：
  - 示例：3.3V、`Cb=200pF`、400kHz → `Rp(min)≈967Ω`、`Rp(max)≈1.77kΩ`，取 1.2~1.5kΩ；100kHz 时可放宽到 4.7kΩ（按规范与实测）。
  - 地址：用 ADDR 引脚接 GND/VDD/悬空（按 datasheet，不允许真悬空）设置；同型号多颗必须能区分；冲突时用 I2C mux（分路器）而不是改上拉。
  - 中断：开漏输出 + 10kΩ 上拉到传感器 IO 电压；GPIO 配置为边沿触发并保留电平状态；中断线远离 SCL/SDA 与开关节点。
  - 电源：传感器电源加 100nF+1µF 去耦；上电顺序与复位时间按 datasheet，必要时主控延时后再访问。
- **怎么查**：示波器测 SCL/SDA 上升时间与高电平；I2C 扫描全部地址并与分配表对照；中断脚逐个触发验证；总线挂满后复测。不通过 → 调上拉/加分路/降速/改地址。
- **依据**：`04-interfaces.md` KP-SCH-055～058；`PCB-RULE-I2C-001`；传感器 datasheet 的地址表、时序与中断极性。

### KP-SCH-163 SPI 传感器接入：片选、时序模式与 MISO 三态

- **判据**：SPI 传感器必须校核：每个从机独立 CS 且默认不选中（上拉）、CPOL/CPHA 与从机一致、SCLK ≤ 从机上限并核算走线/负载、MISO 在 CS 无效时高阻（否则多从机冲突）、传感器数据就绪（DRDY）中断脚处理、上电/复位后首次访问延时。长走线/多负载时降速优先于串阻。
- **为什么**：SPI 是推挽高速总线，两个从机同时驱动 MISO 会短路；模式不匹配表现为“数据整体移位”；CS 浮空会让从机误响应上电噪声。
- **怎么做**：
  - CS 上拉 10kΩ 到从机 IO 电压；未用 CS 默认无效；SCLK/MOSI 可串 22~100Ω 阻尼（按实测过冲决定）。
  - 数据就绪用独立 GPIO 中断（开漏/推挽按 datasheet），不要靠轮询牺牲实时性；首次上电按 datasheet 等待 `tPU` 后再访问。
  - 高速/长线：降低 SCLK、缩短走线、必要时加时钟缓冲；MISO 可串小电阻抑制振铃。
  - 多从机共享 SPI 时确认从机 MISO 三态特性；不满足时加缓冲/多路复用。
- **怎么查**：逻辑分析仪抓 CS/SCLK/MOSI/MISO，核对采样沿与数据窗口；逐个从机单独读写；上电瞬间测 CS 电平。不通过 → 改片选/降速/加缓冲。
- **依据**：`04-interfaces.md` KP-SCH-059～061；传感器 datasheet 的 SPI 时序图与 CPOL/CPHA 定义。

### KP-SCH-164 模拟传感器激励：恒压/恒流与比例式测量

- **判据**：模拟传感器必须明确激励方式：恒压激励（电桥/电位器）或恒流激励（RTD）；若传感器输出与激励成比例，优先做**比例式测量**——ADC 参考与传感器激励同源，使激励的慢漂移在比值中抵消；恒流激励要校核电流精度、温漂与自热；激励电源的噪声直接进入测量结果（除非比例式）。
- **为什么**：激励不稳＝灵敏度不稳。1% 的激励误差在非比例式测量里就是 1% 的读数误差；比例式测量能把电源容差/温漂抵消掉，是低成本高精度的重要手段。
- **怎么做**：
  - 比例式：`Vout = k × Vex`，ADC `VREF = Vex` → `码值 = k × 2^N`，与 Vex 无关；实现上让基准与激励共用同一路 LDO/基准（注意负载电流与压降，见 `08-analog-signal-chain.md` KP-SCH-141）。
  - 非比例式：激励用基准缓冲/精密 LDO，误差按 `08-analog-signal-chain.md` KP-SCH-140 预算。
  - 恒流激励：`I = VREF/Rset`，用运放+基准实现；核算传感器自热 `P = I²R` 与温升（见 KP-SCH-166）。
  - 激励走线按小电流 Kelvin 处理，避免与数字/电机电流共用。
- **怎么查**：改变激励电压/电流看读数是否按比例变化；测激励噪声与温漂；比例式系统做电源拉偏测试（±5%）看读数变化。不通过 → 改比例式/加基准/加滤波。
- **依据**：传感器 datasheet 的激励要求（电压/电流/比例式）；`08-analog-signal-chain.md` KP-SCH-140/141；`PCB-RULE-SHUNT-001` 的开尔文原则。

### KP-SCH-165 惠斯通电桥与应变片：灵敏度、非线性与引线补偿

- **判据**：电桥输出按 `Vout ≈ Vex × (ΔR/R) / 4`（单臂工作，四臂全桥为 `Vex × ΔR/R`）估算；必须校核：激励稳定性、桥臂匹配（否则零点失调大）、引线电阻（2 线制引线电阻直接串入桥臂造成误差，长线用 3 线/4 线补偿）、放大器共模与增益（见 `08-analog-signal-chain.md` KP-SCH-138）。
- **为什么**：电桥输出是 mV 级甚至 µV 级，桥臂失配与引线电阻产生的零点/增益误差可能远大于被测量；引线电阻随温度变化会漂移，必须补偿。
- **怎么做**：
  - 示例：`Vex=3.3V、ΔR/R=0.1%` → 单臂输出约 `3.3 × 0.001/4 ≈ 0.825mV`；增益 1000 → 0.825V，进 3.3V ADC 约 1/4 量程。若目标 12 位分辨率（LSB≈0.8mV），折算到电桥输入约 0.8µV，对应 `ΔR/R` 约 1ppm，需要低噪声 INA + 滤波。
  - 零点：桥臂电阻用 0.1% 配对，或加零点调零网络（电位器/数字校准）；调零不要破坏桥臂对称性。
  - 引线：2 线制只适合短引线；3 线制补偿单侧引线电阻；4 线制（开尔文）精度最高但线多。
  - 激励与放大：比例式测量（KP-SCH-164）+ INA 差分输入 + RC 低通；共模点按 INA 输入范围设置。
- **怎么查**：加已知负载/砝码看输出线性与重复性；短接桥臂（模拟零应变）测零点漂移；改变引线长度看误差；高低温复测。不通过 → 改引线制式/配对电阻/加校准。
- **依据**：电桥公式（标准电路理论）；应变片 datasheet 的灵敏度系数（gauge factor）与桥路接法；INA datasheet 的共模/增益。

### KP-SCH-166 RTD 与热敏电阻：激励电流、自热与引线补偿

- **判据**：RTD（如 Pt100/Pt1000）用恒流激励：`V = I × R(T)`，灵敏度 `dR/dT` 按器件（Pt100 约 0.385Ω/°C，需按标准/器件复核）；必须校核自热 `P = I²R` 与封装热阻带来的温升、引线电阻误差（2 线制误差 = 2×引线电阻，3/4 线补偿）；NTC 用 β 公式 `R(T) = R25 × exp(B × (1/T − 1/298.15))`，非线性强，宽温区需查表/多项式或分段校准。
- **为什么**：RTD 的电阻变化小（Pt100 每 °C 仅 0.385Ω），1mA 激励只有 385µV/°C，极易被噪声/失调淹没；自热会让读数偏高；NTC 的 β 公式在宽温区误差可达数 °C，不能只靠两点线性化。
- **怎么做**：
  - 示例：`Pt100、I=1mA` → `0.385mV/°C`；自热 `P = 1mA² × 100Ω = 0.1mW`，若封装热阻 400°C/W，温升约 0.04°C（可接受）；若用 5mA，自热 2.5mW、温升约 1°C，必须降电流或脉冲激励。
  - 引线：2 线制 0.5Ω 引线 → 约 1.3°C 误差；3 线制用匹配引线抵消；4 线制最准。
  - NTC 示例：`R25=10kΩ、B=3950`，0°C 时 `R = 10k × exp(3950 × (1/273.15 − 1/298.15)) ≈ 33.6kΩ`；用分压+ADC 时按 `08-analog-signal-chain.md` KP-SCH-125 算源阻抗。
  - 激励电流源用基准+运放实现，走线开尔文；RTD 与 NTC 的滤波电容按测量带宽选。
- **怎么查**：恒温槽/冰水混合物（0°C）与沸水（100°C，按海拔修正）两点校准；改变激励电流看自热漂移；三线/四线接法对比引线误差。不通过 → 改激励/改接线/加校准。
- **依据**：IEC 60751（Pt100 分度与容差，需按标准原文复核）；NTC datasheet 的 B 值与 R-T 表；`08-analog-signal-chain.md` KP-SCH-164。

### KP-SCH-167 热电偶：冷端补偿与 µV 级放大

- **判据**：热电偶输出是 µV/°C 级（K 型室温附近约 41µV/°C，按分度表复核），必须做冷端补偿（CJC）：冷端温度由本地温度传感器测量并加入计算；前端需低失调/低漂移/低噪声放大（增益 100~1000），输入共模与偏置要处理（热电偶浮空时加偏置电阻到地，避免共模漂移）；开路检测（断线）应有上拉/偏置方案。
- **为什么**：热电偶信号极小，运放失调（µV 级）与温漂直接变成温度误差；冷端不补偿等于把室温误差全部算进测量；输入浮空会让共模电压漂到轨。
- **怎么做**：
  - 误差示例：若前端总噪声 10µVrms，折算温度约 `10µV / 41µV/°C ≈ 0.24°C`；若运放失调 100µV 不校准，则是 2.4°C 误差。
  - CJC：冷端等温块 + 本地温度传感器（如 I2C 温度传感器）贴近冷端；软件按分度表把热电势换算成温度。
  - 输入偏置：热电偶两端各接高阻（如 1MΩ）到共模点（地或偏置电压），提供偏置电流回路并便于断线检测；注意偏置电阻热噪声。
  - 滤波：RC 低通 + 工频陷波（按需）；输入保护用低漏电 TVS/串阻，避免漏电影响 µV 信号。
- **怎么查**：冰水（0°C）与已知温度源校准；短路输入端（模拟 0°C 冷端）测失调；断开热电偶看是否能检测到开路；高低温测漂移。不通过 → 加校准/换低漂移运放/改 CJC。
- **依据**：热电偶分度表（IEC 60584 / NIST 数据，需按标准原文复核）；运放 datasheet 的失调/漂移/噪声；`08-analog-signal-chain.md` KP-SCH-152。

### KP-SCH-168 霍尔与磁编码器接口：上拉、供电噪声与去抖

- **判据**：开关型霍尔/磁编码器输出若为开漏，必须上拉（典型 4.7~10kΩ，按速率与总线电容算上升时间）；供电必须干净（内部斩波/比较器对电源噪声敏感），加 100nF+1µF 去耦；机械抖动/磁滞不足导致的边沿抖动要用施密特或软件去抖处理；线性霍尔/磁编码器（SPI/ABZ）按数字接口或差分模拟接口处理。
- **为什么**：霍尔输出常在电机附近，换向噪声/电机电流会耦合到供电与输出；开漏无上拉则完全读不到高电平；磁滞不足会在阈值附近多次翻转，造成计数错误。
- **怎么做**：
  - 上拉按 `Rp(max) = tr/(0.8473×Cb)` 估算，例如 `tr=1µs、Cb=100pF → Rp(max)≈11.8kΩ`，取 4.7~10kΩ；高速编码器取更小上拉并核算功耗。
  - 供电从干净的 LDO 引出，串联磁珠/RC 隔离电机噪声；去耦靠近器件。
  - 输出串阻（100Ω~1kΩ）+ 对地小电容（按边沿速率选，几十 pF~1nF）做 RC 滤波，再进施密特/GPIO；软件去抖时间要大于机械抖动但小于最小脉宽。
  - 磁编码器（SPI/ABZ/UVW）按 `04-interfaces.md` 的 SPI/差分规则处理，ABZ 差分对按 `PCB-RULE-DIFF-001`。
- **怎么查**：示波器测输出边沿与抖动（电机运行时）；测供电纹波；慢速转动看是否丢计数/多计数。不通过 → 调上拉/滤波/去抖/改供电。
- **依据**：霍尔/编码器 datasheet 的输出结构、上升/下降时间与磁滞；`04-interfaces.md` KP-SCH-055/059。

### KP-SCH-169 光电/增量编码器脉冲输入：整形、计数与最大频率

- **判据**：脉冲输入必须校核最大频率 `f_max = (RPM/60) × PPR × 4`（四倍频正交解码时），并保证输入滤波/光耦/施密特的带宽 ≥ `2~5 × f_max`；输入要有施密特整形与上拉/下拉确定电平；长线/光耦输入要算传输延迟与脉宽失真；计数丢脉冲通常来自滤波过强或中断延迟。
- **为什么**：编码器脉冲是位置/速度的唯一样本，丢一个脉冲就是固定位置误差；滤波过强会把窄脉冲吃掉，滤波过弱会把噪声当脉冲。
- **怎么做**：
  - 示例：`3000rpm、1000PPR、四倍频` → `f_max = 50 × 1000 × 4 = 200kHz`，滤波 `fc` 至少 400kHz~1MHz；若走光耦（低速光耦），200kHz 可能已超出其能力，需选高速光耦/数字隔离器。
  - 输入链：连接器 → 串阻/TVS → RC 低通 → 施密特（74HC14 类，按电源阈值）→ MCU 定时器/编码器接口；差分输入（A+/A−）用差分接收器。
  - 计数：优先用硬件编码器接口/定时器；软件中断要评估最坏中断延迟与脉冲间隔。
  - 电源与地：编码器电源与电机电源分离，编码器线屏蔽/双绞，屏蔽按整机方案接地。
- **怎么查**：信号发生器扫频到 `f_max` 看计数是否丢；电机实际运行对比理论计数；示波器测脉宽与延迟。不通过 → 降速/换接收器/改滤波/改计数方式。
- **依据**：编码器 datasheet 的 PPR、最大响应频率与输出类型；`04-interfaces.md` 的电平与保护规则；`PCB-RULE-DIFF-001`（差分时）。

### KP-SCH-170 传感器中断/唤醒脚与低功耗时序

- **判据**：可唤醒 MCU 的传感器中断必须：开漏/推挽结构明确、上拉/下拉确定、GPIO 支持边沿唤醒、中断脉宽 > MCU 唤醒延迟（否则丢事件）、休眠前清中断标志并配置好唤醒源；需要“事件锁存”的用传感器内部锁存或外部触发器；中断线加串阻与 ESD 保护（外露时）。
- **为什么**：低功耗系统靠中断唤醒，脉宽不足或标志未清会导致“睡下去就再也醒不来/醒来读不到事件”；中断脚悬空会在休眠时被噪声误唤醒，白白耗电。
- **怎么做**：
  - 计算：若 MCU 从休眠到 GPIO 可响应需 100µs，则中断脉宽必须 >100µs（按 datasheet 与实测）；不足时用传感器锁存模式或外部 D 触发器。
  - 上拉/下拉按有效电平选择；未用中断脚接地或接固定电平，不要悬空。
  - 休眠流程：配置唤醒源 → 清标志 → 进休眠 → 唤醒后先读状态寄存器再清标志（避免丢事件）。
  - 外露/长线中断加 TVS 与串阻（`05-protection.md`）。
- **怎么查**：示波器测中断脉宽与 MCU 唤醒时序；反复休眠/唤醒 100 次看是否丢事件；测休眠电流（误唤醒会明显偏高）。不通过 → 改锁存/加触发器/调时序。
- **依据**：传感器 datasheet 的中断/唤醒时序与锁存选项；MCU datasheet 的唤醒延迟；`08-analog-signal-chain.md` KP-SCH-159 的测试点思路。

## 二、校准、激励、隔离与长线

### KP-SCH-171 传感器校准：零点、满量程、多点与温补

- **判据**：每个传感器通道必须有校准方案：至少零点+满量程两点（线性传感器），非线性传感器（NTC/热电偶/压力）用多点分段/多项式；校准基准可溯源；校准系数带版本存非易失存储；宽温应用做温度补偿（多点温箱或器件内置补偿）；校准记录含日期/设备/环境/操作者。
- **为什么**：传感器本身的容差（灵敏度/零点）通常远大于电路误差；不校准的话，前端做得再好也只是“精确地测了一个不准的传感器”。
- **怎么做**：
  - 线性：`y = a×x + b`，两点定 a/b；多点用最小二乘拟合；非线性用查表+插值（表长按精度定）。
  - 温补：记录不同温度下的零点/灵敏度，建立 `a(T)/b(T)` 或二维表；或选带内部温度补偿的传感器。
  - 存储：EEPROM/Flash 带版本、校验与校准时间；固件升级不覆盖校准区。
  - 产线：校准工装要能给出稳定、可溯源的激励（标准电阻/标准电压/砝码/恒温槽），并记录环境温度。
- **怎么查**：校准后回测 3~5 个点，误差在目标内；换板抽检一致性；高低温复测；不通过 → 重新校准/检查硬件/加温补。
- **依据**：`08-analog-signal-chain.md` KP-SCH-131 的两点校准；传感器 datasheet 的精度/温漂指标；计量溯源要求（按项目质量体系）。

### KP-SCH-172 传感器激励与参考供电：噪声、时序与负载

- **判据**：传感器激励/参考电源必须与数字电源隔离（磁珠/LC 或独立 LDO），噪声按测量分辨率折算：激励噪声直接按比例进入读数（非比例式）；上电时序要保证“先供电、后采样”，传感器稳定时间（datasheet 的 `tPU`/建立时间）内不得采样；激励电源的负载调整率与温度漂移计入预算。
- **为什么**：传感器供电上的数字噪声/DC-DC 纹波会调制传感器输出；上电即采样会读到未稳定的值；激励电源的负载变化（多传感器共用）会互相串扰。
- **怎么做**：
  - 独立 LDO/基准给传感器供电，加 100nF+1~10µF 去耦；必要时每颗传感器单独 RC/磁珠隔离。
  - 噪声预算：若激励噪声 1mVrms、满量程 3.3V、目标 12 位（0.8mV LSB），则噪声已超过 1 LSB，必须滤波/降噪或做比例式。
  - 时序：上电 → 延时 `tPU`（按 datasheet，常见 ms~百 ms 级）→ 首次采样；低功耗系统可用 MOS 开关给传感器供电，采样前提前上电并等待稳定。
  - 共用激励时评估负载电流变化引起的压降（`ΔV = ΔI × R_trace`）。
- **怎么查**：测激励电源纹波/噪声；上电后逐时间点采样看稳定过程；多传感器同时工作看串扰。不通过 → 加滤波/独立供电/调时序。
- **依据**：传感器 datasheet 的供电范围、`tPU`、对电源噪声的敏感度；`08-analog-signal-chain.md` KP-SCH-140/141 的基准噪声与负载调整。

### KP-SCH-173 隔离传感器接口：隔离放大器与数字隔离

- **判据**：传感器与采集系统不共地/地电位差大/有安规隔离要求时，必须隔离：模拟传感器用隔离放大器（隔离侧供电 + 差分输出），数字传感器用数字隔离器（I2C/SPI 专用，注意方向与时钟延展）；隔离电源用隔离 DC-DC 或变压器；隔离器必须满足目标绝缘耐压与爬电距离（`PCB-RULE-ISO-001`），并核算 CMTI 与传输延迟。
- **为什么**：隔离切断地环流与共模电压，是长线/工业环境的根本方案；但隔离器有传输延迟、脉宽失真与 CMTI 限制，选型不当会“隔离了但不通信/精度变差”。
- **怎么做**：
  - 模拟隔离：选隔离放大器（注意增益误差、失调漂移、带宽）；隔离侧电源去耦，隔离带下方禁止铺铜/走线。
  - 数字隔离：I2C 用支持双向与时钟延展的专用隔离器；SPI 用多通道数字隔离器（注意方向与延迟匹配）；隔离器两侧电源各自去耦。
  - 隔离电源：按负载电流选隔离 DC-DC，输出加 LC 滤波降低纹波（隔离电源纹波会进入模拟前端）。
  - 爬电/间隙按目标标准（IEC/UL/产品认证）计算并留余量（需按标准原文复核）。
- **怎么查**：两侧分别测波形/电平；做共模瞬态/地电位差测试；测隔离耐压与漏电流（按安规要求）；测延迟对时序的影响。不通过 → 换隔离器/改电源/改拓扑。
- **依据**：`PCB-RULE-ISO-001`；隔离器 datasheet 的 CMTI、隔离耐压、传输延迟；`04-interfaces.md` KP-SCH-058/064/071。

### KP-SCH-174 长线传感器：屏蔽、共模、浪涌与串扰

- **判据**：长线（>0.5~1m 量级，按环境与速率判断）必须按“差分/屏蔽/保护”设计：差分传输优先、屏蔽双绞、屏蔽层单端接地（按整机 EMC 方案）、两端加共模电感/TVS、接收端加串阻与 RC；单端长线必须核算地电位差与共模范围；长线与电机/电源线分开走，避免平行长距离。
- **为什么**：长线是天线也是接收天线；地电位差、共模噪声、浪涌都随线长增加；屏蔽层两端接地会形成地环流，反而引入工频噪声。
- **怎么做**：
  - 差分对（如 RS485/编码器 A/B）按 `04-interfaces.md` 与 `PCB-RULE-DIFF-001` 处理，终端/偏置按总线规则。
  - 保护顺序：连接器 → TVS/共模电感 → 串阻 → 滤波 → 接收器；TVS 地就近下地（`PCB-RULE-ESD-001`）。
  - 屏蔽：单端接地（一般在接收端或机壳地），另一端悬空/经电容接地（按 EMC 测试结果定）；屏蔽层 360° 搭接连接器外壳。
  - 布线：长线接口远离 DC-DC 电感、电机驱动、晶振；必要时包地/加屏蔽罩。
- **怎么查**：注入共模/EFT/浪涌测试；长线实测误码/丢脉冲；近场探头扫描；不通过 → 改屏蔽/加滤波/改拓扑。
- **依据**：`05-protection.md` 的接口保护顺序；`PCB-RULE-ESD-001`、`PCB-RULE-ISO-001`；`04-interfaces.md` 的 CAN/RS485 终端规则。

## 三、执行器驱动：H 桥、步进、继电器与电磁阀

### KP-SCH-175 H 桥电机驱动：拓扑、死区与损耗

- **判据**：H 桥必须校核：上下管死区（防止直通）、栅极驱动电平与电荷（避免半开）、体二极管/续流路径、`Rds(on)` 导通损耗 `P = I² × (Rds_high + Rds_low)`、开关损耗、电流采样方式（低边/在线/霍尔）、刹车/滑行状态与默认安全状态。电机电源与逻辑电源分开去耦。
- **为什么**：直通是 H 桥最致命的失效（瞬间大电流烧管）；死区过大导致低速抖动/失真，过小则直通；导通损耗与热设计不匹配会过热降额甚至热关断。**失败模式**：死区不足或栅极驱动半开导致上下管直通（shoot-through），母线电流瞬间可达数十安培炸管；续流/钳位缺失导致关断尖峰击穿 MOS。
- **怎么做**：
  - 示例：`I=2A、Rds(on)=50mΩ × 2 管` → 导通损耗 `P = 4 × 0.1 = 0.4W`；开关损耗按 `Psw ≈ 0.5 × Vbus × I × (tr+tf) × fPWM` 估算（`12V、2A、100ns、20kHz` → 约 0.024W），再乘管数并做热校核。
  - 死区：按 MOS 与驱动器 datasheet 设（常见几十~几百 ns，需按器件复核），驱动器自带死区插入时确认最小/最大值。
  - 栅极：按 Qg 选驱动电流 `Igate ≈ Qg/t_switch`；栅极串阻抑制振铃，栅源下拉电阻保证默认关断。
  - 采样：低边采样电阻开尔文走线（`PCB-RULE-SHUNT-001`）；在线采样需高共模 CSA（见 `08-analog-signal-chain.md` KP-SCH-139）。
  - 续流：MOS 体二极管或外接快恢复二极管；刹车（双下管导通）与滑行（全关）按控制需求定义，注意刹车时电流回路。
- **怎么查**：测上下管栅极波形与死区；满载测导通损耗/温升；短路/堵转测试保护动作；示波器看开关节点振铃。不通过 → 调死区/换管/加驱动/改热设计。
- **依据**：MOSFET datasheet 的 Rds(on)、Qg、SOA；栅极驱动器 datasheet 的死区/驱动能力；`PCB-RULE-THERMAL-001`。

### KP-SCH-176 电机驱动体电容与再生能量

- **判据**：电机驱动电源必须有大体电容吸收 PWM 电流与再生能量：`ΔV = I × Δt / C`（按 PWM 周期/换向瞬态估算）；电机减速/换向时机械能回灌，母线电压会升高，必须有钳位（TVS/制动电阻/吸收电容）且不超过 MOS 与电容耐压；体电容的纹波电流额定值必须满足 `Irms`。
- **为什么**：PWM 电流是脉冲，靠体电容就近供给，否则母线电压塌陷/振铃；再生能量没有泄放路径会把母线电压泵高，击穿 MOS/电容（“一减速就炸管”）。
- **怎么做**：
  - 示例：`I=2A、Δt=1ms、C=470µF` → `ΔV ≈ 4.3V`，若母线 12V 则跌到 7.7V，可能触发欠压；需要更大电容或降低 `Δt`（提高 PWM 频率/加电感）。
  - 再生：估算能量 `E = 0.5 × J × ω²`（旋转）或 `0.5 × L × I²`（电感），选择 TVS 钳位功率/制动电阻功率时按最坏工况并留余量；钳位电压 < MOS/电容耐压的 80%。
  - 体电容：低 ESR 电解/聚合物 + 100nF~1µF 高频并联；纹波电流按 datasheet 降额（常见按 80% 额定）。
  - 布局：体电容靠近 H 桥，功率回路面积最小。
- **怎么查**：满载 PWM 测母线纹波；急停/换向测母线过压尖峰；测电容温升；不通过 → 加电容/加钳位/改控制减速曲线。
- **依据**：电容 datasheet 的纹波电流/ESR/耐压；TVS datasheet 的钳位与峰值功率；`PCB-RULE-THERMAL-001`。

### KP-SCH-177 步进电机驱动：电流设定、细分与失步

- **判据**：步进驱动必须校核：相电流设定（斩波恒流型按 `I ≈ Vref/(K × Rsense)`，K 按驱动 IC datasheet，不能套用别家公式）、电源电压与电机额定电压/电感匹配、细分与最大步进频率、衰减模式（快/慢/混合衰减）对电流波形与噪声的影响、失步/堵转检测（如有）、默认使能状态（上电不应自动通电发热）。
- **为什么**：相电流设小则力矩不足失步，设大则电机/驱动过热；细分高但控制器发脉冲能力不足会丢步；衰减模式不当会导致低速噪声大/高速力矩下降。
- **怎么做**：
  - 电流公式必须查所选驱动 IC datasheet；示例：`Vref=1V、Rsense=0.1Ω、K=8`（假设，需按 datasheet）→ `I≈1/(8×0.1)=1.25A`。
  - 电气时间常数 `τ = L/R`：`L=2mH、R=2Ω → τ=1ms`；高速时电流来不及建立，力矩下降，需要更高母线电压或更低电感电机。
  - 细分/频率：`f_step = (RPM/60) × 步数/转 × 细分`；确认 MCU 定时器能输出且不丢脉冲。
  - 使能（EN）默认关断/保持？按安全需求；保持电流可降额（见 KP-SCH-179 的保持电流思路）。
  - 驱动 IC 的电源去耦、散热焊盘、电流采样开尔文按 datasheet。
- **怎么查**：测相电流波形（电流探头）与设定值；低速/高速分别看失步；测驱动与电机温升；堵转测试保护；不通过 → 调电流/细分/衰减/母线电压。
- **依据**：步进驱动 IC datasheet 的电流公式、衰减模式、时序；电机 datasheet 的相电感/电阻/额定电流；`PCB-RULE-THERMAL-001`。

### KP-SCH-178 继电器驱动：线圈电流、续流与触点灭弧

- **判据**：继电器线圈驱动必须校核：线圈电流 `I = V/Rcoil`、驱动管/驱动 IC 的电流与功耗、续流二极管（线圈两端反并联，方向正确）、线圈关断时的电压尖峰被钳位在驱动管耐压内、触点侧按负载类型加 RC/压敏/续流（直流感性负载必须加续流，交流负载用 RC/压敏）、触点额定电压/电流按负载降额。
- **为什么**：线圈是电感，关断瞬间 `V = L×di/dt` 可达数百至数千伏，无续流会击穿驱动管；触点断开感性负载会拉弧，烧蚀触点、产生 EMI。
- **怎么做**：
  - 示例：`V=5V、Rcoil=70Ω → I≈71mA`，功耗 `P=0.36W`；驱动管 `hFE` 或 MOS 阈值按 `Ib ≥ Ic/hFE × 2` 或 `Vgs` 足够；基极/栅极加下拉保证默认关断。
  - 续流：线圈反并联二极管（如 1N4148/肖特基，按电流选），阴极接电源侧；需要快速释放时用二极管+齐纳（提高释放电压但注意驱动管耐压）。
  - 触点：直流感性负载加续流二极管/RC；交流负载加 RC/压敏电阻（按负载电流/电压选，需按继电器 datasheet 的寿命曲线降额）。
  - 高压/大电流负载优先用 MOS/固态继电器替代机械触点。
- **怎么查**：示波器测线圈电流与关断尖峰（探头注意耐压）；测驱动管温升；带实际负载做寿命/拉弧测试；不通过 → 加续流/换驱动管/换继电器/改固态。
- **依据**：继电器 datasheet 的线圈参数、触点额定与寿命曲线；驱动管 SOA/耐压；`05-protection.md` 的感性负载保护原则。

### KP-SCH-179 电磁阀/螺线管驱动：续流、保持电流与热

- **判据**：电磁阀/螺线管必须校核：吸合电流与保持电流（吸合后降流可显著降功耗/温升）、续流路径与关断尖峰、驱动管 SOA/热、电源瞬态（吸合电流冲击导致母线跌落）、动作频率与占空比；降流保持用 PWM 时频率要高于可听/可感范围并避免啸叫。
- **为什么**：螺线管是强感性负载，吸合电流可达数安培，关断尖峰高；长期全额保持会发热、降低寿命；PWM 降流若频率不当会有噪声/抖动。
- **怎么做**：
  - 示例：`12V、R=6Ω → I≈2A`，吸合功率 24W；保持阶段用 30%~50% PWM 降流，平均功率可降到 2~7W 量级（按阀 datasheet 的最小保持电流）。
  - 续流：反并联二极管 + 必要时齐纳/TVS 加快释放；驱动管耐压 ≥ 母线 + 尖峰余量；栅极/基极默认关断。
  - PWM 降流：频率选 20kHz 以上（避免可听噪声）或按阀的机械共振避开；电流纹波 `ΔI = V×D×(1−D)/(L×f)` 要小于保持电流余量。
  - 电源：吸合瞬间大电流要由体电容供给（见 KP-SCH-176），避免拉低逻辑电源。
- **怎么查**：测吸合/保持电流波形与温升；测关断尖峰；听/测 PWM 啸叫与抖动；不通过 → 加续流/改 PWM/加电容/换驱动。
- **依据**：电磁阀 datasheet 的吸合/保持电流、占空比与寿命；驱动管 SOA；`PCB-RULE-THERMAL-001`。

### KP-SCH-180 有刷电机换向噪声与滤波

- **判据**：有刷电机是宽带噪声源（换向火花），必须在电机端子就近加滤波：端子间陶瓷电容（典型 10~100nF，按电机与 EMC 结果）、端子对壳电容、必要时加磁珠/共模电感；电机线双绞、远离信号线；编码器/传感器线与电机线分开走线；电机外壳接地按整机 EMC 方案。
- **为什么**：换向火花产生几十 MHz 的宽带噪声，会通过传导与辐射进入传感器/通信线；只靠板端滤波往往不够，必须在电机端子就近抑制。
- **怎么做**：
  - 电机端子：`C1` 跨接端子、`C2/C3` 端子对壳（容量按漏电流与 EMC 要求，Y 电容需满足安规漏电流）；磁珠/共模电感按电流选型（饱和电流足够）。
  - 布线：电机线双绞、短、远离信号线；H 桥到电机端子的功率回路面积最小。
  - 传感器：编码器线屏蔽/双绞，必要时加共模电感；模拟传感器远离电机线。
  - 软件/驱动：合适的 PWM 频率与斜率控制（部分驱动器可调）也能降低 EMI。
- **怎么查**：EMI 预扫（30MHz~1GHz）对比加/不加滤波；近场探头找噪声源；电机运行时测传感器/通信误码；不通过 → 加滤波/改布线/改驱动斜率。
- **依据**：电机 datasheet 的 EMC 建议；`PCB-RULE-EMC` 相关规则与 `docs/knowledge/pcb/05-emc-esd-thermal.md`；`PCB-RULE-PLACE-DCDC-001` 的功率回路布局原则。

### KP-SCH-181 执行器故障检测：开路、短路与堵转

- **判据**：每个执行器通道应有可量测的故障检测方案：开路（负载未接/线断）用上拉/下拉或电流检测判断；短路（对地/对电源）用过流阈值/硬件比较器；堵转用“电流超阈值 + 无位置变化/无速度”组合判断；检测阈值要留出正常工作峰值余量（如 1.5~2 倍），并定义故障后的安全动作（关断/降级/报警）。
- **为什么**：没有故障检测时，开路表现为“控制没反应”，短路会烧驱动，堵转会过热；有检测才能在上报故障的同时保护硬件。
- **怎么做**：
  - 开路：低边驱动关断时通过上拉/下拉测端子电压；或采样电流接近 0 且驱动使能 → 判开路。
  - 短路：硬件比较器 + 逐周期限流（快速）与软件过流（慢速）双保险；比较器阈值按 `I_trip × Rsense` 设置（见 `08-analog-signal-chain.md` KP-SCH-147）。
  - 堵转：电流 > 阈值且编码器/霍尔无变化超过设定时间（如 100~500ms，按机构）；阈值与延时都要可配置。
  - 故障动作：立即关断输出、置故障标志、按需重试（次数/间隔受限）；故障记录可读。
- **怎么查**：人为断开负载/短接输出/堵转，验证检测与保护动作；测阈值余量（正常峰值不误报）；不通过 → 调阈值/加检测/改保护。
- **依据**：驱动 IC 的过流/故障引脚与阈值；`05-protection.md` 的过流保护协调；`08-analog-signal-chain.md` KP-SCH-147/155。

### KP-SCH-182 执行器驱动安全：上电默认、互锁与急停

- **判据**：所有执行器驱动必须有确定的安全默认态：上电/复位期间输出关断（栅极下拉、使能默认无效、继电器默认释放）；H 桥不得同时导通上下管；正反转/多执行器之间按机械安全要求做硬件互锁（避免软件单点失效）；急停/安全输入应能硬件切断驱动使能（不依赖固件）；故障后不得自动重启到危险动作。
- **为什么**：上电毛刺/复位期间 IO 浮空会让电机/继电器误动作；纯软件互锁在固件跑飞时失效；急停若走软件路径，响应时间不可保证。
- **怎么做**：
  - 默认态：栅极/基极加下拉电阻，使能脚上拉/下拉到“关断”；MCU 复位期间 IO 为高阻时由外部电阻定态。
  - 互锁：正反转继电器/MOS 用硬件互锁（交叉串接常闭触点或逻辑门），软件互锁作为第二层。
  - 急停：急停按钮直接切断驱动电源/使能（安全继电器/接触器），并给 MCU 一个状态输入；按安全等级要求评估（需按整机安规/功能安全标准复核）。
  - 故障恢复：故障清除后需人工确认或上电复位，不自动恢复危险动作。
- **怎么查**：反复上下电看执行器是否误动；拔掉 MCU/复位期间测输出；急停响应时间实测；故障注入后看是否自动重启。不通过 → 加下拉/互锁/硬件急停。
- **依据**：驱动 IC 的使能/默认状态；功能安全/机械安全要求（按整机标准复核）；`05-protection.md` 的保护顺序。

## 四、分区、测试与评审

### KP-SCH-183 传感器/执行器分区与布线：小信号 vs 大电流

- **判据**：原理图与 PCB 必须把“传感器小信号/模拟前端”与“执行器大电流/功率回路”分区：大电流回路（电机、继电器、电磁阀）面积最小、回流不经过小信号地；传感器供电与执行器供电分开（独立 LDO/磁珠）；模拟/脉冲信号线远离功率线与开关节点；跨区信号用差分/隔离/滤波；星形接地或分区单点汇合（见 `08-analog-signal-chain.md` KP-SCH-156）。
- **为什么**：执行器电流在地/电源阻抗上的压降与 `di/dt` 耦合会直接进入 µV/mV 级传感器信号；分区是最便宜有效的噪声控制手段。
- **怎么做**：
  - 布局顺序：连接器/保护 → 功率级（H 桥/继电器）→ 电源 → 数字 → 传感器/模拟前端；功率回路面积最小。
  - 地：功率地与小信号地分开走，在电源入口/星点汇合；传感器地回到采集芯片的 AGND（`07-analog-audio.md` KP-SCH-111 的原则）。
  - 供电：传感器 LDO 从干净电源取电，输入加 LC/磁珠；执行器电源单独走线、加体电容。
  - 信号：编码器/传感器线双绞/屏蔽，远离电机线；必要时加共模电感/隔离。
- **怎么查**：目检分区与回流路径；电机满载时测传感器噪声/读数跳动；近场探头扫描；不通过 → 改布局/改地/加滤波/加隔离。
- **依据**：`07-analog-audio.md` KP-SCH-110/111/133；`PCB-RULE-PLACE-ANALOG-001`、`PCB-RULE-PLACE-SENSOR-001`、`PCB-RULE-RETURN-001`。

### KP-SCH-184 传感器/执行器测试与可量测判据

- **判据**：每类接口必须有出厂/联调测试项与通过判据：传感器（零点/满量程误差、噪声、响应时间、断线检测）、I2C/SPI（全地址扫描、读写一致性、误码率）、脉冲输入（`f_max` 计数不丢）、执行器（吸合/动作电流、堵转/短路保护、温升）、隔离（耐压/漏电流）。判据要写数值窗口与测试条件，不能写“正常”。
- **为什么**：接口问题是“边界条件才暴露”的，只做功能演示会漏掉温漂、丢脉冲、保护不动作；可量测判据让问题在产线/联调阶段被拦住。
- **怎么做**：
  - 建测试表：项目/条件/仪器/通过判据/记录；示例判据：`I2C 全地址扫描无冲突`、`编码器 200kHz 计数 0 丢失`、`堵转 200ms 内关断`、`传感器零点漂移 < 1% FS`。
  - 高低温/电压拉偏按需做边界测试；执行器做带载测试而非空载。
  - 记录原始数据（波形/读数）归档，便于追溯与对比。
- **怎么查**：按测试表逐项执行并留证据；抽 3 项复测；不通过 → 定位硬件/固件/校准。
- **依据**：`08-analog-signal-chain.md` KP-SCH-159；`06-erc-review-checklist.md` KP-SCH-105；`PCB-RULE-TESTPOINT-001`。

### KP-SCH-185 传感器/执行器接口保护与 ESD

- **判据**：外露或长线的传感器/执行器接口必须有 ESD/浪涌保护：连接器 → 串阻/共模电感 → TVS/ESD 阵列 → 滤波 → 芯片；TVS 钳位电压低于后级绝对最大额定值（见 `05-protection.md` KP-SCH-075）、结电容匹配信号速率（编码器/高速信号用低电容）；执行器感性负载的续流与触点灭弧属于“内部应力保护”，同样不能省；保护器件地就近下地。
- **为什么**：传感器/执行器线缆是人体接触与浪涌入口；执行器关断尖峰是板内应力源。保护缺失时，一次 ESD/浪涌就损坏接口芯片，或执行器尖峰击穿驱动管。
- **怎么做**：
  - 接口保护链按 `05-protection.md` KP-SCH-073 的顺序；TVS 选型按工作电压/钳位/结电容三要素。
  - 编码器/高速脉冲用低电容 ESD 阵列；模拟传感器用低漏电 TVS（漏电会影响 µV/mV 信号）。
  - 执行器侧：续流二极管/RC/压敏按 KP-SCH-178/179；连接器端子间加 TVS 抑制插拔/线缆浪涌。
  - 保护器件放在连接器与芯片之间，地过孔就近；保护器件下方不走敏感信号。
- **怎么查**：IEC 61000-4-2 接触/空气放电、IEC 61000-4-4 EFT、IEC 61000-4-5 浪涌（按产品等级）；测试后复测功能/精度；不通过 → 换器件/改接地/加共模。
- **依据**：`05-protection.md` KP-SCH-073～090；`PCB-RULE-ESD-001`；`PCB-RULE-ISO-001`（隔离接口）。

### KP-SCH-186 传感器/执行器评审清单

- **判据**：评审必须逐项确认并有证据：接口选型理由、I2C 上拉/地址/中断、SPI 模式/片选、模拟激励与比例式、电桥/RTD 引线、热电偶 CJC、编码器 `f_max`、校准方案、隔离/长线保护、H 桥死区/损耗、步进电流/细分、继电器/电磁阀续流、故障检测、安全默认态、分区布线、测试判据。缺证据不得放行（`SCH-RULE-REVIEW-001`）。
- **为什么**：传感器/执行器问题的特点是“单看都对，联动才错”——电机一转传感器就跳、继电器一吸合 MCU 就复位；清单化评审才能覆盖跨域耦合。
- **怎么做**：用下表逐项打勾；对“需实测”项单列测试计划；问题单记录编号/位置/严重度/整改/证据；整改后重跑相关测试。
- **怎么查**：按表要证据；抽查 3 项做实测复现；不通过 → 整改后复评。

| 类别 | 检查项 | 关键判据 | 证据 |
| --- | --- | --- | --- |
| 接口 | 选型矩阵、电平/速率/距离/隔离四问 | 与 datasheet 一致、有选择理由 | 接口契约表 |
| I2C | 上拉/地址/中断/总线电容 | `Rp(min)<Rp<Rp(max)`、地址唯一、Cb≤400pF | 上升时间、扫描记录 |
| SPI | CS/模式/三态/速率 | 模式一致、CS 默认无效、无 MISO 冲突 | 逻辑分析仪波形 |
| 模拟 | 激励/比例式/源阻抗/滤波 | 比例式或激励误差在预算内、满足采样建立 | 激励实测、预算表 |
| 电桥/RTD | 灵敏度/引线/自热 | 引线误差与自热在目标内 | 校准数据、温升 |
| 热电偶 | CJC/失调/断线检测 | 冷端补偿误差在目标内、能检测开路 | 冰水校准、开路测试 |
| 脉冲 | `f_max`/整形/计数 | `f_max` 处不丢脉冲 | 扫频计数记录 |
| 校准 | 两点/多点/温补/存储 | 回测误差达标、系数可追溯 | 校准记录、回测数据 |
| 隔离/长线 | 隔离耐压/CMTI/屏蔽/保护 | 共模与浪涌测试通过 | 测试报告 |
| 电机 | 死区/损耗/续流/再生 | 无直通、温升达标、母线不过压 | 栅极波形、温升、母线波形 |
| 步进 | 电流/细分/失步 | 相电流与设定一致、全速不失步 | 电流波形、运行测试 |
| 继电器/阀 | 线圈电流/续流/触点 | 关断尖峰在耐压内、触点寿命达标 | 波形、寿命测试 |
| 故障检测 | 开路/短路/堵转 | 阈值不误报、动作时间达标 | 故障注入记录 |
| 安全 | 默认态/互锁/急停 | 上电不误动、急停硬件切断 | 上下电测试、急停实测 |
| 布线 | 分区/回流/屏蔽 | 传感器噪声在预算内 | 近场扫描、满载对比 |
