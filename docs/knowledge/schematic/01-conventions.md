# 原理图设计规范：图框、网络命名、符号与可读性

> **一句话结论**：原理图能不能被机器（ERC/网表/RAG）和人（评审/返修/产线）同时正确读懂，取决于四件事——**版本与图框可追溯、网络名唯一可检索、每个引脚有明确归属、信号流向可读**；这四件事在画图阶段一次做对，成本远低于在 PCB/试产阶段返工。

## 适用范围与边界

| 项 | 内容 |
| --- | --- |
| 适用阶段 | 需求冻结 → 原理图绘制 → 原理图评审 → 导出网表交付 PCB |
| 输入 | 需求/接口清单、器件选型表、封装库、板卡命名规则 |
| 输出 | 受控原理图 PDF、网表、BOM、ERC 报告、版本记录 |
| 不覆盖 | PCB 叠层/阻抗/布线（见 `docs/pcb-layout/`）、具体料号核验（见 `docs/knowledge/components/`） |
| 编号说明 | 本篇知识点编号为 **KP-SCH-001～018**，全知识库全局连续、不重复 |

## 一、图框、标题栏与版本

### KP-SCH-001 图框与标题栏必须承载可追溯字段

- **判据**：每张原理图（含层次子图）的图框必须包含：项目名/板卡名、Sheet 页码与总页数、版本号、日期、设计者、审核者；同一工程的 PDF、BOM、PCB 三者版本字段必须能对应上。缺任一项即原理图评审不通过。
- **为什么**：原理图是受控工程文件，不是草图。试产、返修、量产换料、客诉分析全部靠“哪一版、哪一页、哪颗器件”定位；图框缺字段时，现场只能靠猜，最终表现为“板子与 BOM 不一致”。
- **怎么做**：
  - 图框字段统一由模板提供，不允许手写在图纸空白处；页码用 `Sheet x / y`，与层次图页数一致。
  - 版本号与 ECO（工程变更单）号绑定，如 `v1.2 / ECO-014`；日期用 ISO 格式 `YYYY-MM-DD`。
  - 导出 PDF 时文件名带 `板卡名_版本_日期`，与图框字段同源，避免 PDF 与源文件脱节。
- **怎么查**：打开图框属性逐项对照模板；`grep -n "v[0-9]" 原理图导出文本` 核对版本一致性；评审清单勾选。不通过 → 改模板并重新导出，禁止在图上手写补字段。

### KP-SCH-002 版本号与修订记录按变更性质递增

- **判据**：每次投板、发 BOM、发外协前必须递增版本；修订记录必须包含**变更内容、变更原因、影响的文件（原理图/BOM/PCB）、批准人**。删除的位号不得在新版本中复用（或必须在修订记录中显式声明“位号已释放”）。
- **为什么**：版本漂移是“原理图改了、PCB 没改”“BOM 多一颗料”类事故的第一来源；位号复用会让历史测试记录、返修记录指向错误器件。
- **怎么做**：
  - 版本语义：主版本 `A` 用于拓扑/接口/电源架构变更，次版本 `.B` 用于器件值、位号、丝印微调；每次变更打 ECO 号。
  - 修订记录表放原理图首页，列：日期 / 版本 / 变更点 / 位号 / 原因 / 影响文件 / 批准人。
  - 变更涉及网络名、连接器定义、电源域时，必须同步更新 PCB 网络类与测试计划。
- **怎么查**：对比两版 PDF 的网络表（导出网表 diff）；核对 BOM 与原理图版本字段；抽查 3 个变更位号在 PCB 上是否同步。不通过 → 冻结发版，补记录并重新评审。

### KP-SCH-003 版本一致性必须覆盖原理图 / BOM / PCB 三件套

- **判据**：原理图版本、BOM 版本、PCB 版本之间必须存在一张“版本映射表”；若三者为同一版本号，则必须同时发布、同时归档；任一件版本落后即视为未受控。
- **为什么**：EDA 工具里三个文件是独立保存的，很容出现“原理图 v1.3 加了一颗 TVS，PCB 还是 v1.2 的封装”。版本映射表是唯一能在评审会上快速判定的凭据。
- **怎么做**：在项目根目录维护 `versions.md`（或工程管理页）记录三件套版本、发布日期、批准人；每次发版同时导出 PDF/BOM/网表并归档到 `deliverables/`。
- **怎么查**：发版前逐项核对映射表与实际文件头；用网表与 PCB 网络表比对（网络数、位号数应一致）。不通过 → 退回修改，禁止“先发后补”。

## 二、网络命名

### KP-SCH-004 网络命名总则：唯一、可读、可检索

- **判据**：所有非电源网络名遵循 `功能块_信号[_序号]` 大写格式（如 `USB1_DP`、`MCU_RST`）；**禁止 EDA 自动生成的 `NetC14_1`、`N$12` 进入评审版**；同一信号跨页必须同名；一个网络只能有一个名字（多别名视为缺陷）。
- **为什么**：网络名会进入网表、PCB 网络类、调试波形、测试点丝印和 RAG 检索；自动名不可读、不可搜、无法与接口清单对照，评审时只能逐个点开看连接。
- **怎么做**：
  - 前缀约定表：`PWR_` 电源输入、`+3V3/+5V0` 电源轨、`GND/AGND/PGND` 地、`CLK_` 时钟、`RST_` 复位、`BOOT_` 启动模式、`DBG_` 调试、`BUS_` 总线、`DIFF_` 差分、`EN_` 使能、`FLT_` 故障、`TP_` 测试点。
  - 差分对成对命名：`USB1_DP/USB1_DM`、`CANH/CANL`，仅极性后缀不同。
  - 总线成员统一写法：`DATA0..DATA7` 或 `DATA[7:0]`，同一工程只选一种。
- **怎么查**：导出网表后用正则筛自动名（如 `^Net[A-Z]?\d+_`、`^\$`、`^N\$`）；比对“接口清单 ↔ 网络名”一一对应。不通过 → 批量重命名并重新跑 ERC/网表比对。

### KP-SCH-005 电源网络名按电压域唯一

- **判据**：每个电压域一个唯一网络名，电压数字与小数点写法全工程统一（推荐 `+3V3` 而非 `3.3V`，`+5V0` 而非 `5V`）；**禁止同名不同压**（例如两个 `+5V` 实际一个是 5.0V、一个是 4.5V 电池直供）。
- **为什么**：电源网络名是 ERC“电源引脚是否被驱动”的判据键、PCB 平面/电源类划分键、上电时序表的主键；同名不同压会让 ERC 通过而板子烧器件。
- **怎么做**：
  - 命名示例表：`VIN`（输入）、`+5V0`（USB/适配器）、`+3V3`、`+1V8`、`VCORE`、`VBAT`、`VDDA`（模拟）、`VREF`（基准）、`VUSB`。
  - 同压多域加后缀：`+3V3_IO`、`+3V3_ANA`、`+3V3_CORE`，并在图上标出域间连接点（磁珠/0Ω/电源开关）。
  - 电源符号属性里的网络名必须与标签一致；电源符号和网络标签不得混用于同一网络。
- **怎么查**：列出全部电源网络 → 核对每个电源脚归属；检查是否存在 `3V3` 与 `+3V3` 并存的重复网络。不通过 → 统一命名并重建网络类。

### KP-SCH-006 地网络命名与地策略：默认单地，分割要有唯一桥接点

- **判据**：默认只用一个 `GND`；只有当存在明确的回流隔离需求（模拟小信号、大电流功率、隔离侧、射频）时才分 `AGND/PGND/ISO_GND/RF_GND`，且**每个分割地必须在图上有一个唯一、可见的连接点**（器件引脚、0Ω、磁珠或单点铜皮）。
- **为什么**：原理图上“分地”不等于物理上分地。若图上分了 AGND/PGND 却没画连接点，PCB 端会按网络名隔离，轻则回流路径断裂，重则模拟地浮空。
- **怎么做**：
  - 混合信号：AGND 与 PGND 在 ADC 或电源芯片的 GND 引脚处单点汇合；连接点画成显式元件（0Ω/磁珠/星点符号），注释写明“单点连接于此”。
  - 隔离侧：`ISO_GND` 只通过隔离器/变压器/隔离电源跨接，禁止与 `GND` 有任何直接网络连接。
  - 命名后 PCB 侧按网络名建立地类，避免“图上有桥、PCB 上断”。
- **怎么查**：网表统计地网络数量与每个地的成员；检查每个分割地是否有唯一连接元件；若 EDA 报“地网络未连接”按错误处理。不通过 → 回到单 GND，或补桥接元件并在评审记录说明。

### KP-SCH-007 差分对命名与配对必须支持自动约束

- **判据**：USB、CAN、RS485、以太网等差分信号必须成对命名，同一对除极性后缀外前缀完全一致；正负极性定义必须与连接器/器件 datasheet 一致；允许 P/N 交换的器件必须在图上注明。
- **为什么**：PCB 侧的等长、间距、阻抗约束依赖网络名自动配对；命名不成对时约束只能手工添加，漏加就是“差分线走成两根单端线”。
- **怎么做**：命名表：USB 2.0 `USB1_DP/DM`、USB3 `USB3_TX_P/N`、CAN `CANH/CANL`、RS485 `RS485_A/B`、以太网 `ETH_TX_P/N`；在原理图连接器旁标注 pin 与极性；终端电阻/TVS 按对放置并共用同一参考地。
- **怎么查**：PCB 工具里检查差分对识别是否 100% 命中；对照 datasheet 的 pin 极性表；不通过 → 改网络名并重跑约束检查。

### KP-SCH-008 总线与位序命名

- **判据**：总线成员用统一基名 + 序号（`SPI1_MOSI` 属于单信号，位序类如 `DATA0..DATA7`、`ADDR0..ADDR15`）；MSB/LSB 在图上标注；同一总线不得混用 `DATA[7:0]` 与 `DATA0..7` 两种写法。
- **为什么**：位序错误属于“能通但数据错位”的隐性故障，ERC 不报、示波器也未必看得出，往往到功能联调才暴露。
- **怎么做**：画一张“连接器/器件 pin ↔ 位序”对照表附在模块旁；位序按器件 datasheet 的 pin 顺序而非直觉；必要时用网络别名统一；每个总线预留测试点或串阻。
- **怎么查**：逐位对照 datasheet pin 表；抽样 2~3 位在 PCB 上核对连接器 pin；不通过 → 修正位序并记录到评审问题单。

### KP-SCH-009 电源符号与网络标签的使用边界

- **判据**：电源/地一律用电源符号（power port）；普通信号用网络标签或层次端口；同一网络不得“半段电源符号、半段全局标签”混用（除非 EDA 明确等价并已验证）。
- **为什么**：电源符号是全局隐式连接，误用会把不同页、不同域的电源短在一起；标签有局部/全局/层次三种作用域，混用会造成“看起来连着、网表没连”。
- **怎么做**：

  | 场景 | 用法 |
  | --- | --- |
  | 电源/地跨页 | 电源符号（全局） |
  | 普通信号跨页 | 层次端口 + 母图 sheet pin |
  | 单页内部信号 | 局部网络标签 |
  | 少数全局使能/中断 | 全局标签（需在规范中登记） |

  每个电源符号的属性里显式设置网络名；符号外形与电压一一对应，禁止不同电压复用同一符号。
- **怎么查**：ERC 的“电源引脚未被驱动 / 同名网络”检查；查看符号属性中的 net name；网表里检查同名网络是否跨越了本不该连接的页。不通过 → 统一符号或改为层次端口。

### KP-SCH-010 网络标签作用域与隐式连接

- **判据**：局部标签只在本页生效；全局标签与电源符号跨页生效；层次端口按层次结构传递。**禁止依赖“同名即连接”跨页**（除非该网络明确使用全局标签并登记）。
- **为什么**：隐式连接是“多出一根线”和“漏连”的根源；两种连接方式共存时，ERC 往往只报 warning，容易被批量忽略。
- **怎么做**：约定页内信号一律局部标签；跨页信号走层次端口；全局网络只保留电源、地与少数全局信号，并维护全局网络清单；每页出图前检查标签类型。
- **怎么查**：生成网表核对每个网络成员是否与设计意图一致；层次图检查 sheet pin 数量与内部端口数量相等；不通过 → 改连接方式后重新生成网表。

## 三、参考编号、器件值与引脚

### KP-SCH-011 参考位号前缀与唯一性

- **判据**：位号全工程唯一，前缀与器件类别一致；多单元器件用 `U1A/U1B`；位号不得跨版本复用；BOM 中每个位号恰好一行（多单元器件除外）。
- **为什么**：位号是 BOM、贴片程序、测试点、返修记录、客诉分析的唯一定位键；重复位号会让贴片机装错位置。
- **怎么做**：

  | 前缀 | 器件 | 前缀 | 器件 |
  | --- | --- | --- | --- |
  | R | 电阻 | C | 电容 |
  | L | 电感 | FB | 磁珠 |
  | D | 二极管/LED | Q | 三极管/MOSFET |
  | U | IC/模块 | J/P | 连接器 |
  | SW | 按键/开关 | Y/X | 晶振/谐振器 |
  | F | 保险丝 | TP | 测试点 |
  | JP | 跳线/焊盘 | TVS/ESD | 保护器件（或并入 D） |

  删除器件后位号留空，不把新器件塞进旧位号；分区编号（如 R1xx 为电源区）可选，但一旦采用必须写进规范。
- **怎么查**：EDA 的“位号重复”检查；BOM 导出后按位号做唯一性校验；不通过 → 重新标注并同步 PCB 与贴片文件。

### KP-SCH-012 器件值与单位书写规范

- **判据**：值必须带工程单位（`4.7kΩ`、`100nF`、`10µH`、`8MHz`）；关键参数（容差、耐压、介质、功率、精度）写在器件属性或 BOM 备注，不得只存在于设计者脑中；不得出现 `4700` 这类歧义写法。
- **为什么**：`4700` 既可能是 4.7kΩ 也可能是 4700pF；耐压/介质缺失会在选型、替代料、降额校核时全部丢失，最终变成“BOM 上是一颗 0402 6.3V 电容用在 12V 上”。
- **怎么做**：
  - 电阻：`4.7kΩ / ±1% / 1/10W`；电容：`100nF / 50V / X7R / 0402`；电感：`4.7µH / Isat≥2A`；晶振：`8MHz / ±20ppm / CL=8pF`。
  - 值放 Value 字段，补充参数放自定义字段并随 BOM 导出；关键器件（LDO、Buck、TVS、晶振、连接器）在图上加简短注释。
- **怎么查**：导出 BOM 检查空值与格式；对电源/保护/时钟类关键器件逐颗核对 datasheet；不通过 → 补全属性后重新导出 BOM。

### KP-SCH-013 引脚编号与封装映射必须一一对应

- **判据**：原理图符号的引脚号必须与封装焊盘号一一对应；多单元器件的单元划分与 datasheet 一致；隐藏电源引脚必须映射到实际 pin；**禁止使用 `pin 0`、`pin -1` 之类占位引脚**。
- **为什么**：引脚映射错误是“板子直接报废”级缺陷，且很多 DRC 规则不检查符号-封装映射；BGA/QFN 等封装一旦错位无法飞线补救。
- **怎么做**：建符号时严格按 datasheet 的 pin table 建，不凭记忆；隐藏引脚用“显式电源脚”表达；多单元器件在图上标 `U1A/U1B` 并注明单元功能；封装核验走三源（datasheet / 供应商 / EDA 库）。
- **怎么查**：逐器件比对 datasheet pin 表（至少对 MCU、电源 IC、连接器、二极管方向）；用 EDA 的符号-封装对应检查；首件 FAI 时抽测极性与 pin 1。不通过 → 改符号库并全项目复查同封装器件。

### KP-SCH-014 隐藏引脚与未用门必须显式处理

- **判据**：多门器件（运放、逻辑门、比较器）的未用门必须显式处理：输入接固定电平（GND 或 VCC，按 datasheet 要求），输出悬空并标 NC；隐藏电源引脚必须连到正确电源/地；未用引脚不得留空。
- **为什么**：悬空 CMOS 输入会因漏电与耦合随机翻转，表现为功耗增大、噪声变大、偶发死机；隐藏电源脚漏连直接导致“上电不工作”，且 ERC 未必报错。
- **怎么做**：未用运放按 datasheet 接成跟随器或接固定电平；未用比较器输入接确定电平；未用逻辑门输入接 GND/VCC；输出的 NC 用 NC 符号标注；隐藏电源脚在符号中列出并在图上可见。
- **怎么查**：ERC 悬空检查；对照器件 datasheet 的“unused pin”章节逐项确认；BOM 中多单元器件的单元数是否与实际使用一致。不通过 → 按 datasheet 补处理并记录。

### KP-SCH-015 去耦电容的画法与归属

- **判据**：每个电源引脚配一颗 100nF（就近），每个电源域至少一颗 10µF（或按纹波计算）；去耦电容在图上画在“电源符号 → 电容 → 器件电源脚”的路径上，按电源域分组，值旁标注所属器件引脚（如 `U1.3`）。
- **为什么**：原理图阶段决定去耦数量与 BOM，也决定 PCB 布局阶段的摆放认知；漏一颗就要在板子上飞线或在下一版补。
- **怎么做**：画法：同一电源域的电容排成一行，电源符号在左、器件引脚在右；高频小容值靠近器件，大容值按域集中；在电容旁标注 `U1.VDD`；电源域分配表记录每域电容数量。
- **怎么查**：统计“电源脚数量 vs 100nF 数量”，缺一即问题；与 PCB 规则 `PWR-01`（去耦电容到电源脚 ≤2.0mm）对齐检查；不通过 → 补电容并同步 PCB。

### KP-SCH-016 层次图与端口

- **判据**：层次化设计的每个子图端口（sheet pin / hierarchical label）必须与母图 sheet 符号一一对应；端口方向与实际驱动方向一致；除电源/地外不得用全局标签替代层次端口。
- **为什么**：层次端口是模块复用、多人分工、ERC 方向判定的基础；方向错误会让 ERC 把输出当输入，漏报多驱动。
- **怎么做**：端口名与网络名一致；方向按实际驱动（IN/OUT/BIDIR/无源）设置；每个模块出图附端口清单；同一 sheet 多次实例化时端口必须同构。
- **怎么查**：母图 sheet pin 与子图端口做数量/名称对照；ERC 层次检查；不通过 → 补齐端口或改正方向后重跑 ERC。

## 四、悬空脚与可读性

### KP-SCH-017 悬空引脚与 NC 必须显式标注

- **判据**：所有未连接引脚必须显式标注（打 X、放 NC/No-Connect 符号、或加 `DNC` 文本）并写明原因（保留/未用/调试）；不得以“什么都不画”表示不连接。
- **为什么**：空白悬空在 ERC 里是一条 warning，在人眼里是“忘了连”；显式 NC 才能把“故意不连”和“漏连”区分开，避免评审时批量忽略告警。
- **怎么做**：

  | 引脚类型 | 处理 |
  | --- | --- |
  | 数字输入 | 接 GND 或 VCC（按 datasheet），不得悬空 |
  | 数字输出 | NC 符号 + 注释 |
  | 模拟输入 | 按 datasheet 接地或悬空，并在图上注明 |
  | 电源引脚 | 必须连接，不允许 NC |
  | 预留功能 | NC 符号 + “预留/不贴”注释 + BOM DNP 标记 |

- **怎么查**：ERC 未连接清单逐条处理并记录理由；统计 NC 数量与 datasheet 未用引脚数对比；不通过 → 补标注或补连接。

### KP-SCH-018 可读性布局与测试点约定

- **判据**：信号流向统一（左→右、上→下），电源在上、地在下；同类功能模块成块并加标题；模块间只通过端口/标签连接；每个电源域、复位、BOOT、时钟、关键总线至少有一个可探测测试点（TP）。
- **为什么**：评审、调试、产线测试都靠读图和探测；图乱会让评审漏项，没有 TP 只能飞线，飞线又会引入新的 EMC/可靠性问题。
- **怎么做**：按“电源 → 保护 → MCU → 接口”分区；每模块加标题文本框与一句话说明；避免一条线跨 3 个模块；测试点命名 `TP_3V3 / TP_RST / TP_BOOT / TP_SCL` 并保证丝印可见；高速信号 TP 需评估 stub 影响。
- **怎么查**：让未参与设计的人在 10 分钟内讲清信号流（走查法）；目检交叉线密度；对照调试计划检查 TP 是否齐全；不通过 → 重排并补 TP。
