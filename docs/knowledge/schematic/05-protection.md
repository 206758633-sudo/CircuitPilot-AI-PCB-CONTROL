# 保护电路设计：ESD、TVS、过压/过流/反接、浪涌与热插拔

> **一句话结论**：保护电路的唯一目标是**让应力在到达被保护器件之前被旁路或切断，并且保护器件自己先于被保护器件失效**；因此必须先算“应力有多大、钳位到多少、谁先坏”，再谈器件选型与摆放。

## 适用范围与边界

| 项 | 内容 |
| --- | --- |
| 适用阶段 | 接口/电源入口设计 → 保护选型 → 原理图评审 → EMC/浪涌测试 |
| 输入 | 接口类型与位置（是否外露）、工作电压/电流、目标测试等级（IEC 61000-4-2/-4-4/-4-5 或产品标准）、后级器件绝对最大额定值 |
| 输出 | 保护拓扑、器件参数（VRWM/VCL/Ipp/I²t/Rdson）、摆放要求、测试计划与记录 |

## 一、总则与 ESD/TVS

### KP-SCH-073 保护设计总则：先定应力，再定顺序，最后定器件

- **判据**：任何保护电路必须能回答三步：①应力来源与等级（人体 ESD、线缆浪涌、热插拔、反接、过流）；②保护器件的动作顺序（谁先导通、谁先失效）；③被保护器件的绝对最大额定值是否在所有工况下不被超过。三步缺一不得定稿。
- **为什么**：保护器件不是“加上就安全”——TVS 钳位电压可能高于后级耐压、保险丝可能在浪涌时先断、PTC 在高温下可能不动作。不算清楚就会“保护器件没坏，芯片先坏了”。
- **怎么做**：
  - 画保护链：`连接器 → 应力泄放(TVS/GDT) → 限流/切断(保险丝/PTC/限流开关/反接 MOS) → 滤波 → 被保护电路`。
  - 对每个节点列出“最高电压/最大电流/持续时间”，与器件额定值和后级绝对最大值对比。
  - 在图上标注保护器件的动作电压/电流与地回路，评审时逐项核对。
- **怎么查**：按测试计划做 ESD/浪涌/反接/短路测试；测钳位点波形与后级电压；检查保护器件是否失效。不通过 → 调整器件或顺序。

### KP-SCH-074 ESD 防护基础：等级、器件类型与选型参数

- **判据**：外露接口（USB、按键、连接器、调试口）必须做 ESD 防护；目标等级按产品标准确定（常见接触放电 ±4/+6/+8kV、空气放电 ±8/+15kV，需按产品规范确认）；器件优先选专用 ESD 阵列/低电容 TVS，不用普通整流二极管或稳压管替代。
- **为什么**：ESD 是纳秒级、kV 级、能量不大的脉冲；专用 ESD 器件响应快、结电容小、钳位可控；普通二极管结电容大、响应慢，会破坏高速信号或来不及钳位。
- **怎么做**：按信号速率选结电容（USB HS <1pF，USB FS <3~5pF，普通 GPIO/Audio 可放宽，需按 datasheet 复核）；多通道接口用集成 ESD 阵列减少寄生；器件放在连接器与芯片之间，地引脚就近下地。
- **怎么查**：IEC 61000-4-2 接触/空气放电测试（正负极性、每个测试点多次）；测试后功能与通信复测；不通过 → 换器件/改接地/加共模。

### KP-SCH-075 TVS 钳位余量计算

- **判据**：TVS 必须同时满足：
  - `VRWM ≥ 1.1~1.2 × Vwork(max)`（避免正常工作电压下漏电/误导通；具体系数按 datasheet 的漏电曲线与工作温度）；
  - `VCL(max @ Ipp) < 后级器件绝对最大额定值`（并留 ≥10%~20% 余量）；
  - TVS 的 `Ipp`（对应测试波形，如 8/20µs）≥ 实际浪涌电流；
  - 结电容满足信号速率要求。
- **为什么**：TVS 是“电压超过 VRWM 后开始导通、在 Ipp 下钳位到 VCL”的器件；只看 VRWM 不看 VCL，是“加了 TVS 还烧芯片”的最常见原因。
- **怎么做**：
  - 示例（5V VBUS）：典型 SMBJ5.0A 级器件 `VRWM=5V`、`VBR≈6.4~7.0V`、`VCL≈9.2V @ 65.2A`（**具体数值以所选 datasheet 为准**）。若后级芯片 VBUS 绝对最大值为 6V，则该 TVS 钳位不住，需要更低钳位器件、加限流/降压，或选耐压更高的后级。
  - 示例（3.3V 信号）：选 `VRWM=3.3V` 级 TVS，`VCL` 常达 7~9V；若后级绝对最大 4.6V，则必须加串联电阻限流 + 更低钳位器件，或改保护方案。
  - 计算浪涌电流：按测试波形与源阻抗估算（IEC 61000-4-5 组合波 1kV/2Ω 对应约 500A 峰值，需按实际测试等级与耦合方式复核）。
- **怎么查**：查 datasheet 的 `VCL vs Ipp` 曲线；实测钳位波形（高压差分探头/电流探头）与后级电压；不通过 → 换 TVS/加限流/改后级。

### KP-SCH-076 TVS/ESD 摆放与接地回流

- **判据**：保护器件必须放在**连接器与被保护器件之间**，且越靠近连接器越好；保护器件的接地必须用短而宽的路径回到接口地/机壳地（过孔就近、多孔并联）；保护电流不得穿过敏感电路地或分割地缝隙。
- **为什么**：ESD/浪涌电流是高频大电流，走线电感会让钳位点电压升高（`V = L×di/dt`）；接地路径长会让“钳位电压”实际到不了芯片端，还会把噪声注入地平面。
- **怎么做**：连接器 → TVS（同一区域）→ 串阻/滤波 → 芯片；TVS 地引脚用过孔直接下地平面，避免长细走线；外壳地/信号地按整机 EMC 方案处理（直接连接或经 RC/磁珠，需按测试结果定）；保护器件下方不走敏感信号。
- **怎么查**：目检/量测 TVS 到连接器与地的距离；做 ESD 测试并监测芯片端电压；不通过 → 移动器件/加地过孔/改地策略。

## 二、过压、过流与反接

### KP-SCH-077 过压保护（OVP）

- **判据**：输入可能超过后级耐压时（适配器误插、PD 协商、感性负载关断尖峰、电池热插拔）必须做 OVP：可用 OVP 控制器 + 串联 MOSFET（切断）、齐纳/瞬态抑制（钳位）、或选用耐压足够的后级。OVP 阈值必须低于后级绝对最大值并高于正常最高工作电压。
- **为什么**：TVS 只能吸收瞬态能量，持续过压会烧 TVS；OVP 控制器能在持续过压时切断负载，是“错误适配器”场景的正确解法。
- **怎么做**：OVP 控制器按 datasheet 设置阈值（分压计算）与恢复方式（锁存/自动重试）；串联 MOSFET 的 Vds 耐压 ≥ 最高输入并留余量；栅极驱动与软启动配合；TVS 作为第一级瞬态旁路，OVP 作为第二级持续保护。
- **怎么查**：可调电源缓慢升压到超过阈值，测负载侧是否切断/钳位；模拟错误适配器（如 12V 接入 5V 口）；不通过 → 调整阈值/换器件。

### KP-SCH-078 过流保护：保险丝选型与 I²t 协调

- **判据**：保险丝额定电流 `In ≥ 1.5 × Iop(max)`（含启动/峰值，具体按保险丝降额曲线）；保险丝的 `I²t` 必须小于被保护器件/PCB 走线可承受的 `I²t`，并与 TVS 的浪涌承受能力协调（不能让浪涌先烧保险丝，也不能让持续过流先烧 TVS）；快断/慢断按启动冲击选择。
- **为什么**：保险丝是“最后切断”，选大了不起保护作用，选小了启动就断（nuisance trip）；I²t 不协调会出现“浪涌时保险丝先断，设备断电”或“过流时 TVS 先烧，短路持续”。
- **怎么做**：先算正常/启动电流与持续时间，再选 In 与特性（慢断耐启动）；核算 `I²t` 与走线/连接器/器件耐受；在图上标注保险丝额定值与分断能力；需要可恢复时用 PTC（KP-SCH-079）。
- **怎么查**：满载/启动/短路测试，确认不误断且故障时能切断；测故障电流与切断时间；不通过 → 换额定值/特性/改拓扑。

### KP-SCH-079 PTC 自恢复保险丝

- **判据**：PTC 的保持电流 `Ihold` 在最高工作温度下必须 ≥ 最大稳态电流（PTC 的 Ihold 随温度升高而下降，需按 datasheet 降额曲线，常见 60~80% 降额）；跳闸电流 `Itrip ≈ 2×Ihold`；动作时间必须满足保护要求（PTC 动作慢，不能替代快速电子限流）。
- **为什么**：PTC 是温度触发，环境温度高时更容易误跳闸或保持电流不足；动作时间在秒级，短路时后级可能先损坏。
- **怎么做**：按最高环境温度选 Ihold；PTC 与负载之间不要有会持续耗流的分支；需要快速保护时用电子保险丝/限流开关替代或并联 TVS；在图上标注 Ihold/Itrip 与降额条件。
- **怎么查**：高温满载测试（是否误跳）；短路测试动作时间；恢复后阻值变化；不通过 → 换规格/改方案。

### KP-SCH-080 反接保护：P-MOS 高边方案

- **判据**：电池/DC 输入可能反接时必须做反接保护；P-MOS 高边方案：源极接输入、漏极接负载、栅极经电阻到地（并加齐纳钳位限制 Vgs）；要求 `|Vgs| > |Vth|` 保证导通，`|Vgs| ≤ Vgs(max)`（常见 ±20V，需查 datasheet），`Rds(on)` 的导通损耗 `I²×Rds(on)` 可接受。
- **为什么**：反接时 P-MOS 体二极管反向、栅极相对源极为正（或零），MOS 关断，负载被切断；正常时栅极被拉低导通，压降远小于二极管。
- **怎么做**：
  - 12V 系统：栅极电阻 10k~100k 到 GND，Vgs≈-12V，通常安全；24V 系统必须加 15V 齐纳（栅-源）限制 Vgs，并串限流电阻。
  - 选 `Vds ≥ 1.5×Vin(max)`、`Rds(on)` 按最大电流的功耗选型（如 1A、20mΩ → 20mW）；栅极加 TVS/齐纳防浪涌；体二极管方向必须正确。
  - 低边 N-MOS 方案适用于负载不共地的场景，注意高边驱动需求。
- **怎么查**：反接测试（电源反接后负载端电压应为 0 或极小）；正常工作时测 Vgs 与压降/温升；不通过 → 调整栅极电路/换 MOS。

### KP-SCH-081 理想二极管与 ORing

- **判据**：多电源输入（USB + 电池、双电源冗余）需要 ORing，防止电流倒灌；理想二极管（MOS + 控制）压降通常几十 mV，显著优于肖特基（0.3~0.5V）；选型关注反向关断速度、正向压降、耐压与浪涌能力。
- **为什么**：肖特基 ORing 在大电流下功耗高、发热大；理想二极管降低压降与热耗，并在反向时快速关断。
- **怎么做**：每路电源串理想二极管控制器 + MOSFET；输入输出加 TVS/电容；注意启动时的反向电流与软启动；多路 ORing 的优先级与切换行为按系统需求定义。
- **怎么查**：测正向压降与温升；反向测试（一路断电/反接时另一路不倒灌）；切换瞬态测试；不通过 → 换器件/加控制。

## 三、浪涌、热插拔与上电冲击

### KP-SCH-082 浪涌与雷击防护：GDT + TVS 分级

- **判据**：室外/长线/高能量浪涌场景必须分级：第一级 GDT（气体放电管，吸收大能量、残压高）→ 第二级 TVS/压敏（钳位到后级可承受）→ 第三级（必要时）限流/滤波；两级之间必须有去耦元件（电阻/电感）让器件按顺序动作；GDT 的续流问题必须处理（在直流电路上 GDT 可能无法熄弧，需串联或改用合适器件）。
- **为什么**：单级 TVS 无法承受雷击级能量；GDT 响应慢、残压高，不能单独保护芯片；没有去耦会让两级同时动作、能量分配失控。
- **怎么做**：按测试等级选 GDT 的直流击穿电压（高于最高工作电压并留余量）与 TVS 的 Ipp；级间用电阻/电感/保险丝做协调；GDT 之后加保险丝防止续流；在图上标明“分级保护，级间去耦”。
- **怎么查**：按 IEC 61000-4-5 做浪涌测试（不同等级/极性）；测各级残压与后级电压；测试后检查器件是否劣化；不通过 → 调整级数/器件/去耦。

### KP-SCH-083 热插拔与限流

- **判据**：支持热插拔的板卡/模块必须有浪涌电流限制（热插拔控制器、限流开关、软启动电路）；限流值按下游稳态电流与上游源能力设定；MOSFET 的 SOA（安全工作区）必须覆盖启动过程；插拔时不能把总线/电源拉跌到影响其他负载。
- **为什么**：热插拔瞬间负载电容近似短路，电流可达数十安培，会拉低母线、烧连接器、触发上游保护。
- **怎么做**：热插拔控制器 + 采样电阻 + 限流/软启动；按 `I = C×dV/dt` 与限流值计算启动时间；MOSFET SOA 与散热核算；加 TVS 抑制插拔瞬态；连接器先接地的针序设计（长针地、短针电源）。
- **怎么查**：带电插拔测试（示波器看母线跌落、启动电流）；反复插拔 100 次；不通过 → 调限流/软启动/换控制器。

### KP-SCH-084 上电冲击（inrush）与负载电容

- **判据**：`Iinrush ≈ C × dV/dt`；上电时间 `t ≈ C × V / Ilimit`；输入源、连接器、保险丝、MOSFET 的耐受必须覆盖该电流与持续时间；大电容负载优先用软启动/限流，而不是简单加大保险丝。
- **为什么**：上电冲击是“正常但很大”的电流，保险丝选小了会误断，选大了短路时又保护不了；MOSFET/连接器可能因反复冲击而劣化。
- **怎么做**：示例：C=470µF、12V、要求 20ms 上电 → `I ≈ 470µ×12/20m ≈ 282mA`；若无限流，初始电流仅受 ESR 与源内阻限制，可达数安培。用软启动/热插拔控制器把 dV/dt 限制在安全范围；NTC 只适合小功率且注意热态失效。
- **怎么查**：示波器+电流探头测上电电流峰值与持续时间；反复上下电 100 次；不通过 → 加软启动/限流/减小电容。

## 四、协调、接地与验证

### KP-SCH-085 保护器件顺序与协调

- **判据**：保护链中每个器件的“动作阈值/能量/时间”必须形成有序配合：瞬态（ns~µs）由 ESD/TVS 先动；浪涌（µs~ms）由 GDT/TVS/限流分担；持续过流（ms~s）由保险丝/PTC/OVP 切断；被保护器件的绝对最大值在所有阶段都不被超过。任何两个器件“同时抢着动作”都视为未协调。
- **为什么**：保护不是堆器件，而是“接力”；顺序错了会出现 TVS 被持续过流烧毁、保险丝在浪涌时误断、GDT 续流。
- **怎么做**：画一张“应力-时间-动作器件”表；核算每个器件的能量/电流/时间余量；用去耦元件控制级间动作顺序；单点接地让泄放电流走设计路径。
- **怎么查**：分别做 ESD、浪涌、短路、反接测试，记录每级动作与残压；检查是否有器件劣化；不通过 → 调整顺序/参数。

### KP-SCH-086 保护接地与地弹

- **判据**：保护器件的泄放电流必须走“连接器地 → 保护器件地 → 机壳地/接口地”的低阻抗路径，不得穿过敏感模拟地、晶振地、ADC 地；保护地与信号地的连接方式（直接/RC/磁珠）必须与整机 EMC 方案一致并画在图上。
- **为什么**：ESD/浪涌电流在接地阻抗上产生地弹（`V = L×di/dt`），会让 MCU 复位、ADC 误码，甚至通过 IO 反向打坏芯片。
- **怎么做**：保护器件地就近多过孔下地；接口地与数字地按方案单点/桥接；敏感区域下方保持完整地平面；避免在保护器件与连接器之间走其他信号。
- **怎么查**：ESD 测试时用示波器监测 MCU 地/复位；测地弹幅度；不通过 → 改接地/加地过孔/改布局。

### KP-SCH-087 通信接口保护：USB / CAN / RS485

- **判据**：外露通信接口必须做 ESD；CAN/RS485 还需总线 TVS（双向、低结电容）与（室外/长线）GDT；USB 的 DP/DM 用低电容 ESD，VBUS 用 TVS + 过流保护；保护器件放在连接器侧，参数按总线共模范围与速率选。
- **为什么**：通信接口是 ESD/浪涌的主要入口；CAN/RS485 共模范围有限（-7~+12V 量级），超限会损坏收发器；USB 高速对结电容极敏感。
- **怎么做**：按接口分别选型（USB 低电容阵列、CAN 专用双向 TVS、RS485 双向 TVS + GDT）；共模扼流圈与 TVS 配合；隔离场景在隔离侧加保护；在图上标注器件与地回路。
- **怎么查**：按接口标准做 ESD/浪涌/共模测试；测试后通信误码与器件状态；不通过 → 换器件/加隔离/改接地。

### KP-SCH-088 电源口保护：VBUS / DC 输入

- **判据**：电源入口必须有：过流（保险丝/PTC/限流开关）、过压/瞬态（TVS）、反接（如可能）、滤波（π 型）；VBUS 还要考虑 Type-C 的电流档与 PD 电压；保护器件额定值按最高输入电压/最大电流/浪涌等级选，并核算后级绝对最大值。
- **为什么**：电源口承受的应力最大（插拔、浪涌、错误适配器、反接），是整板可靠性的第一道门。
- **怎么做**：典型链：`连接器 → TVS → 保险丝/PTC → 反接 MOS → π 滤波 → 变换器`（能量型浪涌场景需按测试调整顺序，见 KP-SCH-073/085）；VBUS 加 1~10µF；PD 场景按最高协商电压选 TVS 与后级器件。
- **怎么查**：反接/过压/短路/浪涌测试；测后级输入电压与器件温升；不通过 → 调整保护链。

### KP-SCH-089 保护验证与测试记录

- **判据**：保护电路必须有可执行的验证计划与记录：测试项目（ESD 接触/空气、浪涌、反接、短路、热插拔、上电冲击）、测试等级、测试点、判定标准（功能正常/通信正常/无器件劣化）、测试后复测项。无记录视为未验证。
- **为什么**：保护设计“看起来对”不等于“打得住”；只有测试证据能证明钳位电压、动作顺序、后级安全。
- **怎么做**：按产品标准制定测试矩阵；测试时用示波器/电流探头记录钳位波形；测试后做功能、通信、绝缘、器件外观检查；把结果归档到 `artifacts/evidence/`（命名含板卡/版本/日期/等级）。
- **怎么查**：评审时要求提供测试记录与波形；抽测复现；不通过 → 整改后重测，不得用“经验判断”替代。

### KP-SCH-090 保护设计常见错误清单

- **判据**：以下任一项存在即判保护设计不通过：TVS 的 VRWM 贴近工作电压（正常即漏电/发热）；只看 VRWM 不看 VCL；TVS 放在连接器很远或地回路很长；ESD 器件放在串阻之后；用普通二极管/稳压管当 ESD；保险丝 I²t 与 TVS 不协调；PTC 未按高温降额；P-MOS 反接保护 Vgs 超限；浪涌只做单级 TVS；保护地与信号地混走；无测试记录。
- **为什么**：这些错误在原理图上都“看起来正常”，但会在 ESD/浪涌/高温/反接时集中暴露，且往往是批量问题。
- **怎么做**：把本清单做成评审勾选项，逐条对照原理图与布局；对每条给出证据（器件 datasheet 页码、计算、测试波形）；不确定的项标注“需实测/需 datasheet 复核”，不得默认通过。
- **怎么查**：评审会逐条打勾并留证；样机做对应测试；不通过 → 整改并复评。
