# 柔性板与刚挠结合板设计（Flex / Rigid-Flex）

> 适用前提：以聚酰亚胺（PI）为基材的单面/双面柔性板、多层挠性板与刚挠结合板；覆盖膜（coverlay）或阻焊油墨保护；常规 FPC 板厂工艺。
> 定位：本文接续 [`02-stackup-impedance.md`](./02-stackup-impedance.md)（刚性叠层与阻抗）与 [`03-placement-routing.md`](./03-placement-routing.md)（布局布线），专门讲**柔性材料、覆盖膜、补强、弯折半径、动态弯折、刚挠结合、柔性连接器**。
> 编号约定：`KP-PCB-257` 起接续 K9 编号段；本文 KP 为 257–282，全局连续。
> 可信度：本机无外网，本文按 IPC-2223（挠性板设计）、IPC-6013（挠性板验收）、IPC-4202/4203/4204（基材/覆盖膜/胶）的通用原则与公开工程实践整理，**不引用具体条款号**；所有数值为工程范围，落地前按材料 datasheet、板厂能力表与弯折寿命实测复核。

**一句话结论**：柔性板的设计核心不是「把刚性板画软」，而是从材料（PI/RA 铜）、保护层（覆盖膜）、机械结构（补强/弯折半径）到装配（连接器/托盘）整条链一起设计；弯折区只允许「顺着弯折方向、无过孔、少铜、圆弧过渡」的走线。

## 0. 口径与术语

| 项 | 本文口径 | 说明 |
| --- | --- | --- |
| 结构 | 单面 / 双面 / 多层挠性 / 刚挠结合 | 层数越高弯折越困难 |
| 基材 | PI（聚酰亚胺），厚度常见 12.5/25/50 µm | 以材料 datasheet 为准 |
| 铜箔 | ED（电解）与 RA（压延） | 动态弯折优先 RA |
| 保护 | 覆盖膜（coverlay）或阻焊油墨 | 动态弯折区必须覆盖膜 |
| 补强 | FR-4 / PI / 不锈钢 / 铝 | 连接器与 SMT 区局部加硬 |
| 弯折 | 静态弯折（装配后固定）/ 动态弯折（反复弯折） | 半径与寿命差异巨大 |
| 标准 | IPC-2223、IPC-6013、IPC-4202/4203/4204、J-STD-020 | 不引用条款号，按标准原文复核 |

## 1. 材料与层结构

### KP-PCB-257 柔性板 = PI 基材 + 铜 + 覆盖膜，先定层结构再谈布线

- **判据**：挠性板必须明确「单面/双面/多层 + 铜厚 + PI 厚度 + 覆盖膜类型 + 补强位置 + 表面处理」六项；弯折区总厚度越薄越好（常见单面 0.08–0.15 mm、双面 0.15–0.30 mm，按叠层复核）。
- **为什么**：弯折应力与总厚度正相关；层数、胶层、覆盖膜都会增加中性轴偏移，厚度每增加一档，允许弯折半径和寿命显著下降。
- **怎么做**：先画挠性叠层（铜/PI/胶/覆盖膜逐层标厚度）；弯折区只保留必要铜层；补强远离弯折区；与板厂确认标准叠层组合。
- **怎么查**：叠层图逐层厚度；弯折区剖面；总厚测量；与板厂标准 FPC 叠层比对。
- **依据**：IPC-2223 挠性板设计原则、IPC-4202/4203/4204 材料规范；具体厚度按板厂叠层表复核。

### KP-PCB-258 覆盖膜 vs 阻焊油墨：动态弯折区必须覆盖膜

- **判据**：动态弯折区、需要高可靠性的区域使用覆盖膜（PI 膜 + 胶）；静态/低成本区域可用阻焊油墨；覆盖膜开窗边缘到焊盘留 0.05–0.15 mm（按板厂能力），胶溢不能盖住焊盘。
- **为什么**：阻焊油墨在反复弯折下易开裂、脱落；覆盖膜是独立 PI 膜，耐弯折与耐化学性更好，但开窗、对位与溢胶控制更复杂。
- **怎么做**：弯折区全覆覆盖膜；焊盘/金手指处开窗；开窗做「双面开窗」避免单侧应力；与板厂确认覆盖膜厚度（常见 25 µm 膜 + 25 µm 胶，需复核）。
- **怎么查**：覆盖膜开窗图；开窗到焊盘间距；溢胶/盖盘检查；弯折后覆盖膜起翘检查。
- **依据**：IPC-4203/4204 覆盖膜材料规范、IPC-2223 保护层要求；开窗数值按板厂能力表复核。

### KP-PCB-259 覆盖膜开窗与焊盘：开窗要「大一点、对得准、不盖焊盘」

- **判据**：覆盖膜开窗比焊盘单边大 0.05–0.15 mm（经验范围，按板厂对位精度）；开窗不得盖住焊盘、金手指接触区、测试点；相邻开窗之间保留 ≥0.15–0.20 mm 覆盖膜桥；开窗边缘不得有尖角。
- **为什么**：覆盖膜对位公差比阻焊大，开窗太小会盖盘导致不上锡；开窗太大则胶层暴露、易吸湿分层；桥太窄会断裂。
- **怎么做**：按板厂「覆盖膜开窗补偿」规则出图；金手指整排开窗；开窗用圆弧/45° 过渡；SMT 焊盘开窗与钢网协同。
- **怎么查**：覆盖膜开窗 Gerber 与焊盘层 XOR；首件目检/显微镜；上锡与溢胶检查。
- **依据**：IPC-2223 覆盖膜开窗原则；补偿值按板厂 DFM 规则复核。

### KP-PCB-260 补强板：连接器、SMT、插拔区必须局部加硬

- **判据**：ZIF/FFC 连接器、板对板连接器、SMT 密集区、螺钉/定位区需要补强；补强材料与厚度按受力选择（FR-4 常见 0.2–1.0 mm、PI 0.1–0.3 mm、不锈钢 0.1–0.3 mm）；补强边缘距弯折区 ≥1–2 mm，且不得跨越弯折线。
- **为什么**：柔性板本身刚度低，连接器插拔力、SMT 器件应力会把局部弯折/焊盘撕裂；补强把力分散到刚性区。
- **怎么做**：补强与覆盖膜/基材用胶（bondply/胶膜）压合；补强外形做圆角；需要接地的补强（不锈钢/铝）留接地焊盘与过孔；与板厂确认压合次数。
- **怎么查**：补强图与弯折线叠合；补强剥离/剪切测试；插拔力测试；3D 装配检查。
- **依据**：IPC-2223 补强设计要求、板厂 FPC 补强工艺；厚度按受力仿真/实测复核。

## 2. 弯折设计

### KP-PCB-261 静态弯折半径：按总厚的 6–10 倍起步

- **判据**：静态弯折（装配后固定，不反复折）常用 `R ≥ 6–10 × 总厚度`（经验口径，按 IPC-2223 与材料 datasheet 复核）；单面柔性板可取偏下限，双面/多层取上限；弯折半径必须大于材料最小弯曲半径。
- **为什么**：弯折时外侧铜受拉、内侧受压，半径越小应变越大；超过材料延伸率就会铜裂/分层。
- **怎么做**：在结构件上做圆角/限位，强制弯折半径；弯折区两侧留过渡区；不要用「折痕」代替圆弧；与结构工程师确认装配空间。
- **怎么查**：3D 结构叠合量弯曲半径；弯折工装/限位；弯折后目检+通断；按需做弯折寿命试验。
- **依据**：IPC-2223 弯曲半径建议、PI/铜箔材料 datasheet；具体倍数按铜箔类型与层数复核。

### KP-PCB-262 动态弯折半径：按总厚的 20–100 倍并必须实测寿命

- **判据**：动态弯折（反复弯折）常用 `R ≥ 20–100 × 总厚度`，具体取决于弯折次数、角度、铜箔类型（RA 优于 ED）、层数与覆盖膜；动态区必须用 RA 铜、单面/薄层结构；最终以弯折寿命试验（如 ±90°/±180°、指定次数）判定。
- **为什么**：动态弯折的应变循环会导致铜箔疲劳裂纹，寿命随半径减小呈指数下降；ED 铜晶粒结构在反复弯折下更易裂。
- **怎么做**：动态区用 RA 铜、减少层数、走线居中（中性轴附近）；增大半径、减小弯折角度；覆盖膜全覆；避免在动态区放补强/过孔。
- **怎么查**：弯折寿命试验（记录次数/电阻变化）；弯折后铜箔裂纹（切片/显微）；动态弯折工装验证。
- **依据**：IPC-2223 动态挠性设计建议、RA/ED 铜箔 datasheet；数值必须按材料与实测复核，禁止直接套用。

### KP-PCB-263 弯折区走线：垂直弯折线、圆弧过渡、少铜/网格铜

- **判据**：弯折区走线方向与弯折线**垂直**（不要平行于折线）；走线用圆弧/45° 过渡，禁止直角/锐角；弯折区铜面积尽量小，大面积铜改为网格/条纹；每根线尽量细而均匀，避免宽度突变。
- **为什么**：平行于折线的走线在弯折时承受最大拉/压应变，最易裂；宽度突变处应力集中；大面积铜会约束变形、把应力传给相邻走线。
- **怎么做**：进入弯折区前把走线扇形展开、垂直穿过；弯折区不铺大铜；地线用细网格或两侧细线；必要时加「应力释放」圆弧。
- **怎么查**：走线方向与弯折线夹角；铜面积统计；弯折后通断/显微裂纹；切片看铜箔。
- **依据**：IPC-2223 挠性布线原则；具体间距/网格按板厂与仿真复核。

### KP-PCB-264 弯折区禁过孔、禁镀通孔、禁器件

- **判据**：弯折区内不得布置过孔、镀通孔、盲埋孔、焊盘、器件、丝印字符、测试点；弯折区边界外 ≥0.5–1.0 mm 才允许过孔；刚挠结合过渡区同样禁止。
- **为什么**：过孔是刚性柱，弯折时孔壁铜与孔环应力集中，极易开裂/拉脱；器件焊点无法承受反复弯折。
- **怎么做**：弯折区定义为 keepout 并在 EDA/机械层标注；过孔移到弯折区外；必须换层时在弯折区外完成；刚挠过渡区做「阶梯」释放应力。
- **怎么查**：弯折区 keepout 与过孔/焊盘/器件层求交；3D 检查；弯折后孔壁切片。
- **依据**：IPC-2223 挠性板过孔与弯折区限制；具体距离按板厂/仿真复核。

### KP-PCB-265 刚挠结合过渡区：应力释放与覆盖膜去除要一起做

- **判据**：刚性区与挠性区过渡处做阶梯/斜角释放应力；过渡区覆盖膜与刚性板开窗对齐，避免胶流到弯折区；过渡区不得有镀通孔；刚性板边缘到弯折线留 ≥1–2 mm 缓冲。
- **为什么**：刚挠结合处刚度突变，弯折应力集中在界面；胶溢/覆盖膜搭接不当会导致分层、铜裂。
- **怎么做**：刚性板开窗比挠性区大 0.2–0.5 mm（经验值，按板厂）；过渡区做圆角/斜边；压合时用填充/缓冲材料；与板厂确认刚挠结合工艺（层压次数、开窗方式）。
- **怎么查**：刚挠过渡区剖面；开窗对齐；胶溢检查；弯折/热循环后分层检查。
- **依据**：IPC-2223 刚挠结合设计、IPC-6013 验收；具体尺寸按板厂工艺复核。

### KP-PCB-266 刚挠板叠层：刚性层与挠性层分别对称，压合次数受控

- **判据**：刚挠板中刚性部分叠层对称、挠性部分单独对称；刚挠结合区的层数/铜厚尽量对称；压合次数按板厂能力（多次压合增加对位误差与成本）；刚性材料（FR-4）与挠性材料（PI）CTE 不匹配，需评估分层风险。
- **为什么**：不对称叠层在压合/回流后翘曲，导致刚挠界面分层；多次压合让挠性区反复受热，影响弯折寿命。
- **怎么做**：先定挠性叠层，再在两侧加刚性层；刚挠结合区用低流动度胶/无流动 prepreg；开窗与层压顺序与板厂共同确定；记录压合次数。
- **怎么查**：刚挠叠层图；压合次数；热循环/分层测试；翘曲测量。
- **依据**：IPC-2223 刚挠结合叠层、IPC-6013；按板厂能力表复核。

## 3. 连接器与电气

### KP-PCB-267 金手指/ZIF：厚度、镀金、倒角与插入方向

- **判据**：FPC 金手指厚度按连接器 datasheet（常见 0.1–0.2 mm，需复核）；接触区镀硬金（常见 0.3–0.5 µm，按插拔次数/厂家要求）；金手指前端倒角/斜边便于插入；插入方向与连接器一致，接触面(金手指面)朝向连接器触点。
- **为什么**：金手指厚度决定插拔力与接触可靠性；镀金太薄易磨损/氧化；无倒角会插入困难、刮伤触点。
- **怎么做**：按连接器 datasheet 出金手指图（宽度/间距/长度/倒角）；接触区不覆盖膜；补强放在金手指背面；丝印标插入方向/1 脚。
- **怎么查**：金手指尺寸/镀层厚度（切片/XRF）；插拔力测试；插入方向 3D 检查；接触电阻。
- **依据**：连接器 datasheet、IPC-6013 镀层要求；镀金厚度按插拔寿命要求复核。

### KP-PCB-268 柔性连接器选型：ZIF/FFC/板对板/热压，按插拔次数与空间选

- **判据**：ZIF（翻盖/抽屉）适合需频繁插拔、接触可靠；FFC 直插适合低成本一次性装配；板对板连接器适合高密度/高可靠；热压焊（hot bar）适合永久连接。选型必须核对间距、高度、插拔次数、保持力、电流。
- **为什么**：不同连接方式的保持力、插拔寿命、装配工艺差异大；选错会导致接触不良或装配困难。
- **怎么做**：按插拔次数/空间/电流列候选；确认连接器与 FPC 厚度匹配；留插拔手指空间；需要时加补强/固定胶。
- **怎么查**：datasheet 参数；插拔力/保持力测试；装配试插；3D 空间检查。
- **依据**：连接器 datasheet、IPC-2223 连接器装配建议；按实际供应商规格复核。

### KP-PCB-269 柔性板阻抗控制：材料 Dk/Df 与胶层厚度决定阻抗

- **判据**：柔性板微带/带状线阻抗同样按 `Z0` 公式计算，但 Dk 更低（PI 常见 3.2–3.6 @1 GHz，需按材料 datasheet）、胶层与覆盖膜厚度不可忽略；50 Ω/90 Ω/100 Ω 目标与刚性板一致，公差按协议（常见 ±10%，需复核）。
- **为什么**：PI 与胶的 Dk/Df 与 FR-4 不同，覆盖膜会改变微带有效介电常数；忽略胶层会让实测阻抗偏低。
- **怎么做**：按材料 datasheet 的 Dk/Df 与叠层厚度计算；把覆盖膜/胶层纳入模型；与 FPC 板厂确认阻抗计算书；加阻抗测试条。
- **怎么查**：板厂阻抗计算书；TDR 测试条；切片测介质厚度；与仿真对比。
- **依据**：IPC-2141 传输线公式、材料 datasheet、IPC-6013；数值按板厂计算书复核。

### KP-PCB-270 柔性板载流与散热：铜薄、散热差，按最窄处降额

- **判据**：FPC 铜厚常用 1/3 oz、1/2 oz、1 oz（12/18/35 µm），载流能力低于同宽度刚性板；大电流路径按最窄处计算并留 ≥1.5 倍余量；避免在弯折区走大电流；发热器件靠近补强/散热铜皮。
- **为什么**：PI 导热差、铜薄，热量只能沿铜箔传导；弯折区大电流会加速铜箔疲劳。
- **怎么做**：电源/地尽量宽、多层并联；大电流区加补强/散热铜；过孔分散；必要时用厚铜或铜条。
- **怎么查**：载流计算（按铜厚/温升）；满载温升实测；红外热像；压降测量。
- **依据**：IPC-2152/2221 载流原则、材料 datasheet；具体按厂家铜厚与温升复核。

### KP-PCB-271 柔性板屏蔽：银浆/铜箔屏蔽层要连续接地

- **判据**：需要 EMI 屏蔽的 FPC 用银浆屏蔽层或覆铜箔层；屏蔽层必须连续、通过接地焊盘/过孔/连接器地与主地低阻抗连接；屏蔽层开窗处不得形成长缝；弯折区屏蔽层要选耐弯折材料。
- **为什么**：FPC 常作为整机内部天线/耦合路径，屏蔽不连续会泄漏；银浆方阻、铜箔厚度决定屏蔽效果。
- **怎么做**：屏蔽层覆盖高速/时钟区域；接地过孔/焊盘沿边缘布置；与连接器外壳 360° 搭接；弯折区用薄铜/银浆并做弯折验证。
- **怎么查**：屏蔽层连续性；接地阻抗；近场/远场对比；弯折后屏蔽层裂纹。
- **依据**：IPC-2223 EMC 建议、材料 datasheet；屏蔽效能按实测复核。

### KP-PCB-272 柔性板接地与 ESD：给放电电流一条短而宽的路

- **判据**：FPC 地平面尽量完整，弯折区地线用多条细线/网格；接口处 TVS/ESD 器件靠近连接器，地回路短而宽；金手指/连接器地针优先接地；避免 ESD 电流经过弯折区细线。
- **为什么**：FPC 地阻抗高，ESD 电流会在细线上产生压降，打坏芯片；弯折区细线易被 ESD/浪涌烧断。
- **怎么做**：地线并联多条、加宽；接口地单独引到主地；TVS 地就近打孔/焊盘；必要时加屏蔽层接地。
- **怎么查**：地连续性/阻抗；ESD 枪实测；TVS 位置与回路；弯折后地线通断。
- **依据**：IEC 61000-4-2 应用原则、IPC-2223；等级按产品要求复核。

## 4. 制造、装配与验收

### KP-PCB-273 柔性板 SMT：托盘/支撑、低温回流、防翘曲

- **判据**：FPC 贴片必须用承载托盘/磁性夹具 + 定位孔固定；支撑区避开器件/金手指；回流曲线按 FPC 与焊膏调整（FPC 吸热快、易翘曲）；双面贴装需确认第二面回流对第一面的影响。
- **为什么**：FPC 薄、软、热容小，直接过炉会翘曲/移位；支撑不足会导致虚焊/偏位。
- **怎么做**：托盘开窗对应器件；定位孔与 FPC 工艺孔对齐；必要时点胶固定；回流后平放冷却；与 SMT 厂确认 FPC 专用载具。
- **怎么查**：首件贴装/AOI；翘曲测量；虚焊/偏位统计；载具 3D 检查。
- **依据**：IPC-2223 装配建议、J-STD-020 回流曲线；具体按 SMT 厂工艺复核。

### KP-PCB-274 柔性板拼板与工艺边：用「框+桥」而不是 V-CUT

- **判据**：FPC 拼板常用带工艺边框 + 连接桥/邮票孔/胶带固定，不用 V-CUT（软板无法 V-CUT）；工艺边宽度按板厂（常见 ≥5 mm，需复核）；拼板外形圆角、无尖角；每拼板加 Mark/定位孔（按贴片厂要求）。
- **为什么**：FPC 柔软，V-CUT 无法分板且会伤铜；边框提供传送/定位刚性；连接桥便于分板且不留毛刺。
- **怎么做**：拼板图标注边框、桥宽、桥位置、Mark、定位孔；桥避开器件/金手指；分板用冲切/激光/手工；与板厂确认拼板方式。
- **怎么查**：拼板图评审；分板后边缘/器件检查；贴片定位；板厂 DFM 报告。
- **依据**：IPC-2223 拼板建议、板厂 FPC 能力表；尺寸按厂家复核。

### KP-PCB-275 柔性板表面处理：ENIG/硬金/OSP 按接触与焊接需求选

- **判据**：SMT 焊盘可用 ENIG/OSP；金手指/接触区必须硬金（厚度按插拔次数）；ENIG 注意黑盘/镍腐蚀风险；OSP 成本低但不耐多次回流/存储。
- **为什么**：不同表面处理的焊接性、接触电阻、耐磨性、存储寿命差异大；金手指用 ENIG 会很快磨穿。
- **怎么做**：焊接区与接触区分开处理（选化金+硬金/局部镀金）；按板厂能力确认；存储期限与包装按要求。
- **怎么查**：表面处理工艺单；镀层厚度（XRF/切片）；可焊性测试；接触电阻/插拔寿命。
- **依据**：IPC-4552（ENIG）等表面处理规范、IPC-6013；厚度按产品要求复核。

### KP-PCB-276 柔性板测试：通断、阻抗、弯折寿命、外观四件套

- **判据**：FPC 必须做：①通断/短路测试（飞针/治具）；②阻抗测试（如受控）；③弯折寿命试验（动态/静态，按产品次数）；④外观/尺寸/覆盖膜/补强检查；关键产品加温循/盐雾/湿热。
- **为什么**：FPC 的铜裂、分层、覆盖膜起翘在外观上不一定明显，必须靠电测与弯折试验暴露。
- **怎么做**：按测试大纲逐项做；记录弯折次数与电阻变化；首件+抽检；失效样品做切片/显微分析。
- **怎么查**：测试报告；弯折寿命曲线；切片；FAI 记录。
- **依据**：IPC-6013 验收、IPC-2223 测试建议；试验条件按产品规范复核。

### KP-PCB-277 柔性板常见失效：铜裂、分层、覆盖膜脱落、补强剥离

- **判据**：典型失效模式：弯折区铜箔疲劳裂纹（电阻增大/开路）、PI/胶分层（起泡/白化）、覆盖膜起翘/脱落、补强剥离、金手指磨损/氧化、过孔孔壁裂。判据按 IPC-6013/客户规范与寿命试验结果。
- **为什么**：FPC 失效多为机械/热机械疲劳，根因常在弯折半径、铜箔类型、覆盖膜工艺、补强设计或装配应力。
- **怎么做**：失效分析（外观/切片/显微/EDS）；回溯设计（半径/材料/层结构）与工艺（压合/烘烤/装配）；改设计后重做寿命试验。
- **怎么查**：失效样品切片；弯折试验；分层扫描（超声/C-SAM）；供应商 8D 报告。
- **依据**：IPC-6013、IPC-2223、IPC-A-610 相关验收原则；具体判据按产品规范复核。

### KP-PCB-278 柔性板存储与装配：防潮、防折、防拉

- **判据**：FPC 真空/防潮包装，存储温湿度按材料要求（常见 ≤30 °C/60%RH，需复核）；装配时不得拉扯/折叠金手指/补强边缘；弯折按工装限位；必要时装配前烘烤除湿。
- **为什么**：PI/胶吸湿后在回流/焊接时爆米花/分层；手工装配的拉扯会直接损伤铜箔。
- **怎么做**：按 MSL/材料要求存储；装配 SOP 规定拿取位置（补强/边框）；使用弯折工装；烘烤按 J-STD-033 条件。
- **怎么查**：来料包装/湿度指示卡；装配 SOP 执行；分层/起泡检查；装配后通断。
- **依据**：J-STD-033 潮湿敏感器件处理、材料 datasheet；条件按供应商要求复核。

### KP-PCB-279 柔性板 DFM 清单：10 项投板前必查

- **判据**：投板前确认：①叠层与总厚；②弯折区 keepout（无过孔/器件/大铜）；③弯折半径与方向；④覆盖膜开窗/桥宽；⑤补强位置/材料/厚度；⑥金手指尺寸/镀金/倒角；⑦阻抗计算书（如需要）；⑧拼板/边框/Mark/定位孔；⑨表面处理；⑩测试要求（通断/弯折/阻抗）。
- **为什么**：FPC 的 DFM 问题在打样后修改成本高（要重开压合/覆盖膜模具），投板前检查性价比最高。
- **怎么做**：按清单逐项留证据；与板厂 DFM 确认；未闭合项走 ECO。
- **怎么查**：DFM 检查表签字；板厂 EQ；首件报告；`GATE-03`/`GATE-05` 对齐。
- **依据**：IPC-2223 DFM 建议、板厂 FPC 能力表；清单按项目流程固化。

### KP-PCB-280 刚挠板机械与结构：弯折区与安装点分开受力

- **判据**：安装孔/螺钉/定位柱应放在刚性区；弯折区不得承受整机装配力；刚挠过渡区加应力释放槽/圆角；连接器受力方向不得指向弯折区；外壳限位与弯折半径匹配。
- **为什么**：刚挠结合处是刚度突变点，装配力/振动会集中到界面，导致分层/铜裂。
- **怎么做**：结构 3D 与 PCB 联合评审；安装点放刚性区；过渡区加缓冲/限位；线缆固定点避免拉弯折区。
- **怎么查**：3D 装配/干涉；振动/跌落测试；弯折区应力仿真；装配后通断。
- **依据**：IPC-2223 刚挠结构建议、结构设计规范；按整机可靠性要求复核。

### KP-PCB-281 弯折寿命估算：只能做量级估算，最终必须实测

- **判据**：弯折寿命与半径、角度、铜箔类型、层数、覆盖膜、环境温度强相关，可用「半径越大/角度越小/RA 铜/层数越少 → 寿命越长」做定性排序；定量必须用弯折试验（记录失效次数与电阻变化），不能靠公式外推。
- **为什么**：铜箔疲劳受晶粒、胶层蠕变、装配公差影响，理论公式误差可达数量级；不同批次材料也会有差异。
- **怎么做**：做 DOE（半径×角度×铜箔）找拐点；以最差装配公差做试验；留寿命余量；把试验条件写进 SPEC。
- **怎么查**：弯折试验机数据；失效分析；与供应商材料数据对比；量产抽检。
- **依据**：IPC-2223 动态弯折建议、材料 datasheet；寿命数据以实测为准。

### KP-PCB-282 柔性板评审清单：材料/弯折/连接/工艺四组签字

- **判据**：评审分四组：①材料与叠层（PI/铜/覆盖膜/补强）；②弯折（半径/方向/keepout/寿命）；③连接（金手指/连接器/补强/插拔）；④工艺（拼板/SMT/表面处理/测试）。任一组未闭合不得投板。
- **为什么**：FPC 问题跨材料、机械、电气、工艺四个域，单组评审容易漏项。
- **怎么做**：用可勾选清单；每组指定负责人；未闭合项标 ⚠️ 并走 ECO；首件后回写。
- **怎么查**：评审记录签字；DFM/EQ；首件报告；与 128 条规则中的 `CONN-*`/`MECH-*`/`DFM-*` 对齐。
- **依据**：IPC-2223/6013、项目评审流程；清单按团队模板固化。
