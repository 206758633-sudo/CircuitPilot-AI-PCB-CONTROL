# 23. 嘉立创EDA专业版工程闭环与 B 站课程学习笔记

> **一句话结论：** 从“会点菜单”到“能投板”，要按 **工程/库身份 → 原理图 → PCB 布局 → 布线 → DRC → 输出文件 → 下单参数** 的闭环走；B 站课程适合建立操作顺序和手感，但课程是 C 级证据，数值、工艺能力和“能不能生产”必须回到官方文档、器件 datasheet、板厂能力表和人工评审。
>
> **来源说明（2026-10-30）：** 本笔记核对了嘉立创EDA官方 B 站教程的标题/简介/分P、`Expert电子实验室` 长课程的分P目录，以及嘉立创EDA官方文档中心的原理图规范、工程输出文件、免费打板流程页面。**没有取得视频逐字稿，也没有逐帧观看**；因此只把视频用于“课程路径/操作顺序”参考，不把视频里的口头经验写成数值规则。来源登记见 [`sources.json`](../../../knowledge/pcb/dataset/sources.json)。

## 2. 工程闭环

### KP-PCB-341 七阶段闭环与每阶段放行物

**判据：** 一块板从工程建立到可投板，至少经过 7 个阶段，每阶段有可检查的放行物：

| 阶段 | 输入 | 输出/放行物 | 失败时 |
|---|---|---|---|
| 1 工程/库 | 需求、器件选型 | 工程、图页、符号/封装/3D、版本号 | 身份不一致则停止 |
| 2 原理图 | 选型、datasheet | 可读原理图、网络名、ERC 结果 | ERC 未归属不得进 PCB |
| 3 PCB 布局 | 结构、接口、电源 | 板框、器件位置、courtyard/3D 检查 | 干涉/接口方向错则回布局 |
| 4 布线 | 布局、叠层、规则 | 电源/地/信号/差分走线、回流路径 | DRC 未过不得铺铜定稿 |
| 5 检查 | 布线结果 | DRC、丝印、3D、DFM/DFA 检查 | 逐条修复或带理由豁免 |
| 6 输出 | 已检查的板 | Gerber、钻孔、BOM、坐标、装配图、源文件 | 任一套缺失/版本不一致不得投板 |
| 7 下单/归档 | 输出包、工艺单 | 下单参数复核、EQ 记录、版本归档 | 参数与设计不一致则停止 |

**为什么：** 后面阶段的错误会掩盖前面阶段的问题。比如封装引脚号错，ERC 可能不报，但 PCB 网表和实物一定错；DRC 0 也可能只是“没有违反当前规则”，不代表器件选型/电源/可制造性正确。

**怎么做：** 用同一套版本号贯穿工程/BOM/PCB/输出包；每阶段结束留一个可复核文件（截图、ERC/DRC 报告、BOM、坐标、装配图），不要用聊天记录当证据。

**怎么查：** 按上表逐项打勾；任一阶段放行物缺失，整体状态只能是“未完成”，不能因为最后 DRC 绿了就倒推前面都正确。

**来源：** 嘉立创EDA 官方文档“工程最终可输出文件”和官方 18 集课程顺序（B/C 级，操作路径参考）。  
**关联条目：** `PCB-MOD-LCEDA-WORKFLOW`。

### KP-PCB-342 原理图可读性：标题栏、模块分区、未连接标记

**判据：** 原理图至少满足：

- 右下角标题栏写清工程/图页名称、公司/作者、绘制/审阅人、页数、日期、版本号、物料编码；
- 每个功能模块有矩形框+文字标注，模块名能直接对应电源/接口/MCU/驱动等；
- 芯片去耦电容画在芯片电源脚旁边，和 PCB 布局顺序一致；
- 未使用的引脚放**非连接标识符**，不要悬空让人猜；
- 大图用多图页或层次图块，顶层框图能看清模块间连接。

**为什么：** 原理图是评审、调试、ECO 和新人交接的共同语言；图页没有版本/模块边界，后面改一点就找不到影响面。官方规范页面明确把标题栏信息、模块划分、去耦位置和未连接标识作为绘图规范。

**怎么做：** 建工程时先填标题栏；按功能画框；先放连接器和电源入口，再放 MCU/外设；去耦跟着芯片走；最后统一网络名和未连接标记。

**怎么查：** 按“标题栏完整、模块边界清楚、去耦在芯片旁、未用脚有 NC 标记、图页版本可追溯”五项人工走查；再跑 ERC，但 ERC 通过不能替代可读性评审。

**来源：** 嘉立创EDA 官方文档《原理图设计规范》（B 级）。  
**关联条目：** `PCB-RULE-LCEDA-SCH-003`。

### KP-PCB-343 符号/封装/3D 身份必须先对齐

**判据：** 一个器件进入 BOM 前，至少确认：

1. 符号引脚号 = 封装焊盘号 = datasheet 引脚号；
2. 封装焊盘尺寸/间距/极性/1 脚方向与器件规格一致；
3. 3D 模型方向/高度与实物一致（有结构干涉要求时必须看）；
4. 位号、值、MPN、LCSC/供应商料号在同一器件上不冲突；
5. 库版本可追溯，复制/修改库有记录。

**为什么：** B 站课程反复演示“先建符号、再建封装、再放器件”，但课程示例不能替代 datasheet 核对。符号/封装错是典型的“原理图看起来对、板子一定错”，DRC 不一定能发现。

**怎么做：** 建库时从 datasheet 的 pin map 抄引脚；封装按 IPC-7351/器件推荐焊盘；3D 只作辅助，机械干涉以结构图为准；新器件先在测试工程放一遍，打印 1:1 核对。

**怎么查：** 逐脚对照 datasheet；封装 1:1 打印/卡尺；3D 与结构图叠合；BOM/原理图/PCB 三方核对位号与 MPN。

**来源：** 官方 18 集第 6/7 集、长课程“元件符号/封装绘制”分P（C 级，操作顺序）；身份规则属于工程常识，最终以 datasheet 为准。  
**关联条目：** `PCB-RULE-LCEDA-LIB-004`、`CMP-RULE-LIB-001`。

### KP-PCB-344 布局：先固定“不能动”的，再摆“可以动”的

**判据：** 布局完成时至少满足：

- 板框/安装孔/连接器/按键/LED/天线区先按结构固定；
- 连接器开口朝外，接口 ESD/保护器件靠连接器；
- 电源入口→保险丝/保护→滤波→DC-DC/LDO→负载，按功率流向摆放；
- 去耦电容紧贴 IC 电源脚，地过孔短；
- 晶振靠近 MCU、下方净空；RF 天线区按模组要求净空；
- 高热器件分散，热敏器件远离热源；
- 所有器件 courtyard 不重叠，3D 不干涉，贴片机/AOI/返修空间够。

**为什么：** 布局决定回流路径和布线可行性，后面很难靠布线补救。官方课程把布局单独作为一集（约 28 分钟），长课程也把“核心板布局/USB 拓展坞布局”作为独立阶段，说明它是独立交付物，不是布线的附属动作。

**怎么做：** 先画板框和固定件；再放接口/电源/大件；再放 IC 和去耦；最后放小阻容/测试点；每放完一个区就做 courtyard/3D 检查，不要等全板摆完再查。

**怎么查：** courtyard DRC、3D 干涉、1:1 打印、接口方向目检、电源流向走查、热像/温升实测（有条件时）。

**来源：** 官方 18 集第 10 集、长课程布局分P、官方布局指导页面（C/B 级）。  
**关联条目：** `PCB-MOD-LCEDA-WORKFLOW`。

### KP-PCB-345 布线：电源/地→高速/差分→普通信号→铺铜

**判据：** 布线完成时至少满足：

- 电源/地先布，按电流算线宽/过孔，避免细线瓶颈；
- 高速/差分/时钟按叠层和阻抗要求布，参考平面连续，不跨分割；
- 普通信号最后布，避免为了“连通”破坏电源/地/高速；
- 换层信号旁边有回流地孔；
- 晶振/RF/开关电源环路按模块要求处理；
- 铺铜后重建覆铜，再做最终 DRC；
- 丝印不压焊盘，极性/1 脚可读。

**为什么：** 先布普通信号会占掉电源/地通道，导致后面要么加层要么飞线；高速信号跨分割会造成回流绕行和 EMI。官方课程把布线单独作为一集（约 33 分钟），长课程则先讲“布线原则”再做实板布线。

**怎么做：** 设置好设计规则/网络类后再布；电源和地先走；差分对按规则成对布；每完成一个区就局部 DRC，不要等全板；铺铜后重开文档再跑 DRC，避免缓存误报。

**怎么查：** DRC 按网络类分组；关键网络量线宽/过孔/回流；高速看参考平面；电源看最窄处；最后目检丝印和极性。

**来源：** 官方 18 集第 11 集、长课程布线原则/实板布线分P（C 级，操作顺序）；数值规则见现有 PCB 规则条目。  
**关联条目：** `PCB-MOD-LCEDA-WORKFLOW`。

### KP-PCB-351 布局不是“先放主控”，而是先放不能动的约束

**判据：** 有结构/外壳/接口/安规/功率约束的板，布局顺序建议为：

1. **结构定位**：板框、安装孔、限高区、连接器开口、按键/LED/天线区；
2. **接口对齐**：连接器先对齐外壳开孔和线缆方向；
3. **功率链路**：电源入口→保护/滤波→变换器→负载，尽量短、直、粗、闭环；
4. **安规隔离区**：高压/低压、一次/二次、隔离带先划出来；
5. **接口防护**：TVS、保险丝、共模电感/ESD 器件靠接口；
6. **主控统筹**：主控放在能兼顾高速/模拟/低速分区的位置，而不是机械地放板中心；
7. **外设分区**：高速、模拟、低速/大电流分开；
8. **阻容器件**：最后做去耦/匹配/细化，但仍受“去耦靠引脚”约束。

**为什么：** 主控位置一旦先定，接口、功率、防护和安规区会被迫绕路；后面再改就要重摆、重布、重跑 DRC。先放结构和接口，能把“不可动约束”固定下来，主控才有真正的选择空间。

**怎么做：** 先在结构图/装配图上标固定件和接口方向；把电源入口和防护件放好；划隔离带；再定主控；最后放阻容/测试点。每放完一个区做 courtyard/3D 检查。

**怎么查：** 布局评审按“结构→接口→功率→安规→防护→主控→外设→阻容”顺序走查；检查接口方向、功率路径长度/宽度、隔离间距、防护器件到接口距离、主控到高速接口/晶振距离。

**来源：** 芯团网视频简介（C 级，工程启发式）；官方布局课程（C 级）。  
**关联条目：** `PCB-RULE-LCEDA-LAYOUT-005`、`PCB-MOD-LCEDA-LAYOUT-PRIORITY`。

### KP-PCB-352 功率链路和接口防护要“先短直粗、再谈美观”

**判据：**

- 电源入口→保险丝/共模/整流/滤波→DC-DC/LDO→负载的路径尽量短、直、宽；
- 大电流环路面积小，输入电容/输出电容靠近对应引脚；
- TVS/ESD/保险丝/共模电感靠连接器，先过保护再进板内；
- 功率器件散热铜/过孔/开窗按电流和温升设计；
- 功率区与模拟/射频/晶振区保持距离，必要时加屏蔽/开槽/隔离带；
- 先保证路径和环路，再做“整齐好看”的走线。

**为什么：** 功率路径长/细会增加压降、发热和环路面积；防护器件放远会让浪涌/ESD 先打坏板内电路。布局阶段的功率流向错误，布线阶段很难补救。

**怎么做：** 用不同颜色/区域标出功率路径；先放输入保护、输入电容、功率电感/变压器、输出电容；量最窄处宽度和环路面积；再放信号器件。

**怎么查：** 电源流向图、最窄线宽/过孔数量、输入/输出电容到引脚距离、TVS 到连接器距离、功率区温升/热像；DRC 之外还要人工看环路。

**来源：** 芯团网视频简介（C 级）；现有电源/布局规则条目。  
**关联条目：** `PCB-RULE-LCEDA-LAYOUT-005`、`PCB-MOD-LCEDA-LAYOUT-PRIORITY`。

### KP-PCB-353 布局评审的最小问题清单

**判据：** 布局评审至少问 10 个问题：

1. 板框/安装孔/限高/接口方向是否来自结构图，而不是“看起来差不多”？
2. 连接器是否朝外、能否插拔、线缆是否干涉？
3. 电源入口/保护/滤波/变换器/负载是否按功率流向排？
4. 大电流路径最窄处够不够，环路面积是否可控？
5. 高压/低压/隔离带是否提前划分，爬电/电气间隙是否满足？
6. TVS/ESD/保险丝/共模是否靠接口？
7. 主控是否兼顾高速接口、晶振、调试口，而不是盲目居中？
8. 高速/模拟/低速/大电流是否分区，敏感电路是否远离干扰源？
9. 去耦电容是否靠 IC 电源脚，地过孔是否短？
10. courtyard/3D/散热/可维修/测试点是否检查过？

**为什么：** 布局错误在布线后修复成本最高；用固定问题清单可以在进入布线前拦住“结构冲突、功率绕路、防护放远、主控挡接口”等硬伤。

**怎么做：** 把清单放进项目评审记录；每项给“通过/不通过/待确认+证据”；不通过项必须在布线前关闭或明确豁免。

**怎么查：** 布局评审会 + 1:1 打印 + 3D + courtyard DRC + 电源流向图 + 结构图对照；清单签字后才进入布线。

**来源：** 官方布局课程（C 级）、芯团网视频简介（C 级）、现有布局/电源规则。  
**关联条目：** `PCB-RULE-LCEDA-LAYOUT-005`、`PCB-MOD-LCEDA-LAYOUT-PRIORITY`、`PCB-FAIL-LCEDA-LAYOUT-CENTER-MCU`。

## 3. 检查、输出与下单

### KP-PCB-346 DRC 是必要条件，不是充分条件

**判据：** 投板前必须：

1. 在 EDA 内主动执行 DRC，读完整报告，而不是只看“是否弹窗”；
2. 错误/警告逐条归属：已修 / 有依据豁免 / 待复核；
3. **0 错误 0 警告只是允许进入下单页的必要条件**；
4. 还要检查 DRC 覆盖不到的内容：器件选型/电源轨/极性/封装/3D/丝印/可制造性/可测试性/BOM 一致性；
5. 对“DRC 缓存”保持警惕：删改图元/覆铜后先重建/保存/重开，再复跑。

**为什么：** 官方免费打板流程明确要求下单前检查 DRC，确保 0 错误 0 警告；但 DRC 只检查规则库能表达的几何/连接问题，查不出“选了错器件”“电源轨缺失”“BOM 与坐标不一致”等设计错误。项目内已有真实案例：网表 0 差异时仍可能残留项目级 Netlist Error，说明 DRC 结论必须结合范围和缓存判断。

**怎么做：** 固定顺序：保存→重建覆铜→关闭重开→DRC→逐条处理→导出报告；对豁免项写理由、影响和批准人；不要把“忽略警告”当修复。

**怎么查：** DRC 报告计数+明细；豁免清单；与 BOM/坐标/装配图交叉检查；用测试工程复跑。

**来源：** 官方免费打板文档（B 级）、官方 18 集第 13 集（C 级）、项目内 EDA 缓存实测条目。  
**关联条目：** `PCB-RULE-LCEDA-GATE-001`。

### KP-PCB-347 生产文件是“一套”，不是“一个 Gerber”

**判据：** 工程输出至少包含以下 7 类，并放在同一版本目录：

| 类别 | 内容 | 用途 |
|---|---|---|
| 1 工程源文件 | `.epro`/`.eprj`、原理图 PDF、网表 | 追溯/返工/改版 |
| 2 Gerber | 铜层、阻焊、丝印、板框、内层 | PCB 制造 |
| 3 钻孔 | PTH/NPTH、孔径表 | 钻孔/沉铜 |
| 4 BOM | 位号、MPN、封装、数量、DNP | 采购/SMT |
| 5 坐标文件 | 位号、X/Y、旋转角、面别 | SMT 贴片 |
| 6 装配图 | 顶/底装配 PDF、极性/1 脚 | 手工焊接/返修 |
| 7 其他 | 叠层/阻抗/工艺单/EQ/DXF | 板厂工程确认 |

**为什么：** 官方文档明确把工程源文件、Gerber、BOM、坐标文件、装配文件、DXF 和其他工艺文件列为“工程最终可输出文件”；少一套，工厂就要回来问，或者按默认做错。Gerber 只解决“板子怎么做”，不解决“贴什么料、贴在哪、怎么装”。

**怎么做：** 建标准目录（如 `01_Gerber`、`02_Drill`、`03_BOM`、`04_PickPlace`、`05_Assembly`、`06_Stackup`、`07_Docs`）；所有文件用同一版本号/日期；导出后逐项打开检查，不只检查文件存在。

**怎么查：** 按清单逐项打勾；Gerber 用查看器叠层；BOM/坐标/装配图三方核对；源文件与输出包版本一致；旧版本归档不覆盖。

**来源：** 嘉立创EDA 官方文档《工程最终可输出文件》（B 级）、官方 18 集第 35 集生产文件导出（C 级）。  
**关联条目：** `PCB-RULE-LCEDA-OUTPUT-002`、`PCB-MOD-LCEDA-OUTPUT-PACK`。

### KP-PCB-348 BOM / 坐标 / 装配图必须三方一致

**判据：** 投板/SMT 前必须核对：

- BOM 位号集合 = 坐标文件位号集合 = 装配图位号集合；
- 每个位号的 MPN/值/封装/极性以 BOM 为准；
- 坐标文件的 X/Y/旋转角/面别与 Gerber 板框和封装 0° 定义一致；
- DNP/不贴/替代料在 BOM 和坐标中都有明确标记；
- 双面贴装分面清楚，底层镜像/旋转规则与贴片厂约定一致。

**为什么：** BOM 错一颗料会整批返修；坐标错会导致贴错位置/贴反；装配图错会让手工焊接把极性件装反。官方输出文档把 BOM、坐标、装配图分别列为独立输出，正是因为它们服务不同环节但必须同源。

**怎么做：** 从原理图导 BOM；从 PCB 导坐标；从同一版 PCB 导装配图；用位号做集合比对；对连接器/二极管/钽电容/LED/IC 的 1 脚逐项目检；把检查结果留成表格。

**怎么查：** 位号集合差集；关键器件抽 3–5 个用坐标在 Gerber 上量位置；首件 AOI/目检；SMT 厂回传的贴片程序核对。

**来源：** 官方输出文件文档（B 级）、长课程“丝印/DRC/生产文件”分P（C 级）。  
**关联条目：** `PCB-FAIL-LCEDA-BOM-CPL-MISMATCH`、`PCB-RULE-BOM-001`。

### KP-PCB-349 下单参数必须与设计/工艺单一致

**判据：** 进入下单页后逐项复核：板层/尺寸/板厚/铜厚/阻焊颜色/表面处理/字符工艺/拼版/出货方式/确认生产稿/SMT/钢网。任何一项与设计文件或工艺单不一致，先停止下单。

**为什么：** 官方免费打板流程中，下单页会根据设计文件带出参数，但仍允许人工修改；参数被改错（例如表面处理、板厚、拼版）不会被 DRC 拦住，却会直接改变实物。优惠券/活动只影响价格，不影响工程正确性。

**怎么做：** 下单前把“设计参数—工艺单—下单页”三列并排核对；截图留档；批量订单选择确认生产稿；不把“免费/加急”当作跳过检查的理由。

**怎么查：** 下单页截图+设计文件参数+工艺单三方对照；板厂 EQ/确认函；首件与订单参数核对。

**来源：** 官方免费 PCB 打板文档（B 级）、官方 18 集第 13 集（C 级）。  
**关联条目：** `PCB-FAIL-LCEDA-ORDER-UNCHECKED`。

## 4. 把视频学习转成工程知识

### KP-PCB-350 视频只能当 C 级证据

**判据：** 从 B 站/课程得到的结论，入库时必须：

- 标 `evidenceLevel: C` / 来源类型 `video-tutorial`；
- 只写“操作顺序/界面路径/学习路径”这类可复核内容；
- 涉及数值、标准、工艺能力、器件参数时，必须另引官方文档/datasheet/标准原文；
- 不把“讲师说”“视频里这样做”写成门禁依据；
- 保留视频 BV 号、标题、作者、核对日期和未核对声明（如“未取得逐字稿”）。

**为什么：** 视频会更新、会省略前提、会把教学示例简化；它不是标准，也不是器件 datasheet。项目知识库的 `candidate` 和 `approved` 分层必须保持，AI 不能自审自证。

**怎么做：** 学完一节 → 写“我实际复现了什么/检查结果是什么” → 只把可重复的操作步骤写成文档；数值结论回到官方文档；结构化条目 `sources` 指向已登记来源。

**怎么查：** 条目是否能追溯到 BV/URL；是否有 `caveat`；是否引用了 A/B 级来源支撑关键数值；是否仍是 candidate。

**来源：** 本笔记的方法约定，以及项目知识治理规范。  
**关联条目：** `PCB-MOD-LCEDA-WORKFLOW`（来源声明）。
