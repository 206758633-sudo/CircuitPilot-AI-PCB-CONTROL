# 可靠性与降额设计（寿命、环境试验、鉴定与闭环）

> 适用前提：消费电子/工业控制/电源类 PCBA，主要器件为 DC-DC/LDO、MCU、连接器、电解/瓷介电容、电阻、MOSFET 与焊点；具体降额比例、试验条件、样本量与判据必须按**器件 datasheet、企业可靠性规范、IPC-9592B / JESD47 / JESD22 / IEC 60068 正本与客户要求**复核。
> 定位：本文接续 [`08-component-placement.md`](./08-component-placement.md)（08 篇止于 `KP-PCB-166`），回答“**这块板在寿命周期内会不会坏、凭什么说不会坏、坏了怎么定位**”。热阻计算见 [`05-emc-esd-thermal.md`](./05-emc-esd-thermal.md)，制造与验收见 [`06-dfm-manufacturing.md`](./06-dfm-manufacturing.md)，多层板 CAF/翘曲/热循环见 [`07-multilayer-highspeed.md`](./07-multilayer-highspeed.md)。
> 编号约定：`KP-PCB-167` 起接续 08 篇，全局连续。
> 可信度声明（2026-10-22）：本期 `web_search` 无 API key、多数公网站点被策略拦截；已用 `bash + curl` 抓取并解析 **IPC-9592B 官方目录 PDF**（§4 Design for Reliability、§5 Design and Qualification Testing、§7 Manufacturing Conformance Testing 的条款结构，见 §7.2）。其余标准号/试验项按公开标准目录与行业通用做法表述，**未逐条核对标准正文数值**；文中所有比例、温度、循环数均为“工程起点/经验范围”，落地必须按标准正本、器件 datasheet、板厂能力与认证机构文件复核。

**一句话结论**：可靠性不是“选好料”或“做一次老化”就能证明的；它是一条 **任务剖面 → 降额计算 → 失效机理 → 加速试验 → 数据闭环** 的可追溯链，每一环都要有量测值、判据和证据，且 MTBF、寿命、失效率这些词必须先统一口径。

## 0. 适用范围、口径与证据等级

| 项 | 本文口径 | 说明 |
|---|---|---|
| 产品范围 | 消费电子/工业控制/电源类 PCBA | 车规、医疗、航天按 AEC-Q100/ISO 26262/IEC 60601 等专用规范另行加严 |
| 可靠性指标 | MTBF、FIT、B10 寿命、退化量、现场失效率 DPPM | 不同指标不可混用（见 KP-PCB-167、KP-PCB-198） |
| 应力量 | 电压/电流/功率/结温/机械应力比 | 应力比 = 实际工作值 ÷ 额定值 |
| 环境试验 | IEC 60068-2-x、JESD22-Axxx、IPC-9592B §5 | 具体条件按产品任务剖面裁剪 |
| 试验性质 | 鉴定（qualification）、筛选（screening）、增长（HALT/HASS） | 三者目的不同，不可互相替代 |
| 证据等级 | S 法规/A 器件文件/B 标准/C 工艺/D 市场/E 实测 | 与 08 篇一致：S 级一票否决，D 级只作假设 |

> **边界**：本文不替代元器件原厂鉴定报告、不替代认证机构的安规/EMC 测试（见 [`11-safety-certification.md`](./11-safety-certification.md)）；没有实测数据的“高可靠”结论只能标为假设。

## 1. 先定口径：目标、任务剖面与证据链

### KP-PCB-167 可靠性指标必须写清“口径 + 条件”，不能只写“高可靠”

- **判据**：可靠性目标必须同时写：指标类型（MTBF/FIT/B10/DPPM）、统计口径（是否含早期失效、是否含电源/风扇等非板级件）、环境条件（温度/负载/占空比）、置信度与样本量；只写“高可靠/工业级”视为无效目标。
- **为什么**：MTBF 是“平均无故障间隔”，不等于寿命；FIT 是失效率单位（1 FIT = 10⁻⁹/h）；B10 是 10% 失效对应的寿命。口径不同，同一块板可以算出相差一个数量级的结论，采购/客户/研发各说各话。
- **怎么做**：在项目可靠性计划里固定一行“指标 = 数值 + 口径 + 条件 + 证据来源”；客户要求与内部目标分列；指标变更走版本记录。
- **怎么查**：抽查可靠性计划；MTBF 报告是否写清环境/负载/是否含电解电容等短板件；指标与投标/合同是否一致。
- **依据**：IPC-9592B §4.1 Reliability Prediction (FIT) 把可靠性预测作为独立条款；Telcordia SR-332 / MIL-HDBK-217F / IEC 61709 均要求声明使用条件与模型版本。**具体模型选择与系数需按标准正本复核。**

### KP-PCB-168 任务剖面（mission profile）是降额、寿命与试验条件的共同输入

- **判据**：降额表、加速试验条件、MTBF 计算必须引用同一份任务剖面：环境温度范围与日/年循环、负载曲线与占空比、输入电压范围、开关次数、插拔次数、振动/跌落/湿度暴露、预期工作年限。
- **为什么**：同一块板在“25 °C 常开”和“55 °C 每天 20 次温循”下的失效机理与寿命完全不同；没有剖面，降额比例和试验循环数都是拍脑袋。
- **怎么做**：按“场景 → 环境参数 → 持续时间/循环 → 来源（客户/现场数据/标准）”建剖面表；用最恶劣工况做降额，用典型工况做寿命预估；剖面变更触发重新评估。
- **怎么查**：剖面表是否覆盖温度/负载/湿度/机械/年限；降额计算与试验报告引用的剖面是否同一版本；是否有“最恶劣工况”说明。
- **依据**：IPC-9592B §5.1 DVT 要求按产品用途定义测试条件与限值；IEC 60068 系列要求先定义试验严酷等级。**具体等级需按标准正文与客户规范确认。**

### KP-PCB-169 降额、试验、FMEA 三条证据链缺一不可

- **判据**：可靠性结论至少有三类证据：① 降额计算（每个关键器件的应力比）；② 鉴定/环境试验报告（失效判据、样本量、结果）；③ FMEA/失效机理分析（关键单点、探测措施）。缺任一类即视为“证据不足”。
- **为什么**：只降额不试验，无法暴露工艺/装配缺陷；只试验不降额，会把设计裕量不足掩盖成“偶发不良”；只做 FMEA 不验证，则是纸面可靠性。
- **怎么做**：建“可靠性证据矩阵”（器件/板级 × 降额/试验/FMEA/现场数据），空白格列为风险；关键单点失效必须有三类证据。
- **怎么查**：证据矩阵完整度；关键器件是否三项齐全；证据是否与当前 BOM/版本对应。
- **依据**：IPC-9592B §4（Design for Reliability：Reliability Prediction、Component Selection、DFMEA、Derating、Voltage Spacing）与 §5（DVT/EST）构成“设计 + 验证”双支柱，可作为证据矩阵框架。

### KP-PCB-170 可靠性证据分级：区分“标准要求 / 厂商承诺 / 实测 / 经验”

- **判据**：每条可靠性结论标注证据等级：S（法规/认证强制）、A（器件 datasheet/原厂鉴定报告）、B（IPC/JEDEC/IEC 标准方法）、C（板厂/工艺能力）、D（行业经验/市场做法）、E（本板实测/仿真）。D 级只能作假设，E 级需注明样本量与条件。
- **为什么**：可靠性领域“经验值”极多且互相矛盾；不标等级，评审时无法判断哪条能签字、哪条只是参考。
- **怎么做**：结论表加“等级/来源/日期/样本量”四列；A 级优先于 D 级；冲突时按“法规 > 器件文件 > 标准 > 实测（本板）> 经验”排序，实测可覆盖经验但不能覆盖法规。
- **怎么查**：随机抽 10 条结论看等级与来源；D 级结论是否被写成强制规则；E 级是否写样本量/条件。
- **依据**：与 [`08-component-placement.md`](./08-component-placement.md) §0 的证据等级表一致；IPC-9592B 将产品分为 Class I/II 并按等级规定不同要求，说明“等级决定要求”是行业通行方法。

## 2. 降额准则：把“额定值”翻译成“工作裕量”

### KP-PCB-171 降额的定义与算法：先算应力比，再按器件类型查表

- **判据**：每个关键器件至少计算一个主应力比：电阻=实际功率/额定功率；电容=工作电压/额定电压（并校核纹波电流）；MOSFET=实际 VDS/额定 VDS、实际 ID/额定 ID、结温；连接器=每触点电流/额定电流；PCB=实际电流下的温升。应力比超企业规范限值即不合格。
- **为什么**：额定值通常是“25 °C、理想散热、单一应力”下的极限，实际板内温度、纹波、瞬态都会叠加；降额就是把多应力叠加后的裕量显式化。
- **怎么做**：从 BOM + 原理图提取工作点（电压/电流/功耗/温度），用脚本或表格批量算应力比；对温度相关参数按最高工作温度修正；输出“超限清单”。
- **怎么查**：抽 5 个功率/高压器件复算应力比；降额表是否用最高工作温度；超限项是否有评审/更换记录。
- **依据**：IPC-9592B §4.4 Derating Guidelines（含 §4.4.1 Documentation Requirements）要求降额成文并可追溯；比例限值以企业规范/客户要求为准，IPC-9592B 正文给出其适用器件的降额表（**需按正本复核**）。

### KP-PCB-172 电阻降额：功率、电压、温度三重校核，脉冲要单独算

- **判据**：常见工程起点（非标准强制值）：连续功率 ≤ 额定 50–60%（环境温度高、散热差时更严）；工作电压 ≤ 额定电压 80%；贴片电阻在 70 °C 以上按 datasheet 降额曲线折减；脉冲/浪涌按 datasheet 的脉冲功率-时间曲线单独校核。
- **为什么**：电阻失效主要是过热与膜层损伤；功率降额不足会长期漂移甚至开路；高压/脉冲下还有电压系数与瞬态击穿问题。
- **怎么做**：按最坏功耗选型；高温区优先金属膜/厚膜高功率封装；浪涌路径（输入、继电器、电容充电）用脉冲曲线校核；避免用 0 Ω 电阻当保险丝（除非认证允许）。
- **怎么查**：功耗复算；额定电压 vs 工作电压；datasheet 降额曲线；浪涌波形与脉冲曲线比对。
- **依据**：器件 datasheet 的 derating curve 与脉冲曲线为 A 级依据；比例区间为行业工程起点，**具体限值需按企业降额规范确认**。

### KP-PCB-173 电容降额：MLCC 看电压/温度/DC bias，钽电容最怕过压与浪涌

- **判据**：常见工程起点：MLCC 直流工作电压 ≤ 额定 50–80%（高可靠/高湿环境更严，并计入 DC bias 导致的容值下降）；铝电解工作电压 ≤ 额定 80%、纹波电流 ≤ 额定 80% 且按温度/寿命公式修正；钽电容工作电压 ≤ 额定 50%（常见做法），禁止反接、禁止低阻充放电浪涌，必要时降额到 1/3 或串联电阻。
- **为什么**：MLCC 的 II 类介质（X5R/X7R）容值随电压/温度显著下降，只看“额定电压够”会低估实际容值；钽电容过压/浪涌会直接短路起火，是可靠性重灾区。
- **怎么做**：按实际直流偏压下的有效容值（厂商曲线/仿真）校核去耦；钽电容优先换聚合物/陶瓷或加限流；电解电容按纹波电流与温度选型。
- **怎么查**：工作电压 vs 额定；DC bias 后的有效容值；钽电容是否有反接/浪涌路径；纹波电流实测。
- **依据**：器件 datasheet 的电压/温度/偏压曲线与纹波电流额定为 A 级依据；IPC-9592B §4.4 要求电容按其类型降额（**限值需按正本复核**）。

### KP-PCB-174 电感/磁珠降额：饱和电流、温升电流、DCR 三项都要看

- **判据**：常见工程起点：峰值电流 ≤ 饱和电流（Isat）的 70–80%（Isat 按感值下降 10–30% 的定义，不同厂商定义不同，必须看 datasheet 注释）；有效值电流 ≤ 温升电流（Irms/Idc）的 80%；DCR 压降/损耗计入效率与温升；磁珠还需校核额定电流与直流偏置下的阻抗下降。
- **为什么**：超过 Isat 后感值骤降、纹波暴涨、环路失稳；超过 Irms 会持续发热；DCR 压降在低压大电流轨道上直接影响负载调整率。
- **怎么做**：按峰值电流选 Isat、按有效值选 Irms；开开关电源时用电流探头实测峰值；磁珠用于电源滤波时确认偏置电流下的阻抗。
- **怎么查**：峰值/有效值电流实测或仿真；datasheet 的 Isat/Irms 定义；DCR 压降；磁珠偏置曲线。
- **依据**：厂商 datasheet 为 A 级依据；Isat 定义差异必须逐条核对，不能用不同厂商的 Isat 直接横比。

### KP-PCB-175 二极管/MOSFET 降额：电压、电流之外必须看结温与 SOA/雪崩

- **判据**：常见工程起点：二极管反向电压 ≤ 额定 70–80%；正向电流按结温降额；MOSFET VDS ≤ 额定 80%、ID ≤ 额定 70–80%、结温 ≤ Tjmax 减 20–40 °C（按产品等级）；开关/浪涌/短路工况必须落在 SOA 与雪崩能量（EAS）额定内。
- **为什么**：MOSFET 失效多由过压/过流/过热/米勒导通引起；只看平均电流会漏掉开关尖峰与雪崩；结温是最终判据，壳温合格不代表结温合格。
- **怎么做**：用示波器测 VDS/ID 尖峰与开关损耗，按热阻链算结温（见 05 篇 KP-PCB-083）；加 RC 吸收/钳位；感性负载校核雪崩能量；保留 ≥20% 电压裕量应对振铃。
- **怎么查**：VDS/ID 波形与额定对比；结温计算/热像；SOA/雪崩曲线；驱动电阻与米勒平台。
- **依据**：器件 datasheet 的绝对最大额定、SOA、EAS 为 A 级依据；降额比例按企业规范，**不可用“经验 80%”替代 datasheet 的脉冲/雪崩曲线**。

### KP-PCB-176 IC/连接器/继电器降额：输出电流、触点电流与温升是主应力

- **判据**：IC 按 datasheet 的 θJA/θJC 与实际功耗算结温，结温留 20–40 °C 裕量；LDO/DC-DC 按最大输出电流的 70–80% 使用并校核热；连接器每触点电流 ≤ 额定 50–70%、总温升 ≤ 30 °C（经验）；继电器触点电压/电流 ≤ 额定 50–75%，感性负载加续流。
- **为什么**：连接器与继电器是整机失效高发件，触点氧化/微动/电弧会随电流与插拔次数累积；IC 长期高温会加速电迁移与封装老化。
- **怎么做**：按“每触点电流 × 同时载流触点数”校核连接器；大电流用多针并联并降额更多；继电器按负载类型（阻性/感性/灯负载）选型；IC 热焊盘按 datasheet 打孔。
- **怎么查**：连接器温升实测；触点电流分配；继电器负载类型与寿命曲线；IC 结温估算。
- **依据**：器件 datasheet 的电流/温升/寿命曲线为 A 级依据；连接器降额比例需按厂商规范与安规温升要求（见 11 篇）复核。

### KP-PCB-177 PCB 本体降额：走线/过孔/焊盘按温升与电流密度设计

- **判据**：走线按 IPC-2152 载流方法计算，常用设计目标为 10 °C 温升（高可靠可更严）；过孔载流按孔径/镀铜厚度/数量分摊，单孔电流留 ≥50% 裕量；大电流焊盘/开窗加锡；铜厚、层数、环境温度修正必须计入。
- **为什么**：PCB 是“隐性”发热与失效点：走线温升过高会加速板材老化、导致阻焊变色；过孔镀层薄会在热循环+大电流下开裂；压降还会影响负载端电压。
- **怎么做**：按峰值电流算线宽/过孔数；大电流路径用铜皮/多层并联；过孔阵列均匀分布；做温升实测（热电偶/热像）；与 [`06-dfm-manufacturing.md`](./06-dfm-manufacturing.md) 的铜厚/工艺能力对齐。
- **怎么查**：载流计算书；过孔数量/孔径；满载温升；压降实测；与现有规则 `PCB-RULE-CURRENT-001` 的一致性。
- **依据**：IPC-2152 载流方法（`PCB-RULE-CURRENT-001` 已引用）；IPC-9592B §4.6 Voltage Spacing 与 §7 制造一致性测试提供板级校核框架（**具体判据按正本**）。

### KP-PCB-178 降额门禁：BOM 自动算应力比，超限清单必须签核

- **判据**：投板前必须输出“降额检查表”：覆盖所有功率/高压/大电流/热敏器件，列出额定值、工作值、应力比、限值、结论；超限项必须有“更换器件/改设计/书面让步”三种处理之一并签核；该门禁不通过不得投板。
- **为什么**：人工抽查只能覆盖少数器件；降额不足往往在量产高温/满载时集中暴露，返工成本远高于设计阶段换料。
- **怎么做**：从 EDA/BOM 导出工作点，用脚本批量计算；把限值做成可配置表（按产品等级）；超限项进评审会；变更后重跑。
- **怎么查**：降额表覆盖率（关键器件 100%）；超限项闭环率；与 BOM 版本一致性；抽查复算 5 项。
- **依据**：IPC-9592B §4.4.1 明确要求降额成文并保留记录；门禁阈值由企业规范定义，**本文给出的百分比只是起点**。

## 3. 寿命与失效机理：算“能用多久”，而不是“现在能用”

### KP-PCB-179 Arrhenius 温度加速：AF = exp[Ea/k·(1/T_use − 1/T_test)]，Ea 必须来自数据

- **判据**：温度加速试验的加速因子必须用 Arrhenius 模型计算：`AF = exp[(Ea/k)(1/T_use − 1/T_test)]`，其中 k=8.617×10⁻⁵ eV/K，温度用开尔文；Ea（激活能）必须来自器件/工艺的试验数据或厂商报告，不能随手取 0.7 eV 当普适值。
- **为什么**：加速因子直接决定“试验 1000 h 等于现场多少年”；Ea 取错会让寿命外推差数倍。不同失效机理（电迁移、腐蚀、介质击穿）Ea 不同，混用会得出错误结论。
- **怎么做**：按失效机理分别取 Ea；用至少两个温度点的试验数据拟合 Ea；记录试验温度/时长/样本量；外推时给出置信区间。
- **怎么查**：AF 计算书；Ea 来源；温度是否用 K；试验温度是否超过材料/器件允许上限（超限会引入新机理）。
- **依据**：Arrhenius 模型为可靠性物理通用方法；JESD47/JESD22 系列与 IPC-9592B §5.2 的加速试验均要求声明加速模型与条件（**具体试验温度/时长按标准与器件规范**）。

**算例**：Ea=0.7 eV，现场 55 °C（328 K），试验 125 °C（398 K）：
`AF = exp[0.7/8.617e-5 × (1/328 − 1/398)] = exp(4.356) ≈ 78`。
即试验 1000 h ≈ 现场 78,000 h（约 8.9 年）——**该算例只用于演示公式，Ea/温度必须按实际数据替换**。

### KP-PCB-180 “10 °C 法则”只是粗略经验，不能替代 Ea 计算与厂商公式

- **判据**：可以用“温度每降 10 °C 寿命约翻倍”做快速估算，但正式寿命结论必须用厂商公式/加速模型；对电解电容用厂商寿命公式（含纹波电流修正），对焊点用 Coffin-Manson，对半导体用 Arrhenius/失效机理模型。
- **为什么**：10 °C 法则隐含 Ea≈0.7 eV 的固定假设，只对部分失效机理近似成立；对电解电容还受纹波自发热影响，对焊点则主要看 ΔT 而非平均温度。
- **怎么做**：快速估算只用于方案对比；正式报告写明模型、参数来源与适用范围；不同机理分开算再取短板。
- **怎么查**：报告是否只有“降 10 °C 翻倍”一句话；是否区分机理；参数来源是否可追溯。
- **依据**：Arrhenius 模型与厂商寿命公式为 A/B 级依据；10 °C 法则属 D 级经验，**不得作为验收判据**。

### KP-PCB-181 焊点热疲劳用 Coffin-Manson：寿命随 ΔT 的 n 次方下降

- **判据**：焊点热循环寿命按 `N2/N1 = (ΔT1/ΔT2)^n` 估算，SAC 无铅焊点 n 常取 1.9–2.0（经验值，按合金/焊点形状/IPC-9701 方法修正）；ΔT 与循环次数来自任务剖面；必须同时校核热循环（慢）与热冲击（快）两种工况。
- **为什么**：焊点失效是 CTE 不匹配导致的塑性应变累积，ΔT 是最敏感变量；ΔT 从 60 °C 增到 80 °C，按 n=2 寿命只剩约 56%。
- **怎么做**：按最恶劣 ΔT 与循环数算寿命；BGA/QFN/大铜面/连接器焊点重点评估；用 IPC-9701 做热循环试验验证；布局上避免大热质量器件与低 CTE 约束叠加。
- **怎么查**：ΔT/循环数来源；Coffin-Manson 参数与合金；热循环试验（IPC-9701）结果；失效分析（裂纹位置）。
- **依据**：IPC-9701 提供表面贴装焊点热循环性能试验方法；Coffin-Manson 为通用经验模型，**n 值与寿命常数需按合金/试验数据标定**。

### KP-PCB-182 电解电容寿命：厂商公式 + 纹波自发热，不能只看环境温度

- **判据**：电解电容寿命按厂商公式估算，典型形式为 `L = L0 × 2^((T0−Ta)/10) × K_ripple`（L0/T0 为额定寿命/额定温度，Ta 为实际环境温度，K_ripple 为纹波电流修正系数）；纹波电流不得超过额定，核心温度需计入自发热；寿命结论必须给出“最短寿命件”。
- **为什么**：电解电容是电源板最常见的寿命短板；纹波自发热会让核心温度高于环境温度，忽略它会把寿命高估数倍。
- **怎么做**：按实际纹波/频率查厂商修正系数；高温位置选长寿命/低 ESR 系列；必要时用固态/陶瓷替代；把电容寿命列进整机寿命预算。
- **怎么查**：厂商寿命公式与参数；纹波电流实测；核心温度估算；最短寿命件识别。
- **依据**：厂商 datasheet 的寿命公式与纹波系数为 A 级依据；**不同厂商公式形式不同，必须用对应 datasheet，不能套用本文示例**。

### KP-PCB-183 浴盆曲线与早期失效：筛选只能压早期，不能改固有寿命

- **判据**：可靠性曲线按三阶段管理：早期失效（β<1，用老化/筛选剔除）、随机失效（β≈1，用降额/冗余降低）、耗损失效（β>1，用寿命预算/更换周期管理）；筛选（burn-in/HASS）不得替代设计降额与鉴定试验。
- **为什么**：早期失效多由工艺缺陷/污染/虚焊引起，筛选能剔除；但筛选也会消耗寿命、增加成本，且对固有设计缺陷无效。
- **怎么做**：按产品等级定义筛选条件（温度/时长/循环）；HASS 限值由 HALT 确定且不得超出设计极限；记录筛选失效并做失效分析。
- **怎么查**：筛选规范与 HALT 结果的一致性；筛选失效分析；是否把“老化通过”当作可靠性证明。
- **依据**：IPC-9592B §7.3.2 Stress Tests (Short Term Reliability Tests – BI/HASS)、§7.3.3 ORT 将筛选与持续可靠性测试分开；**具体筛选条件按产品规范**。

### KP-PCB-184 失效机理清单：先列机理，再选试验，不要“一套试验打天下”

- **判据**：至少评估以下机理并对应试验：电迁移/介质击穿（HTOL/高温偏压）、腐蚀/电化学迁移（THB/HAST/SIR）、CAF（CAF 测试）、焊点疲劳（热循环/热冲击）、机械疲劳（振动/冲击/跌落）、湿气（MSL/THB）、触点氧化（混合气体/插拔寿命）、锡须（无铅镀层）。
- **为什么**：不同机理对应不同加速应力；用错试验会“通过但没测到风险”，例如用高温存储代替湿热偏压无法暴露电化学迁移。
- **怎么做**：建“机理-应力-试验-判据”矩阵；按任务剖面筛选必做项；新产品/新工艺补充对应机理；失效分析反推机理。
- **怎么查**：矩阵完整性；试验项与机理对应关系；失效分析报告是否落回机理。
- **依据**：JESD22-A101（THB）、A110（HAST）、A104（温度循环）、A108（HTOL）等方法对应特定机理；IPC-9592B §5.2.4/5.2.5/5.2.6 分别给出 THB、HTOB、温度循环条款（**试验条件按正本**）。

### KP-PCB-185 寿命预算：整机寿命由最短寿命件决定，必须做“短板分析”

- **判据**：整机/板级寿命预算必须列出所有寿命相关件（电解电容、风扇、继电器、连接器、电池、焊点、光耦），分别给出寿命估算与依据，取最小值作为短板；短板寿命不足目标时必须更换/降额/加维护策略。
- **为什么**：平均寿命没有意义，客户感知的是“第一个坏的点”；短板件往往不是最贵的器件，容易被忽略。
- **怎么做**：建寿命预算表（器件/机理/模型/参数/寿命/来源）；对短板件做敏感性分析（温度/负载）；必要时设计可更换件。
- **怎么查**：预算表是否覆盖机械/电气/电化学件；短板识别；与保修期/客户要求对比。
- **依据**：IPC-9592B §4.1 Reliability Prediction 与 §2.4 Terms 对可靠性预测口径有要求；具体模型按企业规范（**需按正本复核**）。

### KP-PCB-186 可靠性与成本：降额和选型是“用 BOM 成本换保修成本”

- **判据**：可靠性投入必须做成本对比：降额/换高等级器件/加保护/加筛选带来的 BOM 与制造成本 vs 预期现场失效率 × 保修成本 × 品牌损失；关键单点失效优先加保护/冗余，非关键件按失效率可接受原则选型。
- **为什么**：无限加严会把产品做贵、做重；可靠性工程的本质是风险定价，而不是“全部按最高等级”。
- **怎么做**：按 FMEA 的严重度/发生率排序投入；对高严重度单点做冗余/保护；对低风险件用降额+筛选控制；用现场数据校准成本模型。
- **怎么查**：可靠性投入清单与成本；FMEA 排序是否驱动选型；现场失效率与预算偏差。
- **依据**：IPC-9592B 产品分类（Class I/II）体现“按用途分级要求”的成本-可靠性平衡思路；**具体等级划分按标准正本与客户要求**。

## 4. 环境试验与鉴定：用标准试验证明“扛得住”

### KP-PCB-187 环境试验矩阵按任务剖面裁剪：温度、湿热、振动、冲击、腐蚀

- **判据**：环境试验至少覆盖：低温工作/存储（IEC 60068-2-1）、高温工作/存储（-2-2）、温度变化（-2-14）、稳态/交变湿热（-2-78/-2-30）、正弦/随机振动（-2-6/-2-64）、机械冲击（-2-27）、跌落/包装（按产品）、盐雾/混合气体（按使用环境）。每项写严酷等级、持续时间、循环数、通电/监测状态、失效判据。
- **为什么**：环境试验是“把现场应力搬进实验室”；不按剖面裁剪会做多（浪费）或做少（漏风险）；通电监测能抓到“试验后能开机但试验中已失效”的间歇故障。
- **怎么做**：从任务剖面生成试验矩阵；明确“试验中监测”与“试验后功能/参数”双判据；记录试验前后数据；异常做失效分析。
- **怎么查**：矩阵与剖面的一致性；严酷等级来源；试验中监测记录；失效判据是否可判定。
- **依据**：IEC 60068-2-x 系列为环境试验基础方法；IPC-9592B §5.2 Environmental Stress Testing (EST) 给出温度循环、THB、HTOB、振动、冲击、跌落、腐蚀等条款结构（**具体等级/时长按标准与产品规范**）。

### KP-PCB-188 温度循环/热冲击：温变速率、驻留时间与循环数决定暴露的机理

- **判据**：温度循环要写清：高/低温极限、温变速率（°C/min）、驻留时间（保证整板均温）、循环数、通电/监测；热冲击（液体/两箱）与温度循环（单箱）暴露的机理不同，不能互相替代；焊点/大质量器件/通孔件是重点。
- **为什么**：温变速率影响 CTE 失配产生的应力；驻留不足会导致“只有表面到温”，漏检；循环数决定累积损伤。
- **怎么做**：按 IPC-9701/产品规范选条件；大热质量区域加测温点确认均温；失效判据含参数漂移与外观/切片；记录每次循环的监测数据。
- **怎么查**：温度曲线（板面实测）；驻留时间；循环数；失效分析与机理对应。
- **依据**：IEC 60068-2-14（温度变化）与 IPC-9701（焊点热循环）为方法依据；IPC-9592B §5.2.6 Temperature Cycling Test、§5.2.7 Power and Temperature Cycling (PTC) 为电源类产品条款（**参数按正本**）。

### KP-PCB-189 湿热与偏压：THB/HAST 针对电化学迁移，条件必须含偏压与监测

- **判据**：湿热试验必须区分“存储湿热”和“偏压湿热”：THB（如 85 °C/85%RH + 偏压）或 HAST（高温高湿+偏压，加速更快）用于评估电化学迁移/腐蚀/绝缘劣化；必须写明偏压值、加电方式、监测间隔、失效判据（漏电/绝缘电阻/功能）。
- **为什么**：没有偏压的湿热试验测不到电化学迁移；没有监测会漏掉间歇漏电；不同板材/助焊剂/清洗工艺对湿热敏感度差异很大。
- **怎么做**：按产品环境选 THB 或 HAST；试验前确认清洗/涂覆状态；加偏压并周期监测漏电；失效做离子污染/切片分析。
- **怎么查**：偏压与监测记录；温湿度曲线；绝缘电阻/漏电数据；失效分析。
- **依据**：JESD22-A101（THB）、JESD22-A110（HAST）为方法依据；IPC-9592B §5.2.4 THB 条款可用于电源类产品（**条件按正本**）。

### KP-PCB-190 机械试验：振动、冲击、跌落按“使用+运输”两套条件

- **判据**：机械试验分使用环境（振动/冲击）与运输环境（跌落/包装振动）；写明频率范围/加速度/持续时间/轴向/次数、固定方式、通电监测；连接器、大质量器件、BGA、焊点、安装孔为检查重点。
- **为什么**：机械失效多为累积疲劳或瞬时过应力；固定方式不同结果差异极大；运输跌落是最常见的现场损坏来源之一。
- **怎么做**：按 IEC 60068-2-6/-2-27/-2-64 与包装标准做；夹具模拟实际安装；试验后做功能/外观/X-ray/切片检查。
- **怎么查**：试验条件与标准对应；夹具/固定方式；试验后检查记录；失效位置。
- **依据**：IEC 60068-2-6（正弦振动）、-2-27（冲击）、-2-64（随机振动）为方法依据；IPC-9592B §5.2.8–5.2.13 覆盖冲击、振动、自由跌落、跌落测试（**条件按正本**）。

### KP-PCB-191 腐蚀与表面处理：盐雾/混合气体/硫化按环境选，镀层与三防要匹配

- **判据**：按使用环境选择腐蚀试验：盐雾（IEC 60068-2-11）、流动混合气体（-2-60）、硫化物（含硫环境）；PCB 表面处理（ENIG/OSP/沉锡/沉银）与三防漆必须与腐蚀环境匹配；高湿/含硫环境避免裸铜与薄金层。
- **为什么**：腐蚀会改变接触电阻/导致开路，且是渐进失效；不同表面处理的耐蚀性差异大，ENIG 黑盘、锡须、银迁移都是常见问题。
- **怎么做**：按环境选表面处理；连接器镀层按插拔/腐蚀要求；必要时三防涂覆并验证；来料/成品做腐蚀抽测。
- **怎么查**：表面处理与环境的匹配说明；腐蚀试验报告；三防涂覆记录；连接器镀层规格。
- **依据**：IEC 60068-2-11/-2-60 为方法依据（**编号/条件按标准正本**）；IPC-9592B §5.2.14.1 Corrosion Resistance 与 §4.3 Metal Corrosion 提供电源类产品条款结构。

### KP-PCB-192 环境试验的样本量与判据：没有样本量就没有统计结论

- **判据**：每项试验必须写样本量（n）、抽样方式、失效判据（功能/参数/外观）、允许失效数（通常 0 失效）、试验前后数据；声称“通过”必须能回答“n 是多少、判据是什么、失效怎么算”。
- **为什么**：n=1 的“通过”没有统计意义；判据模糊会导致“试验后还能开机就算过”，漏掉参数退化。
- **怎么做**：按产品等级/客户要求定样本量；关键项加监测；失效做失效分析并判定是否批次问题；报告含原始数据。
- **怎么查**：报告中的 n/判据/失效数；原始数据；失效分析；与抽样标准的一致性。
- **依据**：IPC-9592B §5.1.2/§5.2 各试验条款均包含 Sample Size 与 Pass Criteria 要求，可作为模板；**具体样本量按标准/客户规范**。

### KP-PCB-193 加速试验外推：先验证失效机理一致，再谈加速因子

- **判据**：用加速试验外推现场寿命前必须确认：加速应力下的失效机理与现场一致（失效分析/形貌/位置相同）、加速模型适用、未超过材料/器件极限；不满足时只能作为“筛选/对比”，不能外推寿命。
- **为什么**：应力过高会引入新机理（如超过 Tg、超过焊料固相线），外推结果完全失真；机理不一致时加速因子无意义。
- **怎么做**：至少两个应力水平验证机理一致；用失效分析确认；外推给置信区间；记录模型假设。
- **怎么查**：失效分析对比；应力水平是否超限；模型假设；外推报告。
- **依据**：加速试验通用原则（JESD47/JESD22、IPC-9592B §5.2）；**具体判定按标准与失效分析结论**。

## 5. 鉴定、FMEA、HALT 与 MTBF：把证据变成决策

### KP-PCB-194 器件鉴定看 JESD47/JESD22，板级鉴定看 IPC-9592B/IPC-9701，两者不能互相替代

- **判据**：IC/器件级鉴定按 JESD47（应力驱动鉴定）与 JESD22 方法；板级/电源类产品按 IPC-9592B（DVT+EST）与 IPC-9701（焊点热循环）；板级鉴定必须使用实际 PCB 工艺/焊料/清洗/涂覆，不能只用器件原厂数据。
- **为什么**：器件原厂鉴定假设“标准装配”，实际板级的焊点、热路径、清洗残留、机械约束都不同；板级失效常发生在焊点/工艺，而不是芯片本体。
- **怎么做**：器件级引用原厂报告并核对条件；板级做 DVT/EST；新工艺/新板厂重新鉴定；记录鉴定矩阵。
- **怎么查**：器件报告条件 vs 实际使用；板级试验是否覆盖焊点/工艺；鉴定矩阵完整性。
- **依据**：JESD47/JESD22 系列与 IPC-9592B §5、IPC-9701 为方法依据（**版本以 JEDEC/IPC 官网为准**）。

### KP-PCB-195 车规/高可靠场景：AEC-Q100/Q200 等级与温度等级必须匹配任务剖面

- **判据**：车规器件按 AEC-Q100（IC，Grade 0–4 对应不同环境温度范围）、AEC-Q200（无源件）、AEC-Q101（分立器件）选型；器件等级必须覆盖任务剖面的最高/最低环境温度，且需确认板级热设计让结温留有余量；不能用“消费级 + 降额”替代车规鉴定。
- **为什么**：AEC-Q 鉴定包含温度循环、HAST、HTOL、EMC 等一整套应力，消费级器件未做这些试验；温度等级不匹配会在极端工况失效。
- **怎么做**：按任务剖面选 Grade；核对器件鉴定报告与批次；板级做热循环/振动补充验证；供应链确认车规料号与 PPAP 要求。
- **怎么查**：器件 AEC-Q 报告；Grade 与温度范围；板级补充试验；料号与 BOM 一致性。
- **依据**：AEC-Q100/Q200/Q101 为车规鉴定规范（**版本以 AEC 官网为准**）；Grade 温度范围需按规范原文核对。

### KP-PCB-196 HALT/HASS：HALT 找极限、HASS 筛缺陷，都不等于“鉴定通过”

- **判据**：HALT（高加速寿命试验）用于快速暴露设计薄弱点（温度步进、振动步进、综合应力），输出工作极限/破坏极限与改进项；HASS（高加速应力筛选）用低于破坏极限的应力筛量产缺陷；两者都不能替代 DVT/鉴定试验，也不能用 HALT 通过证明现场寿命。
- **为什么**：HALT 是“找问题”的工具，样本少、应力高、失效机理可能与现场不同；HASS 过度会损伤良品、不足会漏缺陷，必须由 HALT 定限。
- **怎么做**：新产品做 HALT 并闭环改进；量产 HASS 限值由 HALT 与剖面确定；监控 HASS 失效并做分析；记录极限值。
- **怎么查**：HALT 报告与改进项；HASS 限值与 HALT 的关系；筛选失效分析；是否被误用为鉴定。
- **依据**：IPC-9592B §5.2.3 Highly Accelerated Life Test (HALT) 与 §7.3.2 BI/HASS 条款明确区分两者用途（**具体方法按正本**）。

### KP-PCB-197 FMEA/DFMEA：用严重度×发生度×探测度排序，措施要落到设计/测试

- **判据**：DFMEA 必须覆盖：功能/失效模式/失效后果（严重度 S）/原因（发生度 O）/现行探测（探测度 D）/风险排序（RPN 或 AIAG-VDA 的 AP）/措施/责任人/验证证据；高风险项必须有设计变更或增加测试，不能只写“注意”。
- **为什么**：FMEA 的价值在“把失效模式变成可执行措施”；只打分不闭环等于没做；RPN 阈值一刀切会漏掉高严重度低概率项。
- **怎么做**：按板级功能块分解；跨职能评审；高严重度项优先；措施完成后更新 S/O/D 并保留证据；与降额表、试验矩阵互相引用。
- **怎么查**：FMEA 覆盖率（关键功能块）；高风险项闭环；措施证据；S/O/D 评分依据。
- **依据**：IEC 60812（FMEA/FMECA 方法）与 AIAG-VDA FMEA 手册（2019，AP 替代 RPN 的行业方法）；IPC-9592B §4.5 Design FMEA 为电源类产品条款（**评分准则按企业规范**）。

### KP-PCB-198 MTBF 口径：Telcordia/MIL-HDBK-217/IEC 61709 各有假设，不能横比

- **判据**：MTBF 报告必须写明：使用标准与版本（Telcordia SR-332、MIL-HDBK-217F Notice 2、IEC 61709、SN 29500 等）、环境/温度/负载假设、是否含非电子件、是否含早期失效、置信度；不同标准/假设算出的 MTBF 不可直接比较；MTBF 是失效率倒数（指数假设），不等于寿命。
- **为什么**：MIL-HDBK-217 已停止维护、偏保守；Telcordia 偏通信场景；IEC 61709 给参考条件。混用会得出误导性数字，甚至被客户/投标质疑。
- **怎么做**：固定一个标准+版本用于项目内比较；报告写清假设；用现场数据校准；对长寿命产品用 B10/寿命预算补充 MTBF。
- **怎么查**：报告标准/版本/假设；是否可比；现场数据校准；是否被当作“寿命”宣传。
- **依据**：Telcordia SR-332、MIL-HDBK-217F Notice 2、IEC 61709、SN 29500 为常用方法；IPC-9592B §4.1 采用 FIT 口径（**具体模型版本按标准正本**）。

### KP-PCB-199 关键单点失效与 FTA：一个器件坏就整机失效的点必须单独管

- **判据**：识别所有“单点失效导致安全/功能丧失”的器件/连接（如唯一的保护器件、唯一的地连接、唯一晶振、电池保护 IC），对这些点做：降额加严、冗余/保护、FMEA 高严重度标记、试验重点覆盖；安全相关单点必须满足安规要求（见 11 篇）。
- **为什么**：平均失效率再低，单点失效也会造成批量事故；FTA 能把“整机失效”分解到具体器件与保护措施。
- **怎么做**：用 FTA（IEC 61025）建故障树；识别最小割集；对单点加冗余/监测；把结果写进 FMEA 与测试计划。
- **怎么查**：单点清单；FTA 最小割集；保护/冗余措施；试验是否覆盖单点。
- **依据**：IEC 61025（故障树分析）为方法依据；安全相关单点按 IEC 62368-1 等安规标准处理（见 11 篇，**条款按正本**）。

### KP-PCB-200 现场数据闭环：FRACAS/ORT 把失效变成规则与选型变更

- **判据**：量产后必须建立失效率/返修率/客诉的数据闭环：失效分类→根因→纠正措施→规则/选型/BOM/工艺变更→效果验证；关键指标为现场 DPPM/年化失效率与 ORT（持续可靠性测试）结果；没有闭环的“可靠性报告”视为静态文档。
- **为什么**：实验室试验无法覆盖所有现场应力；现场数据是最终裁判；不闭环会重复踩坑，也无法校准 MTBF/寿命模型。
- **怎么做**：建失效台账与 FRACAS 流程；定期做 ORT；把根因回写到本文/降额表/FMEA；变更后验证并更新模型。
- **怎么查**：台账闭环率；ORT 记录；规则/选型变更与失效的对应；MTBF 模型是否用现场数据校准。
- **依据**：IPC-9592B §7.3.3 Ongoing Reliability Testing (ORT)、§6.5 Qualification of Change、§4.5 DFMEA 构成“制造-变更-可靠性”闭环框架（**具体频次/样本按正本**）。
