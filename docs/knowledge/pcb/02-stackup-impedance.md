# 叠层与阻抗控制（2/4/6 层）

> 适用前提：FR-4（εr ≈ 4.2–4.6 @1 MHz，随频率与树脂含量变化）、1 oz 外层铜、成品板厚 1.6 mm、常规板厂工艺。所有板厂能力相关数值（介质厚度、铜厚公差、阻抗公差、最小线宽）需按厂家当前能力表与叠层计算书复核。
> 定位：本文讲「怎么选叠层、参考平面怎么保证、50 Ω/90 Ω/100 Ω 怎么估、怎么验收」；项目板级规则见 [`03-设计规则B`](../../pcb-layout/03-设计规则B-电气丝印制造装配.md) 的 `DFM-09`、`DFM-11`。
> 编号约定：`KP-PCB-019` 起接续 01 篇，全局连续。

**一句话结论**：叠层先定「信号层紧邻完整参考平面」，再定层数与厚度；阻抗先用公式估线宽、再用板厂计算书和阻抗测试条闭环，任何「只抄一个线宽数字」的阻抗设计都不可信。

## 0. 口径与工具

| 项 | 本文口径 | 说明 |
| --- | --- | --- |
| 介质 | FR-4，εr 按 4.2–4.6 取值 | 实际 εr 由树脂含量/PP 型号决定，需板厂提供 |
| 铜厚 | 外层 1 oz（35 µm），内层 1 oz 或 0.5 oz | 2 oz 会改变阻抗与最小线宽 |
| 板厚 | 1.6 mm ±10% | 薄板/厚板需重算 |
| 计算精度 | 公式估算 ±10%–20% | 最终以板厂阻抗计算书 + 场求解器 + TDR 为准 |
| 标准 | IPC-2141 传输线公式、IPC-2221B 设计原则、IPC-6012 验收 | 本文不引用具体条款号 |

## 1. 叠层选择

### KP-PCB-019 叠层的核心是「信号层必须有紧邻的完整参考平面」

**判据**：每个信号层至少与一个完整平面层相邻，且平面到信号层距离 ≤0.25 mm（常规 0.10–0.20 mm 更利于阻抗控制与回流）；不允许出现「两个信号层相邻且都无平面」的高速层。
**为什么**：参考平面提供返回电流的低阻抗路径，同时决定微带/带状线阻抗；没有参考平面，回流被迫绕远，形成大环路 → 辐射、串扰、阻抗失配。
**怎么做**：先画叠层框图（信号/地/电源），确认每层信号都有参考；电源层被分割时，跨分割的高速信号必须改层或加缝合电容。
**怎么查**：叠层图逐层核对；EDA 里看每层信号网络的参考层；SI 工具检查回流路径连续性。

### KP-PCB-020 两层板只有「外层微带」，参考面天然不完整

**判据**：两层板信号只能走外层；若底层不是完整地铜，则微带参考面不完整，50 Ω 阻抗无法稳定控制；两层板不宜跑 >100 MHz 时钟或 USB 高速。
**为什么**：两层板没有内层平面，地回流只能靠底层铜皮和过孔；一旦底层被走线切开，回流路径断裂。
**怎么做**：两层板底层尽量整片铺地；顶层高速线下方底层不得走线；关键信号两侧包地并每 5–10 mm 打地过孔；USB 等差分尽量短、不跨断地。
**怎么查**：底层地铜连续性检查；高速线下方是否有走线/开槽；用 TDR 或阻抗测试条验证（两层板通常不做严格阻抗控制）。

### KP-PCB-021 四层板推荐 S-G-P-S（外层信号、内层地与电源）

**判据**：四层板首选「L1 信号 / L2 地 / L3 电源 / L4 信号」；L2 地平面完整优先（不分割），L3 电源按域分割；外层信号到 L2/L3 的介质厚度控制在 0.15–0.25 mm 以稳定 50 Ω。
**为什么**：L2 完整地给 L1 提供最好的参考；L4 以 L3 电源为参考，电源平面需低阻抗；四层板成本与 6 层接近但布线自由度低，适合大多数控制板。
**怎么做**：典型叠层（示例，板厂可调）：L1 铜 0.035 / PP 0.20 / L2 铜 0.035 / 芯板 1.065 / L3 铜 0.035 / PP 0.20 / L4 铜 0.035，总厚 ≈1.60 mm；L1/L4 走 50 Ω 微带，L2 整片地，L3 按 3V3/5V 等分域。
**怎么查**：叠层图与板厂标准叠层比对；L2 是否有走线（应无）；L3 分割线是否被高速信号跨越；阻抗计算书。

### KP-PCB-022 四层叠层顺序的取舍：地优先于电源

**判据**：两种常见顺序——`S-G-P-S`（推荐，L2 完整地）与 `S-G-G-S`（双地，电源走铜皮，适合模拟/RF）；不推荐 `S-P-G-S`（外层信号以被分割的电源为参考）。
**为什么**：地平面是所有信号的公共回流面，优先保证完整；电源平面常被分割，作为参考会让跨域信号回流断裂。
**怎么做**：数字为主选 S-G-P-S；模拟/射频为主选 S-G-G-S；若必须 S-P-G-S，电源层必须整片不分割且低噪。
**怎么查**：叠层图评审；电源层分割数；高速信号参考层是否为地。

### KP-PCB-023 六层板两种典型叠层：S-G-S-S-G-S 与 S-G-S-P-G-S

**判据**：六层板优先保证「每个信号层都有相邻平面」；推荐两种：
- **A（对称、EMC 好）**：L1 信号 / L2 地 / L3 信号 / L4 信号 / L5 地 / L6 信号。L1、L3 参考 L2；L4、L6 参考 L5；L3 与 L4 相邻，需 ≥0.40 mm 芯板并正交布线。
- **B（电源完整性好）**：L1 信号 / L2 地 / L3 信号 / L4 电源 / L5 地 / L6 信号。L3 为带状线（参考 L2/L4），L4 电源必须完整低噪。
**为什么**：A 对称、翘曲小、地平面完整；B 多一个完整电源平面，适合多电源域/大电流，但 L4 被分割时 L3 不能跨分割。
**怎么做**：按信号速率与电源域数量选型；A 的 L3/L4 走线尽量正交、避免长距离平行；B 的 L4 分割线避开 L3 高速线投影。
**怎么查**：叠层图 + 跨分割检查；L3/L4 平行走线长度统计；翘曲测试。

### KP-PCB-024 参考平面完整性：跨分割次数必须为 0（高速/时钟/差分）

**判据**：时钟、差分、>50 MHz 单端信号跨越参考平面分割的次数 = 0；确实无法避免时，在跨分割点两侧 3–5 mm 内加缝合电容（0.01–0.1 µF，按最高频率选择），并记录为受控例外。
**为什么**：参考平面被切开后，返回电流被迫绕过缝隙，环路面积骤增，产生共模辐射与串扰；跨分割还会造成阻抗突变，眼图恶化。
**怎么做**：布局阶段就把高速接口与连接器放在同一平面区域内；电源分割线沿低速区走；必要时改层（换到有完整地的参考层）。
**怎么查**：把参考平面层与高速网络叠合，目视/脚本找交叉；SI 工具检查回流路径；`DFM-09` 的「参考面连续、跨分割 0 次」。

### KP-PCB-025 换层必须同时换回流：回流地过孔就近放置

**判据**：信号换层时，回流地过孔距信号过孔 ≤2–3 mm；差分对换层时每对至少 2 个地过孔（对称分布）；换层过孔数量与信号过孔数量匹配。
**为什么**：信号从 L1 换到 L3，回流也要从 L2 换到 L4 对应的平面；没有就近地过孔，回流绕远形成大环路。
**怎么做**：换层处放「信号过孔 + 地过孔」组合；高速连接器每个地针都接到平面；BGA 扇出时地过孔与信号过孔成组。
**怎么查**：换层点逐个检查 3 mm 内是否有地过孔；SI 工具看回流路径；目检过孔阵列。

## 2. 阻抗估算

### KP-PCB-026 50 Ω 单端微带线估算（IPC-2141 近似）

**判据**：适用 `0.1 ≤ w/h ≤ 2`、`1 < εr < 15`、`t/h < 0.1`：

```
Z0 = (87 / √(εr + 1.41)) × ln( 5.98·h / (0.8·w + t) )
```

其中 `h` = 介质厚度（信号层到参考平面），`w` = 线宽，`t` = 铜厚，单位一致（mm）。
**为什么**：微带线是「空气 + 介质」混合传输线，阻抗由线宽、介质厚度、介电常数共同决定；线越宽阻抗越低，介质越厚阻抗越高。
**怎么做**：以四层板 `h = 0.20 mm`、`εr = 4.3`、`t = 0.035 mm` 为例，50 Ω 对应 `w ≈ 0.34 mm`；实际线宽按板厂叠层微调。
**怎么查**：用板厂阻抗计算器/场求解器复算；做阻抗测试条 TDR 实测；批量抽测记录。

### KP-PCB-027 50 Ω 单端带状线估算（上下都有参考平面）

**判据**：对称带状线、两参考平面间距 `B`（含铜厚）：

```
Z0 = (60 / √εr) × ln( 1.9·B / (0.8·w + t) )
```

**为什么**：带状线两侧都有平面，电场完全在介质中，阻抗比同尺寸微带低、辐射小，适合内层高速线。
**怎么做**：以六层板 `B = 0.30 mm`、`εr = 4.3`、`t = 0.035 mm` 为例，50 Ω 对应 `w ≈ 0.08–0.09 mm`（不同公式变体差 5%–10%，以板厂计算书为准）。
**怎么查**：确认 `B` 取的是两平面间总介质厚（不是单侧）；用场求解器复算；测试条实测。

### KP-PCB-028 90 Ω / 100 Ω 差分阻抗估算

**判据**：先按单端公式算 `Z0`，再用耦合修正：

```
微带差分：Zdiff ≈ 2·Z0·(1 − 0.48·e^(−0.96·s/h))
带状线差分：Zdiff ≈ 2·Z0·(1 − 0.37·e^(−2.9·s/B))
```

其中 `s` = 差分对间距，`h`/`B` 同上；适用 `0.2 ≤ s/h ≤ 2`、`0.1 ≤ w/h ≤ 1`，误差 ±10%–20%。
**为什么**：两根线靠近时电场互相耦合，等效电容增大，差分阻抗低于 `2×Z0`；间距越大越接近 `2×Z0`。
**怎么做**：四层板 `h = 0.20 mm`、`εr = 4.3` 示例：90 Ω 取 `w ≈ 0.25 mm / s ≈ 0.15 mm`；100 Ω 取 `w ≈ 0.23 mm / s ≈ 0.20 mm`。六层带状线 `B = 0.30 mm` 示例：90 Ω 约 `w 0.09 / s 0.15 mm`，100 Ω 约 `w 0.07 / s 0.15 mm`。
**怎么查**：板厂差分阻抗计算书；差分测试条 TDR；批量抽测；注意阻焊、铜厚、蚀刻会使实测偏离计算值。

### KP-PCB-029 阻抗设计六步法（从目标到验收）

**判据**：完整流程 = ①定目标阻抗与公差 → ②选叠层/参考平面 → ③取 εr、h、t → ④公式初算 w/s → ⑤板厂计算书/场求解器复核 → ⑥加测试条并 TDR 验收；缺任一步都不算「阻抗受控」。
**为什么**：公式只是起点，板厂实际 PP 厚度、铜厚、蚀刻补偿、阻焊厚度都会改变结果；只有计算书 + 实测闭环才可信。
**怎么做**：把目标写进工艺说明（如「USB2.0 差分 90 Ω ±10%，L1，参考 L2」）；要求板厂回复叠层与线宽；测试条与产品同叠层同工艺。
**怎么查**：GATE-03 板厂 DFM 门禁；TDR 报告；首件阻抗数据归档。

### KP-PCB-030 阻焊、铜厚、蚀刻对阻抗的影响不可忽略

**判据**：阻焊层会使微带阻抗下降约 2%–5%；线宽每偏差 0.02 mm，50 Ω 微带约变化 1.5–2.5 Ω（`h = 0.2 mm` 量级）；1 oz 改 2 oz 会使细线阻抗下降数欧姆。以上为量级估计，需按实际叠层复算。
**为什么**：阻焊的 εr≈3.5–4.5，等于在铜线上加了一层介质；蚀刻侧蚀让实际线宽比设计值窄；铜厚增加使有效导体变厚、阻抗下降。
**怎么做**：阻抗计算时把阻焊厚度（常规 20–30 µm）纳入；线宽给板厂时说明「成品线宽」还是「CAM 线宽」；不要用 0.10 mm 线做严格阻抗控制。
**怎么查**：板厂计算书是否含阻焊；切片测线宽/铜厚；TDR 对比计算值。

## 3. 叠层工艺与验收

### KP-PCB-031 阻抗测试条（coupon）必须与产品同叠层、同工艺

**判据**：每批/每拼板附阻抗测试条，包含 50 Ω 单端与 90/100 Ω 差分；测试条与产品同叠层、同线宽、同阻焊、同表面处理；TDR 测点长度足够（一般 ≥50 mm），两端有接地测试点。
**为什么**：测试条是唯一能证明「板厂实际做出来的阻抗」的实物证据；测试条与产品工艺不一致时数据无效。
**怎么做**：测试条放工艺边或拼板边缘，标注网络名/目标阻抗；要求板厂出 TDR 报告；超差时整批隔离。
**怎么查**：TDR 报告与计算书比对；测试条位置在 Gerber 中可查；首件 FAI 含阻抗项。

### KP-PCB-032 叠层对称与翘曲控制

**判据**：叠层以板厚中心对称（铜厚、介质厚度、PP 类型对称）；不对称叠层翘曲风险高；回流后翘曲 ≤0.75%（对角长百分比，项目 `MECH-03`/`DFM-12` 口径）；大铜面区域尽量对称分布。
**为什么**：层压时不同材料的热膨胀系数与树脂收缩不同，不对称叠层冷却后产生内应力，表现为弓曲/扭曲；铜分布不均会加剧。
**怎么做**：优先用板厂标准对称叠层；必须不对称时把厚铜/大铜面放在中心附近；拼板与铜平衡配合（见 KP-PCB-017）。
**怎么查**：叠层图对称性检查；回流后平台+塞尺测翘曲；首件记录。

### KP-PCB-033 介质材料与 PP/芯板：厚度与 εr 由板厂标准组合决定

**判据**：叠层厚度不是任意值，而是由芯板（core）+ 半固化片（PP）的标准组合叠加；常用 PP 1080/2116/7628 的单张厚度与树脂含量不同，εr 也不同；设计时写「目标厚度 + 允许组合」，不要写死非标厚度。
**为什么**：板厂只能按库存 PP/芯板组合压合；写死非标厚度会导致加价、交期延长或板厂私自改叠层（阻抗随之漂移）。
**怎么做**：先问板厂标准叠层库；在标准组合里选最接近目标；阻抗线宽按最终叠层复算。
**怎么查**：板厂叠层确认单；PP 型号/张数；介电常数测试报告（如有）。

### KP-PCB-034 铜厚选择：1 oz 常规、2 oz 大电流、0.5 oz 内层细线

**判据**：常规外层 1 oz；≥5 A 或散热需求可用 2 oz（最小线宽/线距会变差，需重新确认工艺档）；内层可用 0.5 oz 以做细线，但载流能力下降。
**为什么**：铜越厚，载流与散热越好，但蚀刻侧蚀越严重、最小线宽越大、阻抗越难控制、成本越高。
**怎么做**：电源层/大电流层用 1–2 oz；信号层保持 1 oz；2 oz 时线宽/线距按厂家 2 oz 能力表重新取（通常比 1 oz 放大 0.05–0.10 mm）。
**怎么查**：叠层表铜厚；板厂 2 oz 工艺能力；载流复算；阻抗复算。

### KP-PCB-035 高速过孔的 stub 与背钻

**判据**：>5 Gbps 或射频信号过孔需评估 stub；stub 长度建议 ≤0.25 mm（约 10 mil）量级，具体按速率与眼图预算由 SI 仿真确定；更长 stub 用背钻（back drill）或盲埋孔。
**为什么**：过孔在未使用的铜筒部分形成开路线（stub），在高速下产生谐振与反射，眼图闭合。
**怎么做**：高速连接器/芯片扇出用盲孔或背钻；普通 2.4 GHz 以下控制板一般不需要；背钻需在制造说明中标注「背钻深度/剩余 stub」。
**怎么查**：叠层与钻孔表；SI 仿真；TDR 看过孔阻抗突变。

### KP-PCB-036 阻抗验收：±10% 为常规门槛，超差要闭环

**判据**：USB2.0 差分 90 Ω ±10%、以太网/LVDS 100 Ω ±10%、RF 50 Ω ±10%（项目 `DFM-09` 口径）；测试条实测超差时，整批隔离并追溯叠层/线宽/蚀刻。
**为什么**：阻抗偏离直接导致反射、眼图恶化、通信距离缩短；批量超差往往是叠层或蚀刻漂移，不是单板问题。
**怎么做**：把阻抗写进工艺说明与验收标准；每批留 TDR 报告；超差时先查板厂叠层实测厚度与线宽，再决定返工/让步接收。
**怎么查**：TDR 报告逐点核对；切片；与计算书比对；`GATE-05` 首件 FAI。

- 规则「阻抗控制」（rule）：USB 90 Ω、RF 50 Ω、100 Ω 差分 ±10%
- 规则「参考面连续」（rule）：高速/时钟/差分跨分割 = 0
- 规则「叠层对称」（rule）：以板厚中心对称、翘曲 ≤0.75%
- 规则「阻抗测试条」（rule）：同叠层同工艺、TDR 验收
- 失败「阻抗失配眼图闭合」（failure）：线宽/叠层偏差导致反射与误码
- 失败「跨分割回流断裂」（failure）：参考平面被切开导致辐射与串扰
- 失败「叠层不对称翘曲」（failure）：回流后弓曲/扭曲超差
- 器件「USB-C 母座」（part）：90 Ω 差分对与连接器扇出的典型场景
