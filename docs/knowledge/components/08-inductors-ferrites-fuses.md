# 电感 / 磁珠 / 共模电感 / 保险丝 / PTC / 热敏电阻选型知识

> **一句话结论**：磁性元件按「电流波形 → Isat/Irms/SRF/DCR → 温度与偏置降额 → 屏蔽与布局」四步选型；保护元件按「正常工作电流/浪涌 I²t → 故障动作电流/电压/分断能力 → 环境温度降额 → 认证与布局」四步选型。**电感看饱和、磁珠看偏置、保险丝看 I²t**，任何一项只看标称值都会在量产/极限工况下翻车。

- **适用阶段**：选型 → 原理图 → BOM → Layout（磁性/保护器件摆放）→ 产测（温升、断路/短路保护验证）。
- **适用对象**：Buck/Boost 功率电感、信号/高频电感、铁氧体磁珠、共模电感（USB/CAN/电源）、一次性贴片保险丝、PPTC 自恢复保险丝、NTC 测温热敏电阻、PTC 过流/加热元件。
- **可信等级**：本文为 `reference` 参考知识。文中数值为通用工程经验/常见规格量级；具体器件必须回读该 MPN 的 datasheet 并由 Librarian 三源核验（EDA 库 / 供应商 / datasheet）后才能作为设计输入。
- **严禁**：不得把本文的「常见量级」当成某颗具体料号的实测参数；不得编造 LCSC 料号、I²t、Isat、温漂等数据。本文涉及的器件型号均为公开常见型号，但 **LCSC 号/封装/参数一律待核验**。

## 1. 功率电感与信号电感

### KP-CMP-122 电感选型第一约束：饱和电流 Isat 与温升电流 Irms 必须同时满足

| 参数 | 定义（按厂家） | 设计判据 | 超限后果 |
|---|---|---|---|
| Isat 饱和电流 | 电感量下降到规定比例时的直流电流，常见下降 −10%、−20% 或 −30%，**各厂定义不同** | 峰值电流 I_peak ≤ 0.8×Isat（启动/堵转/瞬态按冲击电流复核） | 感量骤降、纹波电流暴增、环路失控、输出跌落/复位 |
| Irms 温升电流 | 直流电流使线圈温升到规定值（常见 ΔT=40°C） | 有效电流 I_rms ≤ Irms，且实际温升按环境温度复核 | 长期过热、绝缘老化、焊点/骨架变形甚至烧毁 |
| DCR 直流电阻 | 线圈直流电阻，决定铜损 | P_cu = I_rms² × DCR，计入效率与温升预算 | 效率下降、压降、局部热点 |
| SRF 自谐振频率 | 电感与自身寄生电容谐振的频率 | 开关频率/噪声频段应远低于 SRF（功率电感通常不是高频器件） | SRF 以上呈容性，滤波/储能作用失效 |

- **判据**：功率电感必须同时给出 Isat、Irms、DCR 三条曲线/数值；设计峰值电流 I_peak ≤0.8×Isat，有效电流 ≤Irms，且 Isat 的下降比例定义必须与厂家一致。两只「同感值同封装」的电感 Isat 可能相差 2 倍以上。
- **为什么**：超过 Isat 后磁芯饱和，电感量崩塌导致纹波电流骤升、峰值电流进一步抬升（正反馈），轻则输出纹波/跌落，重则炸管；超过 Irms 的失效是长期热老化，短时间看不出来。Isat 与 Irms 是两条独立边界，不能互相替代。
- **怎么做**：Buck 按 I_peak = I_out + ΔI/2 计算，ΔI 取 (20%~40%)×I_out；有电机/舵机/喇叭等冲击负载时按堵转/启动电流复核；电池供电且会热插拔时按浪涌电流复核；选屏蔽型（磁屏蔽）降低辐射并减少对邻近敏感线的干扰。
- **怎么查**：datasheet 中 Isat/Irms 的测试条件（温度、下降比例、温升）；是否只给 Isat 不给 Irms；BOM/评审表中是否列出 I_peak/Isat 与 I_rms/Irms 两个比值。**可量测判据**：满载 + 启动冲击下用电感电流探头/分流电阻测峰值，I_peak ≤0.8×Isat；满载运行 30min 后热成像测电感表面温升 ≤ datasheet 规定值（常见 ΔT≤40°C）。

### KP-CMP-123 DCR 铜损决定效率与压降，必须计入预算

- **判据**：铜损 P_cu = I_rms² × DCR。以 2A 有效电流、DCR=30mΩ 为例，P_cu=0.12W；若输出 3.3V/2A（6.6W），铜损约占 1.8%，再加上磁芯损耗/开关损耗即构成效率损失。DCR 压降 ΔV = I×DCR 还必须低于后级欠压门限。
- **为什么**：同感值同尺寸的电感 DCR 可相差 2~3 倍（线径、绕法、合金粉芯 vs 铁氧体）；低 DCR 往往意味着更大尺寸或更高成本，是效率与体积的直接 trade-off。
- **怎么做**：先用效率预算反推允许铜损，再选 DCR 档位；大电流/低压输出（如 1.2V/3A）对 DCR 极敏感，优先低 DCR 合金粉芯/扁平线电感；DCR 的温升系数（铜 +0.39%/°C 量级）在高温下会进一步抬高损耗，按热态复核。
- **怎么查**：datasheet DCR 典型值/最大值（按最大值算最坏情况）；满载测输入/输出功率算效率，与预算对比；**可量测判据**：满载时电感 DCR 压降 ≤ 电源轨的 1%~2%（按设计预算），热态效率不低于目标值。

### KP-CMP-124 功率电感的 SRF 与频率特性：不要把它当高频滤波器

- **判据**：功率电感 SRF 常见几十 kHz~几 MHz 量级（感值越大、匝数越多，SRF 越低，具体按 datasheet）；开关频率及其谐波应显著低于 SRF。用于 EMI 抑制的高频场合应选高频电感/磁珠，而不是大感值功率电感。
- **为什么**：SRF 以上电感呈容性，不仅失去储能/滤波作用，还会与外部电容形成新的谐振峰；把功率电感用于数百 MHz 的噪声抑制，往往适得其反。
- **怎么做**：Buck 电感按开关频率 fsw 选型（L 计算见 KP-CMP-125），并确认 fsw 的 3~5 次谐波仍低于 SRF；输出 LC 滤波的高频衰减靠小容值陶瓷电容 + 磁珠，不靠加大功率电感。
- **怎么查**：datasheet 阻抗-频率曲线（部分厂家给出）；实测开关节点振铃频率与输出纹波频谱；**可量测判据**：开关频率处阻抗符合设计预期，输出纹波频谱无异常抬升。

### KP-CMP-125 功率电感按拓扑公式计算，不凭经验套值

- **判据**：Buck：L = (Vin − Vout) × Vout / (Vin × fsw × ΔI)，ΔI 取 (20%~40%)×I_out；Boost：按输入电流与占空比计算。示例：Vin=12V、Vout=5V、fsw=500kHz、I_out=1A、ΔI=30%×1A=0.3A → L=(7×5)/(12×500k×0.3)=19.4µH，取 22µH 标称值（再按 IC 手册推荐范围复核）。
- **为什么**：L 太小 → 纹波电流大、可能进 DCM、输出纹波与 EMI 变差、峰值电流抬高；L 太大 → 体积/DCR 大、瞬态响应慢、成本高。
- **怎么做**：先定 fsw 与 ΔI 比例，算 L 后按 I_peak、Irms、DCR、尺寸、屏蔽类型选具体 MPN；IC datasheet 的推荐 L 范围是重要边界，偏离时要说明理由；计算书留档。
- **怎么查**：对照 IC 推荐 L 与计算值；满载/轻载测电感电流波形（是否饱和、是否 DCM、峰值是否超限）；**可量测判据**：满载纹波电流 ΔI 在 (20%~40%)×I_out 设计带内。

### KP-CMP-126 电感温升与布局：靠近开关节点但不进敏感区

- **判据**：电感是 DC-DC 的主要热源与辐射源之一；满载温升按 datasheet 规定（常见 ΔT=40°C@Irms，环境温度需叠加），表面温度不得超过绝缘等级允许值。布局上电感应靠近 IC 的 SW 引脚以缩小功率环路，但其磁场泄漏区（通常沿轴线方向）要避开反馈走线、晶振、音频/ADC 敏感线。
- **为什么**：功率环路面积决定辐射与开关振铃；电感漏磁会以磁场形式耦合进高阻反馈网络与高阻抗模拟线，表现为输出纹波异常或噪声。
- **怎么做**：SW—电感—输出电容构成的高 di/dt 环路越小越好；反馈分压走线远离电感与 SW 节点，从输出电容处单点取样；电感下方按 datasheet 建议禁铺铜/禁走线（部分屏蔽电感允许铺地，按规格书）；两个电感并排时保持间距或正交摆放，减少互感。
- **怎么查**：Layout 评审检查功率环路面积、反馈走线路径、电感禁布区；热成像看电感与周边器件温升；**可量测判据**：满载 30min 电感表面温升 ≤ datasheet ΔT，反馈节点纹波无明显开关耦合尖峰。

## 2. 共模电感与铁氧体磁珠

### KP-CMP-127 共模电感按接口类型选：阻抗、额定电流、漏感、绕法

| 接口/场景 | 关键参数 | 常见取值量级（按 datasheet） | 注意点 |
|---|---|---|---|
| USB 2.0 差分 | 100MHz 共模阻抗、额定电流、DCR、差模漏感 | 共模阻抗 67~120Ω@100MHz；额定 0.3~0.5A 级 | 差模阻抗要低，避免影响信号；两线对称布线 |
| CAN / RS485 | 共模阻抗、额定电流、隔离等级（如带隔离变压器） | 共模阻抗 100Ω~1kΩ@100MHz 级；额定按总线电流 | 与终端电阻/共模电压一起校核，避免饱和 |
| 电源输入 EMI | 共模阻抗、额定电流、漏感、绕线电容 | 共模电感 mH 级、额定电流按输入电流 | 漏感可能引起差模谐振，需与 X 电容配合 |
| 信号线（低速） | 共模阻抗、额定电流、封装 | 几十~几百 Ω@100MHz 级 | 不要让 DCR 压降吃掉信号裕度 |

- **判据**：共模电感的共模阻抗要高（目标频段）、差模阻抗要低（不损伤信号）、额定电流 ≥ 工作电流、DCR 压降在预算内；差分对必须同层、等长、对称穿过共模电感，两线对地寄生不对称会直接降低共模抑制效果。
- **为什么**：共模电感的原理是两绕组同向绕制，差模电流产生的磁通相互抵消，共模电流磁通叠加 → 高共模阻抗；一旦两线布局不对称，共模噪声会转成差模噪声（反之亦然），滤波器失效。
- **怎么做**：USB/CAN 等接口把共模电感放在连接器与 ESD 器件之后（靠近连接器一侧，按接口规范顺序）；差分走线在共模电感下方连续、不换层、不被分割；额定电流按接口最大电流留 1.5 倍；电源用共模电感注意漏感与 Y 电容配合，避免谐振。
- **怎么查**：datasheet 共模/差模阻抗曲线、额定电流、DCR；Layout 评审对称性与回流；EMC 预扫看目标频段衰减；**可量测判据**：目标频段共模噪声衰减达到设计值（如 10~20dB，按实测/仿真），差模插损在信号带宽内 ≤0.5dB 量级（按接口要求）。

### KP-CMP-128 铁氧体磁珠是「频率相关电阻」，必须按直流偏置降额

- **判据**：磁珠核心参数：目标频率阻抗（常标 100MHz，Ω）、额定电流、DCR、直流偏置下的阻抗衰减曲线。磁珠在直流下近似电阻（DCR），在目标频段呈阻性吸收噪声。**大电流下磁珠会饱和，阻抗可能下降 50% 以上**，必须按实际工作电流查偏置曲线。
- **为什么**：磁珠的阻抗来自铁氧体材料的磁损耗，偏置磁场会让材料进入饱和/低磁导区，高频损耗特性变差；只按 100MHz 标称阻抗选型，在大电流电源线上实际抑制能力可能只剩一半。
- **怎么做**：按工作电流选额定电流 ≥1.5 倍，并查偏置曲线确认工作点阻抗满足要求；DCR 压降 ΔV=I×DCR 计入电源预算；电源入口/时钟/接口线用磁珠，大电流主电源路径改用功率电感或 0Ω（见 KP-CMP-130）；需要低频衰减时用 LC 滤波，磁珠只负责高频。
- **怎么查**：datasheet 阻抗-频率曲线 + 偏置特性曲线 + 额定电流/DCR；**可量测判据**：磁珠 DCR 压降 ≤ 电源轨的 1%（或按预算），目标频段插入损耗满足 EMC 预扫要求。

### KP-CMP-129 磁珠电流、DCR 与「磁珠+电容」谐振

- **判据**：磁珠 + 去耦电容构成 LC 低通，转折频率 f≈1/(2π√(L_bead·C))；磁珠在低频呈感性，可能与电容形成欠阻尼谐振峰，反而放大某频段噪声。工程上常串小电阻（如 1~10Ω）或选阻性占比高的磁珠做阻尼，具体按实测。
- **为什么**：磁珠不是纯电阻，其低频电感量与电容谐振会在转折频率附近产生峰化；Q 值高时噪声被放大，EMC 测试反而变差。
- **怎么做**：电源轨磁珠后加 100nF~1µF 电容时，评估谐振频率是否落在敏感频段；必要时串阻尼电阻或并联电解电容降低 Q；不要在低噪声模拟电源上盲目加磁珠，先确认噪声频段。
- **怎么查**：阻抗分析仪/网络分析仪测磁珠+电容组合的插入损耗曲线；EMC 预扫对比加/不加磁珠；**可量测判据**：目标频段无新增谐振峰超过原噪声水平。

### KP-CMP-130 磁珠 / 电感 / 0Ω / 保险丝：四种「串联件」的边界

| 器件 | 主要作用 | 直流特性 | 不能用来做 | 典型位置 |
|---|---|---|---|---|
| 功率电感 | 储能/滤波（低频大电流） | DCR 小、可过大电流 | 高频噪声抑制 | DC-DC 的 SW 节点 |
| 铁氧体磁珠 | 高频噪声吸收 | DCR 小、额定电流有限 | 大电流主电源、低频滤波 | 电源入口、时钟、接口线 |
| 0Ω 电阻 | 跳线/配置/单点连接 | 近似短路（额定电流有限） | 限流、保险、滤波 | 配置位、地分割单点 |
| 保险丝/PPTC | 过流/短路保护 | 正常时近短路 | 噪声抑制、限流（PPTC 有限流作用但不精确） | 电源输入、电池输出 |

- **判据**：按「功能」选器件，而不是按「封装/阻值」选；0Ω 电阻不能当保险丝（过流行为不可控），磁珠不能串在大电流主电源路径（DCR 压降 + 饱和），功率电感不能替代磁珠做高频抑制。
- **为什么**：四类器件的失效模式与额定边界完全不同；混用会让保护失效或引入新的谐振/压降问题。
- **怎么做**：BOM/原理图中每个串联件标注「作用 + 额定电流 + 压降预算」；评审时逐项确认。
- **怎么查**：原理图/BOM 交叉检查；**可量测判据**：所有串联件的正常压降与温升在预算内，故障工况下保护器件按预期动作。

## 3. 保险丝与 PPTC

### KP-CMP-131 一次性保险丝：额定电流降额、电压与分断能力三件套

- **判据**：① 连续工作电流 I_op ≤0.75×I_rated（25°C，环境温度更高时按厂家温度降额曲线继续降）；② 额定电压 ≥ 系统最大电压，且必须是 **DC 额定**（AC 额定不能直接用于 DC）；③ 分断能力（breaking capacity）≥ 可能出现的短路电流；④ I²t 与浪涌匹配（见 KP-CMP-132）。
- **为什么**：保险丝是热熔断器件，额定电流是在 25°C 特定条件下测的，环境温度、封装热耦合、PCB 铜面积都会改变动作点；DC 灭弧比 AC 困难，用 AC 额定的保险丝切 DC 短路可能拉弧不灭。
- **怎么做**：按 I_op 反推 I_rated（I_rated ≥ I_op/0.75），再查温度降额；电池/USB 输入侧优先选 DC 额定、分断能力覆盖电池短路电流的型号；保险丝放在输入连接器之后、保护器件之前（见 KP-CMP-134 顺序）；需要可恢复保护时用 PPTC（但精度与动作时间不如一次性保险丝）。
- **怎么查**：datasheet 的额定电流/电压/分断能力/I²t/温度降额曲线；**可量测判据**：正常满载 1h 不动作（I_op/I_rated ≤0.75），短路测试按预期时间熔断且无起火/拉弧。

### KP-CMP-132 保险丝 I²t：既要防误断，也要防「该断不断」

- **判据**：保险丝熔断 I²t_fuse 必须大于浪涌/启动 I²t_surge，工程上常取 **I²t_surge ≤ (20%~30%)×I²t_fuse**（即 3~5 倍余量，按厂家建议复核）；同时故障短路电流下的动作时间要满足安规/保护配合要求。I²t = ∫i²dt，对电容充电/电机启动等脉冲电流需按波形积分或厂家脉冲耐受曲线核算。
- **为什么**：余量太小 → 上电/热插拔/电机启动时误断；余量太大 → 真实短路时动作太慢，后级器件先损坏，失去保护意义。
- **怎么做**：用示波器+电流探头测实际浪涌波形并积分 I²t；对照 datasheet 的 I²t 与脉冲耐受曲线；有热插拔/大电容输入的场合选延时型（慢断）或加软启动/NTC 限流；保险丝与后级 TVS/IC 的耐受能力做配合校核。
- **怎么查**：I²t 计算书 + 实测浪涌波形；**可量测判据**：10 次上电/热插拔循环不误断；短路测试动作时间在保护配合窗口内。

### KP-CMP-133 PPTC 自恢复保险丝：保持电流、动作电流与温度降额

- **判据**：PPTC 关键参数：I_hold（25°C 保持电流，不动作）、I_trip（动作电流）、额定电压、动作时间、动作后漏电流、DCR。设计判据：**最高环境温度下的 I_hold ≥ 1.2×正常工作电流**（按厂家温度降额曲线），故障电流应 ≥ I_trip；额定电压按系统最大电压留余量。
- **为什么**：PPTC 的动作点强烈依赖环境温度（温度越高 I_hold 越低），常温选型在高温机箱内会误动作；动作后仍有漏电流与残余电阻，不能当完全断开。
- **怎么做**：按目标工作温度（不是 25°C）查 I_hold 降额；USB VBUS、电池输出等位置优先 PPTC 做可恢复保护；动作时间要求快的场合用一次性保险丝；PPTC 动作后需要断电冷却才恢复，不能用于「自动重试」场景而不验证。
- **怎么查**：datasheet 温度降额曲线、动作时间曲线；**可量测判据**：最高工作温度下满载 1h 不动作；短路后 PPTC 动作，移除故障并冷却后能恢复（恢复后 DCR 在规格内）。

### KP-CMP-134 保护器件顺序与布局：先保险丝，后 TVS，靠近入口

- **判据**：典型输入保护链：连接器 → 保险丝/PPTC → TVS（浪涌/ESD）→ 共模电感/滤波 → 后级 DC-DC。TVS 必须放在保险丝之后、被保护器件之前，且地回路短而宽；保险丝与 TVS 的配合要保证「TVS 先钳位、保险丝后熔断」在能量上可行（否则 TVS 先烧）。
- **为什么**：顺序反了（TVS 在保险丝前）会让浪涌能量全部由 TVS 承受；地回路长会让钳位电压在走线电感上额外抬高，后级仍被过压击穿。
- **怎么做**：保护器件靠近连接器、同一铜皮区域；TVS 地脚用短而宽的走线/多过孔接到保护地；保险丝与热敏器件（NTC）保持距离，避免热耦合导致误动作；高压/安规区域留足爬电距离（按认证要求复核）。
- **怎么查**：Layout 评审保护链顺序与地回路；**可量测判据**：ESD/浪涌测试后后级 IC 无损伤、TVS 未短路，钳位电压 ≤ 后级绝对最大额定值的 0.8 倍。

## 4. NTC / PTC 热敏电阻

### KP-CMP-135 NTC 测温：R25、B 值与分压/ADC 换算

- **判据**：NTC 用 R25（25°C 阻值）与 B 值（B25/85 或 B25/50，**按 datasheet 标注**）描述；B 值方程 R(T)=R25×exp[B×(1/T−1/298.15)]（T 为开尔文）。分压电路中固定电阻 R_fix 取 ≈R25 时，25°C 附近灵敏度最高；ADC 读数需按实际基准电压与分压比换算。
- **为什么**：B 值不同、R25 不同的 NTC 不能互换；分压电阻选得过大/过小会让目标温区灵敏度不足；ADC 基准误差直接变成温度误差。
- **怎么做**：按目标温区选 R25 与 B 值（如 10kΩ B=3380 常见于 0~100°C 测温）；R_fix 取 R25 附近并选 ±1% 金属膜；ADC 端加 RC 滤波（如 10k+100nF，按采样率）；软件用 B 值方程或查表 + 线性插值，并在 0°C/25°C/85°C 三点校准。
- **怎么查**：datasheet R-T 表与 B 值公差；**可量测判据**：与标准温度计/恒温槽对比，目标温区内误差 ≤±0.5°C（消费级）或按产品规格（如 ±0.2°C）。

### KP-CMP-136 NTC 自热、线阻与长线误差

- **判据**：自热功率 P=I²×R_NTC；自热引起的温升 ΔT_self=P×S（S 为 dissipating constant，常见 mW/°C 量级，按 datasheet）。工程上希望 ΔT_self ≤0.1~0.5°C。长线引线电阻会叠加到 NTC 阻值上，2 线制每 1Ω 线阻在 10kΩ NTC 上引入约 0.02°C 量级误差（按 R-T 斜率换算），高精度场合需 3 线/4 线或软件补偿。
- **为什么**：NTC 阻值随温度指数变化，测量电流产生的自热会让读数系统性偏高；线阻/接触电阻在低温段（阻值大）影响小、高温段（阻值小）影响大，引入非线性误差。
- **怎么做**：限制测量电流（增大 R_fix 或降低激励电压）；高精度/长线场合用恒流激励或 3 线制；引线尽量短、避免与发热器件/功率线并行；必要时做两点/三点校准。
- **怎么查**：计算自热 ΔT 与线阻误差；**可量测判据**：自热误差 ≤0.5°C、校准后残差 ≤产品规格。

### KP-CMP-137 PTC 与 NTC 的用途边界

| 类型 | 阻温特性 | 主要用途 | 注意点 |
|---|---|---|---|
| NTC（负温度系数） | 温度升高阻值下降 | 测温、温度补偿、浪涌抑制（功率 NTC） | 测温需线性化/校准；功率 NTC 热态阻值低，不能防持续过流 |
| PPTC（聚合物 PTC） | 过流发热后阻值跃升 | 可恢复过流保护 | 动作后漏电流/残余电阻，温度降额明显 |
| PTC 陶瓷（如 BaTiO₃） | 居里点附近阻值跃升 | 自限温加热、过流保护 | 居里点选型决定限温；启动冲击大 |
| Pt100/Pt1000（RTD） | 正温度系数、近似线性 | 高精度测温 | 需要恒流/电桥与放大，成本高 |

- **判据**：测温用 NTC/RTD，过流保护用一次性保险丝/PPTC，自限温加热用 PTC 陶瓷；功率 NTC 只用于抑制开机浪涌，不能替代保险丝做持续过流保护。
- **为什么**：NTC 的阻值随温度强烈非线性，用于过流保护时动作点不可控；PTC 的「自恢复」伴随漏电流与残余电阻，安全关键场景仍需一次性保险丝。
- **怎么做**：按「功能 + 失效模式 + 认证要求」选类型；安全关键（电池、市电）用一次性保险丝 + TVS，PPTC 只做辅助。
- **怎么查**：选型表与保护配合计算；**可量测判据**：故障注入测试中保护器件按设计动作，且不出现起火/持续漏电超标。

## 6. 常见错误清单（并入 KP-CMP-139 门禁）

| # | 错误 | 后果 | 纠正 |
|---|---|---|---|
| 1 | 只看感值不看 Isat/Irms | 饱和掉压、过热 | 双线校核，I_peak ≤0.8×Isat |
| 2 | 磁珠串大电流主电源 | DCR 压降 + 饱和失效 | 改功率电感/0Ω，或选大电流磁珠 |
| 3 | 用 0Ω 电阻当保险丝 | 过流行为不可控 | 用保险丝/PPTC |
| 4 | 保险丝只看额定电流 | 误断或不动作 | 同时核电压、分断能力、I²t、温度降额 |
| 5 | PPTC 按 25°C 选型 | 高温误动作 | 按最高环境温度降额查 I_hold |
| 6 | NTC 分压电阻随意取值 | 灵敏度不足/自热大 | R_fix≈R25，限流+校准 |
| 7 | 共模电感两线不对称 | 共模抑制失效 | 同层等长对称布线 |
| 8 | 保护器件远离连接器 | 浪涌能量进入板内 | 靠近入口、短地回路 |
| 9 | 电感下方随意铺铜/走线 | 涡流损耗/耦合噪声 | 按 datasheet 禁布区执行 |
| 10 | 磁性件无第二来源 | 缺货停产 | 建立替代料对比表并核验 |

- **判据**：任一项存在即判为选型/布局缺陷。
- **为什么**：这些是磁性/保护元件最高频、可复现的实战错误。
- **怎么做**：并入 BOM 与 Layout 评审清单，逐项确认证据。
- **怎么查**：评审记录 + 测试证据 + Librarian 核验报告。
