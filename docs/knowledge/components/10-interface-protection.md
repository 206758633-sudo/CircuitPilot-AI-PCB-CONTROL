# 接口保护（ESD / TVS 阵列 / 共模滤波 / 隔离器 / 连接器保护）选型知识

> **一句话结论**：接口保护按「威胁等级（ESD/浪涌/热插拔）→ 保护链顺序（保险丝 → TVS → 共模滤波 → 串阻）→ 钳位电压与结电容匹配 → 地回路/隔离/认证」四步设计；**钳位电压必须低于后级绝对最大额定值、结电容必须不破坏信号完整性、保护器件必须紧靠连接器且回流路径短**，三者缺一不可。

- **适用阶段**：接口定义 → 原理图（保护链/隔离）→ Layout（连接器/地回路/爬电距离）→ EMC/ESD 认证 → 产测。
- **适用对象**：USB/HDMI/以太网/CAN/RS485/音频/天线等外部接口；ESD 二极管与 TVS 阵列、共模电感/滤波器、TBU/PPTC、光耦与数字隔离器、连接器与热插拔保护。
- **可信等级**：本文为 `reference` 参考知识；具体器件的 VRWM/VC/IPP/Cj/隔离等级**必须回读该 MPN 的 datasheet**，测试等级与认证要求**必须按产品适用的标准原文**确认，且器件身份**需 Librarian 三源核验（EDA 库 / 供应商 / datasheet）**。
- **严禁**：不得编造 IEC 测试等级、器件钳位电压、结电容、隔离耐压；不得把本文「常见量级」当成某颗料号实测参数；BOM 中料号一律标「待核验」。

## 1. ESD 标准与 TVS 选型

### KP-CMP-158 ESD 威胁模型：HBM / CDM / IEC 61000-4-2 不是一回事

| 模型/标准 | 适用对象 | 放电网络/波形（量级） | 典型等级 | 判据 |
|---|---|---|---|---|
| HBM（ANSI/ESDA/JEDEC JS-001） | 芯片生产/装配 | 100pF / 1.5kΩ，上升沿 ns 级 | 常见 1kV/2kV/4kV 档（按器件规格） | 器件 datasheet 的 HBM 等级 ≥ 产线要求 |
| CDM（JS-002） | 芯片/模组 | 封装电容充放电，上升沿亚 ns 级 | 常见 250V/500V/1kV 档 | 产线/装配 ESD 控制 + 器件 CDM 等级 |
| IEC 61000-4-2（系统级） | 整机/接口 | 150pF / 330Ω，接触放电上升沿 ~1ns，空气放电 | Level 1~4：接触 2/4/6/8kV，空气 2/4/8/15kV（按标准原文） | 整机接口 ESD 测试后功能正常/可自恢复 |
| IEC 61000-4-5（浪涌） | 整机/电源/长线接口 | 1.2/50µs 电压波 + 8/20µs 电流波组合 | 常见 0.5/1/2/4kV 档（按产品类别） | 浪涌后无损坏、无起火，功能恢复 |

- **判据**：先按产品类别/市场确定要满足的**系统级标准与等级**（如 IEC 61000-4-2 Level 4：接触 ±8kV、空气 ±15kV），再选保护器件；器件 datasheet 的 HBM/CDM 等级只用于产线控制，不能替代系统级 ESD 测试。测试等级必须写进设计输入与验收报告。
- **为什么**：HBM/CDM 是芯片级模型，能量与波形和 IEC 61000-4-2 完全不同；用 HBM 等级推断整机 ESD 能力是常见误判。IEC 61000-4-2 接触放电电流峰值可达几十 A（8kV 时约 30A 量级），远超芯片自身耐受。
- **怎么做**：把「整机 ESD/浪涌等级」写进需求；按接口类型（外露连接器/内部板间/长线）确定防护等级；保护器件选型后用 ESD 枪/浪涌发生器做预测试；保留测试布置、等级、判据（A/B/C 性能判据）记录。
- **怎么查**：标准原文与产品认证计划；**可量测判据**：按 IEC 61000-4-2 规定布置打接触/空气放电，测试后功能与性能判据满足要求（如 B 类：暂时降级可自恢复）。

### KP-CMP-159 TVS 选型四参数：VRWM / VBR / VC / IPP 与后级耐压匹配

- **判据**：① **VRWM**（反向工作电压/standoff）≥ 信号最大工作电压 ×1.1~1.2（如 5V 信号选 5.0V 或 5.5V 档，USB VBUS 取 ≥5.5V）；② **VBR**（击穿电压，常规定在 1mA）> VRWM；③ **VC**（钳位电压，在规定 IPP 下）≤ 后级 IC 绝对最大额定值 ×0.8（留 20% 余量）；④ **IPP**（8/20µs 峰值脉冲电流）与峰值功率满足威胁能量。结电容按信号速率另核（KP-CMP-160）。
- **为什么**：VRWM 选低 → 正常信号/电源纹波就会漏电/误动作；VC 选高 → ESD 电流仍会击穿后级；IPP 不足 → TVS 自身先损坏（常见失效模式是短路）。TVS 的「标称电压」不是钳位电压，必须看 VC-IPP 曲线。
- **怎么做**：按接口电压选 VRWM 档位（3.3V 信号选 3.3V/5V 档，5V 选 5.0/5.5V 档，12V 选 12/15V 档）；按后级绝对最大值反推允许 VC；电源口/长线口选大 IPP/功率档（如 SMB/SMC 封装），板内信号选小封装；单向用于直流/单极性信号，双向用于差分/交流信号（按 datasheet 确认）。
- **怎么查**：datasheet 的 VRWM-VBR-VC-IPP 表与钳位曲线；**可量测判据**：ESD/浪涌测试时用示波器（高压差分探头）测被保护节点残压 ≤ 后级绝对最大值×0.8，TVS 不损坏（测试后漏电流在规格内）。

### KP-CMP-160 结电容决定信号完整性：高速接口必须选低电容 TVS

- **判据**：TVS/ESD 二极管的结电容 Cj 并联在信号线上，与走线电感构成低通，会衰减高频、造成码间干扰/眼图闭合。经验边界：USB 2.0 高速（480Mbps）建议 Cj ≤1~2pF 量级；USB 3.x/HDMI/以太网等更高速率需 ≤0.5pF 量级；音频/低速 GPIO 可用几 pF~几十 pF。具体以信号速率、眼图模板与器件 datasheet 为准。
- **为什么**：Cj 在目标频段的阻抗随频率下降，对高速边沿形成容性负载；多路并联/多颗器件会叠加电容，单颗「低电容」不等于整条链路低电容。
- **怎么做**：优先选专用低电容 ESD 阵列（如 USBLC6、TPD4E05U06、RClamp0524P 等，Cj 按 datasheet）；高速差分线每线只放一颗低电容器件，避免多级并联；保护器件放在连接器与 AC 耦合电容/共模电感之间，缩短分支 stub；布局上保护器件「骑」在差分线上，分支越短越好。
- **怎么查**：datasheet Cj（注意测试偏压/频率条件）；**可量测判据**：加保护器件前后眼图/插损对比，目标速率下眼高/眼宽仍满足模板（如插损增加 ≤0.5dB 量级，按接口要求），TDR 无明显阻抗跌落。

### KP-CMP-161 ESD 阵列/多路保护器件选型：通道数、极性、钳位与封装

| 器件类型 | 典型用途 | 关键参数 | 注意点 |
|---|---|---|---|
| 单路 ESD 二极管（如 SOD-323） | 单根 GPIO/按键/复位 | VRWM、Cj、VC、封装 | 布线简单，但多路时占面积 |
| 多路 ESD 阵列（SOT-23-6/DFN-10） | USB D+/D−、多根信号 | 通道数、Cj、VC、引脚排列 | 引脚映射决定布线，注意 I/O 与 GND 排列 |
| 低电容多路阵列（0.3~1pF 级） | USB 2.0/HDMI/高速差分 | Cj、VC、通道间匹配 | 差分对内通道要成对使用，减少失配 |
| 带 Vbus 保护的阵列 | USB Type-C/接口 | Vbus 钳位、ESD、过压 | 需与 VBUS 电压/电流等级匹配 |
| TVS 二极管（SMA/SMB/SMC） | 电源入口/长线浪涌 | IPP、峰值功率、VC | 能量大，需与保险丝配合（KP-CMP-164） |

- **判据**：通道数 ≥ 需保护线数（留 1 路余量），每通道 Cj/VC 满足信号与后级要求；阵列的 GND 引脚要短接到保护地；差分对的两路尽量在同一器件内成对（参数匹配好）。
- **为什么**：多路阵列能把多条线的保护集中在一个封装内，减少寄生与面积；但不同通道的引脚排列/寄生可能不同，差分对跨器件会引入失配。
- **怎么做**：USB D+/D− 用一颗双路/四路阵列；HDMI/多 lane 用多颗低电容阵列；电源与信号分开选型；阵列 GND 用多过孔接保护地，避免 ESD 电流流过信号地。
- **怎么查**：datasheet 通道数/引脚图/Cj/VC；**可量测判据**：每根受保护线 ESD 测试后残压达标，差分对插损/偏斜在预算内。

### KP-CMP-162 ESD 保护布局：先打后过、地回路短、紧靠连接器

- **判据**：ESD 电流必须在到达被保护 IC 之前被旁路到地：保护器件紧靠连接器/接口入口，**「先打后过」**（连接器 → 保护器件分支 → 后级），不能把保护器件放在走线末端；地回路要短而宽，最好用多过孔直接连到完整地平面；被保护走线不得在保护器件之后分叉到其他区域。
- **为什么**：ESD 电流是 ns 级高频脉冲，走线电感会抬升残压（V=L·di/dt）；保护器件离入口越远、地回路越长，后级看到的电压越高。布局不当会让「有 TVS 但照样打坏」。
- **怎么做**：保护器件放在连接器焊盘附近（几 mm 内）；GND 引脚用 ≥2 个过孔（按电流）连到地平面；信号走线先到保护器件焊盘再进 IC，避免 stub；机壳地/连接器金属外壳与信号地按 EMC 策略单点/电容连接（KP-CMP-172）；隔离接口的保护地与数字地分开。
- **怎么查**：Layout 评审保护器件位置、地过孔数量、stub 长度；**可量测判据**：ESD 测试残压达标（≤后级绝对最大值×0.8），保护器件地脚到地平面的回路电感尽量小（多过孔/短走线）。

## 2. 共模滤波与接口保护链

### KP-CMP-163 共模滤波：USB / CAN / RS485 的参数与布局

- **判据**：共模电感/滤波器按接口选：共模阻抗（目标频段高）、差模阻抗（信号带宽内低）、额定电流、DCR、隔离等级（工业接口）。USB 2.0 常选 90Ω@100MHz 级、0.4A 级；CAN/RS485 选 100µH~1mH 级共模电感（按总线速率与电流）；以太网用专用网络变压器/共模扼流圈。差分对必须对称穿过器件，两线不换层、不等长会降低共模抑制。
- **为什么**：共模噪声在两根线上同相，共模电感对其呈现高阻抗；差模信号反相，磁通抵消。布局不对称会把共模噪声转成差模噪声，直接恶化信号。
- **怎么做**：共模滤波器放在连接器与 ESD 保护之后；差分走线同层、等长、等间距，尽量不换层；器件下方地平面完整；工业隔离接口把共模电感放在隔离侧/总线侧（按参考设计）；额定电流按接口最大电流留 1.5 倍。
- **怎么查**：datasheet 共模/差模阻抗曲线、额定电流；**可量测判据**：目标频段共模衰减达标（如 10~20dB 量级，按实测/EMC 预扫），信号带宽内差模插损 ≤0.5dB 量级，眼图/误码率满足接口要求。

### KP-CMP-164 接口保护链顺序：保险丝/PPTC → TVS → 共模 → 串阻

| 顺序 | 器件 | 作用 | 位置 | 常见错误 |
|---|---|---|---|---|
| 1 | 连接器 | 引入外部威胁 | 板边 | — |
| 2 | 保险丝/PPTC/TBU | 过流/短路/热插拔限流 | 紧靠连接器 | 放在 TVS 之后（浪涌先打 TVS） |
| 3 | TVS/ESD 阵列 | 钳位 ESD/浪涌电压 | 紧靠连接器、保险丝之后 | 地回路长、离连接器远 |
| 4 | 共模电感/滤波 | 抑制共模噪声 | TVS 之后、信号进入板内前 | 差分不对称、额定电流不足 |
| 5 | 串阻/RC | 限制残余电流、阻尼谐振 | 靠近 IC 引脚 | 阻值过大影响信号/增加延迟 |

- **判据**：保护链顺序必须保证「浪涌/ESD 能量先被 TVS 旁路，过流由保险丝/PPTC 承担，共模噪声在进入板内前被抑制」；TVS 必须在保险丝之后（否则浪涌能量全打在 TVS 上），且 TVS 的 IPP/能量与保险丝 I²t 配合（保证 TVS 先动作、保险丝后熔断）。
- **为什么**：顺序错误会让「保护器件互相打架」：TVS 放在保险丝前会被大能量浪涌打坏；串阻放在 TVS 前会先承受 ESD 电流；共模电感放在 TVS 前会让浪涌能量经过电感耦合到板内。
- **怎么做**：按接口类型画保护链（USB/CAN/RS485/音频各不同）；TVS 与连接器之间的走线尽量短；串阻按信号速率选（USB 串阻常见 22Ω 级，CAN 终端 120Ω 另计）；保护器件的地全部汇到保护地/机壳地（按 EMC 策略）。
- **怎么查**：原理图评审保护链顺序与器件额定配合；**可量测判据**：浪涌测试后 TVS/后级均无损坏，残压达标；热插拔测试无打火/复位。

### KP-CMP-165 浪涌（IEC 61000-4-5）与 TVS 能量校核

- **判据**：浪涌测试用 1.2/50µs（开路电压）与 8/20µs（短路电流）组合波；TVS 的峰值脉冲功率 P_pp ≈ VC × IPP（按 8/20µs 波形），必须 ≥ 测试等级对应的浪涌电流；多次浪涌/长时间浪涌需按厂家降额曲线（脉冲重复率、脉宽）核算平均功率。TVS 与保险丝/PPTC 的配合：TVS 先钳位，保险丝在浪涌期间不动作、在持续过流时动作。
- **为什么**：浪涌能量远大于 ESD（8/20µs 波形能量高），TVS 若只按 ESD 等级选型会被浪涌打坏；反之保险丝若在浪涌期间误断，设备直接掉电。
- **怎么做**：按产品标准的测试等级算浪涌电流（如 2Ω 组合波发生器、1kV 对应 500A 量级，按标准/发生器定义）；选 IPP 足够的 TVS（SMB/SMC 封装）或加二级保护（气体放电管/GDT + TVS）；电源入口加压敏电阻（MOV）时注意老化/漏电与保险丝配合。
- **怎么查**：datasheet 峰值脉冲功率/电流（8/20µs）与降额曲线；**可量测判据**：按标准等级打浪涌后 TVS 漏电流在规格内、后级功能正常；保险丝未误断。

### KP-CMP-166 热插拔与连接器保护：限流、防反接、上电顺序

- **判据**：热插拔/带电插拔接口必须有：① 浪涌电流限制（PPTC/热插拔控制器/软启动）；② 防反接（P-MOS/理想二极管/二极管，按压降与效率选）；③ ESD/浪涌保护（KP-CMP-158~165）；④ 连接器先接地后通电的引脚顺序（长地短电/先 Make 后 Break，按连接器 datasheet）。连接器额定电流/电压/插拔寿命必须 ≥ 实际使用。
- **为什么**：带电插拔时连接器抖动会产生多次通断与电感反冲，瞬间电流可达稳态数倍；反接会直接烧板；连接器引脚顺序错误会让 ESD 电流走信号脚。
- **怎么做**：按接口电流选 PPTC/热插拔控制器；防反接 P-MOS 注意栅极钳位与 Vgs 耐压；连接器选带先接地引脚/屏蔽壳的型号；大电容输入加软启动/NTC 限制上电浪涌；插拔频繁的接口选高插拔寿命连接器。
- **怎么查**：datasheet 连接器额定/寿命、引脚顺序；**可量测判据**：带电插拔 100 次无损坏/复位，浪涌电流 ≤限流设计值，反接测试不损坏（按产品要求）。

### KP-CMP-167 串阻/RC 滤波与 ESD 器件的配合

- **判据**：串阻/RC 用于限制 ESD 残余电流、阻尼 LC 谐振、匹配阻抗；阻值按信号速率与 IC 输入电流选（USB 22Ω 级、CAN 终端 120Ω、RS485 偏置/终端按总线规范）；RC 的截止频率要高于信号带宽、低于噪声频段。串阻不能替代 TVS（ESD 能量会烧电阻），TVS 也不能替代串阻（残余电流/振铃仍需阻尼）。
- **为什么**：ESD 后级 IC 的失效常由「残余电流注入输入保护二极管」引起，串阻可把电流限制在 IC 耐受范围内；但纯串阻无法钳位电压，必须与 TVS 配合。
- **怎么做**：TVS 之后、IC 之前放串阻（按信号方向）；RC 滤波电容靠近 IC 引脚；高速差分线谨慎加 RC（影响眼图），优先低电容 TVS + 共模电感；串阻封装按脉冲功率选（0402 脉冲耐受有限）。
- **怎么查**：datasheet IC 绝对最大输入电流与信号速率；**可量测判据**：ESD 后 IC 输入电流/残压在规格内，信号上升时间/眼图满足接口要求。

### KP-CMP-168 天线/射频口保护：低电容、低损耗、少分支

- **判据**：天线/RF 口的 ESD 保护必须选超低电容（常见 ≤0.3pF 量级，按频段与 datasheet）、低插损器件，且保护器件的寄生电容会改变天线匹配/谐振频率；布局上保护器件分支极短，地回路就近，避免在 RF 走线上形成 stub。天线口通常还需要匹配网络（π/T 型）与直流接地/隔直（按天线类型）。
- **为什么**：RF 频段下 pF 级电容就是明显的阻抗不连续，会造成插损/驻波恶化；长 stub 会成为天线/辐射体。
- **怎么做**：选 RF 专用低电容 ESD 器件；保护器件放在天线馈点附近、匹配网络之前或之后按参考设计；RF 走线 50Ω 控制、少过孔、包地；ESD 测试后复测 S11/驻波与灵敏度。
- **怎么查**：datasheet Cj@目标频段、插损；**可量测判据**：加保护后 S11/驻波与灵敏度变化在预算内（如插损 ≤0.2~0.5dB，按产品要求），ESD 测试后射频功能正常。

## 3. 隔离：光耦与数字隔离器

### KP-CMP-169 光耦选型：CTR、速度、隔离电压与老化降额

- **判据**：光耦关键参数：电流传输比 CTR（随温度/老化下降，设计时按最小值并留余量，常见按 50% 降额）、响应速度（普通光耦 kHz 级，高速光耦 Mbps~10Mbps 级）、隔离电压（按认证要求，常见 2.5~5kVrms 档）、输入 LED 正向电流/寿命、输出类型（晶体管/达林顿/逻辑输出）。**CTR 会随使用时间衰减，不能按典型值设计。**
- **为什么**：CTR 不足 → 输出无法饱和/通信误码；CTR 随温度升高下降、随 LED 老化下降，按典型值设计会在寿命末期失效；光耦速度不足会限制通信速率。
- **怎么做**：按最小 CTR（datasheet min）与最坏温度算 LED 驱动电流与输出上拉，留 2 倍以上余量；高速数字隔离用高速光耦或数字隔离器（KP-CMP-170）；隔离侧供电独立；LED 串联限流电阻按 IF 与 VF 计算；需要高可靠性/长寿命时优先数字隔离器。
- **怎么查**：datasheet CTR(min)/CTR 老化曲线、传输延迟、隔离电压；**可量测判据**：最坏温度下输出高/低电平裕度满足逻辑阈值，通信误码率 ≤设计值，隔离耐压测试通过。

### KP-CMP-170 数字隔离器选型：隔离等级、速率、CMTI、供电

- **判据**：数字隔离器关键参数：隔离等级（如 2.5kVrms/5kVrms，按认证要求）、通道数与方向、数据速率（Mbps 级）、共模瞬态抗扰度 CMTI（kV/µs，工业/电机环境要求高）、供电电压（两侧可不同）、传播延迟/脉宽失真、默认输出状态（失效时输出高/低）。与光耦相比，数字隔离器速度快、寿命长、CTR 不老化，但需要两侧供电。
- **为什么**：CMTI 不足时，电机/继电器产生的共模瞬变会让隔离器输出误翻转；默认输出状态决定故障时系统安全行为（如使能信号默认关断）。
- **怎么做**：按认证要求选隔离等级与爬电距离（KP-CMP-171）；按总线速率选数据速率并留 2 倍余量；电机/变频环境优先高 CMTI 型号；注意两侧电源上电顺序与默认输出；隔离器两侧地/电源完全分开，不得跨隔离栅布线。
- **怎么查**：datasheet 隔离等级/CMTI/速率/延迟/默认状态；**可量测判据**：隔离耐压测试通过，CMTI 按规格（如 ≥25kV/µs 量级，按器件/环境），通信误码率达标。

### KP-CMP-171 隔离电源与地分割：爬电距离/电气间隙按标准查

- **判据**：隔离接口必须有隔离电源（隔离 DC-DC/变压器）或两侧独立供电；隔离栅两侧的地必须分开，跨隔离栅的器件（光耦/隔离器/隔离电源/电容）是唯一允许的跨接点；爬电距离/电气间隙按工作电压、污染等级、材料组与绝缘类型（基本/加强）**查 IEC 62368-1 / IEC 60664-1 表格**（如 250V 加强绝缘常见 5~6.4mm 量级，具体按标准原文），PCB 开槽/挖空可增加爬电距离。
- **为什么**：隔离失效（爬电/击穿）会导致触电/设备损坏；地分割不当会让隔离形同虚设（两边地通过其他路径连在一起）。
- **怎么做**：Layout 上画隔离带（keep-out），隔离带下方所有层禁铺铜/禁走线；跨隔离栅器件集中布置；按标准计算并留余量（认证通常要求 ≥ 计算值）；隔离电源的变压器/隔离电容选认证型号；产测做隔离耐压测试（按规格，如 1.5kVAC/5s 或 2.5kVrms/1min，按标准/器件规格复核）。
- **怎么查**：Layout 隔离带/爬电距离测量；**可量测判据**：爬电/电气间隙 ≥ 标准计算值，隔离耐压测试通过且漏电流在限值内。

## 4. 接地、选型表与门禁

### KP-CMP-172 接地与屏蔽：机壳地/信号地/保护地的连接策略

- **判据**：接口保护的地（机壳地/保护地）与信号地要分开设计，在单点（或通过电容/电阻）连接；连接器金属外壳、屏蔽层、TVS 地脚优先接机壳地/保护地；信号地保持完整、低阻抗，避免 ESD 电流穿过信号地。屏蔽线/屏蔽罩的接地方式（360° 搭接 vs 单端接地）按频率与 EMC 策略选。
- **为什么**：ESD/浪涌电流若流过信号地，会在公共地阻抗上产生压降，造成 MCU 复位/ADC 误差/通信误码；机壳地与信号地乱连会形成地环流与辐射。
- **怎么做**：连接器区域划出保护地铜皮，TVS 地接保护地；保护地与信号地在靠近接口处单点连接（或按 EMC 方案用电容/磁珠）；屏蔽罩多点接地到机壳地；线缆屏蔽层 360° 搭接；隔离接口的保护地不与数字地直接相连。
- **怎么查**：Layout 评审地分割与连接点；**可量测判据**：ESD 测试时 MCU 不复位/ADC 无跳变，传导/辐射发射满足限值。

### KP-CMP-173 保护器件降额与失效模式：短路失效最危险

- **判据**：TVS/ESD 二极管的主要失效模式是**短路**（过能量/过电压后），会造成电源短路/信号线对地短路；设计必须保证：正常工作电压 ≤ VRWM×0.9、浪涌/ESD 能量在 IPP 降额内、焊接/回流热应力不损伤器件；保护器件短路后系统应有可诊断/可恢复策略（保险丝熔断、自检）。
- **为什么**：保护器件短路会让「保护」变成「故障源」；如果前端没有保险丝/PPTC，短路的 TVS 可能烧板。降额不足时 TVS 在多次浪涌后逐渐劣化（漏电流增大）。
- **怎么做**：TVS 前面必须有保险丝/PPTC（KP-CMP-164）；按厂家降额曲线控制浪涌次数/能量；选漏电流小、质量等级高的器件；产测加保护器件漏电流/对地阻抗检查（可选）；失效分析时优先怀疑 TVS 短路。
- **怎么查**：datasheet 降额曲线/漏电流；**可量测判据**：量产抽测 TVS 漏电流在规格内；故障注入（TVS 短路）时保险丝按预期熔断、不起火。
