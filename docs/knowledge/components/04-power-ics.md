# 电源 IC（LDO / Buck / Boost / 充电管理）选型知识

> **一句话结论**：电源 IC 选型先定拓扑与输入输出窗口，再用「压差/效率/热」三条硬约束收口：LDO 必须按 P=(Vin−Vout)×Iout 与 RθJA 做热核算，Buck 必须按电感公式 + 输入电容 RMS 电流 + 反馈分压三件套算外围，所有替代料必须逐引脚、逐参数、逐外围比对。

- **适用阶段**：电源架构 → 原理图 → BOM → Layout（功率环路/散热）。
- **可信等级**：本文为 `reference` 参考知识；具体器件（如 IP2312、MT3608、SY8089 等）的引脚、外围参数、保护阈值**必须回读 datasheet**，且**需 Librarian 三源核验（EDA 库 / 供应商 / datasheet）**后才能作为设计输入。
- **严禁**：不得编造电源 IC 的引脚定义、反馈基准电压、限流阈值、开关频率；BOM 中料号一律标「项目 BOM 参考（待核验）」。

## 1. 拓扑与电源架构

### KP-CMP-054 先按输入输出窗口与电流选拓扑

| 拓扑 | 条件 | 效率量级 | 外围复杂度 | 典型场景 |
|---|---|---|---|---|
| LDO（线性） | Vin > Vout，压差足够，电流小 | 效率 ≈ Vout/Vin | 最低（2 只电容） | MCU/模拟 3.3V、低噪声、小电流 |
| 非同步 Buck | Vin > Vout | 中（二极管损耗） | 中（外接二极管） | 低成本、低压差比、小电流 |
| 同步 Buck | Vin > Vout | 高 | 中高（内置 MOS） | 主电源轨、大电流、电池供电 |
| Boost | Vin < Vout | 中高 | 中（电感/二极管/输出电容） | 3.7V→5V、LED 背光 |
| Buck-Boost | Vin 跨 Vout | 中 | 高 | 电池电压跨 3.3V |
| 充电管理 | 适配器/USB → 电池 | — | 中（CC/CV + NTC） | 单节锂电 |

- **判据**：压差 (Vin_min − Vout) 小于 LDO 压差 + 裕量 → 不能用 LDO；效率敏感/电流 >300mA → 优先开关电源；噪声敏感（射频/ADC）→ LDO 后级。
- **为什么**：LDO 的效率上限是 Vout/Vin，压差大时发热严重；开关电源效率高但有纹波与 EMI。
- **怎么做**：画电源树：输入 → 保护 → 主变换 → 各轨；每级标注 Vin/Vout/Imax/效率/噪声要求；射频/模拟轨在开关电源后加 LDO 二级滤波。
- **怎么查**：评审项：电源树是否完整（含上电时序、使能、PG）；每级是否有热/效率核算。

### KP-CMP-055 LDO 压差（Dropout）决定最小输入电压

- **判据**：Dropout 是维持稳压所需的最小 (Vin−Vout)，常见 100~300mV（按负载电流，datasheet 给曲线）；最小输入 Vin_min ≥ Vout + Dropout_max + 裕量（建议 ≥200mV）。注意 Dropout 随负载电流与温度增大。
- **为什么**：输入跌入 Dropout 区后输出跟随输入下降，后级可能复位/欠压；电池供电末端电压下降最容易踩坑。
- **怎么做**：电池 3.7V→3.3V 用低压差 LDO（Dropout ≤200mV@目标电流）；核算电池最低截止电压下仍满足；大电流时改 Buck 或 Buck-Boost。
- **怎么查**：datasheet 的 Dropout-负载曲线；实测最低输入下的输出；评审项：电池供电轨是否按电池截止电压核算。

### KP-CMP-056 LDO 静态电流 Iq 决定待机功耗

- **判据**：Iq 是空载时 LDO 自身消耗，常见 µA~mA 量级（低功耗型 <10µA，普通型几十~几百 µA）；电池待机产品总待机电流 ≈ Σ(Iq + 负载待机电流)。
- **为什么**：电池供电产品待机数月，Iq 从 100µA 降到 1µA 可把待机时间提升两个数量级。
- **怎么做**：电池常供轨选低 Iq LDO（并核对轻载稳定性）；不需要常供的轨用使能脚（EN）关断；注意「低 Iq」与「高 PSRR/大电流」常不可兼得。
- **怎么查**：datasheet Iq（空载、使能、关断三种状态）；实测整板待机电流；评审项：电池产品是否核算待机电流预算。

### KP-CMP-057 LDO 的 PSRR 与输出噪声要按频段看

- **判据**：PSRR 随频率下降（常见 60~70dB@1kHz、40~50dB@100kHz、高频更差）；输出噪声常见 µVrms 量级（按 datasheet）。射频/ADC/音频对电源噪声敏感，需要高 PSRR + 低噪声 LDO，并注意 PSRR 在目标频段（如 217Hz、1MHz）的值。
- **为什么**：开关电源的纹波频率（几百 kHz~数 MHz）常落在 LDO PSRR 下降区，后级 LDO 不一定能滤掉；只看 1kHz PSRR 会误判。
- **怎么做**：开关电源后接 LDO 时，选目标频段 PSRR 仍 ≥40dB 的型号；LDO 输入/输出加合适电容（注意稳定性要求）；必要时加 LC/磁珠二级滤波。
- **怎么查**：datasheet PSRR-频率曲线与噪声谱密度；实测输出纹波（示波器 + 弹簧地）；评审项：敏感负载的电源噪声是否有实测/仿真。

### KP-CMP-058 LDO 热耗计算与散热焊盘

- **判据**：P = (Vin − Vout) × Iout（忽略 Iq 时）；Tj = Ta + P × RθJA。SOT-23 的 RθJA 常见 250~350°C/W，SOT-223 约 60~100°C/W，DFN/QFN 带散热焊盘更低。目标 Tj ≤ 125°C 并留 20°C 余量。
- **为什么**：LDO 损耗全部变成热，小封装在大压差/大电流下会过热保护甚至损坏；散热焊盘与铜面积直接决定 RθJA。
- **怎么做**：示例：5V→3.3V/200mA，P=1.7V×0.2A=0.34W；SOT-23（θJA≈250°C/W）温升约 85°C，25°C 环境即 Tj≈110°C（已接近上限）→ 应改 SOT-223/DFN 或降低电流。散热焊盘要打多个过孔连到内层/底层铜，铜面积尽量大。
- **怎么查**：按 datasheet RθJA（注意测试板条件）算 Tj；实测壳温/热成像；评审项：LDO 是否有热计算；不通过则改封装/降电流/改开关电源。

### KP-CMP-059 LDO 稳定性依赖输出电容（ESR/容量），按 datasheet 选

- **判据**：多数现代 LDO 支持陶瓷输出电容（常见 1~10µF），但部分老型号要求 ESR 在特定窗口（如 0.1~10Ω）才稳定；输出电容容量/ESR 不匹配会导致振荡、输出纹波异常。输入电容同样必需（常见 1µF 以上）。
- **为什么**：LDO 内部补偿网络假设了特定负载极点，外部电容改变环路相位裕度；ESR 太低（纯陶瓷）反而可能让某些 LDO 振荡。
- **怎么做**：严格按 datasheet 的「Output Capacitor」章节选容量/介质/ESR 范围；不要随意加大或减小输出电容；需要低 ESR 时选标注「ceramic stable」的型号。
- **怎么查**：datasheet 稳定性章节与典型应用电路；上电/负载跳变示波器看是否振荡；评审项：LDO 输入/输出电容是否与 datasheet 推荐一致。

## 2. 开关电源（Buck / Boost）

### KP-CMP-060 同步与非同步 Buck 的选择

- **判据**：非同步 Buck 用外接肖特基做续流，低占空比/小电流时效率较低但成本低、无下管直通风险；同步 Buck 用内置下管 MOSFET，效率高（尤其轻载/大电流），但需要死区控制，轻载可能进入强制 PWM 或跳周期模式。
- **为什么**：非同步的续流二极管损耗 ≈ Vf×Iout×(1−D)，在 3.3V/2A 场景可占总损耗 10% 以上；同步整流的低 Rds(on) 大幅降低该损耗。
- **怎么做**：电池供电/效率敏感/电流 >0.5A 选同步 Buck；高压小电流/成本极敏感可用非同步 + 肖特基；轻载待机敏感时确认 IC 的轻载模式（PFM/强制 PWM）与 Iq。
- **怎么查**：datasheet 效率曲线（含轻载）；实测满载/轻载效率与温升；评审项：续流二极管（非同步）VRRM/If 是否核过。

### KP-CMP-061 Buck 电感按公式计算，并校核 Isat/Irms

- **判据**：L = (Vin − Vout) × Vout / (Vin × fsw × ΔI)，ΔI 取 (20%~40%)×Iout；峰值电流 I_peak = Iout + ΔI/2，必须 ≤0.8×Isat；有效电流 ≤Irms。
- **为什么**：L 过小 → 纹波大、可能进 DCM、输出纹波与 EMI 变差；L 过大 → 体积/DCR 大、瞬态响应差；Isat 不足 → 大电流下感量崩塌、掉压复位。
- **怎么做**：示例：Vin=5V、Vout=3.3V、fsw=1MHz、Iout=1A、ΔI=30%×1A=0.3A → L=(1.7×3.3)/(5×1e6×0.3)=3.74µH → 取 4.7µH 标称值（需按实际 fsw 与 IC 推荐值复核）。选屏蔽电感，DCR 计入效率预算。
- **怎么查**：对照 IC datasheet 推荐 L 范围；实测满载电感电流波形（是否饱和、是否 DCM）；评审项：电感计算书与 Isat 余量。

### KP-CMP-062 Buck 输入电容按 RMS 电流选，且要靠近 IC

- **判据**：输入电容 RMS 电流 ≈ Iout × √(D(1−D))，D=Vout/Vin；输入电容还要承受 Vin 的纹波与热插拔尖峰。陶瓷电容（X5R/X7R）负责高频，必要时并联电解/聚合物提供大容量。
- **为什么**：Buck 的脉冲输入电流全部由输入电容提供，RMS 电流超标会让电容过热/寿命骤降；布局上输入环路面积大 → EMI 与 SW 振铃严重。
- **怎么做**：示例：5V→3.3V/2A，D=0.66，I_rms=2×√(0.66×0.34)≈0.95A → 选额定纹波电流足够的电容组合。输入电容紧贴 Vin 与 PGND 引脚，SW 节点面积最小化。
- **怎么查**：电容 datasheet 的纹波电流额定（含温度/频率修正）；实测 Vin 纹波与 SW 振铃；评审项：输入电容位置与数量。

### KP-CMP-063 Buck 输出电容按纹波公式选，注意 ESR 与直流偏压

- **判据**：输出纹波 ΔVout ≈ ΔI × (ESR + 1/(8×fsw×Cout))；陶瓷电容的 ESR 很小，但直流偏压下有效容量大幅下降（见 KP-CMP-007），必须按有效容量算。负载跳变时的电压跌落由 Cout 与环路带宽共同决定。
- **为什么**：只按标称容量算纹波会低估实际纹波；输出电容不足会导致过冲/跌落触发后级复位。
- **怎么做**：先按纹波目标算 Cout，再按直流偏压曲线折算有效容量并留 1.5~2 倍余量；大电流/大跳变场景并联聚合物/电解；输出电容靠近电感与负载。
- **怎么查**：实测满载纹波与负载跳变波形；核对电容 DC bias 曲线；评审项：输出纹波是否满足后级要求（如 MCU 复位阈值）。

### KP-CMP-064 Buck 反馈电阻按 Vref 计算，走线远离 SW 节点

- **判据**：Vout = Vref × (1 + R1/R2)，Vref 由 IC 决定（常见 0.6V/0.8V/1.0V，**必须查 datasheet**，不得套用）；R1/R2 用 ±1% 电阻；FB 走线要短、远离 SW 节点与电感，FB 分压下臂接地要干净。
- **为什么**：Vref 因 IC 而异，套错会导致输出电压严重偏离；FB 是高阻节点，耦合 SW 噪声会导致输出抖动/不稳。
- **怎么做**：按 datasheet 公式与推荐阻值选 R1/R2（兼顾功耗与噪声）；FB 走线从输出电容正端取样（Kelvin 取样），不走过功率环路；下臂电阻靠近 IC 地。
- **怎么查**：实测输出电压与纹波；FB 节点示波器看是否有开关噪声耦合；评审项：Vref 是否来自 datasheet 而非经验值。

### KP-CMP-065 开关电源布局：小功率环路、单点地、散热

- **判据**：关键环路（Vin 电容 → 上管 → 电感 → 输出电容 → 地）面积最小；SW 节点铜面积小但足够载流；功率地与信号地单点连接；FB/补偿走线远离 SW；散热焊盘打足够过孔。
- **为什么**：高频 di/dt 环路是 EMI 与振铃的源头；地噪声会串入 FB 与模拟电路；散热焊盘决定实际 RθJA。
- **怎么做**：输入电容紧贴 IC；电感靠近 SW 引脚；输出电容靠近电感；SW 节点不铺大铜（减小电容耦合）；IC 底部散热焊盘多过孔连地平面。
- **怎么查**：Layout 评审：功率环路面积、SW 节点面积、FB 走线；实测 SW 振铃与辐射（近场探头）；不通过则改布局。

### KP-CMP-066 Boost 拓扑：占空比、输入电流与输出电容

- **判据**：Boost 占空比 D ≈ 1 − Vin/Vout（理想）；输入电流 Iin ≈ Iout/(1−D)，因此输入侧电流远大于输出电流；输出电容要承受较大的脉冲电流；必须限制启动浪涌与短路电流。
- **为什么**：Boost 的输入电流大、输出侧是脉冲充电，输入电感与 MOS 的电流应力高；输出短路时无法像 Buck 那样靠占空比限流（需专门保护）。
- **怎么做**：按 Iin 选电感 Isat 与 MOS 电流；输出电容按纹波与 ESR 选；加软启动/限流；3.7V→5V/2A 场景要核算输入电流（约 3A 以上）与 SOT-23 封装的散热能力。
- **怎么查**：datasheet 的电流限制、软启动、推荐外围；实测启动浪涌与满载温升；评审项：Boost 电感 Isat 是否按输入电流（非输出电流）选。

### KP-CMP-067 充电管理：CC/CV 与温度保护

- **判据**：单节锂电充电分恒流（CC）与恒压（CV）两阶段：CC 电流由检流电阻/内部设定决定（**公式按 IC datasheet**），CV 电压常见 4.2V（也有 4.35V/4.4V 高压电芯，必须与电芯规格匹配）；充电温度窗口通常 0~45°C（按电芯规格），需 NTC 检测。
- **为什么**：CV 电压高于电芯规格会过充（鼓包/起火风险）；无 NTC 在低温充电会析锂、高温充电加速老化；截止电压与电芯不匹配是硬伤。
- **怎么做**：确认电芯截止电压（4.2V vs 4.35V）与 IC 匹配；检流电阻按 datasheet 公式与精度选；NTC 贴近电芯并接到 IC 的 TS 脚；设置充电电流 ≤0.5C~1C（按电芯规格）。
- **怎么查**：实测 CC 电流、CV 电压、截止电流；高低温充电测试；评审项：IC 截止电压 vs 电芯规格是否一致；BOM 中充电 IC（IP2312-4V35 类）属项目 BOM 参考，须核验其截止电压与路径管理能力。

## 3. 外围计算、替代与常见错误

### KP-CMP-068 电源 IC 外围参数计算 SOP

1. **输入**：Vin 范围（含瞬态）、Iout(max)、效率目标、纹波/噪声要求、环境温度。
2. **拓扑与 IC**：按 Vin/Vout/电流选型，核对 Iq、fsw、限流、保护（OCP/OVP/OTP/UVLO）。
3. **电感（Buck/Boost）**：按公式算 L、I_peak、Irms，核对 Isat。
4. **输入电容**：按 RMS 电流与耐压（≥1.5~2×Vin_max）选。
5. **输出电容**：按纹波公式 + 直流偏压有效容量选。
6. **反馈/补偿**：按 Vref 算 R1/R2；按 datasheet 选补偿元件（外部补偿型）。
7. **保护/时序**：软启动、使能、PG、OVP/OCP 阈值。
8. **热**：P_loss 估算 + RθJA → Tj；必要时改封装/加铜/降额。
9. **落 BOM**：每个外围写清参数、精度、封装、核验状态。

- **判据**：以上任一步缺失（尤其电感 Isat、输入电容 RMS、热核算）即视为外围设计未完成。
- **为什么**：开关电源的失效大多来自外围：电感饱和、电容纹波电流超标、反馈算错、散热不足。
- **怎么做**：用本 SOP 做计算书留档；关键参数用最坏情况（Vin_max、Iout_max、Ta_max）。
- **怎么查**：评审项：计算书是否覆盖 9 步；实测满载/轻载/瞬态波形与温升。

### KP-CMP-069 电源 IC 替代料判断：pin-to-pin 不等于可替代

| 检查项 | 必须一致/兼容 | 不一致的后果 |
|---|---|---|
| 引脚定义 | 逐脚功能一致（含散热焊盘） | 上电即损坏/不工作 |
| 输入输出范围 | Vin/Vout 覆盖原设计 | 超出范围失效 |
| 反馈基准 Vref | 相同，或重算 R1/R2 | 输出电压错误 |
| 开关频率 fsw | 相同或外围重算 | 电感/电容不匹配、纹波变化 |
| 限流/保护阈值 | 满足负载需求 | 误触发或失去保护 |
| 软启动/时序 | 满足上电要求 | 浪涌/时序冲突 |
| 外围元件要求 | 电感/电容/补偿兼容 | 不稳定/纹波超标 |
| 封装/散热 | 焊盘与 RθJA 满足 | 过热 |

- **判据**：8 项全部通过才可判定「可直接替代」；任一项需改外围则必须重做计算与验证。
- **为什么**：同封装同功能的电源 IC 内部架构可能完全不同（同步/非同步、补偿方式、保护阈值），pin-to-pin 只是必要条件。
- **怎么做**：建立替代料对比表，逐项填原型号/替代型号；替代后必须重跑外围计算与实测（效率、纹波、温升、瞬态）。
- **怎么查**：Librarian 三源核验（EDA 库/供应商/datasheet）核对引脚与参数；评审项：替代料是否逐项比对并留验证记录。

### KP-CMP-070 多路电源的上电时序与电源树复核

- **判据**：多轨系统要定义上电/下电顺序（如核心电压先于 IO、模拟晚于数字），并核对：使能链、PG 信号、复位释放时刻、浪涌电流总和、电池/USB 切换。
- **为什么**：时序错误会导致 IO 倒灌、闩锁、MCU 启动异常；多路同时上电的浪涌可能触发适配器过流保护。
- **怎么做**：用 EN/PG 做时序链或选带时序控制的 PMIC；每轨加软启动；明确「谁先谁后、间隔多久」并写进设计说明；USB 插入/拔出切换要有路径管理。
- **怎么查**：示波器多通道测上电时序；评审项：电源树是否标注时序与 PG；不通过则加时序控制。

### KP-CMP-071 电源设计常见错误清单

| # | 错误 | 后果 | 纠正 |
|---|---|---|---|
| 1 | LDO 不做热核算，SOT-23 跑大压差大电流 | 过热保护/损坏 | 算 Tj，改封装或改 Buck |
| 2 | LDO 输出电容不按 datasheet 选 | 振荡/纹波异常 | 按稳定性章节选容量/ESR |
| 3 | Buck 电感只看感值不看 Isat | 大电流掉压复位 | I_peak ≤0.8×Isat |
| 4 | 输入电容 RMS 电流不足 | 电容过热、寿命骤降 | 按 Iout√(D(1−D)) 选 |
| 5 | 反馈 Vref 套用经验值 | 输出电压错误 | 查 datasheet Vref |
| 6 | FB 走线穿过 SW 节点 | 输出抖动/不稳 | FB 远离功率环路、Kelvin 取样 |
| 7 | 输出电容按标称容量算纹波 | 纹波超标 | 按直流偏压有效容量算 |
| 8 | Boost 电感按输出电流选 | 电感饱和 | 按输入电流 Iout/(1−D) 选 |
| 9 | 充电 IC 截止电压与电芯不匹配 | 过充/充不满 | 核对 4.2V/4.35V 规格 |
| 10 | 充电无 NTC/温度保护 | 低温析锂、高温老化 | 加 NTC 与温度窗口 |
| 11 | 替代料只看 pin-to-pin | 效率/纹波/保护异常 | 逐项比对 + 重做外围与实测 |
| 12 | 多路上电无时序 | IO 倒灌/闩锁 | 加 EN/PG 时序链 |

- **判据**：任一项存在即判为电源设计缺陷。
- **为什么**：电源是板级失效的第一大来源，且多数问题可在原理图阶段算出来。
- **怎么做**：并入电源评审门禁；每路电源做「热/纹波/瞬态/保护」四项实测。
- **怎么查**：评审记录 + 实测报告；关键轨做满载老化。
