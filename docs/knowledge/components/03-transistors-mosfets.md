# 三极管 / MOSFET 开关与驱动知识

> **一句话结论**：三极管开关按「Ic → Ib = Ic/hFE(min) × 过驱动倍数」算基极电阻并保证饱和；MOSFET 按「Vgs 驱动电压 → Rds(on)@实际 Vgs → Qg/Qgd → 热」四步选型，任何开关管都必须核对 Vgs 绝对最大额定、SOT-23 引脚定义与体二极管方向。

- **适用阶段**：原理图 → 选型 → BOM → Layout（散热/栅极回路）。
- **可信等级**：本文为 `reference` 参考知识，数值为通用工程经验/常见规格量级；具体 MPN 必须回读 datasheet，器件身份与引脚均**需 Librarian 三源核验（EDA 库 / 供应商 / datasheet）**。
- **严禁**：不得编造某器件的 Rds(on)、Vgs(th)、引脚顺序；SOT-23 引脚定义**因器件而异**，必须逐一核对（见 KP-CMP-050）。

## 1. 双极型三极管（BJT）

### KP-CMP-037 三极管开关：基极电阻按 Ib = Ic / hFE(min) 计算

- **判据**：集电极电流 Ic 由负载决定；基极电流 Ib 必须满足 Ib ≥ Ic / hFE(min)，且为可靠饱和取过驱动倍数 K=5~10（即 Ib ≥ K × Ic / hFE(min)）。基极电阻 Rb = (V_drive − Vbe) / Ib，Vbe 取 0.7V（硅管，按 datasheet）。
- **为什么**：hFE 是范围值且随温度/电流下降，按典型值算会让三极管工作在放大区，Vce 升高、功耗增大、输出电平不稳。
- **怎么做**：示例（需代入实际器件参数）：Ic=100mA、hFE(min)=100、K=5 → Ib=5mA；V_drive=3.3V → Rb=(3.3−0.7)/5mA=520Ω → 取 470Ω 或 510Ω 标称值。MCU GPIO 输出电流要 ≥ Ib 并留余量。
- **怎么查**：核对 hFE(min) 而非典型值；实测饱和时 Vce(sat) 与 Vbe；评审项：每只开关三极管是否给出 Ib/Ic 计算。

### KP-CMP-038 三极管饱和压降与「深度饱和」的代价

- **判据**：饱和压降 Vce(sat) 常见 0.05~0.3V（小信号管，按 Ic 与 datasheet），深度饱和可低至几十 mV；但过驱动倍数过大会延长关断时间（存储时间），高频开关场景需折中。
- **为什么**：Vce(sat) 直接决定导通损耗 P=Vce(sat)×Ic；过驱动提高饱和深度却降低开关速度。
- **怎么做**：低频开关（按键、继电器、LED、负载开关）用 K=5~10；高频 PWM 场合用 K=3~5 并核对开关时间；大电流优先 MOSFET 而非 BJT。
- **怎么查**：datasheet 的 Vce(sat)-Ic 曲线与开关时间；实测满载 Vce；P 超过封装能力时换 MOSFET。

### KP-CMP-039 三极管功耗与结温核算

- **判据**：总功耗 P = Vce(sat)×Ic×D + Vbe×Ib（D 为占空比）；结温 Tj = Ta + P×RθJA。SOT-23 的 RθJA 常见 250~350°C/W，允许功耗通常只有几百 mW 量级（按 datasheet 降额）。
- **为什么**：三极管在放大区/半饱和区功耗急剧上升，热失效是最常见故障；SOT-23 塑封散热能力很有限。
- **怎么做**：开关应用确保工作在饱和区；负载电流 >0.3A 或环境温度高时改 MOSFET/SOT-223/TO-252；必要时加铜箔散热。
- **怎么查**：P×RθJA 估算 Tj（目标 ≤ 125°C，留 20°C 余量）；实测壳温；评审项：大电流三极管是否做过热核算。

### KP-CMP-040 三极管用于线性放大/射极跟随器的偏置要点

- **判据**：共射放大需设置静态工作点（分压偏置 + 发射极电阻负反馈）；射极跟随器增益≈1，输出比输入低 Vbe≈0.7V，适合缓冲/驱动；小信号管 fT 常见 100~300MHz 量级（按 datasheet）。
- **为什么**：没有直流偏置或偏置不稳会导致削顶/截止失真；射随器输出摆幅受限，无法轨到轨。
- **怎么做**：分压偏置电流取 5~10×Ib；发射极电阻提供直流负反馈稳定工作点；需要轨到轨时用 CMOS 运放或 MOSFET。
- **怎么查**：直流工作点仿真/实测；温漂与失真测试；评审项：线性放大级是否标注静态工作点。

## 2. MOSFET 参数与开关

### KP-CMP-041 Vgs(th) 不是「导通电压」，必须看测试条件与驱动电压

- **判据**：Vgs(th)（阈值电压）是「刚开始导通」的电压，通常定义在 Id=250µA 等微小电流下；**Rds(on) 是在规定 Vgs（如 4.5V/10V）下测的**。逻辑电平 MOSFET 的 Rds(on) 会在 Vgs=2.5V 或 4.5V 下给出规格。Vgs(th) 典型 0.5~4V，还带容差与负温度系数（高温更低，易误导通）。
- **为什么**：只看 Vgs(th) 会误以为「3.3V 能开」；实际要保证 Vgs 达到 Rds(on) 规格点并留余量，否则工作在线性区、发热严重。高温下 Vgs(th) 下降还可能造成误导通。
- **怎么做**：3.3V GPIO 驱动必须选「逻辑电平（logic-level）」且 datasheet 给出 Vgs=2.5V/3.3V 下 Rds(on) 的器件；12V 驱动可用标准 MOSFET（Vgs=10V 规格）；栅极驱动电压 ≥ 规格点 +1V 余量。
- **怎么查**：datasheet 的 Rds(on) 测试条件表；高温 Vgs(th) 曲线；评审项：3.3V 直驱的 MOSFET 是否有 2.5V/3.3V 规格。

### KP-CMP-042 Rds(on) 随温度与驱动电压上升，热设计按最坏值

- **判据**：Rds(on) 有正温度系数，常见 +0.5%~+1%/°C，125°C 时约为 25°C 的 1.5~2 倍（按 datasheet 曲线）；驱动电压越低 Rds(on) 越大。导通损耗 P = I²×Rds(on)(Tj)。
- **为什么**：用 25°C 的 Rds(on) 算损耗会低估 1 倍以上，导致热设计不足；正温度系数虽有利于并联均流，但会让温升正反馈。
- **怎么做**：按 Tj=100~125°C 的 Rds(on) 计算损耗；大电流/高占空比留 2 倍热余量；多管并联时按均流与热耦合评估。
- **怎么查**：datasheet 的 Rds(on)-Tj 归一化曲线；实测满载壳温；评审项：MOSFET 热计算是否使用高温 Rds(on)。

### KP-CMP-043 栅极电荷 Qg 决定驱动损耗与驱动能力需求

- **判据**：驱动损耗 P_gate = Qg × Vgs × fsw；驱动电路的平均电流 I_g = Qg × fsw；峰值电流受栅极电阻限制 I_peak ≈ Vgs/Rg。高频/大 Qg 器件需要更强驱动（专用驱动 IC 或推挽三极管）。
- **为什么**：Qg 大的 MOSFET 在 MCU GPIO 直驱、高频 PWM 时会导致开关变慢（损耗转移为热）、驱动波形塌陷。
- **怎么做**：低频开关（<1kHz）可 GPIO 直驱小 Qg 管；>20kHz 或 Qg>20nC 建议用驱动 IC；栅极电阻在速度与 EMI 之间折中（常见 10~100Ω）。
- **怎么查**：核对 Qg（含 Qgd）、Vgs、fsw 算驱动损耗；示波器看栅极波形上升/下降时间；评审项：高频 PWM 是否用驱动 IC。

### KP-CMP-044 米勒平台与 Qgd：开关损耗的真正瓶颈

- **判据**：MOSFET 开通时 Vgs 先升到 Vgs(th)，然后进入「米勒平台」——Vgs 基本不变、Vds 快速下降，期间由 Qgd（米勒电荷）决定；开关损耗近似 P_sw ≈ 0.5 × Vds × Id × (t_on + t_off) × fsw，t ∝ Qgd / I_gate。
- **为什么**：米勒平台期间器件同时有高压与大电流，是损耗与发热最集中的阶段；Qgd 大 → 开关慢 → 损耗大；米勒电容还会通过栅极电阻与驱动形成寄生振荡。
- **怎么做**：高频/大电流优先低 Qgd、低 Crss 器件；用足够大的驱动电流缩短平台时间；栅极电阻与驱动回路尽量短；必要时加负压关断或有源钳位（专业拓扑）。
- **怎么查**：datasheet 的 Qgd/Crss 与开关波形；示波器测 Vgs/Vds 交叠面积；热成像定位热点；评审项：高频开关损耗估算是否有依据。

### KP-CMP-045 低边开关与高边开关的拓扑选择

| 拓扑 | 器件 | 优点 | 缺点/代价 |
|---|---|---|---|
| 低边开关 | N-MOS（源极接地） | 驱动简单（Vgs 以地为参考）、Rds(on) 低 | 负载不共地，输出侧仍带电位；不适用于共地负载 |
| 高边开关（P-MOS） | P-MOS（源极接电源） | 负载共地、驱动简单（栅极拉低导通） | Rds(on) 通常高于同规格 N-MOS，Vgs 摆幅受电源限制 |
| 高边开关（N-MOS） | N-MOS + 自举/电荷泵 | Rds(on) 最低、成本低 | 需要高于 Vin 的栅极电压（自举/驱动 IC），不能 100% 占空比直驱 |
| 负载开关 IC | 集成 | 带软启动/限流/保护 | 成本略高、需选型核验 |

- **判据**：负载必须共地 → 高边；允许负载浮地 → 低边；输入电压高/电流大 → N-MOS 高边 + 驱动 IC；简单小电流 → P-MOS 高边。
- **为什么**：N-MOS 高边需要栅压高于电源（Vgs=Vgate−Vsource），没有自举就无法持续导通；P-MOS 虽然简单但导通电阻与成本随电流上升。
- **怎么做**：电池 3.7~5V 小电流负载用 P-MOS 高边；12V/大电流用 N-MOS + 驱动 IC/自举；明确标注「高边/低边」与栅极参考点。
- **怎么查**：评审项：高边 N-MOS 是否有自举/驱动电路；P-MOS 栅极是否有上拉（默认关断）；不通过则改拓扑。

### KP-CMP-046 栅极电阻与下拉电阻：默认态与开关速度

- **判据**：栅极串阻 Rg 常见 10~100Ω（抑制振铃/EMI、限制驱动峰值电流）；栅极必须有确定默认态：N-MOS 低边加 10k~100k 下拉到地；P-MOS 高边加 10k~100k 上拉到源极。MCU 复位/上电期间引脚高阻，若无下拉/上拉，MOSFET 可能误导通。
- **为什么**：栅极是高阻节点，浮空会受漏电/耦合影响；上电瞬间误导通可能烧负载或造成危险动作。Rg 太小导致振铃与 EMI，太大导致开关损耗。
- **怎么做**：下拉/上拉电阻靠近栅极放置；Rg 与下拉组成分压时要核算实际 Vgs（下拉会分掉驱动电压）；大功率/高频场合用专用驱动 IC 并保留 Rg 位置（可 NC/贴片调整）。
- **怎么查**：评审项：每只 MOSFET 栅极是否有默认态电阻；上电时序/复位期间实测栅极电压；不通过则补电阻。

### KP-CMP-047 体二极管方向与用途（含反接/续流）

- **判据**：N-MOS 体二极管由源极（阳极）指向漏极（阴极），即 S→D 导通；P-MOS 由漏极（阳极）指向源极（阴极），即 D→S 导通。体二极管可做续流/钳位/反接路径，但 Vf 较高（0.7~1.2V）、恢复慢，不能当低损耗整流管。
- **为什么**：体二极管是结构固有的，无法去除；方向接错（如把 N-MOS 当高边防反接）会导致体二极管直接导通，防反接失效。
- **怎么做**：感性负载（继电器/电机/电磁阀）必须加续流二极管或利用低边 N-MOS 体二极管（注意体二极管只能吸收负向续流）；反接保护优先 P-MOS（源极接输入）或专用理想二极管。
- **怎么查**：评审项：感性负载是否有续流通路；反接保护器件方向是否正确；实测反接时电流；不通过则改电路。

### KP-CMP-048 P-MOS 反接保护：方向、Vgs 与栅极钳位

- **判据**：P-MOS 防反接的标准接法：**源极接输入电源正、漏极接负载、栅极经电阻下拉到地**（并常加齐纳/分压限制 |Vgs|）。正常上电时体二极管先导通，栅极被拉低后沟道导通，压降降为 I×Rds(on)；反接时 Vgs≈0 关断。
- **为什么**：这是利用体二极管「先导后短」的自举式接法；若把源漏接反，体二极管方向错误，防反接失效甚至直通。
- **怎么做**：核对 |Vgs| 绝对最大额定（电池 4.2V 时栅极对源约 −4.2V，通常 ±12V/±20V 器件安全，但 24V 系统必须加分压/齐纳）；栅极电阻 10k~100k；大电流核对 Rds(on) 与热。
- **怎么查**：反接测试（限流电源）+ 正常上电测试；核对器件 Vgs 额定与体二极管方向；项目 BOM 中 P-MOS 防反接件（FDZ451PZ）属项目 BOM 参考，待核验。

### KP-CMP-049 SOA（安全工作区）与热：脉冲/容性/热插拔场景必查

- **判据**：SOA 曲线给出不同脉宽下允许的 Vds-Id 组合；热插拔、容性负载上电、电机堵转、短路保护等**脉冲大电流**场景必须核对 SOA，而不只看 Rds(on) 与 Id 额定。SOA 随温度降额，且高频开关有「开关 SOA」限制。
- **为什么**：Id 额定是封装/结温限制的连续电流，不代表能承受短时大电流；超出 SOA 会发生热失控/二次击穿。
- **怎么做**：热插拔/软启动加限流（电阻/NTC/负载开关）；容性负载按 I_peak=C×dV/dt 与脉宽核对 SOA；电机/继电器负载加续流与 TVS；必要时选更大 SOA 或加保护。
- **怎么查**：datasheet SOA 曲线（注意温度与脉宽条件）；实测启动/堵转电流波形；评审项：脉冲负载是否核对 SOA。

### KP-CMP-050 SOT-23 引脚定义不统一，必须逐器件核对

- **判据**：SOT-23 只是**封装**，内部引脚定义由器件决定：常见三极管为 1=B/2=E/3=C，常见 N-MOS 为 1=G/2=S/3=D，但也有 1=B/2=C/3=E、1=G/2=D/3=S 等变体；同封装不同厂/不同系列可能不同。**不得按封装名推断引脚。**
- **为什么**：原理图符号与 PCB 封装若按错误引脚映射，轻则不工作，重则上电直通烧板（例如把 D/S 接反，体二极管直接导通）。
- **怎么做**：每个器件以 datasheet 的 Pin Configuration 为准，核对 EDA 库符号与封装；SOT-23 封装库必须按器件核对 pin map；高风险器件在原理图上标注引脚序号。
- **怎么查**：Librarian 三源核验（EDA 库 / 供应商 / datasheet）核对 pin map；首件用万用表二极管档验证体二极管方向；评审项：SOT-23 器件是否逐个核对引脚；不通过不得投产。

### KP-CMP-051 封装热阻 RθJA 与散热设计

- **判据**：常见 RθJA 量级（按 datasheet，与铜面积/层数强相关）：SOT-23 ≈ 250~350°C/W，SOT-223 ≈ 60~100°C/W，SOT-89 ≈ 80~150°C/W，TO-252/DPAK ≈ 40~100°C/W，QFN 带散热焊盘 ≈ 30~60°C/W。散热焊盘/大铜箔可显著降低 RθJA。
- **为什么**：小封装散热能力决定实际可用电流；同样的 Rds(on)，SOT-23 与 TO-252 的持续电流能力可能差数倍。
- **怎么做**：按 Tj = Ta + P×RθJA 估算（目标 Tj ≤ 125°C 且留 20°C 余量）；SOT-223/QFN 的散热焊盘必须打足够过孔连到内层/底层铜；避免散热焊盘只连小铜皮。
- **怎么查**：datasheet 的 RθJA（注意测试板条件）与降额曲线；热成像/热电偶实测；评审项：功率器件是否有热计算与散热铜箔。

### KP-CMP-052 三极管/MOSFET 选型参数表（按用途查）

| 用途 | 关键参数 | 典型量级（按 datasheet） | 备注 |
|---|---|---|---|
| 小信号开关（LED/继电器） | Ic、Vceo、hFE(min) | Ic 100mA~500mA，Vceo 40~60V，hFE 100~300 | SOT-23 常见 |
| 低边 N-MOS 开关（<2A） | Vds、Rds(on)@4.5V、Qg、Vgs(th) | Vds 30~60V，Rds(on) 20~100mΩ | 逻辑电平 |
| 低边 N-MOS 大电流（>5A） | Rds(on)@10V、Id、SOA、RθJA | Rds(on) 2~20mΩ | 需驱动 IC + 散热 |
| 高边 P-MOS 防反接 | Vgs 额定、Rds(on)@Vgs=−4.5V、体二极管 | Vds −20~−40V | 源极接输入 |
| 高边 N-MOS + 自举 | 驱动 IC 匹配、Qg、Vds | — | 不能 100% 占空比 |
| 高频 PWM | Qgd、Crss、Qg | Qg 单位 nC | 驱动能力优先 |

- **判据**：选型表必须同时覆盖「电压/电流/驱动/热」四个维度，任一维度缺失即不完整。
- **为什么**：MOSFET 参数互相牵制（低 Rds(on) 常伴随大 Qg/大封装），只看单项会选错。
- **怎么做**：先按用途定拓扑，再定 Vds/Id/Rds(on)，再按驱动电压与 fsw 定 Qg/Qgd，最后按热与封装收口。
- **怎么查**：选型对比表 + datasheet 参数核对；评审项：是否列出替代料并逐参数比对。

### KP-CMP-053 三极管/MOSFET 常见错误清单

| # | 错误 | 后果 | 纠正 |
|---|---|---|---|
| 1 | 按 Vgs(th) 判断「3.3V 能开」 | 工作在线性区、发热烧管 | 看 Rds(on)@2.5V/3.3V 规格 |
| 2 | 用 25°C 的 Rds(on) 算损耗 | 热设计不足 | 按 Tj=100~125°C 值算 |
| 3 | 栅极悬空/无下拉 | 上电误导通、误动作 | N-MOS 下拉 10k~100k |
| 4 | SOT-23 引脚按经验接 | 不工作或直通烧板 | 逐器件核对 datasheet pin map |
| 5 | P-MOS 防反接源漏接反 | 防反接失效/体二极管直通 | 源极接输入、栅极下拉 |
| 6 | 高边 N-MOS 无自举/驱动 | 无法导通或只能体二极管工作 | 加自举/驱动 IC 或改 P-MOS |
| 7 | 感性负载无续流 | 关断尖峰击穿 | 加续流二极管/TVS |
| 8 | 只看 Id 额定不看 SOA | 热插拔/堵转时损坏 | 按脉冲场景核对 SOA |
| 9 | 高频 PWM 用 GPIO 直驱大 Qg 管 | 开关损耗大、驱动塌陷 | 加驱动 IC |
| 10 | Rg 取 0Ω 或过大 | 振铃/EMI 或开关损耗 | 10~100Ω 折中并留调整位 |
| 11 | 基极电阻按 hFE 典型值算 | 不饱和、发热 | 按 hFE(min) × 过驱动 5~10 算 |

- **判据**：任一项存在即判为开关管设计缺陷。
- **为什么**：以上均为可复现的实战失效模式，且多数是「参数没按条件看」导致。
- **怎么做**：并入选型评审门禁；关键开关管做「参数条件 + 引脚 + 热」三查。
- **怎么查**：评审记录 + 首件实测（栅极波形、Vgs、壳温、体二极管方向）。
