# 供应链与元件生命周期管理（EOL / PCN / NRND / 双供 / 替代料 / 假货 / 批次追溯）

> **一句话结论**：供应链风险不是采购阶段才出现的问题，而是**设计阶段就要显性化的架构约束**：每个 BOM 行都要有生命周期状态与来源、关键器件要有经批准的替代料/双供、替代料要逐项参数比对并验证、来料要有批次追溯与渠道合规；任何一项靠“到时候再说”，量产时就会以停线、改板、批量早期失效的形式付出更高代价。

- **适用阶段**：选型 → 原理图冻结 → BOM 定版 → 采购/备料 → 量产维持 → 停产/切换。
- **适用对象**：BOM 全量器件，重点为 MCU、电源 IC、连接器、晶振、认证/安规相关件、长交期件与单点件。
- **可信等级**：本文为 `reference` 参考知识。流程时限、行业标准（JEDEC JESD46/JESD48 等）、AQL 抽样与统计公式**必须按公司流程与标准原文复核**；文中“常见 X 天/常见百分比”只是工程经验量级。
- **严禁**：不得编造 LCSC 料号、厂商型号、交期、价格、批次或 EOL 日期；不得把本文“常见做法”当作某颗料号的实际状态；具体器件状态必须回读原厂/授权代理页面与 PCN 原文。

---

## 1. 生命周期状态与预警

### KP-CMP-176 元件生命周期状态机：Active → NRND → LTB → EOL/Obsolete

- **判据**：每个 BOM 行必须标注生命周期五态之一（Active / NRND / LTB / EOL / Obsolete），并记录**来源（原厂/授权代理/PCN）、采集日期、复核人**；只写“Active”而不带日期与来源，视为未维护。
- **为什么**：NRND（不推荐新设计）与 LTB（最后采购）是两个不可逆的时间窗口；错过 LTB 后只能改板或走灰色渠道，成本与假货风险成倍上升。
- **怎么做**：BOM 增加 `lifecycleStatus / lifecycleSource / lifecycleCheckedAt / owner` 字段；关键器件按月扫、全 BOM 按季度扫；状态变化触发替代料评审与风险登记。
- **怎么查**：核对原厂/授权代理生命周期页面与 PCN 数据库；检查 BOM 字段完整率与数据新鲜度；抽查高风险器件状态是否与库存/交期矛盾。
- **依据**：JEDEC JESD48（产品停产/最后采购通知）与供应商 PCN/PDN 流程；具体时限与状态定义按原厂文件复核。

### KP-CMP-177 PCN 变更影响评估：不是所有 PCN 都一样

- **判据**：收到 PCN 后必须在流程时限内完成分类与影响评估：①工艺/晶圆厂/封装厂变更（可能影响参数、可靠性、EMC）；②料号/封装变更（需重新建库、核验、试贴）；③仅文档/标签变更（低风险）。凡涉及电气、封装、认证的变更，必须有重新验证记录。
- **为什么**：同一料号不同批次的晶圆/封装来源可能不同，参数漂移会导致量产一致性与认证失效；忽略 PCN 是“突然批量不良”的常见根因。
- **怎么做**：建 PCN 台账（料号/日期/变更类型/影响面/结论/负责人）；高风险变更做样机对比与温循；更新库、BOM 备注与测试规范；合同要求时通知客户。
- **怎么查**：PCN 邮件/门户订阅覆盖；台账闭环率；变更前后关键参数对比报告；认证是否需要重测的判定记录。
- **依据**：JEDEC JESD46（产品/工艺变更通知）；车规/医疗等行业另按客户 PPAP/变更审批要求复核。

### KP-CMP-178 LTB 与安全库存：最后一次采购要覆盖“剩余生命周期需求”

- **判据**：LTB 前必须算清 `LTB 数量 = 剩余生产需求 + 安全库存 + 替代验证期用量`，并受 MOQ/MPQ、保质期、湿敏等级（MSL）、存储条件与资金约束；决策需计划/采购/研发/财务会签。
- **为什么**：LTB 是单向门——买少了断供，买多了呆滞；长期库存还要面对存储期与湿度等级限制。
- **怎么做**：用滚动预测 + 产品寿命末期需求估算；库存分账（专用料）；按 MSL/保质期制定存储与烘烤规范；同步推进替代料验证。
- **怎么查**：LTB 审批与计算表；库存与预测对比；保质期/超期料台账；呆滞料统计。
- **依据**：JESD48（停产通知）+ 公司供应链流程；MSL 按 J-STD-020/J-STD-033（按标准原文复核）。

### KP-CMP-179 生命周期风险分级：按“不可替代性 × 用量 × 交期 × 认证依赖”排序

- **判据**：风险分级至少纳入：是否单点、年用量、交期及波动、生命周期状态、是否涉及认证/安规、是否有已批准替代料；高风险器件必须有缓解措施（双供/库存/已批准替代/设计可改）。
- **为什么**：对所有器件平均用力会漏掉真正的单点；高风险器件断供会直接停线或迫使改板。
- **怎么做**：BOM 风险矩阵（A/B/C 级）；季度评审并进入项目风险登记册；高风险项指定责任人与关闭判据。
- **怎么查**：风险矩阵覆盖率；单点清单是否清零或带风险批准；替代料批准状态与库存覆盖期。
- **依据**：公司供应链风险管理流程；可参考 ISO 31000 风险方法论（按组织采用情况复核）。

## 2. 双供与替代料

### KP-CMP-180 双供准入：pin-to-pin 只是入场券

- **判据**：双供必须同时满足：封装/pin map 一致（或已明确改板方案）、电气参数在容差内、温度等级/精度/寿命/认证一致、供货可持续、价格可接受；**“pin-to-pin”不等于“可替换”**。
- **为什么**：参数差异（ESR、CTR、精度、温漂、饱和电流）会让电路在边界工况失效；安规/车规件的换料可能触发重新认证。
- **怎么做**：双供清单 + 参数对比表；样机与边界工况验证；PCN 同步监控；BOM 标明首选/备选与切换条件。
- **怎么查**：参数比对表逐项有 datasheet 页码；替代料验证记录；小批良率与一致性对比；认证影响评估。
- **依据**：器件 datasheet 与行业参数定义；认证要求按产品适用标准复核（不得凭经验判定“认证不受影响”）。

### KP-CMP-181 替代料 7 项比对：电气 / 封装 / 温度 / 精度 / 寿命 / 认证 / 供货

- **判据**：替代料至少逐项比对并留证据：①电气（电压/电流/阻容感/频率/增益/漏电）；②封装与焊盘；③工作与存储温度；④精度/容差/温漂；⑤寿命/可靠性（MSL、寿命曲线、失效率）；⑥认证（安规/车规/RoHS/REACH）；⑦供货（生命周期/交期/MOQ/价格）。差异项必须标“需验证/不可替代”。
- **为什么**：只比封装会买到“装得上但性能不达标”的料；漏认证项会让整机认证失效，代价远高于料价差。
- **怎么做**：统一比对模板（含 datasheet 页码/版本）；硬件负责人签核；差异项转验证任务；结论写入 BOM 与替代料库。
- **怎么查**：比对表完整率；差异项验证报告；Librarian 三源核验结果；抽检替代料批次一致性。
- **依据**：各器件 datasheet 与产品适用标准；比对项来自工程实践，具体阈值按项目规格书确认。

### KP-CMP-182 替代料验证流程：样机 → 小批 → 量产三阶段

- **判据**：替代料必须经过：①样机功能/性能/边界测试；②小批（数量按项目规模与风险定）一致性与良率验证；③量产切换评审。每阶段有明确通过判据与记录，禁止“实验室通过就直接上线”。
- **为什么**：实验室通过不代表批量、温循、长期可靠；切换阶段混料风险最高，必须有批次隔离与追溯。
- **怎么做**：定义验证矩阵（功能/边界/温循/EMC/寿命按需）；小批对比关键指标与直通率；切换时旧料新料分批、工单标注；必要时客户通知。
- **怎么查**：三阶段验证报告；小批良率/失效率对比；切换批次追溯记录；混料检查。
- **依据**：公司变更管理/ECN 流程；可靠性试验项按产品标准与客户要求复核。

### KP-CMP-183 单点失效识别：BOM 里“只有一个来源”的器件必须显性化

- **判据**：每个 BOM 行标注 `sourceCount`（可用合格来源数）与 `singlePoint` 标志；单点器件（尤其长交期、NRND、认证件）必须有缓解措施：安全库存/已批准替代/设计可改方案。
- **为什么**：单点不是单纯采购问题，而是设计阶段的架构风险；越晚发现，改板与认证成本越高。
- **怎么做**：设计阶段就引入双供；无法双供的做最后采购/库存计划并写入风险登记；每季度复审单点清单。
- **怎么查**：单点清单与缓解措施闭环；AVL 中合格来源数；替代料批准状态。
- **依据**：公司 AVL/供应链风险管理流程；单点定义按项目风险准则确认。

### KP-CMP-184 BOM 替代料字段与“禁用替代”规则

- **判据**：BOM 必须区分：`首选料 / 已批准替代 / 仅库存替代（不再采购）/ 禁止替代`；禁止替代项要写原因（认证、参数边界、机械干涉、客户指定）；替代关系必须双向可查。
- **为什么**：没有“禁止替代”标记时，采购/产线可能用“看起来一样”的料替换，导致认证失效或边界故障。
- **怎么做**：BOM 模板增加替代字段与批准人；替代关系进 PLM/ERP；变更时同步更新；关键客户项目单独锁定。
- **怎么查**：字段完整率；替代关系与实际发料一致性抽查；禁用项是否被误用。
- **依据**：公司 BOM/变更管理规范；客户合同/认证约束按项目文件复核。

## 3. 交期、成本、库存与批次

### KP-CMP-185 交期与排期：长交期器件必须前置锁定

- **判据**：交期接近或超过项目硬件周期的器件，必须在原理图冻结前锁定渠道/预留产能；交期数据必须带**供应商、日期、数量档位**，不能凭记忆或旧报价。
- **为什么**：电源 IC、MCU、连接器交期波动会直接拖垮样机与量产节点；没有日期的交期数据不可用于排期决策。
- **怎么做**：关键器件 early buy/预留；备选渠道与替代料并行；排期留缓冲（按历史波动估算）；与采购建立周同步。
- **怎么查**：交期台账新鲜度；关键路径评审；到货 vs 计划偏差；缺料预警记录。
- **依据**：公司计划/采购流程；交期本身随市场波动，必须实时复核，不得引用本文作为数据来源。

### KP-CMP-186 成本模型：单价 ≠ 总成本

- **判据**：选型成本应按 TCO 评估：单价 + MOQ/MPQ 摊薄 + 贴装/加工难度 + 测试/返修 + 库存占用 + 停产/替代风险成本；批量价必须按实际用量档位询价。
- **为什么**：低价料可能 MOQ 高、贴片难、良率低；停产料后期溢价与改板成本远超当初节省的料价。
- **怎么做**：做 TCO 对比表；小批量阶段优先可焊性好的封装；与采购/工艺联合评审；关键料评估“第二来源溢价”是否值得。
- **怎么查**：TCO 表与实际 BOM 成本对比；呆滞/返修成本统计；替代料总成本复盘。
- **依据**：公司成本核算口径；加工/测试成本按工厂报价复核。

### KP-CMP-187 安全库存与缓冲：按交期波动与需求波动定

- **判据**：安全库存可按统计法估算，如 `SS ≈ Z × √(LT × σd² + d² × σLT²)`（Z 为服务水平系数，σd 为需求标准差，σLT 为交期标准差；按实际分布与公司口径复核），并受保质期/MSL/资金约束；关键器件缓冲高于通用件。
- **为什么**：交期波动与需求波动叠加会造成缺料；库存过高又带来呆滞与过期。
- **怎么做**：A/B/C 分级库存策略；关键器件寄售/VMI；定期复盘服务水平与缺料率；按项目阶段调整。
- **怎么查**：缺料率、呆滞率、库存周转；超期料处理记录；服务水平达成。
- **依据**：库存管理通用统计方法；公式与参数按公司计划口径复核，不得直接套用。

### KP-CMP-188 批次与日期码追溯：出问题要能圈定范围

- **判据**：关键器件（电源/MCU/连接器/安规件）必须记录 lot/date code/供应商；BOM、工单、测试记录能关联到批次；追溯链可从成品 SN 正查到原料，也可从原料反查到成品。
- **为什么**：批次性不良（晶圆、封装、材料、假货）需要精确圈定，否则要么全批召回、要么无法定位根因。
- **怎么做**：来料标签保留并录入；MES/工单记录批次；首件与关键测试关联 SN；客诉/失效分析按批次取样。
- **怎么查**：做追溯演练（随机取成品查到来料批次并反查）；批次不良率统计；标签一致性抽查。
- **依据**：IATF 16949/ISO 9001 追溯要求（按组织认证范围复核）；电子行业批次追溯通用实践。

### KP-CMP-189 假货与灰色渠道：来源比外观更重要

- **判据**：只从原厂/授权代理/可信目录商采购；灰色渠道来料必须做真伪鉴别（外观与丝印、日期码与批次一致性、X-ray、开盖、电参数曲线、温度特性），**关键器件禁止灰色渠道**。
- **为什么**：翻新、打磨、改标料在温循与长期可靠性上不可控，可能批量早期失效，且失效分析难以定位。
- **怎么做**：AVL 管理；来料抽检加严；关键料做 X-ray/开盖；异常批次隔离并追溯供应商；建立假货案例库。
- **怎么查**：采购渠道审计；真伪鉴别报告；失效率与渠道对比；供应商纠正措施（8D）。
- **依据**：IDEA-STD-1010 等元器件真伪鉴别方法（按标准原文复核）；公司采购合规制度。

### KP-CMP-190 来料检验（IQC）与 AQL 抽检

- **判据**：按 GB/T 2828.1（等同 ISO 2859-1）选择抽样方案与 AQL；关键器件设加严或全检项（连接器尺寸/极性、日期码、外观、包装标签）；检验项目与判据必须写入 IQC 规范。
- **为什么**：批次混料、错料、外观缺陷是产线不良的前置来源；只靠产线发现，返工成本更高。
- **怎么做**：IQC 规范（抽样方案/项目/判据/记录）；首件确认；异常批次隔离并反馈供应商；关键料加做电参数抽测。
- **怎么查**：IQC 记录与 DPPM；供应商 8D 闭环；错料拦截案例复盘。
- **依据**：GB/T 2828.1 / ISO 2859-1 抽样标准（按标准原文与公司 AQL 设定复核）。

### KP-CMP-191 供应商资质与 AVL：合格来源要“审过”而不是“用过”

- **判据**：供应商必须进 AVL（授权资质、质量体系、过程能力、交付能力、价格）；关键器件应有 ≥2 家合格来源，或明确单点风险并获批；定期绩效评估（来料合格率、交付、响应）。
- **为什么**：供应商质量体系决定来料一致性；单一来源在议价与交付上风险高。
- **怎么做**：供应商审核（体系/过程/产能）；样品承认与首件；年度评估与分级；关键料签质量协议。
- **怎么查**：AVL 覆盖率；审核报告；来料合格率/交付准时率；不合格供应商处置记录。
- **依据**：ISO 9001/IATF 16949 供应商管理条款（按认证范围复核）；公司采购制度。

### KP-CMP-192 停产/断供应急预案：触发条件与动作要预先定义

- **判据**：高风险器件必须有预案：已批准替代料、改板方案、库存覆盖期、最后采购计划；预案要有触发条件（PCN/LTB/交期中止/价格异常）、责任人与验证状态。
- **为什么**：断供发生时从零开始找料，周期与结果都不可控；预案的价值在于提前完成验证。
- **怎么做**：预案卡（器件/触发/动作/负责人/验证状态/预计周期）；提前做替代料打样；与客户沟通机制。
- **怎么查**：预案覆盖率；演练/触发响应时间；替代料验证完成度。
- **依据**：公司风险管理/BCP 流程；JESD48 停产通知触发机制（按标准复核）。

### KP-CMP-193 供应链评审门禁与数据时效：投产前必须过、过期必须重采

- **判据**：投产前 BOM 必须通过供应链门禁：生命周期状态、单点清单、替代料批准、交期覆盖、批次追溯字段、渠道合规；生命周期/交期/价格数据必须带采集日期与 TTL（如 90～180 天，按公司口径），到期重采。
- **为什么**：把供应链风险前移到投产前，避免量产后停线/改板；供应链数据衰减快，旧数据会误导决策。
- **怎么做**：检查表并入 release gate；不达标项走风险批准并跟踪闭环；季度复盘断供/涨价/PCN 事件并更新风险清单。
- **怎么查**：门禁记录与遗留项闭环；数据新鲜度统计；量产后断供事件复盘。
- **依据**：公司发布门禁/变更管理流程；TTL 与审批口径按项目质量体系复核。
