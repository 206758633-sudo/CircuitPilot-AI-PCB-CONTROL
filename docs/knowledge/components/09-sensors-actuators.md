# 传感器与执行器（温湿度 / 压力 / IMU / 霍尔 / 光电 / 麦克风 / 蜂鸣器 / 继电器 / 电机 / 电磁阀）选型知识

> **一句话结论**：传感器先定「接口类型与信号链」再定型号（模拟要算激励/量程/噪声，数字要算上拉/总线电容/电平），执行器先定「驱动方式与感性负载续流」再定器件（线圈电流、PWM 频率、堵转/启动电流、隔离与热）。**传感器看接口与校准，执行器看驱动与续流**，两类都必须在目标工况下用可量测指标验收。

- **适用阶段**：选型 → 原理图（接口/驱动）→ Layout（开孔/隔离/散热）→ 校准 → 产测（功能/极限/失效）。
- **适用对象**：温湿度/压力/MEMS IMU/霍尔/光电/麦克风等传感器，蜂鸣器/继电器/直流电机/步进电机/电磁阀等执行器及其驱动。
- **可信等级**：本文为 `reference` 参考知识；具体器件的量程、精度、引脚、驱动电流、线圈参数**必须回读该 MPN 的 datasheet**，且**需 Librarian 三源核验（EDA 库 / 供应商 / datasheet）**后才能作为设计输入。
- **严禁**：不得编造传感器精度/接口/引脚、执行器线圈电阻/触点额定值；不得把本文「常见量级」当成具体料号实测参数；BOM 中料号一律标「待核验」。

## 1. 传感器接口与信号链

### KP-CMP-140 传感器选型首问：接口类型决定信号链与成本

| 接口类型 | 典型传感器 | 信号链要点 | 主要风险 |
|---|---|---|---|
| 模拟电压/电流输出 | 模拟 MEMS 麦、部分压力/霍尔/光电 | 激励/偏置、输出阻抗、ADC 量程与基准、RC 抗混叠 | 噪声耦合、量程浪费、共模干扰 |
| I2C | 温湿度、压力、部分 IMU/环境光 | 上拉阻值、总线电容、电平、地址冲突 | 总线锁死、上升沿慢、地址撞车 |
| SPI | IMU、ADC、部分压力/磁传感器 | 片选/时钟极性、走线长度、CS 上拉 | 时序错、片选悬空误动作 |
| PDM / I2S | 数字 MEMS 麦克风、音频 ADC | 时钟质量、数据对齐、BCLK/LRCK 布线 | 时钟抖动、声道错位 |
| 脉冲/频率输出 | 流量、部分转速/光电 | 输入捕获、去抖、电平匹配 | 丢脉冲、抖动 |
| 开关量（开漏/推挽） | 霍尔开关、光电开关、干簧管 | 上拉/分压、去抖、ESD | 电平不匹配、误触发 |
| 工业 4-20mA / RS485 | 工业变送器 | 环路供电、隔离、终端/共模 | 地环流、隔离耐压不足 |

- **判据**：先确定接口类型与主控资源（I2C/SPI/ADC/PDM 通道数、引脚电平），再按「量程覆盖 + 精度/分辨率 + 响应时间 + 供电/功耗 + 封装/环境」筛选型号；模拟接口必须做误差预算（传感器误差 + 激励误差 + ADC 误差 + 噪声），数字接口必须核对电平/上拉/总线电容。
- **为什么**：接口不匹配会在原理图/驱动阶段引入大量返工；模拟链路误差预算没做，后期软件无法补偿（如 ADC 量程只用到 20%）。
- **怎么做**：画信号链：传感器 → 激励/偏置 → 滤波/放大 → ADC/MCU；每级标注增益、带宽、噪声、误差；数字接口标注上拉、总线电容、电平转换需求；工业接口标注隔离等级与认证要求。
- **怎么查**：评审项：每个传感器是否有「量程/精度/响应时间/接口」四项记录；**可量测判据**：目标工况下传感器输出落在 ADC 量程的 20%~80%（模拟）或通信误码率/丢包率 ≤设计值（数字）。

### KP-CMP-141 数字传感器 I2C/SPI 总线：上拉、总线电容、电平与地址

- **判据**：I2C 上拉电阻范围：R_min ≈ (VDD − V_OL)/I_OL，R_max ≈ t_r/(0.8473×C_bus)；标准模式 t_r≤1000ns、快速模式 ≤300ns、快速+ ≤120ns，总线电容 C_bus ≤400pF（I2C 规范，标准/快速模式）。3.3V 系统常用 4.7kΩ，快速模式/长线常用 2.2kΩ 或更小（按总线电容与 I_OL 复核）。SPI 的 CS 必须有确定电平（上拉/下拉），时钟极性/相位按器件 datasheet。
- **为什么**：上拉过大 + 总线电容大 → 上升沿变缓、采样错误、通信失败；上拉过小 → I_OL 超限、低电平抬高、功耗增加。地址冲突是多传感器系统最常见的 I2C 故障。
- **怎么做**：先数总线上器件数与总线电容（走线 ~1~2pF/cm 量级 + 器件引脚电容），再算上拉；多传感器优先选地址可配置/不同地址的型号；长线/多板用 I2C 缓冲器/多路开关；电平不匹配（如 5V 传感器 + 3.3V MCU）必须用双向电平转换，不能只靠上拉。
- **怎么查**：示波器测 SCL/SDA 上升时间与低电平；**可量测判据**：上升时间满足模式要求、V_OL ≤0.4V（按 I_OL）、连续 10 万次读写 0 错误；地址表逐项核对无冲突。

### KP-CMP-142 温湿度传感器选型：精度之外先看开孔与热设计

- **判据**：常见数字温湿度传感器精度量级：RH ±2%~±3%RH、T ±0.2~±0.5°C（具体按 datasheet，如 SHT30、AHT20 均为该量级）；工作温区与 RH 量程必须覆盖目标环境。传感器必须与外界空气连通（开孔/透气膜），且远离 MCU/DC-DC/发热器件与阳光直射。
- **为什么**：温湿度传感器的读数由传感器本体温度决定；板上热源会让温度偏高、RH 偏低（相对湿度随温度变化），这是「读数不准」最常见的根因，换更高精度型号也解决不了。
- **怎么做**：传感器布局在板边/开孔下方，远离热源 ≥10mm 量级（按热仿真复核）；外壳开透气孔并加防尘透气膜（IP 等级按产品要求）；避免传感器腔体形成死区；需要快速响应的场合选响应时间短的型号并减小腔体热容。
- **怎么查**：与标准温湿度计/恒温恒湿箱比对；**可量测判据**：整机老化 30min 后读数与标准表偏差 ≤ 产品规格（如 RH ±3%RH、T ±0.5°C）。

### KP-CMP-143 温湿度校准、结露与污染防护

- **判据**：出厂校准只能用标准盐溶液/标准表做两点或多点比对（如 33%RH 与 75%RH 饱和盐溶液，按标准方法），不能只按单点偏移硬改；结露工况下电容式湿度传感器读数会饱和/漂移，必要时加热除露或选带加热器的型号；污染（粉尘、油雾、清洗剂）会堵塞透气膜导致响应变慢。
- **为什么**：湿度传感器长期漂移与污染是主要失效模式；结露会形成水膜改变电容，读数不可信。校准数据是产品精度声明与售后判定的依据。
- **怎么做**：产测至少做「常温常湿 + 高湿」两点比对并记录；外壳设计防滴溅/防凝露；清洗/三防漆不得覆盖传感器声孔/透气膜；长期高湿场景选抗结露型号并加软件合理性判断（RH=100% 持续 → 提示）。
- **怎么查**：盐溶液比对记录、高湿老化记录；**可量测判据**：两点校准残差 ≤产品规格，高湿 85%RH/85°C 老化后漂移 ≤规格值。

### KP-CMP-144 压力传感器：表压/绝压/差压、量程与过压

- **判据**：先确定测量类型（表压 gauge = 相对大气压；绝压 absolute = 相对真空；差压 differential = 两端口之差），再定量程：正常工作压力宜落在量程的 1/3~2/3；必须核对**过压/爆破压力**（常见为满量程的 2~5 倍，按 datasheet）与介质兼容性（腐蚀性气体/液体需隔离膜）。输出类型（mV/V 电桥、模拟电压、I2C/SPI）决定后续信号链。
- **为什么**：量程选太大 → 分辨率不足；选太小 → 压力波动/水锤直接打坏传感器；表压/绝压选错 → 读数整体偏移一个大气压，软件无法修正。
- **怎么做**：按「最大工作压力 ≤2/3 量程、过压 ≥1.5×可能出现的峰值」选型；电桥输出需仪表放大器 + 激励基准，注意共模与零点漂移；数字压力传感器注意 I2C 地址与采样率；差压传感器注意两端口耐压与安装方向。
- **怎么查**：datasheet 量程/过压/精度/温漂；**可量测判据**：零点与满量程两点校准，目标量程内误差 ≤规格（如 ±1hPa 级）；过压测试后零点漂移 ≤规格。

### KP-CMP-145 IMU 选型：量程、ODR、噪声密度、带宽与安装

- **判据**：IMU 关键参数：加速度量程（±2/4/8/16g）、角速度量程（±125/250/500/1000/2000dps）、ODR、噪声密度（µg/√Hz、dps/√Hz）、带宽、零偏稳定性、轴间正交误差、冲击耐受。量程按「最大加速度/角速度 ×1.5~2」选；分辨率不足时不要靠软件放大。
- **为什么**：量程与分辨率/噪声是 trade-off（同一器件量程越大，最小可分辨量越大）；ODR/带宽决定能捕捉的动态；安装刚度不足会让 PCB 振动叠加到测量信号上。
- **怎么做**：按应用算最大加速度（如跌落/冲击）与最大角速度；静态倾角测量选低噪声/低零偏型号，动态控制选高 ODR/低延迟型号；安装面平整、螺钉/胶固定牢靠，避免悬臂；必要时加减震结构（见 KP-CMP-146）。
- **怎么查**：datasheet 噪声密度/零偏/量程表；**可量测判据**：静止 1min 输出 RMS 噪声 ≤设计值，零偏在规格内；施加已知加速度/角速度（转台/倾角台）比对误差。

### KP-CMP-146 IMU 校准与振动隔离

- **判据**：消费级 IMU 出厂零偏与灵敏度误差可达百分比级，必须做校准：至少六面静态校准（±X/±Y/±Z 各测一次，解算零偏与灵敏度/轴间耦合），必要时做温度分段校准；安装上避免 PCB 弯曲/螺钉应力传到传感器，震动环境加减震垫/减震柱。
- **为什么**：零偏直接积分成角度漂移；安装应力会通过封装压阻效应改变零偏；未校准的 IMU 在姿态解算中表现为「静止也缓慢漂移」。
- **怎么做**：产测做六面校准并写入校准参数（存 MCU Flash/EEPROM）；软件做温度补偿（按 datasheet 零偏温漂）；结构上传感器靠近固定点、远离板边与连接器受力点；减震垫的共振频率要低于/高于工作频段（按结构仿真选择）。
- **怎么查**：六面校准残差、静止漂移测试；**可量测判据**：校准后静止 1h 姿态漂移 ≤设计值（如 ≤1°/h 量级，按器件等级）；振动台上输出无异常削顶。

### KP-CMP-147 霍尔传感器：开关型/线性型/锁存型，上拉与磁路

- **判据**：霍尔开关（unipolar）在磁场超过操作点 B_op 时翻转、低于释放点 B_rp 时恢复，存在磁滞；锁存型（bipolar latch）需要交替极性磁场翻转；线性型输出与磁场成正比。开漏输出必须加上拉电阻（阻值按灌电流与上升时间），推挽输出可直接接 GPIO。磁场强度与气隙（磁铁到传感器距离）强相关，必须按磁铁规格 + 气隙做校核。
- **为什么**：霍尔输出电平与磁铁极性/气隙决定是否能可靠触发；磁滞不足会导致临界位置抖动；开漏未加上拉会读不到高电平。
- **怎么做**：按检测距离与磁铁选操作点/释放点合适的型号；气隙留 20%~30% 余量；开漏输出上拉 4.7k~10k（按电流）；长线加 RC 滤波与 ESD 保护；双极锁存用于无刷电机换相/转速检测。
- **怎么查**：datasheet B_op/B_rp/磁滞/输出类型；**可量测判据**：在规定气隙下遮挡/靠近时输出电平翻转可靠（连续 100 次无漏触发），释放点与操作点差符合规格。

### KP-CMP-148 光电传感器：对射/反射/光耦，发射电流与阈值

- **判据**：槽型/对射光电开关由红外 LED + 光敏接收组成：LED 正向电流 I_f 按 datasheet（常见 10~20mA 级）并串限流电阻；接收侧输出（光电三极管/比较器/开漏）需要上拉与阈值设计。必须评估环境光抑制（调制型优于直流型）、遮挡物最小尺寸、槽宽/检测距离与响应时间。
- **为什么**：I_f 不足 → 接收信号弱、临界遮挡误判；I_f 过大 → LED 加速老化、温升；直流型易受环境光/阳光干扰。
- **怎么做**：按 5V/3.3V 与 I_f 算限流电阻并留 20% 余量；接收输出加施密特触发/软件去抖；结构上做遮光筋/遮光罩避免串扰与漏光；高速检测（如转速）选响应时间足够的型号。
- **怎么查**：遮挡/未遮挡两种状态下的输出电压/电流；**可量测判据**：遮挡时输出电平翻转裕度 ≥0.3×VDD，响应时间满足最高检测频率，连续遮挡 1000 次无漏检。

### KP-CMP-149 MEMS 麦克风：模拟/PDM/I2S、偏置、灵敏度与声孔

- **判据**：模拟 MEMS 麦克风输出为交流小信号（mV 级），需要 VDD 供电 + 隔直电容 + 偏置/ADC 输入共模匹配；数字 MEMS 麦克风分 PDM（时钟 + 数据）与 I2S（BCLK/LRCK/DATA）接口，需主控提供时钟并注意采样率/时钟抖动。关键指标：灵敏度（dBV/Pa 或 dBFS）、SNR、AOP（声学过载点）、功耗、声孔位置与密封。
- **为什么**：模拟麦的隔直/偏置设计不对会削顶或引入低频噪声；数字麦时钟抖动/采样率错误会导致噪声或声道错位；声孔被外壳/三防漆堵塞会让灵敏度骤降。
- **怎么做**：模拟麦用差分/单端按 datasheet 推荐，隔直电容与 ADC 输入阻抗构成高通（截止频率按语音下限 100~300Hz 设计）；数字麦 PDM 时钟走线短、加串阻，BCLK/LRCK 等长；声孔开在传感器正上方，加防尘网，避免与外壳共振腔形成峰谷；多麦阵列注意相位一致性。
- **怎么查**：datasheet 灵敏度/SNR/AOP；**可量测判据**：1kHz/94dB 标准声源下输出灵敏度在规格内、SNR ≥规格值、底噪 ≤设计值；声孔密封后灵敏度衰减 ≤1~2dB。

## 2. 执行器驱动

### KP-CMP-150 蜂鸣器：有源/无源先分清，驱动方式与续流

- **判据**：**有源蜂鸣器**内部含振荡电路，给额定直流电压即发声（驱动简单，频率固定）；**无源蜂鸣器**（压电/电磁）需要外部方波驱动，频率应接近其谐振频率（如 2.7kHz/4kHz，按 datasheet）。电磁式蜂鸣器是感性负载，必须加续流二极管；压电式是容性负载，注意驱动电流与电压摆幅。
- **为什么**：把无源蜂鸣器当有源驱动（只给直流）不会响或声音极小；把有源蜂鸣器当无源驱动（方波）可能异响/损坏；感性负载无续流会打坏驱动管。
- **怎么做**：按声压（dB@10cm）、电压、电流、尺寸选型；有源用 NPN/MOS 低边开关 + 基极/栅极电阻；无源用 MCU PWM/定时器方波（频率=谐振频率），占空比 50% 声压最大；电磁式并续流二极管；压电式可串小电阻限流。
- **怎么查**：datasheet 类型/额定电压/谐振频率/声压/电流；**可量测判据**：额定电压下声压 ≥规格（如 70~85dB@10cm）、电流在范围内、无源蜂鸣器在谐振频率处声压最大。

### KP-CMP-151 继电器：线圈驱动、续流与触点负载

- **判据**：继电器线圈是感性负载：驱动管 Ic/I_D 必须 ≥线圈电流 ×1.5~2，线圈两端必须并续流二极管（阴极接 VCC），驱动管基极/栅极加下拉；触点额定值必须按负载类型降额（阻性/感性/灯负载/电机负载差异很大，按 datasheet），触点电压/电流不得超过额定，感性/容性负载加 RC/压敏吸收。机械寿命与电气寿命分开看（电气寿命通常远低于机械寿命）。
- **为什么**：线圈关断反电动势可高达数十~上百 V，会击穿驱动管；触点拉弧会烧蚀触点、粘连；灯负载/电机负载的浪涌电流可达稳态的 5~10 倍。
- **怎么做**：5V 线圈常见驱动电流几十 mA 级（按 datasheet 线圈电阻算）；用 NPN/MOS 低边驱动 + 续流二极管（如 1N4148/SS34，按电流）；高边/隔离驱动用光耦/隔离器；触点侧加 RC 吸收（如 100Ω+0.1µF，按负载调试）或压敏电阻；需要常开/常闭/转换触点按逻辑选。
- **怎么查**：datasheet 线圈电压/电阻/吸合释放电压、触点额定/寿命；**可量测判据**：吸合电压 ≤0.8×额定、释放电压 ≥0.1×额定（按规格），触点接触电阻/压降在规格内，满载通断 1000 次无粘连。

### KP-CMP-152 直流电机：H 桥、PWM 频率、续流与制动

- **判据**：直流电机是感性 + 反电动势负载：H 桥驱动（如 DRV8833 双路 1.5A 级）需要按**堵转电流/启动电流**选驱动能力（启动电流可达稳态 5~10 倍，按电机 datasheet/实测）；PWM 频率建议 ≥20kHz（避开人耳可听频段，减少啸叫），同时考虑驱动器的开关损耗与电机电感；必须有续流路径（体二极管/外部肖特基）；制动方式（滑行/刹车/反转）按控制需求设计。
- **为什么**：堵转电流超驱动能力会触发热保护/烧毁；PWM 频率过低会有音频噪声与电流纹波大，过高会增加开关损耗与 EMI；无续流会在关断瞬间产生高压尖峰。
- **怎么做**：按电机额定电压/电流/堵转电流选 H 桥，留 1.5~2 倍余量；电机两端并 100nF 级高频电容（靠近电机端子）抑制 EMI；长线加共模电感/磁环；电源入口加足够储能电容吸收启动电流；软件做软启动/限流（电流检测）与过流保护。
- **怎么查**：datasheet 驱动器电流/电压/热阻；**可量测判据**：堵转/启动电流 ≤驱动器限流值，满载运行 30min 驱动器温升 ≤规格，PWM 频率 ≥20kHz 且电机无啸叫。

### KP-CMP-153 步进电机：细分、电流设定、加减速与失步

- **判据**：步进电机必须由专用驱动器（如 A4988/DRV8825/TMC 系列，按电流/电压选）驱动，不能直接用 MCU GPIO；相电流由驱动器 Vref/检流电阻设定，必须 ≤电机额定相电流；细分决定步距角与平滑度；启动频率过高/加速度过大 → 失步。单极性（如 28BYJ-48）与双极性电机驱动方式不同。
- **为什么**：相电流超额定 → 电机过热退磁；细分/加减速不当 → 丢步、定位误差，且失步后无法自恢复（除非回零）。
- **怎么做**：按电机额定相电流设定驱动器电流（留 70%~90%）；用梯形/S 曲线加减速，启动频率低于电机牵入频率；细分按定位精度与振动要求选（常见 1/8~1/32）；加原点/限位传感器做回零；驱动器散热焊盘/散热片按电流核算。
- **怎么查**：datasheet 电机相电流/相电阻/步距角、驱动器电流设定公式；**可量测判据**：设定相电流与实测偏差 ≤10%，连续运行 1000 步无失步，满载温升 ≤绝缘等级允许值。

### KP-CMP-154 电磁阀/电磁铁：驱动、续流、保持电流与热

- **判据**：电磁阀/电磁铁是感性负载，吸合电流（inrush）常大于保持电流（hold），可采用「启动全压 + 保持 PWM 降压」降低功耗与发热；驱动管/继电器触点必须按吸合电流选并加续流；阀体类型（常闭/常开/两位三通等）、工作电压、流体兼容性、占空比（连续通电还是短时通电）必须与 datasheet 一致。
- **为什么**：按保持电流选驱动会在吸合瞬间过流；长期全压通电会让线圈过热甚至烧毁（尤其小体积阀）；无续流会击穿驱动。
- **怎么做**：按吸合电流选驱动并留 1.5~2 倍；线圈并续流二极管（响应速度要求高时用齐纳/RC 吸收）；需要低功耗保持时用 PWM（频率避开机械共振，常见几 kHz~20kHz）并加电流闭环；阀体安装避免振动导致误动作。
- **怎么查**：datasheet 电压/电流/功率/占空比；**可量测判据**：吸合/释放动作可靠（连续 1000 次），保持阶段线圈温升 ≤规格，关断尖峰 ≤驱动管 Vds 最大值的 0.8 倍。

### KP-CMP-155 感性负载驱动通用规则：续流、隔离、地回路

- **判据**：所有感性负载（继电器线圈、电磁阀、电机、蜂鸣器）在关断瞬间产生反向电动势，必须提供续流通路（二极管/齐纳/RC/驱动器体二极管），且续流回路面积要小；高压/长线/工业场景使用光耦或数字隔离器隔离控制侧与负载侧；大电流负载的地回路与信号地单点连接，避免地弹。
- **为什么**：没有续流 → 驱动管击穿、MCU 复位/死机；地回路设计不当 → 负载电流在公共地阻抗上产生压降，造成 ADC 误差/通信误码。
- **怎么做**：续流二极管紧贴线圈/负载端子放置；驱动管选 Vds/Vce 耐压 ≥2×电源电压，并核对 SOA（安全工作区）；隔离器件放在控制侧与功率侧之间，隔离电源按需增加；功率地与信号地单点汇合，汇合点靠近电源输入。
- **怎么查**：Layout 评审续流回路面积与地分割；示波器测关断尖峰；**可量测判据**：关断尖峰电压 ≤驱动管耐压×0.8，负载动作时 MCU/ADC 无误动作/复位。
