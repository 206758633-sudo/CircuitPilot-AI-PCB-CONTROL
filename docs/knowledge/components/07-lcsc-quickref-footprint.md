# 常用料号速查与封装核验知识

> **一句话结论**：料号（LCSC/MPN）只是「线索」，可信身份必须由 Librarian 三源核验（EDA 库 / 供应商 / datasheet）给出；封装名不等于引脚定义，任何 SOT-23/QFN/LQFP 器件都必须按 datasheet 的 Pin 1 与 pin map 建库，未核验料号一律标「待核验」，不得进入生产 BOM。

- **适用阶段**：选型 → BOM → 封装库 → 投产前核验。
- **可信等级**：本文为 `reference` 参考知识；速查表中的料号来自项目 BOM（AI 生成），**全部标「项目 BOM 参考（待核验）」**，实际使用前**需 Librarian 三源核验（EDA 库 / 供应商 / datasheet）**。
- **严禁**：不得把速查表中的 LCSC 料号、封装、引脚当成已核实事实；不得编造替代料 MPN；替代料必须逐参数比对并经三源核验。

## 1. 料号使用规范与核验流程

### KP-CMP-105 LCSC 料号使用规范：必须携带「核验状态」

- **判据**：每条料号必须带三态之一：`待核验`（仅候选/参考，默认）、`已核验`（Librarian 三源一致通过）、`冲突`（三源不一致，禁止使用）。项目 BOM（AI 生成）中的料号只能标「项目 BOM 参考（待核验）」。
- **为什么**：LCSC 料号可被重新分配/停产/替换，同一料号在不同 EDA 库中的封装与引脚也可能不同；没有核验状态的料号等于没有身份。
- **怎么做**：BOM 增加「lcscId、mpn、manufacturer、package、identityVerification（pending/verified/conflict）、verificationRef」字段；AI 生成或人工填写的料号默认 pending；只有 Librarian 通过后才改 verified。
- **怎么查**：BOM 字段完整性检查；Librarian 输出 `LIB_IDENTITY_VERIFIED` 才可改 verified；评审项：生产 BOM 是否还残留 pending 料号。

### KP-CMP-106 Librarian 三源核验判定逻辑（与本文档的对应关系）

| Librarian 结论码 | 触发条件 | 严重度 | 对选型/布线的含义 |
|---|---|---|---|
| `LIBRARIAN_INPUT_MISSING` | 缺少 LCSC 料号 | 抛错 | 无法核验，先补料号 |
| `LIB_EDA_SOURCE_MISSING` | 无 EDA 库数据 | error → blocked | 不能核对 symbol/footprint/3D，禁止放行 |
| `LIB_SUPPLY_SOURCE_MISSING` | 无供应商数据 | error → blocked | 无法确认可采购与 MPN/封装一致 |
| `LIB_PART_IDENTITY_MISMATCH` | 供应商/EDA 返回料号 ≠ 请求料号 | error → blocked | 料号身份冲突，禁止使用 |
| `LIB_PACKAGE_MISMATCH` | 封装族明确冲突（SOT vs QFN 等） | error → blocked | 封装选错，必须改库/改料 |
| `LIB_PACKAGE_UNVERIFIED` | 封装命名体系不同/单边缺失，无法判定 | warning | 需 datasheet/人工确认，不阻断 |
| `LIB_MODEL3D_MISSING` | EDA 库无 3D 模型 | warning | 机械/装配检查缺依据 |
| `LIB_DATASHEET_UNVERIFIED` | datasheet 未核验或抓取失败 | warning | 引脚/电气参数仍可能不一致 |
| `LIB_IDENTITY_VERIFIED` | 无 error 级发现 | info | 身份三源核验通过 |

- **判据**：只要出现任一 error 级 finding，结论即 `blocked`（不等于「通过」）；warning 不阻断但必须显式记录并人工确认。
- **为什么**：Librarian 是「只出候选证据」的只读门禁，缺失数据不能被解释成「没问题」；封装族比较只做族级（SMD/SOT/QFN…）判定，无法判定时不假装通过也不误杀。
- **怎么做**：把上表作为 BOM 核验的验收标准；blocked 必须修数据/换料后重跑；warning 在评审记录中逐条写明「谁确认、依据是什么」。
- **怎么查**：运行 `node scripts/verify-librarian.mjs`（只读核验脚本）；核对证据信封里的 `verdict`、`findings`、`blockedReason`；评审项：生产 BOM 是否 100% 无 blocked。

### KP-CMP-107 符号-封装-焊盘三源核验流程（建库 SOP）

1. **来源**：datasheet 的 Pin Configuration / Package Drawing（第一优先），其次供应商页面（封装尺寸/图片），最后 EDA 库（可能已错）。
2. **符号**：按 datasheet 的引脚号与功能建符号；引脚号必须与封装一一对应；电源/地/NC 不得合并错。
3. **封装**：按 datasheet 推荐的 land pattern（或 IPC-7351）建焊盘；核对 Pin 1 位置、间距、焊盘长宽、散热焊盘与过孔。
4. **交叉核对**：符号引脚号 ↔ 封装焊盘号 ↔ datasheet pin map 三者一致；3D 模型/丝印方向一致。
5. **首件验证**：万用表二极管档/通断测试验证关键引脚（如 MOS 体二极管方向、二极管极性）。
6. **标记状态**：通过后写 verified，未通过/缺数据写 pending/conflict。

- **判据**：三源（符号/封装/datasheet）必须一致；只有「EDA 库里本来就有」不构成核验。
- **为什么**：EDA 库中的封装可能是旧版本或通用库，引脚映射错误在投产前很难发现。
- **怎么做**：建库时把 datasheet 页码/版本写进库备注；封装命名包含「封装族 + 尺寸 + 变体」；高风险器件（MOS/电源 IC/连接器）首件必测。
- **怎么查**：Librarian 核验 + 首件测试记录；评审项：新建/修改的封装是否有三源核对记录。

### KP-CMP-108 封装族命名与「公制/英制」混淆

- **判据**：贴片阻容常用**英制**代号：0402 = 1.0×0.5mm（公制 1005）、0603 = 1.6×0.8mm（公制 1608）、0805 = 2.0×1.25mm（公制 2012）、1206 = 3.2×1.6mm（公制 3216）；而部分厂家/日系资料用公制代号（1005/1608/2012），同名不同义。封装族：SOT/SOD/DO-214/QFN/DFN/SOP/SOIC/TSSOP/LQFP/TQFP/BGA/CONN。
- **为什么**：0402 英制 ≈ 公制 1005，如果把「0402」当公制会买到 0.4×0.2mm 的器件（实际不存在该常用规格，但概念混淆会导致选型/建库错误）；不同封装族无法互换。
- **怎么做**：BOM 统一用「英制代号 + 尺寸」双写（如 `0402 (1.0×0.5mm)`）；封装库命名带族名；采购/建库前确认厂家用的是哪套代号。
- **怎么查**：对照 datasheet 的 Package Drawing 尺寸；评审项：封装名是否含族名与尺寸；不通过则统一命名。

### KP-CMP-109 片式阻容封装（0402/0603/0805/1206）与焊盘要点

| 封装（英制） | 尺寸（近似） | 常见额定功率（电阻） | 常见额定电压（电阻） | 焊接/返修 | 备注 |
|---|---|---|---|---|---|
| 0402 | 1.0×0.5mm | 1/16W（部分 1/10W） | 50V | 需镊子+放大镜，手工可行 | 高密度首选，偏压/散热余量小 |
| 0603 | 1.6×0.8mm | 1/10W | 50V | 手工较易 | 通用折中 |
| 0805 | 2.0×1.25mm | 1/8W | 150V | 易 | 功率/耐压余量更大 |
| 1206 | 3.2×1.6mm | 1/4W | 200V | 易 | 大功率/采样电阻 |
| 1210 | 3.2×2.5mm | 1/2W 量级 | — | 易 | 大电流/储能 |

- **判据**：焊盘按 datasheet/IPC-7351 推荐值；0402 焊盘间距过大会立碑，过小会桥连；大封装 MLCC 避免放板边受力区。
- **为什么**：焊盘设计直接影响良率；0402 的工艺窗口最窄，手工返修易损伤焊盘。
- **怎么做**：小批量手工打样可用 0603/0805 降低难度；量产高密度用 0402；钢网开孔按焊盘 1:1 或略缩；0402 以下（0201）需确认贴片厂能力。
- **怎么查**：首件 AOI/目检 + 推力测试（抽检）；评审项：焊盘库是否与封装族匹配。

### KP-CMP-110 SOT-23 / SOT-23-5 / SOT-23-6 引脚与焊盘

- **判据**：SOT-23 本体约 2.9×1.3mm，3 脚间距 0.95mm；SOT-23-5/6 为 5/6 脚、0.95mm 间距。**引脚功能由器件决定，不统一**：三极管常见 1=B/2=E/3=C，N-MOS 常见 1=G/2=S/3=D，但也有其他映射；SOT-23-6 的电源 IC 引脚定义各家不同。
- **为什么**：SOT-23 是最容易「按经验接错」的封装；同封装不同器件的 pin map 不同，接反可能直通烧板。
- **怎么做**：逐器件按 datasheet 建符号/封装；原理图符号显示引脚号；首件测体二极管/通断；SOT-23-6 电源 IC 必须核对 EN/FB/SW 等脚位。
- **怎么查**：Librarian 三源核验 pin map；首件万用表测试；评审项：SOT-23 器件是否逐个核对；不通过不得投产。

### KP-CMP-111 SOT-223 / SOT-89 散热焊盘封装

- **判据**：SOT-223 本体约 6.5×3.5mm，3 引线 + 1 个大散热 tab（tab 常与中间引脚相连，**必须按 datasheet 确认 tab 电气连接**）；SOT-89 本体约 4.5×2.5mm，3 引线 + tab。散热焊盘需足够铜面积与过孔（SOT-223 tab 常见与 pin2 相连）。
- **为什么**：散热 tab 的电气连接（接 GND/Vout/内部节点）因器件而异，接错会短路或失效；铜面积不足会导致 RθJA 偏高、过热。
- **怎么做**：按 datasheet 的 Package/Pin 说明确认 tab 网络；tab 下打多个过孔连到内层地/铜皮；钢网对 tab 开窗（避免锡量过多导致器件漂浮）。
- **怎么查**：核对 tab 网络与 datasheet；热成像实测；评审项：散热焊盘过孔与铜面积是否满足热计算。

### KP-CMP-112 QFN / DFN：散热焊盘与 Pin 1 识别

- **判据**：QFN/DFN 底部有大散热焊盘（EP），**必须**按 datasheet 确认 EP 的电气连接（常为 GND，少数为其他网络）；Pin 1 通常由本体一角的凹点/斜边/丝印圆点标识；引脚间距常见 0.4/0.5/0.65mm，无引脚伸出，靠底部焊盘焊接。
- **为什么**：EP 未焊接或接错网络会导致散热/接地失效；Pin 1 认错会导致整颗芯片旋转 90°/180°，上电即损坏。
- **怎么做**：封装库按 datasheet 的 Pin 1 方向建；EP 打阵列过孔（常见 4~9 个，按 datasheet 推荐）连地；钢网 EP 开窗分区（避免锡多漂浮）；丝印标 Pin 1。
- **怎么查**：首件 X-Ray 检查 EP 焊接（空洞率按工艺要求）；AOI/丝印核对方向；评审项：QFN EP 网络与过孔是否与 datasheet 一致。

### KP-CMP-113 LQFP / TQFP：0.5mm 间距与 Pin 1

- **判据**：LQFP-48 常见 7×7mm、0.5mm 间距；LQFP-32 常见 7×7mm、0.8mm；TQFP-44 常见 10×10mm、0.8mm。Pin 1 由本体一角圆点 + 斜边标识；0.5mm 间距对钢网/贴片/返修要求较高。
- **为什么**：0.5mm 间距易桥连，手工返修难度大；Pin 1 认错会整颗反装。
- **怎么做**：钢网厚度与开窗按 0.5mm 间距优化（常见 0.1~0.12mm 钢网）；焊盘按 datasheet/IPC 建；四周留返修空间；丝印标 1 脚。
- **怎么查**：AOI/放大镜目检桥连；首件通断；评审项：0.5mm 间距器件的贴片/返修能力是否确认。

### KP-CMP-114 二极管封装：SMA/SMB/SMC（DO-214）与 SOD 系列

| 封装 | 别名 | 本体尺寸（近似） | 常见功率/电流量级 | 极性标识 |
|---|---|---|---|---|
| SMA | DO-214AC | 4.3×2.6mm | 1A 级 | 色带 = 阴极 |
| SMB | DO-214AA | 5.3×3.6mm | 2~3A 级 | 色带 = 阴极 |
| SMC | DO-214AB | 7.9×5.9mm | 3~5A 级 | 色带 = 阴极 |
| SOD-123 | — | 2.7×1.6mm | 0.5~1A 级 | 色带 = 阴极 |
| SOD-323 | — | 1.7×1.25mm | 0.2~0.5A 级 | 色带 = 阴极 |
| SOD-523 | — | 1.2×0.8mm | 小信号 | 色带 = 阴极 |

- **判据**：TVS/整流/肖特基的封装必须与功率匹配（SOD-323 不能扛 SMA 的浪涌）；极性色带 = 阴极（负极），单向 TVS/二极管按此方向。
- **为什么**：小封装的热容/结面积小，浪涌/连续电流能力远低于大封装；极性接反是防护电路失效的常见原因。
- **怎么做**：按峰值功率/电流选封装档；极性在原理图符号、丝印、装配图上一致标注；TVS 封装与 VRWM/VC 参数一起核。
- **怎么查**：datasheet 封装与功率曲线；首件极性测试；评审项：封装与功率是否匹配。

### KP-CMP-115 SOD-123 与 DO-41/DO-35 等插件封装

- **判据**：SOD-123 为贴片小功率二极管常用封装（本体约 2.7×1.6mm）；DO-41/DO-35 为轴向插件（玻璃/塑封），需注意引脚成型、极性色带与插件孔间距；插件器件在自动化产线上通常需额外工序，成本高于贴片。
- **为什么**：插件封装与贴片封装的焊盘/工艺完全不同，混用会导致无法贴片；轴向器件引脚间距不匹配会装不进孔。
- **怎么做**：优先选贴片封装；必须用插件时核对孔径/孔距/引脚直径与成型方式；极性色带方向统一。
- **怎么查**：PCB 封装与实物比对；首件试装；评审项：是否还有可替换为贴片的插件器件。

### KP-CMP-116 极性标识：二极管/LED/钽电容/电解/连接器

| 器件 | 极性标识 | 易错点 |
|---|---|---|
| 二极管/TVS（单向） | 色带 = 阴极（负极） | 色带常被误认为正极 |
| LED | 阴极侧有缺口/短线/绿点；封装丝印有极性 | 与普通二极管方向相反易混 |
| 钽电容 | 色带/「+」= 正极 | 与铝电解相反，最易接反 |
| 铝电解 | 色带/「−」= 负极 | 与钽电容相反 |
| 连接器 | Pin 1 标记（三角/圆点/缺口） | 镜像/反转导致线序错 |
| IC | Pin 1 圆点/斜边/丝印 | QFN/LQFP 认错方向 |

- **判据**：原理图符号、封装丝印、装配图三处极性必须一致；钽电容与铝电解的色带含义相反，必须分别标注。
- **为什么**：极性接反轻则不工作，重则炸裂/起火（钽电容、电解电容）；这是量产最典型的装配错误之一。
- **怎么做**：符号库统一「色带/加号」语义；丝印加极性标记与「+」；BOM 注明极性类型；首件逐一核对。
- **怎么查**：首件极性检查表；AOI 极性检测；评审项：极性器件是否全部有丝印标识。

### KP-CMP-119 替代料判断：封装兼容只是第一关

| 检查项 | 要求 | 不通过的后果 |
|---|---|---|
| 封装/焊盘 | 同族同尺寸同引脚数，焊盘兼容 | 无法贴片/虚焊 |
| 引脚定义 | 逐脚功能一致 | 上电损坏/不工作 |
| 电气参数 | 电压/电流/功率/精度/频率覆盖 | 降额不足、性能不达标 |
| 温度等级 | 覆盖工作温度范围 | 高温失效 |
| 外围要求 | 电容/电感/补偿/上拉兼容 | 不稳定/不起振 |
| 认证/合规 | 满足目标市场要求 | 认证失败 |
| 供货/生命周期 | 有库存、非停产 | 量产中断 |

- **判据**：7 项全部通过才可判「可替代」；任一需要改外围或改软件，都必须重做验证并留记录。
- **为什么**：「看起来一样」的器件在参数、工艺、可靠性上可能完全不同；替代是重新设计的一部分，不是采购动作。
- **怎么做**：建立替代对比表（原型号 vs 替代型号，逐项填）；替代后至少做功能/温升/极限测试；关键器件保留第二来源。
- **怎么查**：Librarian 三源核验 + 对比表 + 实测记录；评审项：替代料是否逐项比对。

### KP-CMP-120 钢网、焊盘与返修注意

- **判据**：钢网厚度常见 0.1~0.15mm（按最小间距/器件）；QFN 散热焊盘开窗分区（避免锡量过多漂浮）；0402 以下与 0.5mm 间距需激光切割+电抛光钢网；返修需热风+预热，避免反复加热损伤焊盘/器件。
- **为什么**：锡量过多会导致立碑/桥连/漂浮，过少会虚焊；反复返修会让焊盘脱落、MLCC 开裂。
- **怎么做**：按器件最小间距选钢网厚度与开窗；QFN/连接器做局部减薄或分区；返修前预热板子，控制温度曲线；BGA/QFN 返修后做 X-Ray。
- **怎么查**：首件 AOI/X-Ray；评审项：钢网开窗是否与封装库匹配；不通过则改钢网。

### KP-CMP-121 封装/料号常见错误清单

| # | 错误 | 后果 | 纠正 |
|---|---|---|---|
| 1 | 把 AI 生成 BOM 的 LCSC 料号当已核验事实 | 买错料/装错 | 全部标待核验，跑 Librarian |
| 2 | 按封装名推断引脚（SOT-23 等） | 直通烧板 | 逐器件按 datasheet 核对 |
| 3 | 公制/英制封装代号混用 | 买错尺寸 | 双写「代号 + 尺寸」 |
| 4 | QFN 散热焊盘不接地/不打孔 | 散热/接地失效 | 按 datasheet 打孔连地 |
| 5 | QFN/LQFP Pin 1 认错 | 整颗反装烧毁 | 按凹点/斜边/丝印核对 |
| 6 | 钽电容按铝电解色带理解 | 接反炸裂 | 钽「+」为正，电解色带为负 |
| 7 | 二极管色带当正极 | 电路不工作/短路 | 色带=阴极 |
| 8 | 用 SOD-123 替代 SMA 扛浪涌 | 过流烧毁 | 封装与功率匹配 |
| 9 | 替代料只看封装兼容 | 参数不达标 | 7 项逐项比对 |
| 10 | 生产 BOM 残留 pending 料号 | 采购/装配错误 | 投产前清零 pending |

- **判据**：任一项存在即判为料号/封装风险。
- **为什么**：这些错误直接对应「买错、装错、焊错」，是 PCBA 返工的主要来源。
- **怎么做**：把清单并入投产前检查门禁；BOM 与封装库交叉核对；首件做完整测试。
- **怎么查**：评审记录 + 首件测试 + Librarian 核验报告。
