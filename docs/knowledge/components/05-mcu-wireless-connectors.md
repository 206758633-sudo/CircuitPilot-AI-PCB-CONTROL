# MCU / 无线模组 / 连接器选型知识

> **一句话结论**：MCU 按「资源够用 + 封装可制造 + 供货可持续」选型；无线模组必须先满足天线净空与认证前提，再谈功能；连接器按「额定电流/间距/插拔寿命/防呆」四项收口，引脚定义必须以 datasheet 与实物丝印双向核对，绝不按经验推断。

- **适用阶段**：需求 → 选型 → 原理图 → BOM → Layout（天线净空/连接器布局）。
- **可信等级**：本文为 `reference` 参考知识；具体模组的净空尺寸、连接器额定电流/寿命**必须回读各自 datasheet 与 layout guide**，且引脚定义与料号**需 Librarian 三源核验（EDA 库 / 供应商 / datasheet）**。
- **严禁**：不得编造模组天线净空的具体 mm 值、连接器引脚定义、认证编号；BOM 中料号一律标「项目 BOM 参考（待核验）」。

## 1. MCU 选型

### KP-CMP-072 MCU 选型六维度总表

| 维度 | 要确认的内容 | 不满足的后果 |
|---|---|---|
| 内核/性能 | 主频、算力、浮点/DSP、实时性 | 跑不动算法/丢中断 |
| 存储 | Flash、RAM（含堆栈/缓冲）、外部存储接口 | 固件放不下/OTA 失败 |
| IO 与外设 | IO 数量、复用、定时器、ADC/DAC、通信外设 | 功能裁剪/加外设芯片 |
| 封装与工艺 | 引脚数、间距、QFN/LQFP、散热焊盘 | 无法贴片/返修困难 |
| 供电与低功耗 | 电压范围、休眠电流、唤醒源 | 电池续航不达标 |
| 供货与生态 | 库存、生命周期、工具链、SDK、参考设计 | 停产/开发受阻 |

- **判据**：六维度必须逐项有结论（可行/需评估/不可行），任一维度未确认不得进入原理图冻结。
- **为什么**：MCU 是板级核心，选错会导致硬件返工或固件重写，代价最高；供货问题在样机阶段往往被忽略。
- **怎么做**：先列需求清单（IO 表、外设表、存储/算力估算），再选 2~3 个候选做对比表，最后核对封装与供货。
- **怎么查**：datasheet/选型手册 + 供应商库存 + 参考设计；评审项：MCU 选型对比表是否六维度齐全。

### KP-CMP-073 IO 数量与复用：按「功能 + 预留」核算

- **判据**：IO 需求 = 已用功能 + 调试口（SWD/JTAG/UART）+ 预留（≥10%）+ 启动/BOOT 脚 + 晶振/复位专用脚。注意复用冲突（同一外设可能占用固定引脚）、5V 容忍、上电默认电平。
- **为什么**：IO 刚好够用会导致后续加功能无脚可用；BOOT/调试脚被占会无法下载/调试；上电默认电平可能让外设误动作。
- **怎么做**：画 IO 分配表（引脚号/功能/复用/默认电平/方向/是否 5V 容忍）；调试口用排针或测试点引出；关键控制脚避开上电高电平的引脚。
- **怎么查**：评审项：IO 分配表是否与原理图一一对应；是否有预留；不通过则改 MCU 或加 IO 扩展。

### KP-CMP-074 外设匹配：接口电平、时序与数量要逐项核对

- **判据**：I2C（上拉电阻、速率 100k/400k/1M）、SPI（模式 CPOL/CPHA、片选数量）、UART（电平/流控）、I2S（主从、时钟）、ADC（分辨率、参考电压、采样率、输入范围）、PWM（通道/分辨率）。电平不匹配需电平转换。
- **为什么**：SPI 模式配错是最常见的「通信不通」原因；ADC 输入超范围会损坏或读数错误；I2C 上拉缺失/过大导致波形上升沿慢。
- **怎么做**：每个外设列出「主/从、速率、电平、上拉/串阻、片选」；3.3V 与 5V 混用时加电平转换（或确认 5V 容忍）；I2C 上拉按速率与总线电容计算（常见 2.2k~10k）。
- **怎么查**：示波器/逻辑分析仪抓波形；评审项：外设接口表是否完整；不通过则改参数或加转换。

### KP-CMP-075 存储、封装与可制造性

- **判据**：Flash/RAM 要按「固件 + OTA 双区 + 文件系统/缓冲」估算，不能只看当前固件大小；封装要匹配贴片厂能力（QFN 需散热焊盘与钢网开孔，LQFP 引脚间距 0.5mm 需检查焊接能力）；引脚数影响布线层数与成本。
- **为什么**：OTA 双区需要约 2 倍 Flash；RAM 不足会在运行时溢出（难调试）；小间距封装对小批量手工返修不友好。
- **怎么做**：Flash 至少留 30%~50% 余量；QFN 散热焊盘按 datasheet 打孔；BGA/QFN 需确认贴片厂能力；预留调试测试点。
- **怎么查**：编译产物 size 报告；封装与焊盘库核对；评审项：Flash/RAM 余量是否写明。

### KP-CMP-076 供货与替代：同系列 pin-compatible 是首选

- **判据**：替代优先级：同厂同系列 pin-to-pin（仅 Flash/RAM/温度等级不同）> 同厂不同系列（需核对引脚与外设）> 其他厂（需重做软件与验证）。必须核对：引脚定义、封装、电压、外设、启动方式、工具链支持。
- **为什么**：MCU 替代的软件/工具链成本远高于硬件；「引脚兼容」但外设寄存器不同的型号仍需改代码。
- **怎么做**：选型时就把「第二来源」写进 BOM 备注；同系列不同存储容量的型号通常可共用 PCB（需确认引脚一致）；替代前做最小系统验证。
- **怎么查**：供应商库存/生命周期；Librarian 三源核验；评审项：关键 MCU 是否有替代料与验证计划。

### KP-CMP-077 MCU 最小系统：复位、BOOT、去耦、调试口

- **判据**：最小系统必须包含：电源去耦（每个电源脚 100nF + 总储能）、复位电路（RC 或专用复位 IC，按 datasheet 要求）、BOOT/启动配置脚（固定电平或跳线）、调试口（SWD/JTAG/UART）、晶振（按需）。NRST 等复位脚要加对地小电容（常见 100nF，按 datasheet）。
- **为什么**：缺去耦会导致随机复位/ADC 噪声；BOOT 脚悬空会进错启动模式；调试口没引出会导致无法量产测试。
- **怎么做**：参照 MCU datasheet 的「最小系统/典型应用」逐项对齐；调试口用 2.54mm 排针或 pogo pad；复位脚避免长走线。
- **怎么查**：评审项：最小系统清单是否齐全；上电/复位波形实测；不通过则补齐。

## 2. 无线模组

### KP-CMP-078 无线模组选型：协议、认证、功耗、接口

| 维度 | 要确认 | 备注 |
|---|---|---|
| 协议 | WiFi 频段/标准、BLE 版本、是否需 Mesh | 2.4G/5G、WiFi6 等 |
| 发射功率/灵敏度 | 链路预算是否够覆盖 | 按模组 datasheet |
| 功耗 | 峰值电流、休眠电流、平均功耗 | 电池产品关键 |
| 接口 | SDIO/SPI/UART/USB、GPIO 数量 | 与 MCU 匹配 |
| 认证 | FCC/CE/SRRC/IC 预认证状态 | 影响上市 |
| 天线 | PCB/陶瓷/外置，净空要求 | 影响布局 |
| 供货/生态 | SDK、AT 固件、参考设计 | 开发成本 |

- **判据**：协议与链路预算满足需求、认证状态明确、功耗与电池预算匹配、接口与 MCU 匹配，四项齐全才可定模组。
- **为什么**：无线模组是「认证 + 射频 + 协议栈」的复合体，任何一项不满足都要换方案而不是改外围。
- **怎么做**：优先选带预认证（FCC/CE/SRRC）的模组并保留认证资料；按峰值电流校核电源；确认天线方案（PCB 天线需严格按 layout guide）。
- **怎么查**：模组 datasheet + 认证证书 + 参考设计；评审项：模组选型表是否含认证与功耗列。

### KP-CMP-079 天线净空（Keep-out）必须按模组 layout guide 执行

- **判据**：天线区域（模组天线投影区及周边）通常禁止铺铜、走线、过孔、器件与丝印，且模组应尽量置于板边、远离金属外壳/电池/大电流走线；具体尺寸以该模组 datasheet/layout guide 为准（不同模组、不同天线方案差异很大，**不得套用其他模组数值**）。
- **为什么**：天线附近的金属与介质会改变谐振频率与辐射方向图，导致距离缩短、认证失败；净空不足是最常见的无线设计错误。
- **怎么做**：Layout 前先读模组 layout guide，画出 keep-out 区域并锁定；模组天线朝向板外/远离金属；外壳若为金属需预留开窗或改用外置天线；电池与喇叭等含金属部件远离天线。
- **怎么查**：Layout 评审对照 layout guide 逐项检查；实测 RSSI/吞吐/距离；认证前做预扫描；不通过则改布局或天线方案。

### KP-CMP-080 无线认证：模组预认证 ≠ 整机免测

- **判据**：使用预认证模组可简化认证，但整机仍需做 EMC/射频（如 CE RED、FCC Part 15、中国 SRRC）测试；更换天线、加外壳、改布局都可能需要重新评估。认证要求与目标市场绑定。
- **为什么**：认证是法规要求，不是技术选项；预认证只覆盖模组本身在特定条件下的表现。
- **怎么做**：选型阶段确认目标市场与认证清单；保留模组认证证书与测试报告；整机预留屏蔽罩/滤波位置；天线方案变更前咨询认证实验室。
- **怎么查**：认证清单与证书；评审项：BOM/结构是否按认证要求（屏蔽、天线、标签）。

### KP-CMP-081 无线模组电源：峰值电流与去耦

- **判据**：WiFi 发射瞬间峰值电流可达数百 mA（按模组 datasheet，常见 300~500mA 量级），电源与走线必须按峰值电流设计；模组电源脚就近放 10µF+100nF（或按 datasheet 推荐），大容量储能靠近模组；避免与 ADC/音频共用细走线。
- **为什么**：峰值电流造成电源跌落，会触发模组复位/丢包；去耦不足会把射频噪声耦合到整板。
- **怎么做**：模组单独一路 LDO/Buck 或宽铜走线；按峰值电流算压降（ΔV=I×R）；输入加磁珠/LC 滤波抑制射频回灌；复位脚加 RC 与上拉。
- **怎么查**：实测发射瞬间电源纹波与跌落；评审项：模组供电走线宽度与去耦是否按峰值电流设计。

## 3. 连接器

### KP-CMP-082 连接器选型四要素：电流、间距、寿命、防呆

| 类型 | 常见间距 | 每针额定电流（常见量级，按 datasheet） | 插拔寿命（常见量级） | 典型用途 |
|---|---|---|---|---|
| 排针/排母 | 2.54mm | ~3A（降额用 ~2A） | 50~100 次 | 调试口、扩展板 |
| 排针/排母 | 1.27mm | ~1A | 50 次量级 | 紧凑板对板 |
| 线对板端子（XH） | 2.5mm | ~3A | 30 次量级 | 电源/电机 |
| 线对板端子（ZH） | 1.5mm | ~1A | 30 次量级 | 小电流信号 |
| 线对板端子（GH） | 1.25mm | ~1A | 30 次量级 | 电池/小电流 |
| 线对板端子（SH） | 1.0mm | ~1A | 30 次量级 | 板间信号 |
| FPC/FFC | 0.5mm | ~0.5A/针 | 20~30 次 | 显示屏/摄像头排线 |
| FPC/FFC | 1.0mm | ~1A/针 | 20~30 次 | 排线 |
| USB Type-C | 0.5mm 引脚 | VBUS 多针并联，支持 3A/5A（按规范与线材） | ~10000 次 | 供电/数据 |

- **判据**：连接器额定电流必须 ≥ 实际电流 ×1.5（考虑温升与多针分流不均）；插拔频繁的接口选长寿命型号；有防呆要求的接口必须有极性/键位。
- **为什么**：连接器是机械+电气复合件，额定电流随温度/针数/线径变化；插拔寿命不足会在售后集中失效。
- **怎么做**：按「电流/间距/寿命/防呆」四项选型并写进 BOM；大电流用多针并联并均流；插拔频繁处（充电口、调试口）选高寿命型号。
- **怎么查**：datasheet 降额曲线；评审项：连接器电流是否按 1.5 倍降额；不通过则改型号或多针并联。

### KP-CMP-083 USB Type-C 连接器：16P 与 24P 的能力差异

- **判据**：16P Type-C 通常只支持 USB2.0（无 SuperSpeed 差分对），24P 才支持 USB3.x/DisplayPort 等全功能；作为受电设备（Sink）时 CC1/CC2 各需一只 5.1kΩ 下拉电阻到地（Rd），否则无法被电源识别；VBUS/GND 多针并联载流。
- **为什么**：CC 电阻是 Type-C 检测的核心，缺失/阻值错误会导致「插上不充电」；16P 用于 USB3 会缺少高速差分对。
- **怎么做**：Sink 设备：CC1、CC2 各 5.1kΩ±5% 到 GND；需要 5V/3A 以上要确认线材与电源能力；外壳地（SHIELD）与信号地按 EMC 方案处理（常见并联 RC/直接连接）。
- **怎么查**：实测插入识别与充电电流；评审项：CC 电阻是否两只独立 5.1k；BOM 中 Type-C 16P 母座属项目 BOM 参考，待核验其引脚数与 USB2.0 能力。

### KP-CMP-084 排针/排母：间距、针数与防呆

- **判据**：2.54mm 排针常见 1×N/2×N，注意「单排/双排」「直针/弯针」「针长」；相邻信号与电源不要混排；调试口按标准 SWD（VCC/GND/SWDIO/SWCLK/NRST）或 UART（TX/RX/GND）定义并加丝印。
- **为什么**：排针插反/错位是最常见的调试事故；无丝印标注时容易接错电源烧板。
- **怎么做**：电源针与地针分开布置并加粗；关键接口加防呆（缺针/键位/丝印 1 脚标记）；调试口旁边印引脚定义。
- **怎么查**：目检丝印与 1 脚标记；评审项：排针定义是否与原理图/丝印一致；不通过则改丝印或加防呆。

### KP-CMP-085 FPC/FFC 连接器：间距、翻盖方向、补强与触点面

- **判据**：FPC 连接器要确认：间距（0.5/1.0mm）、针数、**上接/下接（触点面）**、翻盖式/抽屉式、FPC 补强板厚度；插反或触点面不匹配会接触不良。插拔寿命常见 20~30 次，不适合频繁插拔。
- **为什么**：上接/下接由触点朝向决定，选错会导致排线金手指朝天无法接触；翻盖方向影响装配空间。
- **怎么做**：按 FPC 厂家图纸确认「金手指面 + 补强厚度 + 插入方向」；Layout 上连接器开口朝向板边便于插拔；装配说明写清插入方向与锁扣动作。
- **怎么查**：实物试插 + 通断测试；评审项：FPC 连接器上接/下接与排线是否匹配；BOM 中 FPC 24P 0.5mm 翻盖下接属项目 BOM 参考，待核验针数与触点面。

### KP-CMP-086 线对板端子（SH/ZH/GH/XH）：间距与线径匹配

- **判据**：端子选型要匹配：间距（1.0/1.25/1.5/2.5mm）、针数、卧贴/立贴、带扣/无扣、线规（AWG）与压接端子型号；额定电流随线径与针数变化。同间距不同厂家的塑壳/端子不一定互配。
- **为什么**：只按「1.25mm 2P」采购容易出现「插座能插但端子压不紧/锁不住」的兼容问题；大电流用小间距端子会发热。
- **怎么做**：BOM 同时写「连接器 + 对应端子 + 线规」；优先同厂配套（塑壳+端子+针座同一系列）；大电流（>1A）选 2.0mm 以上间距或双针并联。
- **怎么查**：实物插拔力与锁扣测试；评审项：端子与塑壳是否同系列配套；不通过则改配套型号。

### KP-CMP-087 引脚定义与防呆：以 datasheet + 实物丝印双向核对

- **判据**：连接器引脚定义（Pin 1 位置、编号方向、镜像关系）必须同时满足：原理图符号、PCB 封装、实物丝印、线缆定义四处一致；有极性的连接器必须有防呆键位或明确丝印。
- **为什么**：连接器是「板内 ↔ 板外」的边界，镜像/反向错误在样机阶段可能不暴露，量产时批量返工；线缆接反可能烧板。
- **怎么做**：封装建库时按 datasheet 的 Pin 1 标记建；原理图符号引脚号与封装一致；丝印标 1 脚与极性；线缆定义写入装配文件；首件用万用表逐一核对。
- **怎么查**：评审项：四处一致性核对表；首件通断/极性测试；不通过则改封装或改线缆。

### KP-CMP-088 连接器与模组替代风险清单

| # | 风险 | 后果 | 控制措施 |
|---|---|---|---|
| 1 | 同间距不同厂端子不互配 | 插不紧/接触不良 | 塑壳+端子同系列采购 |
| 2 | 上接/下接 FPC 选错 | 无法接触 | 按排线图纸确认触点面 |

| 4 | CC 电阻缺失或阻值错 | 插上不充电 | CC1/CC2 各 5.1k |
| 5 | 排针无 1 脚标记 | 插反烧板 | 丝印 + 防呆 |
| 6 | 连接器电流未降额 | 发热/塑壳变形 | 1.5 倍降额，大电流多针 |
| 7 | 无线模组天线区铺铜/走线 | 距离缩短/认证失败 | 按 layout guide 净空 |
| 8 | 模组峰值电流走线过细 | 发射时复位/丢包 | 按峰值电流加宽/独立供电 |
| 9 | 替代模组未重新认证评估 | 整机认证失败 | 天线/布局变更重新评估 |
| 10 | FPC 频繁插拔 | 触点磨损 | 改用板对板/连接器寿命匹配 |

- **判据**：任一项存在即判为连接器/模组选型风险。
- **为什么**：连接器与模组问题的共同点是「机械/装配/认证」维度，电气仿真常常覆盖不到。
- **怎么做**：并入选型评审门禁；连接器做实物插拔与首件通断测试；模组做净空与射频实测。
- **怎么查**：评审记录 + 首件测试 + 认证预评估。
