# 原理图评审清单（Schematic Review Checklist）

> 用途：原理图冻结（投板/写 EDA）前的逐项检查。每条都必须给出「证据」：网络名、器件位号、计算过程或 datasheet 页码；**没有证据不算通过**。检查人签字后才允许进入 PCB 布局。

## 1. 电源与上电

- [ ] 电源树完整：输入 → 保护 → 转换 → 各电源域，标注电压/电流/效率。
- [ ] 每级电源的输入/输出电容按 datasheet 配置，容值与耐压满足降额（陶瓷 ≥2×、电解 ≥1.5× 工作电压）。
- [ ] LDO 功耗 `Pd=(Vin−Vout)·Iout+Vin·Iq` 已核算，结温 `Tj=Ta+θja·Pd` 留 ≥20°C 裕量。
- [ ] Buck/Boost 电感饱和电流 > `Iout+ΔI/2`，输入电容 RMS 电流满足要求。
- [ ] EN/UVLO/软启动/上电时序明确，无悬空使能脚。
- [ ] 电源域之间电平匹配，跨域信号有电平转换或耐压确认。
- [ ] 电池/适配器/USB 多输入路径的 ORing 与优先级明确。

## 2. 复位、时钟、BOOT

- [ ] NRST 有上拉/电容或专用复位 IC，复位脉宽满足 MCU 规格。
- [ ] BOOT/模式脚按启动方式接固定电平，上电期间不被外设拉偏。
- [ ] 晶振负载电容 `C1=C2≈2(CL−Cstray)` 已按 CL 计算，ESR/驱动电平满足要求。
- [ ] 有源晶振/时钟的电源去耦、使能脚、输出电平已确认。
- [ ] 未用时钟/复位引脚按 datasheet 处理（NC/接地/上拉）。

## 3. 数字接口

- [ ] I2C 上拉电阻按速率与总线电容计算，地址无冲突，电平一致。
- [ ] SPI 每从机独立 CS，CS 默认状态明确（上拉/下拉），时钟模式匹配。
- [ ] UART TX/RX 交叉、电平匹配，调试口引出 TX/RX/GND。
- [ ] USB DP/DM 有 ESD 且结电容满足要求；USB-C CC 电阻按角色配置（Sink 两只 5.1k）。
- [ ] CAN/RS485 终端电阻、偏置、共模/隔离设计明确。
- [ ] 双向/开漏信号有正确上拉与方向控制。

## 4. 保护与 ESD

- [ ] 每个对外连接器都有 ESD/浪涌防护，器件放在连接器与芯片之间。
- [ ] TVS 钳位电压 < 后级绝对最大额定，留 ≥20% 裕量；结电容不影响信号。
- [ ] 反接/过压/过流/热插拔保护链路完整，器件额定值满足最坏情况。
- [ ] 保险丝/PTC 的 I²t 与浪涌电流匹配，不误断。
- [ ] 保护器件失效模式（短路/开路）不会造成更严重后果。

## 5. 可制造性与可测试性

- [ ] 每个关键网络有测试点（电源/地/复位/调试/关键模拟节点）。
- [ ] 器件选型都有 MPN/封装/LCSC 料号，替代料已核验。
- [ ] 调试/烧录接口可访问，不被结构件遮挡。
- [ ] 电源/地符号统一，网络命名规范，无重复/隐式网络。
- [ ] ERC 0 未处理错误；警告逐条解释并记录（豁免需理由）。

## 6. ERC 常见问题速查

| ERC 现象 | 常见原因 | 处理 |
|---|---|---|
| 引脚悬空 | 未用引脚/漏连 | 按 datasheet 接固定电平或标注 NC |
| 输出冲突 | 两个输出接同一网络 | 改开漏/加缓冲/断开 |
| 电源引脚未接 | 隐藏电源脚/多 Part 未放置 | 放置全部 Part 并连接电源 |
| 单端网络 | 只连了一个端点 | 补连接或删除 |
| 重复网络名 | 两个不同网络同名 | 重命名，避免隐式短接 |
| 网络只有两个引脚但跨页 | 连接器/端口未对应 | 核对端口映射 |
