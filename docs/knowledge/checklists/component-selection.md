# 选型评审清单（Component Selection Checklist）

> 用途：BOM 冻结/采购前的逐项检查。器件身份必须可追溯（MPN/LCSC/封装/批次），电气与工艺余量必须可计算；**没有 datasheet 依据不算通过**。

## 0. 基本信息

| BOM 文件 / 版本 | |

## 1. 身份与可采购性

- [ ] 每个器件有 MPN、制造商、封装、LCSC 料号（或明确替代方案）。
- [ ] 经 Librarian 三源核验：EDA 库 / 供应商 / datasheet 一致。
- [ ] 封装与实物一致（引脚数/间距/极性/散热焊盘）。
- [ ] 库存、交期、生命周期（EOL/NRND）满足项目计划。
- [ ] 替代料 pin-to-pin 兼容性与参数差异已核验并记录。

## 2. 电气余量

- [ ] 电阻功率 ≤50% 额定；高压分压电阻耐压满足要求。
- [ ] 电容耐压 ≥2× 工作电压（陶瓷），并核对直流偏压降容与温度特性。
- [ ] 电感饱和电流 > 峰值电流，DCR 与温升满足效率/发热预算。
- [ ] 二极管/TVS 反向电压、正向电流、钳位电压、峰值功率满足最坏情况。
- [ ] MOSFET VDS/VGS/ID/Rds(on)/Qg 满足驱动与热预算。
- [ ] LDO/Buck 输入输出范围、电流、效率、热耗满足要求。
- [ ] 晶振 CL/ESR/频差/驱动电平与 IC 匹配。
- [ ] 连接器额定电流/电压/插拔寿命满足使用场景。

## 3. 工艺与装配

- [ ] 封装在板厂/贴片厂能力内（细间距、BGA、连接器）。
- [ ] 极性器件有明确方向标识与装配图。
- [ ] 湿敏等级（MSL）与烘烤要求已记录。
- [ ] 手工/返修可行性已评估（小封装、底部焊盘）。
- [ ] 钢网/锡膏/回流曲线适配（大焊盘、散热焊盘）。

## 4. 一致性与风险

- [ ] 同容值/同阻值器件尽量归一，减少料号数量。
- [ ] 关键器件无单一来源风险，或有已核验的替代料。
- [ ] 器件工作温度范围覆盖产品环境（含外壳温升）。
- [ ] ESD 敏感器件有包装/工位防护要求。
- [ ] 认证相关器件（无线/隔离/安规）满足目标认证。

## 5. 结论

- [ ] 通过，可冻结 BOM
- [ ] 有条件通过（待核验项与责任人/期限：________）
- [ ] 不通过（必须换料或补证据）

**关联知识条目**：无源器件、二极管/TVS、三极管/MOSFET、电源 IC、MCU/无线/连接器、晶振、常用料号与封装核验；规则「BOM 必备字段」「器件身份三源核验」；失败「封装/引脚映射错误」「MLCC 直流偏压降容」「TVS 选型错误」。
