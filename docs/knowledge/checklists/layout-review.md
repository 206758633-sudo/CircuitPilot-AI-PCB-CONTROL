# Layout 评审清单（PCB Layout Review Checklist）

> 用途：PCB 布线完成、导出制造文件前的逐项检查。每条都要有证据（DRC 项、截图、计算、叠层单）；**没证据不算通过**。

## 0. 基本信息

| 项 | 内容 |
|---|---|
| 项目 / 版本 | |
| PCB 文件 / 哈希 | |
| 层数 / 板厚 / 铜厚 / 表面处理 | |
| 叠层与阻抗计算单版本 | |
| DRC 报告版本 / 未处理项 | |

## 1. 叠层与参考平面

- [ ] 叠层对称、铜厚/介质与阻抗计算单一致。
- [ ] 每个信号层都有相邻完整参考平面；关键信号未跨分割。
- [ ] 电源平面分割合理，分割缝处有桥接/缝合电容。
- [ ] 跨分割的必须跨信号已列出并逐条确认。
- [ ] 板边/拼板区无走线与器件（按板厂与分板方式）。

## 2. 电源完整性

- [ ] 每个电源引脚去耦电容 ≤2mm，回路面积最小，电容两端独立过孔。
- [ ] 体电容+近端电容组合，容值/耐压降额满足要求。
- [ ] 电源平面/铜皮载流满足峰值电流，瓶颈处加宽/多孔。
- [ ] DC-DC 输入电容-SW-电感-输出电容功率环路最小。
- [ ] 反馈走线远离 SW 节点，取自输出电容之后。
- [ ] 地平面完整，模拟/数字分区不破坏回流。

## 3. 信号完整性

- [ ] 阻抗线按计算单线宽/间距，全程同层同参考。
- [ ] 差分对等长（≤5mil）、等距、不跨分割、换层成对并补地孔。
- [ ] 高速信号过孔旁有回流地孔。
- [ ] 敏感线（复位/时钟/模拟）远离高速/开关节点，并行长度受控。
- [ ] 时钟/晶振走线短、对称、下方净空。
- [ ] 长 stub、悬空铜、天线化铜皮已清理。

## 4. EMC / ESD

- [ ] 接口 TVS 靠连接器，地端短宽多孔，受保护线无分支绕过。
- [ ] 开关节点铜皮最小，电感/二极管环路紧凑。
- [ ] 接口滤波（共模/磁珠/电容）位置正确，地回路短。
- [ ] 晶振/时钟/复位区域有地保护与包地。
- [ ] 连接器屏蔽壳/机壳地与信号地连接方式符合设计。

## 5. 热设计

- [ ] 功率器件散热焊盘过孔阵列 + 大面积铜，过孔塞孔防漏锡。
- [ ] Tj 按实际铜面积估算并留裕量；热源远离温度敏感器件。
- [ ] 大电流走线温升与压降满足要求。
- [ ] 外壳/风道/散热器安装空间已确认。

## 6. DFM / 制造

- [ ] 最小线宽/间距/孔径/孔环在板厂能力内，细间距区有 EQ 确认。
- [ ] 阻焊开窗/阻焊桥合规；丝印不压焊盘，字高 ≥0.8mm。
- [ ] 器件距板边/V-cut ≥要求；拼板工艺边 ≥5mm。
- [ ] 光学定位点 3 个以上、非对称、开窗正确。
- [ ] 层命名/板框/原点/单位一致；Gerber 逐层目检通过。
- [ ] BOM、坐标文件、贴片图、版本号一致。

## 7. 测试与可维护性

- [ ] 电源/地/复位/调试/关键模拟节点有测试点。
- [ ] 测试点不被屏蔽罩/电池/结构件遮挡。
- [ ] 调试接口可插拔，方向标识清晰。
- [ ] 关键信号有探点或可飞线位置。

## 8. DRC / 结论

- [ ] DRC 0 未解释项；豁免逐条有理由、对象、批准人。
- [ ] ERC 与 DRC 报告随版本归档。
- [ ] 通过 / 有条件通过（问题清单：________）/ 不通过

**关联知识条目**：叠层与阻抗、布局布线、电源完整性、EMC/ESD/热、DFM 与制造文件；规则「载流线宽」「过孔载流」「去耦距离」「差分等长」「DRC 豁免」；失败「载流不足烧线」「阻抗失配」「EMI 超标」「板翘」。
