## 3. 拓扑判读

```
CN1(外置+) ── Q1.S ▐Q1▌ Q1.D ──●── Q2.D ▐Q2▌ Q2.S ──┐
                     (共漏)      └─ 中点悬空            │
   CN1(+) ──→ U1 VIN                                   ├── VDC ──┬── 负载 ── GND
                 U1 +VO ──→ CN2(+)                     │          │
CN2(内置+) ── Q3.S ▐Q3▌ Q3.D ──●── Q4.D ▐Q4▌ Q4.S ────┘          GND
                     (共漏)      └─ 中点悬空

G1→Q1.G   G2→Q2.G   G3→Q3.G   G4→Q4.G   （均为裸栅极，无驱动）
```

- **外置通路**：CN1+ → Q1(S→D) → 共漏点 → Q2(D→S) → VDC，标准背靠背共漏双向阻断开关。
- **内置通路**：CN2+ → Q3(S→D) → 共漏点 → Q4(D→S) → VDC，同构。
- **U1**：输入取外置电池 +，输出 +VO 直接接到内置电池 +（与会话中描述的"U1 +VO 接内置电池正极"一致），−Vo 与 GND 短接（非隔离用法）。
- **负载**：电阻符号跨接 VDC–GND，为电机负载占位。

## 4. 与需求讨论的吻合度校验

| 需求要点 | 本图实现 | 结论 |
|---|---|---|
| 背靠背 N-MOS 双向阻断 | Q1/Q2、Q3/Q4 共漏背靠背 | ✅ 一致 |
| Q3 作"单向阀"（体二极管方向 电池→中点） | Q3.S 接内置电池 +，D 接中点 → 体二极管正向为电池→中点 | ✅ 与用户修正的 T2 方案完全对应 |
| Q4 作双向通道 | Q4.S 接 VDC，D 接中点 | ✅ 与"Q3 关断、Q4 导通续流"一致 |
| 外置优先、内置备接 | 拓扑支持；**但无任何自动判定电路** | ⚠️ 逻辑全在板外 |
| U1 = 充电模块示意 | 原理图沿用原连接（+VO→电池+） | ⚠️ 与会话判定的"过充风险"仍在 |
| G1–G4 由另一块板驱动 | 只有网络标签 | ❌ 板上无驱动、无接口 |

## 5. 问题清单

### 🔴 阻断级（当前板做不出验证结果）

| ID | 问题 | 说明 |
|---|---|---|
| **E-1** | **无栅极驱动 / 无电荷泵** | G1–G4 直接落在栅极，无驱动器、无电荷泵、无栅极电阻、无下拉。Q1/Q2 源极浮在外置电池上、Q3/Q4 源极浮在电池/母线上，3.3/5 V 逻辑根本无法建立 Vgs。这正是会议说的"需要加电荷泵"。 |
| **E-2** | **无控制接口** | G1–G4 只是网络标签，没有排针/连接器/测试点，外部控制板无法接入。单页工程内这 4 个网络是"单引脚网络"。 |
| **E-3** | **无母线电容** | 全图除 U1 外无任何电容。2 kW / 42 A 下，1000 µF 也只能维持约 24 µs/1 V 的掉压；没有储能，切换瞬态必崩。 |

### 🟠 重要（规格不符 / 安全）

| ID | 问题 | 说明 |
|---|---|---|
| **E-4** | **XT30 额定 15 A** | 器件库参数明确 rated current = 15 A，而系统 42–50 A → 严重欠额，接触电阻 0.65 mΩ×2 也会显著发热。建议 XT60/XT90/AS150 或大电流端子。 |
| **E-5** | **U1 电压域不匹配** | URB2412YMD-30WR3 输入 9–36 V，若外置为 48 V 级则超压；输出 12 V 也无法给 48 V 内置电池充电。若仅作"充电模块示意"可接受，但必须标注，否则误导后续设计。 |
| **E-6** | U1 外围缺失 | 无输入/输出电容、无使能控制，**CTRL（6 脚）与 TRIM（4 脚）悬空**；CTRL 悬空的开/关状态需按手册确认。 |
| **E-7** | **无 TVS / 泄放 / 制动斩波** | 电机回馈泵升能量无出路，会话里认定的最大风险点没有对应电路。 |
| **E-8** | **无外置电池在位检测、无电压采样** | 会议明确要求"检测外置电池在不在 → 采样电路"，图上完全没有。 |
| **E-9** | **Q1 标注"可省略"** | 若去掉 Q1，仅内置供电时 Q2 体二极管会把 VDC 引到外置 XT30 **公头端子上（带电外露）**，同时失去对外置口的反向阻断。省管需配合防反接或改用母座/带保护端子。 |
| **E-10** | 无防反接、无保险丝、无限流、无电流采样 | 热插拔浪涌（2 kW 级可达数百 A）没有任何限制手段。 |

## 6. 结论

这份初版原理图的**功率拓扑是对的**：两路背靠背共漏 N-MOS + U1 取外置电给内置电池 + 假负载，正好对应讨论中"Q3 当理想二极管、Q4 当双向通道、外置优先内置备接"的骨架，`Q3.S=INT+ / Q4.S=VDC` 的朝向与用户修正后的 T2/T3 时序完全吻合，说明画图时已经吸收了那轮讨论。

但它是**纯功率骨架草图**，距离"能验证的可运行板"还差三类电路：

1. **驱动层**：电荷泵 + 4 路栅极驱动 + 栅极电阻/下拉（E-1）
2. **控制/检测层**：G1–G4 接口、电池在位检测、电压采样（E-2、E-8）
3. **保护/储能层**：母线电容、TVS、泄放/斩波、防反接与限流（E-3、E-7、E-10）

另外 3 个明确的规格冲突需要先定：**XT30 15 A vs 42 A**（E-4）、**U1 输入 9–36 V vs 48 V 系统**（E-5）、**Q1 是否真的可省**（E-9）。
