2. **#4 `$2N23`（+3V3 / MIC_VDD）——high**

3. **#5–#28 `CAM_1`…`CAM_24` 同名重复标签（24 条）——low**

4. **#29–#30 器件标准化（47 个元件）——medium**

**核心结论：GND 铺铜存在且网络名正确，但 GND 网络与器件地脚完全没有连接（无 GND 焊盘/走线/过孔、网络长度 0）。因此 GND 过孔缝合的“前置条件不成立”——缝合孔无处可连，必须先修 GND 网络。** 该状态与第二节 `$2N8` 冲突（GND 引脚被归到 +3V3）高度相关：PCB 焊盘也表现为 GND 全部变成了 +3V3（31 个焊盘在 +3V3 上，0 个在 GND 上）。

### 4.2 候选网格/密度建议（参数化，非放置计划）

- 一般数字/音频区：**8–10 mm** 网格；板边一圈 ≤10 mm；RF/时钟/USB/DVP 等敏感区域收紧到 **4–6 mm**（λ/20 @2.4GHz ≈ 6.25 mm）。
- 按当前板框（56.3×62.1 mm）粗算：10mm 网格 ≈ 32 个候选、8mm ≈ 47、6mm ≈ 88、5mm ≈ 108（已做焊盘/过孔/走线**粗避让**，未做 DRC 与铺铜连通性验证）。
- 板边缝合估算：间距 5/8/10 mm → 约 47/30/24 个孔。
- 所有网格候选的 `readiness` 当前均为 `blocked:blocked-gnd-net-isolated` —— 即**参数可参考，但结论是“先别放”**。

### 4.3 必须人工确认项（摘录，完整见 MD）

1. 先修 GND 网络本身（`$2N8`/`$2N23` 网络名冲突 → 重同步 PCB → 确认 GND 焊盘网络正确）。
2. 确认 GND 别名/优先级（AGND/PGND 是否合并）。
3. 确认内层 GND 平面（L15/L16）与 GND 过孔/焊盘的连通性（当前是孤岛）。
4. 确认规则集与 4 层叠层匹配（当前规则名像 2 层板）。
5. 过孔尺寸/孔环符合板厂工艺；缝合位置避开天线净空、安装孔、晶振/模拟区、连接器本体。
6. 实际放置后必须重建铺铜 + 重跑 DRC，并确认 GND 连通性（不能只看“无 DRC 报错”）。

## 六、建议执行顺序

1. **P0（阻断性）**：核查并修复 `$2N8`（GND/+3V3）与 `$2N23`（+3V3/MIC_VDD）——修复前禁止上电；修完后重导网表确认 10 个 GND 引脚回到 GND 网络。
2. **P0（可制造性）**：修复 MK1（`LMA2718B381-OFA08`，实例 `$2I8`）封装——补 1/2/3 焊盘；PCB 回读确认焊盘存在。
3. **P1（BOM 正确性）**：47 个元件器件标准化，核对 LCSC/MPN/封装与 BOM。
4. **P2（接线完整性）**：按第三节清单处理 171 个悬空引脚：7 条“应连接”优先补线/补网络；51 个整器件未连接件决定删件/DNP/补线；其余确认后标 NC。
5. **P2（网络名清理）**：删除 24 条 CAM_n 重复同名标签（低危噪音）。
6. **P3（GND 缝合）**：GND 网络修好并重同步 PCB → 确认 GND 焊盘/过孔连通 → 按 4.2 的密度建议人工放置缝合过孔 → 重建铺铜 → 重跑 DRC。

> 顺序理由：GND 不通时谈缝合没有意义；MK1 无焊盘时板子不可制造；BOM 与接线问题相互独立但都阻断“可交付”。
