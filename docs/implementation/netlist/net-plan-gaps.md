要点：
- **供电链路（与需求/设计计划一致）**：`USB-C VBUS → U2 ETA9880(IN=BAT 充电 + SW/L1 升压) → VOUT → Q16(SI2305 负载开关) → +5V → U6 SY8301 buck → 3V3`；`3V3 → U7 ME6211C28 → 2V8`、`3V3 → U20 ME6211C15 → 1V5`；CH334F(U5) 由 3V3 单电源供电（V5/VDD33 均接 3V3，全量提取对照）；`+5V` 不直接来自 Type-C VBUS（满足需求约束）。
- **地网络**：当前采用单一 `GND` 网（按引脚名 GND/VSS/EP/GNDA/GNDD 判地，90 pin）。参考 PDF 另存在 `AU_GND`（音频模拟地，25 处标签）与 `AGND`（摄像头模拟地）域，本计划暂并入 GND，**模拟星点/单点接地需人工确认**（见第 5 节 I-09）。
- 电源域：VOUT(升压输出)/VBUS(输入)/VBAT(电池)/+5V(负载开关后)/3V3(buck)/2V8(U7)/1V5(U20)/AVDD_2V8(摄像头AVDD)/CODEC_3V3(ES8311)/CODEC_AVDD/ADC_3V3(ES7210)/AMP_VCC(NS4150B)/MIC_VDD(MIC偏置)/ADC_MICBIAS12；SY8301 自举 SY_BS、反馈 SY_FB、LX。

### 2.2 U1 / U4 / U5 / U8 pin 级网络（矢量提取交叉验证）
- U1 ESP32-S3-WROOM-1（38 个已定 + 6 个备用 IO gap）：DVP 8 数据线 + PCLK/XCLK/VSYNC/HREF/PWDN/RESET、I2S（MCK/BCK/WS/DI/DO）、I2C（IO1/IO2）、UART0（U0TXD/U0RXD）、USB（IO19/IO20）、TOUCH10、BAT_SAMPLE、MOTOR、LED(WS2812)、PA_EN、IO0_BOOT。
- U4 CH340K / U5 CH334F：USB 上行（DPU/DMU ↔ Type-C）、CH340 侧（DP4/DM4）、ESP32 原生 USB 侧（DP3/DM3 ↔ IO20/IO19）、11 个 gap（未用下行端口/配置脚/CTS）。
- U8 摄像头 FPC：16 个已定（D0-D7/PCLK/XCLK/VSYNC/HREF/PWDN/RESET/SDA/SCL/2V8），6 个 gap（FPC 脚序为人工输入项）。

### 2.3 其它已定网络
- 自动下载电路：R13/R14 + Q1 双 NPN（B1←DTR、C1→RESET、E1→RTS；B2←RTS、C2→IO0_BOOT、E2→DTR，标准 ESP 自动下载拓扑）；R1/R2 上拉、C7 复位滤波。
- Type-C：CC1/CC2 5.1k 下拉（R11/R12）、USB_D± ESD（D11/D13）、VBUS ESD（D12）、SBU1/2 gap。
- 充电/升压：C2(BAT)、C3-C9(VOUT)、L1 升压电感、BOOST_SW；SY8301 反馈 R8/R9 + EN R18；ME6211 使能按 VIN 上拉。
- 音频数字链路：I2S 三总线 + ES8311(0x18)/ES7210(0x41) I2C，ES8311 I2C 使用 CCLK/CDATA（pin1=IO2_I2C_SCL、pin19=IO1_I2C_SDA），SCLK(pin6)=I2S BCK；ES7210 CDATA/CCLK=pin3/4。
- 电池采样：R10 47k + R7 91k + C86 100nF → BAT_SAMPLE(IO11)。
- **两脚无源件已按 `/tmp/ref_nets_full.json` 器件级网对自动匹配 79 个（C 组 58 + R 组 20 + L1）**，证据标 reference，并注明"两脚方向按几何约定 (low)"；无法两端定名的（音频耦合/参考内部节点、V2.0 独有位号）保留 gap。
- 音频模拟链路（全量提取对齐）：`ES8311 OUTP/OUTN → C46/C47 → R31/R29(0Ω) → OUTP/OUTN 节点 → C72/C73(100nF) → R42/R43(100k) → NS4150B INP/INN`，输出经 R39/R41 0Ω 至 J7；MIC1 → R49/C85 → ADC_MIC1P → C65 → ES7210 MIC1P；MIC 偏置 MIC_VDD←R51←ADC_MICBIAS12。
- WS2812 灯链：U1.IO21 → WS2812_DIN → LED5→LED7→LED8→LED9→LED10 串联（链序为工程假设，待人工确认）；U14.3 亦并接 WS2812_DIN（外部灯环）。
- 外部接口：U13.1=MOTOR、U13.2=+5V、U13.3/4/5=GND、U14.1=+5V、U14.3=WS2812_DIN（全量提取）；电池接口 **CN5.1=GND、CN5.2=VBAT**（全量提取 N$001=GND 判据，修正了初版极性假设）。
