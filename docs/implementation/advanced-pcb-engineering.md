# 三阶段 PCB 工程引擎实施记录

日期：2026-08-25  
OpenSpec：`add-advanced-pcb-engineering-engines`

## 已完成范围

1. 高速数字：USB 2.0、CAN、RS485、SPI、最高 200 MHz 时钟的解析阻抗、传播时延、差分偏差、等长、串扰间距和连续参考面门禁。
2. 多层与 HDI：4/6/8 铜层叠层证据、盲埋孔/微孔与顺序压合能力、最短层切换、叠孔限制、回流缝合计划和 BGA 逃逸容量分析。
3. 2.4 GHz RF：CPWG 解析估算、导波波长、天线禁布区证据、接地过孔围栏和不可执行的 openEMS 仿真交接清单。
4. 通用工程能力：确定性约束布局、碰撞门禁、参考标号丝印候选、SHA-256 不可变报告及操作清单。
5. 嘉立创EDA 边界：仅编译现有白名单 `pcb.component.modify`、`pcb.line.create`、`pcb.via.create` 操作；分析不会自动执行，仍走现有快照、绑定审批、回读、官方 DRC 和失败回滚流程。
6. 产品界面：验证中心提供三套可点击黄金样板，并展示报告哈希、工程发现、待审批操作数和生产边界。

## 黄金样板

- `HS-USB2-4L`：四层 USB 2.0 差分网络。
- `HDI-BGA-6L`：六层、两级微孔和 BGA 逃逸。
- `RF-24G-4L`：四层 2.4 GHz CPWG、天线禁布、围栏与 openEMS 结果证据。

三套样板均必须确定性通过解析门禁；重复输入必须产生相同报告哈希。破坏回流、串扰间距、等长、微孔堆叠、天线资料或外部仿真哈希时必须阻断。

## 明确限制

- 解析模型用于早期设计与门禁，不替代板厂阻抗计算、场求解器、实测 TDR/VNA 或认证证据。
- openEMS 当前是不可执行交接格式；系统不会运行任意外部模型命令。仿真结果必须由外部工具生成后按哈希导入。
- 自动丝印目前生成无碰撞候选，不直接写入嘉立创EDA；当前桥接尚无已验证的官方丝印写入契约。
- 任何工程分析“通过”都不等于可投产；官方 DRC、嘉立创在线 DFM、Gerber/BOM/CPL 不可变清单和人工审批仍是硬门禁。
- 当前 CH32V003 设计未被这些黄金样板修改。

## 成功执行经验

- 黄金样板必须进入默认测试命令，不能只在算法目录单独运行。
- 计算报告中不能包含当前时间等非确定字段，否则相同输入无法稳定绑定审批。
- 工程算法和嘉立创EDA 写入必须分层：先产生可复核语义报告，再编译白名单操作，最后由既有审批执行器负责写入和回滚。
- 对 HDI 和 RF，缺少板厂顺序压合或外部仿真证据时应硬阻断，而不是用默认参数悄悄放行。
