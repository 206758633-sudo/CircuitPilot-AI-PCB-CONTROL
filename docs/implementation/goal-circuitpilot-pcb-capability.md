# 目标锚定：提升 CircuitPilot 的 PCB 设计能力（非单板修补）

> 本文件是后续所有改动的“北极星”，用于防止把工作做成“为某块测试板打补丁”。
> 任何改动提交前必须回答一个问题：**它提升的是 CircuitPilot 的通用能力，还是只对这块板有效？**

## 1. 一句话目标

**让 CircuitPilot 具备“工程师级”的 PCB 设计能力：给定任意一份真实需求（PRD + 尺寸/结构约束 + 器件/成本约束），能自主完成“规格→原理图→PCB→验证→可制造文件”的闭环，并用证据证明结果可信；测试板只是验收样本，不是改造对象。**

## 2. 能力定义（L0~L4，跨板通用）

| 层级 | 能力 | 判定（与具体板无关） |
|---|---|---|
| L0 | BOM/选型草案 | 料号可解析、库存价格可用 |
| **L1** | 需求→原理图 | ERC=0、意图网表 vs 实际网表 diff=0、BOM 冻结、需求逐条有映射 |
| **L2** | 原理图→PCB | DRC=0、DFM 通过、Gerber/BOM/CPL/装配图一致且与设计绑定 |
| L3 | 工程师级布局/布线/EMC/热 | 与工程师方案对比差异可解释、首样通过率达标 |
| L4 | 样机反馈迭代 | 问题单→回归用例→下一版闭环 |

**当前短板：低于 L1**（无规格源、无网表 diff、选型全重来、无双板工作流、门禁只看部分证据）。
**本阶段目标：稳定达到 L2，并为 L3/L4 建好地基。**

## 3. 要建的五项通用能力（与板无关）

1. **规格能力**：`design-spec`（板卡/接口/意图网表/BOM 锁/验收矩阵）作为唯一事实来源；DXF→板框是通用转换，不写死坐标。
2. **知识能力**：联网检索（已起步）+ EDA 库 + 嘉立创供应链 + datasheet 三源核验；K0 知识库沉淀失败/规则/器件身份。
3. **验证能力**：确定性 agent（Netlist Auditor / Rule Runner）+ Gate Engine；生成方不得自证。
4. **门禁能力**：G1~G6 硬门禁 + 证据 sha256 绑定 pcbUuid + 人工终审；缺证据=fail-closed。
5. **学习能力**：Field Loop 把样机/产测问题回灌为回归用例，越用越准。

## 4. 验收标准（跨板盲测）

- 至少 **2 块此前没见过的新需求板**跑完整链路，而非只在一块测试板上“调通”；
- 每块板：ERC=0、意图/实际网表 diff=0、DRC=0、DFM 通过、需求 100% 有证据映射；
- 门禁一次通过率、与工程师方案的差异率、回归用例增量可度量；
- 测试板与参考工程只作为**回归 fixture 与验收基准**，不参与设计输入。

## 5. 防偏航规则（硬约束）

- ❌ 不为某块板写死坐标、料号、网络名、例外逻辑；
- ❌ 不导入/复制参考工程当答案（只做解析基准）；
- ✅ 每个修复先抽成“通用规则/检查项”，再用测试板验证；
- ✅ 新增能力必须带单测 + 至少一个跨板可复用的证据格式；
- ✅ 汇报时区分：能力已建 / 仅在样本板验证 / 尚未验证。
