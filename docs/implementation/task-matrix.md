## 验证纪律
- 不以"调用没报错"当成功：每个结论必须有**读数/文件/对照**；
- 区分：真机验证 / 有代码未验 / 缺失；
- 出现反例（如不填豁免=0/156）必须保留，证明没有静默放行。
