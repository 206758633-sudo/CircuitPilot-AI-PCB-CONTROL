## 1. 关于“查找市场规则”的说明（先讲限制）

本机**无外网**，已实际尝试两种查找方式，均失败：

- `web_search`：报错 `DeepSeek search has no API key for "DEEPSEEK_API_KEY"`；
- `web_fetch`：报错 `URL hostname "www.ipc.org" resolves to a non-public IP address`（网络策略拦截）。

因此本期“查找”采用**可核对的替代证据源**：

1. 公开标准框架：IPC-2221B/2222B（设计）、IPC-7351B（焊盘/courtyard）、IPC-A-610/J-STD-001（验收）、J-STD-020（MSL/回流）、IPC-7093（底部端子）；
2. 器件 datasheet 的通用 Layout/Application 章节（TI/ADI/ST/Espressif/Nordic 等的公开布局原则）；
3. **本地真实工程记录**：衣橱助手 V1.2/V2.0、CircuitPilot 6 层监测板、CH32V003 P0；
4. **公开参考设计案例**：Pico/RP2040、Arduino Uno、ESP32-DevKitC、STM32 Nucleo（已在案例库中整理）。

所有“市场产品做法”均标注为 **D 级证据（未联网核对/未拆解验证）**，只用于理解优先级与惯例，不作为具体数值依据。

## 3. “依据规则”摘要（回答用户问题）

元器件布局/部署位置的依据可归纳为六层，优先级从上到下：

| 层 | 依据 | 回答什么问题 | 典型规则 |
|---|---|---|---|
| 1 | 安全/法规/认证（IEC/UL/GB） | 爬电/间隙/隔离/阻燃能否满足 | 隔离带宽度、爬电距离、认证间距 |
| 2 | 器件 datasheet / 厂商 layout guide | 这个器件要求怎么摆 | 去耦距离、晶振负载电容、DC-DC 热环路、RF 净空 |
| 3 | IPC 标准（2221/2222/7351B/610/7093） | 通用设计/焊盘/验收基线 | courtyard、间距、焊盘、可检性 |
| 4 | 板厂/贴片厂工艺能力 | 能不能做、良率如何 | 最小间距、阻焊桥、拼板、波峰焊、ICT |
| 5 | 市场产品/参考设计（D 级证据） | 同类产品实际怎么做、优先级是什么 | 连接器靠边、天线朝外、高密度/屏蔽罩、测试点 |
| 6 | 仿真/实测 | 本板到底行不行 | SI/PI/热仿真、TDR、热像、试产良率 |

市场实际做法的“规则化”结论（本期沉淀）：

1. **先结构/连接器/天线，再功能**：连接器沿板边开口朝外，RF 模组靠边天线朝外，安装孔/外壳 3D 先定。
2. **去耦看回路不看数量**：0.1µF 距引脚 ≤2mm、地过孔 ≤1mm、每端 ≥1 孔，电源先经电容再到引脚。
3. **晶振靠芯片、包地、下方不走线**，时钟远离 I/O/板边。
4. **DC-DC 先管输入热环路**：输入电容紧贴 VIN/PGND、SW 节点最小、反馈在输出电容之后。
5. **ESD 器件靠连接器、先于 IC、地短而宽**，结电容满足速率。
6. **间距取四层判据最大值**：IPC-7351B courtyard + 吸嘴 + 返修（1–2mm）+ 高件遮挡，量产板再留 0.1–0.3mm 余量。
7. **朝向统一/极性一致/连接器开口朝外**，便于 AOI 与返修。
8. **板边/拼板留工艺余量**（3–5mm 经验），分板应力区禁放易损件，Mark 点/工艺边按贴片厂。
9. **热源分散、热敏感件远离**（传感器 ≥5mm 经验），热过孔/铜皮按 θja。
10. **测试点按探针网格**（2.54/1.27mm），关键网络可测、不被高件遮挡；关键器件留返修空间。

## 5. 已知限制与后续

1. **未能联网核对**：IPC 原文、厂商 app note、拆解报告均未联网获取；文中数值为工程经验范围，必须按标准版本/datasheet/板厂能力/仿真复核。
2. **市场证据为 D 级**：消费/工业/开发板的“常见做法”来自公开资料与本地/公开参考设计，未做拆解验证；只用于优先级判断，不能直接当项目规则。
3. **条目仍全部 candidate**：280 条知识无一 approved，需人工审核（审核人必填）后才能作为门禁引用。
4. **建议下一步**：让 16 条 `PLACE-*` 规则进入人工评审；补充消费电子/工业控制各 1 块真实板的布局拆解（有实物/高清图时）；把布局依据链接入项目评审模板与 DFM/DFA 检查表。
