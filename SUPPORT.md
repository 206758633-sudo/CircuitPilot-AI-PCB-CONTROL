# Support

- **Bugs / feature requests:** GitHub Issues with the provided templates.
- **Security:** GitHub Security Advisories (see [SECURITY.md](SECURITY.md)).
- **Usage questions:** GitHub Discussions (enable it in repository settings if
  it is not enabled yet).

This is a maintainer-driven open-source project; there is no SLA. Please do
not send real customer designs, credentials, or proprietary files. For
commercial support or custom integration, open a discussion first.
